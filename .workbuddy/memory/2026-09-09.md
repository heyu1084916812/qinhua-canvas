## 本组踩坑（已写进 M0-对话交接.md 第 3 组）

1. `react-jsx` 无全局 React → `React.XxxEvent` 必须显式 type import。
2. ESLint 需开 `argsIgnorePattern/varsIgnorePattern: '^_'` 对齐 tsconfig。
3. `no-node-cross-talk` 误报 barrel 与同目录 css → 收紧为「节点实现目录 → 另一节点实现目录的 .ts/.tsx」。
4. TS6 + React18 `createElement` 泛型推断失效 → 显式 `createElement<AppProps>`。
5. 无 jsdom → 用 `react-dom/server` 的 `renderToString` 做整树冒烟；`PlatformProvider/App` 增 `runtime` 参数（测试传 memory 避开 IndexedDB）。
6. **并行 Edit 同一文件会丢改动**（后写覆盖前一次基于旧快照的结果）——同文件多次编辑必须串行。
