feat(canvas): prompt body formatting, text editor lightbox

用户 2026-09-21：「把文本框变成大一点的编辑框，就像灯箱一样」，配一排
格式按钮（H1/H2/H3/正文 | B/I/无序/有序/分隔线 | 复制/全屏），
核心诉求是**不想看到 `#` `**` 这些符号**。

底层用 Markdown 字符串，不用富文本
- 理由是对模型更好：`##` `**` 是主流图像模型见过的语义标记，HTML 标签对它是
  噪音（占 token 却不描述画面）。**生成链路完全没动**（仍是 text 原样发出）。
- 新增 domain/canvas/text/markdownFormat.ts：行级（标题/列表/正文）与行内
  （粗体/斜体）格式变换，纯函数、按字符下标出入光标。
  要点是**幂等**——先摘旧前缀再加新前缀，否则点两次 H2 会变成 `## ## 标题`。
- 新增 markdownRender.ts：Markdown → 结构化块（不是 HTML 字符串，免疫注入）。
  只支持子集，**认不出的语法原样显示**，绝不吞字符。

没有做「透明 textarea 叠渲染层」
- 试过并否决：Markdown 符号在渲染层不占宽度、在 textarea 里占宽度，只要有一行
  折行两层就错位（中文长提示词必然折行），表现为「点这儿光标在那儿」。
- 改为**左编辑 / 右预览**：编辑区是带符号的真实文本（保住光标与输入法），
  预览隐藏符号。真正的所见即所得要完整富文本实现，未做（已记入清单）。

界面
- 新增 text/FormatToolbar.tsx：节点跟随栏与灯箱**共用同一个组件**，
  按钮顺序与选中态永远一致；列表/分隔线用图形符（中文标签会把整排撑长）。
- 新增 text/TextEditorLayer.tsx：观感同素材灯箱（居中大面板、四周留白、
  不能移动），Esc / 点面板外关闭，右上角按钮是开关；store 里与素材灯箱**互斥**。
- 提示词节点的跟随栏从「生成/重命名/复制/删除」换成格式工具栏
  （节点栏无光标，格式作用于整个正文的逐行）。
- 节点本体按 Markdown 渲染：标题变大、粗体加粗，**符号不显示**。
- 双击正文改为**全选**（不再是进节点内编辑态，那个 textarea 已删）。
- 右键菜单新增「全屏编辑」（只有提示词节点有，排在编辑类）。
