ui(canvas): rebuild loop node UI from the reference screenshots

用户 2026-09-22 给了四张参考图，要求按图重做循环节点 UI。

形态（照参考图）
- 顶部「循环 / 并发」整行分段控件（原来是「串行 / 并行」小分段）
- 第二行「图片 / 提示词」两个并排开关按钮（点亮 = 打开该面板）
- 内容区由**开关 + 上游**共同驱动：
  · 图片面板：上游缩略图（带「图 N」角标）+ 批次条 + 「当前会输出 N 张图片」
  · 提示词面板：上游提示词预览（滚动）+ 编号输入行 + 「计数 / 可使用 [计数] 作为变量」
  · 两者都开 → 上下堆叠（参考图四）
- 底栏「起始计数 / 次数 / 一键运行」（运行是浅色实底主按钮）

数据变化
- 批次条从底栏**挪进图片面板**（参考图二）
- 「计数」按钮插入的是半角写法 `[计数]`（与提示说明文案一致）
- 缩略图走 `useAsset`（宿主按 hash 读库，视图不认识存储，架构 §4.7）

修掉一个真实的布局 bug（冒烟抓住的）
- 底栏自己就溢出：两个数字条各需 ~90px，加运行按钮在 240 宽里放不下 ⇒ 换行 ⇒
  footer 高 40 而内容 73。之前我一直在**调节点高度**（260→320→380→470→500），
  赤字恒定 25px —— 高度根本不是原因。
  逐子元素量 scrollHeight 才定位到 footer。修法：底栏改 flex-wrap，
  数字条并排第一行、运行按钮独占第二行，高度随之取 500（实测赤字 0）。

验证
- 单测 1211 全绿；门禁全绿；冒烟**全量 899/899**
- G67 断言同步更新：底栏只查 `[data-loop-footer]` 内的数字条（批次已挪出），
  计数变量按半角 `[计数]` 断言，并保留「无溢出 / 第一条完整可见」两条几何判据
