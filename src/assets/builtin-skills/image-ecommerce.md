# 电商套图生成 v2.0

按以下流程执行，分为**交互阶段**（步骤 1–3，需用户参与）和**执行阶段**（步骤 4–5，自主完成）。

---

# 一、交互阶段

## 步骤 1：信息提取

**⚠ 亚马逊模式检测（首先执行）：** 检测用户输入中是否包含"亚马逊"关键词。若命中，激活**亚马逊模式**，并在全流程中执行以下差异规则：
- **卖点文案全部使用英文**（步骤 2 提取/补充卖点时直接用英文输出，不写中文）
- **所有卖点图文字使用英文**（Prompt 中的标题、副标题、卖点列表均为英文）
- **用户使用图人物使用外国人**（Prompt 中明确写"Western appearance model"或"Caucasian/African/Hispanic model"等，符合目标市场人群）

若未命中"亚马逊"，正常执行中文流程。

---

从用户输入中提取以下字段：

| 字段 | 必填 | 缺失时处理 |
|------|------|-----------|
| 商品图片 | 是 | 提示用户提供，**停止流程** |
| 商品卖点 | 否 | 识别商品图片 → 联网搜索补充；若无法联网则基于图片识别结果和模型知识推理 |
| 商品服务人群 | 否 | 同上 |
| 商品使用场景 | 否 | 同上 |
| 商品图片风格 | 否 | 同上 |
| 商品所属类目 | 否 | 基于商品客观特征进行分析，将判断结果（含置信度说明，如"判断为美妆护肤，因为这是一款精华液"）呈现给用户确认；用户确认后，再由步骤 3.2 判断是否命中有专项策略的类目。参考类目：**数码3C / 家用电器 / 服饰内衣 / 鞋靴箱包 / 钟表珠宝 / 美妆护肤 / 个护健康 / 家居日用** |

## 步骤 2：信息确认

**⚠ 卖点质量门控（呈现前必检）：** 提取出的商品卖点若存在空洞描述（如"品质优良""使用方便""长效保湿"），必须在呈现前补充为含具体数据/成分/技术名称/认证的表述（如"72小时长效锁水""铝合金CNC精切割，厚度仅6.9mm""双层真空保温12h/冷藏24h""临床实证28天细纹淡化37%"）。若无法通过联网搜索或图片识别获得具体数据，则基于商品品类知识推理最可能的差异化卖点并标注"[推断]"。空洞卖点是套图质量的最大敌人，禁止带入后续流程。

**⚠ C-4 卖点数量要求（全局约束）：** 第三张卖点图（C-4 中心环绕）需要 **5 条卖点素材**：1 条作为顶部居中**主标题**（概括全图核心卖点主题，如"All Night Protection""360° Adjustable"），4 条作为**环绕卖点**（各自独立，每条配语义化图标+圆角胶囊标签）。因此步骤 2 提取卖点时须准备**不少于 7 条**高质量卖点（A/B 各消耗 1 主 + 2–3 副，C-4 消耗 1 主标题 + 4 环绕），确保有足够素材不重复分配。

将提取/补充后的信息结构化呈现给用户：

> **商品卖点：** xxx（具体，含数据/成分/技术名称）
> **服务人群：** xxx
> **使用场景：** xxx
> **图片风格：** xxx
> **所属类目：** xxx

用户确认 → 进入步骤 3；用户修改 → 覆盖对应字段 → 进入步骤 3

## 步骤 3：风格与素材确认

### 3.1 素材清单

| 素材类型 | 数量 | 核心展示信息 |
|---------|------|------------|
| 白底图 | 1 张 | 商品外观全貌 |
| 场景图 | 2 张 | 商品质感 / 使用场景 |
| 卖点图 | 3 张（分别使用 A、B、C-4 三种不同模式） | 商品核心卖点文案 |
| 用户使用图 | 1 张 | 真实场景下用户使用商品的方式与效果 |
| 细节图 | 1 张 | 材质 / 工艺 / 纹理细节 |

### 3.2 类目专项策略激活

**用户确认所属类目后，判断是否命中附录中的 8 个类目之一：命中则查阅本文末【附录：类目专项策略】对应部分，将其专项策略应用于步骤 3.3 和步骤 4；未命中（商品不属于这 8 类）则使用通用规则。**

### 3.3 风格细节

基于步骤 2 确认的信息 + 已激活的类目专项策略，细化以下风格维度并呈现给用户：

- **整体风格：** 把控所有图片的整体视觉方向
- **主色调：** 基于商品主色调和使用场景确定，全套图片统一
- **光影与画质：** 基于商品类型和使用场景确定
- **各素材背景方案：**
  - 白底图：纯白背景，RGB(255, 255, 255)
  - 场景图：基于商品类型、使用场景和类目专项策略定义，两张场景图须方向不同（如：一张具象生活场景 + 一张抽象氛围场景）
  - 卖点图：3 张卖点图背景**统一引用场景图第二张（抽象氛围场景）的风格调性**——相同色调方向、相同材质/光效主题，文字叠加于场景之上。三张卖点图不需要混搭不同背景风格，统一背景调性正是套图视觉一致性的核心。具体背景描述在步骤 4 生成各卖点图 Prompt 时提炼自场景图第二张的抽象氛围场景方向
  - 用户使用图：真实生活场景，背景自然不做作
  - 细节图：纯色简约

### 3.4 用户确认

将 3.1 素材清单和 3.3 风格细节一并呈现给用户确认，支持修改素材类型、数量和风格细节。确认后进入执行阶段。

---

# 二、执行阶段

## 步骤 4：生成 Prompt 并调用生图

### 全局约束

- 商品外观必须与用户上传图片完全一致（外观结构、颜色、尺寸比例、配件、包装、logo 标识等）
- **真实场景物理规律（重要）：** 所有真实场景素材必须严格遵循现实物理规律和生活常识——商品摆放位置符合常识；人物与商品的交互方式完整合理；物体重力、支撑、接触关系真实；场景内各元素尺寸比例正确。Prompt 中须对关键细节做出明确描述，不可依赖模型自行推断
- **镜子相关词汇（全局）：** 所有素材的 Prompt 中不得出现任何镜子相关词汇（包括"镜子""镜前""镜中""无镜子"等），直接忽略镜子元素，不做任何提及
- **光影自然真实（重要）：** 除白底图外，所有素材光影必须符合真实物理规律。Prompt 中须明确描述光源类型、方向和氛围（如"左前方 45° 柔和自然光，商品右侧产生自然渐变阴影"），禁止模糊描述
- **质感与高级感（核心要求）：** 所有图片必须达到高端商业摄影级别的质感与高级感——这是用户产生购买欲望的核心视觉驱动。除白底图外，Prompt 中须针对商品材质做具体描述——玻璃要写"通透晶莹、光线穿透折射形成焦散光斑"；金属要写"拉丝纹理细腻如发丝、边缘高光锐利如刀锋"；塑料哑光要写"细密磨砂触感、柔和漫反射无刺眼光点"；织物要写"纤维纹路清晰可辨、表面光泽随光角度柔和起伏"；皮革要写"纹路层次分明、边缘倒角光滑、表面光泽饱满"。禁止仅写"质感细腻""高清画质"等笼统描述。背景/道具/光影的选择须与商品调性相配，整体构建"让人想拥有"的视觉氛围
- **商品角度多样化（重要）：** 除白底图外，各素材应创造性变化拍摄视角和摆放角度，避免全套图片角度一成不变
- **文字排版：** 所有含文字的素材中，单行文字必须水平排版，严禁垂直排版（逐字竖排）。Prompt 中须明确写"文字水平排版"
- **文字位置描述用语（重要）：** 生成含文字的卖点图 Prompt 时，禁止使用"文字区域""文字区块""文案区块""文本板块""文字部分"等具有空间划分感的词汇——这类词汇会触发模型将画面切割为独立色块，产生上下或左右割裂感。应改用"文字叠加于背景之上""文案浮现于画面左侧""标题悬浮于商品上方空间"等描述，使文字与背景自然融合
- 每张图围绕一个核心信息，全套图片光影方向、色调风格、商品比例、质感表达统一
- 画质 4K，高清细腻，具备广告图/海报图的美感
- Prompt 要尽可能补充细节（整体风格、结构布局、背景细节、光影效果、画质要求）
- **默认生图比例 1:1（全局）：** 除非用户明确指定其他比例，所有素材统一使用 **1:1** 比例生成，并在传入生图模型时带上尺寸参数

### 4.1 Prompt 输出格式

```
【素材类型】白底图 / 场景图 / 卖点图 / 用户使用图 / 细节图
【尺寸】1:1（默认；如用户指定其他比例则替换此处并在 Prompt 中注明）
【Prompt】生图 prompt，尽可能补充细节
```

#### 各素材规则

> 若已激活类目专项策略（见附录），各素材的具体策略按类目专项规则执行，通用规则作为兜底。

**白底图** — `[质检项: BG-1~3]`
- BG-1: 纯白背景 RGB(255,255,255)，无渐变、无阴影、无纹理
- BG-2: 仅含商品，无文字、无 logo
- BG-3: 商品置于画面正中央，水平居中、垂直居中，占画面约 80%，四周留白均匀对称
- **角度：保持用户上传的原始角度和摆放姿态，不做任何视角变化**
- **光影：无阴影、无光斑、无反射，均匀无方向性照明**

**场景图** — `[质检项: SC-1~5]`
- SC-1: 非纯白背景，与步骤 3 确认的背景方案匹配
- SC-2: 仅含商品，无额外文字、无额外 logo（商品自身包装上的文字和 logo 必须完整保留）
- SC-3: 商品居中，占比 75%–80%
- SC-4: 背景层次清晰，不堆砌过多元素
- SC-5: 商品包装上的所有文案、logo、标签、图案必须与原图完全一致
- **场景与商品强关联（重要）：** 场景必须结合商品特点，能传达商品核心调性或功能价值
- **两张场景图须使用不同场景方向**，避免同质化
- **场景图分为两种类型（全局统一定义）：**
  - **具象生活场景：** 可识别的真实生活环境——厨房/餐桌/卧室/街景/户外等，有明确生活语境，通常含生活道具或人物，叙述商品在真实场景中的使用故事
  - **抽象氛围场景：** 摄影棚式氛围背景，无可识别的真实生活空间——大理石台面/天鹅绒/渐变光影/几何光效/成分视觉化/材质纹理底纹等，追求质感和美学调性，不依赖真实生活叙事

**卖点图** — `[质检项: SP-1~4]`
- SP-1: 布局结构合理平衡
- SP-2: 文字清晰可读，水平排版，无错别字
- SP-3: 视觉层次清晰
- SP-4: 文案结构正确
- **卖点文案字体：必须使用无衬线字体（sans-serif）**

#### 卖点文案与布局

> **【前置判断】商品宽高比检查（执行布局前必做）：**
> 分析商品图片的宽高比（width ÷ height）：
> - **宽高比 ≥ 1.5**（商品明显横宽，如笔记本/键盘/平底锅/皮带/横版包装盒等）→ **禁止使用任何左右布局**，原因：横宽商品占据大量水平空间，左右布局会导致文字区域极度压缩，画面失衡
>   - 模式 A（左右布局）**强制替换为** 模式 B（上下布局）
>   - 最终三张卖点图布局变为：**B、B（内容不同）、C-4**
> - **宽高比 < 1.5**（商品竖版/方形/轻微横向）→ 正常执行下方三种模式

3 张卖点图分别使用 A、B、C-4 三个不同模式，确保布局多样性：

| 模式 | 文案结构 | 对应布局 |
|------|---------|---------|
| A | 1 个大主卖点标题 + 2–3 条副卖点描述 | 左右布局 |
| B | 1 个大主卖点标题 + 2 条副卖点描述 | 上下布局（上文下商品） |
| C-4 | **1 个主标题**（顶部居中）+ **4 条**并列环绕卖点（各自独立，配语义化图标+圆角胶囊标签）| 中心环绕布局（商品居中，卖点四周对称分布）|

**文案规则：**
- 模式 A/B：主卖点 ≤ 12 字，副卖点 ≤ 10 字
- 模式 C-4：每条环绕卖点 ≤ 8 字；主标题 ≤ 12 字；每条环绕卖点须配合**语义化图标**（图标须在 Prompt 中明确描述语义，如"水滴图标""月亮图标""棉花图标"，禁止泛称"图标"）；文案封装于**圆角胶囊标签**中；另须在顶部居中设置一个**大号主标题**（概括该张图核心卖点主题）

**布局约束：**
- 商品是绝对视觉主角，文字是辅助信息；二者共享同一连续背景，不得形成两个割裂区块
- 左右布局：商品偏置于画面一侧作为视觉锚点，文字自然嵌入另一侧空间；商品视觉元素（光影、倒影、材质延伸）可向文字侧自然渗透，文字垂直方向与商品重心对齐
- 上下布局：商品居于画面下部为视觉主体，文字居于上方空间，上下共享同一背景，均水平居中
- C-4 中心环绕：商品居画面中央为绝对焦点，商品占比 65%（为四周卖点标注留出空间），主标题悬于画面顶部居中；4 条卖点模块对称分布四周，互不遮挡产品主体；引导视线向中心汇聚，引导线不交叉；卖点与商品共享连续背景，不得出现将画面切割为独立区块的色块或分隔线

**【全局约束】A/B 卖点图 Prompt 必包要素：**

生成 A/B Prompt 时，以下要素是画面质感和商业美感的核心，须逐条精细描述：

> **结构示例（以 B 模式/上文下商品 为例）：**
> 商业静物摄影，[产品名称]以[具体姿态，如"侧斜45度悬浮于画面中心"/"以正面视角垂直居中展示"]。背景为[抽象氛围场景精细描述，须与场景图第二张风格一致，如"极简暖灰色渐变空间，左上角点缀轻微七彩虹光光晕（lens flare），营造轻奢现代氛围"/"深色天鹅绒台面，渐变暖光从左后方散射，营造高端陈列质感"/"大理石冷调台面，通透柔光从左上方斜射形成细腻倒影"]。[光影精细描述，如"左前方45°散射柔光，产品表面呈现细腻高光，底部产生柔和倒影"/"左上角七彩虹光光晕（lens flare），产品边缘勾勒出高级光晕"]。[摄影棚式道具/配景（可选），如"台面点缀少量品类相关道具，带有微弱景深虚化""画面边缘有虚化的成分可视化元素"]。画面顶部三分之一处预留干净视觉空间。顶部居中主标题："[核心卖点主题]"（[字体风格]，[颜色]）。下方[副卖点描述，如"副标题：'主动降噪·空间音频·100小时长续航'"/"浅灰色细体列表：1. 卖点A 2. 卖点B 3. 卖点C"]。整体色调[色调描述，与场景图第二张保持一致]，[画质声明，如"8K分辨率，专业电商渲染画质"]。

**9 个必包要素明细：**

| # | 要素 | 说明 |
|---|------|------|
| 0 | **背景与场景图第二张风格一致（前置）** | 生成 A/B Prompt 前，先确认场景图第二张的抽象氛围场景方向（如"大理石+冷调柔光"），A/B 背景须从该方向提炼，保持色调/材质/光效一致，形成套图统一视觉世界 |
| 1 | **产品姿态精确描述** | 须明确写出角度和姿态（如"侧斜45度悬浮""以正面垂直视角居中"），禁止只写"商品居中" |
| 2 | **抽象氛围场景背景精细化** | 禁止使用具象生活场景（户外实地/真实房间）；须具体描述摄影棚式背景元素——材质（大理石/天鹅绒/磨砂亚克力）、色调渐变方向、光效名称（如"极简暖灰色渐变空间""深色天鹅绒+渐变暖光"）|
| 3 | **光影具名描述** | 须明确光源方向、光效专有名称（丁达尔效应/lens flare/散射柔光/侧光勾勒），以及光影在商品上产生的具体效果（倒影/光泽/阴影方向）|
| 4 | **道具配景位置化（可选）** | 摄影棚式道具须具体描述位置（如"台面右前方点缀小型天然矿石""左上角有极简几何装饰"）；景深虚化须明确（"带有微弱景深虚化"/"背景散景(bokeh)虚化"）；禁止加入与背景风格矛盾的道具 |
| 5 | **B 模式顶部预留空间** | B 模式（上文下商品）Prompt 中必须明确写"画面顶部三分之一处预留干净视觉空间"，这是文字与商品自然共存的关键 |
| 6 | **字体风格与调性匹配** | 护肤/香水/轻奢→艺术字体（对应颜色：深绿/黑色）；科技/数码→加粗无衬线字体（对应颜色：黑色/白色）；母婴/生活→加粗无衬线字体（对应颜色：白色）；文字颜色须与背景有足够对比 |
| 7 | **文字层级完整** | 按层级写出每层的字体/颜色/字号：品牌Logo（可选）→ 主标题 → 副标题或卖点列表（多个并列用·分隔）→ 小字说明。每层须各自描述，不可合并 |
| 8 | **画质声明具体化** | 明确写"4K/8K分辨率"+"品类质感声明"（如"高端护肤品牌营销海报质感""专业电商渲染画质""广告级商业摄影质感"），不得只写"高清" |

> **【进阶技法】产品区域标注（适用于多功能区产品）：**
> 当商品本身有多个明显功能区域时（如纸尿裤的腰贴/吸收芯/腿围、耳机的耳罩/头梁/按键、清洁刷的刷头/手柄），可采用"产品区域标注"技法：
> - 在商品展开状态下，对每个功能区添加视觉标注线（浅金色圈出线/白色高亮标注线）指向对应功能说明
> - 可为不同区域添加视觉效果增强信息传达（如"吸收芯体位置用半透明蓝色水波纹效果展示"）
> - 此技法适用于 A 模式或 B 模式，文字层级改为：主标题（顶部）→ 区域标注线+说明 × N 条 → 副卖点列表（底部）

**【全局约束】C-4 核心卖点图 Prompt 必包要素：**

生成 C-4 Prompt 时，以下 7 个要素缺一不可，参照优质 Prompt 结构输出：

> **结构示例（以 C-4 为例）：**
> 商品居中放置，产品占比65%，周围环绕4个卖点图标，互不遮挡产品主体。背景使用[具体色调渐变，如"柔和浅灰蓝色渐变"]，简洁干净。全局风格：高清商业摄影，[光效类型，如"柔光"]，[商品调性色调，如"母婴温暖色调"]。以上传的产品图为准，保持外观不变。排版风格：[调性关键词，如"温馨简约"]。主标题："[核心主题短语]"（大号醒目，顶部居中，[字体风格，如"圆润可爱粗体"/"现代简约粗体"/"优雅衬线体"]）。标签/标注（简洁无衬线体）：（[语义化图标]）"[卖点文案]" × 3或4条。视觉元素：[图标风格，如"卡通简约图标"/"极简线性图标"]，圆角胶囊标签。

**7 个必包要素明细：**

| # | 要素 | 说明 |
|---|------|------|
| 1 | **商品占比 65% + 互不遮挡** | C-4 商品占比固定 65%（低于场景图 75–80%，为卖点标注留空间）；明确写"周围卖点标注互不遮挡产品主体" |
| 2 | **全局风格三要素** | 高清商业摄影 + 光效类型（柔光/冷调专业光/通透柔光）+ 商品调性色调（母婴温暖/冷灰科技/清透裸粉/简约高端） |
| 3 | **背景色调（须与场景图第二张一致）** | 从场景图第二张的抽象氛围场景提炼色调方向（如场景图第二张是"大理石冷调渐变"，C-4 背景则写"冷白色调大理石纹理渐变底"）；禁止模糊写"渐变背景" |
| 4 | **排版风格声明** | 对应商品调性的风格词（温馨简约/极简科技风/简约清新/简约高端），置于全局风格之后 |
| 5 | **顶部居中主标题** | 大号醒目，字体风格与调性匹配：温馨类→圆润可爱粗体，科技类→现代简约粗体，高端类→优雅衬线体 |
| 6 | **语义化图标 + 圆角胶囊标签** | 每条卖点格式：（[语义化图标，如"水滴图标""月亮图标""棉花图标"]）"[卖点文案]"，封装于圆角胶囊标签；禁止泛称"图标" |
| 7 | **固定短语** | "以上传的产品图为准，保持商品外观不变"必须出现在 Prompt 中 |

**【全局约束】卖点图背景规范（统一引用场景图第二张抽象氛围场景风格）：**

3 张卖点图的背景**必须与场景图第二张保持相同的风格调性**，具体执行方式：
- 步骤 4 生成卖点图 Prompt 前，先确认场景图第二张使用的抽象氛围场景方向（如"极简大理石台面+散射柔光""深色天鹅绒+渐变暖光""成分视觉化冷调渐变"等）
- 3 张卖点图的背景均从该场景方向中提炼——相同材质/光效主题、相同色调，只是商品摆放姿态和文字布局不同
- 商品置于场景之中，文字叠加于背景之上；选择场景中色调均匀的区域作为文字落点，避免文字与复杂背景元素叠加导致可读性下降
- 全图背景色调统一，不得出现左右/上下割裂的色块；文字叠加而非区块切割
- **禁止使用具象生活场景（真实厨房/梳妆台/卫浴台面/街景/户外实地等）作为卖点图背景**

**卖点图禁止项：**
- **禁止左右两侧背景出现不同色调或亮度**（"左深右浅""左暗右亮""左冷右暖"均属违规），这是割裂感的直接来源
- 禁止文字垂直排版（逐字竖排）
- 禁止文字全部集中在画面顶部 1/4 区域
- 禁止画面底部出现大面积纯空白区域
- 禁止文字区块总面积超过商品面积
- **A/B 模式**禁止在副卖点文字后添加圆角矩形色块/标签背景（会产生割裂感）；**C-4 模式须使用圆角胶囊标签**封装图标+文案（这是正确视觉元素，不受此禁止项约束）
- 禁止在文案中使用「」或任何特殊分隔符号，避免模型将其直接渲染至画面

**用户使用图** — `[质检项: UU-1~6]`
- UU-1: 画面中必须包含人物正在使用商品，体现具体使用方式或使用效果
- UU-2: 商品外观与用户上传图片一致
- UU-3: 人物自然真实——面部五官协调、手指数量正确（5 根）、肢体比例正常
- UU-4: 背景为真实生活场景，自然不做作
- UU-5: 人物与商品的交互关系合理
- UU-6: 保持商品在现实世界中的实际大小
- **使用场景必须符合逻辑（重要）：** 须明确描述使用者身份、使用时间/地点、使用动作/姿态、使用目的。禁止与商品功能不符的使用方式

**细节图** — `[质检项: DT-1~3]`
- DT-1: 聚焦商品具体细节（材质/纹理/工艺/接缝/配件），展示产品局部特写
- DT-2: 细节与用户上传原图完全一致
- DT-3: 光影自然，质感清晰——侧光或逆光勾勒材质纹理和边缘轮廓
- **优先展示商品独一无二的细节**——专属设计、差异化工艺、核心材质表现，禁止选择平淡通用细节

### 4.2 工具调用

- 用户提供的商品图片为必需输入，步骤 4 的首次生成、步骤 5 质检不通过后的重新生成，**全部必须调用 图生图工具**。图生图时，必须在图片输入参数（如 `resource`）中传入商品图片的真实 `resource_id`，并确保 Prompt 中的 `@图片N` 与实际资源顺序一致。
- 若商品图片资源缺失、不可用或无法绑定，必须停止生成并处理图片输入问题；禁止改用文生图工具绕过。非会员回落只允许更换模型，不得更换生图工具或移除商品图片输入。
- 对商品图片进行识别、元素提取、卖点分析或 Prompt 优化，仅用于补充生成指令，**不代表图片输入已转化为纯文本输入**；完成上述分析后仍必须保留并传入原商品图片。

**两阶段执行：先并行优化，再逐张生图。**

**阶段一 — 并行 Prompt 优化（白底图跳过）：**
步骤 4 全部 Prompt 生成完毕后，**同时**发起对场景图、卖点图（3 张）、用户使用图、细节图的 `dreamina_prompt_optimize` 调用，不等待上一张完成即发起下一张，等全部优化结果返回后进入阶段二。白底图跳过此阶段。

**阶段二 — 逐张生图与质检：**
将各图优化后的 prompt（或白底图原始 prompt）+ 商品图片真实 `resource_id` + 尺寸参数传入图生图工具生成；Prompt 须使用与图片输入参数一致的 `@图片N` 引用。每张生成后立即进入步骤 5 质检。

**用户使用图方向**

- 充电器：手机插线充电场景，清晰展示插头方向和使用逻辑

光影：侧逆光勾勒金属边缘高光形成"刀光"感；玻璃材质表现通透内部结构和镀膜色散效果。

- 精华/乳液/面霜：模特坐在梳妆台旁/卫浴间，用指尖将产品点涂在面颊并轻拍吸收；涂抹动作必须是正确护肤手法（由内而外/由下而上）

约束：产品用量合理；模特皮肤状态与产品功效呼应；场景时间感清晰（早晨/夜间护肤各不同）。模特：功效型护肤用 30–45 岁皮肤状态真实感强；日常护肤用 20–35 岁清新自然。

**细节图方向**
- 精华瓶：滴管吸管处的液体（展示流动性和质地）、玻璃瓶壁折射光效

**细节图特殊策略（美妆护肤类独有）：** 产品质地展示——将一定量产品挤出在干净台面上拍摄质地（乳霜类展示绵密膏体；精华液展示透明流动感；粉剂展示细腻粉质飞散感）；成分可视化细节——若产品含可见成分（金箔/珠光粒子/精油珠），特写展示其在产品中的分布。光影：使用侧光+强反光背景，最大化展示质地光泽感和流动感。
