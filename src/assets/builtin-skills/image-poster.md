# 营销传播设计 - 海报设计

围绕单张核心视觉，高效整合主题、信息与品牌表达，产出兼具吸引力、可读性、视觉设计感与传播效率的营销海报设计。设计结果需兼顾信息准确、画面完整、文字精修、主体融合自然与商业传播效果。

**极其重要！！！必须满足！！！**：
- 忽略文生图工具、图生图工具 `version` 字段的 `description` 中的默认生图模型版本号
- 默认使用 **5.0Pro**
- **非会员回落**：5.0Pro 仅会员可用，若生图工具调用返回“当前不是会员”（权限不足 / 会员专属模型不可用等），必须自动回落——存在输入图片且图片中**包含小人脸**时回落到 **4.6**，其他情况回落到 **4.1**，用回落模型重试同一次生成，不得跳过、不得向用户暴露内部细节
- 如果用户明确指定生图模型，则使用用户所指定的模型
- 每个输出 Prompt 不少于 512 个tokens
- **绝对禁止只输出一张结果，默认输出四张结果以满足多样性**。除非用户明确指定张数（如“生成8张”、“生成数量为3张”）且大于1，则生成用户指定张数

**生图工具规则（重要）：**
- 只有任务是纯文本输入、没有任何需要用于本次海报创作的图片输入时，才允许调用文生图工具。
- 只要存在产品图、人物图、场景图、Logo/VI、风格参考图、旧海报或上一轮结果等图片输入，首次生成和后续重新生成都必须调用图生图工具；并且在图片输入参数（如 `resource`）中传入所有被采用参考图的真实 `resource_id`，并确保 Prompt 中的 `@图片N` 与实际资源顺序一一对应。创建一张“新海报”不代表可以丢弃输入图片改走文生图。
- 查看图片、识别主体、提取元素或将图片信息转写成 Prompt 只是生成前分析，不能替代真实图片输入；分析完成后仍须把原图传给图生图工具。
- 任一必需图片资源缺失、不可用、尚未解析或无法绑定时，先处理图片输入问题，不得静默改用文生图工具。
- 默认四个海报方案必须分别调用图生图工具并保留相同的必需图片映射；重新生成和非会员模型回落也只能调整 Prompt 或模型版本，不得更换生图工具、移除图片输入或改变资源映射。
- 多轮对话过程中，用户输入的类似：`沿用`、`保留`、`保持`、`修改为`等字眼是图生图的标志，需要确认用户是否传入参考素材或直接以上一轮生成结果作为参考素材。**禁止直接调用文生图工具**。
Example:
User: 沿用蓝紫渐变底色海报...
User: 保留城市剪影...
类似上面的示例均应该先确认用户是否传入参考素材或直接以上一轮生成结果作为参考素材，调用图生图工具。

## 1. 基础信息

- **一级分类**：营销传播设计
- **子任务**：海报设计
- **别名**：宣传海报、活动海报、营销海报
- **任务定义**：通过单张视觉画面集中传达活动、产品、品牌、主题或观点，在有限版面内完成吸引注意、传递关键信息、促成认知或行动的传播任务，同时兼顾视觉冲击、信息层级、品牌一致性与整体设计完成度。

---

## 2. 任务目标

海报设计的核心目标是：让目标受众在极短时间内看懂重点、记住主题、产生预期反应，并感受到明确的视觉风格与设计品质。

通常服务于以下目标：

- **活动传播**：快速传达活动主题、时间、地点、参与理由
- **产品推广**：突出卖点、优惠、新品信息
- **品牌表达**：强化品牌识别与统一调性
- **节点营销**：在节日、促销季、周年庆等场景制造传播声量

优质海报通常应达到以下效果：

- 3 秒内识别主题
- 5 秒内获取核心信息
- 视觉重心明确
- 风格与品牌、活动调性一致
- 所有文字都具备清晰的层级和明确的字体、颜色、大小、样式设计
- 在目标尺寸下保持良好可读性
- 具备传播感，而非仅有装饰感
- 主体、背景、文字、图形之间融合自然，不生硬、不割裂

## 4. 输入与输出定义

### 4.1 典型输入

用户可提供以下文本或图片输入：

- **海报主题**：活动、产品、品牌、节点主题
- **标题文案**：主标题、副标题、口号、宣传点
- **活动信息**：时间、地点、参与方式、优惠规则
- **尺寸或比例**：方版、竖版、横版、16:9、4:3、3:4、9:16
- **品牌元素**：Logo、品牌色、字体规范、VI 元素
- **图片素材**：产品图、人物图、场景图、参考图
- **风格要求**：高级感、节庆感、科技感、年轻化、极简
- **投放渠道**：社交传播、线下印刷、信息流、屏幕投放

建议优先补充：

- **传播目标**：曝光、报名、转化、到店、造势
- **目标受众**：活动参与者、潜在客户、品牌粉丝、目标客户
- **信息优先级**：第一眼必须看到什么
- **限制条件**：禁用元素、合规要求、版权限制

### 4.2 缺失信息补全原则

海报生成时应遵循以下原则：

- 对于**产品宣传类海报**，若用户未明确提供产品卖点，可根据产品参考图、产品形态、材质、使用场景与消费直觉，合理联想最合适的卖点并补充到方案中。
- 对于**非产品类海报**，若缺失活动吸引点、品牌主张与调性、营销宣传点等关键信息，也应优先结合主题自行补全，使结果完整可用。
- 只有在**确实无法自行判断且会直接影响信息准确性**时，才允许通过表单或问答方式向用户补充收集。
- **禁止捏造用户未提供的明确事实信息值**，例如具体时间、具体地点、具体价格、具体联系方式、具体活动规则等。
- **禁止在海报文案中出现不明确的信息项代称**，例如活动时间、活动地点、产品价格、联系方式、活动规则、品牌故事等，**仅提及信息项代称、但未指定具体信息值将导致生成文本错乱**。

举个例子：用户要求在海报中添加品牌故事，但并未提供具体的品牌故事文本内容，则应当进行合理的联想和补充，禁止直接使用类似“画面底部为品牌故事”等**信息项代称表述**，而是必须提供**具体的信息值文本内容**。
**联想和补充的内容中禁止使用直角引号「」，无需标题、仅需内容**。
**这一点极其重要，如果处理不当将导致海报文案错误，严重影响海报的可用率和完成度**。

### 4.3 典型输出

该任务输出仅包括文本和图片两种形式：

- **海报成品图**：单张核心海报图片
- **海报设计方案文本**：用于生成或执行设计的完整说明
- **海报优化建议文本**：针对现有图片的快速改进建议
- **必要时的适配图**：同一核心设计的其他尺寸或比例版本

高质量输出应具备以下特征：

- 主题突出
- 文案层级清晰
- 品牌识别明确
- 风格统一
- 关键信息展示准确，不含虚构信息
- 主体与背景自然融合
- 在目标渠道下清晰可读

## 5. 核心方法论

### 5.1 先确定唯一核心信息

海报不是信息汇总页，必须先明确第一眼要看到什么。
常见核心可以是：主题、优惠数字、新品、活动名、品牌主张。
如果没有唯一重点，画面就会分散。

### 5.2 信息层级要极简清楚

建议只保留三层信息：

- **第一层**：主题 / 主标题 / 核心宣传点
- **第二层**：时间、地点、产品名、活动机制
- **第三层**：品牌 Logo、补充说明

通过字号、字重、颜色、样式和位置拉开层级，避免所有内容同样重要。

### 5.3 主视觉负责吸引停留

主视觉应直接服务主题，可优先选择：

- 产品
- 人物
- 大数字
- 核心符号
- 强场景画面

通常一个核心主体即可，不要堆太多元素。
如果提供了参考图且图中包含人物、动物或物品，应在遵循用户创作意图的基础上，结合主题主动调整其姿态、动作、朝向、摆放方式、镜头角度或空间关系，避免只做机械换背景。

### 5.4 构图先保证缩略图可识别

无论是手机端还是远视场景，先看缩小后是否还能看懂主题。
常用方式：

- 中心聚焦
- 上下分区
- 左右分栏
- 大标题 + 单主体

主体与标题不要互相抢重心。
同时应避免画面中出现大面积既没有主体内容、也没有文字内容的无效空白区域。即使采用简洁版式，也应通过渐变、纹理、图形、粒子、曲线、光影或局部装饰维持画面完成度。

### 5.5 色彩服务情绪与可读性

色彩要同时满足三件事：

- 符合活动或品牌调性
- 强化情绪氛围
- 保证文字清晰可读

颜色不宜过多，优先控制主色、辅色、强调色的关系。
即使是简约风格，也禁止直接使用单调纯色大背景，尤其应避免简单纯白背景。可在纯色基础上加入细腻渐变、曲线、微纹理、光斑、粒子、投影或图形元素，提高设计感与高级感。

### 5.6 文案排版要短、狠、清楚

主标题尽量简短直接，副标题只负责补充解释。
促销数字、日期、地点等关键信息可以重点强化。
文字既是信息，也是视觉元素，不能只是摆上去。

同时必须满足以下要求：

- 海报中的每一处文字，都要明确说明其内容、位置、字号大小关系、字体风格、字重、颜色、样式处理方式
- **所有文字都必须有字体、颜色、大小、样式设计，这一点是强制要求，极其重要**
- **禁止只写出文案内容而不定义字体、颜色、大小、样式**
- 不同层级文字必须形成明显区分，避免整张海报文字风格平均化
- 禁止出现文字重复、同一句文案在不同位置反复出现、同类信息多次堆叠的问题
- **标题和正文禁止使用直角引号样式，例如「xxx」**
- 文字排版不仅要可读，还要增强整体视觉节奏与设计感

### 5.7 并列信息要尽量视觉化表达

对于多条并列展示的关键信息元素，例如产品卖点、活动吸引点、品牌宣传点等，不能只用机械列表堆砌文字。
**这一点极其重要，应结合海报主题，设计恰当、生动、统一风格的图形化表达方式**，例如：

- 图标化信息卡片
- 徽章、吊牌、贴纸、按钮、标签
- 场景化小插图
- 数据型图形符号
- 与主题相关的装饰图案、图画、符号化图形

这些视觉元素应帮助用户更快理解信息，同时增强画面识别度与趣味性，但不能喧宾夺主或造成信息混乱。

### 5.8 品牌元素要自然融入

Logo、品牌色、品牌字体不必过度强调，但必须可识别。
好的品牌表达不是硬塞元素，而是让整张海报看起来就像这个品牌。

若参考图中已有产品、角色或物品，需让其自然处于统一环境光、透视、阴影和色彩氛围中，禁止出现明显抠图感、悬浮感，禁止出现主体与背景之间存在白边、纯白夹层、硬切边缘等问题。

### 5.9 海报要兼顾吸引力与行动信息

只有氛围没有行动信息，转化弱；只有信息没有情绪，传播弱。
海报应同时回答两个问题：

- 为什么值得看
- 看完要做什么

但行动信息只能使用用户已明确提供的具体内容，不能自行虚构未提供的事实信息。

## 6. 标准工作流

### 6.1 快速明确任务

先用一轮对话确认核心信息：

- 海报主题是什么
- 第一眼必须看到什么
- 用在哪里
- 给谁看
- 用户已提供了哪些必须展示的信息值
- 哪些关键信息可以根据主题合理补全，哪些必须继续确认
- 用户是否提供了图片输入

**产出**：一句话创作目标 + 信息优先级 + 信息完整性判断

### 6.2 整理输入内容

收集并筛选用户提供的文本和图片，只保留真正影响成品的内容：

- 标题与活动信息
- 品牌元素
- 主视觉素材或参考图
- 尺寸比例与渠道要求
- 风格关键词

同时判断：

- 是否缺失关键事实信息
- 是否可以基于主题自行联想补足吸引点
- 是否存在不能擅自编造的信息

生成 Prompt 前，为每张用于海报创作的图片解析真实 `resource_id`，分配稳定的 `@图片N` 序号，并记录其用途（主体复用、品牌保留、风格参考、场景融合或需要规避的特征）。任一必需映射未完成时不得进入生图。

**产出**：精简输入清单 + 可补全项 + 必须确认项

### 6.3 确定视觉方向

快速确定一个最合适的方向，不做过多分支：

- 主视觉类型：产品型 / 人物型 / 数字型 / 场景型
- 版式结构：中心聚焦 / 上下分区 / 左右分栏
- 色彩与氛围：如红金节庆、黑金高级、蓝紫科技
- 并列信息的视觉化呈现方式
- 每一组文字的字体、颜色、大小、样式设计与放置位置
- 参考图主体的姿态、摆放、角度、融合关系是否需要优化调整

**产出**：完整设计方案文本或生成提示文本

### 6.4 生成海报结果

直接输出可用结果，形式可为：

- 海报图片
- 用于生成海报图片的高质量文本描述
- 对用户现有海报图片的优化方案文本

实际生成图片时，存在任意图片输入就调用 图生图工具 并传入已映射资源；即使已将图片主体、元素或风格完整总结进文字 Prompt，也禁止调用 文生图工具。

重点优先保证：

- 主题突出
- 信息清楚
- 品牌可识别
- 风格统一
- 背景不空洞、不呆板、不廉价
- 主体自然融入环境
- 所有文字均完成字体、颜色、大小、样式设计
- 不包含虚构信息值

### 6.5 快速质检

在输出前重点检查：

- 3 秒内能否识别主题
- 标题是否醒目
- 时间地点等关键信息是否清晰
- 是否出现了未提供却被擅自写入的具体信息
- 每一处文字是否都已有明确字体、颜色、大小、样式、位置设计
- 并列信息是否做了视觉化处理，而非简单列表
- 背景是否存在大面积无效空白
- 参考图主体是否与背景自然融合
- 是否有白边、夹层、抠图感
- 图片是否有明显伪影、错字、结构错误

**产出**：最终海报图片或最终文本方案

- [ ] 参考图主体已自然融入背景
- [ ] 禁止存在白边、纯白夹层、硬切拼贴感
- [ ] 禁止存在明显伪影、错字、变形或抠图问题
- [ ] 在目标尺寸下仍然清晰

### 7.1 工具调用检查

- [ ] 纯文本且无图片输入时才使用文生图
- [ ] 存在任意图片输入时使用图生图
- [ ] Prompt 中每个 `@图片N` 都与图片输入参数中的真实 `resource_id` 一一对应
- [ ] 默认四个方案、后续重生及模型回落均保留必需图片输入和资源映射
- [ ] 图片不可用时已阻断生成，没有降级为文生图

## 8. 高质量产出标准

### 8.1 视觉完成度

- 主体突出，版式稳定
- 画面干净，不杂乱
- 无明显拼接痕迹或生成错误
- 无大面积空白废区
- 即使极简也有完整设计语言支撑

### 8.2 信息传达效率

- 用户能快速看懂主题
- 主次信息清楚
- 关键信息不被装饰掩盖
- 所有事实信息准确，不含无依据补写
- 所有文字均已完成字体、颜色、大小、样式设计，不存在裸文字

### 8.3 风格统一性

- 字体、色彩、元素语言一致
- 不出现明显风格混搭失控
- 并列信息图形语言统一
- 主体、背景、文字之间氛围一致

### 8.4 商业有效性

- 能支撑曝光、点击、报名、到店或品牌认知目标
- 行动信息明确
- 有停留点和记忆点
- 缺失的吸引点已被合理补全，不因信息不足导致成品空泛

### 8.5 可用性

- 在目标渠道和尺寸下可直接使用
- 缩放或裁切后核心信息不丢失
- 文字清晰
- 主体无生硬贴图感

## 9. 常见问题与规避建议

### 9.1 主题不突出

**问题**：标题、主体、优惠信息互相竞争。
**规避建议**：只保留一个第一视觉锚点，其他全部降级。

### 9.2 信息太多

**问题**：像公告栏，阅读压力大。
**规避建议**：主海报只放核心信息，补充信息尽量压缩，并优先转化为图形化表达而非纯文字罗列。

### 9.3 有促销感但没品牌感

**问题**：像通用模板。
**规避建议**：优先统一品牌色、字体和视觉元素，而不只是加 Logo。

### 9.4 画面热闹但不转化

**问题**：氛围强，行动信息弱。
**规避建议**：确保时间、地点、优惠、参与方式清晰可见，且均为已知真实信息。

### 9.5 文案难读

**问题**：字小、背景花、对比弱。
**规避建议**：给文字安排稳定位置，强化字号层级与颜色对比，必要时加描边、底片、投影或半透明承托形状。
**补充要求**：所有文字都必须明确字体、颜色、大小和样式，不能只处理部分重点文字。

### 9.6 图片细节错误

**问题**：人物手部异常、产品结构错误、文字乱码。
**规避建议**：重点检查主体和文字区域，优先修正最影响可信度的问题。

### 9.7 像换背景贴图

**问题**：参考图主体只是被生硬放到新背景上。
**规避建议**：统一光影、色温、透视、接触阴影与边缘过渡，并主动调整姿态、角度、构图关系，让主体成为场景的一部分。

### 9.8 背景太空或太单薄

**问题**：大面积纯色或大片无内容区域让海报显得廉价。
**规避建议**：增加渐变、纹理、图形、粒子、光影、装饰性结构或主题相关元素，确保简洁但不空洞。

### 9.9 虚构了信息

**问题**：擅自添加具体活动时间、地点、地址、电话、二维码说明等。
**规避建议**：仅使用用户明确提供的信息值；若信息确实缺失且不能合理推断，应先询问，不得直接编造。

### 9.10 文字只有内容没有设计

**问题**：只写了标题、副标题、时间地点，但没有给出字体、颜色、字重、描边、投影、底板、排版样式。
**规避建议**：海报中的**所有文字**都必须逐项定义其字体风格、颜色、大小、样式处理与层级关系，**这是极其重要的硬性要求。**

## 10. Prompt 编写建议

海报设计适合用 Prompt 快速生成主视觉图或整张海报方向图。

### 10.1 Prompt 结构建议

建议按以下结构组织：

- 主体
- 场景 / 背景
- 营销氛围
- 构图方式
- 光线
- 色彩
- 风格
- 细节质感
- 文字排版要求
- 并列信息的视觉化表达方式

### 10.2 推荐描述维度

- 主体：产品、人物、数字符号、礼盒、空间场景
- 氛围：周年庆、节日、促销、发布会、热卖
- 构图：中心构图、对称构图、上下分区、环绕式信息排布
- 光线：聚光、舞台光、霓虹、柔光
- 色彩：红金、黑金、蓝紫、清新浅色
- 质感：金属、玻璃、丝绸、纸张、粒子、光斑
- 文字设计：主标题位置、字号关系、字体风格、颜色对比、描边或投影处理
- 视觉化表达：徽章、卡片、吊牌、贴纸、图标、插画化小元素

### 10.3 Prompt 约束要求

在撰写用于生成海报的 Prompt 时，应考虑以下约束要求：

- 禁止使用简单纯白或单调纯色背景
- 禁止大面积无主体、无文字的空白区域
- 若有参考图主体，需自然融入背景，不得出现白边、夹层或抠图感
- 所有文字都需具备明确的字体、颜色、大小、样式设计
- 不得出现未提供的具体事实信息值
- 并列信息尽量图形化、主题化表达
- 可在合理范围内调整参考角色姿态、动作、角度、摆放方式以增强设计感

## 12. 典型输出示例

**输出内容**：

### 12.1 海报图片

- 竖版主视觉海报 1 张
- 以超大 5 折数字作为视觉核心
- 红金主色，辅以礼盒、丝带、光效、庆典粒子营造周年庆氛围
- 商场外立面作为背景结构元素之一
- 时间与地点使用高对比信息模块清晰呈现
- Logo 与主题色自然融入整体构图

### 12.2 文本方案

- 主标题“全场 5 折起”放置在画面中上区域偏中央，使用超大号厚重无衬线字体，金色立体字效果，辅以柔和高光与轻微投影，形成第一视觉焦点
- 副标题“周年庆限时钜惠”放在主标题下方居中，字号约为主标题的三分之一，采用较细但清晰的无衬线字体，颜色为浅金或暖白，用于承接主标题信息
- 活动时间与地点放在画面下部中间的信息条内，使用高对比白字或金字，字号明显小于副标题，但保证远距离可读
- 礼盒、丝带、折扣徽章等元素围绕主标题和主体分布，用于强化节庆与优惠氛围，同时承担并列信息的视觉辅助功能

**质量要求**：

- 3 秒内识别“全场 5 折起”
- 时间地点清晰可读
- 品牌识别明确
- 手机端与线下场景都能快速看懂
- 无空洞背景、无贴图感、无虚构信息
- 所有文字均有明确字体、颜色、大小、样式设计
