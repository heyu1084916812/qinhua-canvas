# TVC 广告片全流程创作 Skill
## 版本 2.0
本Skill是即梦官方内置商业广告片创作标准工作流，适用于所有品牌TVC、产品宣传片、电商广告、品牌故事片、短广创意制作。

---
### 核心工作流阶段
1. **Brief & 概念定调**
   - 解析用户输入的品牌brief，提取品牌名、产品名、核心卖点、目标受众、投放渠道、要求时长、品牌调性
   - 输出2-3个差异化创意方向供用户选定，锚定视觉风格、情绪曲线、核心记忆点
   - 产出物：创意方向确认文档、品牌调性视觉锚定表

2. **剧本创作**
   - 按选定方向编写完整文学剧本，严格匹配目标时长的三幕式广告结构：
     - 0~20% 时长：建立场景、引入用户痛点/情绪钩子
     - 20%~70% 时长：展示产品/解决方案，逐一落地核心卖点，每一个卖点对应一个可视化动作
     - 70%~100% 时长：情绪推向高潮，露出品牌logo和slogan，给出行动引导
   - 同步产出对应旁白/台词/音效文本，标记每一段的时间节点
   - 产出物：完整广告剧本、音频脚本

3. **逐镜分镜设计**
   - 把剧本拆解为独立镜头，单镜头时长建议2~8秒，总镜头数控制在 时长/3 ~ 时长/2 之间，避免单镜过长或过碎
   - 每一条分镜必须明确标注：镜号、时长、景别、运镜、画面内容、光影、音效/台词、转场方式、品牌露出位置
   - 生成配套视觉参考素材清单，确认人物、产品、场景的统一视觉设定
   - 产出物：标准带计时分镜表、参考素材清单

4. **关键帧校验（可选推荐）**
   - 生成所有核心镜头的关键帧参考图，统一人物、产品、场景的视觉一致性，确认画面效果符合预期
   - 提前排查AI生成容易出问题的细节（产品logo、人物手部动作、文字信息等）
   - 产出物：关键帧图集

5. **逐镜视频生成**
   - 把每一条分镜转换为Seedance 2.5可执行的视频生成Prompt，严格匹配画面细节、运镜、光影和情绪
   - 优先使用参考图+多模态生成保证视觉一致性，所有镜头生成后逐镜校验
   - 产出物：全部单条视频片段集

6. **素材拼接与后期封装**
   - 把所有片段按分镜顺序拼接，同步生成匹配广告节奏的BGM、音效和字幕
   - 产出最终成片，同步导出纯BGM版、无字幕版、竖屏适配版（按需）
   - 产出物：最终交付TVC成片

### 执行约束
- 所有TVC生成默认使用 seedance2.5 模型，分辨率优先1080P，比例按投放渠道选
- 单条视频片段最长不超过12秒，长于12秒的分镜自动拆成连续2段过渡生成
- 产品品牌logo和关键信息必须在分镜表明确标注位置，生成时不得出现变形、错字

# 附：阶段规范全文

## Brief 解析与定调标准模板
### 1. 基础信息提取层
| 字段 | 必填说明 | 校验规则 |
| --- | --- | --- |
| 客户/品牌名 | 是 | 必须匹配官方品牌全称，禁止自行缩写/错写 |
| 产品/服务名 | 是 | 明确产品线、SKU、核心版本/迭代点 |
| 视频核心目标 | 是 | 三选一：品宣/种草转化/节点 Campaign |
| 目标受众 | 是 | 年龄层、核心标签、决策动机、日常场景 |
| 时长要求 | 是 | 精确到秒，兼容即梦支持的最大片段时长 |
| 输出比例 | 是 | 16:9横版/9:16竖版/1:1正方形 |
| 交付 deadline | 可选 | 反推各阶段排期 |

### 2. 核心信息对齐层
- **品牌调性锚点**：从品牌过往视觉库提取3个核心关键词，禁止与品牌已有规范冲突
- **核心卖点优先级排序**：最多保留3个一级卖点，其余归为二级辅助信息，避免信息过载
- **情绪基调定调**：从「活力/温馨/高级/硬核/治愈/潮酷/国风/极简」8类里选1-2个主基调，禁止出现矛盾情绪
- **必出现元素清单**：品牌Logo、产品核心视觉符号、指定Slogan、法定合规提示
- **禁止出现元素清单**：竞品符号、不符合品牌规范的颜色/人物/场景、违规内容

### 3. 出片校验阈值
- 信息传递效率：3秒内观众识别品牌，10秒内get核心卖点
- 风格一致性：全片视觉、运镜、音效统一匹配定调关键词
- 合规率：100%覆盖品牌合规要求，无违规表述

## 创意方向生成规范
### 1. 创意基础约束
所有方向必须严格对齐Brief定调，不得脱离品牌、受众、核心目标三个核心锚点，禁止自嗨型创意。
每个创意方向需满足：
- 有明确的视觉主线
- 对应1个核心情绪钩子
- 能完整承载3个一级卖点
- 适配指定时长与比例

### 2. 创意方向产出标准
单次交付至少产出3组差异化方向，每组包含以下字段：
| 字段 | 内容要求 |
| --- | --- |
| 方向名称 | 4-8字，一眼能看懂核心创意 |
| 核心概念 | 1句话讲完底层逻辑，不超过30字 |
| 视觉主线 | 贯穿全片的统一视觉线索/意象/叙事线 |
| 情绪节奏曲线 | 从开篇到结尾的情绪起伏节点，对应时长段 |
| 卖点承载方式 | 3个一级卖点分别用什么情节/镜头落地 |
| 差异化亮点 | 和另外2组方向的核心区别，避免同质化 |
| 适配人群&场景 | 这个方向最适配的传播渠道/受众细分 |

### 3. 创意收敛规则
- 淘汰「创意好看但卖点没地方放」的方向
- 淘汰「需要超复杂实拍/实拍不可替代」的方向，优先适配AI视频生成能力边界
- 淘汰情绪基调前后矛盾的方向
- 最终选定1个主方向后，直接进入剧本阶段，不反复发散

## 广告剧本编写规范与三幕式结构模板
### 1. 通用编写规则
所有广告剧本严格采用三幕式结构，按总时长分配权重：
- 开篇（幕1）：占总时长20%-30%，3秒内抓注意力
- 中段（幕2）：占总时长50%-60%，完整展开核心卖点+情绪递进
- 收尾（幕3）：占总时长20%-30%，强化品牌记忆+行动号召

### 2. 三幕式结构逐段要求
#### 幕1：钩子/引入段
- 开篇必须用「冲突/反差/共情场景/强视觉冲击」四个钩子之一，禁止用空泛的蓝天白云/文字开场
- 10秒内让观众明白「这是什么场景，我能获得什么好处」
- 快速引出主角/核心问题，铺垫后续要解决的痛点
- 无冗余信息，每个镜头都服务于抓注意力

#### 幕2：展开/验证段
- 按卖点优先级排序，逐一把每个卖点对应成「问题→解决方案→爽点反馈」的小闭环
- 情绪节奏从铺垫逐步走高，避免平铺直叙
- 所有产品功能展示必须可视化，禁止用纯口播念参数
- 自然植入品牌/产品核心视觉，不生硬插广告

#### 幕3：收尾/转化段
- 情绪升到最高点后自然回落，落在品牌Logo+Slogan上
- 明确给出行动号召：扫码/点击/立刻入手/前往门店等
- 最后3秒画面固定为品牌收尾帧，视觉信息清晰无干扰
- 全片节奏收束完整，不出现断片/突兀结束

### 3. 剧本文档输出字段
完整剧本必须包含：
- 总时长&比例
- 核心创意概念
- 三幕式分段落大纲，每段标注对应时长
- 完整人物/产品/场景设定清单
- 口播/音效/背景音乐基调说明
- 核心情绪节点标注

## 广告片人物/产品/场景主体统一规范
### 1. 核心目标
全片所有镜头的人物、产品、场景视觉100%统一，不出现AI生成常见的「人物脸崩/产品变样/场景跳戏」问题。

### 2. 人物主体规范
- 1份完整人物卡必须包含：正面+侧面+半侧面三张参考图，明确标注年龄、外貌特征、发型发色、服装固定搭配、身高体型、标志性小动作
- 全片人物的五官、穿搭、肤色、年龄不能出现任何变更，不能每镜换脸/换衣服
- 人物动作统一设定：本广告里人物的核心动作、表情基调，禁止出现偏离人设的奇怪动作
- 多人出镜时，每个人物都独立出卡，明确区分特征，避免AI把不同人物混在一起

### 3. 产品主体规范
- 1份完整产品卡必须包含：正面45°主视图，左/右侧面，背面，产品核心细节特写（比如Logo、按键、发光点）共5张参考图
- 产品的颜色、材质、logo位置、比例尺寸100%严格对齐官方产品图，禁止AI自行改设计/换配色/加不存在的元素
- 产品展示的核心角度提前规划好，所有镜头里产品的视觉识别度拉满，不会出现认不出是什么的情况
- 动态展示产品时，提前明确动作轨迹：比如手打开产品、产品旋转展示，统一所有镜头里的产品朝向

### 4. 场景主体规范
- 1份完整场景卡必须包含：全景参考图，核心细节（桌面/墙面/灯光/陈设）特写图，明确标注整体空间色调、材质、光影方向
- 所有同场景的镜头，空间布局、陈设、光照方向100%统一，禁止AI凭空加/减家具、换墙面颜色、改窗户位置
- 转场到新场景时，新场景独立出卡，确保该场景下所有镜头视觉统一
- 背景元素做弱化处理，避免抢主体（人物/产品）的注意力

### 5. 主体绑定规则
所有主体生成完参考图后，全部注册为即梦的「参考主体」，后续所有视频生成镜头直接绑定对应主体，全程复用，不重新生成随机版本。

## 分镜设计标准与逐镜字段要求
### 1. 分镜通用规则
- 单镜头最长不超过8秒，推荐2-5秒，适配即梦视频生成模型的最优效果区间
- 全片镜头数量：15秒视频3-5镜，30秒视频6-8镜，60秒视频10-12镜
- 镜头之间必须有自然衔接：动作衔接/视线衔接/场景转场/同元素转场，禁止硬切跳戏
- 每个镜头只传递1个核心信息，避免单镜头塞太多元素

### 2. 逐镜必填字段
每一条分镜必须完整填写以下所有字段，无遗漏：
| 字段 | 填写要求 |
| --- | --- |
| 镜头编号 | 按顺序从S01开始编号 |
| 时长 | 精确到0.5秒，单镜最长≤8秒 |
| 画面内容 | 详细描述画面主体、动作、环境、细节，禁止模糊描述 |
| 运镜方式 | 从预设镜头库选1种，最多2种组合，禁止乱写「超酷运镜」这类空泛词 |
| 景别 | 大远景/远景/全景/中景/近景/特写/大特写，明确标注 |
| 画面色调/光影 | 对应视觉Prompt参考库的光影规范，明确写光型、色温、明暗对比 |
| 口播/台词 | 对应本镜头的人声，没有就写「无」 |
| 音效 | 对应本镜头的环境音/动作音，比如「按键咔哒声」「风吹树叶声」 |
| 转场到下镜方式 | 明确写衔接逻辑，比如「主角手拿起产品，下镜顺着手的动作切到产品特写」 |
| 参考图提示 | 对应主体库的角色/产品/场景，标注复用哪个参考 |

### 3. 分镜校验标准
- 逐镜累加时长等于总视频时长，误差不超过0.5秒
- 所有分镜串起来完全对应三幕式剧本，没有遗漏核心情节和卖点
- 每个镜头都能单独生成AI视频，没有需要实拍特殊道具/危险动作/真人不可控的内容
- 口播总字数适配语速：每秒2-3个字，30秒视频口播总字数60-80字，不超时

## 逐镜生成与后期执行校验标准
### 1. 生成前预校验
逐镜检查每个镜头的Prompt，提前排查问题：
- 没有模糊描述、矛盾关键词、违反安全规范的内容
- 所有绑定的参考主体/参考图资源ID正确，没有传错
- 镜头时长、比例、分辨率和全局参数统一
- 镜头提示词明确标注了要保持的主体一致性元素，没有容易出bug的引导词
- 每镜单独生成，批量提交时按顺序排好优先级，避免漏镜

### 2. 生成中监控
- 优先用VIP最高阶模型（Seedance 2.5）生成，拿到第一版结果后先做初检
- 初检必查项：
  1. 主体一致性：人物/产品/场景有没有崩、有没有变样
  2. 动作连贯性：镜头里的核心动作有没有按分镜要求走完，没有跳帧/鬼畜/穿模
  3. 画面清晰度：没有大面积糊、过曝、死黑、奇怪AI伪影
  4. 时长准确性：生成视频的实际时长和分镜标注时长误差≤0.5秒
- 单镜出问题优先微调Prompt重生成1-2次，仍不达标时替换同效果备用镜头，不卡进度。

### 3. 逐镜终检标准
每一个单独镜头通过所有校验后，才能进入下一阶段拼接：
✅ 主体全程统一，没有变形/换脸/改产品
✅ 核心动作/画面内容100%匹配分镜描述
✅ 画面风格、色调、光影和全片定调完全一致
✅ 没有AI生成瑕疵（多手/穿模/漂浮物体/奇怪文字）

## 视觉Prompt参考库 - 视频生成Prompt编写指南
### 1. 单镜视频Prompt标准结构
每一个镜头的生成Prompt严格按这个顺序写，出片效果最稳定：
```
[核心画面动作描述] + [运镜方式] + [景别+焦段+光影] + [风格库关键词] + [绑定参考主体提示] + [通用负面词]
```
#### 示例：
> 女生伸出手拿起桌面上的白色无线耳机，把耳机戴到耳朵上，轻轻点头露出满意的微笑，镜头缓慢向前推镜，近景，85mm f1.4定焦，三点布光柔和自然光，明亮活力种草风，完全参考绑定的人物主体和耳机产品主体，全片视觉统一，无AI瑕疵，无多手多脚，无穿模，无畸形，无模糊糊片

### 2. Prompt编写避坑规则
- 不要一次性塞超过3个独立动作，单镜只讲1-2个连续的核心动作，动作太多AI会乱
- 不要写矛盾的关键词：比如同时写「极暗环境」和「全画面超亮曝光」，会出垃圾结果
- 所有参考主体必须明确标注出来：「完全复用绑定的XX人物主体/XX产品主体，100%保持外观一致，不做任何修改」
- 不要出现时间逻辑混乱的描述：不要同时写「人物拿出手机，同时手机已经在手里了」，动作按先后顺序写
- 单镜Prompt控制在150-300字之间，不要太短（信息不够随机乱生成），也不要太长（关键词互相冲突）

### 3. 不同镜头类型的Prompt技巧
- **人物动作镜头**：重点写清楚动作的起点和终点，比如「从手放在耳机盒上，到打开耳机盒拿出耳机」，不要只写「人物用耳机」
- **产品展示镜头**：重点写清楚产品的朝向、动作轨迹，比如「白色水杯在桌面上缓慢沿水平轴旋转360度，依次展示正面、侧面、背面」，不要只写「展示水杯」
- **转场衔接镜头**：重点写和上一个镜头的衔接元素，比如「顺着上一个镜头里拿起的产品的手，镜头跟着切到产品特写，背景延续同个桌面环境」，保证衔接自然
- **情绪氛围镜头**：重点写光影和氛围，弱化多余动作，比如「暖黄金小时逆光，女生站在窗边，风吹动头发，抬头看向窗外，缓慢环绕运镜」

### 4. 最终校验
提交生成前快速过一遍Prompt：有没有覆盖所有必填要素？有没有矛盾关键词？有没有漏写主体复用提示？有没有把负面词加上？确认后再提交。
