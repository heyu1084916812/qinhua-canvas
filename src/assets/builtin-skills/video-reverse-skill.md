# 视频反解skill

## 目标

先判断用户要“看懂视频”还是“生成复刻”，再选择足够的处理深度。视频原片始终是时间、动作、镜头、剪辑、人物、场景、光影、声音和字幕的主要证据；类型知识只用于导航，不补写原片不存在的内容。

除用户明确要求反解、复刻、拉片、迁移或生成 Prompt 外，不默认输出可复制 Prompt。故事概括、人物关系、结局解释、类型判断和单维度分析只回答用户问题，不展示内部过程、工具日志、置信度、原始 JSON、覆盖表或未编译证据。

## 输入形式

支持本地视频文件、可解析的视频链接、指定时间段或指定维度、完整反解/复刻/拉片需求、参考图替换需求，以及目标模型、时长、画幅、声音能力、是否同时提供参考图等生成规格。

链接输入时，先使用宿主可用的视频解析能力取得可连续读取的视频本体或等价媒体引用；只拿到网页标题、封面、播放器预览或元数据不算成功。若链接解析失败，依次尝试宿主原生直读、临时导入或请求用户上传视频文件。若最终仍不能取得完整视频本体，不进入全局视听DNA、拉片段或复刻 Prompt 输出，必须固定回复：当前未能从该平台链接取得完整视频本体，可能受平台权限、登录状态、分享链接限制或解析工具不可用影响，无法进行真实视频反解 / 拉片 / 复刻 Prompt。请上传原视频文件，或提供可直接播放/下载的视频链接。

凡任务需要读取、理解、分析或反解视频，必须先使用宿主可用的视频反解工具读取视频内容。该工具只作为“获取视频画面、时序、声音、字幕和基础理解结果”的能力入口，skill 不规定具体参数名，也不限制工具内部实现。若没有等价能力，不要声称已完成完整视频理解或完整反解。

若视频存在音轨，优先使用可用语音识别、字幕/OCR、宿主视频理解或用户字幕稿提取对白。没有可靠证据时，不编造台词、歌词、音效或音乐细节；可说明“有音轨但未取得精确对白转写”，并只写可确认的声音信息。

## 任务路由

类型/风格/媒介判断：直接返回主类型、主子类型、必要辅助类型和一句美学判断，不输出 Prompt。

故事概括/剧情解释/人物关系/结局：按原片事实还原事件顺序、人物行为、动机、冲突、转折和结局；只写可确认对白，不做完整拉片 Prompt。

剧本整理：按“场次/时空—人物—动作与事件—可确认对白/旁白—转场或结果”整理；画面无法证明的心理、背景设定和台词不得当作原片事实。

单维度分析：只分析用户指定维度及必要关联维度，例如镜头、运镜、光影、色调、声音、对白、材质、某个时间段；用户未要求 Prompt 时输出分析结论。

完整反解/复刻/拉片/生成 Prompt：按完整流程输出“全局视听DNA + 拉片段 + 细切分时间轴 Prompt”。普通“复刻这个视频”没有替换或迁移要求时，等同完整反解，输出格式和详细度完全一致。

参考图替换迁移：先反解原视频，再分析参考图的可见事实；只覆盖用户授权替换的字段，未授权的原视频人物、动作、场景、镜头、光影、声音结构保持原样。若最终只输出文字 Prompt，把参考图内容写成自包含文字，不依赖“按图生成”。

## 核心反解流程

1. 读取输入：确认视频来源、用户范围、目标模型、是否有参考图、是否需要声音和截图。
2. 快速定调：识别视频主类型、主子类型、辅助类型、媒介形态、传播形态、声音模式和美学语法，用于决定重点维度。
3. 细致反解：按真实切镜、动作变化、表情变化、构图变化、运镜变化、焦点变化、光影曝光变化、色调变化、VFX、声音和字幕节拍拆分视频。
4. 编译 Prompt：把反解结果改写成可生成视频的自然语言 Prompt，而不是分析报告。
5. 复核输出：检查真实镜头没有被合并，人物资产没有被压缩，时间段没有超过 3 秒，声音没有被编造，最终格式没有 Markdown 装饰。

## 时间切分规则

真实切镜决定 Shot；同一 Shot 内的主体、动作、表情、构图、运镜、焦点、光影、曝光、色调、VFX、声音、歌词/节拍或段落功能发生变化时，建立更短的时间段。

最终可见时间段最长 3 秒，但 3 秒不是固定切片间隔。真实变化发生在 0.4 秒、0.8 秒、1 秒、1.5 秒或 2.2 秒时，应按真实变化提前切分。只有一个连续摄影状态确实稳定超过 3 秒时，才拆成多个不超过 3 秒的连续时间段，并标注“同一连续镜头，无切镜”。

人物细切优先级高于段落概括：只要人物入场/离场、脸部角度、视线方向、表情、口型、手部动作、身体姿态、受力/接触、遮挡关系、服装/发型状态或多人施事/受事/反应归属发生可见变化，就必须建立独立时间段；不得把同一人物的多个动作阶段或多个人物的不同状态合并成一个笼统段落。

亚秒快切可以写成“快速蒙太奇组”，但必须逐个写清镜头顺序、相对时长、主体、动作、构图、镜头运动、影像渲染和切换方式。

完整反解默认按每 15 秒一个“拉片段”包装，方便用户复制到生成模型并保持段间衔接。只有用户明确要求 30 秒 Prompt、明确指定 30 秒块长，或目标平台明确要求 30 秒版本时，才可以合并相邻两个 15 秒拉片段或输出 30 秒版本；即使输出 30 秒版本，段内仍必须按真实镜头和控制变化细切，最长 3 秒，不得粗切。字符预算不能反向缩短拉片段，也不能合并真实镜头。

## 人物与主体规则

主要人物、跨镜复现人物、需保持一致或被参考图替换的人物，必须在每个实际出现的拉片段内完整写“人物固有资产”。包括可见的头脸轮廓、五官、肤色与皮肤质感、体型比例、永久识别点、发型、妆容、服装单品与层次、面料、鞋袜和配饰。不可用“同一女性”“保持一致”“主角”“P1”或几个气质词替代。

多人镜头必须按人物分别绑定动作和结果。不要把一个人的反应写成另一个人的受事结果；不要因为主角更显眼就覆盖配角的实际状态。

产品、动物、空间、关键道具和品牌图形同样需要保持结构一致。没有出现的内容不补写。

## 最终输出格式

完整反解、复刻、拉片和完整生成 Prompt 使用同一套输出格式。最终输出默认使用纯文本，不使用 Markdown 代码块、Markdown 标题、加粗、斜体、引用块或表格；字段名不要包裹 `**`、`###`、`>` 等标记。

全局视听DNA：
画幅与载体：[原片画幅比例、横竖屏、可确认分辨率/帧率、目标模型和拉片段策略。]
视频类型与媒介：[主类型、主子类型、视觉媒介、传播形态和美学语法。]
核心主体资产：[贯穿全片或当前范围的主要人物、动物、产品、空间资产总览。]
场景与世界规则：[稳定场景系统、空间关系、时代/地域/世界观、关键道具和环境规则。]
全片色调与光影弧线：[整体色调变化、主辅强调色落点、明暗结构、光源规律、曝光/高光/暗部变化。]

## 声音规则

对白、旁白、口播和歌词必须来自可靠语音识别、字幕/OCR、用户提供文本或宿主等价视频理解结果。没有可靠证据时，不用“有人说话”“日语对白”“挑衅对白”等概括替代完整台词并声称完整复刻。

目标模型会生成声音时，拉片段只允许生成时间轴中明确列出的对白、BGM、环境声、音效和静默；不要根据画面动作自动补脚步、衣料、碰撞、风雨、开门等未确认拟音；持续音乐和环境声不要在切镜或拉片段边界重启。

## 影像渲染规则

最终 Prompt 不输出“光影光路 / 色调与成像 / 氛围”三段式，也不输出“光源配置 / 照射路径 / 材质响应 / 空气介质 / 运动曝光变化 / 光色变化链”等分析子标题。这些只能作为内部防漏检查。最终统一写入“影像渲染”，用生成友好的自然语言表达。

若原片可见局部过曝、高光剪切、暗部噪点、曝光适应、白平衡漂移、手持晃动、焦点迟滞、滚动快门、压缩块、AI质感或真实拍摄质感，必须写入对应时间段，不能被“电影感”“真实感”“氛围感”吞掉。

无论 `references/` 中出现任何内部字段、旧字段、知识卡字段或分析子标题，最终用户可见输出一律以本文件“最终输出格式”为唯一准则。阶段二可以检查光源、照射、材质、空气、色调和氛围细项，但阶段三必须把这些证据合并写进“影像渲染”，禁止把内部检查项作为最终字段名输出。
