# 黏土风创作

## 核心原则

黏土风格的灵魂是"手工感"——画面里的一切看起来都像是被人用双手捏出来的，带着指纹、压痕和不完美的圆润。不是3D渲染的精致，而是手作的温度。

软糯Q弹的关键在于：形体饱满圆润不锐利、表面有指纹与工具压痕、色彩高饱和但不刺眼、整体呆萌可爱到让人想捏一把。

**持久引擎（因果链）：**

**原始对象 → 黏土材质转译 → 质感细节（指纹/压痕/光泽） → 色彩饱和与对比 → 造型呆萌化 → 场景微缩化 → 情绪感染（想捏一把） → 成片**

每一步都是不可跳过的因果：没有材质转译就不像黏土，没有质感细节就像塑料，没有色彩饱和就灰暗无趣，没有呆萌化就缺少黏土风格特有的可爱灵魂，没有微缩化就缺少黏土手工的尺度和趣味。

## 质量测试（可证伪）

**如果画面里的对象看起来像是可以用3D软件直接渲染出来的光滑模型，而非用手捏出来带有指纹和不规则圆润的黏土作品，则风格不成立，必须重做。**

判据清单（全部通过才进入出 prompt 阶段）：

- 表面是否有可见的指纹/工具压痕/不规则纹理
- 形体是否饱满圆润、无锐利棱角
- 色彩是否高饱和但不刺眼
- 整体造型是否传达呆萌可爱感
- 是否有手工制作的不完美感（轻微不对称、压痕深浅不一）

## 工作流

### 第 1 步：诊断输入

解析用户提供的对象、题材、产物类型、画幅。按输入诊断表补全缺失维度，只追问缺失项。

### 第 2 步：加载词库

按路由表加载对应 reference，提取黏土质感关键词、色彩方案、造型指导和动态参数。

### 第 3 步：构建 Prompt

**图片 prompt 结构：**

1. 风格锚定句："黏土手工风格，软糯Q弹质感，表面保留指纹压痕，手工捏制的不完美圆润感"
2. 主体描述：对象的核心特征 + 呆萌化改造（圆润化、比例夸张、表情呆萌）
3. 材质细节：表面纹理（指纹/工具痕/不规则光泽）、色彩饱和度、高光与阴影
4. 场景与背景：纯色柔光背景 或 微缩手工场景
5. 情绪定调："呆萌可爱，让人想捏一把的冲动"

**视频 prompt 结构：**

1. 风格锚定句（同上）
2. 主体描述 + 动态设计：黏土的弹性物理（轻微弹跳、晃动、变形回弹）
3. Beat 分镜（≤15s 一次生成完整片段）：
   - 0-3s：主体入画，轻微弹跳亮相
   - 3-7s：主体动作展开（转动/变形/交互），展现黏土弹性
   - 7-12s：高潮动态（变形回弹/表情变化/场景互动）
   - 12-15s：收束定格，可爱定格pose
4. 材质与光：柔光环境，黏土表面漫反射高光，色彩高饱和
5. 情绪定调：呆萌可爱

### 第 4 步：生成

- 图片：一次生成即可
- 视频：≤15s 的视频用一次生成即可拿到完整片段；&gt;15s 时拆成若干 ≤15s 片段各自一次生成，再做后处理拼接
- 如需角色一致性，把角色参考图通过参考素材传入，并在 prompt 中用 `@图片N` 引用

### 第 5 步：静默自检

对照下方自检清单逐条检查，未通过则修正 prompt 后重新生成。

## 静默自检

交付前内部逐条检查，不外显：

- \[ \] 风格锚定句是否包含"黏土""软糯Q弹""指纹压痕""手工捏制"
- \[ \] 主体造型是否完成呆萌化改造（圆润/夸张/呆萌）
- \[ \] 材质描述是否包含指纹/压痕/亚光光泽/不完美感
- \[ \] 色彩方案是否明确且高饱和
- \[ \] 视频动态是否体现黏土弹性物理（弹跳/变形回弹）
- \[ \] 视频时长 ≤15s 时是否一次性生成而非分段拼接
- \[ \] 视频时长 &gt;15s 时是否已拆成 ≤15s 片段
- \[ \] 如需角色一致性，是否通过参考素材传入角色图
- \[ \] 画幅是否与目标平台匹配
- \[ \] prompt 措辞是否全部正向（无否定式堆叠）
- \[ \] 是否有合规风险（肖像权/品牌/儿童）
- \[ \] 全文语言是否与目标市场一致（中文）无中英混杂
