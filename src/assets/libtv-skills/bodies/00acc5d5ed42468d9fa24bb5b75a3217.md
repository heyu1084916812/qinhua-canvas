# 视频提示词编译器

## 定位

写提示词最常见的失败不是写得太少，而是**回忆关键词**——想起什么修饰语就堆上去。"电影感、高级感、大片质感、氛围拉满"这类词模型无法执行，它不知道要调什么；而"环绕运镜 + 快速推近 + 手持晃动"堆在一起会互相抵消，画面直接塌陷。

本 skill 的做法是把提示词当作**编译产物**：先判断输入属于哪一类（有没有素材、多长），选定对应的结构模板，再逐层填空，最后过一遍空词替换和冲突检查。

镜头层不在本 skill 内展开。需要设计机位时调用「运镜坐标系」类 skill，本 skill 只负责把它的结果嵌进【镜头】那一层。

## 输入

用户给一句创意需求即可。缺失项按 Ask User 处理。

默认值：单镜头 / 10 秒 / 16:9 / 含环境音、无对白。

## 内部流程

### 第一步：判断路径

看两件事——**手上有什么素材**、**要多长**——四条路径只能走一条：

条件路径无素材，≤15 秒A 纯文本短片有首帧图／角色图B 图生视频有参考视频，想改造成自己的主题C 参考复刻超过单次生成上限D 分段长视频（读 REFERENCE-longform.md）

判断不了就问，不要默认走 A。

### 第二步：按路径填结构

**路径 A｜纯文本短片**

12 秒以内用六段式，逐项都要有内容，不留空：

```
[风格总纲/色调] + [主体描述] + [动作序列] + [环境与光影] + [镜头语言] + [声音]
```

13 秒以上改用时间戳分镜——把整条切成 3–4 个时间段，每段各自写清画面、镜头、声音：

```
[总时长][风格总纲]，
0-3秒：[画面] + [镜头] + [声音]；
4-8秒：...
```

**路径 B｜图生视频**

核心纪律：**不要重描图里已经有的东西**。把人物长相、服装、场景陈设再写一遍，文字和图片会互相拉扯，脸和衣服跟着漂。只写三件事——图里什么开始动、怎么动、光怎么变。其余全部交给图。

**路径 C｜参考复刻**

先把参考片拆成两栏，再写提示词：

- **保留**：节奏、运镜方式、剪辑结构、整体基调、开场钩子的类型
- **替换**：主题、主体、环境、色调、具体动作

拆完先把两栏念给用户确认，再进入 A 或 B 的结构。跳过确认直接写，出来的东西通常既不像参考片也不像用户想要的。

**路径 D｜分段长视频**

读 REFERENCE-longform.md，按四件事处理：分段结构、一致性锁定、节奏曲线、段间桥接。

### 第三步：铺美学层

这一层决定成片是"能看"还是"好看"，四个动作：

1. **品质锚定**：开头用具体的工艺名词，不用空形容词。写"35mm 胶片颗粒、柔焦光晕"而不是"电影感"；写"微距镜头、浅景深、油润高光"而不是"高级感"。空词等于没写。
2. **全片物理声明**：声明一个贯穿始终的物理效果——薄雾弥散、空气浮尘、雨水附着、细微颗粒。它的作用是缝住段与段之间的氛围断裂。
3. **色调三件套**：一个冷暖倾向 + 一个高光色 + 一个阴影色。三个就够，给多了互相抵消。
4. **适度的镜头污染**：雾气粘在镜头上、雨滴挂在镜片前、轻微耀光、边缘失焦。这些"不完美"会显著提升真实感——完全干净的画面看起来像渲染图。

词汇选择见 REFERENCE-lexicon.md。

### 第四步：查冲突

写完先自己找矛盾，最常见的三类：

- **运动冲突**：同时出现两个以上运动指令（推近 + 环绕 + 晃动）。留一个主运动，最多加一个辅助轴。
- **光线冲突**：既要"逆光剪影"又要"看清面部表情"。挑一个。
- **风格冲突**：既要"写实纪录片质感"又要"梦幻柔光"。挑一个，或者明确写清哪一段用哪个。

### 第五步：分别创建生成节点

冲突查完，**为每一版各调用一次视频生成**，把提示词写进节点、按命名规则起名，让节点以待确认状态留在画布上。

这一步是动作，不是排版。写完提示词就停在对话里、等用户说"用第二版"，等于没做完——用户还得自己复制粘贴建节点，skill 的价值就丢了一半。

## 输出

**不要把版本排版成文字发在对话里。** 每一版都要**实际调用视频生成，各创建一个生成节点**，提示词写进节点内，让它以待确认状态挂在画布上——用户点哪个跑哪个，不点不消耗。

自查标准很简单：如果回复里出现了「卡片 1」「版本一」这类文字标题，就是做错了，那只是排版，画布上什么都没有。做对的结果是**画布上多出 N 个待确认的视频生成节点**。

对话里只留两样东西：一句路径判断，和一段各版差异说明。提示词正文属于节点，不要在对话里重复一遍。

**版本数由用户决定，不要固定。** 用户报了数字就照办；没报就按需求的明确程度自己定：需求很具体（指定了主体、光、镜头）出 1–2 版，需求笼统或带探索意味出 3 版，超过 3 版没有意义——选项太多反而挑不动。定完在差异说明里交代出了几版、为什么。

**节点命名** — 待确认节点是空占位，没有缩略图，**名字是唯一的区分手段**。按「主体-取向-时长」命名，例如`雨夜便利店-克制纪实向-10s`。不要用"版本一""方案 A"这种，用户过一会儿回到画布上就分不清了。

**每个节点的提示词必须完全自包含。** 节点会被单独运行，所以不能出现"同上""其余不变""参考第一版"这类交叉引用，时长、画幅、声音处理每个节点都要写全。单独拎出一个节点也能跑通，这是硬要求。

版本之间要有**实质差异**——不同的镜头思路或不同的情绪落点，不是同一句话换几个形容词。单个节点的提示词控制在 300 字以内，超长的层会被丢弃。

## 技巧

输出前逐条自检：

- 路径是否判断正确，结构是否用对（≤12 秒六段式 / 13 秒以上时间戳）
- 六段是否都有内容，有没有留空
- 是否还有空词残留：电影感、高级感、大片质感、氛围感、质感拉满、精致、唯美
- 图生视频路径下，是否重复描述了图里已有的内容
- 是否出现运动、光线、风格三类冲突
- 时长是否在单次生成上限内（见 REFERENCE-lexicon.md 的校准表）
- 是否出现对白超千字或多幕分镜（平台不支持）
- 各版本之间是否有实质差异
- **是否真的创建了生成节点**，而不是在对话里排版成「卡片 1」「版本一」这类文字标题
- 单个节点提示词字数是否在 300 字以内
- **每个节点是否自包含**：有没有"同上""其余不变"这类交叉引用，时长／画幅／声音是否每个都写全
- **节点命名是否能区分**：待确认节点没有缩略图，名字要带主体和取向，不能叫"版本一"
- 版本数是否来自用户指定或明确的推断依据，有没有无理由地固定成三版

## Ask User

一次问完，不逐条追问：

- **手上有没有素材**（图／参考视频／都没有）——这决定走哪条路径，缺了必须问
- 时长和画幅
- 要不要声音，有没有对白

**版本数不要问**——按需求明确程度自己定，在输出里说明理由。用户想改数量会直接说，多问一轮不值得。

其余用默认值，输出后一行说明。

## 示例

**输入**：想做一个雨夜便利店的镜头，10 秒，没有素材。

**动作**：调用视频生成三次，创建三个待确认节点。

**节点一** 名称`雨夜便利店-克制纪实向-10s`，提示词：

10 秒，16:9，无对白。35mm 胶片颗粒质感，冷绿荧光为主调、暖黄高光、蓝黑阴影；一名穿湿透外套的年轻男人站在便利店冷柜前，低头看着手里的关东煮，热气往上飘；他抬手擦了一下额前的湿发，然后不动了；店内荧光灯从头顶均匀压下，玻璃门外是雨幕和偶尔扫过的车灯；镜头平视中近景，极缓慢横移，全程雨水附着在玻璃上形成散射光斑；声音是雨声、冷柜嗡鸣、门口感应铃隐约响过一次。

**节点二** 名称`雨夜便利店-强反差戏剧向-10s`，提示词： 10 秒，16:9，无对白。高对比硬光，青蓝夜色与便利店暖橙形成强烈反差；一名年轻男人背对镜头站在店门内侧，肩膀起伏；门外雨势陡然变大，一道车灯横扫过他背影，整个人只剩一片剪影；车灯过后店内暖光重新吃回画面；镜头低机位仰拍，从他背后缓慢推近至肩部特写；空气中有薄雾弥散效果，镜头边缘轻微耀光；声音是雨砸在雨棚上的密集敲打，车灯扫过时压掉所有环境音只留一声低频闷响。

**节点三** 名称`雨夜便利店-无人空镜向-10s`，提示词： 10 秒，16:9，无对白。脱饱和冷蓝色调，高光偏白、阴影偏深蓝；便利店内空无一人，货架整齐、荧光灯均匀打亮；镜头从店外雨幕后缓慢推进玻璃橱窗，雨滴挂在镜片前形成散点虚焦光斑，透过雨滴可见店内货架和收银台上没人的椅子；推近至玻璃贴面时停住，室内外两个世界通过玻璃折叠在同一帧；细微颗粒贯穿全程；声音只有雨声和玻璃门缝隙透出的荧光灯嗡鸣，无任何人声。

**对话里只说这段**——出三版是因为需求只给了场景和时长、没指定主体和情绪，属于探索型。三版差异在**主体的处理**——第一版让人物完整在场、光平均把情绪压住；第二版把人物压成剪影、用光的反差把情绪推出来；第三版彻底去掉人物，用空镜和雨幕做留白。用了默认的 16:9 / 无对白。三个节点已挂在画布上，点哪个跑哪个，不点不消耗；也可以先在节点里改提示词再跑。想加版本或换方向直接说。
