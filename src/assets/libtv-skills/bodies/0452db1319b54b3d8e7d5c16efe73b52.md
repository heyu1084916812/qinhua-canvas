# 泥塑习作·列宾美院风格 SKILL

把**线稿图**或**人物照片**转换为苏派现实主义泥塑习作效果的标准化提示词生成规范。

## 一、参考作品特点解读（风格锚定的依据）

对参考作品库（15+ 张成品泥塑图）逐项拆解，以下特点是生成时必须全部命中的「风格指纹」：

### 1. 材质与色彩

- **灰褐色黏土**：主体统一为湿黏土的灰褐—暖灰色调，色相低饱和，绝不允许出现彩色、铜绿、金色、白色石膏感或陶瓷釉面感；同类作品中偶见轻微偏暖（赭石灰）与偏冷（青灰）两种倾向，默认取中间暖灰褐。
- **湿润感**：表面保留刚塑完的湿润反光——块面高点有细腻哑光高光（非镜面反射），凹陷处吃光变深，整体像「还未进窑、仍在转台上的习作」，而非干燥成品。
- **单色统一**：人物、衣饰、道具、基座全部同一种黏土材质，用明度而非色相区分层次。

### 2. 表面肌理（本风格最核心的识别特征）

按出现频率从高到低，生成图必须可见以下至少 4 类痕迹：

- **雕塑刀刮痕**：平行排刀刮削留下的细密平行纹理，多用于衣料大面与面部过渡面。
- **木刀/刮板压痕**：宽刃工具压出的长条凹槽与棱线，用于表现衣褶、肌肉走向。
- **手堆泥痕**：泥条、泥饼堆叠叠加的阶梯状起伏与指压痕，集中在肩背、基座、衣摆等大体积处。
- **块面切削棱线**：大刀阔斧的切面转折，体面之间保留锐利的「刀口」，不做圆润打磨——这是学院派「宁方勿圆」的直接体现。
- **细节戳塑痕**：胡须、头发、眉眼处用尖工具戳、挑、划出的细碎短线。
- **反向禁止**：表面光滑如镜、3D 渲染的均匀细分面、机械抛光、数字雕刻的 ZBrush 式均匀笔触——出现即判失败。

### 3. 块面与造型语言

- **苏派块面结构**：解剖结构被概括为明确的几何体面（额结节、颧突、下颌角、胸锁乳突肌等转折清晰可辨），强调体块之间的「咬接」与穿插。
- **夸张而合理的动态**：动态姿势重心大胆偏移（前倾、扭转、腾跃），但重心逻辑必须成立，符合纪念碑雕塑的力学感。
- **衣纹处理**：衣褶厚重如「冻住的浪」，褶皱方向服从肢体动态与重力，大皱以宽刀面概括、小皱以排刀收束，绝不画成柔软丝绸。
- **面部刻画**：骨点硬朗、眼窝深陷、眉弓突出；表情克制而凝重，带有史诗叙事的庄严感，不做卡通化、媚态化处理。

### 4. 基座与背景

- **基座**：与主体连体的粗糙黏土台座（方形或不规则块体），表面同样保留刀痕与手塑痕；胸像可接简化方台。
- **背景**：纯白（或极浅灰）无缝背景，无任何环境元素、道具陈设、文字水印——参考作品全部为白背景工作室「证件照」式呈现。

### 5. 光影参数（必须写进提示词）

- **布光类型**：工作室摄影布光，戏剧性单一主光源。
- **主光方向**：默认左上方约 45° 侧光（伦勃朗式），使面部与躯干形成明确的受光面—背光面二分。
- **光比**：高反差戏剧性光比（受光面亮、背光面深但不死黑），用以强调块面转折；阴影边缘清晰偏硬，体现湿黏土的形体咬合。
- **投影**：基座与背景衔接处允许有柔和落地投影，增强雕塑「摆在转台上」的实物感。
- **高光性质**：黏土的湿润亚光高光，集中在骨点、鼻尖、肩头等最高体面，拒绝金属/瓷器式锐利高光。

### 6. 题材与气质

- 参考库题材集中于：历史/革命人物群像、劳动者动态、传统装束人物立像、肖像胸像、宗教/古典人物。
- 共同气质：纪念碑式的庄重感 + 史诗般的氛围 + 学院派的严谨功底；动态类作品强调「充满张力的瞬间定格」。

## 三、提示词组装结构

成稿提示词 = **风格锚定块（第二节，逐字）+ 主体描述块 + 布光与背景块 + 保真子句**。四段顺序固定。

- **主体描述块**：从参考图解读出的动作、姿态、装束、构图（胸像/全身/群像）、视角，要求具体到「重心在哪条腿、头转向哪、手在做什么」。身份特征（脸型、发型、标志性五官）**指向参考图，不在正文重描**。
- **布光与背景块**：默认写「左上方约 45° 单一主光源，高反差戏剧性光比强调块面转折，基座与主体连体粗糙黏土台座，纯白色背景」。用户另有要求时替换。
- **保真子句**（一条总括，整段一行）：`除上述点名改造的内容外，人物身份特征、构图、姿势与画面其余内容全部保持不变。 / Keep the subject's identity, composition, pose and all untargeted content unchanged.`

## 四、两条工作路径

### 路径 A：线稿 → 泥塑（重点：线条转体面）

在线稿的图形结构基础上「立体化」：

1. 线稿的轮廓线 → 泥塑的外轮廓与剪影；
2. 线稿的内部结构线/排线 → 雕塑的块面分界与刀痕走向；
3. 线稿无光影 → 由提示词指定主光方向补出戏剧性光影。\
   模板（整段一行，替换【】内容）：


### 路径 B：人物照片 → 泥塑（重点：身份保持 + 材质置换）

照片提供身份与姿态，泥塑化只做「材质与造型语言置换」：

1. 身份特征（脸型、五官、发型、年龄感）严格保留，**指向参考图，不重描五官**；
2. 皮肤、毛发、织物、金属等一切材质统一置换为灰褐湿黏土；
3. 照片原有环境背景删除，替换为纯白背景 + 黏土基座；
4. 若用户要求改动作（如"改成冲锋姿势"），把动作描述写进主体块，并在保真子句里豁免动作项。\
   模板（整段一行，替换【】内容）：

```
将照片中的人物转化为一件列宾美院风格的泥塑习作：人物身份特征、脸型、五官、发型与年龄感严格保持与照片一致，全身材质统一置换为湿润的灰褐色黏土。列宾美院风格，泥塑习作，写实主义雕塑，充满张力的动态姿势，戏剧性光影效果（强调块面转折），灰褐色黏土质感，保留湿润黏土的柔软可塑性痕迹，可见雕塑工具刮擦与堆叠痕迹，粗犷而富有表现力的表面肌理，苏派现实主义传统，深厚的学院派功底，纪念碑式的庄重感，史诗般的氛围。【姿态/构图描述：沿用照片姿势或描述新动作】，【胸像/全身像/群像】，连体粗糙黏土基座，左上方约 45° 单一主光源，高反差戏剧性光比强调块面转折，纯白色背景，照片原有背景全部移除。除上述点名改造的内容外，人物身份与画面其余内容全部保持不变。
```

## 五、参数速查表（按需替换默认值）

参数默认值可选项黏土色相暖灰褐（湿黏土）偏赭石灰 / 偏青灰构图类型全身立像肖像胸像 / 半身像 / 双人或多人组雕主光方向左上方约 45°正侧光（更强戏剧性）/ 顶光（更凝重）光比高反差戏剧性光比柔和均匀光（习作感更强、纪念碑感更弱）动态强度充满张力的动态姿势静立庄重（肖像类）/ 行走 / 搏斗 / 劳动基座连体粗糙黏土台座简化方台（胸像）/ 不规则岩石状台座背景纯白极浅灰（仅当用户要求）表面完成度粗犷刀痕 + 湿润可塑性更粗糙（速塑感）/ 略收细（接近定稿）

## 六、禁止项（Negative，出现即返工）

光滑或抛光表面、陶瓷/石膏/青铜/大理石等其他材质、任何彩色涂装或做旧铜锈、金属高光、3D 渲染感与 ZBrush 式均匀数字笔触、环境场景与道具背景、文字与水印、卡通化/Q 版化面部、丝绸般轻软的衣纹、干燥开裂的陶土裂纹（湿黏土是柔韧痕迹不是龟裂）。

## 七、交付前自检清单

1. 风格锚定块是否逐字完整？
2. 主体描述是否含重心/头向/手部动作等具体动态信息？
3. 布光方向、光比、背景、基座四项是否都写了？
4. 保真子句是否覆盖身份与未点名内容？
5. 是否误写了分辨率/比例参数？（比例与分辨率绝不写进正文）
6. 成品图自检：灰褐单色✓ 刀痕堆叠痕≥4 类✓ 湿润亚光高光✓ 白背景✓ 连体基座✓
