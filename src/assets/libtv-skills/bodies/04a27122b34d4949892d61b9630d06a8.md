# 暗黑黏土风格创作

## 核心原则

不要把「暗黑黏土」当成"黏土材质 + 把画面调暗"两个标签的叠加。它成立的原因是**黏土的可塑性被用于表达不安**：物形在缓慢变形、指纹与工具痕迹清晰可见、表面哑光吸光、色域低饱和偏灰——观者感到"这个世界的物理规则是软的、活的、不受控的"。

持久引擎（因果链）：

**题材内核 -&gt; 怪诞张力点 -&gt; 黏土形变（被拉伸/挤压/扭曲的具体部位）-&gt; 阴郁光色（单侧冷硬光源 + 低饱和灰调）-&gt; 不可控感 -&gt; 荒诞幽默或不安余韵**

## 质量测试（可证伪）

一张合格稿必须同时满足：

1. **黏土证据可指认**：画面里至少能指出 3 处具体黏土特征（指纹压痕、接缝、拉伸变形、哑光吸光表面、工具刮痕）。
2. **怪诞服务于题材**：抽掉变形与暗调，题材张力明显损失——即怪诞不是贴皮而是叙事本身。
3. **不靠惊吓画面**：不安感来自形变与氛围，不来自伤害性或违规内容。

不满足就重写提示词，不要进入生成。

## 输入诊断

落 prompt 前，识别或合理假设以下维度（用户没给的做合理假设并继续，只在题材完全无法推断时发问）：

- **题材 / 主体**：人物、生物、静物、场景还是抽象概念？
- **怪诞类型**：荒诞幽默（可爱但扭曲）／诡谲不安（阴森变形）／暗黑童话（阴郁叙事感）——默认诡谲不安。
- **画幅**：按需求定（9:16 竖屏 / 16:9 横屏 / 1:1），不固定；用户未提则按主体和用途合理选。
- **产物形态**：单图、套图（几图一组、什么关系）还是短视频（时长、有无运镜）。
- **主体造型**：黏土人偶的比例夸张方向（大头小身、细长扭曲、还是被压扁）。
- **形变程度**：轻微歪斜（克制叙事感）还是剧烈扭曲（强烈怪诞）。默认中等偏强。
- **色彩基调**：默认低饱和灰调 + 一处点睛色（暗红／毒绿／深紫）；也可用户指定。
- **光线**：默认单侧冷硬光源 + 大面积阴影；黏土必须哑光不反光。
- **比例参照**：画面里至少放一个"正常尺度物件"衬托黏土世界的失真。
- **合规**：不出现真实品牌、真人肖像、伤害性或惊悚到违规的元素。

## 工作流（步骤）

1. **解析输入**：按「输入诊断」维度补全缺失项，做合理假设。
2. **定怪诞张力点**：明确这一稿"哪里变形、为什么变形"，形变必须服务题材。
3. **读取参考**：按路由表读取对应 reference，取用词与句式。
4. **组装 prompt**：按输出契约的固定结构写正向措辞的提示词，黏土材质四件套（质感／形变／光／色）一项不缺。
5. **静默自检**：跑「静默自检」清单，弱项重写。
6. **生成并交付**：按任务生成图片或视频；展示产物。素材命名入 `assets/` 目录，语义化英文命名（如 `clay_shot_01.png`）。
   - 时长 ≤15 秒的视频：用一次视频生成拿到完整成片；prompt 里的时间轴（0-3s/3-7s/…）是同一条生成内部的时间描述，不是分段多次生成。
   - 成片超过 15 秒：拆成若干 ≤15 秒片段分别一次生成，再做后处理拼接、配乐。

## 输出契约

### 图片 prompt 结构（四件套，顺序固定）

```
黏土质感：手工黏土模型、哑光吸光表面、可见指纹压痕与接缝、微糙工具痕迹
造型与形变：主体比例描述 + 具体形变部位（如：脖颈被拉长扭曲、面部被挤压出不对称笑容）
光线：单侧冷硬光源（如灰蓝月光／昏黄灯泡）+ 大面积深色阴影
色彩：低饱和灰调为主 + 一处点睛色（暗红／毒绿／深紫）
再补：主体动作与表情、场景与尺度参照物、镜头与构图、情绪基调
```

### 视频 prompt 结构（时间轴式）

```
0-3s: <镜头> <主体首次形变或异常动作> <声音质感，如黏土挤压的闷响>
3-7s: <镜头变化> <形变升级或场景揭示> <环境音>
7-12s: ... 
12-15s: <收束镜头> <怪诞定格或余韵> <声音收尾>
```

每个 beat 以镜头起手；黏土质感四件套写在 prompt 开头一次声明，后续 beat 不重复；全程正向措辞，不写否定式约束。

### 套图

按 `references/formats/series.md` 的方式统一材质、光色与镜头家族，只变换主体与动作，保证系列一致。

## 静默自检

交付前内部执行，弱项重写；除非用户要求点评，不外显清单：

- 黏土证据是否 ≥3 处具体可指认（指纹、接缝、形变、哑光、刮痕）？
- 形变是否服务题材，抽掉后张力明显损失？
- 是否无伤害性内容、真实品牌与真人肖像？
- 质感四件套（质感／形变／光／色）是否齐全且具体到可生成？
- 是否有尺度参照物衬托失真？
- 视频时长 ≤15s 时是否按一次生成完整成片处理？&gt;15s 是否已切成 ≤15s 片段？
- prompt 是否全正向措辞？
- 全文语言是否与用户一致（中文）？
