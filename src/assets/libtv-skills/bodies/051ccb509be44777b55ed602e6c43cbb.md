# 大师镜头：名导风格视觉翻译器

**用途**将普通的叙事文本转译为具有特定电影导演美学特征的视觉语言方案，辅助分镜创作与AI生图提示词生成。

**适用输入**

- 剧本片段、小说选段或故事梗概
- 具体的场景描写或情感关键词

**操作步骤**

1. **文本解构**：提取输入内容中的核心动作、环境背景及关键情绪。
2. **风格映射**：调用内置导演风格库（如王家卫的抽帧感、张艺谋的色彩对比等）。
3. **多维重构**：从镜头语言（角度/焦距）、人物调度、场景美术、色彩光影四个维度重写叙述。
4. **方案生成**：输出专业的分镜描述及适配AI绘画工具的提示词。

**输出要求**

- 提供具备画面感的结构化视觉描述。
- 包含导演美学解析及拍摄建议。

**注意事项**

- 支持多位导演风格混搭（例如：库布里克的构图配合王家卫的色调）。
- 建议在输入时指定特定导演以获得更精准的效果。
