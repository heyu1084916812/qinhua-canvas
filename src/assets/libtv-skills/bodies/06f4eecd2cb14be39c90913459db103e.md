# AI 复现人物·定点口播规范

> 让 AI 复现的人物站在固定点位、面向观众讲一段话。核心不是某一条视频怎么剪，而是三件事的标准化：**形象怎么锁、声音怎么锁、动作怎么才自然**。 产出的是**可复用的规范与素材**，不负责交付成片剪辑。

---

## 一、适用范围与前置确认

适用：用 AI 复活／复现一个指定人物（历史人物、虚构角色、品牌代言人），让他在固定点位面向镜头讲述若干段文本。

开做之前先定四个槽位（每次任务会变的内容）：

槽位取值说明**画幅**原案例全程 4:3。按实际投放改成 9:16（竖屏）／16:9（横屏）／1:1。**必须全局统一**：每条图片提示词、每条视频提示词的结尾，以及生成节点的比例设置，三处都写同一画幅**人物 / 年龄段**一个年龄段 = 一套独立形象锚点。原案例青年与老年是两套独立形象锚点，不共用参考图**台词文本 + 段落划分**每段台词独立成一条配音任务；段数不限**场景 / 时代**决定"场景空镜"怎么写（古代书院／现代社区街巷／现代公园／舞台／会议室……）

下面五条是**锚点**（固定工艺，不随任务变），每个任务都要照做。

---

## 二、锚点 1：形象只认参考图，不认文字

**做法**：先产出该人物该年龄段的**唯一形象参考图（定妆图）**；之后每一张人物关键帧的提示词里都写死同一句话，并且**绝不用文字描述外貌与服装**：

```
以 {人物形象参考图} 为人物形象唯一依据，将{人物}自然合成到场景中。
人物的五官、须发、冠饰、服装一律以参考图为唯一依据，prompt 不做任何外貌或
服装的文字描述，不美化、不改容貌、不换装。
```

**反面做法（一定会漂移）**：在每条提示词里重新描写"花白长须、黑色布冠、灰蓝麻布长袍"。文字描述每写一次就重新采样一次，多条素材之间人物会越来越不像。

参考图里已经包含、因此**不必重复写**的信息：五官、脸型、眉眼、发型发色、冠／抹额、服装形制与配色、年龄感。

---

## 三、锚点 2：定点口播的构图规范

这是"像在跟观众讲话"的镜头标准。所有"站定讲述"关键帧都要满足：

- **完整全身**，位于画面正中，约占画面高度三分之二；
- **头顶与脚下留白**，不顶满、不裁切；
- 身姿端直、重心自然放松；双手自然垂于身侧，或在身前轻拱手／自然交叠；
- **目光平和正视前方**（观众方向），神态庄重、慈祥或温和；
- 受光与场景一致、**投影自然**，不要"贴上去"的假感。

走动／观察类镜头（非讲述段）只换镜头语言：一脚轻迈、一手轻扶长须或衣袖、目光看向一侧而非镜头，同样保持"完整全身、居中、上下留白"。

**人物动、镜头不动**：定点口播的镜头基本固定或只做轻微推拉，避免运镜与人物质感打架。

---

## 四、锚点 3：场景空镜先定调，人物后合成

顺序固定，不要颠倒：

1. 先出**纯场景空镜**（无人物）：写明大环境、光线、色调，并注明"画面中央为后续人物留出站立空间"；
2. 再出**人物关键帧**：提示词同时引用"形象参考图 + 场景空镜"，并写明"严格保持场景的建筑、光线与陈设不变"。

同一幕的多个关键帧必须指向**同一张场景空镜**，否则光线和空间关系接不上。需要过渡镜头（如特写）时，仍引用同一张空镜，只换景别。

---

## 五、锚点 4：音色锚点 + 配音规范

**锁定音色的流程**：

1. 先用定妆关键帧跑一条**人物人设视频**；
2. 从这条视频里**抽出人声**，该人声即成为此人的**唯一音色依据**；
3. 之后每一段台词配音，都以它为参照，并**原样复述同一段音色特征描述**。

**配音提示词模板**：

```
以 {音色依据（人声节点）} 的音色为唯一声音依据，严格保持该音色
（{音色特征描述，例如：老年男声，沉稳宽厚、温润儒雅，略偏老年但不苍老、中气足}），
用相同的嗓音念出以下台词：

"{台词全文}"

{语速与语气指示，例如：语速沉稳缓慢、字字分明，语气庄重笃定；
念到"×××"时放慢、加重、掷地有声，尾音悠长。}
```

要点：

- **音色特征描述固定不变**，多段之间逐字复用，否则同一人物各段音色会飘。
- 每段都要给**语速 + 情绪 + 重音落点**三项指示；关键句（排比、点题句）单独点名"放慢、加重"。
- 一个年龄段一条音色锚点；换了年龄段（青年→老年）必须重新建立音色锚点。

---

## 六、锚点 5：让动作自然的四招

本规范最容易被省略、也最关键的部分。

1. **首尾帧衔接**：从上一段视频里抽出尾帧，作为下一段视频的首帧，用"首尾帧版"再生成。段落之间人物姿态连续，不会每段重新"起范儿"。
2. **同帧多版本择优**：同一张关键帧配同一段任务，跑多个版本（例如：有声／静音／纯音频驱动／首尾帧版／生动首尾帧版），挑动作最自然、无变形的一条，其余留作备选。
3. **待机无缝循环**：以站定关键帧生成一条"聆听待机·无缝循环"视频，长口播中用作插空与背景，避免人物长时间僵住或反复重起动作。
4. **动作幅度写具体、写小**："一手轻抬做小幅度致意"、"缓慢扫地"、"轻轻奔跑"、"静坐休憩、不运动、不站起"。给模糊动词（观察、走动）配上幅度与节奏限定词，是动作不僵硬的主要手段。

---

## 七、提示词收尾的固定负面清单

每条图片提示词末尾固定加上：

```
无文字、无水印、无印章、无logo。
```

画面内出现招牌／价签／店招／横幅时，额外写：

```
所有招牌、价签、店招、横幅上的文字一律模糊、虚化，看不清任何具体字样。
```

质感语汇同样统一复用（属锚点，不逐条新编）：材质高度真实、浅景深、8K、电影级光影、写实电影质感、低饱和。

---

## 八、作业顺序（可直接照跑）

1. 确认四个槽位（画幅／人物与年龄段／台词与段落／场景时代）
2. 产出**形象参考图**（每年龄段一张）
3. 产出**场景空镜**（每场景一张）
4. 由"参考图 + 空镜"产出各段**人物关键帧**（讲述帧按第三节构图规范）
5. 用一条关键帧跑**人设视频** → 抽出人声 → 得到**音色锚点**
6. 按段落写台词，逐段生成**配音**（复述同一段音色特征描述）
7. 关键帧 + 配音 → **图生视频**（首尾帧衔接、多版本择优）；另生成**待机无缝循环**一条
8. 按需做**高清放大**
9. 交付：各段素材 + 本规范的槽位说明；剪辑由使用者自行完成
