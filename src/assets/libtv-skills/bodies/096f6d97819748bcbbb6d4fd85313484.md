# 斯托拉罗色彩摄影

让颜色成为剧情语言，而不是后期滤镜。先定义人物与冲突的色彩轨迹，再让美术、服装、光源、曝光和调色共同执行。

## 收集输入

取得剧本或场景节拍、人物弧光、地点与时段、关键道具、服装与美术参考、前后场次、交付色彩空间以及实拍或 AI 生成方式。

## 工作流

### 1. 提炼戏剧轴

用两端对立词定义本段核心冲突，例如秩序/失控、信任/怀疑、欲望/克制、现实/记忆。不要先选颜色。

标出起点、转折、峰值和余波。为每一段写清人物处于哪一端、正在向哪里移动，以及颜色需要预告、陪伴还是反驳这次变化。

### 2. 建立颜色角色表

为每个主导色规定：

- 戏剧含义和所属人物、空间或力量。
- 出现条件、峰值时刻与退出条件。
- 主要载体：墙面、服装、实景灯、窗外、道具或肤色环境。
- 亮度、饱和度、冷暖和面积上限。
- 可与哪些颜色共存，哪些组合会破坏信息。

同一种颜色在不同项目中可以有不同含义。不要套用固定的“红等于危险”公式。

### 3. 画序列色彩脚本

按场次或镜头建立色彩脚本，至少记录：戏剧节拍、主导色、辅助色、中性色、亮度层级、饱和度、色彩来源、人物肤色关系和转场方式。

用可见的渐变或对比表达变化：颜色进入画面、面积扩大、污染中性色、人物跨入另一色域，或在高潮后被抽离。避免每场独立好看却无法连成弧线。

### 4. 绑定美术、服装与光源

先让颜色存在于世界，再用灯光强化。逐项说明：

- 哪些色由材质反射，哪些由发光体提供。
- 服装与背景如何分离或融合。
- 肤色是否被环境色污染，污染是否有叙事理由。
- 道具或建筑色如何在关键节拍成为视觉线索。

如果颜色只能靠整体 LUT 得到，重新设计场景内的颜色载体。

### 5. 控制曝光与色彩纯度

规定主导色所在的亮度区间、肤色优先级、高光颜色、黑位倾向和相邻色分离。检查 LED 饱和溢出、单通道剪切、暗部偏色与高饱和肤色。

允许黑色和中性色为主导色提供参照；不要把全画面都染成同一颜色。

### 6. 转译为生成提示词

提示词依次描述：人物与戏剧状态、颜色归属、颜色载体、光源方向与色温、画面面积比例、亮度关系、肤色保护、转折时的颜色变化和禁止色。

禁止只写“高饱和电影感”“某片同款色调”或摄影师姓名。要求模型生成世界中的颜色，而非简单覆盖滤镜。

### 7. 做色彩连续性质检

逐镜检查：主导色是否仍有戏剧含义；人物所属色是否提前泄露；转折是否清楚；肤色是否稳定；同一实景灯是否换色；黑位和高光是否被后期拉平。

若画面显得装饰化，先减少颜色数量和面积，再恢复中性色与明暗层级。

## 输出格式

1. **戏剧轴**：冲突两端、转折和人物移动。
2. **颜色角色表**：含义、归属、载体、强度与禁用条件。
3. **序列色彩脚本**：逐场颜色、亮度和转场。
4. **部门执行表**：美术、服装、灯光、摄影和调色责任。
5. **生成提示词**：颜色归属、载体、变化与禁止项。
6. **连续性检查**：最易失控的颜色与修正策略。
