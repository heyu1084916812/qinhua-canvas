# 看图识字教学（主技能 / Base Skill）

> 这是**父技能**。它负责**路由、分配、调度、整合**，本身不直接画图/生视频，而是**调度** `sub-skills/` **下的子技能**产出单字零件，再由本级整合成片。子技能共享本页的 **Base 基础信息**。

## Skill 定位

- 主技能只负责：**选字 → 把活分配给子技能 → 回收零件 → 整合成一条看图识字教学视频**（从单字单图，到整片，一气呵成）。
- **记忆机制 = 图像 + 象形文字演化，不教笔画。** 每个字靠"图画"和"字是怎么从图来的"帮孩子记（山=三座山峰、林=两棵树、叶=一片叶子）。**不做笔画/笔顺演示——AI 生成笔画视频并不好用**（笔画抖动、顺序易错）。
- 子技能（在 `sub-skills/`）：
  - **单字识字卡生成** —— 生成一张"字 + 对应插图"识字卡（提供**图像锚点**，可复用原子件，也能单独当卡出）。
  - **单字象形演化** —— 给一个字做"图像 → 字形演化 → 楷字"的记忆小节（象形字走实物演化，会意/可联想字走构字图像理据，如 林=两树成林）。
- 交付：默认一条**看图识字教学视频**；若用户只要认读/打印，也可只走 `单字识字卡生成` 出卡图。

## Base 基础信息（所有子技能共享，写一次、全局遵守）

### 选字规范

- 用户**指定字全部采用**；**排除字一律剔除**；只给范围/主题时选**象形直观、笔画适中、儿童高频、适龄**的字（人山水火日月木鸟雨伞瓜叶…）。
- 每页/每片字数与形态匹配，别塞太多。**生成前列出最终字表，Ask User 确认**，避免选错白跑一整条。

### 字形正确（全局红线）

- 出现的**每个汉字必须楷书标准、笔画完整、写对**。AI 直接画汉字易错字——**汉字优先用标准字体渲染**、单字单件生成、**逐字校对**，错字立即重做。

### 记忆机制：图像 + 象形演化（不教笔画）

- 靠**图像**和**字形来源演化**帮记忆，**不做笔画/笔顺**（AI 生成笔画视频不好用）。字形来源（象形物象 / 会意构件）要**真实、不编造**。

### 视觉一致性

- 所有子技能产出**同一套模板**（卡片样式 / 字体 / 配色 / 插图风 / 配音音色 / 节奏），整片是一个系列。

## 输入

- **可选（选字）**：指定字 / 排除字 / 范围·主题·字表、这次教几个字。
- **可选（形态）**：只要卡图还是要教学视频、单字短片还是合集、整片时长、是否配音/跟读/字幕/BGM、画幅、风格、是否同时导出可打印卡。
- 没依据的规格**不臆造**（画幅/分辨率/模型/字数——走稳妥默认）。

## 输入使用

- **严格遵守**：指定字全覆盖、排除字不出现；要视频就**真的整合成一条片**（不是散图）；全片汉字写对且稳定；**用图像+象形演化记忆，不掺笔画/笔顺**。
- **只作参考**：插图/演化画法/配色/讲解措辞——在 Base 红线内自由。

## 路由 / 分配 / 合作方式（父技能核心）

### 路由（什么情况调哪个子技能）

- 用户只要**一张/一套识字卡图**（认读、打印）→ 只调 `单字识字卡生成`。
- 用户要**识字教学视频** → 每个字先调 `单字识字卡生成` 出卡（图像锚点），再调 `单字象形演化` 出记忆小节，最后**本级整合成片**。
- 可扩展：将来不同**卡片风格 / 生成方式**做成并列子技能（类比"风格1号 / 风格2号"），按用户偏好路由。

### 分配（怎么把活分给子技能）

- **逐字分配**：一次给子技能一个字，context 最短、可并行、可断点续跑。
- 把 **Base 信息（选字结果、模板规范、目标字）作为输入**传给子技能，保证各件同规范。

### 合作（子技能之间怎么交接）

- `单字识字卡生成` 产出的卡（**真实 node_key**）**作为图像起点传给** `单字象形演化`，让演化就从这张卡的图像做起。
- 各小节产物**回收到本级**，按字表顺序合成整片。

## 调度流程（主技能一气呵成）

1. **选字**（按 Base 选字规范）→ 列表 Ask User 确认。
2. **逐字调** `单字识字卡生成` → 识字卡 / 图像锚点（校字通过）。
3. **逐字调** `单字象形演化`（把上一步的图像传进去）→ 图像+演化记忆小节（校字形来源真实、楷字稳定）。
4. **本级整合**：片头 →（逐字小节）→ 复习闪回 → 片尾，配 BGM，拼接成片。
5. **整体自检** → 输出成片（+可选导出识字卡图）。

## 输出

- 一条整合好的**看图识字教学视频**（片头→逐字小节→复习→片尾，含配音/字幕/BGM 按需）。
- （可选）各单字**识字卡图**副产物。
- 一份**说明**：本片教了哪些字、各字表现方式、是否配音跟读——便于核对与续做。

## 自检（整体层）

- \[ \] 各子技能产物是否都过 Base 红线（**字写对、字形稳定、图像对应、字源真实、风格统一**）？
- \[ \] 是**图像+象形演化记忆**，**没有**掺笔画/笔顺？
- \[ \] **指定字全覆盖、排除字没出现**？
- \[ \] 要视频的，**真整合成了一条片**，节奏适龄、有复习收尾？
- \[ \] 画幅/分辨率/字数——没依据的没被硬填？

## Ask User（整体决策）

- **只要卡图，还是要教学视频**？单字短片还是合集？
- 教**几个字** / 整片多长 / **画幅**（竖屏/横屏）？
- 要不要**配音 / 跟读留白 / 字幕 / BGM**、配音音色语速？
- 只给范围时：把**代选字表**报用户确认。
- 是否**同时导出可打印识字卡**。
