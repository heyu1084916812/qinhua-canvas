# 次世代白女松弛感VLOG · That Girl Effortless Aesthetic

---

## Skill名称

**次世代白女松弛感VLOG · That Girl Effortless Aesthetic**

---

## 风格介绍

「松弛感」是当下全球社交媒体最具传播力的视觉美学。本Skill复刻的是风靡TikTok/Instagram的\*\*"That Girl" / "Clean Girl Aesthetic" / "Effortless Vlog"\*\*风格——一种看似随意实则精心构建的生活美学影像。

**核心视觉语言**：

- **暖调自然光**：晨光透过亚麻窗帘的柔光、黄金时刻的逆光侧光、室内暖色台灯的微光
- **中性色系**：米白、奶咖、燕麦、亚麻、原木色调主导，低饱和高明度的温柔画面
- **手持呼吸感运镜**：轻微晃动的手持镜头，不完美但真实，模拟手机/vlog相机拍摄感
- **生活碎片叙事**：咖啡拉花、护肤仪式、晨间日记、插花、烘焙、散步、阅读——日常即内容
- **胶片质感**：轻微颗粒、柔焦高光、色彩偏暖偏柔和，似拍立得或复古胶片
- **留白节奏**：慢节奏、长镜头、不急不躁，每个画面都在"呼吸"

**情绪基调**：治愈、从容、自洽、不费力的高级感。不是在展示生活，而是生活本身就是艺术品。

**与现有Skill的区别**：区别于"超写实电影级人像旅拍VLOG"的重工业化电影质感，本Skill追求的是**反精致的精致**——用看似随意的镜头语言，传递一种"我就是这样生活的"从容态度。

## Skill内容

### 一、视觉风格定义

1.1 色彩体系

**主色调（占画面60-70%）**：

- 米白色 #F5F0E8 / 奶油白 #FAF6F0
- 燕麦色 #E8DDD0 / 亚麻色 #D4C5B0
- 原木色 #C4A882 / 暖灰色 #B8AFA6

**点缀色（占画面20-30%）**：

- 干燥玫瑰粉 #D4A5A5
- 鼠尾草绿 #B5C4A8
- 陶土棕 #C4956C
- 淡鹅黄 #E8D5A0

**禁忌色**：

- 高饱和荧光色
- 纯黑纯白（用#1A1715和#FFFCF7替代）
- 冷调蓝绿（除非是清晨窗光的自然冷暖对比）

1.2 光影规则

场景类型光源光质色温晨间室内窗户自然光柔光、漫射4500K-5500K偏暖黄金时刻户外太阳低角度逆光/侧逆光、暖金3200K-4000K夜间室内暖色台灯/蜡烛局部暖光、暗部柔和2700K-3000K阴天户外天空漫射光均匀柔光、低对比6000K-6500K

**光影要点**：

- 高光永远不溢出，保留细节（如白色窗帘的纹理）
- 阴影永远是暖灰色而非死黑
- 画面整体偏亮偏柔，对比度偏低
- 适当加入光晕/眩光效果增强氛围感

1.3 运镜风格

**核心原则**：手持呼吸感 &gt; 稳定器平滑感

运镜类型适用场景描述微晃手持固定静物特写、人物中景模拟手持手机拍摄，轻微呼吸感晃动缓慢推镜头细节展示（咖啡、食物、文字）极慢的zoom in，3-5秒完成侧移跟随人物走动、散步跟随人物侧面移动，不追拍俯拍固定桌面物品、手部动作正上方俯拍，轻微手持晃动低角度仰拍人物全身、环境交代贴近地面或桌面，仰视视角虚焦过渡场景切换前一镜头虚焦→下一镜头从虚到实

**禁忌运镜**：

- 快速摇镜头、甩镜头
- 大幅度运镜、运动相机风格的抖动
- 无人机航拍大远景（除非是散步场景的环境交代）

1.4 画面质感

- **颗粒感**：轻微胶片颗粒（ISO 400-800级别），不可过重
- **柔焦**：高光区域轻微柔化（类似Pro-Mist滤镜效果）
- **锐度**：中等偏低，人物皮肤柔滑但有质感
- **暗角**：极轻微，几乎不可察觉
- **色彩偏移**：整体偏暖偏黄绿（类似Portra 400胶片色调）

### 二、角色设计规范

2.1 主角形象锚定

**默认形象**（可根据用户需求调整）：

- 25-32岁女性
- 淡妆/伪素颜妆容：自然眉、裸色唇、轻微腮红
- 发型：自然微卷中长发/低马尾/随意盘发，有碎发
- 穿着：极简中性色系——白T/亚麻衬衫/针织开衫/运动内衣/宽松长裤
- 配饰：极简——细链项链/小耳钉/帆布袋/编织草帽
- 气质：从容、不刻意、微微带笑但不过分表情管理

**角色一致性锚定规则**：

1. 首帧生成角色三视图（正面/侧面/半身），作为后续镜头的参考锚点
2. 每个新镜头提示词中包含角色锚定描述：`[角色名]，25岁女性，自然微卷棕色中长发，淡妆，穿白色亚麻衬衫`
3. 服装在同一场景内保持一致，场景切换可换装
4. 表情管理：自然放松，不过度微笑，偶尔有低头/侧脸/闭眼享受的瞬间

2.2 场景内角色行为库

场景行为动作情绪厨房/咖啡角手冲咖啡、拉花、搅拌、端杯专注、享受浴室/梳妆台护肤涂抹、扎头发、照镜子从容、自爱书桌/窗边写日记、翻书、看窗外、发呆安静、沉思客厅/沙发窝在沙发、盖毯子、抱猫/抱书慵懒、舒适户外/街道散步、买花、骑自行车、晒太阳轻快、自由厨房切水果、烤面包、摆盘用心、温暖

### 五、音乐与音效设计

5.1 BGM风格匹配

视频段落BGM风格节奏参考风格晨间场景Lo-fi piano / ambient慢速60-80BPMNujabes风、轻柔钢琴散步场景Indie folk / acoustic中速80-100BPM原声吉他+口哨旋律护肤场景Ambient / drone极慢40-60BPM氛围音乐、自然白噪音叠加厨房场景Bossa nova / jazz中速80-100BPM轻爵士、Bossa吉他夜间场景Lo-fi beats / ambient慢速60-80BPM暖色lo-fi、黑胶质感

5.2 环境音效

每个场景叠加以下环境音（低音量、自然感）：

- 室内场景：轻微衣物摩擦声、脚步声、呼吸声
- 厨房场景：水流声、切菜声、杯碟碰撞声
- 户外场景：鸟鸣、风声、树叶沙沙声、远处人声
- 夜间场景：蜡烛噼啪声、虫鸣、远处车声

5.3 音画同步规则

- BGM渐入：视频开始0.5-1秒后渐入，避免突兀
- 环境音铺底：全程低音量持续，增强沉浸感
- 关键动作音效：咖啡倒入、翻书、脚步等动作音效适度放大
- BGM渐出：视频最后2秒缓慢渐弱

### 六、剪辑节奏与转场

6.1 剪辑节奏

**核心原则**：慢节奏、长留白、不急躁

时长版本镜头数单镜头时长节奏15秒版5-6个2-3秒/个轻快但不过快30秒版8-10个2-4秒/个从容舒缓60秒版12-16个3-5秒/个慢节奏呼吸感120秒版20-28个3-6秒/个散文诗节奏

6.2 转场方式

转场类型适用场景描述虚焦过渡场景间切换前一镜头虚焦模糊→下一镜头从模糊到清晰遮挡转场人物经过镜头人物/物体经过镜头遮挡画面→切到下一场景色彩匹配同色调场景间两个画面色调相似，硬切但不突兀慢叠化情绪段落间2-3秒的交叉溶解，缓慢柔和留白黑场段落结束0.5秒纯黑/暗画面，制造呼吸感

**禁忌转场**：

- 旋转、缩放、故障风等特效转场
- 快闪式硬切（每个画面&lt;1秒）
- 动感卡点剪辑（与本风格调性不符）

6.3 字幕/文字规则

如需添加文字（日期、地点、心情短语）：

- 字体：手写体 / 细衬线体 / 极简无衬线体
- 颜色：白色或暖灰色，半透明
- 位置：画面下方1/3处或左下角
- 动画：缓慢淡入淡出，不用弹出/滑动
- 内容：简短——"Tuesday morning"、"slow living"、"a quiet moment"

### 七、完整工作流程

7.1 用户输入处理

1. **接收用户需求**：确认视频时长、主题方向（晨间/护肤/散步/居家等）、是否提供角色参考图
2. **角色锚定**：如有参考图则提取角色特征；如无则使用默认形象或根据用户描述生成
3. **场景选择**：根据主题选择1-6个场景模板组合
4. **分镜规划**：按时长版本生成分镜表

7.2 视频生成流程

```
Step 1: 角色锚定帧生成
  → 生成角色三视图（正面/侧面/半身）
  → 确认角色外观一致性

Step 2: 分镜逐镜头生成
  → 按分镜表顺序，逐个生成视频片段
  → 每个片段使用对应的提示词+角色锚定描述
  → 模型选择：Seedance 2.0（主）/ 可灵3.0（备选）

Step 3: 视频剪辑组装
  → 按分镜顺序拼接视频片段
  → 应用转场效果
  → 调整节奏和时长

Step 4: 音乐音效叠加
  → 选择匹配的BGM风格
  → 叠加环境音效
  → 音画同步调整

Step 5: 色彩统一调色
  → 应用暖色调LUT
  → 统一各镜头色彩一致性
  → 添加胶片颗粒质感

Step 6: 输出成片
  → 确认最终效果
  → 输出视频文件
```

7.3 质量检查清单
