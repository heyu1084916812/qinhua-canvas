# 短剧剧本生成完整视频 — Skill 全流程设计方案

基于你提供的角色设定图和场景设定图 prompt，以下是完整的 Skill 补充内容，覆盖从剧本输入到成片输出的全链路：

---

## 一、Skill 总览

**Skill 名称：** AI短剧工业化全流程一键出片

**Skill 定位：** 将短剧剧本（或网文文本）自动拆解为分镜脚本，并依次生成角色设定图、场景设定图、分镜画面、配音配乐、字幕排版，最终合成为完整视频。

**适用题材：** 甜宠、逆袭、虐恋、霸总、穿越、复仇、悬疑、都市职场等高热度短剧类型。

---

## 二、输入端设计

### 2.1 剧本输入

```
用户输入方式：
1. 直接粘贴短剧剧本文本（含对白、动作描述、场景说明）
2. 粘贴网文/小说原文（自动提取关键情节段落转化为剧本格式）
3. 上传 .txt / .docx / .pdf 剧本文件
```

### 2.2 剧本智能拆分引擎

**功能：** 将原始文本自动拆解为可执行的分镜脚本结构

**拆分逻辑：**

```
原始剧本 → 场景分割（按场景/时间/地点变化）
         → 镜头分割（按动作节拍/情绪转折点）
         → 每个镜头输出：
           · 场景编号（S01, S02...）
           · 镜头编号（S01-C01, S01-C02...）
           · 场景描述（环境、时间、天气、氛围）
           · 角色出场（人物名称、外貌关键词、情绪状态）
           · 动作描述（角色行为、肢体语言）
           · 对白文本（台词原文）
           · 情绪标签（紧张/甜蜜/悲伤/愤怒/平静/震惊...）
           · 镜头建议（特写/中景/全景/俯拍/仰拍/跟拍...）
           · 时长建议（2-8秒/镜头）
```

```

1. 每个角色生成设定图后，提取该图为 Seed 参考锚点
2. 后续所有分镜中该角色的画面均引用该锚点
3. 通过 IP-Adapter / Character LoRA 等技术保持角色面部与体型一致性
4. 输出角色 ID 卡片（含角色图 + 关键属性 JSON）
```

## 八、视频合成与后处理模块

### 8.1 画面组装

```
合成流程：

1. 素材准备：
   · 分镜画面（静态图 or 短视频片段）
   · 角色设定图（用于面部一致性校验）
   · 场景设定图（用于风格一致性校验）

2. 画面动态化处理：
   · 静态图 → 动态化（通过 AnimateDiff / SVD / Kling 生成2-4秒微动效）
   · 关键镜头 → 文生视频（通过 Kling / Runway Gen-3 / Pika 生成完整动态镜头）
   · 运镜效果 → 通过视频后期实现推拉摇移

3. 画面后处理：
   · AI 超分辨率放大（Real-ESRGAN / Topaz Video AI）
   · 色彩统一调色（电影感LUT应用）
   · 画面稳定化处理
   · 帧率插值（24fps → 30fps/60fps 平滑处理）
```

### 8.2 音频混合

```
音频层级：
  Layer 1（最底层）：环境音（持续播放，音量 -18dB）
  Layer 2：BGM（持续播放，音量 -12dB，对白时自动降至 -20dB）
  Layer 3：音效（触发式播放，音量 -6dB）
  Layer 4（最顶层）：角色对白配音（音量 0dB，最优先）

音频后处理：
  · 对白：EQ均衡 + 轻度压缩 + 去齿音
  · BGM：淡入淡出 + 场景切换时平滑过渡
  · 整体：响度标准化（-14 LUFS，适配短视频平台）
```

### 8.3 最终成片输出

```
输出规格：
  · 分辨率：1920x1080（16:9横屏）/ 1080x1920（9:16竖屏短剧）
  · 帧率：30fps
  · 编码：H.264 / H.265
  · 码率：8-15 Mbps
  · 音频：AAC 320kbps 立体声
  · 文件格式：.mp4

分集输出：
  · 自动按剧本分集点切割
  · 每集时长建议：1-3分钟（短剧标准）
  · 每集结尾保留悬念钩子
  · 自动添加集数编号水印
```

## 九、爆款短剧创作策略（内置知识库）

### 9.1 节奏控制

```
短剧黄金节奏公式：

每集结构（90秒-180秒）：
  · 开头5秒：高能钩子（冲突画面/悬念台词/反转预告）
  · 前30秒：快速建立矛盾（不要慢热铺垫）
  · 中间段：矛盾升级 + 情绪递进 + 2-3个反转
  · 最后10秒：强悬念断点（"未完待续" + 最大悬念画面定格）

镜头节奏：
  · 紧张场景：镜头平均时长2-3秒，快切
  · 甜蜜场景：镜头平均时长4-6秒，缓推
  · 反转时刻：前慢后快，用慢动作+正常速度切换制造冲击感
```

### 9.2 情绪曲线设计

```

    - 悬念型："她推开房门，看到的那一幕让她崩溃..."
```

## 十一、质量控制与人工审核节点

```
在自动化流程中设置关键审核节点（可选跳过）：

审核节点 1：剧本拆分结果确认
  · 用户可修改/合并/拆分镜头
  · 调整角色信息
  · 修正情绪标签

审核节点 2：角色设定图确认
  · 检查角色形象是否符合预期
  · 可通过文字微调描述重新生成

审核节点 3：场景设定图确认
  · 检查场景风格是否统一
  · 可替换/调整场景元素

审核节点 4：分镜画面确认
  · 逐镜头预览
  · 可替换不满意的画面
  · 可调整运镜方案

审核节点 5：成片预览
  · 完整播放预览
  · 可微调音量平衡、字幕位置、转场效果
  · 确认后导出最终版本
```
