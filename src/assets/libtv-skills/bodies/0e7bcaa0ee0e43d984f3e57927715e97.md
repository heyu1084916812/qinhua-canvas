# Taffy Seedance 2.0 影视提示词工程

## 一句话介绍

为中文 Seedance 2.0 视频生成项目，把一句话想法变成可直接用于 LibTV/即梦/Runway 的专业视频提示词，并在多镜头序列中保持角色、光影、动作与镜头连续性。

## 做什么

- 将模糊创意或剧本片段转写成高保真、低废片的 Seedance 视频提示词。
- 规划多镜头连续剧情：分场景、分镜头、写续拍契约，确保一次只定稿下一个镜头。
- 提供镜头、灯光、动作、角色、声音、风格、版权安全等分项指导。
- 在续拍/延伸时，从已接受成片的实际结束状态出发，而不是从计划状态出发。
- 自动删除 AI 填充词，把"电影感"换成具体的镜头、光与运动。

## 需要什么输入

至少提供以下一项：

1. 一句话画面想法（例："汉代仕女在云端排队，天光从门缝照进来"）。
2. 一段剧本/分镜描述（含画面、动作、情绪、时长）。
3. 参考图/参考视频/参考音频（需说明每个参考控制什么：身份、氛围、镜头、动作还是节奏）。
4. 已有的已接受成片或末帧（续拍/修复时使用）。

可选补充：目标平台（LibTV/即梦/Runway/火山引擎）、时长、画幅、风格、必须保留的品牌/logo/角色、不能出现的内容。

## 怎么做

按这个顺序处理每个请求：

1. **选模式**：判断是 T2V（文生视频）、I2V（图生视频）、V2V（视频生视频）、R2V（参考生视频）、FLF2V（首尾帧）、Edit（编辑）还是 Extend（续接）。
2. **拆单一意图**：这个镜头要让观众"感受到什么"或"注意到什么"？只保留一个可见节拍。
3. **写镜头契约**：景别 + 角度 + 运动 + 速度 + 终点；避免同一镜头里叠加多种冲突运动。
4. **绑参考角色**：每个参考只负责一个主要角色（身份/氛围/镜头/动作/节奏），写明"@Image1 仅控制...不要复制..."。
5. **加物理光与声音**：光源、方向、色温、氛围；声音只保留必要层次（对白/环境声/音效/音乐/静默）。
6. **执行反套路检查**：删掉 "cinematic/epic/beautiful/dynamic" 等空词，换成具体可见的制作语言。
7. **续拍时读正典**：从已接受成片的末帧状态开始，不要从计划结尾开始；标记已完成节拍和预留未来节拍。

## 产出什么

- 模式声明（T2V/I2V/V2V/R2V/FLF2V/Edit/Extend）。
- 参考角色映射（如有）。
- 最终可直接复制进 LibTV 视频节点的自然语言提示词（中英或中文）。
- 镜头清单与续拍契约（序列项目）。
- 意图回声：一句话"这个镜头存在是为了让观众感受到 X"，在生成前确认。
- 版权/安全说明（如有 IP 或肖像风险）。

## 什么时候问你

- 参考素材用途不明确时（"这张图控制身份还是氛围？"）。
- 涉及受保护 IP、名人、品牌、歌曲或真人肖像时，会先提供安全改写并等你确认授权。
- 续拍/延伸时缺少已接受成片或末帧时，会要求你上传。
- 目标平台功能不确定时，会确认平台后再写参数。
