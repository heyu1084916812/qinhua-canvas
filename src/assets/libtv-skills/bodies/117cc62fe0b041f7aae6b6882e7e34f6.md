# 泛健康科普短视频

## 这个 Skill 做什么

用户提供一段现成材料，Agent 依次完成：理解素材 → 生成口播稿 → 生成分镜脚本 → 生成每个分镜的定帧画面 → 将每张定帧画面生成独立视频片段。

每个阶段完成后，Agent 暂停并展示当前产出，等用户明确确认（或提出修改意见）后，再进入下一阶段。

---

## 启动时用户需要提供

1. 原始材料：粘贴一段文章、资讯、产品文案或其他文字内容
2. 口播稿字数范围：例如「300–500 字」
3. 时长：例如「60 秒」

> 画面与视频风格已固定，无需用户指定。

---

## 硬性约束（贯穿全链路，任何阶段不得违反）

### 口播稿文字约束

- 口播稿第一句必须采用「你知道XXX吗」的句式结构，XXX 根据素材核心内容填写
- 禁止出现以下字眼：「治疗」「疗效」「疗程」「痊愈」及其同义近义表达
- 禁止将产品/成分原理与治疗效果并列描述（即不得出现「原理是 X，因此可以治疗 Y」这类句式结构）
- 如素材原文中含有上述内容，须在改写时主动规避，不得直接引用

### 图片与视频画面约束

- **固定风格**（第三、四阶段严格遵循，不得偏离）：3D皮克斯卡通风格，角色为圆润Q版3D造型，材质柔和有光泽，色彩明亮饱满但不刺眼，暖色调自然光，微观场景用拟人化角色（如氧气宝宝、过敏原毛球），场景质感柔软（毛绒/果冻质感），光影柔和有体积感，整体氛围温暖治愈。
- 禁止：高饱和撞色、强烈光晕特效、过于复杂的背景细节；粒子发光效果允许出现，但须保持柔和克制，不得过于强烈刺眼
- 禁止出现：白大褂、医疗器械、手术场景
- 禁止出现：令人恶心、引发生理不适、恐怖、血腥的视觉内容
- 画幅固定为 9:16 竖版
- 每个分镜的角色和场景由各分镜自己的画面描述决定，不得在各分镜之间强制复用同一角色或场景

## 执行链路

### 第一阶段：理解材料，生成口播稿

1. 阅读用户提供的原始材料，提炼核心信息和传播重点

2. 按照用户指定的字数范围，将材料改写为适合真人口播的短视频文案，**必须严格遵循以下四段式结构**：

   **第一段：引出问题**
   - 用生活化场景或身体感受引发观众共鸣，自然点出健康问题
   - 第一句必须采用「你知道XXX吗」句式，XXX 根据素材核心内容填写
   - 语言贴近日常，让观众产生「说的就是我」的代入感
   - 此段内容将对应后续分镜的**现实世界**开场镜头

   **第二段：解释原理**
   - 用通俗语言和拟人化比喻解释身体内部发生了什么
   - 须为后续**微观世界**分镜提供文案基础（如「免疫细胞像士兵一样……」「过敏原就像入侵的小怪兽……」）
   - 让观众理解问题机制，不得出现禁用词汇

   **第三段：解决问题**
   - 给出具体可执行的应对方法（日常预防措施、规范用药等）
   - 分点清晰，通常采用「两招」「三步」等结构，便于记忆
   - 涉及用药内容时须保留「具体用药请遵医嘱」类提示
   - 此段内容将对应后续分镜的**现实世界**预防措施镜头

   **第四段：回归健康**
   - 正向收尾，总结核心建议，传递轻松健康的情绪
   - 语言温暖有力，如「让每一次呼吸都轻松畅快」
   - 此段内容将对应后续分镜的**现实世界**收尾镜头

   **写作要求：**
   - 四段之间过渡自然，整体口语化、节奏感强，适合连续朗读
   - 严格遵守上方「口播稿文字约束」

3. 将口播稿全文输出为**画布文本节点**，节点标题为「口播稿」
   - 在节点内容中标注四段结构的分段位置，格式如下：
     ```
     【第一段：引出问题】
     你知道……
     
     【第二段：解释原理】
     其实，身体里……
     
     【第三段：解决问题】
     怎么办呢？……
     
     【第四段：回归健康】
     只要……
     ```
   - 在对话中标注口播稿实际字数

4. 本阶段只输出文本节点，不得生成任何图片

5. 暂停，等待用户确认
   - 用户确认后进入第二阶段
   - 用户提出修改意见时，按意见修改后更新画布文本节点内容，再次等待确认

---

### 第二阶段：生成分镜脚本

口播稿确认后，必须询问用户分镜数量。

**情况 1**：用户给出了分镜数量。根据口播稿内容、用户指定的总时长、用户给出的分镜数量生成分镜脚本。

**情况 2**：用户无法给出分镜数量。根据口播稿长度和节奏自然划分，再根据口播稿内容和用户指定的总时长生成分镜脚本。

将完整分镜脚本输出为**画布内置结构化分镜脚本节点**，节点标题为「分镜脚本」。

---

#### 叙事结构：现实世界与微观世界双线交替推进

分镜脚本必须采用**现实世界与微观拟人化世界交替推进**的双线叙事结构，不得连续堆积同一类型场景。

**两条线的定义：**

- **现实世界**：真人Q版3D角色在日常生活场景中的行为，包括症状表现、日常动作、预防措施、状态收尾等，用于建立用户代入感
- **微观世界**：拟人化角色（如氧气宝宝、过敏原毛球、药物分子等）在身体内部场景中的互动，用于可视化解释原理；身体内部场景采用柔软质感（毛绒/果冻/半透明管道质感），拟人化角色为圆润3D造型，色彩与现实世界形成区分但保持整体风格统一

**规划要求：**

生成分镜脚本前，Agent 须先根据口播稿四段结构主动规划场景分配：
- 第一段「引出问题」→ 现实世界开场镜头
- 第二段「解释原理」→ 微观世界镜头（可视化原理）
- 第三段「解决问题」→ 现实世界预防措施镜头
- 第四段「回归健康」→ 现实世界收尾镜头
- 两条线交替出现，通过转场（如白光转场、硬切、推近穿越等）衔接
- 典型节奏参考：现实（开场建立情境）→ 微观（解释原理）→ 现实（症状/行为）→ 微观（机制可视化）→ 现实（收尾/预防）

---

#### 每条分镜必须包含以下内容，丰富度要求参照专业样片标准：

**① 基础信息**
- 镜号：第 N 镜
- 时长/秒：该镜头建议时长，所有分镜时长之和须与用户指定总时长一致
- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 俯拍 / 仰拍
- **场景类型**：现实世界 / 微观世界

**② 定帧画面描述**（用于后续生图，禁止画面中出现文字标注）

包含以下子项：
- 风格：固定为「3D皮克斯卡通风格，圆润Q版3D造型，材质柔和有光泽，色彩明亮饱满，暖色调自然光，光影柔和有体积感」；微观世界额外注明「身体内部场景，毛绒/果冻/半透明管道质感」
- 景别与视角
- 场景与角色描述：具体描述画面内容，角色造型、位置、表情、道具等
- 光影：光源方向、色温、阴影质感
- 氛围：整体情绪基调

现实世界示例：
```
场景类型：现实世界
风格：3D皮克斯卡通风格，圆润Q版3D造型，材质柔和有光泽，暖色调自然光，光影柔和有体积感
景别：中景
视角：平视
场景与角色：Q版女孩站在明亮的卧室里，手捂鼻子，表情痛苦，眼睛微红，背景是温馨的家居环境，窗外阳光柔和
光影：室内暖白光，窗边有柔和自然光，整体温馨明亮
氛围：日常生活感，带有轻微不适情绪
```

微观世界示例：
```
场景类型：微观世界
风格：3D皮克斯卡通风格，圆润Q版3D造型，身体内部场景，半透明管道质感，果冻质感气泡，色调偏蓝紫与暖橙对比
景别：全景
视角：平视略俯
场景与角色：一群圆滚滚的橙色过敏原毛球在半透明的鼻腔管道内漂浮，毛球表面有细小绒毛，背景是柔软的粉色管道壁，管道壁轻微颤动
光影：内部柔和散射光，管道壁有轻微透光感，整体通透
氛围：微观奇妙感，略带紧张
```

**③ 运镜**（须具体描述起止景别和运动方式，不得只写「推镜」等单词）

示例：
- 从全景缓慢推进至近景，镜头沿纵深轴匀速前移，落点在角色面部表情
- 从特写快速拉远至全景，同时镜头轻微上升，展现完整场景
- 白光转场：现实世界推近至特写后画面泛白，切入微观世界全景
- 跟随角色向右横移，保持中景，镜头与角色同步运动

**④ 动态描述**（用于后续生视频，禁止画面中出现花字、字幕）

必须包含完整动作链和情绪变化，包含以下子项：
- 时长
- 运镜（含起止景别和运动方式）
- 机位
- 角色动作链：按时间顺序描述完整动作序列，包括起始姿态→过程动作→结束姿态
- 表情与情绪变化：描述情绪起伏和面部变化
- 场景动态：背景/道具/环境的动态变化
- 光影变化：光影随动作或时间的变化
- 台词：该镜头对应口播稿的原文引用（必须引用原文，不得改写）
- 音效：环境音、动作音效等
- 禁止项：该镜头的特定禁止内容
- 风格约束：3D皮克斯卡通风格，圆润Q版3D造型，材质柔和有光泽

现实世界动态描述示例：

时长：4秒。
运镜：从全景缓慢推进至中景，落点在角色面部表情。
机位：平视，与角色视线齐平。

运镜：从全景推进至近景，镜头跟随过敏原毛球运动方向前移，落点在毛球与管道壁接触处。

- 用户确认后进入第三阶段
- 用户提出修改意见时，按意见修改后更新分镜脚本节点内容，再次等待确认

### 第三阶段：生成定帧画面

分镜脚本确认后，**在开始生图之前，必须先询问用户本次要使用的图片生成模型**，等用户明确回复后再开始生成。不得使用系统默认模型，不得假设沿用上一次的模型选择，每次进入本阶段都必须重新询问确认。

按照已确认的分镜脚本和用户指定的图片模型，逐镜生成定帧画面：

- 画幅：9:16 竖版
- **固定风格**：3D皮克斯卡通风格，角色为圆润Q版3D造型，材质柔和有光泽，色彩明亮饱满但不刺眼，暖色调自然光，场景质感柔软（毛绒/果冻质感），光影柔和有体积感，整体氛围温暖治愈。不得使用其他风格。
- 微观世界镜头额外遵循：身体内部场景采用毛绒/果冻/半透明管道质感，色彩与现实世界形成区分但保持整体风格统一
- 每个分镜的角色和场景完全由该分镜自己的「定帧画面描述」决定，不得跨分镜复用角色或场景
- 每张画面生成后，输出为独立的**画布图片节点**，节点标题标注对应的分镜编号（如「第 1 镜」）
- 严格遵守上方「图片与视频画面约束」

所有分镜画面生成完毕后，在对话中整体列出各分镜编号及对应节点，供用户核查。

暂停，等待用户确认：
- 用户确认后进入第四阶段
- 用户对某张画面提出修改意见时，只重新生成该镜头的画面并更新对应图片节点，其余节点不变，修改完成后再次等待确认

---

### 第四阶段：定帧画面生视频片段

定帧画面确认后，**在开始生成视频之前，必须先询问用户本次要使用的视频生成模型**，等用户明确回复后再开始生成。不得使用系统默认模型，不得假设沿用上一次的模型选择，每次进入本阶段都必须重新询问确认。

**视频生成前的分镜合并预处理：**

视频生成最小时长为 4 秒。在开始生成前，先检查每个分镜的时长建议：
- 若某个分镜的时长建议不足 4 秒，则将其与相邻分镜合并，共用一段视频生成
- 合并优先与后一个分镜合并；若已是最后一镜，则与前一个分镜合并
- 合并后的视频时长 = 各被合并分镜时长之和
- 合并后对应的画布视频节点标题标注「第 N–M 镜」（如「第 3–4 镜」）
- 合并处理完成后，在对话中列出最终的生成计划（哪些镜单独生成、哪些镜合并生成），等用户确认后再开始生成

按照已确认的定帧画面、合并计划和用户指定的视频模型，逐段生成视频片段：

- 单独生成的分镜：每个分镜独立生成一段视频
- 合并生成的分镜：将对应的多张定帧画面合并为一段视频生成
- 画幅：9:16 竖版
- **固定风格**：3D皮克斯卡通风格，圆润Q版3D造型，材质柔和有光泽，色彩明亮饱满，暖色调自然光，整体氛围温暖治愈。不得使用其他风格。
- 视频时长参考分镜脚本中该镜头（或合并后各镜头之和）的时长建议
- 严格遵守上方「图片与视频画面约束」
- 每段视频生成后，输出为独立的**画布视频节点**，节点标题标注对应的分镜编号（单镜如「第 1 镜」，合并镜如「第 3–4 镜」）

所有视频片段生成完毕后，在对话中按分镜顺序列出全部视频节点，告知用户所有片段已就绪。

全链路完成。

## 异常处理

- 若素材内容过于简短（少于 100 字），提示用户补充更多背景信息，不强行生成
- 若素材中含有大量违禁词汇，在生成口播稿前先告知用户哪些内容将被规避，再继续生成
- 若某个分镜的画面描述在生图时存在违反约束的风险，在生成前主动提示并建议修改画面描述，不直接生成违规内容
