## 做什么

把用户的一句话故事想法，做成一条完整的暗黑悬疑风格AI漫剧成片（60-180秒）。覆盖剧本→分镜→画面→配音→剪辑全链路，每个环节都有可执行的具体模板和质检标准。

## 需要什么输入

- 必需：一句话故事想法（例："一个男人搬进新公寓，发现墙上有人用指甲刻了倒计时"）
- 可选：画风偏好（暗黑写实/水墨国风/赛博朋克/中式恐怖）、时长（60秒/90秒/180秒）、主角性别年龄、特定恐怖元素偏好（心理恐怖/超自然/血腥/悬疑推理）

## 怎么做

### 第一步：剧本生成（核心环节，决定成片质量上限）

1.1 结构模板（四段式暗黑悬疑结构）

- **钩子段（0-15%时长）**：第一句话/第一个画面必须制造"不对劲"感。不是慢慢铺垫，而是直接把反常甩到脸上。例：开门发现客厅家具全被转了180度，电视开着雪花屏，遥控器被放在鱼缸里。
- **递进段（15-50%时长）**：每30秒必须出现一个新的"不对劲"信号，且信号强度递增。信号类型：视觉异常（影子方向不对/镜子里多一个人）、听觉异常（墙后有声响/电话那头是自己的声音）、逻辑异常（日历日期不对/照片里多了一个人）。
- **反转段（50-85%时长）**：所有"不对劲"信号指向同一个真相，但这个真相必须颠覆观众此前所有假设。反转不是"原来有鬼"，而是"原来主角才是那个鬼/凶手/已死之人"。
- **余韵段（85-100%时长）**：反转后留一个未解的尾巴。例：主角接受了自己已死的事实，但镜头最后拉远，墙上又出现了新的指甲刻痕——而这次，是主角自己刻的。

1.2 对话规则

- 对话占比≥45%，每句对话必须满足以下之一：推进信息量/制造新疑点/暴露角色隐藏动机/制造情绪转折
- 禁止功能性废话（"你还好吗""我没事""这怎么回事"连续出现超过2轮）
- 角色说话要有辨识度：给每个角色一个语言标记（结巴/爱用反问/说话从不说完/总是回答问题但不主动提问）
- 关键反转前的对话要做"信息埋雷"：观众第一次看觉得是闲聊，反转后才发现句句都在暗示

1.3 去AI味规则（强制执行）

- 禁止词汇表：仿佛、宛如、不禁、微微、缓缓、淡淡、轻轻、似乎、隐约、莫名、竟然、居然、不由得、一丝、一缕、一抹、涌上心头、嘴角上扬、眉头微蹙、目光深邃、声音沙哑（可描述但不用这个词本身）
- 五感描写占比≥30%：每个场景至少覆盖2种感官（视觉+听觉为最低配置，触觉/嗅觉/味觉择一加入）
- 五感写法：不写"他感到恐惧"，写"后颈的汗毛竖起来，空调出风口的冷气贴着头皮滑过去，像有人用指甲背蹭过"
- 动作要具体到身体部位和物体交互：不写"她紧张地站起来"，写"她撑着桌沿站起来，指甲在桌面上刮出一道白印"

### 第二步：分镜规划

2.1 分镜数量与时长分配

- 60秒成片：4-6个分镜，每镜8-15秒
- 90秒成片：5-8个分镜，每镜10-18秒
- 180秒成片：8-14个分镜，每镜12-20秒

2.2 景别递进规则（暗黑悬疑专用）

- 第1镜必须是特写或大特写（制造未知的压迫感，让观众不知道自己在哪）
- 钩子段：特写为主（手部动作/物体细节/面部局部）
- 递进段：近景+中景交替（开始建立空间感，但视角受限）
- 反转段：全景或大远景（真相揭示时刻，空间突然打开，与前面的逼仄形成反差）
- 余韵段：回到特写（收束回未知的压迫感）

2.3 运镜规则

- 慢推（dolly in）：用于角色发现异常时，推近速度要慢到让人不安
- 固定机位+主体移动：角色在固定画面中移动，制造"被监视"感
- 手持微晃：用于紧张/恐惧情绪段，晃动幅度要小（不是抖动，是呼吸感的微晃）
- 禁止使用：快速摇移、炫技转场、360度环绕（破坏悬疑氛围）
- 转场方式：硬切为主（80%），闪白（10%，用于记忆闪回/惊吓瞬间），黑屏过渡（10%，用于时间跳跃）

2.4 每镜信息卡格式

```
【分镜X】
- 景别：[特写/近景/中景/全景/大远景]
- 运镜：[固定/慢推/慢拉/手持微晃]
- 画面描述：[主体 + 动作 + 环境 + 关键道具]
- 光影：[光源方向 + 光质 + 阴影描述]
- 色调：[冷青/暗红/灰蓝/深褐]
- 音效方向：[环境音 + 突发音效 + 音乐情绪]
- 时长：[X秒]
- 转场：[硬切/闪白/黑屏]
- 情绪标签：[不安/恐惧/疑惑/震惊/绝望]
```

### 第三步：画面生成

3.1 角色一致性锁定流程

1. 先用平台图片生成能力生成角色定妆照（正面/侧面/背面三视图）
2. 定妆照prompt模板：`[角色描述]，正面半身照，自然光，中性表情，纯灰背景，写实风格，高细节` → 再生成侧面和背面
3. 后续每个分镜的画面生成都引用定妆照作为角色参考
4. 角色描述模板：`[性别]，[年龄]岁，[发型发色]，[瞳色]，[肤色]，[体型]，[标志性服饰]，[标志性特征如疤/痣/纹身]`

3.2 画面生成prompt结构模板

```
[主体描述+动作] + [环境场景描述] + [光源：方向+光质] + [色调：冷青/暗红/灰蓝] + [氛围：低饱和度高对比度] + [运镜方向] + [景别] + [画面风格：电影质感写实/水墨国风/赛博朋克] + [角色一致性约束：引用定妆照外观]
```

3.3 暗黑悬疑视觉规则

- 色温偏冷（3000-4000K区间），反转段可切暖色（2700K）制造不适感
- 阴影占比≥40%：画面中至少40%区域处于暗部，但暗部不能全黑（要有环境光填充，让观众隐约看到暗处的东西）
- 高光要硬：不要柔和的漫射光，用直射光源制造硬边阴影
- 道具暗示：每个场景至少放一个"不对劲"的道具（时钟停在3:17/镜子里反射的角落有东西/窗帘后面有轮廓）
- 禁止：过曝、柔光美颜、日系小清新滤镜、过度饱和

3.4 中式恐怖变体规则（当用户选水墨国风时激活）

- 色调：水墨灰黑为主，点缀朱砂红（用于血液/符咒/灯笼）
- 建筑严格按传统形制：飞檐翘角、榫卯结构、夯土墙，禁止现代元素混入
- 人物服饰：汉服/民国装/寿衣，按朝代设定，禁止混搭
- 禁止：迪士尼风格、日漫风格、赛博朋克元素

### 第四步：配音与音效

4.1 角色配音

- 男主角：低沉、语速偏慢、句尾下沉（选平台低音色男声）
- 女主角/关键女性角色：气声偏多、语速不均（紧张时加快，发现异常时突然停顿）
- 旁白（如有）：冷漠、不带感情、像在读验尸报告
- 对话节奏：关键信息前留0.5-1秒停顿，反转台词前留1.5-2秒停顿

4.2 音效分层

- 底层（持续）：低频嗡鸣（40-80Hz），全程铺设，制造"有什么不对"的潜意识不安
- 中层（间歇）：环境音（滴水/钟表/风声/电流声），每15-20秒切换一次音源
- 顶层（突发）：jump scare节点用高频尖锐音效（金属刮擦/玻璃碎裂/突然的心跳声），但每次只持续0.3-0.5秒，点到为止
- 反转时刻：所有音效突然静默1-2秒，再从静默中渐入反转后的新音效

4.3 背景音乐

- 钩子段：单音符持续低音，不变化
- 递进段：加入不和谐音程（三全音/小二度），节奏逐渐加快
- 反转段：突然切换为大调旋律（制造"真相大白"的虚假安全感）或完全静默
- 余韵段：回到单音符低音，但这次音调比开头高半音（潜意识不安感加剧）

### 第五步：剪辑合成

5.1 剪辑节奏

- 钩子段：快剪（每镜3-5秒），制造信息过载的不安
- 递进段：渐慢（每镜8-15秒），让观众有时间注意到细节
- 反转段：最慢（每镜15-20秒），给观众时间消化真相
- 余韵段：一个长镜头（8-12秒固定机位），让不安感沉淀

5.2 字幕规则

- 简体中文，白色无衬线字体，底部居中
- 字号适中，不遮挡画面关键区域
- 对话字幕：说话人切换时换行
- 关键悬疑线索字幕可加微妙效果：轻微抖动/颜色从白渐变为浅红（仅限反转段）
- 片头：2秒黑屏 + 标题文字（白色，居中，无动画）
- 片尾：3秒黑屏，无文字

5.3 质量自检清单

- \[ \] 第一镜是特写，制造未知压迫感
- \[ \] 前5秒有明确的"不对劲"信号
- \[ \] 对话占比≥45%，无功能性废话连续超2轮
- \[ \] 每30秒出现新异常信号，强度递增
- \[ \] 反转颠覆观众假设，不是"原来有鬼"这种偷懒反转
- \[ \] 余韵段留有未解尾巴
- \[ \] 暗部占比≥40%，高光为硬光
- \[ \] 音效三层分层完整（底层低频+中层环境+顶层突发）
- \[ \] 反转时刻有1-2秒静默
- \[ \] AI禁用词0命中
- \[ \] 五感描写≥30%
- \[ \] 角色外观全片一致
- \[ \] 字幕不遮挡画面关键区域
- \[ \] 总时长在目标时长±10%范围内

## 产出什么

1. 完整暗黑悬疑短剧本（含场景描述、对话、音效标注、情绪标签）
2. 分镜脚本（每镜含景别/运镜/画面/光影/色调/音效/时长/转场/情绪标签的信息卡）
3. 角色定妆照三视图（正面/侧面/背面）
4. 各分镜画面生成prompt完整记录
5. AI漫剧成片（60-180秒，含字幕和配音）
6. 质量自检报告（逐项打勾确认）

## 什么时候问你

- 拿不准故事题材方向时（恐怖/悬疑/惊悚/心理）问一次
- 用户未指定画风时，默认暗黑写实，但可询问是否要水墨国风或赛博朋克变体
- 剧本涉及过度血腥/暴力内容时，询问是否调整尺度
- 用户未指定时长时，默认90秒，但可询问偏好
- 角色定妆照生成后，询问用户是否满意外观再继续后续分镜
- 其余环节自主决定，不需要反复确认
