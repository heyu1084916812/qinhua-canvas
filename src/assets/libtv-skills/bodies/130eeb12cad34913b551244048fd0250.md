# 产品宣传图生成器

## 这个 Skill 是做什么的

接收用户对产品或画面的描述，自动生成一张或多张适合商业宣传使用的图片。支持自然语言输入（如"一瓶高端护肤品，背景是极简白色，光感强"）和结构化输入（如产品名、核心卖点、风格偏好、尺寸要求），Agent 自动识别输入类型并生成图片。

## 什么时候该用它

- 需要快速产出产品宣传图、电商主图、社媒配图等商业用途图片时
- 有画面想法但不会写 prompt 时
- 需要批量生成多张风格不同的宣传图进行对比选择时

## 什么时候不该用它

- 需要对已有图片进行修改或局部编辑时（这是图生图场景，不是本 Skill 的范围）
- 需要包含真实人物肖像或特定品牌 logo 时

## 用户输入

支持两种方式，Agent 自动判断：

**方式一：自然语言描述**直接描述想要的画面，例如：

- "一款黑色运动耳机，悬浮在深蓝色背景中，科技感强，打光从左侧来"
- "有机燕麦奶，田园风，暖色调，适合小红书"

**方式二：结构化信息**提供产品相关的结构化字段，例如：

- 产品名称：xxx
- 核心卖点：xxx
- 目标受众：xxx
- 风格偏好：xxx（可选）
- 图片尺寸/比例：xxx（可选，默认 1:1）

## Agent 的工作流程

1. **识别输入类型**：判断用户输入是自然语言描述还是结构化信息
2. **理解画面意图**：提取产品特征、氛围、风格、构图等关键要素
3. **生成图片**：调用图像生成模型，按用户描述生成图片
   - 默认生成 1 张；用户明确要求多张时，按要求数量生成
   - 风格完全跟随用户描述，不预设固定画风
4. **输出结果**：直接展示生成的图片，附上简短说明（使用了哪些关键描述要素）

## 输出

- 一张或多张商业宣传图
- 简短的生成说明（方便用户调整描述后重新生成）
