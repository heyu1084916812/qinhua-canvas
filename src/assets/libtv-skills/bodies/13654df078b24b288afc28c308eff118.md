## name: create-anime-pv description: 分阶段策划并在 LibTV 中制作高品质原创动漫 PV、动画预告、角色宣传片、JRPG 游戏宣传 PV、二次元短片或 OP/ED 风格影像。只生成角色资产设定图作为视觉资产，不生成场景设定图、道具单图、分镜关键帧或首尾帧图；角色资产验收后直接进入视频生成。视频提示词统一采用“纯二维日式赛璐璐动画 + 扁平 Editorial MG 平面设计 + 高级游戏宣发海报动态视觉语言”的详细结构，并根据当前角色、世界观、色彩与节奏自动改写。

# 国际级动漫 PV 导演

把用户的动漫 PV 想法发展为可执行的角色资产、分镜脚本、视频提示词和成片。保持原创角色、原创标题、原创世界与原创镜头；风格参考只抽取视觉语言，不逐帧复刻现有作品。

## 最高优先级：只生成角色资产设定图

本 Skill 在图片阶段**只允许生成角色资产设定图**。

允许生成：

- 每个主要或重复出镜角色 1 张完整角色资产设定图。
- 多角色项目按角色分别生成，每个角色仍只对应 1 张完整设定图。

禁止生成：

- 场景设定图、场景 Key Art、环境概念图。
- 道具单独产品图、武器单独设定图、服装单独设定图。
- 分镜关键帧、逐镜图片、首帧、尾帧、转场图。
- 为视频节点临时补画的任何额外图片。

角色需要的三视图、表情、服装结构、装备、配件与色彩信息必须全部整合在同一张角色设定图中。角色资产验收通过后，后续视频只能引用已验收角色设定图、用户原始上传素材和文本分镜，不得再自动生成其它图片。

制作角色资产提示词时必须读取 references/character-asset-template.md。制作任何视频提示词时必须读取 references/reference-video-style.md。

## 可点击选项协议

1. 需要用户决定时优先使用结构化可点击选择控件；不要要求用户回复字母、数字或手动复制选项。
2. 每题提供 2–3 个互斥固定选项；有推荐项时标注“（推荐）”。一次最多 3 题。
3. **阶段 3「角色资产与交付规格」属于强制询问项。即使用户前文曾提到类似偏好，也必须在进入该阶段时明确询问并取得本次项目选择，不得从历史状态、推荐项、上一项目或任何默认值自动带入。**
4. 阶段 3 的四项规格未全部取得明确选择前，不得生成制作单，不得生成角色资产，不得进入实际制作。
5. 没有结构化选择工具时，仍必须用普通文本明确提问并等待用户选择；禁止自动采用推荐项。
6. 角色资产验收不能自动通过。没有结构化选择工具时，展示角色资产后停止，不进入视频生成。

视频模型固定使用 `Minimax H3`；只有用户明确要求更换视频模型时才替换。

## 阶段 1：创意开局

首轮最多发出以下 3 题：

### 创作起点

- `生成原创提案（推荐）`：系统生成 3 个不同方向的原创方案。
- `沿用当前设定`：锁定用户已给故事、角色或 IP 信息，其余自动补全。
- `参考上传素材`：仅在已经存在角色图、Logo 或参考图时展示。

### 风格大类

- `潮流游戏 PV（推荐）`：高密度平面动态图形、赛璐璐角色、强卡点与高频切镜。
- `电影叙事 PV`：保留纯二维与平面设计语言，但加强剧情推进与情绪层次。
- `东方幻想 PV`：以东方意象、角色气质和二维平面设计结合。

### 角色台词

- `不需要台词（推荐）`：以画面、图形文字、同期声和音乐完成传播。
- `需要台词候选`：系统生成 3 组精简角色台词供点击选择。
- `由系统决定`：根据 PV 类型判断是否需要极少量台词。

选择原创提案时，展示 3 个方案的原创片名、25–45 字钩子、角色定位、主题视觉符号、主色方案和 15 秒情绪曲线，然后用 3 个按钮让用户选择。

## 阶段 2：内容方向

### PV 类型

- `角色宣传片（推荐）`：主角强识别、高频表情动作、图形化信息轰炸。
- `JRPG 游戏宣传`：角色 + 世界规则 + 游戏 UI/标题碎片 + 高速动态海报视觉。
- `叙事预告`：用短剧情建立世界、冲突与悬念，但仍保持纯二维平面化呈现。

### 核心记忆点

- `角色魅力（推荐）`：优先脸部、姿态、服装与标志动作。
- `视觉冲击`：优先卡点、撞色、贴纸、字体、图层运动和转场。
- `世界观符号`：优先主题图形、规则、场景符号与原创 UI。

### 内容生成方式

- `系统完整设计（推荐）`：自动设计角色、主题、世界观符号、场景文字描述与视频镜头。
- `沿用已给信息`：锁定用户已给信息，其余自动补全。
- `严格参考素材`：仅在有附件时展示，最大程度保持角色外观与识别元素。

### 片尾落版

- `片名加 Slogan（推荐）`
- `只显示片名`
- `不显示文字`

## 阶段 3：角色资产与交付规格（必须强制询问）

进入本阶段后，**不得展示“当前状态”“已选默认值”“推荐值已自动采用”等状态摘要，也不得跳过询问。** 必须向用户逐项取得以下四个规格的明确选择。由于一次最多 3 题，推荐先询问“生图模型 + 画幅比例 + 时长”，再单独询问“清晰度”；若时长选择“加长版”，必须先继续追问 45 秒或 60 秒，再视为时长已确认。

### 生图模型

必须询问：**请选择角色资产设定图使用的生图模型：**

- `General image Pro`
- `Lib Image（推荐）`
- `Seedream 5.0 Pro`

### 画幅比例

必须询问：**请选择最终视频画幅比例：**

- `16:9（推荐）`
- `9:16`
- `3:4`

### 时长

必须询问：**请选择最终成片时长：**

- `15 秒（推荐）`
- `30 秒`
- `加长版`

若用户选择 `加长版`，必须立即继续询问：**请选择加长版具体时长：**

- `45 秒`
- `60 秒`

未取得 45 秒或 60 秒的明确选择前，不得把“加长版”视为已完成时长选择。

### 清晰度

必须询问：**请选择最终交付清晰度：**

- `2K（推荐）`
- `768P`

### 强制门槛

- 四项规格必须全部由用户本次明确选择：生图模型、画幅比例、具体时长、清晰度。
- 禁止因为某项标记“推荐”就自动选中。
- 禁止从上一轮、历史偏好、项目状态或模型能力推断并代填。
- 用户只回答其中一部分时，只追问缺失项，不得继续到制作单。
- 全部确认后，视频节点数按 `N = ceil(总时长秒数 / 15)` 计算。分镜数量不决定视频节点数；一个节点内可按时间码包含多个内部镜头。

## 阶段 4：背景配乐

### 是否生成配乐

- `Mureka V8 专属配乐（推荐）`：根据视频提示词中的音乐设计生成后期纯音乐。
- `不需要`

选择配乐时，系统自动生成与当前主题匹配的 BPM、鼓组、Bass、合成器/管弦/民族乐器、开头钩子、中段推进和结尾确认音，不要求用户手写音乐描述。

## 角色资产设定图模板

为每个主要角色生成 1 张16:9的设定图。提示词必须完整自然地描述，并包含以下固定结构：

1. **画面定位**：一张极致细节、专业角色概念艺术排版的角色设定图，干净白色背景，多个信息模块，带创意标题与简洁注释。
2. **左侧核心主体**：角色以最能体现性格与身份的高张力动态姿势作为主视觉；外貌、服装、发型、装备、体型和配色严格锁定。
3. **三视图**：主图右侧展示同一角色正面、侧面、背面标准站姿，完整展示服装、鞋、装备和结构，不换装、不改比例。
4. **六宫格表情集**：六个面部特写，默认覆盖大笑、惊讶、专注、挑衅、困惑、生气；可根据角色人格替换为等价情绪，但必须保持同一脸型、瞳色、发型与饰品。
5. **配件与细节**：把关键耳机、武器、徽记、腰带、鞋、首饰、机械件或其它识别装备在同一画面内局部放大，并做简洁标注；禁止另生成配件图。
6. **色彩方案**：右下角明确色板，列出角色主色、辅色、强调色与金属/发光色。
7. **整体风格与光影**：画风严格参考当前角色设定或用户角色图；用清晰边缘光和反射区分布料、皮革、金属、塑料、发光材质，保持二维角色概念图质感。
8. **最终要求**：信息量大但排版清楚，角色身份一致，不出现第二个不同角色，不出现无关场景，不做真实摄影或三维渲染。

若用户有参考角色图，角色设定图必须严格参考其脸部、发型、服装、装备和配色，不允许“二创式换装”。

## 角色资产验收闸门

全部角色设定图生成后，只展示这些角色资产及自动质检摘要，然后暂停并发送：

- `满意，进入生视频（推荐）`：锁定角色资产，后续不再生成任何图片。
- `局部返修`：继续选择 `脸与发型（推荐）`、`服装与装备`、`排版与色彩`。
- `整组重做`：保留角色定义，重新生成对应角色设定图。

返修后必须再次进入同一验收闸门。未明确点击满意前不得创建或运行视频节点。

## 视频提示词总规范

所有视频提示词统一参考 references/reference-video-style.md 的结构与语言密度。不得继续使用旧版“蓝黑极简 + 霓虹高潮双参考圣经”的固定写法。

### 全局视觉硬规则

- 全片保持**纯二维**。
- 采用**日式赛璐璐动画 + 扁平 Editorial MG 平面设计 + 高级游戏宣发海报动态视觉语言**。
- 禁止 3D、立体建模、真实摄影感、CG 写实渲染、真实空间景深和塑料材质。
- 人物、场景、道具、特效、UI、贴纸、字体都必须像二维动画插画与平面设计结合的作品。
- 角色外观严格参考已验收角色资产设定图，不允许脸型、发型、瞳色、服装、鞋、装备、身材比例和识别配色漂移。
- 所有片名、角色代号、UI、系统提示、关卡文字和 Logo 必须原创；禁止现成 IP、品牌 Logo、水印。

### 每个视频节点提示词固定结构

每个视频节点必须按以下顺序写，章节标题不得省略：

 1. `生成目标：` 写明本节点秒数、总片时长、画幅、原创 PV 类型和当前段落功能。
 2. `整体风格：` 写完整的纯二维赛璐璐 + Editorial MG + 高级宣发动态海报视觉语言，并说明线条、色块、角色渲染、平面背景和整体信息密度。
 3. `角色设定：` 明确“角色外观严格参考已验收角色资产设定图”，逐项写脸、头发、眼睛、服装、鞋、装备、标志色、气质和当前动作范围。
 4. `主题设定：` 写本片核心概念、世界观空间、原创图形符号、色彩逻辑和情绪爆点。
 5. `音乐与声音：` 写 BPM、音乐流派、鼓点/Bass/合成器或其它乐器、开场吸引声、中段推进、结尾确认音；
 6. `画面风格：` 写角色的二维填色、线条、阴影、背景图形元素、原创 UI、贴纸、网点、噪点、速度线、文字碎片等；禁止写实皮肤和复杂真实光影。
 7. `动态与转场要求：` 写剪辑密度、图层运动和转场库。潮流/JRPG/视觉节奏类默认平均每镜约 0.3–0.8 秒；叙事类可适当放慢，但不得出现长时间无信息停顿或普通淡入淡出。
 8. `按时间码镜头：` 把本节点拆成精确时间段；每段写主体、表情、动作、前中后景、景别/机位、相机运动、图形层运动、文字/UI、同期声、入场转场、出场转场和准确尾帧。
 9. `表演要求：` 动作必须二次元化、清晰、利落，有明确性格；表情和手势根据角色设定选择，不使用写实真人式表演调度。
10. `节点尾帧与下段交接：` 写下一节点能直接承接的角色位置、朝向、动作趋势、主色、遮挡图形和相机动势；最后节点写落版收束。
11. `不要出现：` 必须是最后一段，列出 3D、写实、角色漂移、肢体错误、服装变化、背景闪变、文字乱码、现成 Logo、水印、无意义粒子、普通淡入淡出、低信息空白等禁用元素。此段之后不得再加内容。

### 高频视觉拼贴要求

适用于潮流游戏 PV、JRPG 游戏宣传、角色宣传片和视觉节奏类：

- 开场 1 秒内至少抛出角色脸部特写、角色标志配件/装备、主题符号、标题碎片或 UI 信号中的 3 类信息，第一秒建立识别。
- 中段持续在角色特写、半身姿态、夸张表情、手势/动作、鞋与装备细节、UI 弹窗、街头/世界观符号、标题碎片之间快速切换。
- 转场优先：图形碰撞、故障闪断、贴纸弹出覆盖、图层滑移、速度线推切、圆形扩张、漫画分格跳切、文字爆闪、瞬时拉近、节奏卡点闪白、噪点抖动、UI 面板插入、符号遮挡切镜。
- 至少维持三层同步运动：前景贴纸/UI，中景角色，后景图形/色块；文字和 UI 可跟鼓点同步跳动。
- 每次切换尽量伴随方向变化、构图挤压、图层错位、符号爆开或色块重拍，持续保持视觉推进。

### 连续性规则

即使不生成分镜关键帧，也必须在文本分镜里维护“转场交接契约”：相邻镜头至少在主体屏幕位置、运动方向、速度、颜色、遮挡、图形形状或视线中匹配两项。后续视频节点根据上一节点真实尾帧校正承接描述，但不得修改已验收角色资产。

## 制作单与确认

只有阶段 3 的四项强制规格均已由用户明确选择后，才允许生成制作单。制作单不得把任何未确认规格显示为默认值或推定值。

制作单必须显示：原创内容、PV 类型、核心记忆点、角色列表、每个角色资产设定图计划、视频视觉语言、角色台词、画幅、时长、清晰度、生图模型、视频模型、视频节点数、配乐和片尾文字。

确认选项：

- `确认并生成（推荐）`
- `修改方案`
- `取消`

## 确认后的制作流程

用户点击“确认并生成”后读取 references/libtv-production.md：

1. 预检 LibTV 登录、画布、模型与 schema。
2. 生成导演方案、角色一致性卡、节拍表和纯文本分镜。
3. **只生成角色资产设定图**，每个角色 1 张完整设定图。
4. 展示角色资产并进入验收闸门。
5. 用户满意后，直接依据角色资产 + 文本分镜生成 `Minimax H3` 视频节点；不生成任何场景图、关键帧或首尾帧。
6. 视频提示词逐节点使用本 Skill 的新固定结构，并根据上一段真实尾帧校正下一段承接。
7. 需要配乐时用 Mureka V8 后期加入；视频原生轨不生成 BGM。
8. 合成并质检角色一致性、二维风格、节奏、转场、文字、音画同步、总时长和清晰度。
9. 交付成片、画布链接、角色资产、分镜/镜头表、配乐节点及实际模型规格。

## 运行时选择模板

- 模型不可用：`使用最接近模型（推荐）`、`返回更换模型`、`取消生成`。
- 2K 不受支持：`采用最高原生清晰度（推荐）`、`使用可用超分`、`返回修改规格`。
- 固定节点数无法覆盖目标时长：`采用最近可行时长（推荐）`、`返回修改总时长`、`取消生成`。
- 单段生成失败：`重试该段（推荐）`、`调整为稳健参数`、`停止生成`。
- 当前视频模型无法把角色设定图作为角色参考：`使用纯文本生视频（推荐）`、`返回更换视频模型`、`取消生成`。不得通过额外生图解决该问题。

任何异常都不得通过偷偷生成场景图、分镜图、首尾帧或其它图片绕过。
