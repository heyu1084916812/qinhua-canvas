# 打火机极简科技广告风格创作流程

## 使用说明

本 Skill 基于已验证的打火机极简科技广告创作画布沉淀而来。\
**输入**：一张产品参考图（打火机或其他极简科技产品）\
**产出**：完整的苹果式极简科技广告视觉分析框架 + 10 组图片提示词 + 3 段视频提示词

---

## 一、苹果式极简科技广告视觉分析框架

### 1. 色调

层级取值主背景接近白色的浅灰紫、淡粉白、冷调米白主色黑色文字、深紫色功能强调文字、浅粉机身、银白边框、黑色机身点缀色柔紫色光效、粉紫渐变、淡蓝玻璃反光

### 2. 质感

- **机身**：磨砂陶瓷感、阳极氧化铝边框、细腻金属倒角
- **顶部结构**：高反射金属拨轮，带精密细节
- **文案背景**：干净、平滑、无纹理或极轻微纸感
- **产品光影**：大面积柔光，边缘高光清晰，阴影非常轻

### 3. 构图

- 中心构图为主，产品或文字居中
- 留白极多，突出高级感
- 产品镜头常使用斜向透视、悬浮、叠放、局部切割
- 功能演示画面会出现气流线条、功能标注等辅助信息

### 4. 景别与氛围

- **氛围**：高级、轻盈、干净、安静
- **科技感来源**：材料质感、光效、排版和运动，而非复杂背景
- **广告片节奏**：品牌文字 → 产品外观 → 材质功能 → 功能演示 → 细节微距 → 多款展示 → 结束口号

## 三、3 段视频提示词（每段约 10 秒）

> 适用工具：可灵 / Runway / Pika / 即梦等\
> 建议比例：16:9\
> 整体风格：`minimal tech commercial, smooth camera motion, soft lavender white background, premium product cinematography`

---

### 第一段｜品牌开场 + 产品外观（0–10s）

**节奏**：品牌文字淡入 → 产品从中央缓慢浮现 → 镜头缓推近

**提示词**：

```
浅紫白纯净背景，开场0.5秒黑色品牌标题文字从透明缓慢淡入居中，紫色数字轻微发光，随后文字淡出，一款磨砂白陶瓷质感打火机从画面中央缓慢向上浮现，机身边缘高光逐渐清晰，镜头以极缓慢速度向前推近，产品细节逐渐放大，整体节奏安静优雅，柔和棚拍光，无音效，极简科技广告开场，smooth product reveal，minimal tech commercial，soft studio lighting，16:9，10 seconds
```

**镜头运动**：静止 → 缓慢推近（zoom in 约 10%）\
**负面提示词**：快速切换，强烈闪光，复杂背景，抖动，低帧率

---

### 第二段｜材质细节 + 功能演示（10–20s）

**节奏**：微距扫描机身 → 拨轮特写 → 点燃火焰 → 防风演示

**提示词**：

```
镜头从打火机机身磨砂陶瓷质感表面缓慢横向扫过，细腻纹理在柔光下清晰可见，随后镜头上移至顶部银色金属拨轮微距特写，齿纹反射高光，接着一只手入画轻拨拨轮，橙金色火焰点燃，内核淡蓝紫色，随后画面切至防风演示：气流线条从左侧扫过，火焰纹丝不动，画面左侧淡入黑色文字"防风稳焰"，整体节奏流畅，柔和自然光，warm lifestyle meets tech commercial，macro to medium shot transition，16:9，10 seconds
```

**镜头运动**：横向平移 → 上移微距 → 固定近景\
**负面提示词**：快速剪辑，过曝，杂乱背景，抖动，低分辨率

---

### 第三段｜多色阵列 + 结尾收束（20–30s）

**节奏**：三款颜色产品依次飞入 → 阵列悬浮 → 镜头拉远 → 品牌口号淡入

**提示词**：

```
浅灰白背景，纯白磨砂打火机首先从画面下方缓慢浮起居中，随后哑光黑色款从右上角斜向飞入悬停，淡粉色款从左下方浮入，三款产品形成动态斜线阵列悬浮，机身边缘高光清晰，产品间大量留白，镜头缓慢拉远，三款产品整体缩小至画面中央偏上，下方淡入极简黑色品牌口号文字，字体粗黑无衬线，整体收束优雅，floating product array，brand closing，minimal tech commercial，soft studio light，16:9，10 seconds
```

**镜头运动**：固定 → 缓慢拉远（zoom out 约 15%）\
**负面提示词**：快速切换，复杂背景，过饱和，抖动，低帧率，拥挤构图

## 六、锚点（固定不变的工艺）

- **背景色**：浅紫白 / 浅灰白，始终保持高调冷色调
- **字体**：粗黑无衬线，黑色或深紫色
- **光线**：柔和棚拍光 / 高调打光（high key lighting），边缘高光清晰
- **构图**：中心构图 + 大量留白
- **质感关键词**：磨砂陶瓷、阳极氧化铝、哑光、精密金属
- **比例**：16:9
- **风格锚定词**：`minimal tech commercial, Apple-like aesthetic, premium product render`
