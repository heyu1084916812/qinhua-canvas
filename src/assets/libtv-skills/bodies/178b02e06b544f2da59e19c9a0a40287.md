# Seedance Video Prompt 2.5 Higg短｜独立旗舰时间轴版

## 唯一职责

把当前最新、完整、可用的 Higg 导演母版片段转化为 Seedance 可直接提交的中文技法强化时间轴。导演母版锁定“演什么”，本 Skill 主动强化“怎么拍、怎么演、怎么动、怎么响”：在主剧情、人物、对白、关键因果、场景、道具结果、总时长与结尾不变的前提下，可以重新设计镜数、切点、景别、构图、运镜、焦点、节奏、表演细节、动作力度、物理反馈、灯光、环境动态与声音层次。最终仍只输出 `【时间轴】`；精简的是公开栏目和重复映射，不是专业技法和学习资料。

本 Skill 必须独立运行：只读取本目录的 `references/`、`scripts/`、`tests/` 与用户材料，不读取或调用 `seedance-video-prompt-2-5`、`seedance-video-prompt-2-5-higg` 或其他 Skill 的文件。重装系统时复制本 Skill 整个目录即可保留完整能力。

优先编译 `director-shot-script-2-5-higg-short` 的当前母版；用户明确提供旧 `director-shot-script-2-5-higg` 完整母版时保持向后兼容。导演母版始终是唯一剧情事实源。

一次提取并固定剧情硬事实：主剧情、关键事件顺序、总时长、人物闭集、身份与外形锚点、说话人、对白原字原序与标点、OS/旁白/录音/画外声属性和口型、场景与时间天气、关键空间方向、道具归属与最终状态、动作因果、开场状态和最终结果。

导演母版中的镜数、镜序、切点、切型、景别、构图、摄影机路径、焦点、动作细分节奏、表演外化、光影处理、环境动态、物理反馈和声音层次属于可强化技法，不是必须照抄的硬事实。可以为了画面效果重新切分时间拍、合并或拆分镜头、调整切点和转场、改变运镜与焦点，只要总时长不变、对白完整、剧情事件与关键因果顺序不变、人物和道具状态连续、最终结果一致。

用户要求改变剧情硬事实时停止成功编译，只回复：

`请先用 director-shot-script-2-5-higg-short 修改导演母版；修改完成并通过该 Skill 的必要检查后，即可重新编译本片段，无需额外锁定。`

技法强化必须主动发生，而不是只在母版缺字时被动补全。允许重新设计摄影机物理路径、镜数与切点、景别、构图、焦点、节奏、接触与惯性、动作力度、环境反馈、实际光源、曝光、声源让位、眼神/呼吸/手部表演证据及局部正向防漂移锁。不得增加或删除剧情事件、人物、关键道具、对白、总时长或结局，不得改变关键动作因果顺序。

母版一旦修改，丢弃旧提示词并从最新母版整段重编译；不复制旧时间码或旧细节拼补。

## 时间轴编译

时间轴从 `00:00` 开始，相邻时间拍首尾相接，最后一拍结束时间等于母版总时长。先按剧情、表演和视觉注意力重新诊断母版镜头方案，再决定强化后的镜数、切数、切型和切点；不得机械照抄母版镜头，也不得为了炫技无理由增加切镜。每拍时间码后必须紧接一个且仅一个来自 `camera-move-tags.md` 的英文主运镜标签，然后写中文执行正文。每拍只有一个主要任务，并按以下顺序写成连续段落：

`时间码 → 英文主运镜标签 → 镜头与构图 → 当前可见状态 → 触发 → 连续动作路径 → 表演/道具/环境/声音反馈 → 对白与口型 → 拍尾稳定状态`

- 第一拍直接写足第一帧人物身份、位置、左右、朝向、姿势、手部、道具、场景地标、摄影机位置、主光和初始声音，不另建开场层。
- 中间拍只写本拍变化与防止身份、轴线、道具、光向、声音或环境相位漂移所需锚点，不重复整套资料。
- 最后一拍通过正文动作真实到达人物、道具、环境和声音的最终状态，不另建结束层。
- 每一切写清切型、原因、下一镜开场主体/位置和上一拍镜尾承接；允许重做切点与切型，但切镜不重置任何持续状态，不切断对白、接触、落地、道具交接或必要反应。
- 连续位移保留起点、准备、过程、接近、减速、到达和余波，不瞬移。生成模型需要稳定状态时，在过程关键阶段给出状态里程碑，不能删除动作过程。
- 关键接触、反应、口型切换、落地或道具改变可精确到 0.5—1 秒；普通过程使用 2—5 秒。
- 只写锁定对白。每句固定为 `（说话人｜声源属性）“正文”`；说话者对口型，听者闭口。观众专属 OS 闭口且场内不可听；录音或画外声写清声源与可听范围。
- 表演以目标、阻碍和策略为因，用眼神、呼吸、重心、手部、距离、声线与余波显示；听者可在对方话未结束时开始反应，不堆肌肉清单或抽象情绪词。
- 摄影机、物理、灯光和声音只在实际相关拍写足控制信号：机位物理位置与侧别、可见光学结果、质量/接触/惯性、实际光源及曝光优先、声源与环境让位。
- 英文标签只概括本拍的一个主要摄影机运动，不替代中文正文。复合运镜选择承担核心叙事任务的主运动作为标签，其余推、摇、升降、受力修正或焦点变化继续写入中文正文；确需固定时使用 `[Static Camera]` 并说明稳定功能。
- 用户或母版要求“强化、爆发力、紧张、速度感、压迫感、霸气、冲击感、追逐感、不要太平、不要太呆”等效果时，必须把动作强化与摄影机强化视为同一项任务：逐个受影响镜头重新判断摄影机起点、终点、运动方向、速度曲线、主体占比、前景视差、焦点变化、操作者受力反馈与拍尾落点，并把必要结果写入对应时间拍；不得只强化人物动作、表情、特效或环境而让摄影机无理由停在原地。
- 有外部参考时，在后台完成控制对象、允许继承、不参与和生效时间的权限核对；最终时间轴不得输出`参考体名称→控制对象→允许继承→不参与→时间窗`等映射说明。只把当前镜头真正可见且防止身份漂移所需的脸、发型、服装、场景材质或道具结构自然写入镜头正文，优先把篇幅留给动作、表演、运镜、物理、光影、声音和镜尾状态。除非用户明确要求平台引用标签，否则不输出图号、文件名、参考说明或`@素材`。
- 普通描述、摄影、风格和技术说明使用中文；每拍的受控英文主运镜标签直接合法。用户提供或素材中实际使用的英文人物名、人物简称和人物素材文件名可以保留，不需要导演母版来源证明；其他英文标识仍按来源证明规则处理。不得把人物文件名当作人物外形、动作或参考权限说明的替代品，也不得输出箭头映射。
- 不使用“同前”“同上”“照旧”“沿用上一段”等跨段省略。

## 动作强化与运镜联动

凡当前请求或母版出现动作强化意图，对全部受影响镜头执行一次运镜、切镜与节奏重设计。强化不是默认增加切镜，也不是让摄影机持续乱动；必须服从剧情硬事实、空间连续性和动作因果，但不受母版原镜数、原切数、原切型和原切点束缚。可以在总时长内拆分、合并或移动镜头边界，并强化可执行的摄影机物理路径。

每个受影响镜头至少明确以下五项：

1. 摄影机为什么动，运动由人物位移、冲击、揭示、关系变化、道具路径或情绪转折中的哪一项触发。
2. 摄影机从哪里开始、沿什么方向运动、在哪里结束，主体在画面中的左右、占比与视线是否保持。
3. 运动速度怎样变化，写清启动、加速、匹配、减速、停稳或受力修正，不使用匀速漂浮。
4. 运动如何形成可见结果，例如近景遮挡变化、道路或墙体视差、背景压缩变化、主体逼近、焦点转移、运动遮挡切镜或冲击后的构图恢复。
5. 镜头怎样在关键动作、接触、落地、口型或反应前后落稳，不能用运镜掩盖因果或让模型漏掉动作终点。

动作、追逐、冲刺、爆炸冲击、强势登场、快速转身、逃跑和空间穿越，原则上优先设计有动机的跟拍、退行、横移、推拉、升降、摇摄、前景穿越或运动遮挡，并根据内容选择一种清楚主运动；禁止在没有导演理由时把这些镜头全部写成固定机位。对白微表演、需要完整读取接触因果的侧面镜、精确道具操作、悬念延迟揭示或母版明确要求固定时，可以保持摄影机稳定，但必须明确稳定的叙事功能；前后镜头仍应通过景别、机位、焦点或有动机运动形成节奏变化。

不得为了“更动态”擅自新增人物、剧情事件、对白、总时长、关键道具或结局；允许增加、减少或调整服务剧情的镜头与切点。不得堆叠无动机环绕、升降、推拉和随机抖动。运镜强化的目标是让既有动作更有速度、重量、方向、空间层次和落点，而不是让摄影机抢走表演。

## 输出契约

成功时只返回一个 fenced Markdown 代码块，代码块外零文字。代码块内只允许一个标题：

```text
【时间轴】
(00:00-00:XX) [Slow Dolly In] [镜头与构图；第一帧人物、空间、道具、光线和声音；触发→连续动作路径→反馈→对白/口型→拍尾状态]
(00:XX-00:XX) [Side Tracking] [本拍变化；切镜承接；摄影机、表演、物理、灯光、声音与拍尾状态]
[连续写到总时长；最后一拍真实到达最终状态]
```

`【时间轴】` 后的第一个非空行必须直接是从 `00:00` 开始的时间拍。不得插入固定音频句，也不得出现其他 `【……】` 标题、分析、来源、诊断、对账或创作说明。
