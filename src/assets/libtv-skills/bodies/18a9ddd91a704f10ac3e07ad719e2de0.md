## 四、时间戳精准控制

> Seedance 2.5 的杀手锏功能。把剧本变成秒级指令。

### 4.1 时间戳写法公式

```text
【全局节奏声明】
本镜头总时长 {N} 秒，按以下时间线精确推进：

[00.0-{t1}s] → {阶段一：起始状态 + 微小动作}
[{t1}-{t2}s] → {阶段二：触发事件 + 角色反应（因果链 L1）}
```

## 五、多模态参考工作流

> Seedance 2.5 支持 30 图 / 10 视频 / 10 音频，要按「控制层级」科学分配。

### 5.1 参考资源分配策略

```
┌─────────────────┬──────────┬──────────────────────────────────────┐
│ 类型             │ 数量建议  │ 用途与优先级                         │
├─────────────────┼──────────┼──────────────────────────────────────┤
│ 角色基准图       │ 5-10张/人│ 🔒最高优先级——锁定五官服装体态配色   │
│ 角色表情变体图   │ 2-4张/人 │ 🔒高优先级——情绪切换时绑定           │
│ 场景氛围图       │ 3-5张    │ 🔒高优先级——锁定环境色调时代感       │
│ 风格参考图       │ 2-4张    │ 🎨中优先级——统一系列视觉风格         │
│ 动作参考视频     │ 1-3条    │ 🎬中优先级——复杂动作预演             │
│ 音色参考音频     │ 1-2条/人 │ 🔊中优先级——角色配音音色锁定         │
│ 音乐/音效参考    │ 1-2条    │ 🎵低优先级——纯音频驱动或BGM提取      │
└─────────────────┴──────────┴──────────────────────────────────────┘

原则：先锁死角色和场景（🔒），再注入风格（🎨），最后增强表现力（🎬🔊🎵）
```

### 5.2 多角色群戏策略

```text
Step 1：单独生成每个角色的基准图包（正面/侧面/背面/表情变体）
Step 2：在提示词中明确点名每个角色的位置和动作
  示例："左侧是机器人老铁（牛仔帽+机械钳），右侧是女猎人艾娃
        （皮夹克+双枪），两人背靠背站立，面对前方丧尸群"
Step 3：使用 Seedance 2.5「多角色参考」功能同时上传所有角色基准图
Step 4：若站位混乱 → 先用「白模控制」预演站位 → 再生成正式画面
Step 5：若个别角色崩坏 → 用「局部视频编辑」修复该区域 → 不重抽整段
```

## 六、超长叙事：续写与 180 秒模式

### 6.1 三种时长策略选型

适用场景 推荐模式 操作方式 注意事项 单镜头收尾 / 短视频 标准生成 单次生成 5-10 秒 最基础模式 单场完整动作戏 视频延长 先生 5-10s → 延长 20-30s → 最长 60s 延长前保留 Seed 整集正片 / 长独白 超长视频模式 直接生成最长 180 秒连续视频 建议拆成 4-6 个段落

### 6.2 延长生成的一致性保险

```text
✅ 延长前必做：
  1. 记录原视频 Seed 值，延长时复用
  2. 再次上传同一组角色/场景参考图
  3. 在提示词强调"从上一镜最后一秒的姿态无缝继续"

✅ 时间戳重新标定：
  原视频 5 秒 → 延长部分从 5.0s 开始写时间戳
  例："5.0-7.0s：老铁从蹲姿站起..."
```

### 6.3 180 秒超长视频分镜法

> 不要一镜到底写到满！拆成「镜头段落」用时间戳控制节奏。

```text
【180 秒剧情段落标准拆分模板】

▎第一幕：登场与建立（0-30s）
  0-15s：开场建立镜头，交代世界观/环境
  15-30s：主角登场，展示核心特征和当前状态

▎第二幕：触发与升级（30-90s）
  30-50s：日常状态被打破，触发事件出现
  50-70s：冲突初步展开，角色做出反应
  70-90s：冲突升级，多角色互动/环境变化

▎第三幕：高潮与落点（90-150s）
  90-120s：高潮动作戏 / 情绪爆发点
  120-140s：转折 / 意外反转
  140-150s：情绪落点，角色状态改变

▎第四幕：钩子与悬念（150-180s）
  150-170s：余波处理，为新冲突埋种子
  170-180s：结尾定格/悬念钩子，引向下集
```

## 八、声音与风格进阶控制

### 8.1 纯音频驱动生成流程

```
前置准备                →    Seedance 2.5 操作
─────────────────────────────────────────────────
1. TTS/真人录好对白     →    上传音频文件
2. 铺好音效时间线       →    作为纯音频驱动输入
3. 写画面跟随提示词     →    "第3句台词时角色转身，
                              配合背景爆炸音效画面震动"
4. 选择生成模式         →    标准模式(≤10s) 或
                              超长视频模式(≤180s)
5. 生成                 →    画面自动跟随音频节奏
```

### 8.2 音色参考使用要点

- 为每个主要角色录制/生成 **5-10 秒音色样本**
- 上传为对应角色的「音色参考音频」
- 生成对口型或配音时绑定，避免「同一 AI 声」廉价感
- 不同角色用不同音色参考，形成听觉辨识度

### 8.3 背景音乐分离

- 找到合适的参考音乐/视频片段
- 使用「背景音乐分离」功能提取干净 BGM
- 后期叠加到成片中，避免 Seedance 自动生成音乐与剧情冲突

### 8.4 创意风格迁移

```
用法：
1. 准备 2-4 张「风格锚定图」（你想要的最终视觉效果）
2. 在新项目中上传这些图作为「风格参考图」
3. Seedance 2.5 会把已有风格迁移到新生成的画面/视频
4. 适合：系列化作品、多集统一视觉风格、品牌视觉一致性
```

### 8.5 局部视频编辑 + 空间视角修改

```
局部视频编辑：
  当某个镜头局部崩坏（如一只手畸形、一个表情不对）
  → 用此功能只修复崩坏区域
  → 不需要重抽整个镜头
  → 大幅节省时间和积分

空间视角修改：
  当需要同一镜头的不同角度/景别变体
  → 用此功能快速生成变体
  → 不需要重新写完整提示词
  → 适合批量产出同场景多角度素材
```

## 十、质量自检清单

### 10.1 成品评级标准

等级 角色一致性 风格还原 因果链动态 祛 AI 感 剧情节奏 商业价值 **S** 跨集不变脸 风格极度鲜明 L3 深层因果 疑似实拍 hook 密集 可接商单 **A** 单集稳定 风格清晰可辨 L2 中层因果 高质感 有起承转合 平台推荐 **B** 偶尔小崩 有风格元素 L1 浅层因果 轻微 AI 感 完整故事 有播放量 **C** 明显变脸 风格模糊 命令式描述 明显塑胶感 基本连贯 练习作品 **D** 频繁变脸 无风格 无逻辑 严重畸形 逻辑混乱 不建议发布

**新手目标**：第一部达到 **B 级**，第五部达到 **A 级**。

### 10.2 发布前逐项检查

- **角色一致性**：同一角色跨镜头不串脸、服装不变、道具一致
- **风格统一**：多集之间视觉风格、色调、质感保持一致
- **因果链叙事**：每个关键动作都有动机→反馈→情绪变化
- **时间戳精准**：关键动作/转场发生在预定秒数附近
- **祛 AI 感**：无塑胶皮肤、无对称完美构图、无 CG 游戏感
- **声音干净**：无乱字幕、无 AI 自动生成音乐干扰
- **节奏合理**：开场有 Hook、每 30 秒有变化、结尾有悬念
- **时长合规**：符合目标平台最佳时长（抖音 15-60s / TikTok 30-45s / B站 3-5min）
- **分辨率达标**：1080P 以上，9:16 竖屏或 16:9 横屏
- **无水印/签名**：画面干净无 UI 元素
