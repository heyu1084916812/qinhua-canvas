# 3D 软胶拟物风格统一

把用户给的任意素材（图标、产品图、红包、优惠券、金币、礼盒、车辆相关物件等）转成同一套 3D 软胶拟物风格，输出绘图 prompt 并创建图片节点生成。

这是一个**风格锚定**类技能：它不独立产出内容，而是叠加在用户的任意生成需求之上，负责把主体"套进"这套固定风格。同一批素材生成时，风格、角度、材质、光照、画幅必须完全统一，只有色系与主体不同。

> **流程声明（一步式 · 单节点 4 张）**：只创建 **1 个**图片节点，从一开始就挂载全部 5 个锚点，`run_node` 一次直接得到 4 张带参考的独立成品；用户选用其中一张，**选用不触发第二轮生成**。

---

## 3. 执行流程

### 第 1 步：确认色系

- 用户已指定色系 → 直接使用，不再追问。
- 用户未指定 → 用 `ask_parent_agent` 让用户在**蓝色系 / 橙色系 / 红色系**中选一个，再继续。

### 第 2 步：识别素材主体

读取用户给的图片节点或文字描述，判断主体是什么物件（红包 / 优惠券 / 金币 / 礼盒 / 存钱罐 / 油枪 / 车辆相关物件 / 图标 / 产品图等），并判断**是否属于容器类**（见「材质规范」容器分支）。

### 第 3 步：查主体默认范式库

- **该主体已有默认范式** → 直接沿用其默认组合、角度、配色与材质，不再从零推断。
- **无** → 按第 4 步起从零推断。
- 用户明确指定了不同的组合 / 色系 / 表情 / 贴纸 → **以用户指定为准，覆盖默认范式**。

### 第 4 步：简化造型

把原素材的复杂纹理、多色、文字排版、装饰纹样**全部简化**为几个大色块与圆滑体块，只保留最高辨识度的轮廓特征，去掉一切不影响识别的碎细节。造型强调**更圆润饱满**：体块充气感更强、转角更大更柔和、轮廓更敦实饱满，折角一律大成圆角，避免干瘪和尖锐。

### 第 5 步：判断附加元素

- **拟人表情**：主体是拟人化对象（或用户要求）时，加极简黑色平面表情；用户明确说不要表情则不加。
- **贴纸**：用户给了贴纸文字或主体适合贴标签时，加平面印刷贴画；用户明确说不要标签则不加。
- **组合**：若素材是单一小元素（红包、优惠券、金币等），最多再组合**一个**元素来突出主体。

### 第 6 步：确定画幅（aspect_ratio）

在组装 prompt / 创建图片节点之前确定画幅，按「画幅选择规则」判断。

### 第 7 步：核验锚点池 5 个句柄有效性

1. 用 `search_canvas_nodes` 或 `get_node_details` 核验 5 个画布句柄是否仍存在且有图像产出。
2. 若某个句柄已失效（用户清理了画布），**提示用户从资产库「ICON风格」文件夹把对应那张拖回画布**，取得新 `node_key` 后回填技能；**不要自行重新生成参考图，也不要静默跳过该锚点**。
3. 句柄回填后更新锚点池表格，保持 uuid 与 node_key 一一对应。

> **注意**：分组节点本身无图像产物，**不能直接作为** `reference_nodes` **引用**；只能引用组内有产出的图片节点。

### 第 8 步：创建 1 个节点、挂载全部 5 句柄、标准词序、run_node 一次

- **只创建 1 个图片节点**（**禁止拆成多个节点**，兜底方案除外）。

- 该节点 `reference_nodes` **必须挂载锚点池全部 5 个句柄**：`{{i-8HujaxA5co}}` `{{i-DF6V1CUqzE}}` `{{i-cjJutbxAdZ}}` `{{i-TW8msj8X5M}}` `{{i-jwhGrxhulA}}`；prompt 内写对应占位与风格借鉴句——**从一开始就挂参考**，不存在"先不挂参考出候选、再挂参考出正式图"的两段式。

- `quality_spec` **固定且必须严格按此词序**：

  ```
  生成数量 4 张, resolution 1K, medium quality
  ```

  - **数量短语在最前**，其后只跟分辨率与画质；**末尾不得追加任何解释性自然语言**（"每张独立""不做宫格""单一主体"等一律不写，会破坏数量解析）。

- `run_node` 一次，直接得到 **4 张已带参考锚定的独立成品**；用户从 4 张中挑一张采用，**挑选只是选择，不触发第二次生成**。

**4 张差异的处理方式**：

- 单节点一次出 4 张时，**不在 prompt 里逐张指定差异**（既做不到，也会触发宫格）。4 张的角度、体块饱满度、辅助元素露出比例、材质侧重由模型采样自然产生。
- 生成后按四个维度（构图角度 / 体块简化程度 / 辅助元素位置与露出比例 / 材质侧重）**向用户描述已生成的 4 张差异**，辅助挑选。这四个维度**只用于挑选阶段的描述，不写进生成 prompt**。
- prompt 仍为**单一主体、单一构图**的一套完整描述；必须含反宫格首句「画面中央只有一个主体，四周是大量干净的负空间，整幅画面不存在分格、拼贴、九宫格或多视角排列。」，负面清单必须含「无宫格、无分格、无拼贴、无多视角排列、无同一画面的重复副本」。
- **禁止**在 prompt 中出现"4 张变体""各不相同""分别在以下维度差异"等集体性多图措辞。

### 第 9 步：回读核验 count = 4

- `run_node` 后用 `get_node_details` 回读 `agent_task_params`，确认 `count` 为 4 且产物为 4 张独立图（此时 `modeType` 为 `image2image` 是正常的，不影响数量）。
- 若 `count` 不为 4：**先自查** `quality_spec` **是否把数量短语写在了非首位、或末尾追加了描述性文字**；修正为标准写法 `生成数量 4 张, resolution 1K, medium quality` 后，标废弃原节点、新建节点重跑一次。
- 连续 2 次仍失效：如实告知用户，并询问是否改用"4 个节点各挂全参考、各出 1 张"的**兜底方案**（兜底为例外手段，不是默认流程）。**不得静默当作成功继续推进。**

### 第 10 步：向用户描述 4 张差异，由用户选用其中一张

用四个维度（构图角度 / 体块简化程度 / 辅助元素位置与露出比例 / 材质侧重）向用户描述 4 张的差异，供用户挑选。**挑选只是选择，不触发第二次生成。**

## 4. 全局风格锚点池（固定 5 条，一对一替换）

整套风格的视觉基准，作为**常驻参考**。**每次生图都必须挂载这全部 5 条。**

### 4.1 双层引用机制

- **母库层（持久）**：5 条锚点以**资产库 uuid + url 为权威身份**，永久保存、跨画布跨项目可用，不会因画布节点被删除而丢失。技能引用锚点池时以此为准。
- **句柄层（生成时用）**：生成图片时 `reference_nodes` **只接受画布上的** `node_key`，不接受资产 uuid 或 url。因此每次挂载锚点前必须确认画布句柄有效。
- **句柄失效处理**：见执行流程第 7 步（核验 → 提示用户从资产库「ICON风格」文件夹拖回 → 取得新 `node_key` 回填锚点池表格，保持 uuid 与 node_key 一一对应）。

### 4.3 锚点替换机制

**触发方式**：用户提供一张新的参考图（画布图片节点，或从资产库取），并表达"用它替换 / 这张更好"的意图；或主动要求换掉某一条。

**替换流程**：

1. 判断新图承担的角色（蓝系 / 红系 / 橙系 / 综合质感 / 特定主体范式）。
2. **同角色一对一替换**：新图顶掉池中同一角色的那一条，**池总数仍保持 5，不扩容**。
3. 若新图角色与池中某条不完全对应，**先询问用户要换掉哪一条，不自行挤掉**。
4. 新图必须先在画布上有产出节点、取得 `node_key`；若用户只给了资产库图片或外部图，**先落到画布取得句柄再入池**，**不得用 url 或 uuid 直接充当** `reference_nodes`。
5. 回填锚点池表格：更新该条的「角色、资产名、uuid、句柄」四列；被换下的旧条目从池中移出（旧图在资产库的原件保留不动，仅不再作为锚点）。
6. 替换后向用户确认新池 5 条清单，再继续生图。

**建议做法**：替换时提示用户可顺手把新图存入资产库（如「ICON风格」文件夹），以获得持久 uuid，避免日后画布清理导致锚点丢失。

**明确禁止**：因替换而减少锚点数量；把新生成的成品图自动加为第 6 条锚点（池恒为 5 条，只能一对一换）。

### 4.4 成品图可作为替换候选

每次生成完成后，若某张质量明显优于池中某条同色系锚点，可**主动向用户提出**"是否用这张替换掉第 N 条锚点"，由用户决定；用户同意则走 4.3 的替换流程，不同意则保持原池不变。**不得自行替换。**

## 5. 画幅选择规则（4:3 优先）

- **默认一律用 4:3。**
- 只有在主体为**明显的正方 / 圆形轮廓、且 4:3 会造成两侧大量空白浪费**时（如单独的圆形钟、存钱罐、球状福袋、单枚金币），才退让为 **1:1**。
- 仍**不使用其他比例**（不用 16:9、9:16、3:4、21:9 等）。
- 用户明确指定画幅时以用户指定为准。

---

范式库是**可持续追加**的：以后用户再给新的主体参考图，按同样格式往里加条目。

## 7. 风格规范（固定不变，逐条写入 prompt）

1. **造型语言**：3D 软胶/黏土质感的膨胀圆润体块，玩具化、无锐角无硬边；**更圆润饱满、充气感更强、转角更大更柔和、轮廓敦实饱满，折角一律大成圆角**；主体单一、居中、略微 3/4 侧角、平视或轻微仰视；画面留大量干净负空间。
2. **材质**：表面为细腻均匀的**哑光软陶/微磨砂质感**，带极细的颗粒漫反射——不是塑料、不是亮漆、不是橡胶。
   - **允许**：极轻微、柔和、面积很小的自然反射，看起来像真实柔光箱在哑光表面的自然反光，不刺眼、不成形、不抢眼；容器类主体边缘的柔和透光过渡照旧保留。
   - **仍然禁止**：明显的点状高光、白斑、过曝反光条、锐利亮边、镜面反射、漆面反光、油腻高光条、锐利发光描边、强对比反光。
   - **质感基调不变**：仍以细腻均匀的哑光软陶/微磨砂为主，大面积柔和渐变光塑形，保持高调亮度。
   - **容器分支**：当主体是**容器**（盒子、礼盒、罐子、瓶子、袋子、红包、福袋、存钱罐、背包、抽屉等可装东西的造型）时，容器本体改用**半透明磨砂玻璃/磨砂软胶**质感——细腻均匀磨砂颗粒、透光不透明，能隐约透出容器内部物体的柔和模糊剪影（盒内物件、罐内金币、红包里的钞票/券），不锐利、不清澈见底；容器边缘有一圈柔和的透光过渡（轻微折射亮边），但**仍是柔光渐变、不是镜面高光**；容器上的非容器部件（盖子、绳结、蝴蝶结、提手、标签区）保持哑光软陶质感，形成"磨砂容器体 + 哑光配件"的对比。**非容器主体**（闪电、油枪、券票、金币、工具等）不适用磨砂分支，仍为纯哑光软陶。
3. **色彩**：**纯白（#FFFFFF）干净底色**，不带任何色偏、不加浅蓝灰调、不加渐变、不加底部微发光、不加环境反射；主体使用指定的那一套主色系，并按「配色搭配矩阵」搭配撞色。
4. **拟人化处理**：任何拟人主体一律配极简黑色平面表情——两个实心黑点/黑椭圆眼睛 + 一条简单黑色弧线微笑嘴，无鼻子无其他五官细节，可选淡粉腮红；表情贴在最醒目的正面体块上。用户要求不加表情时省略。
5. **贴纸/标签**：标签是**平面印刷贴纸/贴画**，像印好贴上去的一层薄纸片，**没有 3D 厚度、没有凸起浮雕感、没有立体边缘、没有明显投影**，只有极轻的贴合阴影或直接贴合无阴影。
   - **位置**：贴在主体的**角落或侧边**（如左下角、右上角、侧面边缘），不占据主体正面中央，不遮挡主体的最高辨识度轮廓。
   - **形状**：简洁的圆角矩形/胶囊形/异形贴片均可，按主体图形需要定义，边缘干净利落。
   - **颜色跟随主体色系**：贴纸底色取主体同色系的浅色或白色，贴纸上的图形/文字取主体同色系的深色或该色系允许的撞色（遵循配色矩阵：蓝系禁黄、橙系可搭黄或珊瑚红、红系可搭橙或黄）。不再固定"白色胶囊 + 彩色字"。
   - **文字内容严格按用户给定的英文/文字**，不自造品牌、不翻译、不改写；用户没给文字就不放文字，可只放一个简洁图形符号。
6. **元素组合**：单一元素可以组合，但一张图最多两个元素，用来突出主体；主体之外只允许少量漂浮辅助小元素（小金币、短划装饰、星点），不得堆砌。
7. **光影**：正前上方大面积柔和渐变光（柔光箱铺满式）塑形，只保留极轻微自然反射；**完全不带阴影**——无接触阴影、无投影、无落地黑影、无底部反光板辉光；主体靠自身的柔和明暗渐变塑造体积，不靠阴影托底；画面干净、无环境杂物、无文字水印。

## 8. 配色搭配矩阵

每张图只使用**一套主色系 + 其允许的撞色搭配**，不混用两套主色。撞色点缀只用在局部小部件（扳机、绳结、金币、绑带），不大面积铺色。

主色系主色允许的撞色搭配禁止蓝色系高饱和、纯净通透的宝蓝/亮蓝（不要灰蒙蒙的浅蓝）搭配**橙色**作撞色点缀**禁止出现黄色**橙色系琥珀橙到暖橙渐变可搭配**黄色**，或搭配参考图中红包那种**珊瑚红/橘红**作撞色—红色系参考红包的珊瑚红到橘红渐变可搭配**橙色**，或搭配**黄色**—

- 背景为纯白（#FFFFFF）干净底色。

## 9. 硬性约束

- 不得引入蓝 / 橙 / 红之外的色系。
- **蓝色系作品中不得出现黄色**；黄色只能出现在橙色系或红色系作品里。
- 每张图只使用一套主色系 + 其允许的撞色搭配，不混用两套主色。
- 一张图元素不超过两个。
- **画幅默认 4:3，仅正方 / 圆形单主体退让 1:1**，不使用其他比例。
- **一次生图只创建 1 个节点，禁止拆成多节点**（兜底方案除外）。
- **该节点必须挂载锚点池全部 5 个句柄**，不得遗漏、不得只挑部分、**不得有不挂参考的生图**。
- `quality_spec` **必须严格为** `生成数量 4 张, resolution 1K, medium quality`，**数量短语置首、末尾不得追加任何描述性文字**。
- **4 张差异不得写进 prompt**，只能在生成后按四维度向用户描述。
- **每张图只允许一个主体**、必须含反宫格首句与宫格负面项、**禁止集体性多图措辞**。
- **生成后必须核验** `count=4`，失效先查词序再新建重跑。
- **锚点池恒为 5 条**，不得增减或只挑部分。
- **替换只能一对一顶替同角色条目，换后总数仍为 5**；**新锚点必须先有画布** `node_key` **才能入池**；**旧锚点被换下后立即移出池，不再引用**；**不得把新生成的图自动入池，须征得用户同意**。
- **挂载前必须核验句柄有效性**；失效则请用户从资产库「ICON风格」文件夹拖回并取得新 `node_key`，**不得自行重新生成参考图、不得静默跳过**。
- **资产 uuid 为锚点的权威身份，画布句柄仅为临时引用句柄**，句柄变更须回填技能。
- **不得引用无图像产出的分组节点**；**不得用 url 代替** `node_key` **传入** `reference_nodes`。
- **背景必须为纯白（#FFFFFF）**，不带色偏、不加渐变；**完全不带阴影**（无接触阴影、无投影、无落地黑影、无底部反光、无地面、无底座、无环境反射）。
- **亮度主要靠大面积柔和渐变光维持**；只允许极轻微自然的柔和反射，**禁止明显点状高光、白斑、过曝反光条、锐利亮边与镜面反射**；必须去除明显 AI 感与廉价 CGI 感。
- **容器类主体必须启用半透明磨砂材质并透出内部物体轮廓**，非容器主体不得滥用磨砂。
- **标签必须是平面贴画、贴在角落或侧边、颜色跟随主体色系、文字严格用用户给定内容**，禁止 3D 厚度与浮雕凸起。
- 拟人表情必须是黑色极简样式（黑点眼 + 弧线嘴）；用户明确不要表情时不加。
- 贴纸文字严格按用户需求，**不自造品牌**；用户明确不要标签时不加。
- 不保留原素材的复杂纹理、多色与装饰细节。
- 同一批素材：风格、角度、材质、光照、画幅完全统一，只有色系与主体不同。
