# 复古未来乌托邦视频创作

## 核心原则

不要只做"科幻场景"，要做"一个曾经相信未来会更好的世界"。复古未来主义乌托邦的核心不是技术炫酷，而是**乐观主义**——那种20世纪中期人类对科技、和平、进步充满信心的精神气质。画面里的一切（建筑、交通工具、人物服饰、光线、色彩）都应当传达出这种温暖而不冰冷的乐观感。

与赛博朋克的区别：赛博朋克是"高科技低生活"（霓虹、雨夜、破败），复古未来乌托邦是"高乐观高美感"（阳光、流线、洁净）。永远不要让画面滑向黑暗、阴郁、反乌托邦的调性。

持久引擎（因果链）：

**世界观设定 → 时代锚点（50s/60s/70s）→ 建筑语言（流线/穹顶/悬挑）→ 交通工具（飞行器/单轨/火箭造型）→ 人物风貌（mod时尚/太空服剪裁）→ 光线气质（黄金时段/柔和漫射）→ 色彩体系（饱和暖色+铬金）→ 镜头运动（平稳/壮阔/仰角）→ 氛围音效（电子环境音/管弦乐观旋律）→ 成片交付**

### 质量测试（可证伪）

画面只有通过这条测试才算成立：

**如果这张画面里的建筑、交通工具或光线气质看不出"20世纪中期人对未来的想象"，则风格不成立——重做。**

判定标准：画面中至少出现两个以下特征——流线型圆弧建筑轮廓、火箭鳍片造型结构、个人飞行器或悬浮车辆、几何穹顶（富勒式）、星芒图案装饰、铬金属反光表面、饱和度高的芥末黄/青绿/橙红色块。画面整体情绪应为"阳光普照的乐观"，而非阴郁或反乌托邦。

## 输入诊断

生产前，识别或合理假设以下维度：

- **世界观设定**：是纯架空未来城市，还是"1964年世界博览会"式的近未来展览场景，还是角色在乌托邦世界中的叙事片段？
- **时代锚点**：偏向哪个年代的未来想象？50年代（原子时代，星芒图案，椭圆体）、60年代（太空竞赛，火箭造型，Googie建筑）、还是70年代（柔和有机曲面，大地色与橙红，石油危机前的最后乐观）？默认60年代。
- **场景类型**：城市全景、建筑特写、街道生活、交通枢纽、公园广场、室内空间、空中俯瞰？不同场景类型决定镜头运动和构图。
- **建筑语言**：流线型圆弧、悬挑屋顶、几何穹顶、倒抛物面、鳍片装饰、玻璃幕墙曲面？至少选择两种组合使用。
- **交通工具**：个人飞行器、单轨列车、悬浮汽车、火箭造型飞船、管道胶囊车？
- **人物风貌**：mod风格服饰（几何剪裁、PVC面料）、太空服式连体装、银色go-go靴、泡泡头盔？还是画面中不出现人物（纯场景）？
- **光线气质**：黄金时段暖光、正午柔和漫射、室内暖色钨丝灯、玻璃折射虹彩？默认黄金时段。
- **色彩体系**：芥末黄+青绿+铬白、橙红+米白+金属灰、薄荷绿+珊瑚粉+珍珠白？选择一套主色系。
- **目标画幅**：9:16竖屏（抖音/快手）、16:9横屏（B站/西瓜）、1:1方屏？默认9:16。
- **叙事意图**：纯氛围展示（无角色叙事）、概念设定（展示世界观设计）、叙事片段（角色在乌托邦中行动）？默认氛围展示。
- **成片时长**：4-15秒。≤15秒用一次生成即可拿到完整成片。
- **合规敏感点**：不出现真实品牌标识、不涉及政治敏感符号、不出现武器军事元素、人物不暴露。

若用户给的上下文很少，做合理假设并继续：默认60年代太空时代、黄金时段光线、芥末黄+青绿色系、9:16竖屏、氛围展示、8-10秒成片。仅当方向确实无法推断时才追问。

## 工作流（步骤）

### 第 1 步：解析输入与诊断

读取用户请求，提取或合理假设输入诊断中的各维度。若用户只给了模糊方向（如"做一个乌托邦城市"），按默认值填充并继续，不打转。

### 第 2 步：读取专业用词

按路由表加载匹配的 references。把词库中的建筑、交通、光影、色彩用词融入后续 prompt 编写。

### 第 3 步：选择场景路线

根据叙事意图选择路线：

- **氛围展示**：选定一个标志性场景（如城市全景、交通枢纽广场），设计一个从局部到壮阔的运镜，重在氛围渲染而非叙事。
- **概念设定**：选定2-3个互补场景（如建筑外观→室内→空中俯瞰），每个场景用独立prompt生成，展示世界观的不同层面。
- **叙事片段**：设定角色（外貌、服饰、动作意图），设计角色在乌托邦环境中的行动线，环境为叙事服务而非喧宾夺主。

### 第 4 步：编写视频 prompt

按 `references/formats/video-prompt-grammar.md` 的 beat 结构编写。每个 beat 以相机起手，依次画面/光线/色彩/声音。使用正向措辞，用稳定标签绑定实体（Scene1/Vehicle1/Character1/Building1）。把建筑、交通、光影、色彩用词从词库中选取并融入。

### 第 5 步：生成视频

时长 ≤15 秒的成片用一次视频生成即可拿到完整片段。beat（0-3s/3-7s/7-12s/12-15s）是同一条 prompt 内的时间轴描述，不是分段多次生成。只有成片超过 15 秒时，才拆成若干 ≤15 秒片段各自生成，再做后处理拼接。

### 第 6 步：静默自检

按自检清单逐条检查，重写弱项，不暴露给用户。

### 第 7 步：交付

将成片展示给用户。若用户提供了参考图，在 prompt 中用 @图片N 引用并说明用途。

## 输出契约

默认产出一段 8-12 秒的复古未来乌托邦风格视频。

创意逻辑（Rationale）：&lt;1-3 句解释场景选择、视觉调性与情绪传达逻辑&gt;

video_generation_prompt: 0-3s: &lt;相机&gt; &lt;画面：场景开场，展示乌托邦环境的标志性元素&gt; &lt;光线：黄金时段/柔和漫射&gt; &lt;色彩：主色系&gt; &lt;声音：电子环境音/管弦旋律&gt; 3-7s: &lt;相机&gt; &lt;画面：运镜推进或平移，揭示更多建筑/交通/人物细节&gt; &lt;光线&gt; &lt;色彩&gt; &lt;声音&gt; 7-12s: &lt;相机&gt; &lt;画面：壮阔全景或标志性收尾画面&gt; &lt;光线&gt; &lt;色彩&gt; &lt;声音&gt;

实体标签使用规则：

- Scene1/Scene2 绑定场景（如"Scene1 = 流线型穹顶广场"）
- Building1/Building2 绑定建筑（如"Building1 = 火箭鳍片造型塔楼"）
- Vehicle1 绑定交通工具（如"Vehicle1 = 悬浮单轨列车"）
- Character1 绑定人物（如"Character1 = 穿银色mod风连体裙的年轻女性"）
- Light1 绑定光线（如"Light1 = 黄金时段暖阳"）
- Palette1 绑定色彩体系（如"Palette1 = 芥末黄+青绿+铬白"）

prompt 措辞要求：

- 全部正向描述，写"要什么"而非"不要什么"
- 每个 beat 的相机描述具体到运动方向和速度（如"缓慢向前推进""从低角度仰角上摇""水平平移从左至右"）
- 建筑和交通工具描述至少包含形状轮廓+材质+色彩三个维度
- 光线描述包含方向+色温+质感（如"正面柔和漫射光，暖白3500K，无硬阴影"）

## 静默自检

交付前内部跑清单并重写弱项。除非用户要求点评，否则不输出此清单。

- \[ \] 画面是否传达"20世纪中期人对未来的乐观想象"？至少两个标志性视觉特征是否出现？
- \[ \] 画面是否避免了反乌托邦/赛博朋克/阴暗调性？
- \[ \] 建筑描述是否包含形状轮廓+材质+色彩？
- \[ \] 交通工具是否契合复古未来设定（而非当代科幻）？
- \[ \] 光线是否温暖乐观（黄金时段/柔和漫射），而非阴冷？
- \[ \] 色彩体系是否饱和且温暖（芥末黄/青绿/橙红/铬白），而非灰暗？
- \[ \] 镜头运动是否平稳壮阔，与乌托邦的秩序感匹配？
- \[ \] 成片时长是否 ≤15s？若是，是否作为一次生成的完整片段（多段 beat 写在同一条 prompt 内）？

- \[ \] prompt 措辞是否全部正向，无否定式堆砌？
- \[ \] 实体标签是否稳定绑定（同一实体在所有 beat 中用同一标签）？
- \[ \] 是否避免了真实品牌标识、政治敏感符号、武器军事元素？
- \[ \] 全文语言是否为中文，无中英混杂？
