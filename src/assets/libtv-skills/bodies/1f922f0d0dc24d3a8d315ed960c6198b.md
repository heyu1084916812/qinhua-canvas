# 微表情与情绪表演框架（去 AI 味）

一套约束 Agent 如何在任何含人物的图片/视频提示词中书写表演的底层框架。它不产出内容本身，而是叠加在任意人物生成任务之上的写作准则：换任何人物、任何镜头、任何故事、任何台词数量（零句到多句）都直接套用。

## 何时使用

- 生成任何含人物的图片或视频提示词，且希望表演像真人、没有 AI 味。
- 用户已给出人物设定、场景、剧情或台词，需要把它们落成可执行的表演描写。
- 需要把一段剧情拆成有时间刻度的分镜脚本。

## 核心原则（七条，缺一不可）

### 一、拒绝静态形容词，用「动作」替代「状态」（肌肉解构）

禁止在提示词里直接书写情绪名词（伤心、震惊、失望、决绝、温柔、茫然……）。情绪只能以肌肉的即时运动出现，并写成有先后次序的解剖清单。

- 每个情绪节拍拆成 2–4 个具体部位的独立动作，按先后顺序排列。
- 动词优先：聚拢、翕动、隆起、垂合、颤动、收紧、滑落、别至耳后、抬升、舒展、内收。
- 不用状态词：悲伤的、茫然的、失落的、决绝的。
- 情绪收尾必须写「回落 / 归零」动作，而不是停在最强点。

句式模板：

> 「〔部位 A〕〔动作〕，〔部位 B〕〔动作〕，〔部位 C〕缓缓〔回落动作〕」

反例 → 正例：

> ✗ 她露出伤心的表情 ✓ 眉头内侧向中间轻收，下唇出现极细微颤抖，随后眉心缓缓舒展

### 二、命令矛盾与不完整，打破对称性

真实情绪从不纯粹也从不完整。AI 感主要来自过度对称与过度完成。三种手法至少各用一次：

1. **单侧化**：只允许一侧部位运动，并显式禁止另一侧与其余区域参与。

   > 「只〔单侧部位〕〔动作〕，〔对侧部位〕与面部其余区域完全静止」

2. **未完成**：动作做到一半就停。

   > 「只有半弧」「未扩散至面部其他区域」「未抵达眼底」「话被咽回」

3. **对冲共存**：在同一时刻或指定极短间隔内叠加两种相反状态，并显式标注是「同时发生」还是「若干秒内相继转换」。

   > 「〔状态 A〕的同时，〔状态 B〕，二者同时发生」／「〔状态 A〕在 0.5 秒内转为〔状态 B〕」

### 三、量化生理指标，用数字杀死模糊

所有程度副词（微微、轻轻、几不可察、略微）必须换算成数字：

维度单位与写法位移毫米 / 厘米（如「内收 2–3 厘米」）角度度（如「幅度不超过 15 度」「下沉半度」）时长秒（如「约 1 秒后松开」「持续 0.2 秒」）频率每 N 秒一次（如「眨眼每 3–4 秒一次」）速度先快后慢 / 在第 N 度突然减速

数字要逼近生理真实尺度：1 毫米级颤抖、0.2 秒卡顿、半度下沉。

同时量化「不该出现的东西」——把负向约束也写成可检验的指标：眉间距离保持不变、眼周肤色不发红、液体不溢出边界、不出现竖纹。

### 四、强调克制与中断，制造失序感

不写情绪的全额释放，写它的压抑与半途而废。

- 动作结构：启动 → 减速 → 停止。
- 涌上来的东西被强行锁回；想做的动作在最后一刻收回。
- 每个高强度情绪都必须配一个「抑制动作」和一个「恢复松弛」的时间点。

句式模板：

> 「〔动作〕启动后在第〔N〕度突然减速停止」／「〔生理反应〕被强行锁住，〔部位〕紧绷颤动」

### 五、层级递进 + 时间轴

情绪不是一次到位，而是分阶段递进的链条（如：错愕 → 伤心 → 失望 → 决绝 → 释然）。每个阶段绑定明确的时间区间，区间内再排布微动作的先后。整段表演是一条有时间刻度的乐谱，不是一张静态快照。

- 情绪链至少 2 个阶段，禁止单点爆发。
- 每个阶段写明起止秒数，阶段内部按先后顺序排列微动作。

### 六、台词是微表情的触发器

- 每条台词拆到词级 / 音节级，标注说出哪个字时眼神、瞳孔、肌肉发生什么变化。
- 说完之后必须有余韵（合唇、摇头、呼气、目光滑落）。
- 台词之间的沉默也要写内容：呼吸、空气凝固感、微小动作。不允许出现「空转」时间。
- 若全片无台词，则整段表演由事件与生理动作驱动，此条转化为「每个时间区间都必须有可见的生理动作」。

### 七、全局约束层 + 镜头匹配

在提示词中单独设一段全程有效的「防 AI 味」硬约束（见下方结构骨架第 3 段），必须包含：

- 全程放松的部位清单
- 幅度上限、持续时间上限
- 复位要求（动作后回到松弛状态）
- 禁止清单（哭戏式表情、皱眉、八字眉、表情扭曲、多部位同时大幅运动等）

并让镜头服务于表演：

- 景别与焦点要能承载毫米级微动作（浅景深、焦点死锁面部）。
- 镜头运动克制，避免用大动态运镜抵消微表情。
- 机位与前景设计不得遮挡面部微动作。

## 提示词结构骨架（输出模板）

按以下五段组织，顺序固定：

1. **人物与基础设定**——外观锚定 + 真实肤质要求（毛孔、纹理，不做柔光修饰）。
2. **氛围与画质**——光影、色调、质感基调（胶片颗粒、灰阶过渡、空气感）。
3. **表演基调**——全局微表情硬约束 + 禁止清单（原则七的落地段）。
4. **运镜规则**——景别、焦点、镜头数量、机位、是否一镜到底。
5. **分镜脚本与时间线**——按秒分段，每段 = 事件 + 肌肉级微表情链 + 台词与触发 + 回落。

第 5 段每段的内部写法：

```
▶ 〔起-止〕秒 · 〔段落名〕
〔事件：发生了什么，含环境与光位〕
〔微表情链：≥2 个部位的先后动作，全部量化〕
〔台词与触发：逐词标注触发点；无台词则写沉默区间的生理内容〕
〔回落：动作如何归零、何时恢复松弛〕
```

## 落稿自检清单

落稿前逐条核对，任一条不通过就回去改：

- \[ \] 是否还残留任何情绪名词？
- \[ \] 每个情绪是否拆成了 ≥2 个部位的顺序动作？
- \[ \] 是否所有程度词都换成了数字？
- \[ \] 是否有至少一处单侧化或未完成的中断？
- \[ \] 是否有至少一处矛盾共存并标注了同时 / 相继？
- \[ \] 高强度情绪是否配了抑制动作与复位时间？
- \[ \] 情绪是否有递进而非单点爆发？
- \[ \] 台词是否拆到词级并带出说完后的余韵？沉默区间是否也有内容？
- \[ \] 是否存在全局约束段与禁止清单？
- \[ \] 景别与焦点能否承载所写的最小动作尺度？

## 使用方式

1. 先按结构骨架第 1–4 段搭好人物、氛围、表演基调、运镜。
2. 把用户给的剧情 / 台词按时间轴切段，逐段套用第 5 段模板。
3. 每段写完后立刻对照自检清单逐条核对。
4. 全篇写完后，再整体检查一次情绪链递进与全局约束是否贯穿全程。
