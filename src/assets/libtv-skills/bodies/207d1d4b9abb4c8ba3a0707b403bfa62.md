# 古风短剧全流程成片

本 Skill 属于**流程编排器**：输入一份短剧剧本，按固定工艺一条龙产出「脚本表 → 角色三视图 → 分镜关键帧 → 分镜视频（接力串联）→ 智能剪辑成片」，**每个阶段的产出都保留在画布上**，便于中途检查与单点返工。

原画布样例：《灯语》（夜·桥头，阿晚 16 岁机灵小绣娘 / 沈先生 20 岁温文书生，8 镜）。

---

## 一、输入槽位（换剧本时会变的部分）

| 槽位 | 说明 |
|---|---|
| `{{剧本文本}}` | 一段短剧剧本：人物表（姓名 + 年龄 + 身份 + 造型特征）+ 分场动作与台词拆分 |
| `{{角色表}}` | 每位角色的简称与造型要点，用于三视图 prompt |
| `{{镜头数}}` | 原画布为 8 镜；剧本短则 6 镜、长则 10 镜均可 |
| `{{画风关键词}}` | 原画布统一为「古风写实电影质感」；可替换为其他统一画风 |
| `{{场景与光线基调}}` | 原画布为「深蓝夜色 + 暖黄河灯对比」，全链路复用同一套光线基调 |

## 二、固定工艺锚点（不要改的部分）

1. **三视图规范**：正面 / 侧面 / 背面并排、纯白背景、三个视图同一人物、五官发型服饰完全一致、等高站立、双臂自然张开、全身中性站姿、柔和均匀打光、角色设定图风格。 → 这是全链路角色一致性的唯一锚点。
2. **关键帧 prompt 模板结构**：`画风基调 + 场景。角色形象严格参考三视图 {{对应角色三视图节点}}（角色名 + 一句话造型）。画面：<该镜动作/表情/台词>。<光线与背景>。{{画风关键词}}，<景别>，<景深/构图>。`
3. **双人镜必挂两张三视图**：同框镜头必须同时连上两位角色的三视图节点，prompt 里逐一写明"角色形象严格参考三视图 {{A}}（阿晚）与 {{B}}（沈先生）"，并在画面描述中分别交代两人的动作。
4. **视频接力工艺**：第 1 镜视频只由本镜关键帧生成；第 2 镜起，每个视频节点同时接收「本镜关键帧 + 上一镜视频」两个输入，用上一镜视频保证动作与机位接续。禁止把全部关键帧一次性丢给一个视频节点。
5. **顺序化剪辑**：全部视频按镜号顺序接入同一个智能剪辑节点，再输出成片节点。
6. **收尾镜为空镜 + 渐黑**：末镜不含正面人物，以景物特写收束，画面缓缓隐黑。
7. **落地层保真**：三视图 / 关键帧 / 视频 / 剪辑各节点使用的模型名与采样参数，必须与你在原画布上实际使用的一致（本 Skill 不写入未经确认的模型名，见第六节）。

---

## 三、执行步骤

### 阶段 1：剧本 → 脚本表
1. 新建文本节点，粘贴 `{{剧本文本}}`。
2. 用「脚本生成器」类节点（脚本表）读取剧本文本，产出一张按镜号拆分的脚本表（原画布为 8 行，对应 8 镜）。
3. **脚本表纪律**：每行只对应一镜，写明镜号 / 景别 / 人物 / 动作 / 台词；双人镜与空镜要在行内标清。

### 阶段 2：角色三视图（数量 = 角色数）
对每位角色各建一个角色三视图生成节点：
- 阿晚类（少女主角）：`古风角色「{角色名}」标准三视图（正面、侧面、背面并排），纯白背景。{年龄 + 身份}，{脸型/眼睛/发型/发饰}；身穿{内层}，外罩{外层}，{纹样与配色}，下穿{下装}。三个视图同一人物、五官发型服饰完全一致，等高站立、双臂自然张开、全身中性站姿。{画风关键词}，柔和均匀打光，角色设定图风格。`
- 沈先生类（男性配角/主角）：同上结构，替换为「面容清俊温润，剑眉星目，黑色长发束成高髻、戴金色雕花发冠；内穿…外披…腰系…」。
- 三视图节点可以同时接收「剧本文本」作为上下文，但**必须**保证其造型描述与剧本人物表一致。

### 阶段 3：分镜关键帧（数量 = 镜头数）
为每一镜建一个关键帧图节点，按第二节第 2、3 条写 prompt，并按下列依赖连线：
- 单人镜 → 只连该角色的三视图。
- 双人镜 → 同时连两位角色的三视图。
- 派生镜 → 若某镜的画面明显是另一镜的延续（原画布中的空镜收尾镜由相邻镜派生），可额外连上那一镜的关键帧。
- 每镜都写清：景别（近景 / 中景 / 双人中景 / 远景剪影 / 特写）、景深（浅景深）、构图（过肩、偏仰拍等）。

### 阶段 4：分镜视频（接力串联，数量 = 镜头数）
按镜号顺序逐个建视频节点，**串成一条链**：
1. 镜 1 视频 ← 镜 1 关键帧。
2. 镜 2 视频 ← 镜 2 关键帧 + 镜 1 视频。
3. 镜 3 视频 ← 镜 3 关键帧 + 镜 2 视频。
4. ……以此类推，直到末镜视频 ← 末镜关键帧 + 上一镜视频。
5. prompt 里写明本镜动作推进、镜头运动与情绪落点（如"接住坠落的河灯""提笔补画弯月""行礼与回礼"），并保持与关键帧一致的光线基调。

### 阶段 5：智能剪辑 → 成片
1. 新建智能剪辑节点，把**全部**分镜视频按镜号顺序接入。
2. 剪辑节点输出接到成片节点，产出最终成片。
3. 验收：成片时长 ≈ 各镜视频之和，镜序、人物服装与光线在镜头间连续，无跳帧断裂。

## 五、阶段验收标准

- **脚本表**：行数 = 镜头数，每行镜号 / 景别 / 人物 / 动作 / 台词齐全。
- **三视图**：每位角色一张，三视并排、纯白背景、姿态与服饰在三视间一致。
- **关键帧**：每镜一张；双人镜中两人形象都能追溯到对应三视图；光线统一为同一套基调。
- **视频**：每镜一段；相邻段的人物动作、机位、光线接得住。
- **成片**：镜序正确、节奏连贯、末镜空镜渐黑收尾。

## 六、待补充项（运行前请先补齐）

- **模型与参数**：原画布的节点信息中未携带可确认的模型名、尺寸、生成数量、时长等取值，本 Skill 未写入任何猜测值（避免在别的画布上跑出与原画布不一致的结果）。请按你原画布实际使用情况补齐：图像节点（三视图 / 关键帧）模型与尺寸、视频节点模型与时长、智能剪辑参数。
- **未接入链路的关键帧**：原画布中「分镜 #5 / #6 / #7」三张关键帧没有连出视频节点，暂按备用镜头处理；若它们本应参与接力，需要在阶段 4 里补上对应视频节点。

## 七、可迁移到的其他剧本

换剧本时只需要替换：剧本文本、角色表（数量可大于 2）、镜头数、画风关键词、场景与光线基调；第二节的七条锚点保持不变。角色超过 2 人时，同框镜头按同框角色数挂等量的三视图。
