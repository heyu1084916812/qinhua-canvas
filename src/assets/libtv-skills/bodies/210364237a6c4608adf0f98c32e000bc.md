# 即梦漫剧提示词生成

## Overview

将 AI 漫剧剧本拆分为即梦（字节跳动 Seedance）可用的分段提示词。每个分段包含：角色绑定、场景描述、目前状态、核心设定、核心需求（含镜头语言 + 时间轴）。

---

## 优先级金字塔（规则冲突时按此裁决）

```
L0（铁律）── 台词完整保留、原文对照完整性
   ↓ 永不妥协
L1（核心）── 时长 ≤15秒、绑定区正确、镜头不参与演绎
   ↓ 必须遵守
L2（质量）── 微表情选择适当、运镜合理、跨段一致
   ↓ 尽量做到
L3（参考）── 字数限制、检查清单
   ↓ 弹性执行
```

当规则冲突时，L0 压倒一切规则。L1 的规则遇到 L0 时让路。

---

## 工作流程（5 步约束链）

### 步骤 0：询问生成要求

每次触发 skill 必须先向用户确认：

1. 核心设定是否需要修改（默认值见下文）
2. 有无补充需求

### 步骤 1：读剧本 + 人物关系分析

理解场景、人物、戏剧节奏。建立人物关系与空间层次模型。详见 `references/人物关系分析模板.md`、`references/空间层次示例库.md`、`references/动态变化追踪表.md`。

### 步骤 2：分段 + 绑定区分配

根据对话轮次、动作节点、情绪转折判断分段数（一集通常 7-12 段）。每段绑定区动态生成：

- `@图片1`：当前场景描述
- `@图片2` 起：按优先级（主角→重要配角→跨段物品→特殊元素）绑定
- 群众角色不绑定，统一提供风格参考图
- 剧本没有的元素不绑定

详见下方"绑定区"章节。

### 步骤 3：逐段生成内容

对每个分段：

3a. 生成 `【原文对照X】`：逐字保留本段原始剧本 3b. 生成绑定区并整合到 `【分段X-时长评估X秒】`3c. 生成"目前的状态"：上一段结尾的静态定格画面 3d. 生成"核心需求"：从起点出发推进剧情

- 台词原文逐字保留（L0 铁律）
- 动作描写一次性写完整，不依赖括号补充
- 根据类型识别（对话/动作/情感/揭示/过渡/特效）选择优化方向
- 从 `references/微表情数据库.md` 选取微表情融入正文
- 从 `references/运镜体系参考.md` 选取运镜+景别+视角，分散嵌入

3e. 使用约束链校验（详见下方"约束链"章节）

### 步骤 4：脚本辅助校验

生成完成后，运行以下脚本：

```
python scripts/verify_output.py 输出文件.txt --original 原文文件.txt
python scripts/check_forbidden.py -f 输出文件.txt
```

根据输出修正问题，确认后再交付。

### 步骤 5：输出

一次性输出完整提示词文档。段落间以 `---` 分隔。

## 约束链（字数 ↔ 时长 ↔ 拆段）

这是整个 skill 的核心机制，替代了旧版中分散在多处的"先写内容再填时间轴"规则。

### 执行步骤（按序执行，不可跳过）

```
Step A: 写完整段内容（台词+动作+运镜+微表情）
   ↓
Step B: 字数 ≤ 500？
   ├─ 是 → 进入 Step C
   └─ 否 → 在自然断点处拆分 → 返回 Step A
   ↓
Step C: 运行 python scripts/duration_calculator.py 计算时长
   ↓
Step D: 时长 ≤ 15 秒？
   ├─ 是 → 进入 Step E
   └─ 否 → 进入时长修正流程
   ↓
Step E: 生成时间轴标记 → 完成
```

### 时长修正流程（Step D 失败时的处理）

按以下顺序尝试，每步之后回到 Step C 重新校验：

顺序修正手段限制1在该段自然断点处拆段台词不变2精简动作描述中的冗余词汇不能删动作逻辑3精简"目前的状态"描述保留核心空间关系4精简镜头指令措辞保留运镜和焦点

**铁律**：台词不能删、不能改。修正只能在台词之外的区域进行。

### 分部计算方式

```
预估总时长 = 台词时长 + 动作描摹时长（×镜头拉伸系数）

台词时长 = Σ(每句台词文字字符数 ÷ 4)
  - 文字字符：中英文+数字，不含标点
  - 例如："你到底是什么人？" → "你到底是什么人" = 7字 → 7÷4 = 1.8秒

动作描摹时长 = 分类累加
  - 简单动作（握拳、转头）：1.5秒
  - 中等动作（拔剑、冲刺）：3.5秒
  - 复杂动作（横扫、炸开）：5.0秒
  - 情绪特写（目光阴沉）：2.5秒
```

**以上计算由** `scripts/duration_calculator.py` **自动完成。**

## 绑定区规则

### 核心原则

每个分段独立发送给即梦AI，因此每段内部必须包含完整的绑定区。

### 动态生成

绑定区位于 `【分段X-时长评估X秒】` 内部、`目前的状态是:` 之前。

```
@图片1 是当前场景（随段落变化）。
@图片2 是角色A。
@图片3 是角色B。
敌方士兵风格参考 @图片4。
```

### 规则

1. `@图片1` 始终是当前场景
2. `@图片2` 起：按动态优先级绑定（主角 → 重要配角 → 跨段物品 → 特殊元素）
3. 角色直接写名，不加括号形态描述（如 `@图片2 是杨戬`，而非 `@图片2 是杨戬（持三尖两刃刀）`）
4. 群众角色不单独绑定，用"风格参考"提供统一图
5. 剧本没有的元素不绑定
6. 跨段重要物品：每段必须完整描述位置和状态，不能只写名称

### 演出分析判断标准

判断维度需要绑定不需要绑定角色出现有台词/动作/必然在画面中仅被提及但不在画面物品出现被持有/使用/可见已毁/不在场景隐含存在持有者→标志物必然存在持有者未出现

---

## 台词保留规则（L0 铁律）

1. **不能修改**台词中的任何词语、语法、标点
2. **不能概括**——无法用一句话代替多句对话
3. **不能删除**或重新设计台词
4. 引号仅用于包裹角色实际说出的对话
   - ✅ `角色A："你到底是什么人？"`
   - ❌ `"他拼命想冲过去，却被更多天兵缠住"`（动作描述不应加引号）

---

## 目前的状态（起点画面规范）

### 核心定位

"目前的状态"是上一段视频结尾的**静态定格画面**。它是核心需求演绎的起点，不是演绎本身。

### 与核心需求的分工

部分定位内容边界目前的状态起点画面镜头焦点、人物站位、空间关系、环境氛围。不含动作核心需求剧情演绎从起点出发推进剧情，不重复起点画面

### 写法规则

- 只描述"这一刻是什么样子"，不描述"这一刻在做什么动作"
- 必须包含：镜头焦点+人物分组、情绪化姿态、环境氛围
- 禁止包含：任何动作描述（冲出、劈开、下坠）、演绎性内容

### 字数指引

- 对话型：50-70字
- 动作型：60-80字
- 情感型：60-90字
- 过渡型：30-50字

## 核心设定（默认）

```
核心设定:无字幕,2D半厚涂原画风格动画、国风质感.合适的分镜景别切换。用专业动画导演的思维，运镜丰富，全部人物面部情绪表达丰富，符合剧本人物设定和剧情场景。
```

用户可在步骤 0 中修改。

---

## 跨段物品追踪规则

重要物品即使某段未提及，只要符合以下条件仍需绑定：

1. **状态持续**：物品存在状态需要跨段追踪
2. **画面逻辑**：基于空间位置，物品应仍在场景中可见
3. **剧情连贯**：物品对后续剧情有影响，需要视觉连续性

**重要**：即梦AI每段独立生成，每次提到跨段物品时必须完整描述其位置和状态，不能只写物品名称。

## 输出格式

### 文档结构

1. **场景人物关系分析**（前置分析，可选但推荐）
2. **分段提示词主体**：每段按序呈现
3. **安全检查摘要**（脚本输出）

### 单个分段结构

```
【原文对照X】
本段对应的原始剧本台词（逐字保留）

【分段X-时长评估X秒】 @图片1 是当前场景。 @图片2 是角色A。

目前的状态是: 上一段结尾的静态画面定格。

核心设定:无字幕,2D半厚涂原画风格...

核心需求：
【0到4秒】（【镜头】近景固定聚焦角色A）台词/动作内容...
    【4到10秒】（【镜头】中景切换角色B）台词/动作内容...
```

### 格式要点

- 时间轴格式统一为 `【X到X秒】`（用"到"字，不用波浪号）
- 时间轴标记后直接接镜头指令，**不换行**
- 一个时间区间可包含多个镜头
- 各时间段之和应等于分段总时长
- 段落之间用 `---` 分隔
- ID 使用 `@图片1`、`@图片2` 等占位符

---

## 镜头语言规范（核心）

### 嵌入方式：分散嵌入

每个镜头指令对应一段动作描写，镜头指令紧贴其管辖的内容。

**格式**：`（【镜头】运镜+景别+聚焦目标）动作描写`

**注意事项**：

- 镜头括号只包含"怎么拍"，不描述动作结果或情绪状态
- ✅ `（【镜头】近景固定聚焦角色A面部）`
- ❌ `（【镜头】近景特写小杨咬牙痛苦表情）`（"咬牙痛苦"是演绎内容）
- 每个镜头必须明确聚焦到具体角色或物品
- ✅ `（【镜头】中景推进聚焦角色A）`
- ❌ `（【镜头】中景推进）`

完整的运镜类型、景别体系、视角映射见 `references/运镜体系参考.md`。

---

## 微表情使用

从 `references/微表情数据库.md` 中选择微表情描写，直接融入正文。

**原则**：

- 情绪变化时才添加新描写，无变化不重复
- 强度匹配剧情激烈程度
- 用身体微动配合微表情，比单独描写更自然

---

## 违禁词处理

1. 完成核心需求内容后，运行 `scripts/check_forbidden.py`
2. 扫描核心需求文本，标记疑似违规词汇
3. 标准模式：仅标记 `【⚠疑似违禁】`，提供替换建议，由人工决定修改
4. 生成安全检查摘要

## 脚本使用说明

本 skill 包含 3 个辅助脚本，位于 `scripts/` 目录：

### 1. 时长计算器

```
python scripts/duration_calculator.py "核心需求文本"
# 或从文件读入
cat segment.txt | python scripts/duration_calculator.py
```

### 2. 输出格式校验

```
python scripts/verify_output.py 输出文件.txt --original 原文.txt
```

### 3. 违禁词扫描

```
python scripts/check_forbidden.py "核心需求文本"
# 或从文件
python scripts/check_forbidden.py -f 输出文件.txt
```

## 最终输出校验（单份清单）

输出前检查以下各项：

**必过项**：

- \[ \] 所有段头（【原文对照】、分段、目前状态、核心设定、核心需求）齐全
- \[ \] 【原文对照】逐字保留，合并后等于完整原文
- \[ \] 台词逐字保留，未删改、未概括
- \[ \] 时间轴使用统一格式（X到X秒）
- \[ \] 时长未超 15 秒（脚本验证）
- \[ \] 字数未超 500（脚本验证）
- \[ \] 每段都有绑定区（@图片绑定）
- \[ \] 跨段物品位置和状态每段完整描述
- \[ \] 段落间有 --- 分隔

**质量项**：

- \[ \] 微表情描写恰当融入正文
- \[ \] 运镜与情绪类型匹配
- \[ \] 镜头指令不包含演绎内容
- \[ \] 跨段画面衔接自然
- \[ \] 违禁词已检查并经人工确认
