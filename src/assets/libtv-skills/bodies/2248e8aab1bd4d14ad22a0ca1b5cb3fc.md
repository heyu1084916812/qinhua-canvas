# 通用1VS1打斗导演执行 Skill

## 1. 任务定位

把“双方互相挥拳、格挡、再反击”的流水账，转化为：

- 有明确剧情任务和胜负因果；
- 有清楚的实力关系、空间方向和接触结果；
- 可拆成三个独立生成、独立重抽、尾帧接力的镜头组；
- 包含特殊角度、关键特写KCU、升高镜头和大环绕；
- 能直接用于真人拍摄、动画、AI生图、AI视频或故事板生产。

核心原则：**结构可以复用，动作不能复制；先决定胜负因果，再拆三组，再设计动作和镜头。**

## 2. 适用边界

适用：

- 人物VS人物：徒手、摔投、短兵器、长兵器、枪械近距离攻防；
- 人物VS类人：兽人、机器人、异族、改造人；
- 人物VS怪物：体型差明确，但胜负仍由角色判断、弱点、场地或能力规则决定；
- 魔法／超能力VS物理或能力；
- 单主角面对单核心敌人，背景群战不得遮挡主动作。

不适用：

- 车辆追逐、空战、舰船战、大型机甲军团战；
- 多人混战、团队战术、多人轴线分配；
- 胜负主要依赖载具性能、军团阵型或大尺度航线的战斗。

## 3. 不可妥协的硬规则

 1. 每镜只完成一个主要动作，最多附带一个由主动作自然引发的表情、受力或环境反应。
 2. 每组只有一个局势任务和一种主特殊运动。
 3. 上一镜尾帧就是下一镜首帧；先继承未变化状态，再发生本镜唯一变化。
 4. 每次有效攻击必须写清：起点、方向、目标部位、应对、接触点、位移／损伤结果、策略反应。
 5. 重击后，人物身体、位置、装备、能力、环境或情绪至少改变一项。
 6. 连续攻击最多三次；第三次必须产生可复述结果。
 7. 同一种格挡连续两次后，第三次必须失效、升级或被破解。
 8. 大换位、绕背、击飞、上下层变化或180°以上环绕后，必须重新建立空间。
 9. 大环绕若跨过180°，必须保留固定空间锚点，并在结束镜确认新的画面左右。
10. 特殊角度必须提供新增信息：威压、弱点、落点、攻击路径、空间关系或心理变化。
11. 升格只用于危险察觉、关键接触、名场面结果或终结前一拍。
12. 禁止人物增殖、镜像换手、武器跳手、接触错位、身体穿模、无重力漂浮、战损恢复和特效遮挡接触点。

## 4. 必填输入参数

生成完整打斗前，必须获得或确认：

- 项目／场次；
- 画幅与介质：9:16／16:9，真人／3D／二维／游戏过场／其他；
- 总时长；
- 角色A、角色B：身份、体型、初始画面左右、面朝方向；
- 双方战斗DNA：力量、速度、技巧、防守、远程、魔法、狂暴或混合；
- 武器与能力：持手、有效距离、能力规则、资源和代价；
- 实力关系；
- 剧情功能；
- 开场观众判断；
- 最终结果与胜负原因；
- 场地、危险边界和最多3个核心可利用环境物；
- 必须出现的名场面；
- 结尾停点；
- 伤害展示等级与禁止项；
- 输出格式。

以下任一项不明确时，不直接生成完整三组打斗：**剧情功能、实力关系、最终结果、胜负原因、总时长、场地、结尾停点。**

## 5. 执行流程

严格按以下顺序工作：

 1. 用一句话写清胜负逻辑。
 2. 填写双方战斗DNA，各确定至少一个优势和一个弱点。
 3. 选择一个主战斗关系模块，最多叠加两个功能插件。
 4. 锁定初始空间、主轴线、画面左右、持手、伤势、环境锚点和危险边界。
 5. 先设计G01、G02、G03的唯一功能、局势起点、局势变化和组尾冻结状态。
 6. 为每组分配特殊镜头预算：最多一种主特殊运动、两类特殊角度、2—4个KCU。
 7. 为每个重要动作填写动作六步链。
 8. 再拆成十项单镜卡。
 9. 生成AI提示词版时，按主体、方向、持手、接触、结果、摄影机、连续性的顺序编译。
10. 通过Gate A／B／C后交付。

不得先堆招式，再反向拼剧情。

## 6. 三组镜头组结构

### G01｜危险建立与试探

建议占比：25%—30%。

唯一功能：

- 建立空间、体量、距离、武器、初始强弱；
- 完成第一次有效接触；
- 让观众形成首次胜负判断。

必须产出：

- 开头1—2镜交代画面左右、距离、持手、高低差和危险边界；
- 至少一个起点KCU和一个接触／结果KCU；
- 组尾出现后滑、擦伤、掉武器、盾裂、失衡、施法中断或策略改变；
- 不停在“双方仍在互打”。

优先镜头：虫眼贴地、极低位、武器后跟、前景遮挡、低位起升。

不建议：大环绕。

### G02｜反击换位与升级

建议占比：35%—40%。

唯一功能：

- 让一方打出有效方法并短暂占优；
- 通过规律暴露、环境触发、旧伤、能力代价或分神完成反转；
- 改写观众对胜负的判断。

必须产出：

- 至少一次明显换位、高低差变化或画面左右交换；
- 至少一次装备、伤势、体力、资源或环境升级；
- 至少一个完整中景动作镜；
- 快速剪辑后必须有结果镜或空间镜收束。

优先镜头：120°—180°大环绕、顶视、穿视、主观受击、高低差升高、接触点升高重建。

### G03｜破绽回收与终结

建议占比：30%—35%。

唯一功能：

- 回收G01或G02建立的优势、弱点、伤势、环境或心理信息；
- 完成明确胜负、中断、撤退、濒死或不杀结果；
- 收束情绪并留下钩子。

必须产出：

- 眼神／判断KCU；
- 旧伤、握持失效或资源不足KCU；
- 接触KCU；
- 不可逆结果KCU；
- 中景／全景或升高抽离确认胜负。

优先镜头：180°—270°终结环绕、超低仰、接触升格、结果抽离升高。

## 7. 主战斗关系模块

每场只选一个主模块：

- M1 力量VS技巧：力量压缩空间，技巧借力、闪避、打弱点。
- M2 速度VS力量：速度前期奏效，力量通过预判落点或破坏场地反制。
- M3 势均力敌武器战：拆招、锁武器、体力和一次错误决定胜负。
- M4 近战VS远程：围绕火力线、掩体、装填和距离缩短。
- M5 能力VS物理：先建立能力规则，再找蓄力间隙、范围边界或代价。
- M6 人类VS巨怪：体量差持续存在，人物靠距离、弱点和场地争取机会。
- M7 高手碾压：高手动作少、判断快，用最小动作化解升级攻击。
- M8 弱者拖延强敌：目标是争取时间，每次起身都付出代价。
- M9 势均力敌消耗：每轮交换消耗体力、资源、装备或旧伤。

## 8. 功能插件

最多叠加两个：

- P1 保护目标；
- P2 夺取物品；
- P3 试探身份／能力；
- P4 复仇失控；
- P5 身份暴露；
- P6 濒死救场；
- P7 环境崩塌；
- P8 主动撤退；
- P9 不杀约束；
- P10 能力代价。

插件必须改变动作决策和胜负原因，不能只作为背景设定。

## 9. 动作六步链

每个重要动作都必须形成闭环：

**起点 → 攻击 → 应对 → 接触 → 位移／损伤结果 → 情绪或策略反应**

填写标准：

- 起点：重心、距离、武器位置、哪只手、是否蓄力；
- 攻击：方向、速度、目标部位、动作幅度；
- 应对：格挡、闪避、反击、承受、借力或预判；
- 接触：具体接触点和先后关系；
- 结果：身体、位置、装备、能力、环境至少改变一项；
- 反应：人物判断、情绪或下一策略变化。

动作等级：

- 一级普通试探：2—3镜；
- 二级关键反击：4—5镜；
- 三级终结／名场面：5—7镜。

## 10. 特殊角度库

- 虫眼贴地：体量、脚步、落点、地面破坏；
- 极低位穿腿／武器下方：攻击路径、遮挡揭示、长兵器距离；
- 顶视／正俯：路线、落点、环形走位、危险边界；
- 高位斜俯：脆弱、被逼角落、高低差；
- 超低仰／下巴线：威压、终结蓄力、巨物悬顶；
- 倾斜角：失衡、眩晕、能力干扰；结果后必须拉正；
- 主观攻击／受击POV：危险逼近和反应时间；1—2秒后回客观空间；
- 过肩贴身：武器距离、视线关系、锁武决策；
- 镜面／反射角：背后信息、身份暴露、诱敌；
- 前景遮挡穿视：绕柱、救场、突然换位；
- 武器后跟视角：攻击路径、速度和目标部位；
- 旋转／滚转角：摔投、击飞、坠落；只随受力旋转。

同一景别和角度连续不超过三个镜头。

## 11. 关键特写KCU系统

五类KCU：

1. 意图KCU：眼神、呼吸、脚尖、握拳；
2. 起点KCU：握持、扳机、剑柄、盾带、施法手势、旧伤发力；
3. 接触KCU：拳面、刀锋、盾缘、腕部、关节、能力命中点；
4. 结果KCU：盾裂、刀口缺损、手指松开、弹匣掉落、血痕、地面裂纹；
5. 情绪KCU：恐惧、识破、绝望、冷静、克制不杀。

密度规则：

- 连续KCU不超过3镜；
- 两次接触／结果KCU后必须回中景或全景；
- 一个爆点最多1个接触KCU＋1个结果KCU＋1个情绪KCU；
- 眼神KCU必须在下一镜兑现动作或判断；
- 伤势和装备KCU一旦出现，后续必须保持或合理加重；
- AI生成KCU只保留单一主体和单一接触对象。

## 12. 升高镜头规则

### 低位起升

从脚步、武器、伤势或接触点垂直升到胸口、脸或双人全身。用于登场、蓄力、伤势揭示和高低差建立。

### 跟随升高

角色跃上高台、被击飞、被托起或攀升时，摄影机保持相对距离向上跟。必须交代物理支撑和落点。

### 接触点升高重建

从裂开的护臂、盾面、落地武器或地面裂纹升至双人全景，确认新位置、画面左右和环境变化。

### 结果抽离升高

结果先成立并停顿，再从近／中景缓升拉开，确认胜负、场地破坏和人物孤立感。

禁止边升高边大环绕。两者同时需要时拆成相邻两镜。

## 13. 大环绕规则

- 120°小环绕：关系改变但不完全翻轴；适合绕柱、锁武、短占优；
- 180°大环绕：完成优势翻转和画面左右交换；
- 240°—270°终结环绕：从败者／接触侧绕到胜者正面或结果侧，揭示终结和反应。

大环绕只用于动作相位稳定的节点：锁武、缠斗、蓄力、绕柱、上下层交错。

拆镜范式：

1. 起始中景建立双方关系、轴线和空间锚点；
2. 环绕镜只完成环绕和一次稳定动作相位，不叠加多次攻击；
3. 接触KCU明确命中／格挡位置；
4. 结果中景／全景或升高抽离确认新方向、位移和结果。

每80°左右应揭示一项新信息。全场通常只保留一次240°—270°终结环绕。

## 14. 空间与连续性锁

开场六项空间锁：

- 角色A初始位置；
- 角色B初始位置；
- 双方面朝方向；
- 主轴线；
- 武器持手；
- 环境锚点与危险边界。

八项连续性锁：

1. 姿态与身体朝向；
2. 相对位置与画面方向；
3. 视线与表情；
4. 口型与声音；
5. 左右手与道具；
6. 接触与受力；
7. 服装、伤口、毛发、护甲与破损；
8. 灯光、环境运动和关键声音。

连续性红线：

- 人物从画左被击飞到画右，后续不能仍从画左起身；
- 武器脱手必须有落点，重新取得必须有路径和时间；
- 右腿受伤后不能无说明高速冲刺；
- 盾裂、刀口缺损、护甲凹陷、环境崩塌不能在下一镜恢复；
- 大环绕结束后下一镜必须继承新的屏幕方向。

## 15. 武器与能力执行要点

- 徒手：拳脚起点、受力部位、脚步、抓握和落点；
- 短刀：持刀手、刀刃方向、控腕和躲避路线；
- 长剑／刀：剑锋路径、护手、换手、格挡接触点；
- 长枪／长矛：枪头距离、枪杆支点、近身弱点；
- 盾牌：盾面受力、盾带、下盘、裂痕和重量；
- 重锤／钝器：蓄力、落点、惯性恢复、环境破坏；
- 软兵器：起点、弧线、目标、收回路径；
- 枪械：枪口方向、弹着点、弹匣、后坐力、掩体和装填；
- 魔法／超能力：起点、路径、范围、接触、物理结果和代价。

武器切换必须由距离、损坏、伤势或策略变化触发。备用武器必须提前出现。

## 16. 环境参与战斗

环境因果链：

**动作触发 → 材质响应 → 空间改变 → 角色策略改变**

环境必须改变路线、距离、高度、视线或胜负条件。禁止只掉灰、只爆裂、只制造特效而不影响战术。

## 17. 特殊镜头强度

- S0 清晰执行：简单运动，1—2个KCU，无大环绕；
- S1 强化：每组1个特殊角度，全场1次升高或顶视，3—5个KCU；
- S2 名场面：G02或G03各可1次大环绕／升高，接触升格，4—6类特殊角度；
- S3 高风险：FPV、240°—270°环绕、滚转、复杂高低差，必须拆镜和预演。

默认采用S1；核心反转、角色出场或集尾名场面可采用S2。

## 19. AI提示词编译顺序

1. 角色身份、外观和资产版本；
2. 双方站位、朝向、画面左右和高低关系；
3. 武器持手、攻击方向、目标部位和能力起点；
4. 接触点、受力、位移／损伤结果；
5. 景别、焦段、特殊角度和摄影机主运动；
6. 伤势、装备破损、环境破坏和组间交接状态；
7. 灯光、材质、影调、成像和负面词。

提示词过长时，先删修辞，再删非核心材质，再删成像装饰。不得删除角色、方向、持手、接触点、结果、特殊运动路径和尾帧继承。

通用防崩限制：

```text
禁止人物数量增加、同一角色复制、脸型和服装变化、武器持手镜像；
禁止攻击方向前后矛盾、接触点错位、身体穿模、武器穿体、无重力漂浮；
禁止大环绕中空间锚点消失、人物瞬移、背景旋转而主体不动；
禁止升高镜头摄影机穿地、主体比例突变、落点和高低差跳变；
禁止特效、烟尘、血液和火花遮挡脸、武器、接触点和结果；
禁止切镜后伤势、破损、掉落武器、环境崩塌和道具位置恢复。
```

## 20. 三道质检门

### Gate A｜生成前

必须通过：

- 剧情功能、实力关系、结果、胜负原因、场地和结尾明确；
- 三组各有唯一节点、起始／结束状态和交接契约；
- 重要动作形成六步链；
- 画面左右、轴线、持手、伤势、环境锚点和环绕方向已锁定；
- 每组最多一种主特殊运动；
- S2／S3镜头有拆镜和安全边界。

### Gate B｜生成后

必须检查：

- 人物脸、服装、武器、持手、伤势和环境一致；
- 攻击方向、接触点、受力和位移正确；
- 大环绕后画面方向和空间锚点正确；
- 升高镜头起点、终点、高低关系和落点连续；
- 重击有可见结果；
- KCU提供新增信息，不重复同一爆点。

### Gate C｜合成前

必须检查：

- 上一镜尾帧＝下一镜首帧；
- G01建立判断、G02改写判断、G03回收因果；
- 快剪、大环绕和KCU后有结果／空间镜收束；
- 声音桥、破风、接触、呼吸、环境破坏和停顿完整；
- 前3—5秒出现危险／实力差，中段改写判断，结尾停在强结果或危险前一刻。

## 22. 最终自检

交付前逐项确认：

- G01是否建立首次胜负判断；
- G02是否真正改写判断；
- G03是否回收前文因果；
- 每5—8秒是否至少有一个可复述结果；
- 特殊角度、KCU、升高和大环绕是否提供新增信息；
- 大换位后是否有空间重建；
- 武器持手、落点、伤势、体力、装备和环境破坏是否连续；
- 名场面是否具备单一视觉记忆点；
- 结尾是否停在最强结果、最危险前一刻、克制选择或身份／关系反转。

总控句：**先锁胜负与空间，再拆三组；先写动作因果，再分配特殊镜头；先保证观众看懂，再追求角度、特写、升高和大环绕的视觉强度。**
