# 短视频口播文案生成器
## Skill 定位
- 只负责：生成短视频的口播文案（旁白/解说词），不负责画面分镜
- 纯文本输出，不调用绘图/视频模型，零额外积分成本
## 输入
- 主题（如"暗黑奇幻手游测评"）
- 平台（抖音/B站/小红书）
- 时长（如60秒）
## 内部流程和 Knowhow
- 按"钩子开头→信息展开→观点输出→CTA收尾"四段式结构
- 根据平台调整语气：抖音(短句/网感)、B站(信息密度/深度)、小红书(种草/亲和)
- 标注每段预估用时，确保总时长对齐
- 附字幕断句建议（每句≤15字便于阅读）
## 输出
- 完整口播文案（文本），含分段标注+预估用时+字幕断句
- 末尾附「文案结构模板」：本片使用的四段式结构及适用场景速查
## 自检
- 各段用时之和=总时长、每句≤15字、含CTA
## Ask User
- 主题或平台缺失时，先问再生成
