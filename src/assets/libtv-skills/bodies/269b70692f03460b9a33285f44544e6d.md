# VI 应用的提案 Mockup

## 这个 Skill 是做什么的

用户上传一张 LOGO 图片，Agent 自动分析图形和配色，判断品牌所属行业与风格调性，选取 6～9 个适合该行业的常见 VI 应用场景，生成一张国际化提案风格的全览图——多个样机场景按提案排版规范平铺在同一画面中，适合直接用于客户提案或品牌汇报。

## 什么时候用这个 Skill

- 需要向客户展示完整 VI 落地方案时
- 需要一张可直接放入提案 PPT 或 PDF 的 VI 全览图时
- 不适合用于：只需要单个场景效果图的情况（请使用「LOGO VI 样机生成器」）；需要精确贴图合成的情况

## 输入

- **必填**：LOGO 图片（支持 PNG / JPG，建议透明背景）
- **可选**：品牌风格关键词（如：高端、简约、活泼、国潮）
- **可选**：主色调偏好（如：深蓝、暖橙、黑白）

> 风格和色调为可选项。Agent 会优先从 LOGO 图形和配色中自动判断，仅在无法判断时才向用户追问。

## 执行步骤

### 第一步：分析 LOGO

**前置检查：** 如果用户未上传任何图片，立即用 `ask_parent_agent` 提示：「请上传你的 LOGO 图片（PNG 或 JPG 格式），我才能开始分析。」不继续执行后续步骤，等待用户上传后再重新开始。

接收用户上传的 LOGO 图片后，提取以下特征并记录为本次任务的 **LOGO 基准**，后续所有步骤统一引用，不得改变：

1. **行业判断**：根据图形元素、字体风格、配色组合，推断品牌所属行业
2. **LOGO 特征提取**：
   - 主色调（如：深绿色 + 米白色）
   - 图形元素（如：叶子图形、几何三角、字母组合等）
   - 字体风格（如：衬线体、无衬线体、手写体等）
   - 整体调性（如：高端 / 亲民 / 活泼 / 严肃）

**判断置信度规则：**

- 能明确判断行业和风格 → 直接进入第二步，无需追问
- 行业模糊 → 用 `ask_parent_agent` 追问：「我从 LOGO 中无法确定行业，请问这个品牌主要做什么？」
- 色调/风格模糊 → 用 `ask_parent_agent` 追问：「请问你希望样机呈现什么风格或色调？」

### 第二步：选取 VI 应用场景

根据行业，选取 6～9 个最具代表性的 VI 应用场景，覆盖以下几类接触点，确保提案图内容丰富且有层次：

类别示例场景印刷物名片、信封、文件夹、菜单封面包装/容器纸袋、包装盒、杯子、餐盒服装/配件T恤、围裙、帽子、胸牌数字/屏幕手机壳、笔记本电脑贴纸环境/陈设马克杯、雨伞、帆布包

**参考表外行业的处理：** 如果行业不在常见分类中（如宠物用品、游戏电竞等），Agent 根据该行业的典型品牌接触点自行推断合适场景，并在第三步说明选取依据。

选取原则：

- 优先选择该行业最高频出现的品牌接触点
- 场景之间应有大小、远近、材质的视觉差异，避免全部选同类物品
- 确保场景组合在一张图中排布时有视觉层次感

### 第三步：生成提案全览图提示词

基于选取的场景，生成一段用于生成提案全览图的 AI 图像提示词。

**提示词构成规则：**

- 描述一张完整的提案展示图，多个 VI 应用物品平铺排布在同一画面中
- 排版风格参考国际化品牌提案模板：干净的浅色或深色背景（根据品牌调性选择）、物品之间留有适当间距、整体构图对称或网格化
- 所有物品统一引用 LOGO 基准的主色调和图形风格，确保视觉一致性
- 不描述"将 LOGO 原样贴入"，而是描述物品呈现品牌的色彩和风格语言

**提示词模板：**

```
A professional brand identity mockup presentation sheet featuring [6～9个场景物品列举], all designed with [品牌主色调] color palette and [图形风格/调性] aesthetic, flat lay arrangement on a [浅灰/深色/米白] background, evenly spaced grid layout, international branding proposal style, clean and minimal, soft studio lighting, 8K, photorealistic
```

将生成的提示词展示给用户，并用 `ask_parent_agent` 询问： 「以上是为你准备的提案全览图方案，包含 \[N\] 个 VI 应用场景。你可以直接确认生成，也可以修改提示词或调整场景组合。」

### 第四步：生成提案全览图

根据用户确认或修改后的提示词，调用图像生成模型，生成一张提案全览图。

**生成要求：**

- 单张图，包含所有选取的 VI 应用场景，平铺排布
- 排版符合国际化提案风格：网格或对称构图、背景干净、物品间距均匀
- 所有物品统一引用 LOGO 基准，配色、图形风格与原始 LOGO 保持一致，不因物品不同而出现色调漂移
- 整体画面有品牌感，可直接截图放入提案文档
- 输出分辨率建议：2048×1536 或更高（横版，适合提案页面比例）

### 第五步：输出结果

输出生成的提案全览图，并附上：

- 图中包含的 VI 应用场景列表
- 使用的完整提示词（方便用户后续调整复用）
- 简短说明：「这张图可直接用于提案 PPT 或 PDF，建议放置在品牌应用展示页。」

## 约束与注意事项

- **输出为单张全览图**：与「LOGO VI 样机生成器」不同，这个 Skill 的产出是一张包含多个场景的提案展示图，而非多张独立效果图
- **不做精确贴图合成**：AI 生成整体场景图，LOGO 的视觉元素以色彩和风格的形式融入各物品，而非将 LOGO 文件原样粘贴
- **LOGO 一致性贯穿全程**：第一步提取的 LOGO 基准（配色、图形元素、字体风格）在提示词和效果图中必须保持完全一致，确保整张提案图的品牌视觉统一
- **排版风格固定为国际化提案风格**：网格/对称构图、干净背景、均匀间距，不做其他排版风格
- **行业判断可被用户纠正**：用户可随时告知行业有误，Agent 重新选取场景
- **提示词可修改**：用户可在第三步修改提示词或调整场景组合，修改后才生成效果图
