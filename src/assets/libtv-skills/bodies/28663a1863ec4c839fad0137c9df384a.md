# 电影全案与MV剧本生成器

## 这个 Skill 是什么

根据输入要求，系统性生成完整的电影制作全案文档或歌曲MV剧本。涵盖剧情、分镜、角色、场景、道具、技能设计，支持20+位导演/12位摄影师风格模仿、分镜配图、角色形象图、场景道具参考图，以及 MiniMax H3 视频批量生成。

---

## 触发方式与模式识别

Agent 根据用户输入自动判断模式：

模式触发词示例模式A：电影全案"写一部电影"、"生成电影剧本"、"电影策划"、"做电影分镜"模式B：歌曲MV剧本"根据这首歌写MV"、"生成MV剧本"、"MV分镜"

---

## 模式A：电影全案

### 输入

用户描述电影需求，可包含：

- 故事方向或核心概念（必填）
- 片型（爱情/科幻/动作/奇幻等，可选）
- 目标时长（可选，默认90分钟）
- 导演风格（可选，见下方支持列表）
- 摄影风格（可选，见下方支持列表）

### 输出八大模块（按顺序执行）

**模块1：需求解析与项目定位**输出：片名、类型、时长、世界观、核心概念、导演/摄影风格确认。

**模块2：完整电影剧情**输出：

- Logline（一句话概念）
- 故事大纲
- 三幕结构
- 分场剧情
- 关键场次剧本

**模块3：分镜头脚本**输出8列分镜表，每行包含：

- 镜号 / 时长 / 画面描述（含人物站位）/ 景别 / 光影 / 对白 / 音效 / 运镜

人物站位规范（写入"画面描述"字段）：

- 位置：左/中/右、前景/中景/背景
- 朝向：正面/侧面/背面、面向镜头/面向对方
- 距离：近距（亲密/冲突）、中距（对话）、远距（疏离）
- 多人站位类型：对峙型、三角型、列队型、包围型、追随型等
- 关键镜头附：人物站位俯视图（ASCII）+ 画面构图示意图

分镜配图（一镜一图）：

- 调用 image_gen 为关键镜头生成配图
- 提示词结构：景别 + 角度 + 人物站位 + 场景 + 光影 + 色彩 + 导演风格 + 胶片质感 + 画幅
- 所有配图使用相同基础提示词，确保全片视觉一致
- 图片插入对应分镜下方，标注镜号和提示词

**模块4：人物形象设计**每个主要角色输出：

- 角色卡（7维度：姓名/年龄/身份/性格/外貌/服装/气质）
- 9:16三视图角色形象图（1152×2048）：
  - 顶部1/3：正面头部极近特写
  - 底部2/3：正面/侧面/背面三幅全身视图
  - 风格：深灰纯色背景、均匀漫射白光、真人实拍电影质感、低饱和、胶片颗粒

**模块5：场景设计**每个核心场景输出：

- 场景设计卡
- 16:9横版主场景参考图（2048×1152）
  - 提示词7维度：时代背景 + 场景地点 + 空间结构（前中背三层）+ 关键陈设 + 材质颜色 + 光影视角 + 胶片质感

**模块6：道具设计**每个关键道具输出：

- 道具设计卡
- 1:1方形道具参考图（2048×2048）
  - 提示词6维度：时代背景 + 类别功能 + 形状尺寸 + 材质颜色（含磨损）+ 展示环境（深灰磨砂背景板+均匀冷光）+ 胶片质感

**模块7：技能设计（按需**）仅奇幻/科幻/动作片触发，输出：

- 能力体系设定
- 角色技能列表
- 关键对决设计

**模块8：导演与摄影风格适配**输出：视觉语言、摄影技术、叙事手法、标志性元素融入说明。

## 模式B：歌曲MV剧本

### 输入

用户提供歌曲（文件/歌词/歌曲名），可附加：

- MV类型偏好（叙事/表演/概念/舞蹈/混合，可选）
- 主角参考图（可选，用于角色一致性）
- 特定场景或动作要求（可选）

### 输出七大模块（按顺序执行）

**模块1：歌曲信息与分析**输出：风格、时长、BPM、主题、意象、情绪曲线、结构时间轴。

**模块2：MV概念定位**输出：MV类型、核心概念、视觉风格。

**模块3：角色与场景设计**输出：主要角色、核心场景、服装造型、象征意象。

**模块4：歌曲结构与画面规划**按段落（前奏/主歌/副歌/桥段/尾奏）规划：画面主题、运镜节奏、色彩光影。

**模块5：MV分镜头脚本（核心**）输出11列分镜表，每行包含：

- 时间码 / 歌曲段落 / 歌词同步 / 镜号 / 时长 / 画面描述（含人物站位）/ 景别 / 光影 / 运镜 / 特效 / 配图

人物站位规范与分镜配图规则同模式A模块3。

**模块6：视觉与特效设计**输出：调色方案、光影设计、特效说明、剪辑节奏、字幕设计。

**模块7：质量自检与交付**逐项检查清单，确认所有模块完整交付。

---

## 视频批量生成

所有分镜脚本完成后，调用 MiniMax H3 批量生成视频：

**输出物：**

- 视频文件：`shot_01_xxx.mp4`（按分镜编号命名）
- 工作流JSON：可导入 ComfyUI 调试
- 生成报告：`generation_report.json`

**视频合成**：所有分镜视频生成完成后，拼接画面并合并音频，输出完整成片。

## 使用示例

**示例1：电影全案**

> 用王家卫+杜可风风格，写一部1990年代香港的爱情电影，主角是一个失恋的警察和一个神秘的女杀手，时长120分钟。生成完整剧情、分镜、角色卡、场景设计。

**示例2：MV剧本**

> 根据《跟住做》这首歌生成MV剧本，港风变装手势舞主题，主角用我上传的图片人物，从现代装变装成80年代港风造型，副歌每句对应一个手势动作，在茶餐厅、庙街、维港等香港地标跳舞。批量生成视频。

**示例3：小说章节分镜**

> 根据我上传的《湮灭前线》小说第0001章·征召令，生成分镜头脚本，科幻战争题材，郭帆+赵小丁风格，生成角色卡和场景参考图。
