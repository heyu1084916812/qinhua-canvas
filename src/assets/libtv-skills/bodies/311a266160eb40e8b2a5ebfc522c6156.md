# 短剧成片生成器

把用户给的一段故事梗概 / 段子 / 台词，做成一条**带角色、有剧情推进的短剧（或漫剧）成片**。产出直接可用的最终成品，不需要用户再接下一步生产环节。

## 什么时候用

- 用户想把自己的故事梗概、段子或台词变成一条有角色、有剧情的短剧/漫剧成片。
- 内容偏娱乐、日常向。

## 什么时候不要用

- 严肃商业用途：品牌广告、正式宣传片、需要严谨合规审核的内容。这类需求请明确告知用户本 skill 不适用。
- 用户只想要脚本、分镜表等半成品而不需要成片时——那是流程类需求，不要用本 skill 硬凑成片。

## 工作流

### 第 1 步：收集输入

需要用户提供：

- **故事内容**（必需）：一段故事梗概、段子或台词。
- **角色设定**（可选）：主要角色的名字、外貌、性格。用户没给时，由你根据故事内容补出一份简洁设定，并在第 2 步一并给用户确认。
- **画风与时长**（可选）：如"日系动漫""写实电影感""30 秒左右"。用户没给时，默认采用与故事内容匹配的通俗画风，并在第 2 步确认。

如果用户只给了方向、没给具体故事内容，先问清楚故事讲什么，不要自己编一个故事开始做。

### 第 2 步：产出剧本 + 角色描述，等用户确认（硬性节点）

根据输入整理出**分幕剧本**和**角色描述**，一起呈现给用户：

- **角色描述**：为每个出场角色写一段**固定的文字描述块**，涵盖外貌、发型、服装、配色、气质等所有影响形象的特征。这段描述一旦确认，全片不再改动。
- **分幕剧本**：每一幕的场景、出场角色、画面内容、台词/旁白。

把这两份内容完整呈现给用户，**明确等待用户确认**。用户说 OK 之前，不要开始生成任何画面。

用户提出修改时，改剧本或角色描述并再次确认，直到用户明确同意。若角色描述被修改，视为全片基准变更，后续所有幕都按新描述走。

### 第 3 步：逐幕生成画面（靠固定文字描述锁定角色一致性）

按剧本顺序逐幕生成画面。**角色形象必须前后一致，不能换脸**，通过固定文字描述来保证：

- 生成每一幕画面时，把该幕出场角色的**固定文字描述块原样、完整地**写进画面提示词，不要改写、精简或换同义词——任何措辞变化都可能导致角色形象漂移。
- 角色描述块在全片所有幕中保持逐字一致，不允许"这一幕写得细一点、那一幕写得简一点"。
- 如果某一幕生成出来角色明显走样（换脸、换装、配色突变），重做该幕，不要将就使用。

### 第 4 步：配音与字幕

- 按台词/旁白生成配音，区分不同角色的音色。
- 生成与配音对齐的字幕。

### 第 5 步：合成成片

把各幕画面、配音、字幕按剧本顺序合成为一条完整视频，输出给用户。

## 槽位与锚点

**可替换（槽位）**——随每次任务变化：

- 故事内容、角色描述内容、画风关键词、时长、配音音色。

**固定不变（锚点）**——每次都必须遵守：

- 第 2 步的剧本与角色描述确认节点：用户确认前不得开始生成画面。
- 角色一致性靠固定文字描述锁定：每个角色的描述块逐字一致地出现在全片每一幕的提示词中，不改写、不精简。
- 全片画风、色调统一。
- 最终产出是一条完整成片，不是脚本或素材片段。

## 完成标准

- 剧本与角色描述经过用户明确确认。
- 所有出场角色的描述块在全片逐字一致，无换脸。
- 全片画风、色调统一。
- 输出为一条可直接观看的完整短剧/漫剧成片，含画面、配音、字幕。
