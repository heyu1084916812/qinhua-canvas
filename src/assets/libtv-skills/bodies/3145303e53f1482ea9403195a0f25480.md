精修 Skill\
Skill 名称\
high_end_refine\
Skill 目标\
对用户提供的图像进行高质量精修，在保留主体结构、识别特征和整体构图的前提下，重点优化：\
• 材质质感\
• 光影结构\
• 明暗层次\
• 场景融合感\
• 商业摄影高级感\
该 skill 的重点不是“把表面修得更亮更细”，而是让画面看起来像真实重新布光后的成片。\
￼\
适用场景\
适用于以下类型的精修任务：\
• 产品图精修\
• 家居场景图精修\
• 电商海报图精修\
• 品牌视觉图修正\
• 宠物/人物/产品与环境融合优化\
• 局部重绘后的统一修整\
￼\
核心原则

1. 保留主体不变\
   • 不改变产品外形、结构、比例、主要识别特征\
   • 不随意改动主体颜色、款式、关键细节
2. 材质与光影同步修\
   • 不能只提升材质，不处理光影\
   • 不能只抛光表面，不重建明暗关系\
   • 材质、反射、高光、阴影必须统一
3. 重塑真实光照\
   • 明确主光方向\
   • 补足环境光和反光\
   • 调整阴影层次和边缘虚实\
   • 增强体积感、空间感、纵深感
4. 让主体融入场景\
   • 主体不能像贴上去的\
   • 必须有接触阴影、环境反光、空间透视和统一色温\
   • 背景光线和主体光线要一致
5. 商业成片感优先\
   • 高级、干净、自然、真实\
   • 避免过度锐化、过度磨皮、塑料感、廉价滤镜感\
   • 避免平光、死白、死黑、悬浮感\
   ￼\
   输入内容\
   可接收以下信息：\
   • 原图\
   • 精修目标\
   • 参考风格\
   • 是否保留构图\
   • 是否保留主体颜色\
   • 输出用途（海报 / 电商 / 详情页 / 社媒）\
   ￼\
   处理流程\
   第一步：识别主体\
   判断图中核心主体是什么，确认必须保留的特征。\
   第二步：分析现有问题\
   重点检查：\
   • 材质是否真实\
   • 光源是否统一\
   • 阴影是否合理\
   • 主体是否悬浮\
   • 背景是否干扰主体\
   • 色温是否冲突\
   第三步：重建光影\
   对画面进行统一布光思路：\
   • 重新明确主光方向\
   • 加强高光与暗部层次\
   • 增加环境反光\
   • 修正阴影边缘\
   • 提升空间真实感\
   第四步：统一材质与场景\
   让材质表现和场景光线一致，避免局部过修：\
   • 金属不过曝\
   • 织物不过糊\
   • 塑料不过亮\
   • 木材不过脏\
   • 玻璃不过假\
   第五步：输出商业化效果\
   整体成图要具备：\
   • 高级感\
   • 干净感\
   • 真实感\
   • 品牌感\
   • 场景融合感\
   ￼\
   精修关键词\
   可优先使用以下方向：\
   • 重新布光\
   • 调整明暗关系\
   • 优化主光方向\
   • 增加环境反光\
   • 增强阴影层次\
   • 加入轮廓光\
   • 柔化投影边缘\
   • 提升空间纵深感\
   • 统一色温\
   • 增强真实感\
   • 高级商业摄影感\
   • 电影感布光\
   • 真实接触阴影\
   • 体积感\
   • 空气感\
   ￼\
   需要避免的方向\
   以下情况不要出现：\
   • 只修材质不修光影\
   • 过度磨皮或过度锐化\
   • 平均打光\
   • 背景死白\
   • 阴影过黑\
   • 反光假亮\
   • 主体悬浮\
   • 风格化过强导致失真\
   • 场景和主体光线割裂\
   ￼\
   推荐输出风格\
   根据任务，可偏向：\
   • 高端电商图\
   • 品牌广告图\
   • 家居杂志感\
   • 生活方式摄影感\
   • 极简商业摄影感\
   ￼\
   输出要求\
   最终结果应满足：\
   • 主体保真\
   • 材质升级\
   • 光影统一\
   • 场景融合\
   • 画面高级自然\
   • 适合直接商用\
   ￼\
   简洁版 Skill 定义\
   如果你想做成更短的系统 skill，可以直接用这个版本：\
   Skill 名称： high_end_refine\

   原则： 保留主体结构与识别特征，统一光源方向与色温，增强真实阴影、接触阴影和环境反光，避免悬浮感与过度修饰。\
   目标： 输出具备商业摄影质感、真实空间感和高级品牌感的成片。
