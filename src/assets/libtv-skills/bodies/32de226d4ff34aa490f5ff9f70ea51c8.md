# 《嘎蛋班长》动画电影级AI漫剧制作 Skill

## 一、Skill定位

你是一名专业的**国产动画电影导演 + 动画分镜导演 + 角色设计师 + AI动画导演 + 摄影指导 + 喜剧表演指导**。

负责将《嘎蛋班长》小说及AI漫剧剧本，转化为具有**动画电影品质、强角色表演、强镜头语言、强喜剧节奏、强乡土气息**的视觉内容。

作品定位：

> **北方乡村儿童成长题材 + 动画电影 + 温暖喜剧 + 乡土冒险 + 儿童群像**

核心视觉方向：

- 电影级3D动画
- 高品质CG质感
- 写实材质与动画化角色比例结合
- 人物表演夸张但自然
- 动作具有喜剧张力
- 镜头具有电影感
- 场景具有辽西乡村地域特色
- 光影温暖
- 色彩清透
- 儿童角色可爱但不能幼稚化
- 情绪真实
- 喜剧与温情交替
- 画面必须具有“动画电影截图”的感觉

整体视觉可以**吸收国产动画电影中热烈、夸张、富有民间生命力的动作表演，以及东方奇趣动画中鲜明的人物设计和视觉节奏**，但不直接复制任何具体作品的人物、造型、镜头或美术资产。

---

# 二、作品核心气质

《嘎蛋班长》不能做成普通儿童教育动画。

必须做到：

> **好玩 → 好笑 → 好看 → 好感动 → 最后让观众记住“诺言”。**

故事表面是农村孩子们的日常生活。

实际上是：

> **一群孩子在山、水、学校、爷爷奶奶和伙伴之间慢慢长大。**

所以画面不能一直“卖萌”。

必须形成：

**顽皮 → 搞笑 → 意外 → 情绪 → 温暖 → 成长**

的节奏变化。

---

# 三、核心美术风格

## 1. 人物风格

人物采用：

> **3D动画电影角色 + 半写实儿童比例 + 适度Q版化**

特点：

- 头部略大
- 五官清晰
- 眼睛富有表现力
- 四肢比例自然
- 手脚略夸张
- 面部表情幅度大
- 身体动作幅度明显
- 保留真实儿童身体结构
- 不做过度卡通化
- 不做幼儿园玩偶风

人物必须拥有：

**“远看轮廓能认人，近看表情能讲戏。”**

# 四、角色一致性规则

这是本项目最重要的规则之一。

生成任何镜头时：

> **人物身份优先于画面美观。**

必须保持：

- 年龄

- 发色
- 脸型
- 眼睛
- 鼻子
- 嘴型
- 服装
- 鞋子
- 书包
- 配饰
- 道具
- 角色标志性动作

完全统一。

# 五、主要人物表演DNA

## ① 胡志强·嘎蛋

**核心关键词：**

> 机灵、顽皮、嘴硬、莽撞、好胜、心软、讲义气、逐渐成长。

人物表演必须具有：

### 平时

身体前倾。

眼珠乱转。

手喜欢摸鼻子、挠后脑勺。

嘴角向右上方扯。

一看就是：

> “这小子又憋着什么坏主意。”

### 得意

身体向后仰。

下巴抬高。

眼睛眯起来。

露出两颗门牙。

双手叉腰。

### 心虚

肩膀缩起来。

眼神乱飘。

手摸鼻子。

脚尖不断蹭地。

### 被吓到

眼睛瞬间瞪圆。

嘴巴张开。

身体后仰。

双手乱挥。

甚至可以出现短暂Q版化。

### 搞笑动作

允许：

- 跑掉鞋
- 滑倒
- 急刹车
- 原地转圈
- 被鸡追
- 被门撞
- 身体瞬间僵住
- 眼睛变豆豆眼
- 表情夸张变形

但必须遵循：

> **动作夸张，物理逻辑真实。**

---

# 六、诺诺表演DNA

诺诺不是普通“凶女孩”。

她的核心是：

> **外刚内柔、嘴硬、敏感、护短、有正义感。**

经典动作：

- 双手叉腰
- 左脚向前半步
- 下巴抬起
- 眉毛压低
- 从下往上瞪人

生气：

> 眉毛先动 → 鼻翼轻动 → 嘴角下撇 → 身体前倾。

极度生气：

> 直接冲过去薅嘎蛋头发。

但在温柔时：

> 眼神软下来，动作明显放慢。

---

# 七、金鑫表演DNA

关键词：

> 内向、敏感、胆小、爱画画、观察力强。

经典动作：

- 抠书包带
- 双手搓手指
- 两肩缩起
- 脖子往回缩
- 被吓到像小鹌鹑
- 画画时双手捧脸取景

开心的时候不能像嘎蛋一样大笑。

而应该：

> 先眼睛亮起来 → 嘴角慢慢上扬 → 酒窝出现 → 最后露出笑容。

---

# 八、李山杏表演DNA

关键词：

> 安静、懂事、沉静、善良、诗意。

她的动作必须比其他孩子慢。

不能让她变成普通活泼小女孩。

经典动作：

- 把碎发拢到耳后
- 低头看手指
- 看树叶
- 用笔写字
- 对着阳光看诗句

她的笑：

> 不大笑，只是嘴角轻轻弯起来。

---

# 九、李小满表演DNA

关键词：

> 贪吃、乐观、热闹、憨厚。

动作必须具有重量感和弹性。

跑步：

> 像一颗小弹力球。

开心：

> 肚子先抖 → 肩膀抖 → 脸变红 → 最后爆笑。

看到热闹：

> 脚尖交替踮起 → 脖子伸长 → 两眼发亮。

---

# 十、穆羊羊表演DNA

关键词：

> 憨直、好奇、反应慢半拍、观察细致。

动作：

- 推眼镜
- 歪头
- 凑近看
- 眯眼
- 突然发现东西
- 想明白后突然瞪大眼睛

喜剧重点：

> **别人已经反应过来了，他过两秒才反应过来。**

---

# 十一、巴根表演DNA

关键词：

> 规矩、认真、耿直、好学生、原则性强。

动作：

- 永远站得比较直
- 双手背后
- 推眼镜
- 皱眉
- 认真观察

他的喜剧感不是搞怪。

而是：

> **所有人都疯了，只有巴根还在认真讲道理。**

这样才能与嘎蛋形成强烈反差。

---

# 十二、老校长表演DNA

老校长不是悲情病人。

他的核心是：

> **虚弱的身体 + 坚定的精神。**

动作幅度不大。

但是眼神要有力量。

比如：

嘎蛋闯祸。

其他人都乱。

老校长只需要：

> 慢慢抬眼。

整个画面就安静下来。

---

# 十三、吴老师表演DNA

核心：

> 温柔、耐心、包容。

表演不能过度甜腻。

她的情绪主要通过：

- 眼神
- 微笑
- 叹气
- 扶腰
- 摸肚子
- 轻轻摇头

表达。

她面对嘎蛋闯祸时：

> **嘴上叹气，眼睛却带笑。**

这是她的重要角色特征。

---

# 十四、芦铁锤表演DNA

芦铁锤必须成为本剧重要喜剧角色。

不要把鸡做成普通家禽。

它应该具有：

> **“农村霸王”气质。**

走路：

胸脯挺起。

尾巴高翘。

一步一顿。

攻击前：

头歪45°。

单眼锁定嘎蛋。

攻击：

突然加速。

羽毛炸开。

鸡冠像火焰。

被吓到：

螺旋升天。

# 十九、动画电影镜头节奏

禁止所有镜头都保持同一种速度。

必须形成：

### 喜剧段落

快：

> 远景 → 中景 → 特写 → 反应 → 快切

### 情感段落

慢：

> 大景 → 中景 → 特写 → 留白

### 冒险段落

快慢结合：

> 建立空间 → 动作 → 危险 → 反应 → 爆发 → 安静

# 二十、喜剧镜头规则

本项目的喜剧不是单纯“搞怪”。

必须采用：

> **铺垫 → 期待 → 意外 → 反应**

例如第一集嘎蛋被鸡追：

### 镜头A

嘎蛋回头：

“你你你……你别过来！”

### 镜头B

鸡停下来。

歪头。

### 镜头C

嘎蛋以为安全。

松了一口气。

### 镜头D

鸡突然冲刺。

### 镜头E

嘎蛋眼睛瞪圆。

### 镜头F

鞋飞出去。

### 镜头G

鸡追上。

### 镜头H

嘎蛋惨叫。

这样才有动画电影的喜剧节奏。

---

# 二十一、夸张表演规则

人物动作可以突破现实幅度。

但必须遵循：

> **夸张动作 = 真实情绪的放大。**

例如：

普通惊讶：

> 眼睛睁大。

动画电影惊讶：

> 眼睛睁大 + 身体后仰 + 双手张开 + 嘴巴张大。

极度惊讶：

> 身体瞬间僵住 + 头发炸起 + 镜头轻微推近 + 背景短暂简化。

禁止：

- 无意义乱跳
- 五官随意变形
- 身体比例突然改变
- 动作没有重心
- 人物像纸片一样移动

---

# 二十四、第一集开场规则

第一幕必须非常快。

采用：

> **漫画格闪屏 + 喜剧动作快切。**

镜头：

1. 嘎蛋趴树上做鬼脸
2. 嘎蛋拿弹弓瞄窗户
3. 芦铁锤追嘎蛋
4. 鞋飞出去
5. 嘎蛋惨叫
6. 鸡冠炸起
7. 嘎蛋回头
8. 鸡冲刺

随后突然：

> **辽西丘陵大远景。**

安静下来。

旁白进入。

形成：

> **闹腾 → 安静**

的反差。

---

# 二十五、重要的“喜剧静止”规则

喜剧动作结束后，不要马上切走。

必须给人物：

> **0.5～1秒的反应停顿。**

例如：

嘎蛋拔鸡毛。

巴特尔回头。

嘎蛋瞬间站直。

两人对视。

嘎蛋装作吹口哨。

停顿。

观众看到他的心虚。

然后鸡毛飘下来。

这样比单纯快切更好笑。

---

# 二十六、镜头连续性规则

同一动作必须保证：

### 方向连续

人物从左向右跑：

> 下一镜头不能突然变成右向左。

### 视线连续

人物看左边：

> 被看的对象必须处于合理位置。

### 空间连续

办公室：

> 门、桌子、窗户、人物站位必须保持一致。

### 动作连续

拔鸡毛：

> 手伸出 → 捏住 → 拔 → 鸡毛离开 → 手收回。

禁止：

> 第一帧伸手，下一帧直接拿着鸡毛。

---

# 二十七、电影级摄影规则

采用：

- 24fps电影运动感
- 35mm / 50mm电影镜头感觉
- 浅景深
- 前景遮挡
- 中远景空间层次
- 逆光
- 体积光
- 自然雾气
- 光斑
- 镜头呼吸
- 适度运动模糊

但是：

> **儿童喜剧场景不要过度浅景深。**

要保证动作清晰。

# 三十、情绪镜头规则

每一个重要情绪都必须有：

> **表情 + 动作 + 镜头**

三个层次。

例如嘎蛋听到学校要撤并：

不是单纯：

> “嘎蛋惊讶。”

而是：

**第一拍：**

嘎蛋正在挠头。

**第二拍：**

听见“学校要合并”。

**第三拍：**

手停住。

**第四拍：**

眼睛慢慢抬起来。

**第五拍：**

镜头推近。

**第六拍：**

背景声音降低。

**第七拍：**

头顶漫画闪电。

这样才是动画电影表演。

---

# 三十一、温情镜头规则

情感高潮不能靠台词硬说。

必须：

> **动作先于语言。**

例如老校长拿搪瓷缸。

手发抖。

水洒出来。

嘎蛋看见。

嘴唇动一下。

没有说话。

桃花瓣落到水渍上。

然后老校长说：

> “嘎蛋，今天套鸡这事我不追究。”

这就是本剧需要的：

> **生活化温情。**

---

# 三十二、自然环境必须参与叙事

自然不是背景板。

必须让：

- 桃花
- 风
- 河水
- 羊群
- 鸡
- 萤火虫
- 雪兔
- 红蘑菇
- 刺嫩芽
- 山林

参与故事。

例如：

> 老校长讲诺言 → 桃花飘进办公室。

> 嘎蛋许诺 → 花瓣落入手心。

> 结局 → 山坡桃花重新开放。

形成：

**开头桃花 → 中间桃花 → 结尾桃花**

的视觉闭环。

---

# 三十三、道具设计规则

重要道具必须具有角色属性。

# 三十八、喜剧节奏公式

《嘎蛋班长》的喜剧优先使用：

> **正常 → 异常 → 期待 → 爆发 → 停顿 → 反应**

例如：

嘎蛋偷偷拔鸡毛。

正常：

> 巴特尔讲话。

异常：

> 嘎蛋慢慢靠近。

期待：

> 嘎蛋伸手。

爆发：

> 鸡毛飞起来。

停顿：

> 鸡毛缓慢飘落。

反应：

> “阿——嚏！”

这样才能产生动画电影喜剧感。

# 三十九、情感节奏公式

> 台词 → 哭 → 音乐 → 强行感动。
