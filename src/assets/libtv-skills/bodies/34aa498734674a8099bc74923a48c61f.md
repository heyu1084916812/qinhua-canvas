# 千禧年梦核视频制作

## 核心方法论

### 1. 三维风格元素库系统

将梦核风格拆解为三个可组合的元素库,每个库对应不同场景需求:

**梦核基础库**(适用于城市/街道场景):

- 视觉标志:蓝色玻璃灰色外墙建筑、千禧年城市街道
- 氛围关键词:无人、白天、一切还在运转但没有人、胶片色调
- 禁忌元素:恐怖、诡异色调、夜晚黑暗

**夏日梦核库**(叠加夏天季节感):

- 魔幻元素:半空中游动的金鱼
- 食物道具:玻璃瓶冰镇汽水、冰淇淋、插勺子的半个西瓜、绿豆糖水
- 光影细节:晒到物品上有些曝光的阳光、大树透下来的阳光
- 动态元素:被风吹起来的白色窗帘
- 陪衬物:小鸭子、郁郁葱葱的大树

**学校梦核库**(校园场景专用):

- 建筑场景:升旗台、教室(吊扇+黑板报+布置作业的黑板)
- 商业场景:校门口小卖部、哎呀呀精品店、8+8精品店、不同颜色奶茶粉的奶茶店
- 互动细节:地上的跳格子
- 道具考据:需考据千禧年代表性零食包装(老冰棍/天天派奶糖/山楂果冻等)

### 2. 剧本化分镜逻辑(Story-Driven Shot Planning)

必须建立主线剧本,而非孤立片段堆砌。核心原则:

**代入感构建三要素**:

1. **角色锚定**:确定视角身份(小学生/中学生/青年),决定活动范围和道具选择
2. **时间线索**:建立时间流(如放学后的一天),串联场景逻辑
3. **记忆触发点**:每个场景必须对应真实童年体验(小卖部买零食、商场吹空调、QQ约集合地)

**分镜序列设计框架**:

- 起点场景(建立身份):教室放学/家里醒来
- 过渡场景(空间转移):走廊/楼梯/街道
- 核心场景(记忆载体):小卖部/商场/精品店/游乐设施
- 终点场景(情感闭环):回家/卧室开QQ

每个分镜时长5-7秒,总镜头数根据目标时长倒推(30秒短片=5-6镜头)。

### 3. 第一人称探索运镜法则

所有镜头必须遵循第一人称视角的运动逻辑:

**运镜动作词汇表**:

- 左顾右盼(环境扫视)
- 缓步向前(空间推进)
- 仰望(建筑/天空)
- 俯视(地面细节)
- 停留凝视(关键道具)

**禁止出现**:

- 第三人称上帝视角
- 快速摇晃(破坏沉浸感)
- 人物出现(除非用户明确要求并生成人物资产)

## 工作流程

### 1. 需求收集阶段(交互式问询)

按以下顺序逐步收集信息,每步等待用户确认:

**Step 1: 风格选择**提供三选项:

- 梦核(千禧年城市,无人,一切还在运转)
- 夏日梦核(+夏天元素库)
- 学校梦核(+校园元素库)

**Step 2: 视频参数确认**

- 时长:短片(30秒内)/中片(30-60秒)/长片(60秒+)
- 尺寸:16:9横屏/9:16竖屏/1:1方形
- 人物:需要(需生成千禧年服饰人物资产)/不需要(保持无人)

**Step 3: 主线剧本选择**根据风格提供预设剧本,或引导用户自定义:

- 放学后的一天(小学生):校门→小卖部→公园秋千→回家
- 放学后的一天(中学生):教室→小卖部→商场→精品店→回家开QQ
- 夏日午后:家里→老小区树荫→冰饮店→河边
- 周末探索:商场→游戏厅→录像带店→回家

**Step 4: 特别道具/场景需求**多选询问是否需要:

- 年代道具:CRT显示器、QQ界面、特定零食包装
- 居家环境:老小区楼梯间、带蚊帐卧室、客厅电视
- 商业场景:精品店、小卖部、商场中庭
- 自然场景:公园、河边、大树下

### 2. 分镜方案生成阶段

根据收集的信息生成详细分镜表,提交用户确认:

**分镜表必含字段**:

- 镜头编号(S01/S02...)
- 场景名称(教室放学/小卖部/商场...)
- 关键元素清单(道具/光线/运镜)
- 预估时长(5-7秒)

**示例**:

#场景关键元素时长S01教室放学下午阳光斜射、黑板上作业、吊扇转动、课桌书包6sS02校门口小卖部玻璃柜台、老冰棍、手写价格牌、第一人称靠近5s

### 3. 图片锚点生成阶段

必须使用**Lib Image模型**生成所有锚点图(该模型专门训练千禧年胶片质感)。

**提示词构建公式**:

```
[场景主体] + [年代标志物] + [光线描述] + [视角说明] + [氛围关键词] + [色调约束]
```

**示例**: "2000年代中国中学教室,下午阳光从右侧窗户斜射进来,黑板上用粉笔写着作业,天花板老式吊扇缓慢转动,课桌上有书包和文具盒,第一人称从教室后门向前看的视角,无人,安静,胶片感,色调偏暖不要过饱和"

**生成检查清单**:

- \[ \] 光线是否为白天自然光(非夜晚昏暗)
- \[ \] 是否完全无人(除非用户要求)
- \[ \] 年代标志物是否符合千禧年(不要出现智能手机/现代电器)
- \[ \] 视角是否为第一人称可行角度

如果某张图不符合要求,立即与用户确认是重新生成还是接受当前版本。

### 4. 视频分镜生成阶段

使用锚点图生成对应视频分镜。

**运镜提示词模板**:

- 环境扫视镜头:"第一人称缓慢左右环顾,视线从左侧扫到右侧,停留2秒"
- 推进镜头:"第一人称匀速向前走,画面中心物体逐渐放大"
- 凝视镜头:"第一人称站定,视线集中在\[关键道具\],微小呼吸晃动"

**生成后审查**:

- 是否保持第一人称
- 运动是否平滑(不抖动)
- 画面是否保持锚点图的光线和构图

### 5. 成片合成前确认阶段

在合成前询问后期需求:

**字幕需求**:

- 不需要字幕
- 需要字幕 → 二选一:
  - 场景描述式("教室" "小卖部" "商场")
  - 感受短句式("放学了" "买点什么好呢" "还记得吗")

**BGM需求**:

- 不需要BGM(保留环境静默感)
- 需要梦核风格BGM

梦核BGM特征:

- 环境音色(模拟磁带底噪/老收音机)
- 缓慢节奏(60-80 BPM)
- 简单旋律(钢琴/吉他/合成器pad)
- 怀旧氛围(模拟器预设/低保真质感)

### 6. 最终交付阶段

交付清单:

- 带BGM成片(如需要)
- 字幕时间轴文本(如需要,供剪映/PR导入)
- 所有锚点图存档
- 所有分镜视频存档

## 关键约束与质量标准

### 年代考据约束(不可违反)

**必须出现的千禧年标志物**:

- 2000-2010年流行的零食包装(老冰棍/天天派奶糖/茶娇女奶糖/山楂果冻)
- CRT显示器(非液晶屏)
- QQ聊天窗口(腾讯QQ 2008版界面风格)
- 老式吊扇(非现代风扇灯)
- 蚊帐(布质,非现代蚊帐)
- 精品店风格:哎呀呀/8+8(墙面挂满发卡贴纸)

**禁止出现的现代物品**:

- 智能手机
- 液晶电视/显示器
- 现代汽车外观
- LED灯具
- 扫码支付标识

### 光线与色调约束

**强制规则**:

- 必须为白天自然光(非夜晚/非昏暗)
- 色彩饱和度:低到中等(过饱和破坏胶片感)
- 色温:偏暖黄(模拟胶片)
- 对比度:适中(不要高对比黑白分明)

**允许例外**:

- 卧室夜晚场景可以偏暗,但需用户明确确认

### 视角一致性约束

**镜头内一致性**:

- 单个镜头内视角高度不变(模拟人眼高度1.5-1.7米)
- 运动必须符合人类行走逻辑(不能突然跳跃)

**分镜间一致性**:

- 相同场景的光线方向必须一致(如教室阳光都从右侧来)
- 相同建筑的材质/颜色必须一致

### 批次生成优化规则

**锚点图批次**:

- 单次并行生成不超过5张(避免模型负载过高导致质量下降)
- 如总镜头数&gt;5,拆分为两批生成

**视频分镜批次**:

- 单次并行生成不超过5个
- 如总镜头数&gt;5,拆分为两批生成

## 推荐工具与模型

使用 **Lib Image** 模型生成所有锚点图片,该模型专门训练千禧年胶片质感,能准确还原2000-2010年代中国城市视觉特征。

## 进阶技巧

### 记忆触发点设计方法

优秀的梦核视频应让观众产生"这就是我的童年"的代入感。设计记忆触发点的方法:

1. **身体记忆**:夏天吹电扇的凉风感、玻璃瓶汽水的冰凉触感
2. **行为记忆**:放学路上和朋友边走边聊、在小卖部柜台前犹豫选什么零食
3. **空间记忆**:老小区楼梯间的回声、商场里冷气和外面热浪的对比
4. **物品记忆**:QQ消息提示音、CRT显示器开机的"滋"声

在提示词中加入这些感官细节描述,能显著提升画面的情感浓度。

### 批量主题变体生成

如需生成系列视频(如"四季梦核"系列),可复用相同分镜结构,仅替换元素库:

- 春日梦核:樱花飘落、校服换季、操场风筝
- 夏日梦核:使用前述夏日元素库
- 秋日梦核:落叶、月饼包装、运动会
- 冬日梦核:雪地脚印、热气腾腾的关东煮、暖气片
