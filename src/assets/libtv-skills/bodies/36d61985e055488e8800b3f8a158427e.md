# **阿桃分镜·工作流（执行层）**

本Skill与姐妹Skill「阿桃分镜·视觉参考库」配合使用，生成视频时两个必须同时参照。 执行附件：《视频提示词规范增补（可灵3.0对齐版）》，优先级与本Skill同级；与本文冲突处以该附件为准。本Skill已按该附件对齐。

## **定位**

执行层。每集生成视频时必须调用。覆盖工作流程、检查清单、提示词写作规范。

## **最高原则：内容完整优先于段数/时长**

分镜按剧本真实节奏拆，该几段就几段，每段≤15秒；台词、OS、动作、留白一个不删、不赶。**段数与成片总时长不是约束，内容完整才是约束。** 红果/平台的单条时长、分几条发布，全部留到剪辑阶段再合并或分集，不在分镜阶段靠"快说/快切/删金句"压缩。

## **阿桃人物红线（4条，不可违反）**

1. 阿桃敢爱敢恨、跳脱有劲——该哭哭，该笑笑，该闹闹，这是她的性格底色。禁止的是表演式情绪：偶像剧式捂嘴哭/泪眼汪汪示弱/没原因地对镜头甜笑/明显演给摄影机看的夸张动作。咧嘴大笑完全可以有，真实情境下的咧嘴大笑就是她。一切情绪和动作都真实发生，不是表演。克制是她在压力下的选择，不是底色。
2. 眼神不直视镜头，视线看向画面内的其他人或远处。
3. 台词一字不差，不概括、不意译、不省略。
4. 淡蓝色牛仔裤（第2集起）每段提示词必写，不能丢。

## **资产准备规范**

- 生成顺序：场景图→道具图→角色图→分镜草图→视频。
- 干净分离：场景图绝不出现人物；人物图绝不带道具。
- 先盘点再补缺口：每集开始前检查锚点清单，缺什么补什么。
- 按需建立：能复用复用，能派生派生，不能复用才新建。
- 锚点拦截：涉及待确认/未生成锚点的段，禁止进入视频生成，先确认锚点。

# **核心工作流程（六步）**

## **第一步：布景情绪分析（含服装/造型连续性核查）**

每个场景必做，分析布景如何服务情绪——不是抄布景描写，而是导演思维：布景里每样东西在说什么。

**1.0 服装/造型连续性核查（每集布景前强制，先于布景描写）** 每集开布景情绪分析前，必须先查《全系列服装连续性表》（工作区 剧本/[全系列服装连续性表.md](http://xn--15q9pm26a2vg7s3appcpzxgva742c.md)），并在本集布景情绪分析文件开头固定写一节「服装连续性核查」：

1. 列出本集每个出场角色上一次出场的造型（上装/下装/鞋/发型/标志件）。
2. 先判故事内时间线再定装：
   - 同一天/同一连续事件（哪怕跨集、跨到次日清晨、连续奔波）：**必须穿同一件**，发型、随身物、汗污磨损都要接得上；中途换装即穿帮。
   - 隔了日子、换了场合（上班/回老家/相亲/婚礼/奔丧）或换季：才换装，并写出与上一次的区分点。
   - 判定依据是"剧情里过了多久、什么场合"，不是"是否相邻一集"。
3. 回家/相亲/婚礼等场合可给角色"她最好的一件"。
4. 是否新建锚点的裁决：同年份、同龄、仅换日常衣服＝复用角色锚点＋在提示词里描写服装，不新建图；只有年龄/状态跨度大（变老、憔悴、身份大变）才派生锁脸新图。
5. 每新建或派生一个角色锚点，立刻把 node_key 与造型回填《全系列服装连续性表》对应行，保持表最新。
6. 时代红线：无真实品牌logo、无超前时装、无浓妆首饰。阿桃衣服"少而重复穿"以体现穷——同一连续事件刻意保持同件；隔日子/换场合则必须能区分。

## **第二步：创作脊柱**

写清：这集情绪弧线是什么；明线、暗线分别是什么；情绪最重的落点在哪里。

## **第三步：分镜规划**

### 3.1 语速选档（按角色+场景情绪，不得直接套一个数）

先判定说话角色与场景情绪，再选语速（字/秒）：

对白：

- 阿桃·压迫感/悲伤/情绪积压：4
- 阿桃·常态叙述：5
- 阿桃·爽点/想通/笃定/轻松逗趣：6
- 长辈（爸/妈）偏慢：5–5.4
- 配角标准对白（工作人员/陌生人）：5.2
- 电话里亮快的人（如婆婆）：6

内心OS（V/O，同样按情绪分档，不要一律按最慢）：

- 悲伤/哽咽/压住的情绪：4
- 叙述、偏沉的回忆：5
- 冷静/清醒/带刺的判断：5.2
- 调侃/逗趣/穷幽默：6

台词字数 ÷ 适用语速 = 台词秒数。\
具体每镜秒数统一用 3.4 公式算；本节只负责选档。\
同一条OS若情绪在句中转变，可在自然停顿处拆到不同镜头、按各自档算，但一条台词不得拆到两个镜头念半截。

### **3.2 景别规则（竖屏强制）**

- 竖屏景别提升一档：想要全景→中景，中景→近景，近景→特写，特写→极近特写。
- 相邻两镜不得同档（中/近/特/极近，每镜跳档）。
- 不用全景，95%为中景、近景、特写。
- 竖屏人物填满画面宽度60%以上。
- 例外：表达孤独/渺小/无人注意时，允许中远景（仍非全景），人物占画面&lt;30%，此类镜头不强制提升一档。
- 竖屏补充：避免两人左右并排同时入镜，优先越肩或单人+画外音；优先垂直方向运动（起身/坐下/抬头/低头）；关键信息放画面垂直中心线；特写比横屏多停留0.5–1秒。

### **3.3 首镜规则**

每段第一个镜头不能是空镜，必须有人物或核心道具。空镜仅用于段间情绪承接，不作单段首镜。

### **3.4 分镜单元与逐镜时长核算（先定时长，再定格数）**

分镜脚本（草图）是把剧本视觉化的施工蓝图，标准栏：**镜号｜时长｜景别｜运镜｜画面内容(动作/站位)｜台词/OS｜音效/BGM｜引用锚点**。

**一镜的边界（判据）**：同一机位、同一情绪点、时间连续，即为一个镜头——一镜内允许连续动作、允许一来一回多句对白，不是"一格只能一个回合/一句词"。一旦发生机位变化、景别跳档、或情绪/攻防转折，就切镜。

**逐镜时长公式（强制，先于画草图）**：

镜头时长 = max(台词字数÷适用语速, 该镜头情绪档时长) + 该镜头独立动作的物理秒数

- 台词秒：按3.1选档——OS/对白 沉4、叙述5、冷静5.2、调侃6（长辈对白5–5.4）；只算"念完词"的时间。
- 情绪档时长（见《情绪-镜头对照表》）：压抑/隐忍、对话近景4–6s；孤独/无力中远景5–8s；等待/沉默/凝视5–8s（特殊长镜可至12s）；克制行动中近景3–4s；压住情绪不说话的侧脸3–5s；爆发瞬间极近特写1–2s；小小的胜利2–3s。
- 动作物理秒：起身/坐下/递接/转身/端放/掐跳等每个约1–2s，连做累加；无台词的留白镜也照常占秒，不得记0。
- 一个完整互动回合（A说做→B反应→A再反应）至少2.5–3s，低于此模型会吞动作。

**核算与拆段规则**：

- 每个镜头逐镜填《逐镜时长核算表》（台词秒/情绪档秒/动作物理秒三列，镜头秒=max(前两列)+动作秒），先给用户确认，再画草图，禁止只凭总字数估。
- 【零容差】逐镜核算时，每个镜头必须同时满足两条，缺一即判不合格：\
  ① 台词秒（字数÷该句核定语速）≤ 该镜头给定秒数；\
  ② 台词秒 + 该镜头独立动作/反应秒 ≤ 该镜头给定秒数（动作必须有时间，不能让台词塞满整镜）。\
  禁止用“紧”“跨镜念”“微延”“余韵靠画面”“念前半”“余句画外音收完”“声音溢出到下一镜”等任何说法让台词超出镜头秒数。\
  一条台词只能完整落在一个镜头内，不得拆到两个镜头念。\
  不合格当场二选一：㈠在该段≤15s内重新分配各镜秒数，使每镜①②都满足；㈡拆成两段（拆段即同步补一张草图、多建一个视频节点）。
- 各镜时长累加＝该段总时长；一段&gt;15秒必须拆段，禁止删金句、禁止用“快切/快说”硬压；段数不预设，核算出几段是几段。
- 【唯一基准】视频时间轴的镜头秒数与语速档，必须逐字沿用用户已确认的分镜脚本，禁止在建视频节点时自行改慢语速或压缩秒数；视频节点建完，按分镜脚本做一次“秒数对账”（每句台词字数÷该句语速 ≤ 所在镜头秒数，且动作有时间）。
- 内容完整优先：成片总时长、分几条发布由剪辑阶段决定，分镜阶段不为时长删戏。
- 核算表与最终视频段数、草图张数严格一一对应；拆段后必须补对应草图。

### **3.5 每段镜头节奏参考（默认区间，非硬指标）**

默认节奏参考：3–5秒≈1镜，6–10秒≈2–3镜，11–15秒≈4–6镜（平均2.5–3.75s/镜，源自短视频剪辑节奏）。

- 镜头数量最终服从《情绪-镜头对照表》的单镜时长：等待/沉默/凝视/孤独等长镜段，一段只有2–3个长镜也合格，不受4–6镜限制。
- 判定顺序：先用3.4公式算出每镜秒数和段总时长，镜数自然得出；本节只用于事后检查"是否过闷或过碎"，**不得用来反推必须切几镜**。对话密集段镜数可多，情绪留白段镜数可少。

### **3.6 分镜草图（生成视频前必须执行）**

每段视频生成前必须先出分镜草图，用户确认构图与动作编排后，才能写提示词、生成视频。视频提示词必须把对应草图节点引用进 reference_nodes。

草图格式：

- 横版16:9画布，画9宫格铅笔线稿，黑白线条，不上颜色、不上灰度；每格内画细线9:16竖屏安全框。
- 每格对应一个镜头（一个机位状态）；同一镜头内可含连续动作与多句对白，按脚本时长给足。
- 格数跟随分镜脚本：一段有几个镜头画几格，讲清楚为准，**不必凑满9格、不设纯凑数的"补充格"**；一段镜头在一张9格里排不下时，拆成多张草图。
- 每格标运镜（推/拉/摇/跟/固定）。
- 景别特写与近景交替，禁止连续相同景别。

草图叙事规则：

- 非最后一段的最后一格：禁止收尾信号，保持动作进行中。
- 仅最后一段的最后一格：可收尾定格。

草图文字口径（与4.1一致）：道具/界面文字照常写清、不模糊；只有角色台词/OS用气泡+说话人尖角或虚线OS云标注，不做成字幕条。

Step 3.6.1 草图提示词提交前自检（运行前必过）

1. 服装复述：每个露出角色身体的格子，都在该格文字里再写一次具体服装（不只靠开头锚点行），并与《全系列服装连续性表》一致，写明"不是X、不是Y"防模型回退成熟悉款。
2. 身体边界：任何肢体接触/掐拽/跌倒，明确"隔着衣物、衣物不撩起、不露肤、动作不夸张"，默认防走光、防歧义。
3. 气泡规范：气泡内只放台词原文，禁止"人名：""OS："前缀；说话人靠气泡尖角指向＋格外线条小字标注；标点逐字对剧本。
4. OS呈现：虚线云朵、角色嘴闭合，云内只放OS文字。
5. 道具/文字：字卡、屏幕、单据文字逐字照抄；后期字卡（如"两个钟头前"）用独立黑底白字条，与台词气泡区分。
6. 格数＝该段镜头数，每格独立内容、不凑补充格；相邻景别跳档。
7. 引用齐：该段所有出场角色＋场景＋道具锚点全部挂入 reference_nodes。\
   任一条不过，不进入生成。

### **3.7 本集作业顺序（防止跳步）**

逐镜时长核算表/分镜脚本表 → 用户确认时长与段数 → 分镜草图（格数跟随镜头）→ 用户确认草图 → 先做 S1 一条视频样板 → 用户确认密度后批量做其余段。

# **第四步：提示词写作规范**

**格式要求（最高优先级）**：以视觉参考库「标准样板提示词」为格式模板，所有要素（机位/动作/声音/BGM/台词/否定排除）融合为一段连贯自然语言，禁止分模块列条目。视频内容叙事不写进提示词，只写摄影机看到的画面。

**线性顺序**：4.1强制指令 → 人声双轨 → 4.3c导演因果链 → 4.3h空间锚点卡 → 4.3d场景动态锁定 → 4.9声音设计分轨块 → 时间轴（台词绑定/声音点到/BGM融合）→ 否定排除 → 结束状态+状态账本。

### **4.1 强制开头指令（一字不差放最前）**

你是一个爆款短剧的导演，禁止使用正视图，采用侧视图35度或者45度侧拍，相邻景别之间不允许衔接，避免全景，95%的景别为中景、特写、近景，采用浅景深拍摄。禁止把角色的台词或内心独白做成字幕、文字贴进画面。场景内实物道具上本来就有的文字与记号（单据栏目线、手写笔迹、铅笔记号、屏幕界面字、后期字卡）是画面的一部分，必须清晰不模糊。 拍摄轴线必须保证不越轴，摄像机始终在人物同一侧拍摄，禁止跨越180度轴线。

### **人声双轨全局指令（紧跟4.1，每段必写）**

本片有两种人声：对白是角色当场开口、嘴唇开合发声；内心独白(V/O)是人物嘴唇闭合不动、嘴里不出声，同时画面外有她第一人称的画外音，直接发出、清晰可闻，不是静音。

### **4.2 四件套（每段必含）**

布景 + 人物 + 时间轴 + 否定排除。

### **4.3a 摄影机视角转换**

把"阿桃做了什么"转成"摄影机在哪里看到什么"。错误：「阿桃走进来」；正确：「平视，胸口高度，50mm，手持，位于阿桃右后方约1米，她走入画面左侧」。

### **4.3b 机位四参数（缺一不可）**

高度（平视/胸口/腰部/低角度）＋焦段（35mm自然/50mm标准/85mm压缩）＋距离（距人物约X米）＋运动方式（固定/随人物后退/手持跟随/弧线环绕）。 每秒必须有具体身体部位在动：不写「她走过去」，写「右脚先迈出，风衣下摆随步伐轻摆，左手小本贴着大腿」。

### **4.3b2 每镜自检（不是排版格式）**

时间轴每镜按六项自检：主体/动作/场景/镜头语言/灯光/氛围+音频。正文必须连贯散文逐秒，禁止把六项做成小标题。主体：谁 + 一致性锚点（服装/发型/手持物）。人物在本段第一次出现的那个镜头，时间轴正文里必须当场写出具体造型（服装/发型/年龄/标志件），不能只在开头人物表里写、时间轴里不写；当本集造型与角色参考图默认形象不一致时（如换了年代/场合服装），该镜头必须复述"穿什么、不是什么"，防止模型回退成熟悉款。后续镜头可简称为"穿X装的\[人名\]"。

### **4.3c 导演因果链（每段时间轴前必写）**

人物判断/目标 → 动作A → 环境/他人反馈A → 动作B → 反馈B → 最终结果。

### **4.3d 场景动态锁定（进时间轴前必写）**

前景/中景/背景各是什么；环境持续运动（吊扇转、纸角被风掀）；180°轴线摄影机在哪一侧；本段禁止出现的元素。

### **4.3e 竖屏景别**

见3.2（含孤独/渺小中远景例外）。

### **4.3f 台词执行约束（硬规则）**

1. 台词只说一次，不重复。
2. 口型与台词严格同步，嘴唇动作与字数匹配。
3. 不新增、不改写、不省略台词。
4. 每句绑定说话人：`[Speaker: 人名，情绪/音色]: "台词原文"——[其他人]不开口`。
5. 无对白镜头明确写：「无台词，仅保留呼吸与环境声」。

### **4.3g 跨段衔接**

上一段结束状态必须等于下一段开始状态（人物位置、手部/道具、服装、朝向）。每段末尾写：「本段结束状态：\[人物位置/手部/道具/朝向\]」。

### **4.3h 全局空间锚点卡（每段因果链后、时间轴前必写）**

【空间锚点 / 场景名】固定参照物；人物当前状态（阿桃位置+朝向+手持物；其他角色同）；光影基调（光源+方向+色温+氛围词）。 切近景/特写防背景穿帮：「在{{场景锚点}}场景空间的基础上，保持空间结构与光影一致，将镜头推进至\[角色\]的\[景别\]——其身后依然是\[专属背景\]，按透视自然虚化，不更改背景元素。」

### **4.3i 状态账本+全局对照**

每段写完追加状态账本（阿桃位置/朝向、手持物、服装、其他角色、关键道具）；并把全段终态汇总，检查非相邻段的手部/道具/服装漂移。

### **4.3j 多角色同框**

2人及以上独立角色互动需站位参考。**本项目默认以已确认的分镜草图作为多角色站位参考，不再单独出合成图**；仅当草图站位不清时，才先出静态合成图（reference依次引各角色锚点）、用户确认后作为首帧。单角色镜头不需要。

### **4.3k 表演锁定（有台词或重要动作的角色必写）**

\[角色\]表演锁定：不要演成\[类型化陷阱\]；要演成\[正确基调\]；动作边界\[上限\]。 阿桃通用锁定（每段按剧情选用）：不要演成偶像剧捂嘴哭/泪眼汪汪/没原因甜笑/演给镜头；要演成真实情绪，克制是压力下的选择不是底色；眼神看具体的人或物、不飘向镜头。 「憋住的节拍」（仅情绪积压/转折/被拒/想通节点加）：明确写「停顿X秒，嘴唇动或不动，呼吸变化」。纯动作过渡段不强制。一镜只放1个情绪点；眼睛必须参与情绪；动作与触发之间留0.3–1秒延迟。

### **4.3l 动作拆分**

见3.4。一镜可含连续动作与多句对白（同一机位），但一镜只承载一个情绪点/一次攻防转换，情绪或台词一旦转折即切镜。

### **4.3m 禁用抽象情绪词**

禁止「她很难过」等，换成具体身体短句（眼神失焦/下眼睑微颤/嘴唇抿住/呼吸变浅/手指扣紧等），每镜只选1–2个。

### **4.3n 动作-距离匹配**

近距离≤1米：递接、抓握、触碰、耳语；中距离1–3米：指向、正常对话；远距离&gt;3米：喊叫、挥手、远注视。距离不合理先写移动过渡再写互动。

### **4.3o 失败修复单变量**

不满意时先判失败模块（锚点/站位/道具/时序/机位/光线/表演/台词/过载），只改那一块，其余不动。同镜连续3次失败：考虑拆镜/补合成图/预建道具图。

### **4.3p 生成难度评级**

★单人无台词可直接生成；★★单人有台词注意口型；★★★两人对话先站位参考、逐句绑台词；★★★★多人互动/道具文字/快动作，道具预建、考虑拆镜；★★★★★三人以上同框或复杂互动必须拆镜。

### **4.3q 人声双轨写法**

- 对白轨：`[Speaker: 人名，情绪/音色]: "台词"`（嘴唇开合、同步发声），多人同框标清谁说、谁反应。
- V/O轨：`[V/O: 人名，画外音，嘴唇闭合不动、嘴里不出声，声音直接发出、清晰可闻，语气]: "台词"`；禁用「后期旁白/配音/不来自场景内」等致静音词；闭着的嘴要给明确可见状态；音画对齐。
- 哼歌等无词义发声归对白轨（嘴唇动）。

### **4.4 情绪信号**

用≥2个具体身体信号锁定情绪，见4.3m。

### **4.5 在场角色**

每段写清谁在画面里、谁不在。

### **4.6 文字身份锚**

每个出场人物：姓名+{{node_key}}+外貌描述+眼神不直视镜头。

### **4.7 否定排除**

有漂移风险的元素，正面描述+否定排除双写。

### **4.8 时间轴（镜头号+精确秒数同时写）**

以精确秒数为主、镜头编号为辅，禁止只写「镜头1/镜头2」让模型自定时长。统一格式「镜头1 \[0—3秒\]……」。

- 单镜常态2—6秒、一镜一个情绪点；等待/沉默/凝视/孤独等长镜按情绪-镜头对照表可至8秒、特殊12秒，不受2—6秒限制。
- 纯单动作段也写秒数；快剪段也必须镜头号+秒数齐全。

### **4.8a 时间轴自带动作与声音**

禁止只写对白。每个时间窗必须能看到：具体动作、环境动态、本窗音效(秒)、BGM(秒)、人声。【声音设计】块里每个音效/BGM要能在某镜秒数找到落点。自检：删台词画面仍有动作；关掉BGM仍有环境声/音效。

### **4.8b 排版铁律：连贯散文逐秒推进（最高优先级）**

用「0—3秒：……」的自然语言段落，把动作、环境、声音、BGM、人声融进同一句，用「接着/随后/与此同时」衔接。禁止写成「- 主体与动作：/- 场景：/- 声音：」这类分条目。六项五段式只是自检清单，正文不得出现小标题。

### **4.9 BGM与声音设计**

need_bgm：始终显式传 need_bgm:true，不依赖默认，禁止false。

**4.9a 声音密度（每镜必达标）**

- 1条持续环境床：场景给2–3种声源，写明「从第0秒到最后一秒全程持续不断、始终可闻」。
- 1条落秒点音效：由该镜具体动作触发、落到具体秒。
- 自检：任一镜挑不出"持续环境床+落秒点音效"即不合格。

**4.9b 乐器声明**：凡有BGM必写「背景音乐的＋\[乐器\]……，画面里不出现该乐器、无人演奏」。

**4.9c 声音设计分轨块（时间轴之前独立成块，四层）** 【环境床 ambient bed】…全程持续，始终可闻。 【点音效 foley/SFX】\[动作\]→\[拟声\]，远近，持续/偶发，落秒。 【人声】对白轨/V/O轨按4.3q写明。 【混音关系】写死各轨绝对音量比例（如环境床50%、V/O 80%、BGM约V/O三分之一，互不遮盖）；默认不依赖ducking。

**BGM可听见写法（有BGM段必守）**：①乐器+演奏法（如钢弦木吉他手指拨弦、单音旋律，非和弦扫弦）；②时间锚点（第几秒、配哪个动作/哪句V/O进入、拨什么）；③绝对音量（约为V/O的三分之一，清晰可辨、浮在环境床之上，不盖人声）；④只保留"不盖人声"一条，删掉"裹在风声里/几乎听不见"等多重弱化词；⑤乐器不入画。 只有分镜表明确"无BGM"才不写，且用正面写法（"本段以环境声为声音主体"），禁止"没有BGM/只有……"这类否定句。

### **4.10 对白铁律**

台词逐字还原，不概括不意译，绑定说话人口型。

### **4.11 动作五要素与三原则**

哪只手/脚、哪个部位、做什么、幅度、速度；身体部位细化+程度量化；优先慢速连续小动作；补动作过渡（借惯性/借力）。 **4.11b 禁词**：禁止"快速/fast/迅速"（易致运动模糊）；要速度感写物理细节（指尖连捻、纸页接连翻过、轮胎尖啸）。

### **4.12 文字写死**

道具该有字就有字、不模糊；台词字幕除外；需清晰呈现的文字提前建道具图并引用。**道具上的非文字记号（单据表格栏目线、铅笔记号、刮改痕、空白签字栏、缠线圈数等）与文字同等对待：该段需要观众看清的，必须在道具描述块里逐字写清内容与状态、写明"清晰可辨、不模糊、不得省略"，并引用对应道具锚点图。**

### **4.13 场景引用**

已有场景图一句话点明「参考{{node_key}}场景空间」，不重复描述。

### **4.14 禁抽象美化词**

禁止"高级感/氛围感/电影级"，改写成可拍的具体光与物。 **4.14a 灯光ROI**：每镜尽量给光源方向+色温+光质，必要时用伦勃朗光/纪录片光/黄金时段逆光带灰尘颗粒等文化词。

### **4.15 皮肤去脏（视频阶段）**

常驻声明「人物皮肤干净通透、暗部提亮不脏、肤色均匀无杂色偏色、自然肤质不油腻不磨皮」；负面词：皮肤发脏、暗部脏污、肤色斑驳、灰绿蜡黄、油腻油光、过度锐化毛孔、磨皮塑料假脸。

## **第五步：人物音色规范**

见 anchors/atao_s2_voice\_[profiles.md](http://profiles.md)，五维（音高/音色质感/共鸣位置/语速节奏/情绪语调）缺一不可。

## **第六步：完整检查清单**

**6.1.前置**：服装连续性表已查并按故事时间线定装（同一连续事件保持同件，隔日子/换场合才换装）／布景情绪分析／创作脊柱／台词按角色+场景选速换算／逐镜时长核算表已确认／草图已确认／待确认锚点全部✅。

**提示词格式**：以样板为模板／连贯自然语言非分模块／未写入视频叙事／草图节点已引用；**该段需看清的道具文字与非文字记号（表格线、铅笔记号、空白签字栏、涂改痕、缠线圈数）是否已在道具描述块里逐字写清并引用锚点图**。

**6.2.分镜**：

- 每段≤15秒；超段已按3.4拆，未删金句、未靠快说硬压。
- 有逐镜时长核算表（台词秒/情绪档秒/动作物理秒，镜头秒=max(前两列)+动作秒，留白镜也占秒）；草图张数/格数与脚本镜头一一对应。
- 镜数由3.4自然得出：对话密集段可多镜，等待/沉默/凝视/孤独长镜段2–3镜也合格；3.5仅作过闷/过碎检查，非配额。
- 一镜一边界清晰：同机位同情绪点可含连续动作与多句对白，情绪/攻防转折即切。
- 景别跳档（孤独中远景例外合理）；台词完整覆盖。
- 镜头号+精确秒数齐全（禁止只给镜号）；每镜按4.3b2六项自检。
- 连贯散文逐秒，无分条目排版（4.8b）；互动回合≥2.5–3秒，无多回合挤一镜。
- 零容差：每镜都满足 台词秒≤镜头秒、且台词秒+动作秒≤镜头秒；无“紧/跨镜/念前半/余句收完”等糊法；一条台词完整在一个镜头内；超段已拆且草图同步补齐。
- 视频秒数对账：视频时间轴的秒数与语速档逐字沿用已确认分镜，未自行改慢或压缩。

**6.3四件套**：强制开头／人声双轨／因果链／空间锚点卡／场景动态锁定／台词逐句绑定／结束状态／状态账本+全局对照。

**6.4 视觉**：机位四参数／每秒身体部位在动／负面清单针对当前场景／灯光方向色温ROI／皮肤去脏／多人人人皆动。人物首次入画镜头的时间轴正文是否当场写了具体造型；与参考图默认形象不一致时是否写明"穿什么、不是什么"。

**6.5动作情绪**：具体短句非抽象词／距离匹配／难度评级／憋住节拍（仅情绪节点）／动作三原则／无"快速"类词。

**6.6多角色**：以草图站位作参考（不清才补合成图）／表演锁定。

**6.7时间音频**：

- 时间轴格式与连贯散文正确；每窗自带动作+环境动态+音效/BGM/人声（4.8a）。
- 每镜声音密度：1条持续环境床（2–3声源）+1条落秒点音效（4.9a）。
- 有BGM：乐器+演奏法+时间锚点+绝对音量比例+只留"不盖人声"，写明「画面里不出现乐器、无人演奏」（4.9b）；need_bgm显式true。
- 时间轴前有独立【声音设计】四层块；环境床写明全程持续；混音写死绝对比例、默认不靠ducking。
- 每句V/O在本时间窗紧贴闭唇状态+"直接发声清晰可闻"语义。

**6.8 技术规格**：节点命名 EP0X-SX-内容-版本号；H3或Kling3.0；9:16；720p；need_bgm:true。

**6.9 建节点模型约定**：创建时不传ai_model（用默认seedance/star-video2建、可挂多参考图），用户生成时手动切Kling3.0。参考图严禁简化：草图+相关角色+场景+道具全部挂入reference_nodes。

**每集先出样板**：多段视频每集先只做S1一条完整时间轴，用户确认密度后再批量做其余段。

## **红果短剧导演思维（每集开始前必读）**

核心公式：真实困境 × 真实性格 × 观众代入感。

1. 钩子（前3秒命中其一）：冲突/悬疑/身份反转/情绪/视觉钩子。
2. 爽点（每集至少一个）：压迫→忍耐→想通→反击→爽点；爽点是她用自己的方式解决别人解决不了的问题，不是逆袭，爽后不炫耀；结尾留悬念；加爽点必回看情绪重力，底色乐观≠没心没肺。
3. 共鸣场景：农村女孩的窘迫，让观众"认出自己"。
4. 小确幸：不给正脸，给手/脚/道具。
5. 矛盾性格双层表达：两个镜头讲两层，不在同一镜头解释内心。

## **EP24标准段模板（唯一标准模板）**

每段分镜照此结构：开头文字口径 → 两种人声定义 → 场景锚点散文 → 环境声三层+背景音乐声明 → 逐秒镜头散文 → 结束状态。不得另立格式。

- 【开头文字口径】即4.1强制开头
- 【两种人声定义】即4.3q双轨，紧跟其后。
- 【场景锚点散文】连贯散文写阿桃在{{场景锚点}}的位置/朝向/手持物、固定参照物、主光方向色温光质、前中背景、持续运动元素、摄影机侧、禁止元素。
- 【环境声三层+背景音乐声明】环境床2–3声源全程；点音效落秒；BGM按4.9写乐器/时间锚点/音量/不入画，无BGM用正面句。
- 【逐秒镜头散文】「0—3秒：……」连贯散文，每窗融动作、环境、声音、BGM、人声；用4.3b2六项自检但不出现小标题。
- 【结束状态】人物位置/手部/道具/朝向；另附状态账本。

## **生成后定点修复表**

- 台词被错误人物说出→查4.3f说话人绑定，重写后重新生成。
- 台词丢失→查3.1语速选档与3.4拆段，重新规划时长。
- 人物位置跨段漂移→查4.3h/4.3i锚点卡与账本。
- 多角色同框脸漂移→查4.3j，用草图站位或补合成图。
- 阿桃被演成委屈/霸气→查4.3k表演锁定。
- 动作塞太多/一镜多回合→查3.4一镜一边界与时长，拆镜拆段。
- 表情假→查4.3m眼睛参与。
- 动作物理不合理→查4.3n补移动过渡。
- 整段重写仍失败→查4.3o单变量、4.3p拆镜。
- 草图末格出现收尾信号→按3.6只改该格。
- 皮肤发脏→按4.15补去脏声明。
- 背景人物僵立→补每人动作声明。
- 缺停顿/太流畅→按4.3k补"停顿X秒+嘴唇/呼吸"。
- 切景别背景穿帮→按4.3h背景绑定前置句式。
- V/O嘴在动或被静音→按4.3q在该窗补闭唇状态+"直接发声清晰可闻"。
- 环境音丢失→查4.9c四层块是否独立完整。
- 音效少/只有对白→按4.9a每镜补环境床+落秒音效。
- 画面凭空出现乐器→按4.9b补"不出现乐器、无人演奏"。
- BGM听不见/消失→按4.9可听见写法，删多重弱化词。
- 时间轴被写成字段清单→按4.8b改连贯散文。
- 各镜时长随机/动作被吞→按4.8补"镜头N\[X—X秒\]"。
- 镜头只有对白无动作声音→按4.8a补齐。
- 镜头缺灯光/场景/镜头语言→按4.3b2补全。
- 各段结构不统一→按EP20标准段模板重排。
- 出现"快速/迅速"→按4.11b改物理细节。
- 道具/界面文字被模糊或误删→按4.1/4.12写清并引用道具图，只删台词字幕。
-
