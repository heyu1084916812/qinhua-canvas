# 品牌 LOGO + 吉祥物开场动画生成

## Skill 定位

将用户提供的品牌 LOGO 分镜参考图、吉祥物形象图、字幕文案、人声音轨，通过「图片合成 × 2 → 图生视频 → 音视频合成」四步标准化流程，生成一段品牌开场标识动画视频。

**适用场景**：品牌开场、项目片头、活动标识动画。

**画面风格锚点**（固定不变，不随用户输入改变）：
- 背景：纯白
- 质感：3D 卡通
- 构图：居中
- 机位：固定，无运镜
- 主色调：以品牌 LOGO 色为主（原始案例为黑/橙/白）
- 时长：约 5 秒

---

## 用户需提供的输入（槽位）

| 槽位 | 说明 | 对应原始画布节点 |
|---|---|---|
| `[LOGO分镜参考图]` | 含品牌 LOGO 构图、背景色、字幕位置的参考画面 | i-lzrQnTkBop（分镜 #12） |
| `[吉祥物参考图]` | 品牌吉祥物形象图，用于保持角色一致性 | i-nhm3gfaq222f |
| `[字幕文案]` | 3 行以内的品牌调侃/标语文字，将出现在画面下方 | 由用户输入 |
| `[人声音轨]` | 从品牌原始视频中提取的人声音频（mp3 / wav） | a-wZtBs2C5TW（视频节点 9_人声） |

## 四步生成流程

### 第一步｜合成主体画面（图片节点 1）

**节点类型**：图片生成节点

**输入**：`[吉祥物参考图]`（参考角色形象）

**任务**：以吉祥物参考图为角色形象锚点，生成吉祥物趴在品牌 LOGO 上的合成画面。

**画面要求**：
- 吉祥物形象与参考图保持一致（颜色、造型、表情）
- 吉祥物趴伏姿态，位于 LOGO 正上方或趴在 LOGO 文字上
- 纯白背景，3D 卡通质感，居中构图

**产出**：图片节点 1（对应原始画布 i-Ud7Q38sc0R）

---

### 第二步｜合成最终定格关键帧（图片节点 25）

**节点类型**：图片生成节点

**输入**：
- `[LOGO分镜参考图]`（提供 LOGO 位置、背景、整体构图参考）
- 第一步产出的图片节点 1（提供吉祥物形象参考）

**任务**：以两张参考图为基础，合成包含「品牌 LOGO + 吉祥物 + 字幕」的最终定格关键帧。

**画面要求**：
- LOGO 居中显示，吉祥物趴在 LOGO 上
- 画面下方出现 `[字幕文案]`（3 行，依次排列）
- 纯白背景，3D 卡通质感，整体构图与分镜参考图一致

**产出**：图片节点 25（对应原始画布 i-Eg9dt9hFCn）

---

### 第三步｜图生视频——生成开场动画（动画视频节点）

**节点类型**：图生视频节点

**输入**：第二步产出的图片节点 25（作为起始帧参考）

**任务**：以最终定格关键帧为起始帧，生成开场动画视频。

**动画内容要求**（固定动作序列，不随用户输入改变）：
1. 品牌 LOGO 从画面上方下落，归位至居中位置
2. 吉祥物出现，趴上 LOGO
3. 字幕文案三行依次弹出

**画面风格**：纯白背景，3D 卡通质感，固定机位，无剪辑运镜，时长约 5 秒

**产出**：动画视频节点（对应原始画布 v-QQ3xcS8NUz 的视频部分）

---

### 第四步｜音视频合成——输出最终视频

**节点类型**：音视频合成节点

**输入**：
- 第三步产出的动画视频节点
- `[人声音轨]`（a-wZtBs2C5TW 对应的人声音频）

**任务**：将动画视频与人声音轨合成，输出最终开场视频。

**合成要求**：
- 音轨与视频时长对齐（以视频时长为准，音轨超出部分截断）
- 不添加背景音乐，仅保留人声

**产出**：最终视频节点（对应原始画布 v-QQ3xcS8NUz）

## 边界说明

- **本 Skill 只处理「LOGO + 吉祥物 + 字幕 + 人声」四要素的开场动画生成**，不处理多镜头剪辑、旁白配音生成、背景音乐合成等扩展需求。
- **人声音轨需用户自行提取后上传**，本 Skill 不包含从原始视频中分离人声的步骤（该步骤在原始画布中为独立操作，不属于本流程的可复用部分）。
- **字幕文案由用户输入**，不由 Agent 自动生成，确保品牌表达准确。
- **动画动作序列固定**（LOGO 下落 → 吉祥物出现 → 字幕弹出），如需调整动作顺序或增加动作，需修改第三步的图生视频提示词。
