# 女装搭配展示短视频生成

本 Skill 旨在将多套服装搭配图、模特参考图与背景音轨整合，生成一段约 15 秒、人物一致且卡点准确的服装展示成片。

## 适用输入
- **搭配图（6套左右）**：每套搭配一张图片，建议同一模特、同一拍摄风格与背景。
- **模特多视图**：同一模特/服装的多角度参考图，用于锁定人物与服装一致性。
- **背景音轨**：决定视频成片时长的音频文件（建议约 15 秒）。
- **主题风格**：如“通勤风”、“多巴胺风”等风格描述语。

## 操作步骤
1. **素材准备**：确保 N 套搭配图风格统一，确认音轨时长。
2. **一致性锁定**：将“模特多视图”作为参考节点输入，确保生成的视频中模特与服装特征不发生漂移。
3. **文案聚合**：所有搭配图首先汇入文本节点，生成展示顺序及对应的镜头描述文案。
4. **视频合成**：将文本节点、搭配图、多视图及音轨接入视频生成节点，设置成片时长与音轨同步。
5. **节奏对齐**：配置视频生成参数，确保镜头切换点与音轨节奏一致。

## 输出要求
- **时长对齐**：视频成片时长必须与背景音轨基本一致（误差控制在 0.1s 内）。
- **逐套展示**：N 张搭配图对应 N 个镜头，按序平铺展示，无漏图掉帧。
- **视觉稳定**：模特五官及服装细节在切换镜头时保持高度一致。

## 注意事项
- 严禁直接从搭配图跳转至视频生成，必须经过文本节点进行文案整理。
- “模特多视图”仅作为参考输入，不应直接作为视频画面镜头展示。
- 若素材风格严重不统一，应先进行风格预处理，避免硬性拼接导致效果突兀。
