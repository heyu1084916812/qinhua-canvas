# 3D霸道总裁短剧视频生成器

## Skill 定位
- 只负责：根据用户提供的**剧情文本**和**角色设定**，生成一部时长约1分钟、3D动画风格的“霸道总裁”题材短剧视频制作方案。方案包含：强冲突四幕故事脚本、15~20个快节奏分镜（竖屏/横屏适配）、每个镜头的AI 3D渲染提示词、动态运镜描述、情绪化配乐与音效剪辑计划，最终输出可直接用于AI视频生成（如Sora、Runway、Pika等）的制作文档。

## 输入
- 需要什么：
  1. **剧情梗概**（必填）：霸道总裁题材的短剧剧情描述，需包含核心冲突、情感转折或“打脸”爽点，字数建议150~300字。
  2. **男主角形象设定**（必填）：年龄、外貌特征、标志性穿搭（如黑色高定西装、银灰色头发、冷峻眼神等）。
  3. **女主角/配角形象设定**（必填）：女主角或关键配角的外貌及风格描述。
  4. **核心“爽点”或“反转”**（必填）：1~2个剧情高潮点（如“百万合同当面撕毁”、“前男友跪地求饶”等）。
  5. **场景设定**（选填）：如摩天大楼顶层办公室、私人车库、奢华宴会厅、雨夜街头等。若无提供，默认生成2个标志性场景（办公室+宴会厅）。
  6. **品牌露出需求**（选填）：若有植入需求，提供品牌名称及产品（如“XX腕表”），否则不强制。
  7. **视频比例**（选填）：默认竖屏9:16（适配抖音/Reels），可选横屏16:9。

## 输入使用
- 怎么用（哪些严格遵守、哪些只是参考）：
  - **严格遵守**：
    - **男主角形象**必须在所有含主角的分镜中保持一致（发型、服饰色系、面部轮廓特征）。
    - **核心爽点**必须在视频的第30~45秒（黄金高潮位）出现，且至少持续3秒特写镜头。
    - 总镜头数必须≥15个（1分钟快节奏短剧标准），每个镜头平均时长3~4秒。
    - 视频比例（9:16或16:9）一经确定，所有分镜构图必须适配该比例。
  - **参考使用**：
    - 剧情梗概作为叙事基线，但需按照短剧“强冲突-快反转-留钩子”的节奏进行重组，以强化“爽感”。
    - 场景设定若未提供，由Skill自动选取“总裁办公室”作为主场景，“豪车/宴会厅”作为辅助场景。
    - 品牌露出为非必须项，若有则自然地融入道具（如男主戴的腕表、使用的手机），不刻意给特写打断叙事。

## 内部流程和 Knowhow

- 故事脚本编写（霸道总裁短剧专属“三压一扬”结构）
  - **五幕式极速叙事**（1分钟极限压缩）：
    - **Act 1 - 人设碾压（0~10s）**：男主惊艳亮相（慢镜头入场），配角/反派嘲讽或质疑男主（建立冲突），往往以一句极具侮辱性的台词开场。
    - **Act 2 - 压抑蓄势（10~25s）**：男主隐忍/淡然回应，动作细节特写（如整理袖口、推眼镜、擦拭戒指），配合低沉压迫感的BGM，气氛降至冰点。
    - **Act 3 - 核心反转（25~40s）**：男主亮出底牌（展示身份/资产/权力），极速“打脸”对手。画面转为高亮、暖色调，使用快速正反打镜头强化冲突爆发。
    - **Act 4 - 情感归属（40~50s）**：男主走向女主/展现柔情一面（仅限眼神或微表情），或独自立于落地窗前俯视城市，展现孤独霸总的反差感。
    - **Act 5 - 悬念结尾（50~60s）**：留下未完待续的悬念（如电话响起、门被推开、合同最后一页亮出），黑屏出标题或品牌Logo。
  - **文案与字幕**：对话密度极高，10~15句短台词（每句2~6字），配合画面闪现，字幕使用霸气粗体字效。

- 资产锚点创作和使用（比如角色、场景、道具、音乐等）
  - **角色锚点（视觉统一核心）**：
    - 男主特征固化：如“银灰色背头+黑色双排扣西装+鳄鱼皮皮鞋+劳力士腕表”。此套组合拳在**所有**分镜中不得更改。
    - 女主特征固化：如“白色缎面长裙+泪痣+弱柳扶风的气质”。
  - **场景锚点（视觉冲击）**：
    - 场景A（办公室）：深色胡桃木办公桌、全景落地窗、雪茄柜、水晶威士忌杯。光影采用“侧逆光+暗调”，强调权力感。
    - 场景B（宴会厅/红毯）：金色水晶吊灯、红毯、香槟塔、西装革履的人群。光影采用“暖黄顶光+光斑”，强调上流社会氛围。
  - **道具锚点（爽点触发物）**：
    - 设定关键道具（如：黑卡、合同文件、手机转账界面、戒指），作为每次打脸的核心视觉载体。
  - **色彩锚点**：
    - 压抑期：黑、灰、深蓝（冷色调，饱和度低）。
    - 反转期：金、红、白（高饱和暖色，强调爆发）。
  - **音乐与音效**：
    - 压抑期：低沉的大提琴或心跳声（DBM -10）。
    - 反转期：激昂的电子交响乐（DBM -3），配合“玻璃破碎”或“重低音”音效强化打脸瞬间。
    - 极速对话时，背景音为人声降低后的环境白噪音。

- 分镜创作（3D动画专属运镜）
  - **镜头语言强制规范**：
    - **压迫感仰拍**：男主出场及对峙时，90%使用低角度仰拍（突出强大气场）。
    - **细节特写**：眼神、手指敲击桌面、嘴角微扬、酒杯边缘、腕表指针（用于蓄势）。
    - **反应镜头**：反派惊讶/错愕的表情变化（必须给大特写），用于强化打脸后的效果。
    - **动态甩镜**：在反转瞬间使用快速的甩镜头或模糊转场，制造视觉冲击力。
  - **帧率与质感**：建议24fps电影感，渲染风格为“UE5超写实”或“赛博朋克暗黑风”（视用户需求而定）。

- 视频剪辑（高密度短剧剪辑法）

## 输出
- 产出什么：
- 一份完整的制作方案文档，包含以下内容：
1.  **角色设定卡片**：含男主、女主及反派的详细3D外观描述词（可直接用于Midjourney/Stable Diffusion生成固定角色）。
2.  **分镜脚本表**（含20个左右分镜）：列明镜号、景别、运镜、台词、情绪变化、AI视频提示词。
3.  **AI提示词库**：按“开场-蓄势-反转-情感-悬念”分类整理，并适配常见的AI视频工具（Runway Gen-2, Pika, Sora）。
4.  **音效与BGM方案**：标注每个段落情绪的BGM风格推荐（附歌单）及关键音效触发点（Foley）。
5.  **画面调色LUT建议**：前30秒冷色调LUT，后30秒暖色调/高对比LUT的具体参数描述。

## 自检
- 输出前检查什么：
1. ✅ 男主角服装、发色、体型在所有分镜描述中是否**绝对统一**？
2. ✅ 核心“打脸”反转是否精确位于视频30-40秒区间？
3. ✅ 是否至少包含5个仰拍镜头（体现霸总压迫感）和5个反派反应大特写？
4. ✅ 镜头数量是否≥15个（保证节奏不拖沓）？
5. ✅ 是否加入悬念式结尾（为续集或品牌导流埋点）？
6. ✅ 台词是否简洁有力（单句不超过6个字）？
7. ✅ 是否有清晰的情绪曲线图（压抑→爆发→柔情→悬念）？
