# 托兰德深焦调度

让多个景深层同时承载叙事，而不是把“全部清晰”当成视觉噱头。先确定观众何时看谁，再用空间、尺度、遮挡、走位和光线层级组织注意力。

## 收集输入

取得场景目标、人物权力关系、关键揭示、场地平面、门窗与纵深、演员走位、可用机位、光源、画幅、交付平台和相邻镜头。标出必须同时可读的人物、动作与道具。

## 工作流

### 1. 写出空间命题

用一句话定义画面中的空间关系，例如“前景父亲压住谈话，中景女儿观察，背景门口的行李提前暴露离开决定”。每一层只承担一个首要信息。

若没有两个以上必须共存的信息，不强行使用深焦；改用较浅景深或切镜头。

### 2. 绘制三层平面

把场地划为前景、中景、背景和可穿越通道。记录人物到镜头的距离、尺寸比例、视线、入口、出口、遮挡物和危险空区。

优先利用真实建筑线条建立纵深。禁止为了“有层次”随意摆放无叙事作用的前景物。

### 3. 分配注意力顺序

为每个节拍标记第一、第二、第三阅读点。用动作起止、亮度差、色彩、面部朝向、声音、停顿和遮挡解除引导视线，不依赖后期模糊。

同一时刻不要让三层都发生同等强度的动作。需要观众主动选择时，也要明确允许歧义的剧情理由。

### 4. 设计演员调度

让走位改变人物的尺度、遮挡和权力位置。规定谁进入谁的轴线、谁被框住、谁从背景逼近、谁退出可读区域，以及动作如何触发观众重新阅读画面。

排练碰撞点：面孔互相遮挡、身体贴边、道具挡眼、视线越轴和背景动作抢戏。优先微调走位与机位，不先增加镜头。

### 5. 选择镜头与机位

根据空间关系选择适度广角、机位高度、俯仰角与拍摄距离。说明选择如何放大距离、维持人物比例或让建筑参与叙事。

避免把超广角畸变当作深焦。检查边缘人物、脸部透视、垂直线和近景物尺寸；必要时后退机位、缩小前景比例或换较长焦段。

### 6. 建立可实现的清晰度

列出前后清晰边界、对焦基准、光圈目标、传感器或胶片条件、允许的感光度与快门范围。实拍时用景深计算和现场测试确认；生成时用“前中后景均具清晰纹理、无虚化跳变”描述结果。

不要承诺不可实现的无限景深。光线不足时按顺序评估：增加有来源的光、缩短纵深、调整机位、改变焦段、允许局部柔化或拆分镜头。

### 7. 用光分层而不割裂

为三层安排可信光源与亮度关系。以局部明暗、轮廓交叠和环境反射分离人物，同时保持同一空间的方向、色温和空气感。

禁止给每个人单独加无来源轮廓光。背景可以清晰，但不必与前景同亮。

### 8. 转译为拍摄或生成提示

写明画幅、机位、焦段倾向、三层内容、距离比例、阅读顺序、走位触发、光源、清晰边界、首尾帧和禁止项。人物姓名后固定其层级与动作，避免生成模型交换身份或位置。

禁止只写“某摄影师风格”“经典深焦”或具体影片镜头。禁止假景深、无故焦点漂移、层级互换、人物穿模、边缘拉伸和无来源补光。

### 9. 做空间连续性质检

逐帧检查人物身份、前中后关系、尺寸、遮挡、视线、建筑线、动作接力、光向和焦点。缩略图观看时仍应读出第一信息；静音观看时仍应理解空间权力变化。

若画面全部清楚却无法阅读，先降低同时动作数量并重排注意力顺序，不靠更强锐化解决。

## 输出格式

1. **空间命题**：叙事关系与采用深焦的理由。
2. **三层平面**：人物、道具、距离、通道与遮挡。
3. **节拍调度表**：阅读顺序、动作触发与权力变化。
4. **摄影方案**：机位、焦段、清晰边界、曝光和光源。
5. **拍摄或生成提示**：首尾帧、层级约束与禁止项。
6. **质检清单**：可读性、连续性、畸变和穿模风险。
