# 短剧封面生成

根据剧本或故事简介，生成适合短剧平台首页 Feed 流的高点击率封面。

本 Skill 遵循：

> Movie Moment，电影瞬间。

封面不是普通人物海报，而是要冻结故事里最有戏剧张力的一秒。

## 核心原则

所有封面优先级：

```text
关系 > 情绪 > 冲突 > 颜值 > 场景
```

背景永远只是辅助。人物关系必须第一眼看懂。

## 输入信息

必填：

- 剧名
- 故事简介

可选：

- 人物设定
- 角色图片
- 世界观
- 想强调的剧情
- 指定题材，例如古风、现代、霸总、甜宠、悬疑、重生、宫斗
- 上一张封面的风格，用于避免重复

## 生成前确认

在生成封面或封面 Prompt 前，必须先向用户确认关键信息。不要在信息明显不足时直接生成。

必须询问并确认：

```text
1. 短剧标题是什么？
2. 短剧内容概览是什么？如果是分章封面，每一章的标题和剧情简介是什么？
3. 需要生成几张封面？是单张、按章节批量，还是每章多个版本？
4. 图片规格是什么？例如 3:4、9:16、1:1、16:9。未指定时，建议使用短剧平台常用 3:4 竖版。
5. 有没有偏好的视觉风格？例如现代都市、电影感、甜宠、悬疑、古风、男频爽感、大女主、真实剧照感、平台爆款封面感。
```

建议继续询问：

```text
6. 是否有人物设定或角色图？如果有，需尽量保持人物年龄、气质、服装和关系一致。
7. 封面上允许出现哪些文字？默认只写剧名和必要小标题，不写章节号、集数号或批量序号。
8. 是否有参考图或上一批不满意的图？如果有，分析需要保留和避免的点。
9. 希望强调哪一个点击点？例如误会、反转、暧昧、背叛、证据、救命、羞耻、身份曝光。
10. 图片保存位置是否有指定？未指定时保存到当前工作区的“短剧封面输出”目录。
```

如果用户已经一次性提供了上述信息，可以不重复提问，只需简短复述确认后生成。若缺少图片规格或视觉风格，可以使用默认值继续，但必须在生成前说明默认选择：

```text
未指定比例：默认 3:4 竖版
未指定风格：默认真人电影感、短剧平台爆款封面风
未指定保存位置：默认保存到本地“短剧封面输出”目录
```

## 生成流程

### 第一步：分析剧情

先判断：

- 题材
- 爽点
- 人物关系
- 情绪核心
- 主要冲突
- 用户为什么会点

题材示例：

```text
古偶，都市甜宠，豪门，重生，宫斗，萌宝，玄幻，校园，悬疑，霸总
```

爽点示例：

```text
闪婚，身份反转，先婚后爱，马甲，打脸，逆袭，追妻火葬场，契约婚姻，替嫁，复仇
```

点击点示例：

```text
第一点击点：外卖员居然是百亿总裁
第二点击点：闪婚
第三点击点：隐藏身份
第四点击点：高颜值CP
```

### 第二步：找出 Movie Moment

封面必须回答：

```text
这一秒发生了什么？
```

错误示例：

```text
男女主站在一起。
```

正确示例：

```text
男主刚说“我们结束吧”，女主眼眶泛红，桌上的手机亮着，屏幕显示分手短信。
```

必须冻结剧情最精彩、最有情绪、最想让人点进去的一秒。

### 第三步：匹配封面类型

根据剧情自动选择：

```text
双人CP
单人大女主
多人修罗场
接吻封面
婚礼封面
豪门封面
权谋封面
战损封面
真相揭露封面
倒计时封面
误会道具封面
```

### 第四步：匹配模板

模板1：冲突对峙

适合：

```text
争吵，对视，拉扯，分手，压迫感，误会爆发
```

关键词：

```text
争吵，对视，距离，压迫感，眼泪，转身，拉住手腕
```

模板2：真相揭露

适合：

```text
身份曝光，亲子鉴定，诊断书，照片，短信，戒指，合同
```

重点：

```text
证据必须进入画面。
```

模板3：克制暧昧

适合：

```text
甜宠，先婚后爱，暗恋，暧昧升温
```

关键词：

```text
眼神，靠近，克制，暧昧，呼吸感，未完成的拥抱
```

不能直接拥抱，除非剧情要求。

模板4：倒计时

适合：

```text
抢票，游戏，考试，比赛，救援，限时任务
```

关键词：

```text
倒计时，电脑，屏幕，数字，抢票，游戏，考试
```

画面必须出现清晰数字。

模板5：误会道具

适合：

```text
礼物引发误会，道具推动剧情，物品代表情绪
```

关键词：

```text
礼物，裙子，鞋子，项圈，热巧，炸鸡，戒指，文件
```

物品就是剧情，必须出现在画面里。

模板6：圆满结局

适合：

```text
复合，求婚，婚礼，亲吻，烟花，重逢
```

关键词：

```text
暖光，拥抱，戒指，烟花，亲吻，婚礼
```

## 风格库

封面不能连续出现相同颜色、构图、光线、镜头。

自动切换：

```text
Style A：电影暖光，适合甜剧
Style B：高反差冷光，适合冲突
Style C：胶片风，适合回忆
Style D：广告摄影，适合都市
Style E：日系自然光，适合校园
Style F：欧美电影感，适合悬疑
```

## 色彩策略

现代短剧常用：

```text
黑金，暖橙，城市夜景，高级电影光
```

古装短剧常用：

```text
红金，黑红，暖光，皇家质感
```

可选色彩：

```text
暖金
蓝橙
粉白
红金
黑红
绿色森林
机场蓝
咖啡暖棕
Live House霓虹
图书馆奶咖
```

相邻封面禁止使用相同色彩策略。

## 构图规则

必须遵守：

```text
比例：3:4
人物占画面：70%～80%
背景占画面：约20%
单张封面只表现一个章节或一个剧情瞬间
禁止拼图
禁止九宫格
禁止多个章节放在同一张图
禁止章节数字编号
```

章节数字编号指任何类似以下文字，封面上不得出现：

```text
第1章
第01集
第12话
Chapter 1
EP01
Episode 3
```

如果剧情需要数字，只能作为画面内道具或情节证据出现，例如倒计时、金额、诊断书编号、短信时间、航班号。不能让数字看起来像平台章节、剧集编号或批量序号。

镜头可选：

```text
近景
中近景
特写
侧脸
背影
俯拍
仰拍
```

不能连续重复同一种镜头。

## 生成与交付规则

生成图片时必须遵守：

```text
图片比例固定为3:4竖版
每一章生成一张单独封面图
一张图只对应一个章节或一个剧情瞬间
不能把多章内容合成到同一张图
批量生成时逐章生成、逐张保存、逐张预览
图片文件自动保存在电脑本地
保存后的图片必须支持在对话中直接预览
图片文件名使用封面标题命名
```

文件命名规则：

```text
优先使用剧名或该章封面标题作为文件名
如果有小标题，用“剧名-小标题”命名
如果同名文件已存在，在文件名后加短时间戳或序号，但图片画面上仍不能出现序号
文件名可以有序号用于本地管理，封面画面里不能出现第几章、第几集或批量序号
```

交付时必须展示：

```text
每张图的对话预览
每张图的本地保存路径
每张图对应的标题和小标题
```

## 标题设计

标题必须使用：

```text
中国书法字体
爆款短剧封面字体
```

禁止：

```text
黑体
描边艺术字
廉价综艺字体
复杂到看不清的字体
```

标题规则：

```text
标题占画面约15%
不能遮挡人物表情
优先放在底部30%～40%
必要时可放侧边，但不能破坏人物关系
标题必须拆行
封面文字只写剧名和必要小标题
不要写第几章、第几集、第几话、EP、Episode、Chapter或批量序号
```

小标题只在能增强点击点时使用，例如“闪婚当晚”“身份曝光”“她不装了”“追妻火葬场”。小标题必须短、狠、像剧情钩子；不能解释剧情，不能堆满画面。

字体气质必须跟题材绑定：

```text
古风/玄幻/权谋：粗书法、飞白、墨迹、金粉或白色微光，可配侧边竖排小字
都市甜宠/校园/治愈：白色手写体、轻书法、柔光，字距松，有呼吸感
大女主/复仇/女强：粗书法或硬笔刷字，白字或金字，笔画重，压迫感强
男频/系统/末世/战神：立体金属字、红金渐变、厚描边、强阴影，标题可成为主视觉
悬疑/现实/商战：冷白标题、少装饰，可配红线、印章、证据贴纸、合同章
群像/修罗场：底部大标题，少用小标题，优先保证每个人脸和关系不被遮挡
```

标题位置不能固定在底部。按人物和题材选择：

```text
人物脸集中在上半部：标题放中下部或底部
拥抱、对视、拉扯等双人关系：标题可压在身体区域，但不能遮挡手部动作和表情
多人群像或修罗场：标题放底部，减少装饰
古风、权谋、悬疑：可加侧边竖排小标题增强质感
男频、系统、末世：允许巨型标题占画面25%～35%，但仍要保留核心人物和关键道具
甜宠、校园、治愈：标题更轻、更松，避免厚重描边和廉价立体字
```

标题示例：

```text
我的老公
是隐藏大佬
```

不要写成：

```text
我的老公是隐藏大佬
```

批量生成多张封面时，字体排版必须有变化，不能每张都使用同一套标题位置、字号层级和拆行节奏。按剧情自动轮换：

```text
排版A：底部压字型，大书法标题压在底部，适合古风、女强、逆袭
排版B：中下横幅型，标题横跨人物身体区域，适合都市、甜宠、暧昧
排版C：侧边竖字型，主标题底部，侧边加短竖排小标题，适合古风、权谋、悬疑
排版D：巨型主标题型，标题占画面25%～35%，适合男频、末世、系统、战神
排版E：手写轻字型，白色手写体轻贴人物关系，适合校园、治愈、纯爱
排版F：证据贴纸型，小标题像红印、手写签、便签、合同章或短信框，适合真相揭露、误会道具
排版G：主副标题错落型，主标题一行大、一行小，副标题贴近主标题，适合都市冲突和大女主
排版H：留白呼吸型，标题只占中下部一角，保留人物关系和氛围，适合高级感甜宠或虐恋
```

批量封面还必须变化：

```text
标题位置
标题拆行
主副标题比例
横排/竖排倾向
字体粗细
字色与底纹
是否使用短小标题
```

## 自检清单

生成完成后必须检查：

```text
□ 是否是3:4比例
□ 是否只有一个章节
□ 批量生成时是否每一章都有一张单独封面图
□ 是否没有第几章、第几集、第几话、EP、Episode、Chapter或批量序号
□ 是否只写了剧名和必要小标题
□ 是否使用书法字体
□ 是否按题材匹配字体气质，而不是随机换字体
□ 批量生成时，是否与上一张的标题位置、拆行、字号层级和字体排版不同
□ 是否人物关系清晰
□ 是否情绪足够强
□ 是否画面明亮，适合Feed流
□ 是否与上一张风格不同
□ 是否符合Movie Moment原则
□ 是否关键证据、道具或数字已经进入画面
□ 是否标题没有遮挡人物表情
□ 是否已保存到电脑本地，并用标题命名文件
□ 是否已在对话中展示图片预览和本地保存路径
```

如果任何一项不满足，必须重新调整封面策略或 Prompt。
