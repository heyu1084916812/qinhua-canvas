# 古龙武侠片场

## Skill 定位

- 只负责：将用户的主题/灵感转化为古龙武侠美学的完整短片（从剧本到成片）
- 视觉风格：致敬1970s邵氏武侠电影——暖琥珀色调、胶片颗粒感、戏剧性低光、经典构图
- 叙事风格：古龙式短句、留白、意境、孤独与侠义

## 输入

- 用户提供：主题/故事梗概（一句话或一段话均可）
- 可选提供：时长偏好（60s/90s/180s）、情绪基调（悲壮苍凉/快意恩仇/孤独寂寥/悬疑诡谲）、主角类型

## 输入使用

- 主题是核心创作起点，必须严格遵守
- 时长/基调/主角类型为参考，未提供时使用默认值（60s、悲壮苍凉、孤傲剑客）
- 如果用户提供了参考图片或视频，在角色和场景设计时作为视觉锚点

## 内部流程和 Knowhow

### 第一步：剧本创作

按【开场→发展→高潮→收尾】四幕结构，将主题展开为古龙式分镜剧本。

- 60秒=6镜，90秒=8镜，180秒=10镜
- 每个镜头包含：镜号、景别、画面描述、旁白/对白、时长分配
- 旁白风格严格遵守古龙短句美学：一句话不超过15字，句与句之间留白，意象叠加
- 详细叙事规则和示例见 [narrative-guide.md](narrative-guide.md)

### 第二步：角色与场景资产

根据剧本创建角色设定和场景设定：

- 角色：外貌、服饰、武器、标志性动作（用文字描述，供后续图像生成使用）
- 场景：每个场景的环境、光线、氛围、关键道具
- 保持全片视觉一致性：所有角色/场景共享邵氏复古美学基底

### 第三步：分镜创作

将剧本转化为详细的分镜指令：

- 每镜标明：景别（远/中/近/特写）、机位角度、运动方式、转场方式
- 武打场景的镜头语言遵循专门规则（见 [shot-language.md](shot-language.md)）
- 节奏控制：开场舒缓→发展渐快→高潮密集→收尾留白

### 第四步：画面生成 Prompt

为每个分镜生成图像/视频的 prompt：

- 统一基底：Shaw Brothers 1970s wuxia film, warm amber grading, film grain, dramatic low-key lighting, analog film look
- 按情绪基调叠加氛围修饰词
- 详细 prompt 模板和修饰词表见 [visual-style-guide.md](visual-style-guide.md)

### 第五步：视频生成与剪辑指导

- 指导 Agent 将分镜逐镜生成为视频片段
- 转场：以交叉淡入淡出为主，高潮段落用硬切
- 节奏：每镜实际时长与剧本标注对齐
- 字幕：古龙式旁白以字幕形式叠加，白色描边字体居中底部
- 片头：暗红底+金色标题，2秒
- 片尾：渐黑+「江湖再见」或主题金句，2秒

## 输出

- 完整武侠短片视频（1-3分钟）
- 包含：片头标题、分镜场景、旁白字幕、转场过渡、片尾

## 自检

- 全片视觉风格是否统一（不能出现现代元素、赛博朋克等违和画面）
- 旁白是否符合古龙短句美学（不能有长句、大白话）
- 镜头节奏是否匹配情绪曲线（不能全程一个节奏）
- 角色外貌是否全片一致（同一角色不能换脸换装）
- 每个镜头的画面是否包含邵氏复古元素（胶片感、暖色调、经典构图）

## Ask User

- 用户只给了极短的主题（如"剑"）时，追问：希望什么情绪基调？大约多长？
- 用户提供了参考图但没说明用途时，追问：这是角色参考还是场景参考？
- 剧本生成后，展示给用户确认再进入生产阶段
