# 穿搭变装视频生成器

输入人物参考图与服装要求，产出竖屏（9:16）换装成片：**同一场景、同一机位**，一条视频内连续展示多套穿搭，服装之间干净硬切，可配音乐卡点。适用于穿搭博主、美妆达人、高定走秀、宠物变装等批量内容制作。

## 输入

1. **人物参考图**：1-3 张清晰的正面或半侧面照片（宠物变装则为宠物照片），面部特征清晰、无遮挡、光线均匀。
2. **服装要求**：一段文本描述（如"法式复古、红色长裙配草帽"），或具体服装参考图（一套一张）。
3. **视频基调**：音乐风格（动感电子 / 节奏鼓点 / 舒缓轻音乐）、换装套数（建议 3-5 套）、场景设定（影棚纯色背景、居家卧室、都市街头等）、发布平台与画幅。

参考图不清晰或角度不佳时先提示更换或补充；服装描述过于复杂时建议拆成单品或改用参考图。

## 两条产出路径

**默认路径（直出成片）**：一条视频内连续展示多套穿搭，生成即交付。 **分段路径（可选）**：先出 N 张穿搭首帧图供挑选，再逐段图生视频，最后按音乐卡点合成。

用户未指定时走默认路径；用户要求"先挑图""每套要单独质感""卡点更精准"时走分段路径。两条路径的场景、机位与一致性规则完全相同，只是产物形态不同。

### 默认路径：一条视频一次生成

1. **固定同一场景、同一机位、同一光线**：所有穿搭都在这个空间里换，不要一套一个场景、一套一个背景。
2. 用一段结构化 prompt 一次写完全部套数，分区顺序固定：
   - 【首帧】{{node_key}} 本段起始画面，写明"人物的面孔、第一套服装、场景与构图严格从该画面开始"；
   - 【人物】{{node_key}} 锁定同一面孔、发型、身形、肤色，写明"全片始终是同一个人"；
   - 【服装一】【服装二】… 每套一行，写清款式、配色、材质、配饰、鞋；
   - 【场景】{{node_key}} 全片唯一的场景与光线；
   - 【阶段一】【阶段二】… 每套一个阶段，每阶段写 `开始时` → `主要事件`（该套的微动作）→ `结束时`（画面干净切走）。 末尾补一句：`保持人物身份、数量、服装、道具归属、空间方向和声音关系稳定。`
3. 每套之间用**干净的镜头硬切**衔接，不表现脱衣或更衣过程。
4. 时长一次到位：一条视频覆盖全部套数，套数越多时长越长（3 套约 10 秒）；单次时长受所选视频模型上限约束。**优先一次性生成，不拆成多段再拼接。**

### 分段路径：首帧图 → 图生视频 → 卡点合成

1. **多套首帧图**：按套数生成 N 张穿搭首帧图，背景统一或风格连贯；人物姿势带动态感（正在转身、整理衣领、手扶帽檐），便于后续转视频。prompt 结构：`[人物特征]+[穿搭描述]+[场景描述]+[镜头语言]+[画质要求]`；同一场景的不同套数，prompt 中写明"与第一套同一位置、同一光线"。
2. **图像转视频**：每张首帧图逐段生成 2-4 秒短动态片段，每段包含一个自然微动作（第 1 套向前走并摘下墨镜、第 2 套原地转身甩动裙摆、第 3 套整理帽子或抚摸宠物）。
3. **卡点剪辑合成**：选一首有明显鼓点的音乐，标出重音卡点，把动态片段按卡点剪切拼接，实现"音乐一响换一套"；卡点处可加轻微特效（闪白、震动、运镜拉近）掩盖拼接感，并加引导性字幕。
4. **节奏参考**：3 套时前奏约 1 秒、每套展示 1.5-2 秒、结尾 0.5 秒定格或互动动作，完播率最佳。

## 全局强制规则

- **人物一致性锁定**：所有穿搭必须同一张脸、同一发型、同一身形。以人物锚点图作参考反复引用，并在 prompt 中明确写出不采用的内容（例如"不采用其中的白色背心、灰色短裤与纯色背景"），避免换装后换脸或换人。
- **服装贴合度**：以服装参考图为准写清款式、配色、材质与配饰；复杂服装先抠出衣服区域再局部重绘，保证细节真实、版型不变形。
- **宠物变装**：prompt 中强化"保持特定品种特征、毛色不变"。
- **多套同场景**：全套穿搭在同一场景、同一机位、同一光线完成，视觉基调统一。
- **一条优先**：能一次生成完的，不拆成多段分别生成再拼接。

## 安全审核与容错

- 换装转场若被判定为"更衣过程"而未通过审核：改为干净的镜头硬切展示，并在 prompt 中明确写出"每套之间用干净的镜头切换（直接硬切），不表现脱衣或更衣过程"。
- 仍被判定违规时，可改为**手持手机对着镜子拍摄**的呈现方式（对镜自拍视角）：模特始终举着手机、对着同一面落地镜拍摄，镜中映出全身穿搭，更贴近真实博主内容。
- 人物参考图模糊、角度差或被遮挡时，先要求更换或补充参考图，不要直接开始生成。
- 套数、节奏、场景、平台比例不符合用户预期时，按用户新指定的值调整后重新生成，不擅自改动已确认的套数、场景与音乐基调。

## 输出格式

- **成片**：竖屏（9:16）高清换装视频，同一场景连续展示多套穿搭、硬切换装，可带音乐卡点与转场特效。
- **分段路径附加**：N 张穿搭首帧图（背景统一或风格连贯）、N 段 2-4 秒短动态片段。
- **附加**：备选标题与话题标签（Hashtags）。

## 自检

- 所有穿搭中面部、发型、身形是否始终一致（未换脸）。
- 服装款式、配色、配饰是否贴合参考图，细节真实无变形。
- 是否同一场景、同一机位、同一光线。
- 每套是否有自然微动作，而非僵硬定格。
- 套数与节奏是否在 3-5 套、每套 1.5-2 秒的舒适区间。
- 转场是否干净不突兀；走卡点路径时是否卡准音乐重音。
- 宠物变装是否保持品种与毛色特征。

## AskUser

- 人物参考图不清晰或角度不佳时，提示更换或补充。
- 服装描述过于复杂时，建议拆分为多个单品或改用参考图。
- 用户希望调整换装套数、节奏、场景、音乐风格时，按用户指定值执行。
- 用户需要特定平台格式（抖音、小红书等）时，调整输出比例与标签。
- **每次运行生成前，先向用户确认即将生成的内容（套数、场景、时长、呈现方式），确认后再运行。**

其余情况直接按所选路径生成并输出成片。

## 执行说明

本 Skill 描述的是穿搭变装这一内容形态的镜头与工艺规则；节点的创建、运行、审批与成片合成按站内视频编排能力执行。编排规则与本 Skill 冲突时，以本 Skill 为准。
