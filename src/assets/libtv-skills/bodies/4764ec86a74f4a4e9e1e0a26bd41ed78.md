# 佛国净土天宫视频生成

## Skill 简介

基于用户提供的中式天宫仙境美学参考图，由 Agent 辅助生成符合佛教经典的佛国净土图片提示词，再经图片生成、元素编辑、视频生成、视频高清增强，最终产出一条 IMAX 电影级佛国净土天宫高清视频。

---

## 核心美学锚点（固定不变）

### 视觉美学体系
- **构图秩序**：中轴线 × 对称构图，层层递进的空间仪式感，整体庄严高级
- **反现实尺度**：制造巨物感、辽阔感、无尽感；用远大近小的反常比例形成视觉冲击
- **尺度反差**：前景放极小人物，中远景立巨构主体，加入巨型天体或异象，用尺度反差制造奇观
- **大量留白**：让主体更突出，制造空灵感
- **透视感**：极小的人物、梦幻的云海光线、强调透视纵深

### 人物与元素规范
- **人物形象**：以佛教女修为主，背对镜头、尺寸极小，作为画面尺度参照
- **灵兽**：须出自佛教经典（如迦楼罗、孔雀明王坐骑、白象、金翅鸟等）
- **灵树**：须出自佛教经典（如菩提树、七宝树、贝多树等）
- **禁止**：无现代物体，无花哨仙侠特效

### 风格定调（锚点）
超写实电影级东方神话，戏剧性黄金时刻暮色，暖色轮廓光与冷调蓝灰阴影，大气薄雾、空气透视、体积云和丁达尔光束；24mm 广角镜头，IMAX 电影级宽画幅（**优先使用 21:9**，平台不支持时退选 16:9），照片级写实 CG 渲染，物理精准的旧木、石材与瓦片质感，电影调色，细微胶片颗粒。

## 提示词写作结构（锚点）

按以下四层视觉规律组织提示词：

| 层次 | 内容 |
|------|------|
| **前景** | 建立尺度参照：古亭/廊柱/台阶，极小的佛教女修背影 |
| **中景** | 铺开空间层次：山脊宫殿、体积云海缠绕群山 |
| **远景** | 制造超常尺度：巨型石质天门/天宫建筑群，大半隐于云雾 |
| **风格定调** | 统一光影质感：光源方向、雾气、镜头参数、渲染质量 |

## 执行步骤

### Step 1：上传参考图

参考图缺失时，提醒用户必须上传，否则无处理分支

**参考图用途说明：**
- 提供给 Agent 作为美学风格参照，辅助生成提示词
- 作为图片生成节点的风格参考输入（Image Reference）

**⚠️ 参考图缺失处理：**
若用户未上传任何参考图，**不得自动跳过此步骤**，应暂停并向用户说明：
> "请上传 1-6 张中式天宫仙境美学参考图，用于风格参照。若不上传，生成的提示词将缺少风格锚定，图片效果可能与预期偏差较大。你可以选择：①上传参考图后继续；②仅凭主题文字继续（风格参照会减弱，建议在提示词中补充更详细的风格描述）。"

用户明确选择"仅凭主题文字继续"后，方可跳过参考图进入 Step 2，并在 Agent 指令中注明"无参考图，请在提示词中强化风格描述"。

---

### Step 2：Agent 辅助生成佛国净土图片提示词

**节点类型**：Agent / 文本生成节点
**输入**：用户上传的参考图（若有）+ 用户指定的佛国净土主题（槽位）
**输出**：2 组完整的图片生成提示词

**Agent 指令（锚点）：**

```
你是一位专精中式佛国净土美学的视觉提示词设计师。

请基于用户提供的参考图风格（若有），以【佛国净土主题】为核心，设计 2 组图片生成提示词。

## 约束条件
- 人物形象以佛教女修为主，背对镜头、尺寸极小，作为画面尺度参照
- 灵兽、灵树须出自佛教经典（如迦楼罗、金翅鸟、白象、菩提树、七宝树等）；当用户要求非佛教经典元素时，需直接拒绝并提醒替换成佛教经典里的元素

- 遵循中式天宫美学：中轴线对称构图、层层递进空间仪式感
- 制造巨物感/辽阔感：反现实尺度，远大近小，尺度反差
- 大量留白，空灵感，强调透视纵深
- 无现代物体，无花哨仙侠特效

## 元素合规性检查（必须在生成提示词前执行）
检查用户补充的场景细节中是否包含非佛教经典的灵兽或灵树（例如麒麟、凤凰、仙鹤、龙（非佛教语境）等中国神话元素）。
- 若发现不合规元素，**不得直接采纳**，须先向用户说明：
  > "「[元素名称]」属于中国神话体系，非佛教经典灵兽/灵树。为保持佛国净土主题的经典准确性，建议替换为：[推荐的佛教经典替代元素及其经典出处]。请问是采用替代元素，还是坚持使用原元素？"
- 等待用户明确回复后再生成提示词。
- 若用户坚持使用非佛教经典元素，在提示词中保留该元素，但在提示词末尾添加备注：「注：[元素名称] 非佛教经典元素，已按用户要求保留。」

## 提示词结构（每组必须包含四层）
1. 前景：建立尺度参照（古亭/廊柱/台阶 + 极小佛教女修背影）
2. 中景：铺开空间层次（山脊宫殿 + 体积云海缠绕群山）
3. 远景：制造超常尺度（巨型石质天门/天宫建筑群，大半隐于云雾）
4. 风格定调：超写实电影级，优先使用 IMAX 21:9 宽幅（不支持时退选 16:9），丁达尔光束，体积云，8K HDR，无现代物体

请输出 2 组完整提示词，每组标注"提示词 A"和"提示词 B"。
```

**等待用户确认**：Agent 输出提示词后，等待用户选择或修改，再进入下一步。

### Step 3：佛国净土天宫图片生成

**节点类型**：图片生成节点
**上游依赖**：Step 1 参考图（风格参考）+ Step 2 Agent 输出的提示词
**生成数量**：每组提示词生成 1 张，共 2 张

**图片生成参数（锚点）：**
- 画幅比例：**优先使用 21:9**（IMAX 宽幅）；平台不支持 21:9 时，退选 16:9
- 风格：超写实 CG 渲染，电影级光影
- 参考图权重：中等（参照风格，不强制复刻构图）

---

### Step 4：元素编辑（精修）

**节点类型**：元素编辑节点（图片节点 → 元素编辑）
**上游依赖**：Step 3 生成的图片
**操作目的**：
- 修正人物比例（确保人物极小，符合尺度反差要求）
- 强化云海/光束/建筑细节
- 去除不符合佛教经典的元素

**等待用户确认**：元素编辑完成后，等待用户确认图片满意，再进入视频生成。

---

### Step 5：佛国净土天宫视频生成

**节点类型**：视频生成节点
**上游依赖**：Step 4 元素编辑后的图片
**输出**：佛国净土天宫主题视频

**视频生成参数（锚点）：**
- 运镜建议：缓慢推进（Slow Push-in）或环绕上升（Orbit Up），强化空间纵深感
- 时长：5-8 秒
- 风格：与图片保持一致，超写实电影级

---

### Step 6：视频高清增强

**节点类型**：视频高清增强节点（视频节点 → 高清）
**上游依赖**：Step 5 生成的视频
**输出**：高清放大后的佛国净土天宫视频（最终产出）

| `{场景细节补充}` | 可选，用户对特定场景元素的补充描述（须经元素合规性检查） | 七宝莲池、八功德水、宝树行列等 |

## 注意事项

1. Step 2 和 Step 4 完成后需等待用户确认，不自动跳过
2. 灵兽、灵树元素必须有佛教经典出处；用户要求非佛教经典元素时，须先提示并推荐替代，等待用户确认后再生成
3. 提示词中不得出现现代物体、现代服饰、现代建筑
4. 人物必须背对镜头且尺寸极小，不得出现正面特写
5. 参考图缺失时不得静默跳过，须向用户说明影响并等待用户选择
6. 图片画幅比例优先使用 21:9，平台不支持时退选 16:9
