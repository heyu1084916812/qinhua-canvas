# 材质质感融合

## 这个 Skill 做什么

接收两张图片，将质感参考图的材质质感细节融合到主图中，输出一张保留主图构图色调、同时具备参考图材质质感的融合图。全程不需要用户输入任何提示词。

核心约束（不可违反）：

- 构图以主图为准，不变
- 色调以主图为准，不变
- 画面内容以主图为准，不变
- 只从质感参考图提取材质质感（布料纹理、皮肤质感、金属光泽、石材纹路等），不引入参考图的内容、构图或色调
- 严禁在提示词中加入任何风格类词汇，防止风格迁移

---

## 执行流程

### 第一步：接收两张图片

用户提供两张图片，无需任何文字说明：

- **质感参考图**：只提取其材质质感细节，不取构图和色调
- **主图**：构图、色调、画面内容以此为准，作为重绘底图

### 第二步：分析主图画面内容

对主图进行详细的画面内容分析，提取以下信息用于构建提示词（分析结果不展示给用户）：

- **角色细节**：角色数量、发色发型、服装款式与颜色、武器或道具、表情与姿态
- **场景细节**：地面材质、背景主要元素、空间层次（前景/中景/远景）
- **光效细节**：光源方向、光效类型（如逆光、侧光、发光特效）、阴影关系
- **构图特征**：主体位置、视角（俯视/平视/仰视）、景别（全身/半身/特写）
- **色调特征**：整体色彩倾向、明暗关系、饱和度风格

### 第三步：构建质感融合提示词

按**三段式结构**用中文构建正向提示词：

**第一段（固定意图句，不变）：**

```
{{质感参考图节点key}} 作为质感参考图，{{主图节点key}} 作为主图，将质感参考图的材质质感细节融合到主图中，保持主图的构图、色调完全不变。
```

> 说明：`{{质感参考图节点key}}` 替换为实际质感参考图的节点 key，`{{主图节点key}}` 替换为实际主图的节点 key。

**第二段（动态画面描述，基于主图分析动态生成）：**

```
[角色细节描述]，[场景细节描述]，[光效细节描述]，[构图特征]，[色调特征]
```

重要原则：

- 基于对主图的分析，详细描述主图的画面内容
- **严禁加入任何风格类词汇**（如"数字绘画""插画""写实风格""赛博朋克"等），防止风格迁移
- 不得加入任何改变画面内容的描述

**第三段（固定结尾强化词，不变）：**

```
保留原有材质的质感细节，精致的材质渲染，高质量，无伪影，构图不变，色调不变。
```

### 第四步：调用图生图工具

**工具：Lib Image 2.5 Pro**

调用参数：

- **reference_nodes（参考节点）**：同时传入两张图——质感参考图 + 主图
- 重绘强度（denoise strength）：**0.35**
- 宽高比：跟随主图（自动检测）
- 提示词：使用第三步构建的三段式正向提示词
- 其他参数保持默认

### 第五步：输出结果

直接输出融合后的图片，不需要附加说明文字。

---

## 参数说明

- 重绘强度 0.35：在保留主图构图色调的前提下，有效融入参考图材质质感细节
- 提示词结构：三段式（含双图插桩的融合意图句 + 主图动态画面描述 + 结尾强化词）
- 双图引用：reference_nodes 同时传入质感参考图和主图两个节点
- 输出模型：Lib Image 2.5 Pro
- 风格词禁用：第二段画面描述中不得包含任何风格类词汇，防止风格迁移
