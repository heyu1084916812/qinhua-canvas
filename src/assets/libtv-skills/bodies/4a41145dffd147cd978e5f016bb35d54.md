# 3C 数码电商海报生成器

## 用途说明

本 Skill 专为 3C 数码类产品设计，旨在通过 AI 技术快速批量生成电商投放所需的使用场景图及带文案的卖点海报，帮助商家提升视觉运营效率。

## 适用输入

- **产品图片**：建议提供白底或透明底的产品实拍图，以确保合成效果。
- **核心信息**：产品名称、2-5 个核心卖点。
- **目标受众**：具体的受众画像描述（如"25岁职场女性"）。
- **生成参数**：所需的场景图数量及画面比例（严格支持 16:9 或 9:16）。

## 操作步骤

1. **信息解析与引导**：接收产品信息，若受众描述过于模糊（如"所有人"），将引导用户细化。
2. **场景图合成**：根据受众画像生成匹配的典型使用场景，并将产品自然融入，确保光效与透视真实。
3. **用户反馈确认**：展示生成的场景图，由用户决定是否进入下一步或针对特定图片重绘。
4. **文案设计与排版**：在场景图基础上叠加卖点文案，支持用户提供文案或由 Agent 自动生成。
5. **海报成品输出**：完成排版布局，输出最终营销海报。
6. **动态视频生成**：在海报成品基础上，将静态海报转化为动态视频。用户可选择动效风格（如产品入场动画、文案渐显、背景粒子特效等）；默认输出时长为 5-15 秒，格式与原海报比例保持一致（16:9 或 9:16）；生成后展示预览，用户可确认输出或调整动效重新生成。

## 输出要求

- **产品保真（强制）**：外观轮廓、Logo 位置、颜色材质及屏幕界面必须与原图严格一致，严禁变形或简化。
- **视觉品质**：呈现商业摄影棚级质感，光影层次丰富，材质纹理清晰，避免低级 AI 涂抹感。
- **排版规范**：文案与背景色调协调，主次分明，不遮挡产品核心视觉位，字体现代简约。
- **视频规范**：动效流畅自然，帧率不低于 24fps，动画节奏与产品调性匹配，避免过度特效干扰产品主体。

## 注意事项

- 每次运行仅针对单一产品进行批量创作。
- 产品表面细节（如金属拉丝、玻璃反光）将根据原图深度还原。
- 若生成的海报文案不符合预期，用户可在第二步确认前进行修改。
- 动态视频步骤为可选流程，用户可在海报输出后选择是否继续生成视频。
