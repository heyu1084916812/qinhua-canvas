# 音乐MV创作工作流

## 核心方法论：歌词-场景映射框架

音乐视频叙事通过歌词时间戳与视觉隐喻的系统性映射构建。

### 时间分割逻辑

- 解析音频，生成带时间戳的歌词片段 `[start_time - end_time]`
- 识别情感峰值和过渡（主歌/副歌/桥段结构）
- 计算总时长，建立节拍-镜头节奏比例
- 将器乐部分（前奏/间奏/尾奏）映射为纯视觉叙事节拍

### 隐喻提取维度

- **具体意象**：歌词中的直接视觉参照（如"朋友圈"→社交媒体界面，"明信片"→明信片道具）
- **情绪状态**：将抽象情感转化为电影语言（如"单向思念"→手机屏幕照亮主角孤独的面孔）
- **空间隐喻**：将关系概念转化为物理距离/障碍（如"分界"→屏蔽的社交媒体帖子，物理分隔镜头）
- **时间隐喻**：使用视觉连续性/不连续性编码记忆/疏离（如渐暗的灯光=失去联系）

## 角色-场景分离架构

为确保多镜头制作的一致性，将MV分解为独立可确认的元素。

### 第1层：主角设计（所有镜头中不可变）

- 年龄范围、体型、面部特征
- 服装调色板（与情感基调挂钩）
- 光影签名（光线如何打在他们脸上——成为视觉主题）
- 生成1张主角色参考图，锁定后方可继续

### 第2层：场景库（模块化空间单元）

- 每个场景=具有固定光照/天气/时间的不同地点
- 基于歌词内容分析设计3-5个核心场景
- 每个场景生成1张主参考图（空镜或带角色）
- 场景在多个镜头中重复出现——保持像素级一致性

### 第3层：故事板矩阵（镜头级合成）

- 组合主角+场景+运镜+道具/UI叠加
- 每个镜头是独特的排列组合，但继承自锁定的第1/2层资产

## 故事板结构公式

一个完整的故事板条目必须编码：

`[镜头#] | [时间戳] | [歌词摘录] | [场景名] | [运镜规格] | [动作/VFX备注]`

### 运镜规格词汇

- **景别**：ECU（极特写）、CU（特写）、MS（中景）、FS（全景）、WS（广角）
- **运动**：静态 / 摇镜 / 俯仰 / 轨道 / 手持
- **角度**：平视 / 低角度 / 高角度 / POV（主观视角）

### 动作/VFX备注必须指定

- 主角动作（躺在床上、行走、盯着手机）
- 道具交互（打字后删除消息、手持明信片）
- UI叠加（聊天泡泡光标、合成到实拍画面中的社交媒体界面）
- 光线转换（屏幕辉光渐弱、路灯熄灭）

## 工作流阶段

### 1. 准备阶段

所需输入资产

- 音频文件（MP3/WAV，含清晰人声）
- 歌词文本（如无法自动提取则需提供）
- 用户偏好：主角性别、视觉风格关键词、任何必选场景

制作前决策

- 确认主角性别、年龄、造型（休闲/正式、现代/复古）
- 定义2-3个核心视觉风格参考（调色、胶片颗粒、UI美学）
- 确定3-5行需要特定视觉隐喻的关键歌词
- 确定宽高比（9:16用于竖屏社交媒体，16:9用于电影感）

元素库存清单

- \[ \] 主角参考图锁定
- \[ \] 场景参考图（每个地点一张）锁定
- \[ \] 歌词时间戳解析完成
- \[ \] 镜头数量估算（标准为每5-8秒音频一个镜头）

### 2. 初始设计阶段

步骤2A：音频分析 → 情感蓝图

- 完整聆听音频轨道
- 提取歌词内容并为每行打上时间戳
- 识别情感弧线：开场情绪 → 高潮 → 结局
- 记录器乐部分（这些成为纯视觉叙事时刻）

步骤2B：生成主角 + 场景参考图

**主角提示框架**： `[年龄/性别描述] + [造型备注] + [情绪品质] + [光影签名]`*示例*：`"20岁男性，短发，白色针织衫+牛仔裤，冷淡文艺气质，手机屏幕蓝光打在脸上，眼神克制落寞"`

**场景提示框架**： `[地点类型] + [一天中的时间] + [天气/光照] + [色温] + [情绪关键词]`*示例*：`"出租屋卧室，深夜，昏黄台灯+手机蓝光，冷暖对比，孤独感"`

并行生成（批量5张：1张主角 + 4张场景）。

步骤2C：用户确认关卡

展示所有参考图。在用户确认前不得进入故事板。如有任何图片被拒绝，仅重新生成该特定元素。

步骤2D：构建故事板表

- 计算总镜头数（音频时长 ÷ 平均镜头时长）
- 按时间顺序将歌词片段分配给镜头
- 将每个镜头映射到已批准的场景库中的场景
- 定义每个镜头的运镜和景别
- 在歌词需要视觉隐喻处添加VFX/道具备注

### 3. 迭代阶段

镜头生成工作流

- 以5个镜头为一批生成（系统限制）
- 使用主角+场景参考图作为输入以保持一致性
- 在视频生成提示中编码运镜和动作
- 审查批次输出 → 标记任何破坏角色/场景一致性的镜头

一致性审计清单（每批）

- \[ \] 主角面部/服装在所有镜头中与参考图一致
- \[ \] 场景光照/调色与参考图一致
- \[ \] 运镜符合故事板规格
- \[ \] 镜头时长与歌词时间戳对齐
- \[ \] 未出现意外物体/人物

优化维度

- **时间对齐**：如果镜头过早/过晚结束，调整视频时长参数
- **情感强度**：如果镜头感觉平淡，增加运镜（推进以加强亲密感，横摇以表现孤独）
- **视觉隐喻清晰度**：如果歌词含义不清，添加UI叠加或道具特写

### 4. 最终组装阶段

- 按故事板顺序拼接所有已批准镜头
- 将原始音频轨道叠加到合成视频上
- 验证总时长与音频匹配（允许±1秒容差）
- 导出最终MV文件

## 关键约束与标准

### 不可变规则

- **主角身份锁定**：一旦参考图获批，面部、体型、服装必须在所有镜头中保持像素级一致
- **场景一致性锁定**：每个命名场景在所有使用该场景的镜头中必须具有相同的光照、家具、墙面颜色
- **歌词-时间戳忠实度**：每个镜头的开始时间必须与其分配的歌词片段对齐（不允许任意排序）
- **音频保留**：原始音频轨道永不修改——视频围绕它构建，而非相反

### 保真度标准

- **镜头时长**：每个镜头5-8秒为叙事清晰度最佳
- **场景数量**：最多3-5个不同场景——更多场景会稀释视觉认同
- **调色一致性**：在所有镜头中保持相同调色板
- **UI叠加集成**：数字元素必须感觉是合成的——使用微妙模糊/辉光与素材融合

### 一致性规则

- **镜头语法**：每类场景保持一致的镜头语言
- **光照连续性**：场景内的时间段必须保持一致
- **道具使用**：道具在所有镜头中必须保持视觉一致
- **宽高比锁定**：所有镜头必须共享相同的宽高比

### 质量检查点

- **生成前**：用户必须在任何故事板工作前确认角色+场景
- **故事板后**：用户必须在视频生成前批准镜头表结构
- **每批审查**：每生成5个镜头后，检查一致性是否破坏
- **组装前**：在拼接前验证所有镜头满足时长/内容规格
