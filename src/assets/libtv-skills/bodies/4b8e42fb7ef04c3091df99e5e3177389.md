# 超写实 CG 电影级仙侠短片创作工具

本 Skill 旨在将仙侠创意转化为具备电影质感的生产级物料包。通过专业的摄影语言与超写实材质描述，覆盖从脚本到 AI 提示词的全流程，确保视觉风格的高度统一。

### 适用输入

- **核心内容**：故事梗概、主要角色设定、期望的叙事节奏。
- **视觉参考**：目标风格（如暗黑仙侠、唯美超写实）及特定仙侠元素（御剑、阵法、灵兽）。
- **约束条件**：特定的世界观规则、禁止出现的元素。

### 操作步骤

1. **故事脚本精炼**：将梗概扩展为含对白、动作与情绪节点的 1-3 分钟短剧脚本，融入“道韵”等仙侠叙事装置。
2. **资产锚点创作**：
   - **角色/场景**：细化皮肤、丝绸、金属材质表现，建立包含光源与粒子特效的资产档案。
   - **道具/氛围**：提供法宝细节及对应的音效风格指引。
3. **电影级分镜设计**：使用摄影机语言（焦段、景深、光影方向）切分镜头，并标注视觉强度等级。
4. **Prompt 引导生成**：为每个分镜撰写包含“主体+动作+环境+镜头参数+风格标签”的超写实提示词，并配套负向提示词。
5. **后期剪辑指引**：规划镜头顺序、转场方式、特效合成逻辑与音效触发点。

### 输出要求

- **全流程包**：包含《短片剧本》、《资产设定集》、《分镜脚本及 Prompt 表》、《剪辑与音效指南》。
- **风格核验**：所有产出须符合物理光影规律，排除二次元或廉价特效感。

### 注意事项

- **一致性**：必须确保同一角色与法器在跨镜头描述中细节一致。
- **真实感**：Prompt 必须包含真实的摄像机参数（如 Anamorphic Lens, 8k, Unreal Engine 5 render）。
- **交互**：若用户提供的视觉要求与超写实风格冲突，将主动询问确认。
