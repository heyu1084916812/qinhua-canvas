## 触发条件

当用户描述一个视觉概念、场景主题，并明确要求设计分镜 / 画面提示词 / 拍摄风格时，启用本 skill。

---

## 工作流程

### Step 1：理解用户的视觉概念

从用户描述中提取关键要素：

- **主体**：画面中有什么（人物、物体、场景）
- **情绪**：想要传达什么情感（史诗、孤独、速度、温暖、不安……）
- **调性**：科技感 / 自然感 / 复古 / 未来 / 暗黑 / 明亮……
- **用途**：单人海报 / 系列分镜 / PPT 封面 / AI 生图 / AI 生视频

### Step 2：拆解为分镜序列

根据画面复杂度，设计 3-12 个分镜：

用户需求规模分镜数量说明单个场景/氛围3-4 镜建立 → 主体 → 细节一个事件/过程5-8 镜引入 → 发展 → 高潮 → 落幕宏大主题/史诗叙事9-12 镜完整的情感与视觉弧线

每个分镜需覆盖：

- **镜号 + 主题名**
- **景别**（大远景 / 全景 / 中景 / 特写 / 大特写 / 荷兰角等）
- **构图**（对称 / 三分法 / 引导线 / 框中框 / 负空间等）
- **主色调**

### Step 3：为每个分镜设计画面提示词（Image Prompt）

画面提示词描述 **有什么**——画面内容、主体、动作、环境。

**格式要求**：

```
**画面提示词（Image Prompt）**：
[英文提示词，纯描述性，不含技术术语]

**画面提示词（中文）**：
[中文完整翻译，与英文一一对应]
```

### Step 4：为每个分镜设计风格提示词（Style Prompt）

风格提示词描述 **怎么拍**——成像系统、镜头、布光、色彩、质感、风格标签。

**参考文档**（已内置于本 skill，三份文件覆盖全部术语体系）：

## 提示词编写规则

### 画面提示词（Image Prompt）规则

- **纯描述性**，不包含胶片/镜头/摄影术语
- 描述画面里有什么：主体、动作、环境、光线方向
- 英文 3-5 行，简洁精准
- 中文完整对应翻译

### 风格提示词（Style Prompt）规则

- **全部使用技术术语**，从内置参考文档中调用
- 必须覆盖以下至少 4 个维度：
  1. 成像系统（§1）
  2. 镜头系统（§2）
  3. 光线与照明（§5）
  4. 色彩与调色（§6）
  5. 质感指令（§7）
  6. 风格标签（§8，可选）
- 可叠加 Style Lock 禁止指令（§10）来锁定风格边界
- 英文术语与参考文档保持一致
- 中文翻译术语与参考文档保持一致

### 中英对照规则

- 每个分镜的**画面提示词**和**风格提示词**都必须提供完整的中英文对照
- 英文和中文都完整展示，不省略任何一侧
- 中英术语保持一一对应
