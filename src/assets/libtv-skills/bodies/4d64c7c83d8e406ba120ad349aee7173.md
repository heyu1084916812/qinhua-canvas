# 机车运动分镜策划器 (Motorcycle Storyboard Framework)

本 Skill 专门用于策划机车、滑板、越野等连续移动类故事的分镜，确保视觉上的空间连续性与动作张力。

### 1. 适用场景与输入

- **适用类型**：治愈系公路片、热血越野、城市竞速等二次元或实拍分镜。
- **核心输入**：明确主角、载具、行驶场景及最终目标。

### 2. 操作流程

- **路线规划**：设计包含S弯、坡度、路面材质变化的连续路径，而非碎片化场景。
- **动态节奏**：根据路线规划加速（Build Speed）、过弯（Corner）与平稳期（Stable），禁止全程高速。
- **镜头语言**：组合使用高低角度跟拍、倒影镜头（Reflection Shot）与环境遮挡（Hidden Observer）。
- **环境交互**：引入飞鸟、落叶、路灯等动态元素作为“前景流”（Near-field Flow），增强速度感与沉浸感。

### 3. 输出要求

每一组镜头必须以“导演节拍 (Director Beat)”格式输出：

> **\[镜头类型\]** + **\[动作描述\]** + **\[环境互动\]** + **\[路线变化\]** + **\[摄影特点\]** + **\[下一镜引导\]**

### 4. 核心原则（必须遵守）

- **空间连续性**：保持路线、方向、重心的统一，严禁瞬移、回头或跨轴。
- **动作锚点**：上一镜的结束位置必须是下一镜的起始位置。
- **Hard Match Cut**：切换镜头时只改变摄影机机位，不改变人物动作及空间关系。
- **路线驱动**：所有的镜头设计必须服务于行驶路线的变化。
