## name: script-visual-asset-groups description: Turn a supplied short-film, short-drama, animation, or comic script into reusable LibTV canvas groups for characters, environments, props, and storyboard images. Use when the user wants upstream visual assets rather than a finished video, needs style and aspect ratio inferred from the script, or wants approved assets reused for consistent image editing and storyboard generation.

# 剧本视觉资产师

把用户提供的剧本或简短故事拆成可复用的视觉资产，并在同一张 LibTV 画布中整理为人物组、场景组、道具组和分镜组。只做图片资产，不扩写长剧本，不生成视频、配音、剪辑、3D 场景或导演台预演。

## 启动方式

1. 读取剧本、用户说明和参考图，只提取生成资产所需的信息，不复述或扩写正文。
2. 建立一个简短的“视觉设定”文本节点，只写画风、画幅、色彩光线、材质质感和统一规则，控制在五行内。
3. 用户已说明画风或比例时直接采用；信息可从题材、情绪和发布场景判断时，给出一句判断后继续；只有关键歧义会明显改变结果时才集中询问一次。用户说“你来定”或“直接做”时不要停顿。
4. 建立简短资产清单，只列剧情实际需要的人物、场景、关键道具和分镜。没有内容的类别不创建空组。

## 模型路由

- 首次从文字创建人物、场景或道具母图时，调用 LibTV 的 `image` 生图能力，优先使用 **Lib Image**（当前 modelKey：`lib-image-2`）。
- 已有母图后的改图、三视图修正、状态变化、场景调整和分镜图生成，优先使用你指定的 Banana 高一致性编辑路线；LibTV 当前模型列表中的显示名是 **Lib Navo Pro**（modelKey：`nebula-ultra`）。若名称更新，选择平台当前描述为图片编辑、一致性好的同系型号。
- Lib Navo 2（`nebula-2-flash`）只作为速度优先或 Pro 暂不可用时的备选，不默认替代 Pro。
- 工作图默认 2K；只有已批准且确需放大的最终图才使用 4K。比例始终继承“视觉设定”。
- Lib Navo Pro 单次最多接收 7 张参考图；只输入当前画面真正需要的人物、场景、道具和构图参考，避免重复、冲突或无关参考。

## 生成基础资产

1. 生成前读取 references/asset-form-prompts.md，先判断道具是否需要独立资产、是否属于场景固定物、是否需要确定性二维内容。
2. 读取 references/asset-prompts.md，逐个生成基础资产。人物、场景、道具不要在同一张图里混合生成。
3. 每个反复出场人物默认只生成一张人物三视图母图；临时路人不必建立独立人物资产。只有剧情明确要求换装、年龄变化、受伤或其他持续状态时，才追加状态图。
4. 场景母图必须是可复用的空环境，不出现人物或剧情动作。固定在环境中的普通桌椅、柜台、灯具等直接留在场景中。
5. 独立道具只保留剧情、身份、接触、尺寸或连续性真正需要的对象；一张图只表现一个可独立使用的道具。
6. 每张图单独验收。只有已批准的母图才能进入后续参考链。

## 组织画布

按依赖顺序排列：

`视觉设定 → 人物组 → 场景组 → 道具组 → 分镜组`

- 人物组：人物三视图母图和必要状态图。
- 场景组：每个唯一场景的空环境母图及确有必要的局部参考。
- 道具组：独立道具母图和必须准确的二维内容；无独立道具时省略。
- 分镜组：依据剧本镜头逐张生成或复用的分镜图。使用 LibTV 脚本节点生成分镜行时，把对应人物参考图写入角色参考，并将分镜图片模型设为 Lib Navo Pro。

## 生成分镜

1. 读取 references/storyboard-and-editing.md。
2. 每张分镜只表达一个镜头，写清景别、机位、人物位置与朝向、动作起点、道具状态、场景锚点、光线和留白。
3. 输入已批准的人物、场景和道具母图，并明确每张参考只负责什么。人物三视图只锁定身份、五官、发型、体态和服装，不得复制白底排版或多视图布局。
4. 同一机位、人物关系和道具状态没有改变时优先复用已有画面。只有镜头方向、正反打侧、空间关系、关键接触、决定性构图、可读信息或时间地点发生实质变化时才生成新图。
5. 不因镜号、台词、普通表情变化或简单动作变化自动增加分镜图。

## 改图与返修

- 始终从最近的已批准母图分支修改，禁止把多次改图结果继续串联改图，以免噪点、纹理和身份误差累积。
- 一次改图只解决一个明确问题，并写明“只修改什么”和“必须保持什么”。
- 人物或场景母图改变后，只重做受影响的节点和分镜，不整组重跑。
- 构图、身份、透视或大面积结构错误时重新生成；局部语义错误时用 Lib Navo Pro 做受限改图。
- 源图不加入胶片颗粒、传感器噪点、过度锐化、脆硬 HDR、压缩纹理或重复微纹理。需要胶片颗粒时留到成片统一调色阶段，本 Skill 不处理。

## 完成条件

- 人物身份、服装、体态和必要状态稳定。
- 空场景结构、入口、门窗、固定物、光线方向和年代一致。
- 道具形状、尺寸、材质、正反面和接触比例稳定；随机文字不得进入正式参考链。
- 分镜比例统一，没有拼图、额外人物、白底三视图排版、文字、水印、Logo、明显噪点或参考冲突。
- 所有结果已放入对应画布组，且允许单节点局部返修。
