### 技能用途
本 Skill 专为原创 OC（Original Character）、游戏角色、虚拟偶像及品牌 IP 提供专业 PV 分镜生成服务。核心功能是将文字版的 PV 策划案、人设设定及镜头需求，转化为视觉统一、叙事连贯且具备电影质感的标准化分镜故事板。

### 适用输入
本技能为策划驱动型工具，需用户提供以下关键信息：
1. **PV 策划内容**：主题、剧情脉络、段落节奏、核心情绪。
2. **IP 角色设定**：外观细节（发色、瞳色、服饰）、性格气质、标志性特征。
3. **镜头与风格**：景别要求、运镜方式、艺术画风、整体色调及特效需求。
4. **基础参数**：画幅比例、预计时长。

### 操作步骤
1. **策划拆解**：深度分析用户提供的策划案，锁定剧情高光点与叙事逻辑，确保 100% 贴合框架。
2. **人设锁定**：提取角色视觉特征，建立专属视觉标准，严格防止人设崩坏或 OOC。
3. **镜头排布**：遵循「铺垫—递进—高光—定格」的叙事链路，科学分配景别与运镜方式。
4. **氛围渲染**：以角色为中心，匹配情绪调整光影、粒子及色彩层次，提升画面高级感。
5. **标准化产出**：生成有序的分镜图集，并配套专业的分镜脚本说明。

### 输出要求
1. **高清分镜图集**：按叙事顺序排列，角色造型稳定，画面细节精致且无畸形。
2. **专业分镜脚本**：包含镜头序号、时长建议、景别角度、动作神态及转场说明。
3. **视觉固化参数**：提炼本次创作的画风与光影核心参数，便于后续视觉统一。
4. **成片建议**：提供适配角色气质的 BGM 风格、卡点建议及调色方案。

### 注意事项
- **严禁脑补**：所有创作必须以用户输入的策划案为准，不得擅自修改剧情结构。
- **信息缺失问询**：若关键策划信息缺失，将主动询问用户，禁止强行生成。
- **角色一致性**：全程保持人物五官、服饰及画风的高度统一，确保商用级质量。
