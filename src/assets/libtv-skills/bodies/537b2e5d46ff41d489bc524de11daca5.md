# 图片去噪二次优化

## 这个 Skill 做什么

接收一张由 Image2 或 Image2.5 生成的图片，自动对其进行去噪与细节简化处理，输出一张画面更干净的优化图。全程不需要用户输入任何提示词。

核心约束（不可违反）：

- 构图不变
- 色调不变
- 画面设定（角色、场景、风格、氛围）不变
- 绘图风格不变
- 只做"减法"——去除噪点和繁杂细节，不添加新元素，不改变画面内容

---

## 执行流程

### 第一步：接收图片

用户直接上传一张图片，无需任何文字说明。

### 第二步：分析图片内容

在调用重绘工具之前，先对图片进行详细的内容分析，提取以下信息，用于后续重绘提示词的构建：

- **角色细节**：角色数量、发色发型、服装款式与颜色、武器或道具、表情与姿态
- **场景细节**：地面材质、背景主要元素、空间层次（前景/中景/远景）；判断画面中是否有建筑、是否有云雾/云海
- **光效细节**：光源方向、光效类型（如逆光、侧光、发光特效）、阴影关系
- **构图特征**：主体位置、视角（俯视/平视/仰视）、景别（全身/半身/特写）
- **色调特征**：整体色彩倾向、明暗关系、饱和度风格

分析结果仅用于构建重绘提示词，不展示给用户。

### 第三步：构建去噪重绘提示词

基于第二步的分析结果，按**三段式结构**用中文构建正向提示词：

**第一段（去噪意图强调句，固定不变）：**

```
让画面的细节噪点少一点
```

**第二段（画面详细描述，基于分析动态生成）：**

```
[角色细节描述]，[场景细节描述]，[光效细节描述]，[构图特征]，[色调特征]
```

**第三段（结尾去噪强化词）：**

固定必须保留的词：

```
干净的图像，无过多的复杂细节，无噪点，高质量，无伪影，精致的渲染，材质的质感要保留
```

按画面内容判断是否加入的可选词：

- 画面中有建筑元素时，加入：`无多余的建筑细节`
- 画面中有云雾/云海元素时，加入：`云的细节减少`

完整第三段示例（含两个可选词时）：

```
干净的图像，无过多的复杂细节，无多余的建筑细节，无噪点，云的细节减少，高质量，无伪影，精致的渲染，材质的质感要保留
```

重要原则：

- 三段顺序固定，不得调换或合并
- 第二段画面描述必须详细还原原图内容，使用中文表达
- **严禁在第二段中加入任何风格类词汇**（如"数字绘画""插画""写实风格""赛博朋克"等），防止风格迁移
- 第一段和第三段固定词不得修改或删减；第三段可选词根据实际画面决定是否加入

### 第四步：调用重绘工具

**主力工具：General Image V2（优先使用）**

调用参数：

- 参考图：用户上传的原图
- 重绘强度（denoise strength）：**0.25**
- 宽高比：跟随原图（16:9 或自动检测）
- 提示词：使用第三步构建的三段式正向提示词
- 其他参数保持默认

**备选工具：Seedream 5.0 Pro（当 General Image V2 效果不理想时使用）**

调用参数：

- 参考图：用户上传的原图
- 重绘强度：**0.25**
- 宽高比：跟随原图（16:9 或自动检测）
- 提示词：同上

### 第五步：输出结果

直接输出优化后的图片，不需要附加说明文字。

## 已验证参数记录

以下参数经实际图片测试验证，效果满意，作为当前标准固化：

- 重绘强度：0.25（避免改变画面风格表现，稳定保留原图细节）
- 提示词结构：三段式（去噪意图强调句 + 画面详细描述 + 结尾去噪强化词）
- 第一段固定句：让画面的细节噪点少一点
- 第三段固定词：干净的图像，无过多的复杂细节，无噪点，高质量，无伪影，精致的渲染，材质的质感要保留
- 第三段可选词：无多余的建筑细节（有建筑时加）；云的细节减少（有云雾/云海时加）
- 风格词禁用：第二段画面描述中不得包含任何风格类词汇，防止风格迁移
- 验证场景：云海简化、远景建筑细节收敛、主体（白衣人物 + 龙柱）构图色调保持不变
- 工具优先级：General Image V2 优先，Seedream 5.0 Pro 备选
