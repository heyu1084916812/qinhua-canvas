# 《天空》AI电影制作 Skill V4（libTV Agent｜Minimum 4s版）

## 0. 总使命

把“AI生成视频”升级为“AI参与制作的电影镜头”。

本 Skill 必须保证：

1. 先判断任务类型，再产出对应模板。
2. 任何分镜图Prompt、分镜视频Prompt在输出前，都要先执行**资产自动解析**。
3. 若缺失资产，不得直接跳过；必须自动补出对应资产Prompt。
4. 所有S / S+镜必须优先使用白模 / Previs逻辑。
5. 输出给 libTV Agent 的Prompt必须可直接复制，不写空泛说明词堆砌。
6. 输出结构稳定、可复用、可批量排产。

# 2. 核心执行顺序（强制）

只要涉及镜头、Prompt、资产或视频生成，必须按以下顺序运行：

1. **解析任务**：判断是项目设定、拆镜、Previs、资产Prompt、分镜图Prompt、分镜视频Prompt、视频QC中的哪一种。
2. **解析镜头等级**：A / A+ / S / S+。
3. **自动解析资产需求**：列出人物、机械、场景、道具、关键帧、Previs、动作参考、运镜参考。
4. **自动资产引用**：从资产注册表中解析可直接使用的资产。
5. **缺失资产补Prompt**：若某资产缺失，自动生成该资产Prompt。
6. **再生成分镜图Prompt**：严格引用已解析资产。
7. **再生成分镜视频Prompt**：严格引用已解析资产和分镜图/Previs信息。
8. **输出QC清单**：资产QC / 分镜图QC / 视频QC。

不得颠倒顺序。

# 2.1 双时长体系（强制）

执行视频相关任务时，同时读取：`references/duration_validation_rules.md`

本 Skill 必须区分：

## A. Generation Duration｜模型生成时长
这是送入 Seedance / libTV Agent / 白模视频生成器的**单条素材总时长**。

### 硬规则
- **任何单条生成视频不得低于 4.0 秒。**
- 白模 / Previs参考视频不得低于 4.0 秒。
- 影视动作参考视频的截取窗口不得低于 4.0 秒。
- 分镜视频Prompt的时间轴终点不得低于 4.0 秒。

### 推荐生成时长
| 镜头等级 | 推荐Generation Duration |
|---|---:|
| A | 4–6秒 |
| A+ | 4–6秒 |
| S | 5–8秒 |
| S+ | 6–10秒 |
| 世界观Scale Reveal | 6–12秒 |

如果模型平台只允许固定档位，以平台可用的**最接近且不少于4秒**的档位为准。

---

## B. Edit Duration｜最终剪辑取用时长
这是最终正片真正使用的片段长度，可以短于4秒。

例如：
- 最终剪辑只需要“钟挡刀”1.2秒
- 但模型必须生成4–6秒完整素材
- 后期只从完整素材中截取最有效的1.2秒

**禁止把Edit Duration直接当作Generation Duration。**

---

# 2.2 4秒最小生成封装结构（Generation Envelope）

如果核心动作很短，必须把它放进至少4秒的完整动作封装中：

`Head Handle → Core Action → Tail Handle`

## 默认结构
- **Head Handle**：0.8–1.5秒
  - 动作准备
  - 呼吸
  - 威胁建立
  - 摄影机进入
  - 重心准备
- **Core Action**：1.0–3.5秒
  - 真正需要的攻击 / 格挡 / Reveal / 高光
- **Tail Handle**：0.8–1.5秒
  - 受力释放
  - 敌人位移
  - 摄影机稳定
  - 烟尘余韵
  - 角色收势

### 最短4秒示例
- 0.00–1.00：Head Handle
- 1.00–3.00：Core Action
- 3.00–4.00：Tail Handle

后期可只取1.35–2.65秒。

---

# 2.3 参考视频最小时长规则

影视 / CG / 动漫参考中的目标动作本身可以短于4秒，但**给模型使用的参考视频截取窗口必须≥4秒**。

正确：
- 想借0.7秒“武器碰撞”
- 截取碰撞前1.5秒 + 碰撞0.7秒 + 碰撞后1.8秒
- 得到约4秒参考片

错误：
- 只裁0.7秒碰撞瞬间直接作为动作参考

原因：模型需要理解：
- 动作如何进入
- 速度如何变化
- Camera如何提前准备
- Impact之后如何释放

---

# 2.4 分镜拆分规则更新

“一个镜头最终剪辑只有1–3秒”并不意味着生成一个1–3秒视频。

以后镜头任务表必须同时包含：
- `Edit Duration`
- `Generation Duration`

如果同一故事镜头包含多个独立复杂动作：
- 可拆成多个4–8秒生成单元
- 后期再组合成1–5秒最终剪辑

例如镜头004“三刀破盾”：
- GEN004A：切入+第一刀，4–5秒生成
- GEN004B：第二刀+第三刀，4–5秒生成
- GEN004C：终结重劈，4–6秒生成
- 最终正片可能只使用总共3.5秒

# 4. A / A+ / S / S+ 判级决策树

## A镜
推荐Generation Duration：4–6秒。
适用：
- 单主体
- 轻动作
- 普通对白
- 过场

输出要求：
- 资产可最简
- 可只输出1条分镜图Prompt + 1条视频Prompt

## A+镜
推荐Generation Duration：4–6秒。
适用：
- 人物跑动
- 简单机械运动
- 两主体简单交互
- 转场镜头
- 一般威胁建立

输出要求：
- 尽量生成首/尾帧Prompt
- 视频Prompt必须写清运动路径

## S镜
推荐Generation Duration：5–8秒。
适用：
- 高光打斗
- 英雄出场
- 大型机械压迫
- 复杂攻防
- 宣发级镜头

输出要求：
- 必须自动解析全部资产
- 必须生成分镜图Prompt包
- 必须生成视频Prompt包
- 必须优先调用Previs

## S+镜
推荐Generation Duration：6–10秒。
适用：
- 整集天花板镜头
- 最复杂动作镜头
- 最关键世界观镜头
- 宣发 / 预告主镜头

输出要求：
- 必须有Previs
- 必须有三关键帧Prompt
- 必须有完整视频Prompt
- Previs未过不允许进入最终生成

# 5. 资产自动引用规则（强制）

1. **先引用，不先重造。**
2. 若已有 `LOCK` 资产，优先强制使用。
3. 若多个资产可选，优先：
   - 同角色 / 同镜头专用
   - 最新版本
   - 状态最高（LOCK > APPROVED > DRAFT）
4. 若缺失资产，先输出资产Prompt再继续。
5. 任何分镜图 / 分镜视频Prompt都必须在开头显式写出“严格参考以下资产”。
6. 不允许把“资产引用”留给用户自己猜。

# 6. Prompt生成核心规则

## 6.1 资产Prompt
目标：用于生成可复用的标准化母资产。

规则：
- 不写剧情，不写剪辑。
- 以“标准展示图 / 设定图 / 资产图”为目标。
- 必须清楚写用途、角度、背景、统一风格。
- 若为角色，必须明确身份一致性和服装装备一致性。
- 若为场景，必须明确宏观结构与功能结构。

## 6.2 分镜图Prompt
目标：用于生成镜头设计图、关键帧图、构图图。

规则：
- 必须写镜头号、镜头内容、景别、机位、焦段感、构图重心、人物与背景比例。
- 若为S镜，默认提供首帧 / 高光帧 / 尾帧三条Prompt。
- 必须显式引用资产ID。
- 若存在Previs，必须说明“严格遵循Previs的空间关系和Camera Path”。

## 6.3 分镜视频Prompt
目标：用于Seedance / libTV Agent生成视频。

硬规则：单条Generation Duration不得低于4秒；最终Edit Duration可短于4秒。

规则：
- 以“时间轴 + 运动 + 摄影机 + 光影 + 环境反馈 + 禁止项”的结构写。
- 不允许只写“很震撼、很史诗、电影感”这种空词。
- 对S镜必须明确Impact Frame、反作用力、环境反馈。
- 若为世界观镜头，必须写Scale Reveal。

# 7. 打击感规则（视频Prompt强制带入）

所有重击默认包含7阶段：
1. 蓄力
2. 加速
3. 接触前短暂降速
4. Impact Frame（1–2帧）
5. 反作用力
6. 环境反馈
7. 结果位移 / 结构变化

若视频Prompt未体现5/6/7三类内容，判为不合格动作Prompt。

---

# 8. 世界观宏大镜头规则

1. 必须使用Scale Reveal。
2. 先小尺度，再中尺度，再巨构。
3. 人物一般不超过画面高度5–20%。
4. 前中后景至少三层。
5. 摄影机以稳定、后拉、升高、固定观察为主。
6. 禁止一上来就满画面大全景无尺度参照。

# 10. 失败处理策略

若结果不够好：
- 先看资产是否错
- 再看分镜图是否错
- 再看Previs是否错
- 最后才看视频Prompt是否要重写

不要直接无限重写视频Prompt。
