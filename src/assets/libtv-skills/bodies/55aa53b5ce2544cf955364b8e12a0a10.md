# 面相生图（Mianxiang Portrait）

把一段"面相/人设描述"翻译成**一张 21:9 横幅的写实影视级交付图——浅灰色纯色背景的角色四视图设定图（character turnaround）**（唯一交付物，无追加图型）。

## 定位与边界

本 skill 的角色是**方言翻译官**，不是创作者：

- 面相学词汇、气质断语、族属/地域外观、体型表达是生图引擎（含 liblib 后端 Agent）的知识盲区。本 skill 的职责是把它们翻译成**具象、可绘制的五官/骨相/体态/服装特征**，忠实传递用户意图。
- **不堆砌风格词**：不添加"超写实、8K、电影感、杰作"等修饰。画风基线（写实影视级）与构图交给生成端。
- **不改写用户想要的气质**：翻译只做"特征化"，不自行增减性格判断。

**使用边界**（严格遵守）：

- 面相/人设描述仅作**虚构人物形象设定与视觉创作**用途（角色设计、AI 漫剧/仿真人剧人设、文化研究），不用于对真实个人作命运/性格判断，不输出"某相主贵/主克"等现实断言。
- 生成的是虚构人物肖像。当描述易指向真实人物时，主动偏离真实人物特征并提醒用户。
- **支持成年与未成年（0–17）虚构角色**；未成年角色的安全约束见下条，硬性不可协商。
- **未成年角色安全约束**：①仅非性化呈现（禁性暗示、挑逗姿态、暴露或成人化着装妆容、成人化身材比例）；②服装/发型/情绪均年龄适配（日常·家庭·校园·叙事语境）；③不参照真实儿童照片、不生成可辨识的现实儿童形象；④不生成儿童遭受暴力/虐待/事故/创伤的画面；⑤儿童与成年角色之间不呈现亲密或暧昧关系，儿童不进入恋爱叙事；⑥真实感宪法对其不豁免，但不得借"真实感"强化成人化特征。
- 民族/地域条目只作外观与世俗造型翻译，遵守 `references/demographics-and-body.md` 的合规红线（不联想性格/阶层、不贬义漫画化、不主动调用宗教符号）。
- 职业/工作环境条目按**三层翻译**（装束无标识通用款 + 体貌印记 + 场景光线）产出，但**本交付形态为浅灰色纯色背景，只取前两层**（装束 + 体貌印记）入消息；场景空间与光线**不再入画**（背景恒为浅灰纯色）。遵守 `references/occupation-environment.md` 的合规红线（无真实机构标识、不渲染事故血腥、职业不作性格阶层联想）。
- 年代/时代条目只作**大众日常造型翻译**（发型服装 + 鞋履 + 随身物参考），遵守 `references/era-style.md` 的合规红线（无真实政治符号、不舞台化猎奇、不与真实历史人物撞款）。
- **情绪层在本交付形态下恒为中性**：四视图设定图要求"无表情"，故瞬时情绪词**一律不写进消息**（仅作气质参考）；气质基调仍通过骨相/五官形态体现。规范见 `references/emotion-expression.md`。
- **真实感是全局宪法**（所有词典、所有档位不豁免）：人物必须像"能被真实拍到的人"而非"被渲染的形象"。禁磨皮美颜、禁对称完美模板脸、禁空洞眼神、禁僵直摆拍姿态、禁贴图衣纹与手部错乱；每条档案必须携带 ≥2 个真实感锚点（痣/疤/斑/纹/不对称）。规范见 `references/realism-standard.md`（必读）。

## 交付形态（唯一）

- **只交付一张图**：浅灰色纯色背景的**角色四视图设定图（character turnaround）**，21:9 横幅 · 标准画质 · 2K，`[角色名]_turnaround_21x9.png`。
- **四个视图横向排列在同一张图内**（左→右）：
  1. **高清正脸特写**——正面平视的头部特写，五官清晰为主要信息；
  2. **正面无头全身**——正面站姿全身，**自锁骨上方自然截断至鞋底**；头部、下巴与脖子**不得出现**，截断处只保留完整的衣领开口与浅灰色纯色背景；
  3. **右侧无头全身**——右侧面站姿全身，截断规则同第 2 项；
  4. **背面全身**——背面站姿全身，**保留头部**（后脑与发态可见）。
- **统一性硬要求**：四个视图为同一人物（脸型/五官/发色一致）、**同一套服装**（同款同色同细节，含鞋履）；**无表情**；**双手自然下垂、自然站立、无动作，手中无任何道具**。
- **浅灰色纯色背景**：无环境、无场景、无渐变、无道具、无文字与编号标注。
- **直接生成，无前置基准**：单条消息一次直出成品，**不先出浅灰底基准图、不做任何本地拼合**（无拼版/抹头/派生视角脚本环节）。
- 用户提供参考脸图要求改造 → 从参考图出发走图生图，流程见 `references/liblib-integration.md` 末节。

## 工作流

### 第 1 步：解析描述，识别盲区词汇

从用户输入中抽取以下要素，缺省项用合理默认值并在档案中标注"推断"：

 1. **性别与年龄**（如"四十岁上下的女性""九岁男孩"）——缺失则默认中性偏 35–45 岁，并向用户确认或说明推断。年龄档翻译见 `demographics-and-body.md` 第二节（成人档 2.1 / 未成年档 2.2）；未成年角色须叠加第六节安全约束。全身视图需要**真实头身比**（少年约 6–7 头身、学龄约 5–6 头身、婴幼儿约 4 头身）。
 2. **国家/民族/地域外观**（如"北方汉人、藏族、日本人"）——翻译为肤色/发色区间 + 骨架倾向 + 世俗造型元素，遵守合规红线。见 `demographics-and-body.md` 第四、五节。
 3. **体型**（如"健壮、纤细、魁梧"）——翻译为肩/颈/胸背特征；**四视图含全身，须同时给腰胯与腿型倾向**。见 `demographics-and-body.md` 第三节。
 4. **脸型与骨相**：额头、颧骨、下颌、下巴、整体轮廓。
 5. **五官逐个**：眉、眼、鼻、口（唇）、耳——每个只取"有信息量"的，用户没提的不强行编造；给"重要度"排序。**视图一为高清正脸特写，五官翻译是它的主要信息量。**
 6. **皮肤与质感**：肤质、气色、皱纹、痣、疤痕等。
 7. **气质基调**——长期底色（断语，如"沉稳、有城府、温柔、清冷"）→ 走骨相与五官形态，进"长相"。**注意：本交付形态表情恒为中性，气质只靠长相与仪态传达，不靠表情**；用户若给了瞬时情绪词，仅作气质参考，不写进消息。
 8. **服装与发型**（发型、上衣、裤子、鞋）——**四视图的服装是核心信息**：视图二/三无头，身份全靠服装与体型传达，故须给到"形制 + 颜色 + 面料质感 + 鞋"这一级；用户没说全时按职业/年代档合理推断并标注。
 9. **职业/工作环境**（如"在渔船上干了二十年的渔民、外科医生、外卖骑手"）——翻译为\*\*装束（无标识通用款）+ 职业体貌印记（皮肤/手/体态）\*\*两层入消息；**场景空间与光线本形态不入画**。见 `references/occupation-environment.md` 第一\~四节。
10. **年代/时代**（如"90年代国营厂女工""民国教书先生""69年生人"）——翻译为大众发型服装款 + 鞋履 + 装束旧化质感，并按"年代×年龄""年代×职业"规则与年龄档、职业装束合并。见 `references/era-style.md`。

**识别盲区词**：相学术语、古文描述、抽象气质词、族属地域词、体型词、职业与装束词、年代/时代词，都属于需要查词典翻译的"盲区词"。

**词典路由**：

- 现代面相/气质词 → `references/face-reading-lexicon.md`
- 四字古语/整相断语/生僻骨名/象形断语（`剑眉星目`、`鹰视狼顾`、`伏犀骨`、`龙形`）→ `references/classical-physiognomy.md`（该词典内建"抽形态、弃命理"三律）
- 国家/民族/地域/年龄档/体型/头身比 → `references/demographics-and-body.md`
- 职业/工作环境/劳动印记 → `references/occupation-environment.md`
- 近现代年代/时代词（民国→当代→近未来）→ `references/era-style.md`；古代朝代词（"唐代""宋朝"）→ `references/classical-physiognomy.md` 古风层
- 红线总原则：**生成消息与档案中禁止出现命理断言（主贵/主刑克/帝王命/克夫）与任何基于民族的性格/阶层联想**，只保留可绘特征与中性气质词。

- **翻译原则**：档案中的"翻译后可视特征"必须是**绘制引擎可直接执行**的中性描述——形状、比例、位置、质感，而不是价值判断。如"贵气"→"五官比例端正对称、鼻梁中正挺拔、下颌线条清晰利落、仪态舒展不谄媚"，而不是"一看就是大人物"。

**档案校验**：若用户描述内部矛盾（如"圆润娃娃脸"+"下颌骨突出有棱角"），按主气质判定优先级并只保留一方，向用户说明取舍。民族外观与用户明确五官描述冲突时，以五官描述为准。

```
视图四（最右）：背面全身——背面站姿全身，保留头部。
统一要求：四个视图同一人物、同一套服装（同款同色同细节，含鞋履）；无表情；双手自然下垂、自然站立无动作、手中无道具；浅灰色纯色背景，无环境、无道具、无文字标注。
[人物特征标准块——档案翻译后全部特征行：地域外观/体型与头身比/面部特征(含真实感锚点)/服装与发型(含鞋)/装束印记/整体气质/中性表情。]
[真实感默认行 + 虚构人物注意句]
```

**绝不加**：分辨率词、画质堆词、镜头术语（除非用户指定）、相机型号、任何环境/场景短语（背景恒为浅灰纯色）。

### 第 4 步：质检与迭代

对照档案检查交付图，输出命中表。常见失败模式：

- 眉形/眼型被"平均化"（最常见）→ 重发时把眉眼特征提到句首并加"必须/强调"。
- 下颌/颧骨骨感丢失 → 补"下颌线清晰/颧骨形态"。
- 气质只靠表情堆出来、五官没跟上 → 强调五官层面的特征化翻译（本形态本来无表情，气质必须落在长相上）。
- **四视图不齐/不合规**（缺视图、顺序错、无头视图仍画出头/下巴/脖子、背面视图没画头）→ 按 liblib-integration 失败排查重发，把四视图清单逐条前置到消息开头。
- **视图间不一致**（同一人物的脸/发色/服装在不同视图漂移、服装换款换色、鞋不一致）→ 把"同一人物、同一套服装（同款同色同细节，含鞋履）"提为强约束句重发，并逐视图重复一遍服装描述。
- **背景非浅灰纯色**（出现环境、光影渐变、道具、文字标注）→ 重发并补"浅灰色纯色背景，无环境、无道具、无文字与编号标注"。
- **出现道具/手中有物**（工具、包、杯、器械等）→ 重发并补"手中无道具、画面内不出现任何物品"。
- **姿态带动作**（叉腰、抱臂、插兜、行走、扭头）→ 重发并补"双手自然下垂于体侧、自然站立无动作、不握拳不插兜"。
- 写实度不足、像插画 → 追加"接近真人摄影质感、皮肤表面平整、近距离可见细毛孔"（唯一允许的少量质量基线词；**不写"真实纹理"**）。
- **族属外观被画成刻板漫画** → 回退为区间词 + 世俗造型元素重发，并检查是否误加性格联想。
- **职业被画成刻板形象**（如只穿制服没有印记）→ 补该职业的体貌印记段（晒痕/茧/油污手），让人物被环境"打磨"过；无头视图的服装细节是重点。
- **年代错乱**（发型/服装跨年代混搭，如 30 岁青年脸配 50s 老干部发型）→ 重发时把年代压缩为固定短语（如"1990年代中国北方工人日常造型"），并遵守"发型服从年龄档"规则。
- **一眼假**（磨皮瓷感/模板网红脸/左右绝对对称/空洞眼神/手部错乱/姿态僵直/衣纹贴图）→ 按 `references/realism-standard.md` 第三节校正短语加码重发；皮肤单色/CG/瓷感按第五节 5.4 加码句重发；肢体与衣纹问题按第六节动态层规则逐项修正（手与脸同档、衣纹物理成因），并核对真实感锚点是否被"平均化"抹掉。
- **皮肤出现一圈圈 / 鱼鳞状 / 涡旋状 / 局部重复卷曲纹理**（高频细节伪影，不是皮肤结构）→ 按 `realism-standard.md` 5.6 处理：先删净消息里"纹理 / 走向 / 毫毛"类词并补"表面平整、远看肤色均匀"，必要时才追加负向清单（liblib 规则 13）；**不要继续加"更真实/更细节"**，那是反方向，越加越重。
- 输出带多余人/文字/logo → 追加负面："画面中仅一人、无文字水印"。
- 画面出现真实机构标识（徽章/警号/LOGO/品牌字）→ 重发，装束改"无标识素色通用款"。

一次最多迭代 2 轮；仍不达标则输出档案 + 已生成图 + 差距说明，供人工微调。

## 质量门（交付前核对）

- 档案是否覆盖用户输入中每个有信息量的特征（无遗漏、无过度脑补）？
- "翻译后可视特征"是否都是可绘制的中性形状/质感描述，而非价值判断？
- 古风输入是否只取形态内核？民族/地域是否只用外观与世俗造型词、无性格/阶层联想？
- 职业是否翻成"装束 + 印记"两层？是否无真实机构标识、无职业性格联想？（环境场景不入画）
- 年代是否翻成发型服装/鞋/旧化质感？发型是否服从年龄档？是否无真实政治符号、无舞台化猎奇？
- 服装行是否给到"形制 + 颜色 + 面料 + 旧化 + 鞋"这一级，且四视图共用一份描述？
- **真实感门**：无磨皮美颜瓷感/无模板网红脸？皮肤自然（极简默认句生效，无塑料感）？**无高频纹理伪影**（无鳞片/鱼鳞/涡旋/网格/皮革纹）？≥2 个真实感锚点命中且位置稳定？像"被拍到的人"而非"渲染的形象"？（见 realism-standard 第九节；出伪影查 5.6 排障手册）
- **未成年门（仅未成年角色）**：是否非性化（无性暗示、暴露或成人化着装、成人化身材比例）？服装与情绪是否年龄适配？是否未参照真实儿童、未呈现创伤画面与亲密关系？皮肤与骨相是否按 2.2 未成年档翻译（未套用成人骨相词与相学断语）？头身比是否为其年龄档的真实比例？（见 demographics-and-body 第六节）
- **规格门（唯一成品）**：交付是否只有一张图？是否单张 21:9 横幅·标准画质·2K、未被拆成多张？**四视图是否齐备且顺序正确**（正脸特写 → 正面无头全身 → 右侧无头全身 → 背面全身）？
- **截断门**：两个无头视图是否"自锁骨上方自然截断至鞋底"、**未出现头部/下巴/脖子**、截断处保留完整衣领开口？背面视图是否**保留了头部**？
- **统一门**：四视图是否同一人物（脸/发色一致）、**同一套服装**（同款同色同细节，含鞋）？是否**无表情**、**双手自然下垂无动作**、**手中与画面内无任何道具**？背景是否**浅灰纯色、无环境无文字**？
- 是否清除了命理断言词与风格堆词？
- 生成图与档案逐项比对是否吻合，偏差是否已向用户说明？
- 是否输出档案 + 命中表 + 实际发送的描述 + 交付图路径？
