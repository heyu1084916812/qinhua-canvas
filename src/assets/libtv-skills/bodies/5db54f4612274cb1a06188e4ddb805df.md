# 明亮青橙胶片视频

把用户的题材转化成可执行的视频视觉提示词：真实摄影质感、明亮但柔和的日光、明确青橙色块、清晰主体，以及随镜头运动仍成立的构图。默认中文输出，用户需要时提供英文版本。

## 用户已确认的视觉方向

以 references/mj-consistency.md 中用户满意的第一张 MJ 图片为最新主参考，处理风格与稳定性任务时先读它。涉及 LibTV 或跨模型灰雾、泛白漂移时，再读 references/libtv-prompt-calibration.md，以其中最新提示词修正为准。原 references/approved-look.md 的游乐设施截图降为辅助参考。用户本次明确仅用提示词修改和约束，不添加 MJ 参数。

默认优先真实日光中的青蓝、砖橙红和奶油白色块，柔和但有密度的色彩、轻微光学软感、可读的材质与自然运动感。场景不限游乐园，也不要求每张都出现天空。避免沿用此前被用户否定的过分光洁、金黄逆光、旅游宣传照式效果。

用户希望复古胶片感更明确，但明确否定了后续过度浓郁、怪异的色彩。以原始截图的色彩强度为基准：天空为明亮、中等饱和度、略偏青的蓝色，保留自然渐变；云层为中性灰白或极轻微暖白。复古感主要来自细密适度的颗粒、轻微光学软感和柔和高光，不靠深孔雀蓝、黄色云层、强暗角或全局暖色滤镜。风格化只做克制的局部冷暖分离，保持写实材质与明亮曝光。

最新跨模型修正优先于上述历史描述与早期示例：默认天空为明亮清透的青绿色／绿松石色，保留适中色彩密度，不灰白、不深蓝。暖色为陶土橙、旧砖橙与暖象牙白。明亮中间调、平滑高光，同时保持明确明暗分离与有深度的阴影。不要叠加“浅灰、低饱和、低反差、褪色、雾感”作为默认风格；这些词在 LibTV 的生成样例中伴随泛白或灰暗效果。以清晰空气、扎实色彩和局部柔和高光表达目标。暖象牙白是物体颜色，不等于把白云和全画面染黄。

## 视觉基调

- **明亮胶片感**：中间调明亮且有色彩密度，暗部保留层次，高光柔和滚降，白色略带奶油感；轻微光学软感与细颗粒可见但不过度。保留材质、不做数码式锐化。胶片感不依赖压暗、灰雾、粗颗粒、划痕或全局复古滤镜。
- **胶片光晕（Halation）**：默认加入轻微、局部的红橙色光晕，仅出现在强反光、逆光边缘或高亮与暗部交界处，窄而柔和，强度随亮度自然变化。不能把所有物体边缘描红，不能变成全局黄雾、黄色云层或大范围辉光。缺少强高光时效果可以极微弱，不为展示光晕添加无关灯光。与 Bloom 区分：Halation 是局部红橙晕边，Bloom 是更宽的高光柔光扩散；不要用整体暖白调色代替光晕。
- **青橙关系**：偏青的蓝色主要来自天空、水面、墙面、衣服或环境反射；暖色优先来自砖橙红、赭橙、暖红涂装等主体材质，辅以肤色、木材和光照。允许明确饱满的大色块对比，保持真实曝光与色彩层次，避免荧光色和全局染色。不要把青橙自动解释成金色夕阳与青色阴影。
- **自然色彩**：肤色健康，白色可轻微偏暖但不染黄，绿色保留自然变化。物体本身可以呈砖红或橙红，肤色不可被统一推成橙红；青色不荧光化。冷暖焦点形成层级，色彩饱满且有密度，不追求灰淡或高饱和滤镜感。
- **极简主体**：每个画面默认只有一个主视觉主体，最多两个；仅在明确叙事需要时使用第二主体，且保持主次。主体按独立视觉焦点计数：过山车列车及必要轨道可视作一个完整主体，乘客作为其从属细节，天空与云层作为背景；不能借“整体”名义加入多台设施、多个同等醒目人物或多辆车。背景不引入抢眼的建筑、标牌、装饰和其他设施，优先大面积干净留白。
- **干净美观**：控制背景杂物、文字和抢眼亮点，保留合理负空间，用必要的前中后景建立深度。主体轮廓清楚，避免背景线条穿过头部和切断关节。景深和前景仅在帮助主体时使用，不为丰富画面增加额外物件。
- **光线可解释**：默认明亮的白天日光和天空漫射补光，可有清楚受光面与真实阴影，但反差温和；根据场景选侧光、窗光或逆光，不默认金色时刻。保持云层与亮面细节，避免过曝换取明亮。

这些是默认风格；用户指定夜景、情绪、参考图或品牌色时，以其要求为准，在合理曝光内保留冷暖层次，不强行改成白天。

## 构图选择

每镜头选一种主构图，必要时搭配一种辅助方法。用主体位置、线条走向和镜头变化描述它，而不是堆叠构图术语。

方法适合场景必须写清的画面关系对角线构图街道、楼梯、山脊、奔跑、动态场景道路或主体动作沿左下至右上等明确方向展开；保持合理水平线，对角线不等于倾斜相机。三分法构图人物、旅行、环境叙事主体位于左或右侧三分位置，朝向或运动方向留空间；根据天空和地面重点选择地平线高度。中心构图产品、建筑、仪式感、英雄镜头主体落在中轴，周围简洁或对称，借光线和背景分离突出主体；不要让中心主体过小失去焦点。引导性构图道路、走廊、河流、栏杆、光影线条从前景进入画面并汇聚至主体，而非把视线引向边缘或无关亮点。框中框窗户、门廊、枝叶、拱门前景框住主体，边缘不过度遮挡，焦点落在框内，利用层次增加纵深。留白构图孤独、安静、广告文案空间主体与留白形成平衡；说明留白方向和用途，避免无意义空白。三角或层次构图单一静物、建筑、山景或双主体用同一主体内部的形态或最多两个主体与背景线条建立稳定关系；不得为了三角形增加第三主体。

多镜头序列按叙事需要变化构图和景别；无需为了覆盖所有方法加入无用镜头。

## 从静态画面到视频

### 在 LibTV 中使用

用户要求在 LibTV 中生成时，先按本 skill 形成完整提示词，再使用已安装的 `libtv-cli` skill 操作画布。通过实际模型 schema 确认提示词字段，将完整视觉描述写入生成节点；需要参考图时通过 CLI 上传本 skill 的最新主参考 `assets/mj-approved.png`，按模型支持的参考图方式连接或填写。默认只借鉴参考图颜色和摄影质感；用户要求复现布局时才同时参考内容与构图。读取 `libtv --help` 和相应子命令帮助，不编造命令、参数或 skill 注册接口。仅在用户已要求实际生成时执行模型运行；若只是安装或打包，不创建画布或触发付费生成。

1. 从用户给出的主体、场景、情绪和动作出发。未指定模型时使用通用自然语言，不编造模型专属参数。普通缺项可合理补全，并简短说明影响结果的假设。
2. 先确定光源、冷暖分工和主构图，再选择景别与机位。焦段可用作视觉描述，但不把它当作模型一定执行的参数。
3. 每镜头给出一个主要动作和一个主要运镜，例如慢推、横移、跟拍或固定机位。控制运动幅度，保持焦点、主体比例和画面边界可读。
4. 写清开始、运动过程及结束时的构图关系。跟拍时保持前方空间，横移时防止前景遮挡主体，推近时避免意外裁切；只有叙事需要时才主动改变构图。
5. 多镜头保持肤色、白平衡、颗粒尺度与冷暖基调一致，允许不同场景有合理的亮度和色温变化。避免逐帧曝光跳变、纹理闪烁、主体变形和背景漂移。
6. 图生视频时以输入图的身份、物体、空间结构和主构图为锚点。仅在用户要求改风格时提出青橙与胶片调整；不要声称提示词能精确保留身份或完成像素级调色。

默认交付一段可直接复制的完整提示词，加一段精简的避免项。用户要求分镜时，逐镜给出画面、构图、光色、动作与运镜；有总时长时使镜头时长与其吻合。用户只要色调模块时只提供模块，不扩写剧情。

## 可复用提示词模块

### 色调与质感

写实日光胶片摄影，明亮清透的青绿色天空，保留适中的色彩密度与自然渐变，不灰白、不深蓝；少量柔和中性白云。陶土橙与暖象牙白主体颜色扎实且不过饱和。明亮温润的中间调，高光平滑不过曝，受光面与背光面清楚分离，阴影有深度并保留细节。空气清晰，真实涂装和布料纹理可读，细密轻微胶片颗粒；柔和感集中在高光过渡，主体轮廓保持清楚。极简背景，一个主视觉主体，最多两个且主次明确，保留大面积连续留白。

默认追加：仅极少数强反光边缘有微弱、窄范围的红橙胶片光晕，其余区域不发光，不能沿整条轨道或机身描出辉光。避免全局灰雾、褪色、泛白、欠曝、普通钴蓝或深海军蓝天空、荧光色、黄色云层、强暗角、HDR、过度锐化和渲染感。视频中颗粒细微自然变化，不能导致材质闪烁或曝光跳变。

按实际题材替换光源与色彩载体，不强行把原本没有暖色的物体改为橙色。无人场景删除肤色描述；夜景改用真实灯光与环境反射，不套用阳光。用户参考优先于下方早期示例；这些示例用于理解构图，不作为默认金色光线配方。

### 完整提示词骨架

默认融入两条约束：一个明确主视觉主体，最多两个且主次分明，背景极简并保留留白；强高光与暗部交界处有微弱、窄而柔和的红橙色胶片光晕，天空与白云保持自然颜色。光晕只跟随真实亮部，不生成全局染色或发光描边。

先写主体与场景，再描述可见动作、景别和机位；接着写主体在画面的位置、前景或道路的具体走向以及留白方向；加入适配场景的色调模块；最后写单一主运镜、运动过程的构图保持及结束画面。把这些内容写成自然语言成稿，不向用户交付未填写的占位符。

### 避免项

塑料或蜡质表面、CG 渲染感、过度数码锐化、过度 HDR、均匀金黄滤镜、画面昏暗、过曝高光、死黑阴影、全局青色偏色、橙红肤色、荧光饱和色、粗颗粒、强烈光晕、背景杂乱、主体被遮挡、随意裁切、曝光闪烁、色温漂移、物体变形、镜头抖动。

仅保留与任务相关的避免项。目标工具不支持负面提示词时，将关键约束融入正文，不编造负面提示词参数。

## 示例

**旅行人物 · 三分法与引导线**

清晨海边，一位穿米白亚麻衬衫的旅行者沿步道缓缓向前走。中远景，平视机位，人物位于右侧三分位置，面向画面左前方并留出行进空间。步道由左下方延伸至人物脚边，远处海岸形成简洁层次，背景仅保留海面和少量建筑。低角度阳光从侧后方勾勒肩部，天空反射柔和照亮面部；海面和环境阴影呈淡青色，阳光和肌肤呈温润金橙色。画面明亮通透，肤色自然，细腻胶片颗粒，高光柔和。镜头以稳定的慢速平行跟拍保持人物在右侧三分位置，结束时人物仍完整可见，光色与曝光稳定。

**建筑 · 中心构图**

明亮午后的现代美术馆入口，浅色石材与一扇温暖木门形成清晰焦点。正面广角中远景，木门位于画面中轴，两侧立柱形成对称框景，地面接缝由前景汇聚至入口。柔和日光照亮墙体，廊下阴影带少量青色环境反射，木门保持自然橙棕色，白墙中性且保留纹理。电影胶片质感，细颗粒，轻微高光晕染，亮部不过曝。镜头沿中轴缓慢推进，始终保持垂直线稳定和门框完整，结束于入口的对称中景。

**动态街景 · 对角线构图**

晴朗下午，一位骑行者沿整洁滨海公路平稳前进。道路从画面左下方斜向右上方延伸，骑行者位于靠近右上三分交点的位置，前方留出道路空间，海平线保持水平。海水和远处阴影呈清透青色，斜射阳光在衣服及路面上形成克制的橙金色亮部。清晰主体、简洁背景、柔和高光、细腻胶片质感。镜头稳定侧向跟拍，道路的对角线关系贯穿整个镜头，骑行者比例稳定，动作连贯，结束时继续保留前方空间。

## 交付前检查

确认提示词实际描述了明亮曝光、青橙的具体载体、自然中性色、清楚的视觉焦点和可执行的构图；确认主视觉主体默认一个、总数不超过两个，背景极简；确认光晕只在强高光处局部出现，未染黄天空或白云。确认运镜不会破坏构图，胶片质感不会吞掉细节。删除互相矛盾的光线、同时堆叠的运镜和无作用的形容词。只在看过生成结果后评价实际画面效果；仅写提示词时，不声称已生成或验证视频。
