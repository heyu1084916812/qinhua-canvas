## 做什么

把"现实场景 + 毛绒萌系 IP 角色"的治愈短视频，拆成中文分镜脚本与可直接粘贴的视频提示词，覆盖抖音 / 视频号 / 小红书毛绒账号的竖屏内容生产。

## 需要什么输入

- 题材或剧情方向（可选；可从 `reference/PLOT_LIBRARY.md` 剧情库或 `reference/FESTIVAL_CALENDAR.md` 节气日历里挑）

- 角色参考图：毛绒 IP 的正面 / 侧面 / 背面三视图 + 材质微距（已有或现设计）

- 场景与道具参考图（每个提示词组需要）

- 画幅：默认 9:16 竖屏，少数 16:9 横屏

- 单条时长：默认 5-10 秒

- 视频生成模型：可灵 / Seedance / MiniMax 等

最少输入只要给一句话方向，其他都按"固定治愈风格底座"和"剧情库"自行决定，不要反复反问。

## 怎么做

**画风固定成治愈系**：现实生活场景 + 毛绒萌系 IP，慢节奏，象声词表演，低饱和暖调，**禁止棚拍 / 纯色背景 / 三维渲染感 / 动画感 / 插画感**。角色材质必须可信：绒向、压痕、起球、飞绒、重量变形、接缝走线必须可见。具体四段风格控制见 `reference/STYLE_BLOCK.md`。

**节奏固定成 5-10 秒单镜头**：每条提示词不超过 10 秒，最多 2 个镜头，禁止快切。摄影机总位移不超过 20 厘米，缓慢手持呼吸感，禁止环绕 / 无人机 / 慢动作 / 慢门拖影。具体运镜规则见 `reference/CAMERA_PACING.md` 与 `reference/ASPECT_RATIO.md`。

**镜头结构固定成 7 块**：以 `不要出现BGM，不要出现字幕` 开头 → 四段风格控制（`【全局画质】` `【角色材质】` `【灯光与风格】` `【核心治愈机制】`，**注意：通用版的【核心特效】在本 skill 改名为【核心治愈机制】，写"最打动人的物理瞬间"**）→ 素材句柄 `@image1` `@image2` → 空间与镜头数量警告 → 镜头段（`画面动作概述：` → `画面构图：` → `机位：` → `动作：` → `象声词：` → `音效：`）→ 环境活动 / 全场音效 → 防错警告。完整结构与示例见 `reference/PROMPT_PATTERNS.md`。

**八道 gate 必须逐道确认**：① 角色锁定 → ② 剧情与象声词 → ③ 画幅 → ④ 空间调度 → ⑤ 时间划分 → ⑥ 提示词结构 → ⑦ 交付形式 → ⑧ HTML QA。任何修改要回到对应 gate 重确认，不得跳过。

**象声词必出现且必须三件套**：基础音为 `呼呼` `悠悠` `baba` `波比波比` `瓜皮` `哈皮`，扩展库约 60 个（满足 / 惊喜 / 撒娇 / 猎奇 / 进食系）。每个象声词必须写成"发声 + 身体同步动作 + 声音质感"三件套，例如不是"角色说呼呼"，而是"第 3 秒发出"呼呼"，身体整体缓慢起伏一次，腹部绒毛鼓起再回落，声音为鼻腔柔和气流声，尾音拖长 0.8 秒"。详细词库见 `reference/ONOMATOPOEIA.md`。

**防崩坏硬约束（每条提示词都要带）**：禁止角色被画成真人；禁止长出人类手指；禁止悬空漂浮（必须有接触面和接触阴影）；眼睛为哑光材质（不转动 / 不变大小 / 单一柔和反光点）；嘴为固定线迹（不开合）；绒毛必须有物理反应（被压塌要回弹 / 遇水要黏成一撮 / 遇热要贴伏）。完整 12 条防崩坏清单见 `reference/CHARACTER_LOCK.md`。

## 产出什么

- 一份按提示词条数分段的中文分镜脚本，每段含：时间段 / 画幅 / 象声词 / 四段风格控制 / 句柄 / 画面构图 / 机位 / 动作 / 象声词 / 音效 / 字数统计

- 选 `只要文字提示词`：直接在对话里按顺序输出，每条间空行加分隔线

- 选 `生成网页`：保存为 `FluffyShotlist_<题材>_v1_0.html`，带复制按钮、分段资产对照表、字数统计、治愈调性配色。完整模板见 `templates/HTML_TEMPLATE.md`

## 什么时候问你

- 用户没给三视图或材质微距 → 停下来要图，不要靠文字描述硬生成

- 用户给的剧情在 250+ 条剧情库和节气日历里都对不上 → 问一次确认方向，不要再问第二题

- 画幅从竖屏改横屏（或反过来）→ 重写构图百分比和景别，不是替换比例数字

- 生成结果出现真人化 / 漂浮 / 长手指 / 绒毛纹丝不动 / 眼睛转动 / 嘴开合 → 告诉用户具体崩坏点并改提示词，不要沉默继续

- 角色形象在两条提示词之间漂移 → 回到角色锁定 gate 重确认

- 用户说"风格你来定"或"随便做" → 直接套用固定治愈风格底座和剧情库，**不问**；剧情库也匹配不上再问

- 用户要求改治愈系以外的风格（如暗黑 / 赛博 / 高对比商业广告）→ 一次确认是要放弃本 skill 还是临时破例
