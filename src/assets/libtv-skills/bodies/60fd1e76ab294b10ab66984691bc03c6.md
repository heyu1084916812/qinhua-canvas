## name: neon-webverse-director description: 将用户上传的实拍或动画视频转换为原创高能多维漫画三维电影风格。适用于视频风格化、三维漫画动画、动作镜头强化、动态漫画摄影与跨镜头一致性处理。

# Neon Webverse Director（霓虹多维漫画导演）

> **一句话简介：** 让任意影片跃入霓虹多维漫画宇宙——每一帧都以网点、错位色彩和爆裂动势，完成主角级登场。

## 目标

将用户上传的视频处理为连贯、原创的三维漫画动画电影风格，同时保留故事节点、人物身份、原始镜头意图与剪辑节奏。使用可泛化的多维漫画视觉语言；不得模仿特定工作室、电影、系列角色、服装、标志或原片镜头。

## 所需输入

收集或从素材中推断以下信息：

- 源视频、时长、画幅比例与目标交付分辨率。
- 主体人物、情绪目标，以及必须保持可辨识的内容。
- 风格强度：`轻度`、`英雄` 或 `全漫画`。
- 需避开的元素：品牌服装、标志、可识别角色、文字或肖像。

用户未指定时，默认使用 `英雄` 强度，保留源视频画幅，并按 15–30 秒社交媒体短片优化。

## 视觉语言

跨镜头一致地使用以下元素：

- **三维图形角色：** 棱面感但富有表情的造型、干净轮廓、赛璐璐明暗面、可信的接触阴影与克制的材质细节。
- **漫画印刷质感：** CMYK 网点、选择性墨线排线、纸张颗粒，以及仅在高能帧出现的轻微套印错位。
- **动势设计：** 强调姿势、选择性降帧节奏、突然推拉镜头、倾斜构图、长焦压缩后接极广角透视；速度线只服务于剧情节拍。
- **冲击设计：** 原创拟声图形、放射爆点、碎屑卡片、画框裂变，以及命中或穿越时短促的色散效果。
- **色彩脚本：** 每场景限制主色；仅在转折点使用霓虹青、品红与亮黄对比，避免全片视觉疲劳。

不得将任何系列名称作为风格提示词。不得复刻可识别的服装、徽记、面具、角色、标题字效、原片构图或镜头调度。

## 工作流

### 1. 分析素材

按镜头拆解视频。为每个镜头记录主体、动作、摄影机运动、主光方向、情绪节点与时序风险（高速运动、遮挡、人群、文字、面部近景）。

必须保留：

- 演员身份、服装色系、视线方向、关键道具与屏幕方向的连续性。
- 原剪辑节奏，除非用户明确要求重新剪辑。
- 对白清晰度与原始声画同步，除非用户要求替换声音。

### 2. 制定视觉方案

生成前先写出简短方案：

```text
场景色彩：午夜靛蓝 + 电光青；品红仅用于冲击瞬间
角色语言：三维赛璐璐明暗与雕塑感轮廓；不使用系列化符号
摄影语言：低机位推进；转折点仅使用一次突然推近
图形语言：网点阴影；动作帧使用青/品红套印偏移
情绪：坚定、兴奋、真实
```

### 3. 按镜头风格化

每个镜头使用以下提示词结构：

```text
[主体与动作]；保持人物身份、姿势、服装色系和镜头方向；
原创高能三维漫画动画、赛璐璐明暗的雕塑感形体、网点阴影面、
选择性墨线轮廓、立体灯光、[场景色彩]、[摄影语言]、
[与动作匹配的一项图形强化]、电影级运动连续性、干净边缘。
避免任何系列角色、标志、面具、原电影镜头、水印、文字伪影、额外肢体、
人脸漂移和服装细节不一致。
```

每个镜头只选择一项图形强化。例如：奔跑使用速度线，撞击使用放射爆点，揭示使用分层视差拼贴；不要默认叠加三者。

### 4. 控制时序一致性

- 每个新场景先建立稳定、干净的定场画面。
- 在相邻镜头间传递角色参考与色彩参考。
- 面部和对白镜头优先保持五官稳定、口型同步，再添加网点效果。
- 高速动作必须包含清晰的关键姿势、预备、命中与恢复；仅在强调帧使用降帧节奏。
- 先修复伪影，再叠加网点、套印偏移与颗粒。

### 5. 合成与交付

按以下顺序完成后期：

1. 统一曝光并稳定问题镜头。
2. 应用三维漫画风格与连续性修正。
3. 添加选择性图形效果与场景级调色。
4. 恢复或混合对白、环境声与音乐。
5. 输出母版，以及 H.264 交付版；仅在用户要求时烧录字幕。

## 风格强度预设

预设适用场景执行方向`轻度`对白、纪录片、品牌片赛璐璐明暗、克制色彩、极轻网点；不使用降帧。`英雄`预告片、音乐视频、运动与动作片强轮廓、每个剧情节拍一项强化、动态镜头标点。`全漫画`奇幻、高能短片、片头分层印刷效果、强调帧降帧、图形化转场、强烈但可读的动作设计。

## 质量验收

交付前逐项确认：

- 人脸、手部、服装与道具在所有衔接镜头中保持一致。
- 图形效果只在有意图的节拍出现，不应持续遮挡画面。
- 文字、字幕与产品标记清晰可读，或按用户意图移除。
- 声画同步、帧率、画幅比例与成片时长符合原素材或项目简报。
- 成片呈现原创多维漫画三维电影气质，而非某一既有电影或系列的复制品。

## 面向用户的输出格式

按以下顺序返回：

1. 一句话创意处理方案。
2. 选用的风格强度与场景色彩。
3. 镜头清单，并标注高风险连续性镜头。
4. 导出参数及简明的处理变更列表。

## 示例请求

```text
使用 $neon-webverse-director 将我上传的 22 秒跑酷视频改造成原创的英雄级三维漫画短片。保留跑者的可辨识度与日落场景，以青橙为主色，只在落地瞬间使用品红冲击效果，并让最后一跳具有穿越维度般的突破感。
```
