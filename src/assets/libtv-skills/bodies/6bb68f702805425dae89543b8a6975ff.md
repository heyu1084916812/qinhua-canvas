# 天宫巨物美学提示词

默认把用户的一句话扩写成一个可直接生图的固定格式电影起始画面，以及一个从该画面自然继续运动的单镜视频提示词。不要先解释创意，不要要求用户补充专业参数；除非用户明确只要其中一项，否则始终同时输出图片和视频提示词。

## 路由

- 用户只给一句人物、动作或场景：进入**单画面模式**，只输出图片提示词和视频提示词。
- 用户明确说15秒、30秒、多镜头、分镜或完整短片：进入**多镜头模式**，读取 references/style-blueprint.md。
- 用户上传参考视频并要求分析或复盘：先建立镜头证据，再读取 references/style-blueprint.md；只把稳定规律写回 Skill。

## 单画面模式

读取 references/single-shot-prompting.md，按以下步骤执行：

1. 从原句提取人物数量、性别/年龄感、服装颜色、动作、目的地、情绪和显式场景；用户写出的信息视为不可改变锚点。
2. 先确定摄影机位于远望平台、建筑内部、长廊中轴或建筑侧面，再选择焦段和构图。人物脚下的平台、桥、长廊或殿堂本身也必须具有巨构尺度，再用更遥远的主建筑或巨型物体完成第二级尺度跃迁；只设置一个主奇观，不把所有仙侠元素塞进同一画面。
3. 为所选机位写出量化尺度证据：近处正常尺度锚点限制在画面底部约6%至10%，人物约0.5%，连续结构至少8至12组并汇入同一消失点，极远主奇观占画面高度55%至70%且允许越出顶部或侧边。
4. 补全人物外观时保持简洁，只写视频连续性需要的年龄段、发型、服装层次、体型和一个识别色；不要凭空添加复杂首饰、武器或新角色。
5. 设计真正可动画的起始帧：运动人物要露出脚下路径和前进空间，等待人物要保留视线方向和环境空位；不要把动作写到终点。
6. 从同一画面继续写5秒单镜视频：明确人物动作轨迹、摄影机运动、环境微运动、结束状态和连续性约束。视频提示词不重新设计人物和场景。

## 固定母版

图片提示词必须采用“固定风格开头 + 当前场景主体 + 量化构图与尺度 + 光色材质 + 禁止项 + 参数后缀”的单段结构。不要改写成字段表、分镜表或解释性文字。

- 昼景固定以“东方神话巨构主义电影画面。晴朗淡青蓝天空，云层保持中性偏白，右侧可有克制的淡金逆光轮廓，不做整体暖橙滤镜。”开头。
- 月夜固定以“东方神话巨构主义电影画面。冷蓝澄澈的月夜天空，云层保持月白与雾青色，巨月或月光提供淡玉色主光，不做整体暖橙滤镜。”开头。
- 随后固定写入：极致远景或长焦强透视、近景/中景/远雾/极远景四层空气透视、体积云、电影级超写实、HDR、8K、结构可信、重量真实、尺度辽阔。
- 默认采用85–100mm中长焦压缩空间，优先100mm；用户明确指定其他焦段或模型时服从用户。不要同时写广角、鱼眼或夸张近大远小。
- 人物或正常尺度锚点占画面高度0.3%–0.8%，默认约0.5%；主建筑或唯一巨物占画面高度60%以上并允许越出边缘；至少45%为连续低信息留白。
- 图片末尾必须使用与场景匹配的一句“不要……”禁止项，并以“--v 8.2”结束。用户明确指定不支持该后缀的模型时才删除或替换。
- 视频提示词必须以“以上图片为首帧，5秒单镜头，无剪辑。”开头，只延续图片中的人物、建筑、光线和空间；写人物小幅动作、唯一摄影机运动、环境微运动、结束状态与连续性禁止项，不加入新角色或新奇观。

## 自动构图

- **默认尺度**：采用公里级远机位的极致远景。人物以画面高度0.5%为目标，允许稳定范围0.4%至0.6%；只需辨认人数、服装识别色、行进方向与粗略全身轮廓，不呈现面孔、手指、鞋履或衣料纹理。人物高度不得超过最近可见巨柱柱基的1/40，避免人物退化为噪点，也不得成为视觉主体。主建筑在设定上距离数十至数百公里，经过空气透视后仍占画面高度55%至70%并可越出画框。
- **华贵建筑**：默认不是素白空壳，而是具有中式古建筑的东方巨构。以朱漆木构、青白玉台基、青绿色琉璃、古金结构节点和彩绘斗拱构成主色；在飞檐、斗拱、门钉、藻井、铜门、栏板和仪典入口集中呈现鎏金、玉石镶嵌、雕梁彩绘与丝绸垂幔。装饰必须服从承重结构和透视尺度，华丽、尊贵、精工但不满金、不铺满画面，并继续保留至少45%低细节留白。
- **人物所在空间**：人物必须置于宽达数百米的悬空平台、横跨云海的巨桥、通天柱廊或高大殿堂中；场地边缘、柱基、台阶和空旷地面先压小人物，再由远处主奇观继续放大尺度。禁止“普通小露台上的小人物 + 远处大建筑”的割裂构图。
- **近景锚带**：允许在画面底部约6%至10%放置正常尺度的小平台、小亭、矮栏、灯柱、地砖或人物，用来证明远方巨构的尺度；这些元素必须低矮、完整且不贴镜。默认取消占画面15%以上的飞檐、巨柱、树枝和门框，不允许两侧粗柱夹景。近景只负责测量，不负责抢戏。
- **重复结构证据**：长桥、天梯、柱廊和巨殿必须提供至少8至12组逐级缩小的地砖接缝、栏杆、灯柱、门窗、柱列或飞檐，全部汇入同一消失点；重复物要有尺度递减和轻微差异，禁止复制粘贴式机械重复。
- **大量留白**：画面至少45%为低细节负空间，来自淡青天空、中性云海、空旷白玉平台、暗部殿堂或月夜天幕；留白必须连续、安静，不塞满柱列、屋檐、灯笼、飞鸟、花瓣和装饰。人物放在留白与巨构交界处的下三分之一，不居中成为主角。
- **长焦史诗感**：固定母版默认采用IMAX级65mm大画幅电影观感与85–100mm中长焦，优先100mm；用空间压缩、尺度重叠、空气透视和明暗层次建立史诗感。用户明确要求更强的远距压缩时可提高到135–300mm。禁止24–70mm广角、鱼眼、夸张低机位和强烈近大远小。
- **等待、守望、停立**：人物作为微小剪影置于下三分之一、平台边缘或巨柱脚下，使用背影/侧身；远方归途保留大面积空位；优先极慢拉远、升镜或横移揭示规模，不向人物持续推近。
- **向某处行走**：使用背后或后侧方极远景，目的地位于远景轴线或偏离中心；只需让道路方向与行走姿态成立，不要求辨认脚掌或服装细节；摄影机远距离固定或极慢跟随。
- **多人同行**：严格保持用户指定人数，人物错开半个身位，服装轮廓和识别色各不相同；步伐存在自然相位差，不整齐机械同步。
- **仰望、发现、抵达**：人物作为尺度参照，远景只设置一个主奇观；轻微升镜或越过栏杆揭示空间。

## 默认参数

- 图片：16:9，IMAX级65mm大画幅电影观感，默认100mm中长焦，中景至无穷远深焦，至少45%低细节留白，建筑、环境和人物均为超写实实体质感。近处尺度锚点限制在底部约6%至10%，人物或近景元素占画面高度0.3%至0.8%、默认约0.5%，连续结构至少8至12组，极远皇家巨构或唯一巨物占画面高度60%以上并允许越框。建筑以朱漆、青玉、古金和彩绘结构呈现华丽高贵的礼制感，无文字，末尾附“--v 8.2”。
- 视频：5秒，单镜头，无剪辑，无对白；极慢推、移、升或跟拍；云、雾、瀑布、衣摆、发丝、树梢承担微运动。
- 用户指定画幅、时长、模型、对白或参考图时，以用户要求为准。涉及可能变化的模型规格时先查官方资料，不杜撰参数。

## 默认输出

严格只输出以下两个区块，不增加创意说明、资产表、时间轴、操作教程或反问：

```text
【图片提示词】
[一段按固定母版写成、可直接生图的完整中文提示词，包含主体、准确人数、起始动作、四层空间、尺度阶梯、构图、85–100mm焦段、光色、材质、简洁禁止项，并以--v 8.2结束]

【视频提示词】
[一段以“以上图片为首帧，5秒单镜头，无剪辑。”开头的连续视频提示词，包含动作轨迹、唯一摄影机运动、环境微运动、结束画面和连续性禁止项]
```

只有用户明确说“再给负面词”时才单独增加第三个区块；默认把必要禁止项压缩到两个提示词末尾。

## 高级模式

用户明确要求多镜头时，按 references/style-blueprint.md 输出全局资产、逐镜时间轴、整段提示词、拆镜提示词、禁止项和连续性检查。不要因为主题具有故事性就自动进入多镜头模式。

## 质量检查

- 图片必须是视频的起始状态，而不是动作结束状态。
- 图片和视频中的人物数量、服装、发型、站位和方向必须一致。
- 等待镜头必须让“缺席者”保持缺席；不要擅自生成归来者。
- 行走镜头必须显示脚下路径、目的地和足够运动空间。
- 巨物感必须来自人物→栏杆/树→柱/桥→宫殿/天体的尺度阶梯。
- 近处正常尺度锚点必须限制在画面底部约6%至10%；没有锚点会让远宫失去可测尺度，锚点超过15%或贴镜则会抢占巨构主体，两者都判定失败。
- 长桥、天梯、柱廊或巨殿必须出现至少8至12组逐级缩小的结构证据并汇入同一消失点；多消失点、道路突然弯折、重复间距不递减或机械复制都判定失败。
- 默认人物以画面高度0.5%为目标，允许0.4%至0.6%，可辨人数、服装颜色、方向、站姿或步态，但没有可辨面孔、手指、鞋履和衣纹；若人物高于画面0.8%、高于最近柱基的1/40、能看清面部或一眼先看到人物，则判定失败。
- 画面至少45%必须是连续低信息留白；若近柱、屋檐、栏杆和装饰填满四周，或天空、云海、空地不足以产生寂静与呼吸感，则判定失败。
- 固定母版默认使用85–100mm中长焦、优先100mm；若出现24–70mm广角透视、鱼眼畸变、两侧近柱粗大外扩、人物被中央透视线主动放大或普通建筑展示感，则判定失败。只有用户明确要求更强远距压缩时才提高到135–300mm。
- 建立至少三至四层空间：人物所在巨型场地、连续柱列/桥体、远雾云海、极远主奇观；用重复结构、统一消失点、尺度递减和空气透视共同证明距离，不能依赖突出的贴镜前景或浓雾。
- 画面必须具有IMAX大画幅的空间容量与深焦层次，而不是浅景深广告片或游戏过场动画；无贴镜前景时，仍要用地面收束线、斜向结构、层间遮挡与视频视差证明纵深。
- 人物所在场地必须先提供一组巨构尺度证据，例如数百米宽平台、人物数十倍高的柱基、延伸数公里的桥面或越出画框的殿柱。
- 建筑需可见石材孔隙、轻微风化、木材纹理、榫接关系和接触阴影；环境需具有统一光向、真实云层密度与空气衰减；微小人物仍须保持正确肢体、自然姿态、衣料重量和真实轮廓。禁止过度HDR、过锐、塑料皮肤、蜡像人物、游戏CG和无依据的AI高光。
- 巨墙、朱漆木构梁架、层叠彩绘斗拱、青绿色琉璃和宽阔飞檐要有真实承重关系；古金、玉石镶嵌、浮雕铜门与藻井集中在结构节点和仪典焦点，既要华丽高贵，也禁止满屏金色与廉价亮金。
- 若建筑只有素白石材和普通木梁、缺少皇家礼制与精工装饰，判定为不够华贵；若装饰淹没结构、留白不足或像游戏宫殿贴图，同样判定失败。
- 每张图只选一种光色状态：昼景使用淡青蓝天空、中性白云与克制淡金轮廓光；月夜使用冷蓝夜色、淡玉色月光与雾青云海。禁止把晴朗昼景和深夜月色混写。
- 禁止用人物近景、人物半身、中景肖像、清晰面部特写或持续推近人物替代巨物构图。
- 只保留一个主异构或巨物奇观，建筑结构仍可读、可走、可承重。
- 禁止人物复制、变脸、服装漂移、人数变化、肢体错误、脚底滑行、建筑融化、栏杆弯曲、云层闪烁、瀑布倒流、镜头突然加速、塑料CG、字幕和水印。
