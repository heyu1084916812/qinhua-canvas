## STEP 1: Product Image Prompt

### 1.1 — Ask product type

Ask the user:

> "请告诉我你想要生成广告图的产品类型是什么？（例如：香水、运动鞋、手表、护肤品等）"

Wait for the user's answer before continuing.

### 1.2 — Follow-up questions

Based on the product type the user provided, ask 3–5 targeted follow-up questions to gather enough detail for a precise prompt. Choose the most relevant dimensions from:

- Product appearance: color, material, shape, texture, size
- Visual style: minimalist, luxury, natural, tech, editorial, etc.
- Background: solid color, gradient, lifestyle scene, abstract, etc.
- Lighting: soft diffused, hard directional, backlit, neon, studio, etc.
- Camera angle: front-facing, overhead, 45-degree, close-up macro, etc.
- Brand tone and target audience

Ask all follow-up questions together in one message. Wait for the user to answer all of them before continuing.

### 1.3 — Ask about cinematic style

Before generating the prompt, ask:

> "是否需要在产品图 prompt 中加入真实电影画面风格参数？（包含胶片质感、超写实效果、自然光线等电影级画质）"

If yes, append the following block at the end of the generated image prompt:

```
Shot on ARRI Alexa 65 with Cooke vintage cinema lenses. 35mm film grain, Kodak Vision3 500T aesthetic. Aspect ratio 16:9 cinematic widescreen (enforced). Hyperrealistic skin texture with visible pores, wrinkles, and natural imperfections, zero retouching, true-to-life skin like a real person. Natural light priority, real shadows, ambient light fully influencing skin tone. Motion blur on moving shots with shutter drag effect.
```

### 1.4 — Generate the image prompt

Using all information gathered, generate a complete, professional English prompt for AI image generation.

Requirements:

- Language: English only
- Describe scene composition, lighting, materials, background, and atmosphere in detail
- Write as a cohesive descriptive paragraph suitable for Midjourney, DALL-E, Stable Diffusion, or similar tools
- Do NOT include any product placeholder in this prompt

After generating the image prompt, internally record a **Product Profile** summarizing the key characteristics of this product. This profile will be used in Step 2 to ensure the video prompt is compatible with this specific product. The profile should include:

- Product category and name
- Key visual traits: shape, material, color, texture, finish
- Size and form factor feel
- Brand tone and target aesthetic

## STEP 2: Video Prompt Reverse Engineering

### 2.1 — Request the video file

Tell the user:

> "接下来进入视频 prompt 反推环节。请提供视频文件的路径，我将分析视频内容，反推出适合 AI 生成同款效果的 prompt。"

Use the Read tool to read and analyze the video file the user provides.

### 2.2 — Analyze the video

Carefully analyze the following elements from the video. Extract only the **cinematic and directorial language** — the goal is to understand *how* the video is made, not *what product* is in it. The product from Step 1 will replace whatever product appears in this video.

Elements to analyze:

- Camera movement: push-in, pull-out, orbit, handheld, static, drone, etc.
- Scene and background environment (keep only what is compatible with the Step 1 product)
- Lighting style and color grading / color tone
- Pacing and editing rhythm
- Shot structure: how the product enters frame, lingers, and exits; angles used
- Visual effects, transitions, overlays
- Overall mood, energy, and brand aesthetic

### 2.3 — Ask for placeholder number

Ask the user:

> "视频 prompt 中的产品将使用占位符替代。请问产品编号是多少？（例如输入 1，则占位符为 @product_1.png）"

Wait for the user's number. Use it in the format `@product_编号.png` wherever the product name or product reference appears in the video prompt.

### 2.4 — Ask about cinematic style

Ask:

> "视频 prompt 是否也需要加入真实电影画面风格参数？"

If yes, include the following block in the generated video prompt:

```
Shot on ARRI Alexa 65 with Cooke vintage cinema lenses. 35mm film grain, Kodak Vision3 500T aesthetic. Aspect ratio 16:9 cinematic widescreen (enforced). Hyperrealistic skin texture with visible pores, wrinkles, and natural imperfections, zero retouching, true-to-life skin like a real person. Natural light priority, real shadows, ambient light fully influencing skin tone. Motion blur on moving shots with shutter drag effect.
```

### 2.5 — Generate the video prompt

Generate a complete English video prompt by **fusing** the video's cinematic language with the product from Step 1. This is a creative transplant: take the *how* (direction, movement, mood, lighting, rhythm) from the reference video, but replace the *what* (the original product) entirely with the product profiled in Step 1.

Fusion rules:

- **Product identity comes entirely from Step 1.** Describe the product's material, shape, color, texture, and form factor based on the Step 1 product profile — never from the reference video's product.
- **Scene compatibility check:** If the reference video's scene or environment would be visually incoherent with the Step 1 product (e.g., a beach scene for a luxury watch), adapt the scene to one that is natural for the Step 1 product while preserving the lighting style and mood.
- **Camera and motion are borrowed from the video.** Keep the shot types, movement patterns, and editing rhythm from the reference video.
- **No visual conflict.** The final prompt must describe a world where only the Step 1 product exists — no trace of the reference video's original product category, props, or context that would clash.
- Replace every product reference with `@product_编号.png` (using the number the user provided).

Requirements:

- Language: English only
- Describe camera movement, scene, lighting, motion, pacing, and atmosphere in detail
- Suitable for AI video generation tools such as Sora, Runway, Kling, or similar
