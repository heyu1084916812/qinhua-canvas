# 角色工业级三视图生成器

## 用途

本 Skill 专门用于创作高质量的角色设计稿，生成符合工业标准的正交三视图（正面、90°侧面、背面）。确保角色在不同视角下的造型、服饰、比例完全一致，为建模或插画提供精准参考。

## 适用输入

- 角色身份描述（如：职业、性别、种族）
- 详细服装及配饰清单
- 艺术风格倾向（如：矢量平整、写实商用、动画人设）

## 操作步骤

1. 输入角色的核心形象描述与服装要求。
2. 系统将自动应用标准制图规范：横向三段式布局。
3. 生成左（正面）、中（90°侧面）、右（背面）的全身视图。
4. 确保所有视角使用统一的纯白背景与均匀光影。

## 输出要求

- **排版布局**：严格的横向并列，间距规整，居中对齐。
- **高度一致性**：三个视角的头部大小、身高比例、发型结构、服装版型及配饰正反细节必须完全同步。
- **画面表现**：8K高清，线条利落，无广角透视畸变，光影均匀柔和。
- **背景环境**：统一干净纯白底，无任何环境杂物干扰。

## 注意事项

- 侧视图必须为标准的 90° 正侧位，避免出现 45° 或其他带有透视的角度。
- 确保所有细节（如鞋子花纹、背包带子）在三个面上逻辑闭环。
