# 苏联废土美学短片生成器

## 这个 Skill 是什么

输入一句视觉意象或氛围描述，自动生成一条苏联废土宏大美学风格的视觉短片方案，包含分镜序列、画面描述、运镜方式和配乐/音效建议。无需角色、情节或对白，聚焦纯粹的视觉与氛围呈现。

## 什么时候用它

- 想生成一条以氛围和视觉冲击为核心的美学短片
- 需要苏联废土风格的纯视觉内容，不需要叙事结构

## 什么时候不该用它

- 需要有角色、情节、对白的剧情短剧
- 需要明亮、现代、清新等与苏联废土美学相悖的风格

## 输入

用户提供一句视觉意象或氛围描述，例如：

- "废弃的冶炼厂在黄昏中沉默"
- "无尽的麦田与生锈的收割机"
- "地下掩体里唯一亮着的灯"

## 执行流程

### 第一步：拆解视觉意象

将用户输入的意象拆解为以下维度：

- **主体**：画面的核心视觉元素（建筑/机械/自然景观/光线）
- **氛围词**：从输入中提炼 2\~3 个情绪关键词（如：压抑、宏大、孤寂、肃穆）
- **时间/光线**：黄昏逆光 / 阴天漫射光 / 夜间单点光源（优先选择戏剧性光线）

### 第二步：生成分镜序列

生成 4\~6 个分镜，构成完整的视觉节奏，每个分镜包含：

- **镜头编号**
- **镜头类型**：大远景 / 全景 / 特写（以大远景和仰拍为主，强调宏大感）
- **运镜方式**：静止 / 缓慢推进 / 低速横移 / 俯冲（优先缓慢、沉重的运镜）
- **画面描述**：具体描述画面内容、光线、质感
- **风格关键词**（锁定）：苏联构成主义构图、低饱和度灰绿/锈红色调、工业废墟或荒原、厚重云层或烟雾、斑驳金属/混凝土质感

### 第三步：生成配乐与音效建议

- **配乐风格**：低频弦乐、工业噪音底噪、苏联时代进行曲变奏（缓慢、沉重）
- **关键音效**：金属摩擦声、风声、远处机械轰鸣、寂静中的回响
- **节奏建议**：整体节奏缓慢，每个分镜停留 5\~10 秒，不追求快速剪辑

## 风格锁定说明

以下风格关键词在任何情况下都必须体现，不因用户输入内容而改变：

- 苏联构成主义构图（强对角线、仰拍、几何感）
- 低饱和度灰绿/锈红色调
- 工业废墟、荒原或集体农庄场景
- 厚重云层、烟雾或戏剧性逆光
- 缓慢、沉重的运镜节奏
- 宏大叙事视角（渺小的人造物映衬无垠的荒芜）
