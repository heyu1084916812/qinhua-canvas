## 三、镜头语言规范（专业级，禁止单一）

### 1. 焦距使用（必须覆盖全焦段）

焦距用途使用频率**24mm**大全景、空间交代、群体场面、压迫感15%**35mm**中景/中全景、叙事主力、环境+人物关系30%**50mm**中近景、对话、自然视角25%**85mm**特写/近景、情绪、细节、浅景深20%**135mm**极端特写/大远景（压缩空间）、关键惊点10%

### 2. 景别配置（禁止全片中景/全景）

- 大特写（眼睛、手部、道具细节）
- 特写（脸部、伤口、关键物品）
- 近景 / 中近景（情绪、对话）
- 中景 / 中全景（动作、人物关系）
- 全景 / 大全景（空间、群体）
- 大远景（城市、格局）
- POV主观镜头（代入感，关键段落必须有）
- 过肩镜头（对话、观察）

### 3. 运镜手法（按段落情绪匹配）

运镜适用段落效果**固定长镜**序幕、屏息段、恐怖静默压抑、等待、观众一起憋**缓推/缓拉**发现、信息揭示、情绪递进聚焦、不安渐强**手持微晃**爆发段、紧张段临场感、纪实感**跟拍**行动、奔跑、移动代入、紧迫**急推/急晃**惊点、变异、扑击惊吓、爆发**横摇/缓摇**群像、空间扫描、环境交代展示、关系**斯坦尼康**组队段、有序移动稳定、组织感**灯光骤变**灯灭、应急灯亮转折、威胁升级

### 4. 镜头纪律

- 一镜一动作，不贪多
- 主体运动与相机运动分离
- 每镜必须有：新信息 / 强情绪 / 清晰动作（三者至少一个）
- 动作衔接：上一镜动作终点 = 下一镜起点
- 视线匹配：角色看哪，镜头切哪
- 不默认合并长镜头，不因素材便利改镜头数量

### 5. 分镜组跨镜头连续性（Cross-shot Continuity，铁律）

**核心原则：每生成新一组分镜，必须先继承上一组分镜的最终画面状态，不允许无参考地"重新开始"。**

5.1 连续性锚点机制（Continuity Anchors）

- 每个叙事段落（分镜组）的**首帧和尾帧**各设一个"连续性锚点"
- 锚点记录以下信息： ① 每个角色的空间位置、朝向、姿势 ② 角色情绪/表情状态 ③ 伤口/血迹/污渍/汗水的位置与程度 ④ 服装状态（领口、袖口、卷袖、破损） ⑤ 关键道具的持有者、位置、完整度 ⑥ 光源方向、光线强度、色温 ⑦ 画面构图与机位关系
- 下一组分镜生成时，**必须以上一组尾锚点为起始状态**
- 新一组首锚点与上一组尾锚点核对，不一致则修正，不带着断裂继续

5.2 必须继承的六类连续性

连续性类型具体要求**动作连续性**上一镜动作终点 = 下一镜动作起点；遵循"动作接动作剪辑（Cut on Action）"，在动作进行中切换，不跳动作**空间连续性**遵守**180度轴线规则（180° Rule）**，同一场景角色相对方向不越轴；角色与场景物体的位置关系跨镜保持，不无故换位**角色状态连续性**情绪/表情递进不突变；伤口/血迹/汗水/脏污位置和程度只增不减（除非有处理动作）；发型/服装凌乱状态连续**道具连续性**道具不凭空消失或出现；谁持有、放在哪、什么状态（完整/破损/沾血/被踩瘪）必须逐镜携带；道具转移必须有动作交代**光线连续性**同一场景光源方向一致；时间流逝通过光线变化体现，不无故跳色温；灯光递进单线推进（亮→闪→灭→应急灯），不反复**声音连续性**环境声跨镜连续，不无故中断；上一镜声音余韵可自然延续；音乐/音效进入退出有铺垫，不硬切

5.3 分组生成纪律

1. 按叙事段落分组（序幕组/爆发组/规则组/威胁组/收尾组），不一次性无参考批量生成全部镜头
2. 每组生成后，先做组内连贯性检查，再进入下一组
3. 下一组生成时，将上一组**尾锚点状态**作为前置参考输入
4. 发现跨组断裂（位置跳变/道具消失/状态矛盾）时，**回溯到断裂点修正**，不带着矛盾继续往后生成
5. 每个新镜头生成前，核对与前一镜头的：人物位置、动作走向、道具状态、视线方向
6. 长场景跨多个生成批次时，每批次开始前重新读取当前场景最新锚点状态，不依赖记忆

5.4 连贯性验证方法

- **相邻帧核对**：相邻两个镜头，后一镜首帧是否能从前一镜尾帧自然推演
- **状态表追踪**：维护逐镜角色/道具状态表，每生成一镜更新，对照检查
- **反证检查**：主动寻找"这个东西上一镜在哪""这个人为什么突然到这了"类断裂
- **空间预演**：复杂站位场景先用导演台/白模预演空间关系，再生成正式画面

## 四、叙事与台词规范

### 1. 叙事原则

- **无全知旁白**（铁律）
- 信息通过三种方式传递：\
  ① 角色对话（主力）\
  ② 角色内心独白VO（关键判断时刻，极短句）\
  ③ 低声自语（思考过程）
- 观众跟主角一起理解局势，不提前剧透

### 2. 内心独白（VO）规则

- 仅主角第一人称使用
- 每集不超过6处
- 每处不超过15字
- 只在关键判断时刻使用（发现规则、震惊、绝望、核心疑问）
- 语气：低于正常音量、带呼吸感、像在对自己说

### 3. 台词要求（呼吸感、去AI味）

- **口语化**：正常人怎么说话就怎么写，不书面
- **有停顿**：人在紧张/恐惧时说话会断、会重复、会改口
- **有废话**：真实对话不是每句都推进剧情，允许语气词、重复、无意义的短句
- **符合人设**：老师沉稳指令、班长简短有条理、体育生急且直、胆小的碎嘴吐槽、知情者缓慢斟酌
- **禁止**：长篇大论解释设定、所有人说话一个腔调、书面化台词、AI式工整对话

### 4. 台词功能分配

角色台词风格功能程屹（老师/主角）沉稳、指令性、关键判断指挥、发现规则、信息确认宋嘉宁（班长）简短、有条理、带安抚点人、物资、情绪稳定马铮（体育生）急、直、偶尔带脏字替观众发问、行动反馈唐小棠（化学课代表）碎嘴、吐槽、带颤音观众嘴替、轻喜剧调剂、预警周明（技术位）紧张但有条理、语速快提供细节信息、技术相关张敬山（知情者）缓慢、短句、停顿多规则告知、真相揭示

## 五、恐怖手法规范（核心竞争力）

### 1. Jaws规则（怪物隐藏原则）

- **怪物不全现**，尤其是高级怪物
- 揭示节奏：声音 → 影子 → 局部 → 全貌（全貌留到后期）
- 每次怪物出场换一种铺垫方式，不重复
- 观众的想象力比直接展示更可怕

### 2. 怪物出场铺垫方式（按层级）

**死体（一级）**：

- 先给异常动作（抽搐、僵硬站起）
- 再给声音（嗬嗬声、拖沓脚步）
- 最后给外观（眼白上翻、面色死灰）

**伪人（二级）**：

- 先给声音（门外求救、机械重复）
- 再给轮廓/影子（贴墙挪动、玻璃上的身影）
- 只给局部（一只眼、半张脸、关节不自然）
- 不正面冲入，靠伪装制造心理恐怖

**母体（三级）**：

- 先给环境征兆（低温、电器失灵、低频震动）
- 再给边界痕迹（潮湿蔓延、发黑水渍）
- 然后局部一闪（一条触手、一截肉质增生，立刻缩回）
- **第一季不给出全貌**

### 3. 声音恐怖（本类型核心）

- **战略性静默**：关键恐怖时刻抽掉环境声，真空压迫
- **声音先行**：怪物没出场先听到声音，观众自己脑补
- **单点音效放大**：药瓶落地、椅子刮地、呼吸声、滴水声，在安静中放大
- **规则即声音**：死体靠声音，"安静"本身就是生存手段，观众会跟着屏息

### 4. 恐怖节奏

- 不持续高能（观众会疲劳）
- 紧张→短暂喘息（轻喜剧/吐槽）→更紧张
- 每个恐怖段落之间必须有"呼吸口"
- 最大的威胁放在结尾，留余悸

## 六、节奏与结构规范

### 1. 单集节奏曲线（5分钟标准）

时间段落节奏功能0:00-0:35序幕·反常慢、压抑建立日常、埋钩子、不安感0:35-1:40爆发快、爆裂变异、混乱、主角行动1:40-3:00规则与组队中→慢发现规则、验证、组队成形3:00-4:10新威胁/信息慢、阴冷伪人/知情者、规则深化4:10-5:00被困与更大威胁慢→惊格局拉开、母体局部、悬念收尾

### 2. 情绪起伏设计

- 压抑平静 → 突发爆裂（第一个高潮）
- 绝境 → 发现规则（短暂希望）
- 组队 → 新陷阱（希望被打压）
- 困局 → 更大真相（绝望升级）
- 局部威胁 → 黑屏悬念（收尾惊点）

### 3. 开场钩子（必须在前30秒抓住观众）

至少包含以下2-3个：

- 视觉异常（灯光闪烁、画面不对劲）
- 无法解释的现象（地面多出来的人影）
- 具体人物的反常状态（攥药瓶、失焦、气音）
- 声音异常（不该有的声音、环境突然安静）

### 4. 结尾悬念（必须留钩子让观众想看下一集）

- 不把所有问题解答
- 至少留2-3个悬念：角色生死、规则疑问、更大威胁、真相碎片
- 最后一个画面/声音要有"惊点"，但不俗套（禁止只用红眼睛/突然跳出来）

## 七、角色规范

### 1. 角色一致性（铁律）

- 同一角色跨镜头：脸型、发型、服装、配饰必须一致
- 服装不能中途无故变化
- 伤口/污渍/血迹位置必须连续
- 道具携带状态必须连续（谁拿着什么、放在哪）

### 2. 主角团配置原则

- 每个角色必须有**不可替代的技能**，不能有"什么都不会的拖累"
- 能力覆盖：领导/医疗/后勤/近战/技术/特殊技能
- 角色性格差异化，说话不能一个腔调
- 群演也要有小差异（发饰/外套/文具），避免NPC感

### 3. 标准主角团配置（6+1人）

角色定位核心技能程屹（28岁老师）领袖/战术指挥、观察、近战基础、逻辑表达姜晚（27岁校医）医疗/驾驶急救、感染判断、开车、基础防身宋嘉宁（18岁班长）后勤/地图组织、物资分配、记忆力、情绪稳定马铮（18岁体育生）近战主力最强战力、体能、标枪投掷、执行唐小棠（18岁化学课代表）化学/预警燃烧瓶、听觉敏锐、潜行、吐槽周明（18岁技术宅）技术/情报电子/无线电、观察力、记忆力张敬山（53岁老教师）知情者/阶段性规则真相、学校地图、生存经验

### 4. 阶段性角色处理

- 张敬山为阶段性成员（已感染），第一季中后段退出
- 退出方式：为掩护团队断后，变异前传递全部信息
- 信息传递链：张敬山 → 程屹（主角继承知情者功能）
- 阶段性角色的退出必须有戏剧意义，不随便死

## 八、世界观与规则体系

### 1. 三级变异体系

**一级·死体**：

- 面色死灰、眼白上翻、肢体僵硬
- 听觉极敏锐（铁律）、视觉退化、怕强光频闪
- 保留生前最后一个习惯动作（执念），打断触发攻击
- 不会开门/用工具/协作
- 只有打头才停

**二级·伪人**：

- 外表近真人，破绽：瞳孔泛白/失焦、无眼泪、无痛觉
- 有智慧、会说话、开门、设套、伪装求救
- 破绽：情绪慢半拍、不懂双关、求救机械重复、倒影不同步
- 仍需打头才死，数量稀少

**三级·母体**：

- 非人形，肉质/菌丝/触手增生体，潮湿低温
- 释放感染、制造死体、封锁区域
- 有核心器官，火/燃烧物有效，须命中核心
- 前期只给局部，不全现

### 2. 关键生存规则（观众能秒懂）

1. 死体靠声音
2. 打头才停
3. 重复生前习惯，打断触发攻击
4. 求救先验证（会求救的可能是伪人）
5. 母体封锁，潮湿痕迹是边界
6. 提神药是陷阱

### 3. 长线真相（分层揭示，不一次讲完）

- 母体是层级"母体网络"，学校只是底层节点
- 每3年活跃一次，校方/高层知情并掩盖
- 提神药含母体提取物，"标记"服药者
- 底牌：远古老生命体 + 人为圈养（实验/地外为前期烟雾）

## 九、声音设计规范

### 1. 总原则

- 写实克制、以静写恐
- 环境声 + 静默 + 单点音效为主
- 音乐只在关键节点淡入，不贯穿全片
- 无旁白音轨

### 2. 声音分层

层内容处理环境底噪灯管电流、钟摆、翻书、风前半清晰，爆发后被混乱取代怪物音效死体低吼、拖沓脚步、潮湿蠕动低频为主、方位感强单点音效药瓶落地、椅子格挡、打头闷击、忙音、滴水放大留白，制造惊跳静默屏息段、母体出场前抽掉环境声，真空压迫角色VO主角内心独白第一人称、极短句、带呼吸感音乐极简低频drone/不安弦乐仅节点淡入，不煽情

### 3. 混音纪律

- 人声始终可懂，危急时压低但不糊
- 怪物低频不掩盖人声
- VO不压过环境声
- 惊跳音效"先静后响"
- 不默认加背景音乐

## 十一、执行流程（Agent工作流）

### 阶段1：资源准备

1. 读取/接收剧本与制作手册
2. 提炼一句话故事概述与核心约束
3. 明确画幅、时长、风格、模型等全局参数
4. 如有冲突，先确认执行优先级

### 阶段2：视觉圣经

1. 建立角色视觉档案（外形、服装、配饰、特征）
2. 建立场景视觉档案（空间、光影、色调、关键物体）
3. 建立道具视觉档案（关键道具、状态、连续性）
4. 高影响设定需用户确认后才进入批量生产

### 阶段3：故事板

1. 严格按原分镜数量、顺序、边界
2. 每镜明确：场景、人物、动作、台词、景别、焦距、运镜、角度、构图
3. 不默认合并镜头，不因素材便利改镜头语言
4. 故事板完成后确认，再进入素材生产

### 阶段4：素材生成

1. 角色/场景/道具分别建立可复用元素
2. 优先复用已有素材，不重复生成
3. 同一角色不同状态用图生图保持一致性
4. 有对白角色准备音色参考
5. 提示词使用中文，明确视觉依据，不套用冲突模板

### 阶段5：视频生成

1. 按故事板逐镜生成
2. 保留原镜头时长边界，不因素材较长延长剧情
3. 有对白镜头明确说话者、台词、音色
4. 独立旁白/音乐按计划执行，不重复叠加

### 阶段6：剪辑组装

1. 按原分镜顺序与时间边界组装
2. 对齐音画，保留镜头语言
3. 素材不完整时先粗剪检查流畅度
4. 全部素材齐备后完成最终组装

## 十二、禁止事项（红线）

 1. **禁止全知旁白**（只能用角色对话+主角VO）
 2. **禁止怪物直接全现**（必须铺垫，尤其母体）
 3. **禁止镜头语言单一**（必须覆盖多焦段、多景别、多运镜）
 4. **禁止角色不一致**（脸型/服装/伤口/道具跨镜头必须连续）
 5. **禁止AI味台词**（必须口语化、有停顿、符合人设）
 6. **禁止私自改剧情/加剧情/合并镜头**
 7. **禁止网红脸/夸张身材/性感化角色**
 8. **禁止持续高能无喘息**（必须有节奏起伏和呼吸口）
 9. **禁止结尾俗套**（不要只用红眼睛/突然跳脸）
10. **禁止角色无技能成拖累**（每个主角必须有不可替代性）
