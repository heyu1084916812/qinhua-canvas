# 宣传片 / 广告片生成器

## 这个 Skill 做什么

接收用户提供的品牌/产品信息和创作要求，生成一条完整的宣传片或广告片视频。支持两种输入模式：

- **模式 A（主题模式）**：用户提供主题和品牌信息，Agent 自动生成脚本，再逐步推进到成片。
- **模式 B（文案模式）**：用户直接提供已写好的文案，跳过脚本创作，直接进入分镜设计和合成环节。

每个阶段完成后，必须等用户确认后再进入下一步，不得自动跳过。

---

## 启动时必须收集的信息

在开始任何生产步骤之前，先向用户确认以下所有信息（如用户已在输入中提供，则无需重复询问）：

信息项说明品牌 / 产品名称必填，将融入画面Logo 或品牌视觉元素如有，请用户提供图片或描述视觉风格必填，如：高级感、活泼、科技感、温暖、极简等视频时长必填，选项：15s / 30s / 60s配音风格或背景音乐必填，如：磁性男声、温柔女声、电子音乐、轻音乐等输入模式模式 A（提供主题）或模式 B（提供现成文案）主题 / 文案根据所选模式提供对应内容

---

## 生产流程

### 模式 A：主题 → 脚本 → 分镜 → 画面 → 配音 → 合成

第一步：脚本创作

根据用户提供的主题、品牌信息、视觉风格和视频时长，生成一份完整的广告脚本，包含：

- 整体叙事结构（开场 / 主体 / 收尾）
- 每个场景的画面描述和对应旁白/字幕文案
- 品牌名称、产品卖点的植入位置
- 预估时长分配（各场景秒数）

**完成后展示脚本全文，等待用户确认。用户确认后进入第二步。**

---

第二步：分镜设计

基于确认后的脚本，为每个场景生成详细分镜描述，包含：

- 镜头类型（全景 / 中景 / 特写 / 运动镜头等）
- 画面构图和主体元素
- 品牌 / Logo 出现的位置和方式
- 场景切换节奏

**完成后展示分镜表，等待用户确认。用户确认后进入第三步。**

---

第三步：画面生成

按照确认后的分镜描述，逐场景生成画面。要求：

- 严格遵循用户指定的视觉风格
- 品牌名称、Logo 等元素必须融入对应场景画面，不得缺失
- 画面风格在各场景间保持一致

**完成后展示所有场景画面，等待用户确认。用户确认后进入第四步。**

---

第四步：配音 / 背景音乐合成

按照用户指定的配音风格或背景音乐偏好，为视频生成或匹配音频：

- 如需配音：按脚本旁白内容生成对应配音
- 如需背景音乐：匹配用户指定风格的背景音乐
- 配音与背景音乐可同时存在，注意音量层次

**完成后提供音频预览，等待用户确认。用户确认后进入第五步。**

---

第五步：最终合成

将确认后的画面、配音/背景音乐、字幕按时间轴合成为完整视频，输出成片。

**交付最终视频，流程结束。**

---

### 模式 B：文案 → 风格冲突检测 → 分镜 → 画面 → 配音 → 合成

跳过第一步（脚本创作），在进入分镜设计之前先执行**风格冲突检测**，再从\*\*第二步（分镜设计）\*\*开始，后续步骤与模式 A 完全相同。

风格冲突检测（模式 B 专属，在分镜设计前执行）

读取用户提供的文案，判断其整体语气、情绪基调是否与用户指定的视觉风格存在明显差异。

**判断标准**：若文案语气（如激进、热血、幽默、煽情）与视觉风格（如极简、温柔、高级感、清冷）在情绪方向上明显相反，则视为存在差异。

**存在差异时**：向用户提示：

> "检测到文案风格与视觉风格可能存在差异，是否继续按指定风格执行？"

等待用户确认后，再进入分镜设计。

**无差异时**：直接进入分镜设计，无需提示。

---

## 固定约束（不可跳过）

以下约束在所有步骤中始终有效，不因用户未主动提及而省略：

1. **品牌 / 产品名称、Logo 等元素必须融入画面**，不得仅出现在字幕或旁白中。
2. **视觉风格必须由用户明确指定**，Agent 不得自行决定风格。
3. **视频时长必须由用户明确指定**（15s / 30s / 60s），脚本和分镜的节奏设计须与时长匹配。
4. **配音风格或背景音乐必须由用户明确指定**，Agent 不得自行选择。
5. **每个阶段完成后必须等用户确认**，不得自动进入下一步。

---

## 不适用场景

- 不适合用于与品牌/产品无关的纯娱乐内容创作
- 不适合用于生成超过 60 秒的长视频
- 不适合用于无明确品牌信息的通用视频生成
