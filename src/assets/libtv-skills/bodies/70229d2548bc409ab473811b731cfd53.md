# 双图全能变身特效视频

## 概述

本 Skill 基于「双图生视频」画布链路提炼，支持多种类型的变身/变换特效视频生成。核心流程分两阶段：

1. **锚点准备阶段**：生成人物/角色锚定图（可含三视图）和变身目标图，作为固定锚点。
2. **特效生成阶段**：将锚定图与目标图同时输入视频生成节点，通过提示词控制生成变身过渡动画。

---

## 支持的变身类型

| 变身类型 | 说明 | 典型应用场景 |
|---|---|---|
| **服装变装** | 人物服装从一套换为另一套 | 时装展示、角色换装、古今对比 |
| **超级英雄变身** | 普通人变身为超级英雄/战士形态 | 漫画风格、战斗觉醒、能力激活 |
| **动漫/画风转换** | 写实人物变为动漫/插画/像素等风格 | 风格化创作、IP 形象转换 |
| **年龄变化** | 人物从年轻变为年老，或反向返老还童 | 时光流逝、成长故事 |
| **物种/形态变换** | 人变为动物、精灵、机器人等非人形态 | 奇幻创作、游戏角色 |
| **场景/环境切换** | 人物所处场景从一个环境切换到另一个 | 穿越、传送、季节变换 |
| **情绪/状态变化** | 人物从普通状态变为愤怒/觉醒/神圣等特殊状态 | 情绪爆发、能量释放 |
| **自定义变身** | 用户自定义任意变身效果 | 不限类型，由描述词完全控制 |

---

## 输入

| 槽位 | 说明 | 是否必填 |
|---|---|---|
| `{{锚定图}}` | 变身前的人物/角色/场景图，用于锁定变身起点的外貌、风格、环境 | 必填 |
| `{{目标图}}` | 变身后的目标形态图，可以是服装、角色、风格、场景等任意目标状态 | 必填 |
| `{{变身类型}}` | 从上方支持的变身类型中选择，或自定义描述 | 建议填写 |
| `{{变身描述词}}` | 描述变身过渡的具体方式、特效风格和结束姿态 | 建议填写 |

---

## 节点结构

```
[步骤1: 锚定图准备]          [步骤2: 目标图准备]
（人物三视图/场景图等）      （目标形态/服装/风格图）
         |                            |
   [锚定图节点]                 [目标图节点]
         \                           /
          \                         /
      [视频生成节点（变身特效）]
                   |
          [输出：变身特效视频]
```

---

## 执行步骤

### 第一阶段：锚点准备

**步骤 1：准备锚定图**
- 创建图片节点，上传或生成 `{{锚定图}}`
- 若需要高度一致的人物形象，建议先生成人物三视图（正面/侧面/背面），从中选取最清晰的一张作为锚定图
- 锚定图确定后，同一系列视频应复用同一张，保证变身起点一致

**步骤 2：准备目标图**
- 创建图片节点，上传或生成 `{{目标图}}`
- 目标图应清晰呈现变身后的最终状态，细节越丰富，生成效果越准确

---

### 第二阶段：特效视频生成

**步骤 3：创建视频生成节点**
- 类型：视频节点
- 输入连线：同时连接「锚定图节点」和「目标图节点」
- Prompt 填写 `{{变身描述词}}`（参考下方各类型模板）

**步骤 4：运行视频生成节点**
- 等待视频生成完成
- 输出为一段约 5～10 秒的变身过渡特效视频

## 各变身类型描述词模板

### 服装变装
```
人物站立，身体发出 [光芒/粒子/烟雾]，
服装从 [原始服装描述] 变换为 [目标服装描述]，
过渡特效为 [旋转一圈/光效扫过/布料飘散重组]，
变装完成后人物摆出 [结束姿势]。
```

### 超级英雄变身
```
人物身体散发能量光芒，
从 [普通状态描述] 觉醒变身为 [英雄形态描述]，
变身过程伴随 [闪电/火焰/冲击波/光柱] 特效，
变身完成后摆出英雄姿势，背景出现 [能量爆发/光环]。
```

### 动漫/画风转换
```
画面从 [写实/3D/水彩] 风格逐渐转变为 [动漫/像素/插画/油画] 风格，
人物外貌保持一致，线条和色彩风格发生变化，
过渡效果为 [涟漪扩散/笔触扫过/像素化再重组]。
```

### 年龄变化
```
人物面部和身体从 [年轻/年老] 状态逐渐变化为 [年老/年轻] 状态，
时间流逝感，过渡自然流畅，
背景可伴随 [季节更替/光线变化/环境老化] 效果。
```

### 物种/形态变换
```
人物身体逐渐变形，从 [人类形态] 转变为 [目标形态描述]，
变形过程伴随 [骨骼重构/皮肤变化/翅膀展开] 等细节，
特效风格为 [奇幻/科幻/恐怖/治愈]。
```

### 场景/环境切换
```
人物所处环境从 [原始场景描述] 切换为 [目标场景描述]，
切换方式为 [传送门/光幕扫过/镜头旋转/时空裂缝]，
人物姿态保持连贯，环境完成替换。
```

### 情绪/状态变化
```
人物从 [平静/普通] 状态进入 [愤怒/觉醒/神圣/黑化] 状态，
眼神、气场、周围光效发生变化，
特效为 [能量爆发/光环出现/暗影笼罩/圣光降临]。
```

## 锚点与槽位说明

| 类型 | 内容 | 说明 |
|---|---|---|
| 锚点（固定） | 人物三视图 / 角色设定图 | 确定后不随任务变化，保证变身起点一致性 |
| 锚点（固定） | 变身特效风格（如粒子/光效/烟雾） | 同一系列视频建议统一特效风格 |
| 槽位（可替换） | `{{锚定图}}` | 每次可换不同人物/角色/场景 |
| 槽位（可替换） | `{{目标图}}` | 每次可换不同变身目标形态 |
| 槽位（可替换） | `{{变身类型}}` | 每次可选择不同变身类型 |
| 槽位（可替换） | `{{变身描述词}}` | 每次可调整过渡动作、特效细节和结束姿态 |

---

## 注意事项

- **风格一致性**：锚定图与目标图的画面风格建议保持一致（如同为写实风或同为动漫风），风格差异过大会影响过渡自然度；若目的本身就是风格转换，则可以刻意使用不同风格的图片。
- **描述词精度**：变身描述词中明确写出「变身前」和「变身后」的状态，并指定过渡特效类型，生成效果更可控。
- **批量复用**：若需批量生成多套变身视频，只需替换 `{{目标图}}` 和 `{{变身描述词}}`，锚定图保持不变，可高效复用。
- **自定义扩展**：以上变身类型不构成限制，用户可完全自定义描述词，实现任意变身效果。
