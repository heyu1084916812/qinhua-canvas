## 二、使用方式

### 方式一：自然语言（推荐）

直接描述需求，系统自动识别各维度参数：

```
帮我生成一个北欧清冷感女模，极简高级风，秋天，全身棚拍
```

系统会自动匹配：北欧人种 + 青年女性 + 标准身材 + 极简高级风格 + 秋季 + 封面主图场景

### 方式二：选项式交互

回复"开始"，系统将逐步引导你选择：

1. 人种 → 2. 年龄段 → 3. 性别 → 4. 身材 → 5. 风格 → 6. 季节 → 7. 场景 → 8. AI工具

### 方式三：批量生成

回复"批量" + 基础描述，一次生成多角度/多场景：

```
批量生成 韩国女模 甜系清新 夏季
```

默认生成：封面主图 + 三视图 + 服装细节 + 外景街拍（4张）

也可以指定场景：

```
批量 中国男模 通勤风 春季 场景:封面主图+服装细节+生活方式
```

```

```


### 3.2 真实感等级调整

指定真实感等级：

- `电商基础级` - 干净美观，适度真实（默认）
- `人像真实级` - 皮肤纹理丰富，适合近距离
- `电影质感级` - 胶片感，适合编辑大片
- `服装细节级` - 强调面料质感和做工

```
人像真实级 中国女模 极简高级 特写
```

### 3.3 自定义描述

在末尾追加自定义要求：

```
韩国女模 甜系清新 夏季 封面主图 +粉色头发+拿着冰淇淋+游乐园背景
```

用 `+` 分隔多个自定义关键词。

## 八、适配说明

### Midjourney

- 自动添加 `--ar 比例 --style raw --v 6.1`
- 提示词结构：人物 → 穿搭 → 姿态 → 背景 → 光影 → 质感 → 构图

### Stable Diffusion

- 纯英文prompt，无额外参数
- 负面提示词单独列出，适合放入Negative Prompt框
- 推荐模型：realisticVision、deliberate、majicMIX等写实模型

### Flux

- 纯英文prompt，适配自然语言描述风格
- 负面提示词可选择性使用
- 推荐使用 flux.1 \[schnell\] 或 \[dev\] 版本
