# Real-Photo To Fighting Video

## 核心方法论

### 分阶段资产准备框架

打斗视频生成是一个**资产驱动**的工作流,核心是将制作流程拆解为3个独立资产层:

**Layer 1: 角色资产 (Character Assets)** — 两个独立的战斗角色,每个角色包含:

- 外貌特征锁定维度: 面部轮廓/五官比例/发型/肤色/体型
- 服装细节维度: 款式/颜色/材质/配饰
- 风格统一维度: CG游戏风格 / 卡通动漫风格 / 原始照片质感

**Layer 2: 场景资产 (Scene Assets)** — 战斗发生的环境空间,包含:

- 空间结构: 室内擂台/室外街道/训练场等
- 光影氛围: 聚光灯/自然光/暗调等
- 环境道具: 护栏/地面材质/背景观众等

**Layer 3: 动作编排 (Action Choreography)** — 15秒完整打斗叙事,包含:

- 攻防节奏: 开场试探 → 僵持对峙 → 逆转反击 → 终结一击
- 动作库: 刺拳/勾拳/直拳/摆腿/躲闪/格挡/倒地
- 镜头语言: 全景确立环境 → 中景展示动作 → 特写捕捉冲击
- 物理反馈: 汗水飞溅/尘土扬起/衣物动态(禁止能量光效等非真实特效)

### 风格转换决策树

当用户上传真实照片素材时,必须立即询问渲染风格偏好,这决定了后续所有资产的视觉语言:

```
用户上传角色图 → 触发风格询问
  ├─ 选项1: CG游戏风格 → 高精度3D渲染,肌肉线条清晰,材质写实
  ├─ 选项2: 卡通动漫风格 → 描边明确,色块分明,简化细节
  ├─ 选项3: 不生成新图 → 直接使用上传的原始照片
  └─ 选项4: 其他(用户自定义) → 接受文本输入(如"赛璐璐"/"油画"/"黑色电影")
```

风格一旦确定,所有后续资产(角色2、场景)必须使用同一风格语言,确保视觉一致性。

### 全能参考模式(Omni Reference)约束

视频生成必须使用全能参考模式,将3张素材图(角色1 + 角色2 + 场景)全部作为视觉锚点:

- **角色外貌锁定**: 面部特征/身高比例/服装细节在整个15秒视频中100%一致
- **场景空间锁定**: 环境布局/光源位置/道具摆放保持稳定
- **风格语言锁定**: 渲染质感/色彩饱和度/线条风格全程统一

## 工作流程

### 1. 资产准备阶段

**输入清单**:

- 用户上传的角色照片(2张,分别对应角色1和角色2)
- 用户上传的场景照片(1张)或场景描述文本
- 用户确认的渲染风格(CG/卡通/原图/自定义)

**执行流程**:

```
Step 1: 素材询问
  → 询问用户是否已有素材
    ├─ 有 → 跳转Step 2
    └─ 无 → 询问是否需要生成素材
         ├─ 同意 → 执行角色生成子流程
         └─ 拒绝 → 结束流程

Step 2: 风格确认(仅当用户上传真实照片时)
  → 显示4个风格选项
  → 等待用户选择
  → 记录所选风格作为全局参数

Step 3: 角色资产生成
  → 如用户选择"CG游戏风格"或"卡通动漫风格":
     - 使用图生图功能转换上传照片
     - 提示词结构: [风格关键词] + [原图外貌描述] + [保持细节指令]
     - 示例: "CG游戏角色,3D高精度渲染,保持原图人物面部特征/发型/服装款式,游戏角色建模风格"
  → 如用户选择"不生成新图":
     - 直接使用上传图片,跳过转换
  → 依次生成角色1和角色2,每次生成后等待用户确认

Step 4: 场景资产生成
  → 如用户上传场景图:
     - 按相同风格转换场景图
  → 如用户提供场景描述:
     - 使用文生图生成场景,风格关键词与角色保持一致
     - 示例场景描述: "室内拳击擂台,全景,四周护栏,顶部聚光灯,观众席环绕,[风格关键词]"
  → 生成后等待用户确认

Step 5: 资产确认
  → 展示3张素材缩略图
  → 询问: "3张素材已准备完成,是否立即生成15秒打斗视频?"
    ├─ 同意 → 进入视频生成阶段
    └─ 拒绝 → 询问需要重新生成哪张素材 → 返回对应Step
```

**关键决策点**:

- 风格转换必须在资产准备阶段完成,不可在视频生成后调整
- 每个角色/场景生成后必须等待用户确认,避免积累错误
- 如用户对某个资产不满意,允许单独重新生成该资产

### 2. 动作脚本构建阶段

**标准15秒打斗叙事结构**:

```
一次性生成15秒的打斗效果，无特效
```

**动作细节描述规范**:

- 每个动作必须明确: 出拳角度(上勾/平直/下砸) + 击打部位(下巴/腹部/侧脸)
- 每个反应必须明确: 格挡方式(双臂交叉/单手拨开) + 身体反馈(后退步/重心下沉)
- 物理效果仅限真实元素: 汗水/尘土/衣物褶皱动态,严禁出现能量光效/魔法粒子/慢动作光轨

### 3. 视频生成阶段

**生成参数锁定**:

- 时长: 15秒(严禁分段生成后拼接)
- 分辨率: 720p
- 画幅: 16:9
- 参考模式: 全能参考(Omni Reference),3张素材全部引用

**提示词构建框架**:

```
[@image:#1:角色1:URL] [@image:#2:角色2:URL] [@image:#3:场景:URL]

[整体视觉规格]
- 4K超高清渲染
- [风格关键词: CG游戏/卡通动漫/写实]
- 720p输出,16:9画幅
- 电影级运镜,动态镜头构图

[动作脚本完整描述]
一次性生成15秒的视频打斗视频，无特效
[场景互动细节]
- 擂台地面轻微震动
- 聚光灯随动作晃动
- 汗水在光束中清晰可见
- 衣物随肢体运动产生褶皱

[严格约束]
- 角色外貌/服装100%还原参考图
- 无能量特效/魔法光效/慢动作光轨
- 15秒完整生成,不分段
```

**生成后检查清单**:

- ✓ 角色面部特征是否与参考图一致
- ✓ 服装细节(颜色/款式/配饰)是否还原
- ✓ 动作连贯性是否流畅无断层
- ✓ 场景空间是否与参考图匹配
- ✓ 是否出现非真实特效(如有则标记为失败)

## 关键约束与标准

### 不可变规则(Immutable Rules)

1. **15秒完整生成约束**

   - 严禁生成5秒片段后建议用户"延长视频"
   - 严禁生成多个短片段后使用剪辑工具拼接
   - 严禁引导用户"分段制作更精细"
   - 如生成失败,必须重新生成完整15秒,不可部分修复

2. **外貌锁定约束**

   - 角色面部特征(眼睛形状/鼻梁高度/嘴唇厚度)必须像素级一致
   - 发型(长度/颜色/卷曲度)不可变化
   - 体型比例(肩宽/腰围/腿长)不可变化
   - 肤色(色调/饱和度/明度)不可变化
   - 如任一帧出现角色面部明显变形,标记为失败

3. **服装锁定约束**

   - 服装款式(领口设计/袖长/下摆)不可变化
   - 服装颜色(主色/辅色/图案)不可变化
   - 配饰(拳击手套/护腕/鞋子)不可增减
   - 如出现"角色1穿着角色2的服装"情况,标记为失败

### 保真度规则(Fidelity Rules)

1. **风格一致性**

   - 如选择CG游戏风格,全程保持高精度3D渲染质感
   - 如选择卡通动漫风格,全程保持描边+色块风格
   - 不可在视频中途切换风格(如前半段CG,后半段卡通)
   - 场景风格必须与角色风格匹配

2. **物理真实性**

   - 允许的真实物理效果: 汗水飞溅/尘土扬起/衣物褶皱动态/头发飘动
   - 严禁的非真实特效: 能量光环/魔法粒子/冲击波光效/慢动作光轨/爆炸火花
   - 拳击碰撞时可有空气扰动感,但不可出现可见光波
   - 角色倒地时可扬起尘土,但不可出现地面龟裂光效

3. **动作连贯性**

   - 每个攻击动作必须有完整的"蓄力-发力-收回"过程
   - 每个防守动作必须有"观察-反应-格挡"过程
   - 不可出现"瞬移"(角色突然从A点跳到B点无过渡)
   - 不可出现"凝固"(角色动作突然静止超过0.5秒)

### 一致性规则(Consistency Rules)

1. **场景空间一致性**

   - 擂台护栏位置不可移动
   - 光源方向不可突变(如顶光突然变侧光)
   - 背景道具不可凭空出现或消失

2. **镜头逻辑一致性**

   - 全景镜头必须展示完整擂台空间
   - 中景镜头必须展示两个角色的相对位置
   - 特写镜头必须聚焦关键动作(如拳头击中瞬间)
   - 不可出现"镜头穿模"(镜头穿过护栏/地面)

3. **时间流逝一致性**

   - 不可使用慢动作(所有动作必须实时速度)
   - 不可使用快进(15秒必须对应真实15秒)
   - 动作节奏必须符合真实格斗(拳速约0.3-0.5秒/拳)

**用户上传素材**: 一张男性健身爱好者照片 + 一张女性武术运动员照片 + 一张拳击馆内景照片

**风格选择**: 用户选择"CG游戏风格"

**生成提示词**:

```
[@image:#1:男性角色:https://example.com/male.jpg] [@image:#2:女性角色:https://example.com/female.jpg] [@image:#3:拳击馆:https://example.com/gym.jpg]

4K超高清CG游戏风格渲染,720p输出,16:9画幅,电影级运镜。
```

## 高级技巧

### 多轮对战场景构建

如用户需要制作超过15秒的长视频,可采用"多回合"策略:

- 第一轮: 生成15秒"第一回合"视频,结尾定格在角色2获胜姿态
- 第二轮: 使用视频最后一帧作为新的参考图,生成15秒"第二回合"视频,角色1反击
- 后期拼接: 使用视频编辑工具无缝拼接多个15秒片段

但必须注意:

- 每个15秒片段必须完整生成,不可在单个片段内分段
- 拼接点必须在角色静止姿态(如对峙/倒地),避免动作断层
- 服装/场景/光影必须在所有片段保持一致

### 风格混合策略

如用户希望角色使用CG风格,但场景使用真实照片质感:

- 分别生成角色资产(CG风格)和场景资产(写实风格)
- 在视频生成提示词中明确: "角色采用CG游戏风格渲染,场景保持照片级写实质感"
- 注意光影匹配: CG角色的光照方向必须与真实场景光源一致

### 动作库扩展

标准15秒模板可替换为其他格斗类型:

- 功夫风格: 以踢技为主(侧踹/旋风踢/后旋踢)
- 摔跤风格: 以擒抱为主(过肩摔/扫堂腿/锁技)
- 综合格斗: 拳腿组合+地面缠斗
- 武器格斗: 双节棍/刀剑对决(需额外生成武器资产)

但所有动作必须符合真实物理规律,不可出现"飞天""瞬移"等夸张效果。
