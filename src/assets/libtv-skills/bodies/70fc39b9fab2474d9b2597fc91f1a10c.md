# 剧本写作

专业电影剧本写作技能，基于系统化的编剧理论和经典剧本案例分析，指导从创意到完成的完整写作流程。

## 写作流程

当用户请求创作剧本时，按以下流程逐步执行。每一步完成后与用户确认，再进入下一步。

### 第一步：创意孵化

与用户讨论故事创意，提炼出**故事线（Logline）**

1. 故事线必须包含：
   - **意外**：有反差/讽刺的吸引力
   - **心理影像**：一句话能在脑海中看到整部电影
   - **观众和成本**：明确目标观众
   - **片名**：体现故事实质
2. 确定影片类型（参考 `references/03-救猫咪方法论.md` 十大类型）
3. 故事线格式：**"一个\[形容词\]的\[主角\]，在\[情境\]中，必须\[行动\]才能\[目标\]"**

### 第二步：人物创造

1. 确定主角——必须满足：
   - 在该情景下能带来最大冲突
   - 情感上能走得最远
   - 能让最多观众喜爱
2. 写人物传记（从出生到影片开始）
3. 从三个维度定义人物关系：
   - **职业的**：工作、与同事/老板关系
   - **个人的**：婚姻、社交、家庭关系
   - **私生活的**：独处时做什么
4. 明确主角的**戏剧性需求**——想要什么？
5. 设计"救猫咪"场景——让观众尽早喜欢主角
6. 设计反面力量——越强大越好
7. 为每个重要角色确定**视觉辨识特征**

### 第三步：结构设计

1. 确定结尾——**知道结尾才能写好开端**
2. 用三幕结构规划全片（参考 `references/01-三幕结构理论.md`）：
   - **第一幕（1-30页）**：建置——10页内交代主角、前提、情境
   - **第二幕（30-90页）**：对抗——冲突升级，障碍重重
   - **第三幕（90-120页）**：结局——解决冲突
3. 用布莱克·斯奈德节拍表细化（参考 `references/03-救猫咪方法论.md`）：
   - 开场画面 → 主题呈现 → 铺垫 → 推动 → 争执 → 第二幕衔接点
   - B故事 → 娱乐游戏 → 中点 → 坏蛋逼近 → 一无所有 → 灵魂的黑夜
   - 第三幕衔接点 → 结尾 → 终场画面
4. 确定两个情节点——转折故事方向的关键事件
5. 设计中点——伪胜利或伪失败

### 第四步：分场大纲

1. 将节拍表展开为40-60个场景
2. 每个场景标注：
   - 场景标题（内景/外景 - 地点 - 日/夜）
   - 押上台面的价值（正面/负面）
   - 场景结尾的价值转折
   - 该场景的功能（推进动作或揭示人物）
3. 确保每个场景都有转折——没有转折的场景删除
4. 每10-15页设置一个转折点
5. 情绪色环：相邻场景的情绪不同

### 第五步：初稿写作

1. 按照分场大纲逐场景写作
2. 严格遵守中文剧本格式（参考 `references/04-中文剧本格式规范.md`）
3. 动作描写原则：
   - 现在时态、只写镜头能看到的东西、简洁视觉化、一页=银幕一分钟
4. 对白原则：
   - 每句对白要么推进动作，要么揭示人物
   - 口语化，避免书面语
   - 展示，不要告知——用行为而非言语传达信息
5. "泳池里的教皇"原则——用视觉趣味包裹枯燥的信息交代

### 第六步：自检与修改

用以下清单检查剧本：

**结构检查：** 前10页交代主角/前提/情境？情节点在正确位置？冲突持续升级？高潮绝对不可逆转？开场与终场画面对比？

**人物检查：** 有"救猫咪"场景？需求明确且原始？有人物弧光？反面力量足够强？有视觉辨识特征？

**场景检查：** 每场景有价值转折？无非事件场景？每10-15页有转折？相邻场景情绪不同？

**对白检查：** 无"说情节"？无无意义寒暄？每句推进动作或揭示人物？

**动力检查：** 动机原始？危险迫在眉睫？主角退到比开始更差？中点是伪胜利还是伪失败？

## 剧本诊断

当用户请求诊断已有剧本时：

1. 识别类型归属
2. 检查三幕结构完整性
3. 定位情节点位置
4. 分析主角弧光
5. 检查冲突升级
6. 找出"非事件"场景
7. 诊断对白问题
8. 用自检清单逐项排查
9. 给出具体修改建议

## 剧本分析

当用户请求分析某部电影时：

1. 三幕结构分解
2. 主角分析（需求、弧光、原始动力）
3. 主题和价值冲突
4. 类型归属
5. 关键场景分析
6. 叙事技巧
7. 可借鉴的写作技法

## 核心原则

 1. **动作即是人物**——行为而非言谈定义人物
 2. **没有冲突就没有戏剧**——每场戏都要有冲突
 3. **展示，不要告知**——用画面讲述故事
 4. **故事是生活的比喻**——提取精华而非照搬
 5. **知道结尾才能写好开端**——方向决定一切
 6. **每个场景都必须有转折**——没有转折就是非事件
 7. **原始动力最有力**——生存、性、保护爱人、死亡恐惧
 8. **反面力量越强，主角越伟大**
 9. **似而不同**——遵循类型规律但要有新转折
10. **对白是压缩的艺术**——不是真实对话的还原
11. **所有问题归于三类**——情节、人物、结构（三者联动）
12. **停滞=死亡**——节奏停滞时必须有东西死去，新东西才能诞生
13. **凯瑞斯·哈丁法则**——最完美的时候，就是一切即将崩塌的时候
14. **英雄必须死而复生**——磨难中的"死亡"是重生的前提
15. **正题→反题→合题**——故事是从旧世界到颠倒世界再到新世界的旅程
16. **两次撞击**——催化剂不是一次，暗示+冲击才有张力
17. **先享受故事，结构是后话**——构思时不要被规则束缚创造力
18. **第一稿都是狗屎**——接受这个事实，然后改写、改写、再改写
