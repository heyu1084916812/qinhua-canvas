# 邵氏赛博武侠 (Shaw Brothers Cyberpunk Wuxia)

## 技能用途

本 Skill 深度融合了 1970 年代邵氏武侠电影美学、胡金铨导演的空间哲学以及现代赛博朋克中的“巨物恐惧症”视觉元素。它能生成比例极度悬殊的人物与环境对比，创造出一种既复古又未来的东方史诗级科幻画面。

## 适用输入

- **角色设定**：如“机械义肢的剑客”、“披着丝绸斗笠的改造人”。
- **场景描述**：如“摩天塔林中的古镇”、“废土风格的龙门客栈”。
- **构图倾向**：如“极小人物占比”、“垂直构图”、“体积光”。

## 操作步骤

1. **空间构建**：采用胡金铨式的非对称构图，将建筑或机械结构设为视觉主体，占据画面 80% 以上空间。
2. **比例校准**：强制设定人物在画面中的高度占比为 5%-10%，利用比例失调制造压迫感。
3. **风格渲染**：模拟 35mm 胶片质感，加入低饱和度的土黄色、墨绿色或褪色红调。
4. **赛博融合**：将霓虹灯带嵌入传统飞檐，或在丝绸袍服下隐藏机械齿轮，确保科技元素具有陈旧的铁锈质感。

## 输出要求

- **质感**：具备 1970 年代胶片颗粒感，包含明显的体积光束（丁达尔效应）和浓重的烟雾感。
- **色彩**：主色调限定在琥珀色、朱砂红、翡翠绿及深阴影中，严禁出现现代荧光紫粉色调。
- **构图**：必须包含大量“负空间”，利用深焦镜头展现宏大的纵深感或垂直高度。

## 注意事项

- 
- 拒绝廉价科幻：科技元素应像“古代文明的遗物”，而非崭新的未来设备。
- 保持东方审美：霓虹文字需使用繁体中文或书法体，建筑比例应遵循古典营造法式。

  你的任务是帮助用户生成具有胡金铨古典武侠电影美学的AI图片提示词，以及基于图片\
  首帧生成对应的视频提示词。\
