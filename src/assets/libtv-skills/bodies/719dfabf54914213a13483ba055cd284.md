# Y2K Virtual Dress-Up Video Generation

## Core Methodology

### Y2K Visual Constitutional System

This skill operates under a locked visual framework that defines immutable Y2K aesthetic DNA:

**Color Protocol**: High-saturation hot pink (#FF69B4), baby blue (#89CFF0), metallic silver (#C0C0C0), pure white (#FFFFFF), translucent plastic tones. Prohibit dark/muted/natural earth tones.

**Material Language**: Transparent PVC, jelly textures, mirror reflections, patent leather, pearl luster. Apply soft-focus filters, low-pixel digital camera grain, localized overexposure.

**Iconography**: Butterflies, stars, sparkles, bubbles, pixel hearts, cursor arrows, Win98/XP window borders as mandatory visual markers.

**Typography**: Pixel fonts or rounded bold with glowing outlines or 3D shadows.

### Layered Identity Isolation Framework

Treat each video as a **5-layer compositional stack** where layers obey strict independence rules:

- **Layer 1 (Facial Identity)**: Face shape, eyes, nose, mouth, skin tone — **ABSOLUTE LOCK across all outfits**. This is the anchor layer that must achieve pixel-level consistency.
- **Layer 2 (Hairstyle)**: Hair length, color, styling — may vary per outfit if user requests, otherwise inherit from source.
- **Layer 3 (Outfit)**: Clothing items — the primary transformation variable. Generate 4-5 distinct outfits following specified style direction.
- **Layer 4 (Accessories)**: Jewelry, bags, glasses, hats — secondary styling variations.
- **Layer 5 (Background Environment)**: Color-matched themed spaces — changes per outfit to reinforce color storytelling.

### Outfit Generation Logic

When user provides a single portrait, apply **Outfit Matrix Expansion**:

1. **Style Direction Parsing**: Decode user keywords (sweet/street/retro/futuristic/eclectic) into concrete garment categories.
2. **Color Scheme Inheritance**: Extract 2-3 dominant colors from portrait, expand into Y2K-compatible palette families.
3. **Outfit Diversification**: Generate 4-5 outfits spanning:
   - Top variation (crop tops, jackets, tees with graphic prints)
   - Bottom variation (mini skirts, cargo pants, flare jeans)
   - Footwear (platform sneakers, transparent heels, chunky boots)
   - Accessory clusters (sunglasses, bags, jewelry, headwear)
4. **Name Assignment**: Each outfit gets a pixel-font Y2K-style name (e.g., "BUTTERFLY GIRL", "CYBER ANGEL", "PINK FEVER").

### Unified Transition Architecture

All scene transitions follow **360° Clockwise Rotation Standard**:

- **Motion**: Every outfit switch executes a full 360° clockwise spin with consistent angular velocity
- **Duration**: 0.3-0.5 seconds per transition
- **Effect Layer**: Simultaneous color-matched neon burst (pink→pink neon, blue→blue neon)
- **Particle System**: Silver glitter, pixel fragments, or themed icons (stars/butterflies) scatter during rotation peak

This creates predictable rhythm and visual coherence across 4-5 outfit changes.

## Workflow

### 1. Input Analysis & Mode Detection

**Asset Checklist**:

- 1 character portrait (photo/illustration/game character)
- Optional: outfit style keywords (sweet/street/cyber/retro)
- Optional: color scheme override (use preset palettes or custom)
- Optional: ending text overlay

**Decision Logic**:

- Single portrait input → Mode B (Virtual Dress-Up)
- 2-6 outfit images → Mode A (Physical Outfit Cards) — NOT covered in this skill

**Facial Identity Extraction**:

- Analyze face geometry: eye spacing, nose bridge height, lip fullness, jawline
- Detect skin tone: undertone (warm/cool/neutral), saturation level
- Note hairstyle: length, texture, color for potential inheritance
- These parameters become **immutable constraints** for all generated outfits

### 3. Video Prompt Construction

**15-Second Continuous Video Structure** (9:16 vertical format):

**0-3s (Opening)**: Y2K desktop surface with butterfly stickers, silver glitter, star confetti. Small window frame appears center with character portrait (establish facial identity). Pixel title "DRESS UP" or custom text fades in with primary color glow. Cursor arrow drifts.

**3-6s (Outfit 1)**: 360° clockwise rotation transition. Character now wearing first outfit. Name appears below in pixel font. Background shifts to color-matched themed space (e.g., blue neon tunnel for blue outfit). Character performs subtle action (adjusts sunglasses, winks).

**6-9s (Outfit 2)**: 360° rotation transition with pink/blue/green neon burst. Second outfit appears, same face. Name updates. Background changes. Character action varies (hand on hip, holds prop).

**9-12s (Outfits 3-4)**: Rapid succession, 360° rotations maintain same angular velocity but occur faster. Pixel fragments/stars scatter during transitions. Backgrounds flash corresponding colors.

**12-15s (Final Outfit & Ending)**: Last 360° rotation. Final outfit settles center. Slight camera push-in. Desk elements (butterflies, stars, glitter) drift inward to frame character. Bottom center: pixel text closing statement ("BE YOUR OWN ICON ✦" or custom). Character performs ending gesture (rock sign, peace sign, blowing kiss). Freeze frame with slight zoom.

**Camera**: High-angle overhead perspective throughout (never shifts to side/low angles). Slight fish-eye lens distortion acceptable. Final segment allows gentle push-in but maintains vertical axis.

### 4. BGM Integration

**Music Style**: Y2K bubblegum synthesizer pop — upbeat tempo (120-140 BPM), major key, short arpeggio loops, synthetic drums, occasional pitch-shifted vocal chops.

**Sync Strategy**:

- **Beat alignment**: Each 360° rotation peaks on downbeat
- **Energy curve**: Build energy through first 3 outfits, climax at outfit 4, slight decay into ending freeze
- **Transition hits**: Neon bursts/particle explosions sync with snare hits or synth stabs

**Generation then merge**: First generate video, then generate BGM separately, finally composite with video at 70-80% volume (dialogue-free).

## Key Constraints & Standards

### Immutable Identity Rules

- **Facial geometry lock**: Eye distance, nose shape, lip contour, face width CANNOT vary by even 5% across outfits
- **Skin tone consistency**: Maintain identical RGB values (±3 tolerance) for skin rendering
- **Ethnicity preservation**: If source portrait shows specific ethnic features, all outfits MUST retain those features
- **Age consistency**: Apparent age (teenage/young adult/mature) must remain constant

### Y2K Aesthetic Fidelity

- **Mandatory visual markers**: Every frame must contain at least 2 of: butterflies, stars, pixel text, holographic elements, transparent materials
- **Color saturation floor**: No color may drop below 60% saturation (except whites/silvers)
- **Prohibited elements**: Realistic fabric textures, natural wood grain, stone surfaces, organic materials, warm incandescent lighting
- **Typography enforcement**: All text uses pixel fonts or rounded bold with stroke outlines, never serif or script fonts

### Transition Consistency Standards

- **Rotation uniformity**: All 360° rotations complete in 0.4 seconds ±0.05s
- **Direction lock**: ONLY clockwise rotations, never counterclockwise or mixed
- **Effect synchronization**: Neon burst MUST trigger at 180° rotation midpoint
- **Particle count**: 20-40 particles per transition (stars/glitter/pixels), evenly distributed

### Output Technical Standards

- **Aspect ratio**: 9:16 vertical (1080×1920 minimum)
- **Frame rate**: 24 FPS
- **Duration**: 15 seconds ±0.5s
- **Outfit count**: 4-5 (user may request +1 outfit, regenerate full video)
- **Color depth**: 8-bit per channel minimum for Y2K digital aesthetic

### Batch Coherence Rules

- When user requests "add one more outfit", regenerate entire 15s video with N+1 outfits
- Maintain same facial identity and color scheme across regenerations
- Preserve successful outfit designs from previous generation
- Adjust timing: 4 outfits = 3s each, 5 outfits = 2.5s each, 6 outfits = 2s each
