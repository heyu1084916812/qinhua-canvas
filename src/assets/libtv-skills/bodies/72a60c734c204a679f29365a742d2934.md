# 纪实摄影 × 复古印刷上下对照海报

## Core Methodology

以单张参考照片为唯一内容依据，生成“上半幅纪实摄影＋下半幅复古平面印刷”的上下对照海报。上半幅作为身份锚点，必须锁定原图中所有核心主体的身份、数量、外形、姿态、朝向、相对位置、比例、遮挡关系及原始视角/透视/构图/光影/色彩；下半幅作为风格化重译，在保持主体轮廓、方向与相对位置可辨的前提下，将其转化为高反差的丝网印刷/RISO/报纸半色调/朋克拼贴语言。中间以撕纸毛边、油墨飞白与印刷磨损自然分隔，整体形成独立杂志封面、复古专辑或城市旅行刊物的气质。

## Workflow

1. **解析参考图**：识别核心主体（建筑/人物/动物/车辆/物品/植物/地形）、数量、外形、姿态、表情、朝向、相对位置、比例、遮挡关系、视角、透视、构图层次、光线方向、阴影、天气/季节、标志性色彩。

2. **确定版式与文字**：默认 3:4 竖版，上下两幅接近 1:1。根据内容确定英文主标题（1–3 个单词）、编号（NO. XXX）、竖向副标题、底部地点/日期/坐标短句。

3. **提取限色体系**：从原图提取一种深色主色（深海军蓝或炭黑）与一种高识别强调色，搭配暖象牙白旧纸底色，形成双色或三色限色。

4. **撰写生成提示词**：

   - **上半幅**：35mm/50mm 纪实摄影、自然景深、环境光、柔和高光、哑光黑位、低对比度电影调色、轻微色彩分离、胶片颗粒/灰尘/划痕/褪色/暗角/印刷旧化。
   - **下半幅**：高反差剪影、粗颗粒网点、交叉排线、干刷边缘、油墨拖痕、局部破损、暖象牙白旧纸底、纸张纤维/泛黄/污渍/折痕、油墨渗透/飞白/喷溅/刮擦/套色错位/印版磨损/不均匀墨色。
   - **分隔**：轻微撕纸毛边、油墨飞白、印刷磨损。
   - **文字**：超大窄体粗体英文标题（可分两行、延伸至边缘并被主体局部遮挡）、右上朱红小字编号与竖向副标题、左下高字距小字、细线/箭头/编号/少量编辑标记。

5. **调用生成**：使用 `generate_image_gpt_image_2_5_sunburst`（`quality=high`），将参考图传入 `reference_image_urls`，输出比例按需求设为 3:4 或其他。

## Key Constraints

- 上半幅必须严格以参考图为唯一依据，不得镜像、拉伸、增减或重新设计主体。
- 下半幅保持主体数量、方向、轮廓与相对位置可辨，仅适度压缩次要背景、简化杂乱细节与调整尺度。
- 文字必须准确清晰、无额外乱码；英文主标题限制 1–3 个单词。
- 避免新增无关主体、五官肢体畸形、透视错误、过艳、霓虹赛博风、塑料皮肤、光滑矢量感、密集无意义文字、边框和水印。
