# 做什么

将普通AI视频提示词增强为具有真实世界生命感的电影级动态场景。

该Skill用于解决AI视频中常见问题：

- NPC站桩
- 背景人物像复制粘贴
- NPC缺少行为目的
- 人物动作机械
- 环境像静态背景
- 世界缺少真实社会运行感
- 场景没有人与环境的互动关系

通过建立“活世界系统”，让AI生成的视频中的人物、环境和空间拥有持续自然的运动逻辑，使场景像真实电影世界一样运行。

# 需要什么输入

用户提供：

- 视频场景描述
- 场景类型
- 主要角色设定
- 时间时代背景
- 世界观设定（可选）

例如：

- 现代城市
- 未来都市
- 古代街市
- 机场
- 港口
- 餐厅
- 办公室
- 自然环境
- 战争场景
- 科幻基地

# 怎么做

在原始视频提示词后自动添加“活世界增强规则”。

保留用户原始：

- 主角设定
- 剧情内容
- 镜头语言
- 摄影风格

只增强：

- 背景人物逻辑
- 环境运动
- 世界真实性

# 1. NPC身份与多样性系统

所有背景人物必须具有独立身份。

NPC不是背景装饰，而是真实生活在这个世界中的人。

生成不同类型的人物：

- 不同年龄
- 不同身高
- 不同体型
- 不同脸型
- 不同五官
- 不同发型
- 不同发色
- 不同皮肤纹理
- 不同服装
- 不同配饰

每个NPC拥有独立外观。

禁止：

- 相同脸
- 克隆人物
- 重复服装
- 相同发型
- 同一动作复制

# 2. NPC行为目的系统

每个NPC必须拥有明确目的。

生成NPC时，根据环境赋予：

- 身份
- 当前目标
- 行为状态
- 与环境关系

例如：

城市街道：

不是简单走路。

而是：

- 上班族赶路
- 游客观察建筑
- 朋友聊天
- 行人查看手机
- 商店顾客购物
- 等待交通工具

机场：

- 乘客拖运行李
- 查看信息屏
- 等待登机
- 工作人员协助旅客

餐厅：

- 顾客聊天
- 服务员上菜
- 厨房工作人员移动
- 客人查看菜单

办公室：

- 员工讨论工作
- 使用电脑
- 打印文件
- 走动交流

自然环境：

- 游客拍照
- 人观察风景
- 动物活动
- 环境自然变化

# 3. NPC行为链系统

避免NPC只有单一动作。

每个NPC动作应该包含连续行为：

例如：

错误：

走路 → 结束

正确：

走路 → 注意环境 → 停顿 → 与他人交流 → 改变方向 → 继续行动

NPC行为应该具有：

- 偶然停顿
- 临时改变路线
- 观察周围
- 与环境互动
- 与其他人物交流

# 4. 真人运动系统

所有人物保持真实生命状态：

- 自然呼吸
- 自然眨眼
- 眼神移动
- 轻微表情变化
- 手部动作
- 身体重心变化
- 不同走路节奏
- 不同动作速度

人物动作不能像游戏角色。

禁止：

- 机械行走
- 同步动作
- 循环动画
- 木偶感

# 5. 环境生命系统

环境必须持续运动。

根据场景自动增强：

## 城市：

- 车辆移动
- 行人流动
- 建筑灯光变化
- 信息屏更新
- 商店活动
- 公共设施运行

## 未来城市：

- 机器人执行任务
- 自动交通运行
- 居民使用科技设备
- 飞行载具移动

## 港口：

- 船只进出
- 工作人员活动
- 海浪变化
- 设备运行
- 鸟类飞行

## 自然环境：

- 风吹植物
- 云层移动
- 水流变化
- 动物活动

# 6. 世界物理真实系统

所有动作符合真实物理：

- 人避让其他人
- 物体受到重力影响
- 衣服受到风影响
- 头发自然摆动
- 水面产生真实波纹
- 光影随着环境变化

# 7. 电影真实感约束

增强：

- 真实空间关系
- 真实人物互动
- 真实环境反馈
- 真实社会氛围

禁止：

- NPC站立不动
- 背景人物像贴图
- 人群同步运动
- 重复动作循环
- 所有人看镜头
- 空洞环境
- 游戏NPC感觉
- 塑料人物感
- AI生成感

# 输出什么

输出增强后的完整AI视频生成提示词。

最终结果包含：

- 主角剧情保持不变
- 背景世界更加真实
- NPC拥有独立行为
- 环境持续运动
- 场景具有电影级生命感
