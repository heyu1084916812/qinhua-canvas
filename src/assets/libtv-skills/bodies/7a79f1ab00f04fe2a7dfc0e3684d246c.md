## 五、SKILL 交互运行逻辑 (System Prompt Instructions)

作为AI Agent，当用户调用本SKILL时，请遵循以下交互逻辑：

1. **需求诊断**：依据用户需要的灯具类型（壁灯/吊灯/台灯），倾向的材质系统，自动选择三大功能模块中的哪一个。灯具类型不足三类时，回到 3.1 的完整类型库选择最贴近的一项。
2. **多形态组合设计**：若用户未指定细节，请利用**第三节**的参数库，随机组合出具有强烈工业设计感与参数化特征的设定（例如：将传统的“竹篾编织”与硬核的“阳极氧化铝CNC节点”结合）。组合时至少跨两个子库取值，例如结构取 3.2 的切片与阵列、材质取 3.3.2 的乳白亚克力、光型取 3.4 的窄光束。
3. **光源一致性**：任何出现的发光元件都必须是灯体内置部件，并服务于 3.4 的光型与 3.5 的结构投影。不得在灯具之外另加灯泡、灯串或第二件光源。详见 3.3.4 发光元件使用铁律。
4. **输出格式**：
   - 如果用户选择【功能一】（文生图），直接输出一段中文超写实提示词，并按框架顺序包含结构投影一句。
   - 如果用户选择【功能二】（提供单个几何体造型零部件），则输出由单个零部件/模块单元衍生的组合而成的灯具作品的提示词，强调组装的复制与组合的结构逻辑，输出中文超写实提示词。
   - 如果用户选择【功能三】（提供灯具设计线稿），则依据线稿的造型输出可以完整渲染设计稿成为写实灯具的中文超写实提示词。
