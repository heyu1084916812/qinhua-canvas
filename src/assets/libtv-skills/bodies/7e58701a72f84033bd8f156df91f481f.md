# 次元觉醒动漫短片生成器

## 这个 Skill 做什么

输入一个主题，产出一条**约 84 秒、8 个分镜**的日系动漫短片成片。

链路固定为 5 段：**脚本 → 角色/场景/道具锚点图 → 分镜图 → 分镜视频 → 智能剪辑合成成片**，每段产出物都在同一张画布上落地，下一段以上一段为输入。

<hr>

## 输入槽位

| 槽位 | 是否必需 | 说明 |
|---|---|---|
| `{主题}` | 必需 | 一句话故事方向，如"次元少女觉醒并融入星河" |
| `{主角设定}` | 可选 | 外貌、发型、发色、服装风格；不填则按风格模板生成"次元潮流少女" |
| `{场景设定}` | 可选 | 主要场景列表；不填则由脚本自动派生 |
| `{道具/能力设定}` | 可选 | 关键道具或能力意象；不填则由脚本自动派生 |
| `{单镜时长}` | 可选 | 8 个镜头的秒数，默认 `10 / 8 / 12 / 10 / 15 / 7 / 12 / 10`，合计 84 秒 |

**时长是硬约束**：8 镜秒数之和决定成片长度。用户没指定时用默认值，不要自行改成别的节奏。

<hr>

## 锚点（固定工艺，不随主题变化）

1. **整体风格锚**：`日系精致动漫、二次元赛璐璐质感、高细节发丝笔触、4K 高清`，并在每条镜头描述末尾统一追加：
   `[视觉风格：近未来赛博与幻想·日系动漫二次元]`
2. **画质锚**：涉及近景/特写时强调 `细腻的面料肌理与皮肤纹理`；全景/大远景强调 `4K 极致高清`。
3. **8 镜叙事骨架**（镜头数与推进节奏固定，内容随主题替换）：

| 镜 | 时长 | 景别 | 叙事功能 | 画面要点 |
|---|---|---|---|---|
| 镜1 | 10s | 近景 | 开场·苏醒 | 人物初现，三分法构图，侧光勾轮廓，压抑氛围 |
| 镜2 | 8s | 大特写 | 定人物 | 焦点在眼眸，瞳孔含流动特效，正平视，强对比霓虹光 |
| 镜3 | 12s | 中景 | 进入新空间 | 人物做标志性小动作，人物置于画面左三分，丁达尔光束 |
| 镜4 | 10s | 中远景 | 冲突/奔跑 | 动态奔跑，背景光效扭曲，频闪预警光，节奏最紧 |
| 镜5 | 15s | 全身景 | 大场景展示 | 广阔场景中伫立，捧起关键道具，柔和漫反射蓝紫调 |
| 镜6 | 7s | 全景 | 高潮动作 | 凌空跃起，对角线构图，激光束精准打光 |
| 镜7 | 12s | 特写 | 蜕变/觉醒 | 粒子光辉、发丝放射状漂浮，伦勃朗布光，神圣浪漫 |
| 镜8 | 10s | 大远景 | 收尾留白 | 背影剪影，强逆光，人物融入背景，宏大治愈 |

   骨架顺序不要打乱；镜4 与镜5 的先后即"冲突在前、舞台在全"的节奏，随意交换会削弱张力。

4. **锚点图先行工艺**：所有角色/场景/道具锚点图必须**先于**分镜图产生。分镜图提示词只做"参照 + 组合"，不重复描写锚点图里已有的外貌细节，改由上游连线提供一致性。
5. **一致性锚**：同一人物在不同镜头必须复用同一张人物锚点图；换了服装/形态的镜头（如编发形态、觉醒形态）单独出一张形态锚点图，并只给该镜使用。
6. **分镜图 → 分镜视频的绑定规则**：每个分镜视频节点同时输入 [该镜分镜图] + [该镜涉及的人物/场景/道具锚点图]；提示词内以"参照上游的 XX 保持一致性"的方式说明每张输入图的角色，输入图数量与该镜相关度一一对应，不要挂无关锚点。
7. **剪辑合成规则**：所有分镜视频按 **镜1→镜8** 顺序接入智能剪辑节点，顺序即时间轴顺序；只接最终采用的那一版分镜视频，不接重做中的废稿。

## 执行流程

### 第 1 步：生成分镜脚本
在画布上放一个文本节点写出**完整分镜脚本**（风格说明 + 人物设定 + 逐镜描述），再转成一个**脚本 V2 节点**（本画布为 8 行）。

脚本必须包含：
- 顶部：视频时长与镜数、核心风格、人物设定；
- 每镜一段，以 `### 【起-止秒 镜N】` 开头，段内固定四要素：**景别 + 人物状态与动作 + 环境与光效 + 构图/光影 + 画质**，结尾附风格锚句。

脚本里的人物名、台词、具体场景名都是槽位，按用户 `{主题}` 替换。

**如果人物/场景设定或锚点图已经先做好，把它们一并接到脚本节点的输入端**，让脚本文本基于真实锚点描述来写。

### 第 2 步：产出锚点图
按脚本设定逐张生成锚点图，放在脚本上游/同层：

- **人物锚点**：至少 1 张主角基础形态；有形态变化的主题，额外各出 1 张（参考本画布：核心形态少女、编发形态少女，各 1 张）。
- **场景锚点**：每个主要场景 1 张。
- **道具锚点**：每个关键道具/能力意象 1 张。

锚点图提示词 = `{风格锚}` + `{该实体的设定描述}` + 构图/光影要求（人物锚点用正面/半身、背景干净，便于后续复用）。

### 第 3 步：生成分镜图（可分组）
按脚本逐镜生成分镜图节点。分镜图提示词结构：

```
{镜号}分镜。{景别}。{人物}在{场景}中{动作}。{光效与构图描述}。
参照上游：{人物锚点图} 保持人物外貌与发型一致；{场景锚点图} 保持场景结构一致；{道具锚点图} 保持道具形态一致。
{风格锚}
```

- 人物外貌**不重写**，只引用上游锚点图；
- 镜1–镜3、镜5–镜8 使用基础人物锚点，镜4、镜6 使用编发形态锚点（此为该画布的形态分配，换主题时按"该镜人物形态"决定挂哪张人物锚点）；
- 全部 8 张分镜图可归入一个分组节点，分组名格式 `分镜图 · {主题名}`。

### 第 4 步：生成分镜视频
每张分镜图对应一个视频节点，**时长取 `{单镜时长}` 中该镜的值**。视频节点提示词沿用该镜分镜描述，并强调运动：`{动作/运镜描述}，运镜丝滑，{风格锚}`。

### 第 5 步：剪辑合成
建一个**智能剪辑**节点，把 8 段分镜视频按镜号顺序接入，产出成片。成片时长应与 `{单镜时长}` 之和一致（默认 84 秒）；若不一致，检查是否漏接或多接了素材。

## 边界与注意事项

- **模型与参数**：本画布未提供分镜图/分镜视频节点的原始提示词与模型参数，因此本 Skill 只固定**链路结构、提示词写法与风格锚点**，具体图像/视频模型与参数请沿用当前环境可用的动漫向模型默认值，并按成片效果微调。
- **风格漂移**：若某镜画风跳脱，优先检查该镜提示词是否漏了风格锚句，以及是否挂了正确的人物锚点图。
- **人物不一致**：优先检查该镜分镜图/视频是否真的连了对应人物锚点，而不是在提示词里重述外貌。
- **本 Skill 不生成音效**：原画布脚本标题提到音效，但画布上没有音频节点，故本 Skill 不包含配乐/音效环节；需要时请单独处理。
