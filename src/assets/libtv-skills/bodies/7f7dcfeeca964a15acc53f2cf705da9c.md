# 图片转无人机灯光点阵图

把一张真实图片（或一段零散的文字想法）转成无人机灯光表演秀用的圆形光点点阵图，作为创意视频转场的前置出图步骤。

## 什么时候用

**用**：用户想得到一张无人机灯光秀风格的圆形光点点阵图——手上有一张真实图片，或者只有一段零散的想法和要求。

**不用**：

- 用户要把点阵图继续做成视频/转场动画——那属于后续环节，本 Skill 只出这一张静态图。
- 用户要的是普通马赛克/像素化、方形色块效果，不是圆形光点。

## 输入：两条路径

两条路径都需要用户给出**无人机数量（点数）和输出尺寸与比例**；区别在于画面依据从哪来。

**路径 A（有参考图）**：用户上传一张真实图片 → 按图片转换。

- 需要：真实图片 + 无人机数量 + 尺寸比例。

**路径 B（无参考图）**：用户只给零散的文字想法和要求（主题、物体、氛围、配色偏好等）→ 直接生成。

- 需要：文字想法/要求 + 无人机数量 + 尺寸比例。
- 用户没提到的视觉细节由 Agent 按想法合理补足，但不得违反下面的通用硬规则。

三条输入（画面依据、无人机数量、尺寸比例）都必要，缺哪条就先向用户确认，不要自行假设。

## 通用硬规则（两条路径都适用）

1. **单张图内所有光点直径完全一致**。不允许大小差异、不允许尺寸渐变。画面的明暗层次只能靠光点的颜色和亮度表现，绝不靠改变点的大小。
2. **光点尺寸随无人机架数反比变化**：架数少（如 500）点就大、间距宽、抽象感强；架数多（如 2000、5000）点就小、间距窄、细节更丰富。具体尺寸档位由 Agent 根据用户给的架数灵活确定。
3. **只对画面主体布点**：背景桌面、环境、雾气，以及任何文字、logo、水印位置一律不排光点，保持纯黑。
4. **背景固定纯黑（#000000）**：无渐变、无光晕、无辉光扩散、无星空、无氛围元素，主体之外完全干净，便于后续叠到任意转场画面。
5. **所有光点必须是正圆形**，边缘清晰锐利，不做发光模糊扩散；禁止出现方形马赛克格子。
6. **输出单张静态点阵图**，不在本 Skill 内接视频。

## 输出

一张静态点阵图，满足上面六条硬规则，并且：

- 点的颜色取自画面依据对应位置的色调（路径 A 取原图色调；路径 B 取用户描述里的配色偏好）。
- 整体能辨认出主体轮廓，不是一片均匀噪点。
- 点的总数等于用户指定的无人机数量。

## 执行步骤

1. 判断走哪条路径：用户给了图片走路径 A，只给了文字想法走路径 B。两者都没给就先问用户要。
2. 确认另外两项输入：无人机数量、输出尺寸与比例。缺失就问，不要填默认值。
3. 建立画面依据：路径 A 读取原图的构图、明暗与色调；路径 B 按用户描述确定主体、氛围与配色，未提及的细节自行合理补足。
4. 确定光点尺寸档位：按用户给的架数反比定档——架数少则点大、间距宽，架数多则点小、间距窄。
5. 只在主体上布点，按用户指定的数量排布；点的颜色与亮度随画面依据的明暗变化，全程保持单张图内点径一致。
6. 把点画成正圆形光点，铺在纯黑背景上，不加任何背景氛围元素。
7. 按用户指定的尺寸与比例输出这一张图。
8. 自检后再交付：点数是否等于指定数量、单张图内点径是否完全一致、背景是否纯黑、主体轮廓是否可辨、文字与背景区域是否留黑、有无方形格子或发光模糊。任一项不满足就重做，不要直接交付。

## 约束

- **必须**：单张图内所有光点直径完全一致，明暗只靠颜色和亮度表现。
- **必须**：点径与无人机架数反比变化，档位由 Agent 按架数灵活确定。
- **必须**：只对主体布点，背景、环境、文字、logo、水印位置保持纯黑。
- **必须**：背景纯黑（#000000）；点必须是正圆形；点数严格等于指定数量。
- **必须**：三条输入（画面依据、无人机数量、尺寸比例）都由用户提供，不自行假设。
- **禁止**：在背景上加星空、光晕、渐变、辉光扩散、烟雾等氛围元素。
- **禁止**：用改变点大小的方式表现明暗；禁止方形马赛克格子。
- **禁止**：输出视频或动画，本 Skill 只产出这一张静态图。
- **禁止**：按画面复杂度自动决定点数。
