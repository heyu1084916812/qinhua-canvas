# multi-char-spatial-storyboard

## Skill 定位

- 只负责：利用上帝视角“彩色站位标记图”与“上一帧生成图”的双重图文约束，结合已生成图的实时属性分析（动作、神态、环境坐标），严格遵循180度轴线法则并合理切换全/中/近景，生成空间无穿帮、视觉高度连贯的电影级剧情分镜图及 Prompt。

## 输入

- **剧情脚本**：包含场景描写、角色对话、人物动作及情感张力。

- **场景视觉特征**：风格（如：赛博朋克、古典欧式、日系写实）、时代背景、光影氛围。

- **彩色站位标记图**（核心底图）：用户在 AI 生成的上帝视角底图上用红/黄/蓝等色圈标记的站位及朝向图。

- **色圈角色映射表**：告知每个颜色圈代表的具体角色（如：红圈=主角A，黄圈=反派B）。

- **上帧分镜参考图与属性状态**（链式图文）：上一张已生成的连续分镜图及其分析数据（角色姿态、表情神态、相对坐标）。

## 输入使用

- **严格遵守：**

  - **每帧必连双重输入**：生成**每一张**分镜图片时，必须**无一例外**地同时挂载：（1）彩色标记俯视底图（锁定空间与背景）；（2）上一张生成的第 $N-1$ 帧分镜图（锁定角色外貌、服饰、动作连贯与光影）。

  - **严格轴线原则 (180-Degree Rule)**：在建立镜头关系时，严禁相机越过角色对视建立的视线轴线（Action Axis），保证左右相对位置逻辑不发生颠倒错乱。

  - **景别层级区分**：剧情推进中必须有节奏地交替使用**全景（Establish/Wide）**、**中景（Medium/OTS）与近景/特写（Close-up）**，严禁同种景别机械重复。

- **参考/弹性：**

  - **前景与特殊构图**：灵活运用前景虚化人物（如肩部/手部/侧影）带出同场其他角色，增强空间深度感与镜头对抗感。

## 内部流程和 Knowhow

### 阶段一：生成上帝视角场景底图 (God's-Eye View)

1. 解析剧情场景，提取核心地标参照物（如：长条会议桌、主门、落地窗、沙发区）。

2. 生成纯环境的 **正俯视视角的建筑结构图 (Top-down floorplan / Architectural God's-eye view)**。

3. 要求画面：平视无透视畸变，无任何人物，只有空间与家具，结构清晰且易于标注。

### 阶段二：解析彩色标记图与轴线构建

1. 接收用户上传的“色圈标记图”及“色彩映射表”。

2. **建立 180 度安全轴线**：

   - 识别每个色圈的 $(X, Y)$ 空间坐标及朝向矢量。

   - 连结主要角色视线形成“主体对话轴线”，划定相机放置的安全半圆区（180度安全区），确保后续反打镜头不越轴。

### 阶段三：景别规划与电影级镜头拆解

1. 根据剧情张力拆解分镜，明确区分景别，形成高低起伏的电影节奏：

   - **全景 (Wide / Long Shot)**：用于建立多人空间关系、环境氛围及整体站位。

   - **中景 (Medium Shot / OTS 过肩)**：用于展现角色腰部以上肢体动作、双人互动及带前景的对话。

   - **近景/特写 (Close-up)**：用于呈现面部神态细节、眼神交锋或关键道具微操。

2. 避免单一单人画面，多采用“前景带人”、“双人对拍”、“过肩反打”等构图带出场内其他角色。

### 阶段四：逐帧图像属性深度分析 (Image Property Analysis)

在生成第 $N$ 帧前，系统必须对第 $N-1$ 帧（已生成画面）进行属性提取与状态诊断：

1. **人物动作解析**：分析上一帧角色的肢体姿态（如：站立/坐姿、手势方向、是否身体倾斜）。

2. **神态与情绪解析**：分析角色表情（如：愤怒张嘴、冷笑眯眼、惊恐瞪大眼睛）。

3. **环境绝对位置校验**：确认上一帧中人物与背景参照物（如落地窗、门框）的相对位置是否与俯身底图吻合。

4. **动态演变推演**：根据属性分析结果与剧情下一步发展，推演第 $N$ 帧动作与神态的合理顺接（如：上一帧“震惊起身”，下一帧“双手撑桌前倾”）。

### 阶段五：双重图文约束生图与链式生成 (Dual-Condition Generation)

- **生图条件组合（生成第** $N$ **帧时必须同时满足）**：

  - `Condition 1 (空间底图)`：彩色站位俯视底图 $\\rightarrow$ 强制锁定三维空间透视、背景参照物与 180 度轴线。

  - `Condition 2 (视觉链条)`：第 $N-1$ 张已生成分镜图 $\\rightarrow$ 强制锁定角色脸部、服装、光影连续性及承接上一帧的动作神态。

  - `Text Prompt`：明确指定景别（全/中/近）、前景遮挡元素、主体动作神态演变以及背景参照物。

- **Prompt 标准结构**：\
  `[指定景别 (Wide/Medium/Close-up)] + [前景带出角色/构图] + [主体角色基于上帧顺接的动作与神态] + [空间参照/对应俯视图位置] + [遵循180度轴线的镜头角度] + [电影光影]`

## 输出

- **阶段一输出**：

  - 1张高清“纯场景上帝视角俯视图”（供用户下载并在上面画圈标注）。

- **阶段二及后续链式输出**：

  1. **分镜设计与分析表**：

     - 镜头号、**明确景别（全/中/近）**、参与角色（明确主/前景角色）。

     - **上帧图属性分析摘要**（上一帧动作/神态 $\\rightarrow$ 当前帧连贯顺接说明）。

     - 轴线与相机角度说明（证明未越轴）。

  2. **AI 生图 Prompt 列表**：针对多图参考（色圈俯视图 + 上帧参考图）的参数及英文 Prompt。

  3. **连贯分镜画面组**：景别丰富、轴线严谨、神态与空间位置精准顺接的电影级分镜图。

## 自检

- **双重图文关联检查**：生成当前分镜图时，是否**无一例外**地同时关联了“色圈俯视图”和“第 $N-1$ 帧图”？

- **属性连贯检查**：当前帧角色的动作与表情是否基于对上一帧属性分析的合理延伸，是否存在断层或突变？

- **轴线法则检查**：反打或视角切换时，相机是否越过了 180 度轴线？左右人物的视线与相对位置是否错乱？

- **景别丰富度检查**：分镜组图是否清晰涵盖全景、中景、近景/特写？是否有连续3张以上同景别机械重复？

## Ask User

- **阶段一问询**：“生成的场景俯视图布局是否符合您构想的建筑结构？满意请下载并在上面画圈标注角色站位。”

- **阶段二问询**：若用户上传的标记图未标明朝向，需询问：“请确认各色圈角色此时的对视关系与主朝向，这对于确定 180 度相机轴线至关重要。”

- **冲突问询**：若剧情动作/景别转换与标记站位存在严重逻辑冲突，需询问：“当前剧情要求从全景跳切至近景拉扯，但标记图中两角色距离过远，是否允许调整站位或微调动作细节？”
