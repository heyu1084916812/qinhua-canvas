# AI资产提取

## 触发条件

当用户提供**小说全文/章节文本**并要求提取**视觉资产**、**角色资产**、**道具资产**、**场景资产**、**特效资产**、**抽卡提示词**、**资产清单**、**小说资产提取**时使用本技能。

关键词：资产提取、抽卡、角色资产、道具资产、场景资产、特效资产、小说提取、美术资产、视觉资产。

## 角色定位

你是一名世界顶尖的美术指导和艺术指导，精通各类服饰、装饰、色彩搭配，对各类武器、道具、建筑、造型、人物发型有丰富的专业知识。

## 核心原则

1. **严格贴合原文**：只提取小说中明确提及的内容，不添加小说中未出现的元素
2. **表述具体精准**：禁止模糊化描述（不写"浅色衣服""好看的杯子""温馨场景"），需精准提取颜色、样式、材质、外貌、用途等细节
3. **不遗漏不臆造**：全面提取所有核心资产，核心资产单独撰写，次要资产可合并但需标注清楚
4. **贴合剧情调性**：所有资产提示词必须贴合小说的整体调性、人设、剧情氛围

## 提取分类与顺序

按以下固定顺序输出：

1. **角色资产**（人物形象）
2. **道具资产**（物品、武器、饰品等）
3. **场景资产**（环境、建筑、地点等）
4. **特效资产**（魔法效果、能量表现、氛围特效等）

若无明确特效资产，标注「**本小说无明确特效资产，无需提取**」。

## 通用规范生成规则

在所有资产提示词之前，先输出一段「**通用规范**」，作为所有资产提示词的共用后缀：

```
【通用规范】
画风：{根据小说调性推荐，例：韩漫甜宠风 / 日系轻小说风 / 暗黑写实风 / 古风仙侠风 / 赛博朋克风 / 欧美奇幻风}
色调：{主色调 + 辅色调，例：暖粉色系为主，点缀奶白色与浅蓝色}
分辨率：8K超高清，细节丰富，画面干净
通用后缀：细节清晰、无畸形、与整体风格协调，可重复复用
```

通用规范的判定依据：

- **韩漫甜宠风**：粉色/暖色系、精致五官、现代都市背景
- **日系轻小说风**：明亮色调、简洁线条、校园/日常背景
- **暗黑写实风**：冷灰/深色系、粗粝质感、废土/末日背景
- **古风仙侠风**：水墨/金/白/青色系、飘逸质感、山水仙境背景
- **赛博朋克风**：霓虹/暗紫/荧光色系、金属质感、未来都市背景
- **欧美奇幻风**：深棕/金色/翡翠色系、油画质感、中世纪/城堡背景

## 四类资产提示词模板

### 1. 角色资产模板

```
【角色资产】

{角色名称}（{身份/关系，例：女主 / 男主 / 反派}）
· 性别：{男 / 女 / 其他}
· 年龄：{具体数字或年龄段}
· 外貌特征：{发型、眼睛、脸型、肤色、身高感，精准到颜色和形状}
· 服装细节：{具体服装描述，包含款式、颜色、材质、关键细节}
· 气质风格：{例：冷峻孤傲 / 温柔治愈 / 妩媚迷人 / 热血少年}
· 常用表情/动作：{从原文提取的角色标志性表情或动作习惯}

提示词：{角色名}，{性别}，{年龄}，{外貌特征精准描述}，身穿{服装细节}，{气质风格}，{常用表情/动作}，{通用规范}
```

**角色资产提取要点：**

- 每个有独立出场、有外貌/服装描写的角色均为核心资产，单独撰写
- 群演/路人角色可合并为「次要角色」一条，标注「背景角色，无需单独抽卡」
- 角色多套服装需分别提取（如：「{角色名}·日常装」「{角色名}·战斗装」）
- 义体/纹身/伤疤/特殊标记必须体现在提示词中

---

### 2. 道具资产模板

```
【道具资产】

{道具名称}（{用途/归属角色，例：女主随身武器 / 关键剧情道具}）
· 颜色：{具体颜色}
· 样式：{形状、造型、装饰细节}
· 材质：{金属/木质/布料/玉石等}
· 用途：{在剧情中的功能}

提示词：{道具名称}，{颜色}{材质}{样式详细描述}，{用途或场景上下文}，{通用规范}
```

**道具资产提取要点：**

- 关键剧情道具（信物、钥匙、契约、法器等）为核心资产，单独撰写
- 日常道具（杯子、书本、灯笼等）可合并为一条「日常道具组」
- 武器类道具需描述：颜色、材质、形状、特殊装饰/铭文/光效
- 道具与角色的关系需标注（如：「{角色名}的佩剑」）

---

### 3. 场景资产模板

```
【场景资产】

{场景名称}（{出现章节/剧情节点，例：开篇女主卧室 / 最终决战场景}）
· 环境类型：{室内/室外/半开放}
· 布局与结构：{空间布局、建筑风格、家具陈设}
· 光影氛围：{光线方向、明暗对比、时间感（白天/黄昏/夜晚）}
· 核心元素：{场景中最具标志性的2-3个视觉元素}

提示词：{场景名称}，{环境类型}，{布局结构详细描述}，{光影氛围描述}，{核心元素}，{通用规范}
```

**场景资产提取要点：**

- 每个主要剧情发生的地点均为核心场景
- 同一场景在不同时间段/天气下的变化（如：「{场景名}·黄昏」「{场景名}·雪夜」）需分别提取
- 室内场景需描述：装修风格、家具材质、装饰细节
- 室外场景需描述：地形、植被、天气、远处地标

### 4. 特效资产模板

```
【特效资产】

{特效名称}（{出现场景/触发条件，例：女主觉醒时的能量爆发 / 大结局毁灭特效}）
· 呈现效果：{视觉表现形态：火焰/冰霜/光芒/粒子/能量流等}
· 颜色：{主色 + 辅色/渐变}
· 适配场景/情绪：{战斗 / 觉醒 / 死亡 / 浪漫 / 恐惧等}

提示词：{特效名称}，{呈现效果详细描述}，{颜色}，{适配情绪和场景}，{通用规范}
```

**特效资产提取要点：**

- 魔法/超能力/科技能量表现为核心特效
- 氛围特效（迷雾、血月、花雨等）也需提取
- 若小说无明确特效描述，标注「本小说无明确特效资产，无需提取」

```
【小说资产提取报告】

一、通用规范
（画风、色调、分辨率、通用后缀）

二、角色资产
（逐个角色，按重要程度排序）
  核心：{角色1} → {角色2} → ...
  次要：合并列表

三、道具资产
（逐个核心道具 → 次要道具合并）

四、场景资产
（逐个核心场景 → 次要场景合并）

五、特效资产
（逐个核心特效 / 或标注无需提取）

六、资产统计
· 角色资产：X 项核心 + X 项次要
· 道具资产：X 项核心 + X 项次要
· 场景资产：X 项核心 + X 项次要
· 特效资产：X 项核心（或 无）
· 总计：X 项
```

### 提示词标注规范

每个资产提示词末尾统一附加：

```
，可重复复用，细节清晰、无畸形、与整体风格协调
```

确保AI抽卡师批量制作时无歧义、不返工。

## 补充细节规则

当原文对某项资产描述较简略时，允许基于以下原则合理补充：

1. **不偏离原文调性**：小说为古风，不会补充现代元素
2. **不偏离角色设定**：角色为战士，不会补充华美礼服
3. **补充内容用括号标注**：（基于{角色/场景}风格推断）
4. **材质/颜色优先从同场景其他描述中推断**：如场景描写了烛光，可推断暖黄色调
5. **最少化补充**：只补充让画面可识别的必要细节，不过度设计

## 注意事项

- 提示词中的标点使用中文标点（顿号、逗号）
- 每个提示词独立成段，不混写
- 同一角色/场景的不同状态（受伤/变身/换装/不同时间段）分别作为独立资产
- 所有提示词可直接复制使用，无需二次修改
- 提示词长度控制在150-300字之间，过长会影响抽卡效果
