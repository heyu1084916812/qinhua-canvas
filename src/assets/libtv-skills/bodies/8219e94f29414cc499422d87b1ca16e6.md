# 赛博朋克CG动漫短剧创作

## Skill 定位

- 只负责：将用户的一句话创意/角色/主题，转化为一个完整的赛博朋克CG动漫风格单集短剧创作方案（脚本+资产锚点+分镜+prompt+剪辑建议）。
- 仅支持单集，剧本正文控制在千字以内；不支持多集拆分、长篇连续剧。
- 不负责运行代码/脚本，不指定具体文件写入路径（由 Agent 自行编排）。

## 输入

- 需要什么：
  - 核心创意（故事/角色/主题/情绪关键词）
  - 用途（剧情短片、角色预告、概念片等）
  - 时长（默认60秒左右）、画幅（默认9:16）
  - 主角信息（身份、性格、外观）
  - 风格偏好（更暗黑/更燃/更悬疑等，可选）

## 输入使用

- 严格遵守：用户明确指定的主题、主角设定、核心冲突、禁止元素、时长与画幅。
- 仅作参考：用户给出的风格词、参考作品（只借氛围与节奏，不复刻具体角色/剧情/台词）。
- 缺失信息按赛博朋克CG短剧常见规律自动合理补全，不强行反复确认。

## 内部流程和 Knowhow

- **故事脚本编写**：采用“强钩子开场→交代危机→冲突升级→情绪爆点→结尾钩子”的单集结构；台词短促有信息量，避免长段解释；正文不超千字。
- **资产锚点创作**：为主角、场景、关键道具建立“名称+外观+色彩+标志物+情绪气质”的固定描述，保证多镜头、多张图之间视觉一致，不随镜头漂移。
- **分镜创作**：每个镜头标明时长、景别、运镜、画面内容、台词/音效、情绪目的；前5秒必须有强画面或强台词，60秒内建议2\~4个核心场景。
- **prompt guide**：图像prompt需含主体、动作、场景、赛博朋克CG动漫风格、光影（霓虹/雨夜）、材质、色彩、镜头信息；视频prompt需强调动作变化、镜头运动与环境动态，避免只写静态画面；可附负面提示词（如变形、风格漂移、画面故障）保证质量与一致性。
- **视频剪辑**：给出节奏（强开场、快切危机段、慢速情绪段、反转停顿）、音乐/音效方向（电子/工业/警报/心跳）、字幕与转场风格（全息UI、故障转场、霓虹光扫）建议。

## 输出

- 产出什么：
  - 项目概念（名称、一句话故事、看点、结尾钩子）
  - 角色/场景/道具资产锚点
  - 单集剧本（千字以内）
  - 分镜表（镜头号、时长、景别、运镜、画面、台词、prompt）
  - 图像与视频生成prompt（含负面提示词）
  - 剪辑建议（节奏、音乐、字幕、转场）

## 自检

- 输出前检查什么：
  - 是否为单集方案，未做多集拆分；剧本是否控制在千字以内。
  - 是否有清晰的开场钩子、核心冲突、情绪爆点与结尾记忆点。
  - 角色/场景/道具资产锚点是否稳定、可支持多镜头一致生成。
  - 分镜是否含景别、运镜与节奏变化；图像/视频prompt是否要素齐全（主体、动作、场景、风格、光影、色彩、镜头/运动）。
  - 是否避免直接复刻已有作品的具体角色、剧情、台词。
  - 是否未指定Agent具体写入文件路径，未涉及代码/脚本运行。
  - 内容是否精炼，未堆砌冗长设定。

## Ask User

- 什么情况问用户：
  - 完全没有提供故事/角色/主题方向时。
  - 用途不明确（剧情片、角色预告、品牌概念片等）且明显影响产出方向时。
  - 用户设定之间存在明显冲突，需确认取舍时。
  - 用户要求多集或超长剧本时，需提示当前仅支持单集、千字以内，并询问是否先做第一集。
  - 用户内容涉及不适合公开传播的元素时，需引导改为更安全、克制的表达方式。
