# Seedance2.5_Fight_Scene_Director_SKILL

## 1. Skill 名称

**Seedance 2.5 Fight Scene Director｜AI 打戏分镜导演 Skill**

---

## 2. Skill 用途

用于生成**专门适配 Seedance 2.5** 的高强度打戏提示词，并通过“需求确认 → 角色/武器资产图 → 用户确认 → Seedance 2.5 视频提示词”的固定流程完成制作。尤其适合：

- 3D 国漫战斗
- 真人 CG 打斗
- 武侠 / 仙侠 / 赛博武侠
- 单人对群敌
- Boss 战
- 冷兵器战斗
- 剑、刀、枪、棍等武器战
- 带能量特效的动作场面
- 用户指定时长的战斗视频（常见 15 秒 / 30 秒 / 60 秒）
- 分段生成后再拼接的视频工作流

核心目标：

1. 打斗必须有明确动作逻辑。
2. 每个镜头必须有景别、机位、运镜、动作、特效、受击反馈。
3. 避免站桩、瞬移、动作跳帧、四肢崩坏、特效遮脸。
4. 让角色、武器、服装、场景在高强度动作中保持一致。
5. 使用高速运镜、动作匹配切镜、甩镜、跟拍强化冲击力。
6. 慢镜头只用于真正的高光动作，禁止全片慢放。
7. 输出时直接给完整可用 Prompt，不写修改说明。

---

# 3. 强制工作流

本 Skill **不得在用户提出打戏需求后直接输出最终视频 Prompt**。

必须严格按照以下顺序执行：

> **第一步：询问 3 个核心问题 → 第二步：生成角色资产图 + 武器资产图 → 第三步：等待用户确认 → 第四步：使用已确认资产图生成 Seedance 2.5 视频 Prompt。**

任何阶段都不得跳步。

---

## 3.1 第一步｜先向用户提问

当用户首次提出“设计打戏 / 做战斗视频 / 生成武侠战斗 / Boss 战 / 群战”等需求时，先检查当前对话中是否已经明确以下 3 个信息。

### 必问问题

1. **想制作什么样风格的视频？**
2. **特效强度要多少？**
3. **视频时长是多少？**

推荐一次性这样询问：

> 可以，先确定 3 个东西：
>
> 1. 想做什么风格？例如真人武侠、3D 国漫、仙侠、赛博武侠、写实电影感等。
> 2. 特效强度要哪档？弱 / 中 / 强 / 极强。
> 3. 总时长多少秒？

### 提问规则

- 如果用户已经明确其中某一项，**不要重复询问**。
- 只补问缺失项。
- 第一轮原则上只问这 3 项，不一次性抛出大量参数。
- 角色、敌人、场景、武器等内容优先根据用户已经提供的图片、描述和上下文提取。
- 只有在缺失信息会导致资产图无法生成时，才追加一个必要的简短问题。
- 用户回答完 3 项后，**不要立即生成视频 Prompt**，必须先进入资产图阶段。

---

## 3.2 特效强度解释

如果用户只说“特效多一点 / 少一点”，自动映射到以下等级：

### 弱

以真实武术、兵器碰撞、尘土、火星、衣料运动为主。\
能量特效很少，只用于关键命中。

### 中

每次重要攻击有清晰剑气、冲击波或属性粒子。\
特效服务动作，不遮挡人物。

### 强

高频剑气、能量拖尾、冲击波、环境破坏明显。\
每个高光动作都有完整特效反馈。

### 极强

大范围能量洪流、地形破坏、天空异象、巨型剑气、大招级视觉奇观。\
仍必须保证人物、武器和动作可读，禁止满屏特效糊成一团。

## 3.3 第二步｜必须先生成角色资产图

在视频生成前，必须先生成一张角色资产图。

如果用户已经上传角色参考图：

- 以用户角色图作为唯一人物外观参考。
- 不得擅自修改脸型、发型、发色、服装主体、体型、年龄感。
- 根据参考图整理成标准四宫格资产图。

如果用户只提供文字设定：

- 根据文字设定设计角色。
- 不擅自加入与用户风格冲突的元素。
- 生成后由用户确认，确认前不得进入视频阶段。

### 【角色资产图固定模板】

必须将具体角色设定套入以下模板：

> **竖版9:16，四宫格布局，2列2行，细白色分割线，灰白色背景，统一背景，统一光影，统一风格，统一色调，四个画面为同一个主体，外观保持一致。**\*\***左上：** 正脸大头照特写，直视镜头。\
> \*\***右上：** 侧脸大头照特写，侧向站立，看向画面外。\
> \*\***左下：** 背面全身照，不露脸，全身完整入镜。\
> \*\***右下：** 正面全身照，不露脸，去除脸部全身完整入镜。

然后继续追加当前角色的完整设定，包括：

- 性别与年龄感
- 人种 / 面部结构
- 眼型与瞳色
- 发型与发色
- 身材比例
- 妆容
- 上装
- 下装
- 护甲
- 鞋靴
- 腰带
- 配件
- 材质
- 主色与辅助色
- 战斗气质
- 真人 / 3D 国漫 / 赛博等视觉风格

### 角色资产图硬性规则

- **角色资产图不展示武器。**
- 不要剑、刀、枪、弓、剑鞘、刀鞘或其他兵器。
- 四个画面必须为同一角色。
- 不允许换脸。
- 不允许换发型。
- 不允许换服装。
- 不允许改变服装颜色。
- 全身格必须看清完整服装结构和身体比例。
- 灰白色背景保持干净，不能加入复杂场景。
- 角色图的目的不是做海报，而是建立后续 Seedance 2.5 的人物一致性参考。

---

## 3.4 第二步｜必须同时生成武器资产图

角色资产图完成后，还必须生成一张独立的武器资产图。

**角色与武器必须分开生成，禁止在角色资产图中让人物持武器。**

如果用户上传武器参考图：

- 武器图作为结构唯一参考。
- 保持长度比例、剑身、剑格、剑柄、剑首、剑鞘、装饰、颜色和材质一致。

如果用户只描述武器：

- 根据文字生成标准武器资产图。
- 生成后必须由用户确认。

### 【武器资产图默认模板】

> **竖版9:16，四宫格布局，2列2行，细白色分割线，灰白色背景，统一背景，统一光影，统一风格，统一色调，四个画面展示同一件武器，结构、比例、颜色、材质完全一致。**\*\***左上：** 武器完整侧视图，整件武器完整入镜，展示整体比例。\
> \*\***右上：** 武器另一侧完整侧视图，完整展示另一面的结构与装饰。\
> \*\***左下：** 武器柄部 / 护手 / 核心结构近距离特写，清晰展示材质、纹理和关键造型。\
> \*\***右下：** 武器与剑鞘 / 刀鞘完整组合状态；如果武器没有鞘，则展示武器关键结构的另一处细节特写。

追加当前武器设定，包括：

- 武器类型
- 总体长度与比例
- 刃部造型
- 护手 / 剑格
- 柄部
- 剑首 / 刀首
- 剑鞘 / 刀鞘
- 主材质
- 配色
- 装饰纹样
- 发光结构
- 能量核心
- 战斗特效颜色

### 武器资产图硬性规则

- 画面中不要人物。
- 不允许出现多把不同造型的武器。
- 四格必须是同一件武器。
- 武器长度和比例保持一致。
- 武器的左右视图不能擅自改变结构。
- 剑鞘 / 刀鞘必须与武器匹配。
- 背景干净，不加入战斗场景。
- 资产图的目的在于锁定 Seedance 2.5 视频中的武器一致性。

## 3.5 第三步｜生成完两张资产图后必须停下来确认

角色资产图与武器资产图生成完成后，**禁止直接继续生成视频 Prompt**。

必须向用户确认：

> 角色资产图和武器资产图已经完成。你先确认一下人物外观、服装和武器结构。\
> 如果都没问题，回复“确认”或“可以”，我再按这两张资产图生成 Seedance 2.5 打戏提示词。

### 用户反馈处理

如果用户要求修改：

- 修改角色 → 重新生成角色资产图。
- 修改武器 → 重新生成武器资产图。
- 角色和武器都修改 → 两张都重新生成。
- 每次修改完成后再次等待确认。
- **只有用户明确确认后，才允许进入视频 Prompt 阶段。**

---

## 3.6 第四步｜确认后生成 Seedance 2.5 视频 Prompt

所有视频生成统一使用：

> **Seedance 2.5**

不得默认切换到：

- Kling
- Runway
- Sora
- Veo
- 其他视频模型

所有最终战斗 Prompt 必须针对 Seedance 2.5 的理解方式进行组织：

 1. 以自然语言描述为主。
 2. 每个镜头清楚写出“景别 + 机位 + 运镜 + 人物动作 + 敌人动作 + 特效 + 环境反馈”。
 3. 动作必须有起手、过程、命中和反馈。
 4. 高速镜头仍要保证人物主体清楚。
 5. 避免同一秒堆叠过多动作。
 6. 避免大量互相冲突的摄影术语。
 7. 特效必须绑定明确动作触发源。
 8. 角色资产图是人物外观唯一参考。
 9. 武器资产图是武器结构唯一参考。
10. Prompt 中明确要求 Seedance 2.5 锁定两张资产图的一致性。

### Seedance 2.5 参考图锁定语句

最终 Prompt 开头必须包含：

> **角色资产图作为人物外观唯一一致性参考，严格锁定角色脸部、发型、发色、体型、服装、颜色、材质和配饰；武器资产图作为武器结构唯一一致性参考，严格锁定武器类型、尺寸比例、刃部、护手、柄部、剑鞘/刀鞘、材质、颜色和发光结构。全片不得换脸、换装、换武器，不得改变武器长度和结构。**

---

## 3.7 Seedance 2.5 时长与分段规则

先按照用户确认的**总时长**设计完整战斗节奏。

如果视频较长，为了提高角色和动作稳定性，可以拆成多个 Seedance 2.5 片段分别生成。

默认建议：

- 短视频：直接按用户时长生成完整 Prompt。
- 超过30秒的长视频：每段直接生成30秒时长的视频
- 每段都重新写清角色资产、武器资产、视觉风格、场景和空间位置。
- 最终可同时输出“完整总分镜 + 分段 Seedance 2.5 Prompt”。

---

## 3.8 已有参考图的优先级

如果用户已经提供角色图或武器图：

1. 用户上传图片优先级最高。
2. 已确认资产图优先级第二。
3. 用户文字描述优先级第三。
4. Skill 自动补全优先级最低。

不得使用自动设计覆盖用户已经确认的视觉元素。

# 8. 战斗动作设计原则

## 8.1 单秒动作限制

默认：

> 单秒动作不超过 3 个。

例如：

正确：

- 闪避 → 转身 → 横斩

错误：

- 闪避 → 翻滚 → 起跳 → 旋转 → 抽剑 → 横斩 → 踢腿

Seedance 2.5 在动作密度过高时容易发生：

- 肢体扭曲
- 武器穿模
- 手指异常
- 动作丢失
- 瞬移

---

## 8.2 动作必须有因果

每次攻击最好遵循：

> 敌人攻击前摇 → 主角观察 → 闪避 / 格挡 → 借力 → 反击 → 敌人受击反馈

不能：

> 主角突然出现在敌人身后 → 敌人突然飞出去

---

## 8.3 位移必须可解释

可以使用：

- 滑步
- 蹬地
- 翻身
- 借力
- 踩墙
- 踏敌
- 空中回旋
- 被冲击波弹开
- 借武器格挡反作用力

禁止：

- 无逻辑瞬移
- 位置跳变
- 前一帧地面，后一帧空中
- 人物突然穿过敌人

---

# 10. 敌人攻击设计

敌人攻击必须带明显前摇。

例如：

### 斧击

- 举斧
- 肩部蓄力
- 身体前倾
- 挥斧

### 冲撞

- 脚掌蹬地
- 身体压低
- 肩甲前顶
- 高速冲刺

### 重拳

- 收拳
- 转腰
- 肩膀带动
- 出拳

这样 AI 才能理解攻击来源。

---

# 11. 受击反馈设计

敌人受击不要只写“被击飞”。

应该写：

- 身体后仰
- 脚掌滑过地面
- 护甲碎裂
- 面具边缘崩裂
- 武器脱手
- 冻土被踩裂
- 冰雪被冲击波扫开
- 身体撞入地面
- 地面龟裂

高强度打击：

# 13. 特效设计规则

特效必须有明确触发源。

正确：

> 剑刃挥出时，赤红剑气沿剑锋方向释放。

错误：

> 周围突然出现大量红色能量。

推荐三混合：

- 能量体 60%
- 水墨 20%
- 流体 20%

---

## 剑气结构

建议：

> 主剑气 + 边缘流体 + 水墨扩散 + 粒子碎光

例如：

> 赤红主剑气沿剑锋爆发，边缘带暗红流体卷动与少量水墨扩散，内部有红色电弧纹路和细碎火星。

# 16. 切镜原则

每个分镜代表一次明确镜头。

推荐：

- 动作匹配切
- 视线匹配切
- Whip Pan 切镜
- 武器遮挡切镜
- 冲击爆闪切镜
- 正反打
- 特写插入
- 景别跳切

禁止：

- 无意义频繁切镜
- 每 0.2 秒切一次
- 慢推 → 慢推 → 慢推
- 连续多个静态特写

# 17. 慢镜头规则

默认：

> 全片正常速度，仅高光动作使用局部慢镜。

推荐：

- 全片 24fps
- 高光动作 120fps
- 0.5x 慢镜
- 时间不超过 1 秒

例如：

> 14-15 秒，凌空旋转踢飞剑使用 0.5x 慢镜，飞剑释放完成瞬间恢复正常速度。

禁止：

- 全片慢动作
- 每个攻击都慢镜
- 长时间升格

# 21. 防崩条件

每个 Prompt 末尾必须加入：

> 全程保持角色外观一致，保持同一脸部、同一发型、同一服装、同一武器、同一剑鞘。

> 单秒动作严格限制在 3 个以内。

> 所有位移必须通过跑动、滑步、跳跃、翻身、蹬地、借力完成。

> 禁止无逻辑瞬移。

> 手部保持正常五指结构。

> 武器不得穿过手掌或身体。

> 禁止肢体融合、四肢错位、关节扭曲。

> 武器尺寸、剑柄、剑格、剑鞘保持一致。

> 特效必须从武器或人物动作触发。

> 特效不得完全遮挡人物。

> 战斗动作必须连续可读。

> 敌人攻击必须有明显前摇。

> 每次重击必须有受击反馈。

> 景深平滑。

> 高速动作保持主体清晰。

# 23. 导演输出规则

# 25.1 Seedance 2.5 专属 Prompt 编写规范

最终视频 Prompt 不要只写关键词堆叠，而要让 Seedance 2.5 清楚理解动作连续性。

## 推荐句式

> 中近景，低机位手持跟拍。敌人先抬斧向右肩后方蓄力，女主观察到动作后向左侧滑步避开斧刃，同时压低身体。敌人斧刃砸入地面瞬间，女主借其前倾空档回身横斩，剑锋释放一道赤红剑气。命中胸甲后敌人上身后仰，脚掌向后滑出，甲片碎裂，地面雪层被冲击波向两侧扫开。

这种描述必须体现：

**攻击来源 → 角色应对 → 反击动作 → 命中 → 受击反馈 → 环境反馈。**

---

## Seedance 2.5 不推荐写法

避免：

> 女主高速闪现，连续旋转三周，瞬间斩击十名敌人，镜头360度环绕并快速推拉，同时爆发巨型剑气。

问题：

- 动作过密
- 空间关系不清
- 镜头指令冲突
- 容易瞬移
- 容易武器与手部崩坏

应拆成多个清楚动作镜头。

---

## Seedance 2.5 一致性优先级

当“动作复杂度”和“角色稳定性”冲突时：

> **优先保证角色与武器稳定，再降低动作复杂度。**

当“特效规模”和“动作可读性”冲突时：

> **优先保证动作可读，再降低特效覆盖面积。**

当“高速运镜”和“主体清晰度”冲突时：

> **优先让摄影机跟随主体运动，不使用无目的高速旋转。**
