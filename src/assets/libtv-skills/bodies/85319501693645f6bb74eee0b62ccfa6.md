## name: Cinematic Prompting v2 description: Cinematic Prompting 是一种为 AI 视频生成模型（如 Runway Gen-3、Kling、Pika、Sora）编写结构化提示词的工作范式 version: 1.0.0 author: Bruce

## 

Skill: Cinematic Prompting v2 这个 Skill 是什么 Cinematic Prompting 是一种为 AI 视频生成模型（如 Runway Gen-3、Kling、Pika、Sora）编写结构化提示词的工作范式。

核心问题：视频生成与图像生成最大的区别在于时间维度和摄影维度——图像模型只需要描述静态画面，而视频模型需要理解镜头语言、时间节奏、空间纵深和运动逻辑。当前 AI 视频工具在「理解拍摄意图」上仍然很弱，如果你只说「一个人走在街上」，它会随意决定用什么景别、什么角度、什么运镜方式，结果往往与你预想的相去甚远。

v2 核心改进：增加了「起始画面状态」字段和「关键帧时间锚点」机制，解决 AI 默认从「动作结果」开始而非「动作起点」开始的问题。

这套 Skill 的核心价值：把视频拆解为可描述的原子要素——景别、角度、运镜、节奏、动作、穿模防护。通过结构化提示词，把你在脑海中的导演意图完整翻译给 AI，让输出结果从「随机生成」变成「可控生产」。

使用场景 制作产品概念视频或功能演示短片

快速验证镜头语言的可行性，用于分镜脚本迭代

生成用于情绪板或 pitch 的高保真视频素材

将静态 UI mock 或品牌视觉延展为动态视觉素材

探索镜头组合方案，辅助确定最终拍摄方案

Agent 工作流程 当用户调用此 Skill 时，按以下步骤推进，每步完成后等待用户确认，不要跳步。

第一步：明确视频类型和风格定位 首先需要理解用户要生成的视频属于什么类型，不同类型的镜头语言差异巨大。逐项确认以下内容：

视频类型（单选或组合）：

产品展示类（App 录屏 + 界面演示）

实拍类（真人/真实环境）

3D 动画类（虚拟场景/角色）

2D 插画类（扁平/矢量动态）

混合类（实拍 + 特效）

抽象/氛围类（无具体对象，以光影/材质为主）

风格定位：

写实 / 超写实 / 风格化（如赛博朋克、新中式、复古）

色调描述：暖/冷/高饱和/低饱和/单色/双色调

光线氛围：自然光/硬光/柔光/背光/侧光/彩色霓虹

参考标准（可选但强烈推荐）：

类似某部电影/广告的视觉语言（如「类似《Her》的暖色未来感」「类似 Apple 产品广告的极简白背景」）

确认模板：

我理解的视频类型是 \[xxx\]，风格偏向 \[xxx\]，色调以 \[xxx\] 为主，整体感觉类似 \[参考片\]。请确认是否正确。

第二步：逐个确认镜头要素 这是提示词质量的核心。以下每一项都需要用户明确，不能假设默认值。

2.1 景别 明确告知 AI 使用哪个景别，不要留白。可选范围：

景别 英文 使用场景 特大特写 Extreme Close-Up (ECU) 眼睛瞳孔、产品logo纹理、水滴表面 大特写 Big Close-Up (BCU) 人脸局部（嘴唇、手指）、产品按钮/接口 中特写 Medium Close-Up (MCU) 面部到胸部，适合传递情绪 小特写 Close-Up (CU) 面部到锁骨，产品正面全部 近镜 Mid Shot (MS) 人物腰部以上，对话/动作演示 中镜 Medium Full Shot (MFS) 人物膝盖以上，兼顾动作和背景 全景 Full Shot (FS) 人物全身，展示完整动作 远景 Long Shot (LS) 人物与环境关系，位置交代 大远景 Extreme Long Shot (ELS) 环境为主，人物很小 询问格式：

这个镜头希望用哪个景别？

A. 特写系列（表达细节/情绪）

B. 中景系列（平衡人物与环境）

C. 全景/远景系列（交代空间/氛围）

D. 具体景别名（请直接告知）

2.2 镜头角度 角度决定了观众与内容的权力关系/情感距离：

角度 效果 示例 平视 中性、平等、客观 新闻采访、产品展示 俯视 弱势感、被观察、全貌 俯拍桌面物品、俯瞰城市 仰视 压迫感、力量感、宏伟 拍摄高楼、演讲者 第一人称（POV） 沉浸、代入感 玩家视角、主观镜头 越肩 对话张力、旁观介入 审讯场景、双人对话 荷兰角（倾斜） 不安、紧张、失衡 悬疑/惊悚片 上帝视角（俯拍正下） 平面化、抽象、地图感 食物摆拍、桌面整理 询问格式：

镜头角度要求是什么？平视（最常见），还是需要特定角度？

2.3 运镜方式（Camera Motion） 明确镜头本身是否运动，以及如何运动：

运镜 效果 说明 固定镜头（Static） 稳定、客观、平静 镜头完全不移动 推轨（Dolly） 进入感、接近感 镜头物理向被摄体移动 拉远（Dolly Out） 离开感、揭示更大环境 从特写拉到全景 横移（Truck/Pan） 跟随运动、扫视空间 左右移动 升降（Crane/Pedestal） 上升/下降、高度变化 揭示垂直空间 手持抖动（Handheld） 主观、紧张、纪实感 类似新闻/纪录片 希区柯克变焦（Dolly Zoom） 眩晕、时空扭曲 推轨同时反向变焦 呼吸感（Subtle Breathe） 轻微浮动、有机感 模拟手持但极轻微 询问格式：

运镜方式：固定镜头，还是某种运动镜头？是否需要特别效果（如手持抖动）？

2.4 时间节奏（含起始画面状态） 这是视频提示词中最容易被忽略但最重要的部分。AI 默认会「直接显示动作结果」，你需要主动控制第 0 帧的姿态。

必须明确的结构：

起始画面状态（新增 - 关键字段）：

描述第 0 帧时主体正在做什么、处于什么姿态

示例：「男生站在房门口，女生双脚着地站在男生面前，男生双手已张开做公主抱的准备姿势，女生尚未离地」

反面示例：「男生公主抱女生」（这是结果，不是起点）

开篇静置时长：是否有一段纯静态的「定场时间」？

例如：「前 2 秒镜头完全静止，无任何运镜」

动作序列（带时间锚点）：

强制使用「第 X 秒开始做 Y，第 Z 秒完成」格式

示例：「第 0-1 秒：男生弯腰将女生抱起；第 1.5 秒：抱起完成」

节奏速度：

慢速（Slow）/ 中速（Medium）/ 快速（Fast）

询问格式：

节奏上有什么要求？

起始画面状态：第 0 帧时主体在做什么？（必须描述「准备做」或「刚开始做」，不能是「已经在做」）

开篇是否需要静置几秒？

请按时间顺序描述动作序列（第X秒开始→第Y秒完成）

整体速度：慢/中/快？

2.5 视角/视点（Point of View） 这是最容易混淆但极为重要的维度——「镜头是谁的眼睛？」

视角类型 说明 示例 客观视角 观众是旁观者，观察角色 大多数影视镜头 主观视角（POV of Character A） 镜头是某个角色的视线 看到角色 A 看到的画面 角色代入视角 镜头模拟角色位置但非视线 驾驶位看到方向盘和路 主体跟随视角 镜头始终跟随某个移动主体 跟拍运动员 固定机位视角 镜头固定在某个物理位置 监控摄像头视角 自由飞翔视角 无明确主体，自由移动 无人机俯瞰 询问格式：

这支视频是站在谁的视角？

A. 客观视角（观众是旁观者）

B. 某个角色的视线（POV）

C. 固定机位（比如桌子一角）

D. 主体跟随

E. 其他（请描述）

第三步：描述画面内容和动作 在镜头语言确认之后，才进入传统的画面描述。这一步注意以下要点：

3.1 关键帧列表（新增 - 核心机制） 要求用户或 Agent 将动作拆解为关键帧，每个关键帧标注时间点和状态：

markdown

- 关键帧1（第0秒）：\[描述第0帧的精确姿态\]
- 关键帧2（第X秒）：\[描述第一个动作完成时的状态\]
- 关键帧3（第Y秒）：\[描述第二个动作完成时的状态\]
- ... 示例（公主抱案例）：

关键帧1（第0秒）：两人面对面站立，男生双臂呈环抱预备姿态，女生双脚着地

关键帧2（第1秒）：正在抱起过程中，女生身体倾斜、双脚离地

关键帧3（第1.5秒）：公主抱完成，两人稳定，开始移动

关键帧4（第5秒）：走到床边

关键帧5（第7秒）：放下完成，女生躺在床上

3.2 主体描述 是什么：具体名称（「一个戴黑色棒球帽的男性」比「一个人」好）

位置：在画面中的空间位置（「画面左三分之一处」）

与镜头的关系：面向镜头/侧向/背对/四分之三侧面

支持占位符：可使用 @男生 @女生 @主体 等占位符，使用时替换为实际素材标识

3.3 动作描述 用动词精确描述：不是「在动」，而是「右手食指轻敲桌面」

强制使用时间锚点：「第 0-1 秒：他缓缓抬头」

避免复杂多阶段动作（AI 容易穿模），拆分为多个镜头更好

3.4 环境与道具 场景简述（室内/室外、具体空间：厨房/街道/地铁车厢）

关键道具（只写画面中会被注意到的物品）

氛围细节（光的方向、空气中的灰尘/雨雾/光线束）

3.5 穿模防护（Critical！） AI 视频对以下内容容易产生穿模/变形/不自然，需要在提示词中显式约束：

高频穿模场景：

手部动作（手指交叉、握持物品、手势变换）

面部表情（口型过度夸张、眼球运动不自然）

长头发（飘动诡异、穿模穿身体）

多肢体接触（握手、拥抱、触碰）

衣物与身体交界处（衣领/袖口/腰带）

透明/半透明材质（玻璃、液体、塑料膜）

防护写法示例：

「双手握持咖啡杯，手指自然弯曲，关节可见，五根手指分开明显，无融合或变形」

「长发在肩后自然垂落，飘动幅度小于 10 度，始终保持与身体分离」

通用防护语（可直接复用）：

「所有肢体动作要求：关节可辨，手指脚趾分开明显，无肢体融合或穿插，衣物与皮肤交界线清晰，变形幅度低于正常物理可能。避免任何超现实变形或液体化效果。」

## 使用说明

- 建议时长：\[X 秒\]
- 尺寸建议：16:9 / 9:16 / 1:1
- 注意事项：\[如需要多次抽帧、占位符替换说明等\] 好提示词的标准（v2 更新版）

1. 镜头要素一个都不能少 不合格：「拍摄一个咖啡杯」 合格：「小特写，平视，固定镜头，第0秒时杯子静止放在木桌上，前1秒静置，第2秒开始极缓慢推轨，客观视角」

2. 起始画面状态必须明确（v2 新增核心要求） 不合格：「男生公主抱女生」（这是结果） 合格：「第0秒时男生站在房门口，女生双脚着地站在男生面前，男生双手已张开做公主抱的准备姿势，女生尚未离地」

3. 先定节奏和起始状态，再定动作 AI 默认会「直接显示动作结果」，必须显式说明「第0秒的状态」和「第X秒开始变化」。

4. 穿模防护要具体 「不要变形」是无效的。「手指分开明显」「关节位置清晰」「衣物与皮肤交界线明确」才有效。

5. 视角要明确标注 如果不说视角，AI 会随机选取。明确写「客观视角」或「POV of 角色名」。

6. 复杂动作拆解为多个关键帧 一个提示词里写「他走过来、坐下、拿起杯子喝了一口、放下、转头看窗外」= 高概率穿模。拆解为 3-5 个关键帧分别描述，每个关键帧标注时间点。

7. 不要描述动效或时间维度外的内容 视频模型需要时间锚点，但不需要「淡入」「闪现」这类转场描述（除非模型明确支持）。
