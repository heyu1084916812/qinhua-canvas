# 微表情表演视频生成

## 这个 Skill 做什么

根据用户提供的**角色图片**和**情绪描述**（一句短语、台词或动作清单），设计精细的微表情表演提示词，用户确认或调整后，生成一段表演视频。

适合的情绪类型：心动、爱而不得、强颜欢笑、尬笑手足无措、含泪强撑、犹豫破防、沉默愤怒、释然离开等复杂内心戏。

**不适用于**：完整编剧、面部绑定、口型精确编辑、多人合成。

---

## 工作流程

### 第一步：接收输入

用户需提供：

1. **角色图片**（人物正面或半身照，面部清晰）
2. **情绪描述**，可以是：
   - 一句情绪短语（如"爱而不得"、"心动瞬间"）
   - 具体动作清单（如"嘴角上扬、眼神躲闪、发出干笑、最后抿嘴点头"）
   - 台词 + 场景（如"她听到消息后强忍眼泪，说：没事的，我很好"）

如果用户只提供图片没有情绪描述，先分析角色气质，给出 4-5 个情绪方向供选择。

### 第二步：设计微表情提示词

根据角色气质和情绪方向，按以下维度组织提示词：

维度内容**镜头设置**景别（近景/中景）、机位（固定/手持）、视角（平视/下压）**眼神**视线方向、聚焦/失焦、眼睑开合、眼眶状态（泛红/蓄泪）**眉眼**眉头聚拢/松开、睫毛颤动、眼皮下垂**口周**嘴唇开合、嘴角弧度、抿嘴、干笑音调**手部/身体**手指动作、握拳/松开、摸手串/后颈、抱紧物品**节奏**各动作的时间节点（0-2秒/2-4秒/4-6秒）**光线**冷白光/暖金侧光/户外自然光，背景虚化程度**台词**（可选）极短台词，带哭腔/小声/沙哑等声音质感描述

**锚点（固定不变的工艺原则）**：

- 情绪全部内收，不崩不哭，细节泄露比直接表达更有张力
- 每个动作都要有"为什么这样做"的内心逻辑支撑
- 时间节点要具体到秒，让模型有节奏感
- 光线描述要配合情绪色调（克制用冷光，心动用暖光）

### 第三步：用户确认与调整

展示完整提示词后，询问用户是否满意，常见调整方向：

- 加强某个细节（如"让眼眶更红"、"加一个手部小动作"）
- 加入台词
- 调整情绪强度（更克制 / 更破防）
- 修改镜头或光线

**用户确认后**，再调用视频生成工具。

### 第四步：生成视频

**模型**：Minimax H3\
**参数**：

- 比例：9:16（竖版）
- 时长：6秒
- 分辨率：720p
- tag：final_product

**Prompt 结构**：

```
{{角色图片节点}} [景别+机位+光线描述]。画面中是[角色外貌简述]。
[第一段·情绪名·0-Xs]：[具体微表情动作描述]
[第二段·情绪名·X-Ys]：[具体微表情动作描述]
[第三段·情绪名·Y-6s]：[具体微表情动作描述]
全程[有/无]台词，[核心张力描述]。[光线+色调收尾]。
```

## 典型案例参考

### 案例一：爱而不得·眼眶泛红

- **角色**：红色长辫、白衬衫黑领带的职场女性
- **情绪**：目送某人离开，强忍情绪，无台词
- **核心提示词要点**：眼睑收紧、吞咽动作、眼眶泛红但泪水不落、拒绝眨眼、最后深吸气静止定格
- **光线**：室内冷白光，轻微侧光

### 案例二：心动瞬间·少女拤发

- **角色**：黑色马尾、JK制服、手抱书本的少女
- **情绪**：无意间看到某人，心动慌乱
- **核心提示词要点**：眼神定住→睫毛颤动→双颊泛红→拤发丝→抱紧书本→偷瞟又低头→嘴角藏不住
- **光线**：户外柔和自然光，逆光晕染发丝

### 案例三：强颜·放下·蓄泪不落

- **角色**：黑发短发、坐在车内、手持香烟的女性
- **情绪**：强颜欢笑→嘴角慢慢放下→眼神失焦，眼眶蓄泪不落
- **核心提示词要点**：笑意止于颧骨、嘴角一毫米一毫米往下沉、下眼睑水光颤着不落、烟雾散开定格
- **光线**：傍晚暖金侧光，车窗光影流动

### 案例四：糙汉尬笑·就这样

- **角色**：黑发凌乱、雀斑、户外强侧光的男性
- **情绪**：被夸/被表白时手足无措的尴尬反应
- **核心提示词要点**：嘴角不自然上扯→眼神左右飘→插兜抽出来摸后颈→干笑「哈哈」→小声说「就这样」→抿嘴点头撤退
- **光线**：户外自然强侧光，发丝轻微飘动

## 安全注意事项

- 含有枪械的角色图片可能触发平台安全审核，即使提示词中规避射击描写，参考图本身也可能导致审核不通过
- 建议使用不含武器的角色图片
- 如遇审核不通过，优先建议用户更换图片，而非反复修改提示词
