# 角色设定板生成（写实电影感）

给一个角色出一张整版专业设定板大图，像游戏／影视美术的角色设定板那样，把「是谁、长什么样、怎么动、细节在哪」全部拼进同一张图。不写剧情、不做分镜与视频。

## 产物

**一张**整版设定板大图，画面内按区块排布，四个区块缺一不可：

1. **三视图**：正面、侧面、背面全身，等高等距、朝向一致，姿态中立。
2. **多姿态**：三到四个能体现该角色身份的架势或动作（持械、结印、回身等），保持服装与体型一致。
3. **细节特写**：面部与发型、配饰与纹样、武器或道具的局部特写，二到四个放大格。
4. **设计卡文字**：图内一块文字区，写明角色名、身份、外貌要点、服装材质与配色、武器道具、关键数值（身高、体型等）。

## 清晰度要求（第一优先级，逐区块落实）

整版设定板必须高清，**四个区块全部清晰锐利、细节可辨**，任何风格化处理都不得牺牲清晰度。逐区块标准：

- **整版输出**：高分辨率出图，长边不低于 2048px；模型或工具有画质档位时选最高档；不用低分辨率出图后再放大补救。整版画面锐利稳定、边缘清晰，无拖影与动态模糊（这是静帧展示图，不是动态镜头）。
- **三视图区**：正／侧／背三个全身像的边缘、轮廓与服装剪影清晰；衣料层次、腰带与系带、靴履结构可辨；不因缩小排布而糊成一团。
- **姿态区**：每个姿态的四肢结构、手部动作、持械方式清晰；武器轮廓、刃口与结构细节可辨；不因动作而模糊。
- **细节特写区**：每个放大格尺寸足够大，放大后仍清晰——五官轮廓与瞳孔、发丝走向、服装材质纹理（布纹、皮革纹、金属反光）、配饰纹样、武器结构与磨损痕迹都能看清。
- **设计卡文字区**：文字用清晰的无衬线字体，字号足够，底衬干净；不糊边、不缺笔画、不错字、不与人物或纹样叠压。
- **禁止削弱清晰度的写法**：不写整体柔焦、不写主体虚化或浅景深虚化主体、不写运动模糊、不写「柔和朦胧」「梦幻朦胧」「模糊感」；不靠重胶片颗粒、噪点或低画质渲染营造质感。写实电影感的颗粒只保留极轻微程度，不得掩盖细节。
- **冲突优先级**：清晰度与风格化表达冲突时，以清晰度优先。

对应到 prompt，清晰度句必须逐字带上，例如：「高分辨率精细渲染，长边不低于2048px，整版每个区块均清晰锐利：三视图轮廓与服装结构清晰、各姿态与武器细节可辨、细节特写格的五官发丝材质纹理清晰、设计卡文字清晰可读；画面锐利无模糊、无柔焦、无运动模糊、无重颗粒。」

出图后如任一区块清晰度不达标，先提升分辨率与锐度重出，不靠后期锐化弥补。

## 固定工艺（锚点，不逐图发挥）

- **风格**：写实电影感，35mm 胶片质感，光影硬朗。原句复用，不换词；与「清晰度要求」冲突时，清晰度优先。
- **模型**：`Lib Image 2.5 Pro`；画幅 `16:9`。用户明确指定其他模型或画幅时从指定。
- **版式**：横向整版，左部三视图竖排、中部多姿态、右部细节特写与设计卡文字；区块之间留白清晰分隔，不重叠、不互相压盖；每个区块的尺寸要保证该区块内容看得清（宁可减少姿态数量，也不缩小到看不清）。
- **背景**：中性灰／浅灰底，无场景、无剧情环境。
- **不写剧情**：不出现叙事场景与情绪化表演，姿态只体现身份与能力。
- **一致性**：全图所有区块共用同一段设定描述，发色发型、脸型五官、体型、服装结构、配色、配饰逐字一致。

## 槽位（每次按角色替换）

- 角色主题：姓名或身份、年龄性别、气质
- 外貌：发型发色、脸型五官、瞳色、体态与身材数值
- 服装：材质、颜色、版型、层次
- 配饰与武器
- 世界观基调（古代仙侠／武侠、现代都市、末世等）
- 参考图节点
- 姿态清单：本次要画的动作（不指定时按其身份推断三到四个）

## 步骤

1. **读素材**：有参考图节点先读取，确认面部、发型、服装与气质基线；同时读用户的设定描述。
2. **归纳描述**：整理成一段角色设定描述，按「外貌 → 服装 → 配饰武器 → 气质」排序，全图所有区块逐字复用。
3. **建图节点**：用 `create_image_node`，`tag=character`，`aspect_ratio=16:9`，单节点单图；分辨率／画质按最高档设置。prompt 结构：
   - 开头写「专业角色设定板，一张图内分区排布，高清精细渲染」；
   - 依次写四个区块：三视图（正面／侧面／背面全身，等高等距、朝向一致、姿态中立）→ 多姿态（列出具体动作）→ 细节特写（面部与发型、配饰纹样、武器局部放大）→ 设计卡文字（写出图上要显示的具体文字内容）；
   - 写版式与背景句：「左部三视图竖排、中部多姿态、右部细节特写与设计卡文字，区块间留白清晰分隔、互不叠压，中性灰纯色背景」；
   - 写清晰度句（见「清晰度要求」，逐字带上高分辨率、逐区块清晰、文字可读、无模糊／柔焦／运动模糊／重颗粒）；
   - 写风格句：「写实电影感，35mm胶片质感，光影硬朗」；
   - 补一致性句：「全图所有区块为同一角色，发色发型、脸型五官、体型、服装结构、配色与配饰完全一致」。
4. **参考图引用**：有参考图时在 `reference_nodes` 引用其 `{{node_key}}`，prompt 中写职责行：`{{node_key}}用于<角色代称>的外貌、发型与气质基线，不采用图片背景。`
5. **运行与交付**：运行前按当前审批方式请用户确认；运行后交付这张设定板，说明用到的模型、分辨率与画幅、姿态清单，并在交付前逐区块确认清晰度是否达标。

## 提交前自检

- 四个区块齐备：三视图、多姿态、细节特写、设计卡文字；版式不重叠、不挤到看不清。
- 清晰度句已逐字写入：高分辨率（长边≥2048px）、逐区块清晰锐利、文字清晰可读、无模糊／柔焦／运动模糊／重颗粒；prompt 里没有削弱清晰度的词。
- 逐区块确认：三视图轮廓与服装结构清晰、姿态与武器细节可辨、特写格放大后仍清晰、设计卡文字无糊边错字叠压。
- 出图分辨率与画质档为最高档。
- 全图是同一角色，脸、发、体型、服装、配色一致。
- 风格句原句未改写；模型、画幅与本节锚点一致。
- 画面内无剧情场景与情绪化表演。
- 每个 `{{node_key}}` 真实存在，代称与主体对应。

## 例子

- 输入：「红衣术士，女性，御火，长发，赤金配饰」→ 出一张整版板：三视图竖排、中部多个御火架势、右侧面部与配饰纹样特写、右下设计卡文字写明身份与配色；四个区块的细节与文字均清晰可辨。
- 输入：参考图 + 角色描述 → 面部发型沿用参考图，其余按描述补齐，仍输出单张整版板，并保证分辨率与各区块细节达标。

## 边界

- 只产出角色设定板，不产出分镜、台词、视频与场景设计。
- 「半身身份卡 + 全身服装图」这类分区成图属于另一套做法，不在本技能范围。
