# 品牌 Logo 设计

## 核心方法论

### 极简几何符号系统

基于品牌核心价值抽象出视觉符号,遵循三层递进逻辑:

- **概念层**: 从品牌名称/理念中提取 2-3 个关键词,识别行业属性和价值主张
- **形态层**: 将关键词转化为几何图形语言 — 圆形(包容/完整)、方形(稳定/专业)、三角(方向/创新)、线条(连接/流动)
- **组合层**: 用减法原则构建符号 — 单一形状优于复合形状,负空间优于正空间填充,可识别度 &gt; 复杂度

### 双版本输出标准

每次设计必须同时交付两种独立版本:

- **Symbol Only (纯图标版)**: 纯几何符号,无文字,适用于小尺寸场景(App 图标/社交媒体头像/产品标识)
  - 可识别性测试: 在 32x32 像素下仍能辨识核心形态
  - 边界规范: 图标外围留 15%-20% 安全留白
- **Symbol + Wordmark (图文组合版)**: 图标 + 品牌名称文字组合,适用于正式场景(官网 header/名片/宣传物料)
  - 排版逻辑: 横向排列(图左字右)或纵向排列(图上字下),根据品牌名称长度选择
  - 字体规范: 使用无衬线字体,字重 Medium-Bold,字间距 +5%-10%

### 中性+暗色配色法则

构建双色调系统确保品牌高级感:

- **主色**: 从中性色选择(纯黑 #000000/炭灰 #2C2C2C/纯白 #FFFFFF)
- **辅助色**: 从暗色系选择(深蓝 #1A2332/深紫 #2D1B3D/深绿 #1C2E1F),用于渐变/阴影/辅助元素
- **对比度标准**: 确保主色与背景对比度 ≥ 4.5:1 (WCAG AA 级)
- **单色适配**: 所有 Logo 必须可无损转换为纯黑或纯白版本

## 工作流程

### 1. 品牌信息解析阶段

**输入收集清单**:

- 品牌名称(必需): 中文/英文/缩写
- 品牌理念(必需): 核心价值观、目标受众、差异化定位
- 行业属性(推荐): 科技/金融/教育/消费品等细分领域
- 禁忌元素(可选): 明确不可使用的图形/颜色

**关键词提炼**:

- 从品牌名称和理念中提取 2-3 个核心视觉关键词
- 例: 品牌名称「云知」+ 理念「连接知识与智慧」 → 关键词: 云(轻盈/流动)、连接(网络/桥梁)、智慧(光芒/开启)

**形态方向判断**:

- 根据关键词确定主导几何语言 — 有机曲线 vs 硬朗直线
- 确定符号复杂度级别 — 单一形状(1 个基础图形) vs 复合形状(2-3 个图形组合)

### 2. 符号设计阶段

**草图生成策略**:

- 基于关键词生成 3 种不同形态方案:
  - 方案 A: 抽象符号(高度简化的几何图形)
  - 方案 B: 字母融合(品牌首字母变形)
  - 方案 C: 意象化图形(具象物体的极简化)
- 每个方案用 1-2 句话描述核心视觉逻辑

**扁平化执行标准**:

- 无渐变色块(纯色填充)
- 无阴影/高光/纹理效果
- 线条统一粗细(建议 2-4pt 描边)
- 圆角统一半径(若使用圆角,半径 = 图标尺寸 × 8%-12%)

**负空间利用**:

- 优先使用负空间构建识别性 — 图形间的「空白」本身形成可读符号
- 经典案例: FedEx 的 E-x 箭头、NBC 的孔雀尾羽

### 3. 双版本输出阶段

**Symbol Only 制作规范**:

- 画布尺寸: 1024x1024px(输出后可缩放)
- 图标占比: 核心图形占画布 60%-70%,四周留白
- 细节检查: 在 64x64px 预览下确认关键形态仍清晰

**Symbol + Wordmark 排版规范**:

- 图标与文字间距 = 图标宽度 × 30%-50%
- 文字大小: 文字高度 = 图标高度 × 60%-80%
- 对齐方式: 视觉中心对齐(非数学中心)
- 品牌名称处理:
  - 中文: 使用思源黑体/阿里巴巴普惠体等开源无衬线字体
  - 英文: 使用 Montserrat/Inter/Poppins 等现代 Sans-serif

**配色应用**:

- 主色版本: 图标+文字使用单一主色(黑/灰/白)
- 双色版本: 图标使用暗色辅助色,文字使用主色
- 反白版本: 同步输出透明背景的纯白色 Logo(用于深色背景)

## 关键约束与标准

### 视觉简洁性规则

- **形状数量上限**: 单个 Logo 中独立几何形状 ≤ 3 个
- **颜色数量上限**: 除黑白灰外,额外颜色 ≤ 1 种
- **线条一致性**: 所有描边线条粗细必须统一,禁止混用不同粗细
- **无装饰元素**: 禁止添加花纹/纹理/光效/3D 效果

### 可识别性标准

- **缩放测试**: Logo 缩小到 32x32px 时核心形态仍可辨识
- **单色测试**: 转为纯黑或纯白后信息传达无损失
- **5 秒记忆测试**: 用户看 5 秒后能大致描述 Logo 的核心形状

### 文字排版约束

- **字体类型**: 仅使用无衬线字体(Sans-serif),禁用衬线体/手写体/装饰体
- **字间距调整**: 标准字间距增加 5%-10%,确保呼吸感
- **字重规范**: 品牌名称字重 ≥ Medium,避免 Light 或 Thin
- **大小写**: 英文品牌名称优先全大写或首字母大写,禁止全小写

### 版本完整性要求

- **强制双版本**: 每次输出必须包含 Symbol Only + Symbol + Wordmark 两个独立版本
- **背景适配**: 每个版本至少提供白底和透明底两种背景
- **尺寸规格**: Symbol Only 输出 1024x1024px,Symbol + Wordmark 根据文字长度输出 1024x(高度自适应)或(宽度自适应)x1024px

### 品牌名称处理规则

- **中文名称**: 使用品牌全称,禁止缩写(除非用户明确要求)
- **英文名称**: 若品牌有官方英文名使用官方名,否则使用拼音全拼
- **双语品牌**: 仅在图文组合版中显示一种语言,优先中文(除非用户指定英文)

## 示例

### 输入

品牌名称: 云知\
品牌理念: 连接知识与智慧,让学习像云一样轻盈流动\
行业属性: 在线教育\
色彩倾向: 中性色(黑灰) + 深蓝

### 关键词提炼

- 云(轻盈、流动、无界)
- 连接(桥梁、网络)
- 智慧(开启、光芒)

### 方案设计

**方案 A: 抽象云纹符号**

- 3 条流动曲线层叠,形成云的抽象形态,曲线间负空间形成向上的箭头暗示(知识提升)
- 颜色: 纯黑主色

**方案 B: 字母「云」几何化**

- 将汉字「云」的上半部分抽象为两条平行弧线,下半部分简化为支撑直线,形成稳定的几何图形
- 颜色: 炭灰 #2C2C2C

**方案 C: 连接节点网络**

- 4 个圆点排列成菱形,中心圆点连接四周形成放射状线条,象征知识节点互联
- 颜色: 深蓝 #1A2332

### 最终输出(选择方案 A)

**Symbol Only**:

- 1024x1024px,透明背景
- 3 条流动黑色曲线居中,占画布 65%
- 白底版本和透明底版本各一

**Symbol + Wordmark**:

- 1200x1024px,透明背景
- 左侧图标(400px 宽),右侧「云知」文字(思源黑体 Bold,文字高度 280px)
- 图标与文字间距 150px
- 白底版本和透明底版本各一
