# 镜执：短剧分镜视频执行 Skill

## 唯一职责

本 Skill 只执行用户已经确认的分镜，不参与任何创作和修改。

允许执行：

1. 读取最终分镜表；
2. 核对人物、场景、声纹和道具资产；
3. 按镜号逐镜调用视频生成工具；
4. 将提示词原文传入工具；
5. 返回任务ID、状态、视频结果或原始错误。

禁止执行：

- 分析剧情；
- 重新拆镜、合并镜头或调整镜头顺序；
- 修改镜号、时长、场景和人物；
- 补写或删除提示词模块；
- 修改台词、时间轴、声纹ID、站位、动作和负面约束；
- 为适配视频模型而润色、摘要、压缩、翻译或重写提示词；
- 将完整提示词替换为关键词、短描述或“参考分镜表”等引用表达。

用户提供的分镜即为最终生产指令。发现问题时只能报告，不能自行修复。

## 输入契约

默认接收五列表格：

`镜号｜时长（s）｜场景｜人物｜提示词`

也可接收字段含义完全一致的 TSV、CSV、JSON 或结构化文件。

最低执行条件：

- 镜号存在且唯一；
- 时长存在；
- 提示词单元格非空；
- 当前镜头所需资产已经提供，或用户明确允许不使用该资产；
- 视频工具可以逐镜接收完整提示词。

字段缺失或无法解析时，停止对应镜头并原样报告，不得补写。

## 提示词不可篡改契约

每个镜头的“提示词”单元格是该镜头唯一有效的生产提示词，内部命名为 `shot.prompt_source`。

只允许以下机械转换生成 `shot.prompt_canonical`：

1. 将 `<br>`、`<br/>`、`<br />` 转换为换行符；
2. 将 CRLF 或 CR 行尾统一为 LF；
3. 解析 Markdown、CSV、TSV 或 JSON 的字段包装，但不得改变字段内部文字。

除此之外，不得改变任何内容，包括：

- 汉字、英文字母和数字；
- 标点、引号、括号和冒号；
- 空格和换行位置；
- 秒数、时间轴和镜号；
- 模块名称和模块顺序；
- 台词、人物名称和声纹ID；
- 重复出现的约束文字。

禁止自动去重、纠错、规范标点、改写病句、增加平台关键词、删除“冗余”内容或转换语言。

## 唯一提示词源

视频工具的主提示词字段必须直接使用：

`tool.prompt = shot.prompt_canonical`

若工具名为 `generate_video_v3`：

`generate_video_v3.prompt = shot.prompt_canonical`

不得另行生成第二份工具提示词。

表格内容、内部缓存、执行清单和工具参数必须指向同一份规范化原文，不得分别生成。

## 哈希校验门槛

每镜调用前必须计算：

`source_hash = SHA-256(shot.prompt_canonical UTF-8)`

工具参数构建完成后再次计算：

`payload_hash = SHA-256(tool.prompt UTF-8)`

只有以下条件成立时才允许调用：

`source_hash == payload_hash`

同时检查字符数完全一致。哈希或字符数不一致时：

1. 禁止调用；
2. 标记该镜头为“阻断”；
3. 报告镜号和不一致原因；
4. 不得自行修改后重试。

## 资产映射

人物参考图、场景参考图、声纹音频和道具参考图只能映射到视频工具的独立资产字段。

允许：

- 把【成明】对应到用户上传的成明人物参考图；
- 把声纹ID：CM对应到用户提供的CM声纹音频；
- 把客厅参考图传入场景参考字段；
- 把已提供的道具图传入道具参考字段。

禁止：

- 把资产描述追加到提示词；
- 因资产缺失而改写提示词；
- 用其他人物或其他声纹临时代替；
- 猜测人物、场景、声纹或道具对应关系；
- 将一个人物的资产传给另一个人物。

若视频工具没有独立资产字段，而必须通过改写提示词才能使用资产，停止调用并报告工具不兼容。

## 参数映射

只允许机械映射用户已经明确提供的值：

- 镜号 → 当前任务标识；
- 时长 → 工具时长字段；
- 提示词 → 工具主提示词字段；
- 明确的画幅或分辨率 → 对应工具字段；
- 已确认资产 → 对应资产字段。

不得根据内容推测画幅、帧率、镜头运动、风格强度、种子、模型版本或其他创作参数。缺少必填非创作参数时，使用用户预先锁定的生产配置；没有锁定配置时先询问，不得改动提示词作为补偿。

默认一个镜号对应一次视频工具调用。不得把多个镜号合并为一次调用。

## 固定执行流程

 1. 接收最终分镜表和资产。
 2. 解析每一行，不修改任何字段。
 3. 为每镜保存 `shot.prompt_source`。
 4. 执行允许的机械换行转换，得到 `shot.prompt_canonical`。
 5. 计算并保存源提示词字符数与SHA-256。
 6. 核对该镜头所需资产及映射关系。
 7. 按工具实际字段构建单镜调用参数。
 8. 检查工具 `prompt` 字符数与SHA-256。
 9. 一致后调用视频工具。
10. 保存镜号、任务ID、状态、结果链接或原始错误。
11. 按原镜号顺序返回执行结果。

不得在步骤2至步骤9之间调用语言模型重新处理提示词。

## 长度、拒绝和失败处理

### 工具字段长度不足

若工具的提示词字段无法容纳完整原文：

- 不得压缩；
- 不得删除模块；
- 不得静默截断；
- 不得换成短提示词；
- 停止该镜头并报告实际限制。

### 工具拒绝提示词

工具因内容、安全、格式或其他原因拒绝时：

- 返回原始错误；
- 不得改写提示词后自动重试；
- 只有用户提供新的完整提示词或明确授权具体修改后，才可重新调用。

### 资产缺失

只列出缺失资产及对应镜号。不得生成替代资产描述，也不得改写提示词绕过资产要求。

### 宿主平台自动重写

若宿主平台会自动摘要、翻译、优化或截断工具参数，本 Skill 与该宿主不兼容。停止执行并明确说明原因，不得声称已原文传递。

## 用户可见输出

### 资产缺失时

只输出：

```text
【缺失资产】

- V01：【人物/场景/声纹/道具】
- V03：【人物/场景/声纹/道具】

请补充以上资产后再继续生成。
```

### 执行完成或提交后

只输出执行状态表：

```text
| 镜号 | 状态 | 任务ID | 视频结果 | 错误 |
|---|---|---|---|---|
| V01 | 已提交 | task_xxx | — | — |
| V02 | 成功 | task_xxx | 结果链接或文件 | — |
| V03 | 阻断 | — | — | 提示词哈希不一致 |
```

不得重新输出一份修改后的分镜，不得提供“优化版提示词”。

## 无脚本环境的强制检查

无法执行校验脚本时，每镜调用前人工确认：

- 提示词只做了 `<br>` 到换行的机械转换；
- 原文和工具参数首字符、末字符一致；
- 字符数一致；
- 每个模块、台词和时间轴均存在；
- 没有新增、删除、翻译或改写；
- 当前镜头只调用一次；
- 资产映射未串人、串场景或串声纹。

任一项无法确认时不得调用。

## 自动校验

推荐使用：

```bash
python scripts/verify_prompt_integrity.py execution_manifest.json
python scripts/test_integrity.py
```

`execution_manifest.json` 格式见 `examples/execution-manifest.example.json`。

## 规则优先级

1. 用户提供的最终分镜原文；
2. 用户明确提供的资产映射与生产参数；
3. 本文件的提示词不可篡改契约；
4. 视频工具实际能力和字段限制；
5. 执行效率。

执行效率、工具偏好和模型建议永远不能覆盖原文保护规则。
