# 高端电商产品主图 + TVC广告视频生成

## Skill 说明

本 Skill 分两步完成：

1. **生成高端电商产品主图**：适用于任意产品，商业广告摄影质感，8K细节
2. **将主图制作成TVC广告视频**：基于主图生成动态展示视频

---

## 第一步：收集产品信息

如果用户没有提供产品信息，询问以下内容：

- **产品名称/描述**：要拍摄的产品是什么？（如：无线耳机、护肤精华瓶、香水瓶、手表、口红等任意物品）

> 产品信息是唯一必填项，其余参数均有默认值，无需追问。

---

## 第二步：生成高端电商产品主图

使用图像生成工具，按以下参数生成主图：

### 图像生成 Prompt 模板

```
高端电商产品主图：[产品名称/描述]，产品居中微侧15度摆放，纯净浅色渐变背景（浅灰到白），柔和影棚三点布光，主光在产品边缘勾勒出细腻高光轮廓，产品底部呈现轻微镜面倒影，材质细节锐利清晰，商业广告摄影质感，8K超高清细节，白色干净背景，专业产品摄影棚
```

### 默认参数（用户未特别说明时使用）

以下参数为默认值。**用户明确提出新要求时，以用户要求为准，覆盖对应默认值**；用户未提及的参数保持默认值不变。

参数默认值画面比例1:1（正方形，适合电商主图）背景纯净浅色渐变（浅灰到白）布光方式柔和影棚三点布光主光效果细腻高光勾勒产品轮廓底部效果轻微镜面倒影画质材质细节锐利清晰，商业广告摄影质感，8K细节产品姿态居中微侧15度

### 可替换槽位

槽位说明`[产品名称/描述]`用户提供的任意产品，如"无线耳机"、"护肤精华瓶"、"机械手表"等

---

## 第三步：确认主图并生成TVC视频

主图生成后，**暂停并等待用户确认**，再进入视频生成步骤。

- 用户确认主图（如"好的""可以""继续"或直接说"生成视频"）→ 立即进入视频生成
- 用户提出修改意见（如"背景换成深蓝色""角度改成正面"）→ 先按修改意见重新生成主图，用户确认后再生成视频；修改的参数同步体现在后续视频中
- 视频始终以用户最终确认的主图作为首帧参考

### 视频生成策略

基于已确认的产品主图，使用视频生成工具，按以下参数生成TVC广告视频：

**视频 Prompt 模板：**

```
高端产品TVC广告视频：以[产品名称]电商主图为基础，产品从画面中央缓缓浮现，伴随柔和光晕扩散，产品缓慢旋转360度展示细节，镜面倒影随之流动，最后产品定格居中，光影渐渐稳定，整体氛围奢华、精致、商业感强，无文字，纯产品展示，高端广告摄影质感
```

### 视频默认参数（用户未特别说明时使用）

以下参数为默认值。**用户明确提出新要求时，以用户要求为准**；用户未提及的参数保持默认值不变。

参数默认值时长5\~8秒（适合电商/社交媒体投放）画面比例与主图一致（默认1:1）运镜产品缓慢旋转或轻微推进，镜头保持稳定背景与主图一致风格高端商业广告，无文字叠加，纯产品展示参考帧使用用户最终确认的产品主图作为首帧参考

---

## 第四步：输出结果

完成后向用户展示：

1. **产品主图**：高端电商主图（默认1:1，8K商业摄影质感）
2. **TVC广告视频**：基于主图的动态展示视频（默认5\~8秒）

并告知用户：

- 如需更换产品，直接告知新产品名称即可重新生成
- 如需调整任意参数（背景、比例、时长、运镜等），随时提出

---

## 注意事项

- 本 Skill 适用于**任意实体产品**，不限定品类
- 所有参数均为默认值，用户明确提出新要求时以用户要求为准
- 如用户提供了产品参考图，优先以参考图为基础进行风格迁移
