# 商业产品视频风格复刻

## 核心方法论

### 1. 视觉基因提取框架

参考视频的可复用设计知识不是表面的「模仿画面」,而是提取其底层的视觉决策系统。将任何参考片解构为以下5个独立维度:

**运镜语法层** — 镜头如何移动以构建叙事节奏

- 开场策略: 推进(Push-in)建立主体 vs 拉出(Pull-out)揭示环境
- 转场逻辑: 硬切强调对比 vs 环绕(Orbit)制造沉浸感
- 景别组合: 全景铺陈→中景交互→特写强化情绪,这是商业片的标准三段式
- 时长分配: 每段镜头应维持在3-7秒以保持注意力,15秒成片通常为3-5个镜头单元

**光影构图层** — 如何通过光线雕刻视觉层次

- 光源类型: 舞台聚光(硬光+暗部)营造戏剧性 vs 环境光(柔光+高亮)营造清新感
- 色彩饱和度: 高饱和度(商业广告感) vs 低饱和度(高级电影感)
- 主色调延续: 从参考片提取主色调(如暖橙/冷紫),映射到产品包装色系统中以保持品牌一致性

**文字排版层** — 信息如何视觉化落地

- 位置法则: 居中(强调品牌调性) / 左下角(新闻感) / 右上角(时尚感)
- 字体性格: 无衬线粗体(力量感) / 衬线体(优雅感) / 手写体(亲和感)
- 出现动画: Fade-in(平稳) / 打字机效果(科技感) / 从下滑入(动感)

**节奏剪辑层** — 视觉与时间的结构化关系

- 快剪(1-2秒/镜)制造能量感,适合运动饮料/潮牌
- 慢镜头(5-7秒/镜)强化质感,适合高端护肤品/珠宝
- 卡点逻辑: 画面转场应与音乐节奏对齐(即使在无声提示词中也需预设此节奏感)

**空间奇幻层** — 超现实视觉符号的构建

- 复制阵列(克隆主体无限延伸)表达产品的「无限可能性」
- 悬浮元素(产品成分/果片)象征「营养释放」
- 背景抽象化(纯色几何空间替代现实场景)避免信息干扰

### 2. 提示词工程化框架

将视觉基因转译为模型可执行的提示词,需遵循以下结构化逻辑:

**时间轴分段描述法**

```
[0s-2s] 镜头类型 + 角度 + 运动方式 + 主体动作 + 光影描述
[2s-4s] ...
[13s-15s] ...
```

每段必须包含:

- 镜头术语(Medium shot / Close-up / Bird's-eye view)
- 相机运动(Static / Tracking / Push-in / Orbit)
- 主体行为(角色动作 + 产品交互)
- 光线材质(Warm spotlight / Bright studio lighting / Neon rim lighting)

**层级描述优先级**

1. 主体(人物/产品)的空间位置和动作状态
2. 镜头的运动方式和拍摄角度
3. 光影的类型、方向、色温
4. 背景环境的具体描述(不可用"beautiful background"这类空洞词)
5. 特效元素(溅起液体/悬浮成分/速度线)
6. 文字信息(内容/字体/位置/动画)

**色彩映射规则**参考片的色调必须「翻译」而非「复制」:

- 参考片为暖红舞台→产品色为紫色→转译为紫色奇幻空间+暖光轮廓
- 参考片为冷蓝科技感→产品色为绿色→转译为绿色电子网格+冷光扫描

**负向提示词必须明确禁止的视觉缺陷**

- 解剖错误(extra limbs / deformed face)
- 品牌元素污染(random unrelated text / watermark)
- 风格断裂(style inconsistency / dark muddy colors)

## 工作流程

### 1. 准备阶段

**输入清单审查**

- \[ \] 参考视频素材(视频文件 OR 3-5张关键帧截图 OR 详细的文字描述)
- \[ \] 产品图片(需包含产品正面/侧面/包装细节,最好有透明背景版本)
- \[ \] 角色图片(如涉及真人/数字人,需提供清晰的全身照或半身照)
- \[ \] 核心文案(品牌slogan / 产品卖点,需确认字数不超过20字以适配15秒时长)
- \[ \] 可选项: 指定色调偏好(暖/冷/高饱和/低饱和)

**参考片风格基因提取**

- 运镜分析: 记录每个镜头的类型(固定/跟随/推拉/旋转),转场方式(硬切/溶解)
- 光影分析: 识别主光源(顶光/侧光/背光),色温(暖黄/冷蓝),对比度(高对比戏剧性/柔和自然)
- 排版分析: 记录文字出现的时间点、位置(居中/角落)、字体风格(粗体/细体/衬线/无衬线)、动画效果
- 节奏分析: 统计每个镜头的持续时长,是否有慢镜头/快剪效果

### 2. 初始设计阶段

**三段式结构设计**

标准15秒商业片的黄金结构:

**第一段(0-5s): 主体登场+情境建立**

- 目标: 吸引注意力,快速建立产品与角色的关联
- 镜头策略: 从全景推进到中景,或固定机位开场后快速切换到特写
- 角色动作: 持产品进行核心交互(饮用/涂抹/展示)
- 光影: 使用戏剧性光源(聚光灯/侧光)制造视觉冲击力

**第二段(5-10s): 视觉爆发+产品价值具象化**

- 目标: 通过超现实视觉符号传达产品功效
- 空间转换: 从现实场景切换到奇幻空间(纯色背景+悬浮元素)
- 特效密集区: 复制阵列、旋转轨道、成分爆炸、速度线等视觉奇观集中在此段
- 色彩策略: 映射产品主色调,饱和度拉满

**第三段(10-15s): 产品定版+信息落地**

- 目标: 强化品牌记忆,完成视觉收束
- 镜头: 产品居中特写,缓慢旋转或静止
- 文字: slogan/产品名以Fade-in方式叠加在画面中上部
- 背景: 简化为纯色或模糊的成分环绕,避免信息干扰
- 结尾: 淡出到黑屏或品牌logo定版

**提示词组装**

将三段结构转译为时间轴标注的prompt:

```
Vertical 9:16 cinematic commercial video, 15 seconds total. [整体风格描述]

[0s–5s] [第一段完整描述: 镜头+动作+光影+背景]
[5s–10s] [第二段完整描述: 空间转换+特效+色彩]
[10s–15s] [第三段完整描述: 产品定版+文字+收束]

Negative prompt: [禁止的视觉元素列表]
```

**角色与产品素材插入**

- 使用`{{CHARACTER}}`标记角色图的插入位置
- 使用`{{PRODUCT}}`标记产品图的插入位置
- 在描述中明确角色与产品的交互动作(左手持产品、右手持瓶盖、抬头饮用等)

### 3. 迭代优化阶段

**动作细节校准**

用户最常见的修正需求来自"角色动作的物理合理性"。需建立动作细节检查清单:

- \[ \] 瓶盖状态明确: 若角色饮用,瓶盖必须已拧开(左手持无盖瓶身,右手持瓶盖)
- \[ \] 手部位置合理: 避免"两只手同时握住瓶身"这类不自然动作
- \[ \] 面部表情匹配: 饮用时应有"享受"表情(微闭眼、嘴角微扬)
- \[ \] 产品朝向: 产品logo/标签应面向镜头

**视觉一致性校验**

- 色调一致性: 三段镜头的主色调应保持在同一色系(暖色系 OR 冷色系)
- 光影一致性: 若第一段使用舞台聚光,后续段落不应突然切换到柔和自然光
- 品牌元素一致性: 产品在每段中的视觉权重应递增(开场为道具→中段为符号→结尾为主角)

**技术约束检查**

- 时长控制: 15秒提示词的总字数应控制在800-1200字(过短缺乏细节,过长模型难以全部执行)
- 镜头数量: 3-5个镜头单元为最佳(过多导致碎片化,过少显得单调)
- 特效密度: 特效元素(悬浮物/液体溅射)应集中在中段,避免全程密集导致视觉疲劳

**用户修正转译规则**

当用户提出修正需求时,需将自然语言精确转译为提示词调整:

用户说:"瓶盖要拿下来" → 转译为: 在角色动作描述中加入 "holds an open bottle in left hand and the detached bottle cap in right hand"

用户说:"色彩太暗了" → 转译为: 在光影描述中加入 "high-brightness commercial lighting, vibrant saturated colors"

用户说:"产品不够突出" → 转译为: 在第三段增加 "shallow depth of field, product in sharp focus, background fully blurred"

## 关键约束与标准

### 不可妥协的视觉规则

**运镜禁忌**

- 禁止在15秒内使用超过7个镜头(会导致视觉碎片化)
- 禁止全程使用固定机位(缺乏动感)
- 禁止突然的视角跳跃(如从正面直接切到俯拍,需要过渡镜头)

**光影禁忌**

- 禁止在同一镜头内混用暖光与冷光(除非刻意制造冲突感)
- 禁止背光导致主体变成剪影(除非刻意追求剪影效果)
- 禁止过度曝光导致产品细节丢失

**文字排版禁忌**

- 禁止文字占据画面超过30%面积(会压迫视觉焦点)
- 禁止使用超过2种字体(会导致风格混乱)
- 禁止文字出现时间少于2秒(观众来不及阅读)

**角色动作禁忌**

- 禁止角色面部朝向背离镜头超过3秒(会断开观众连接)
- 禁止不合理的解剖结构(如扭曲的手臂角度)
- 禁止角色表情与产品调性不符(如高端护肤品配夸张搞笑表情)

### 保真度标准

**参考片风格还原度检查**

- 运镜类型匹配度 ≥ 80%(如参考片用推进镜头,生成片也应以推进为主)
- 色调饱和度偏差 ≤ 15%(通过色卡对比)
- 镜头时长分布相似度 ≥ 70%(如参考片开场5秒,生成片开场不应只有2秒)

**品牌一致性标准**

- 产品logo在至少2个镜头中清晰可见
- 品牌主色调在画面中占比 ≥ 40%
- slogan文字在画面中停留时间 ≥ 3秒

**技术输出标准**

- 视频分辨率: 1080×1920(9:16竖屏)
- 帧率: ≥ 24fps
- 时长误差: ±1秒(目标15秒,实际输出14-16秒可接受)
