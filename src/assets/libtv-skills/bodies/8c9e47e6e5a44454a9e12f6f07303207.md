## name: lighting-time-weather-skill description: 对已有场景底图先做可行性分析，再在用户选择后通过图生图（image-to-image）生成物理可信的时段、天气、室内外光照与摄影作品/影视剧照成片效果，同时锁定机位、构图、人物、物体和原生细节。适用于日出、白天、黄金时刻、日落、蓝调时刻、夜晚、晴天、阴天、雨、雾、雪及有动机的室内光影调整；尤其适用于要求场景一致性与影视级光影的任务。不用于从零创建场景、自由重设场景内容或大规模替换季节植被。

# 光影时刻与天气skill（V1.00）

> 本 Skill 作者：抖音-六万的旅行（仅用于署名，不参与 Skill 的触发、执行或输出。）

先让光照状态真实成立，再追求摄影感或影视感。场景身份与内容一致性优先于氛围。

## 强制两阶段流程

### 阶段 A：可行性预检（始终先执行）

用户上传底图并调用本 Skill 时，先分析、后给出简化决策菜单。即使用户顺带说了想做的效果，此阶段也**不得生成或编辑图片**；等待用户选择方案或补充控制项。

内部完成以下审计，但默认不展开推理过程：

1. 判断为室外、具有外部采光入口的室内，或封闭室内。
2. 识别有动机光源、采光入口、可见天空、朝上稳定表面、景深层次、高频材质保护区及所有人物；同时确定原图的视觉锚点（人物、入口、窗、倒影、建筑或远处主体）与其必须保留的观看优先级。
3. 对每位可见人物记录不可变主体锚点（immutable subject anchor）：人数、位置、姿态、朝向、服装大色块、遮挡关系，以及与道具的接触关系。信息过小或模糊时，标记“人物保真风险”，建议轻量变化或更高清/局部参考。
4. 将候选变化归类为：可生成、可选、不建议。
5. 天气会迫使大量重绘时，推荐更保守的方案；例如雾按景深层次选择，雪优先落在稳定朝上表面并保护复杂植被。若目标时段与天气在物理上相互矛盾，不把它列为可生成项。
6. 输出菜单后停止，等待用户选择；不承诺每个选项都能稳定成功。

默认只使用下列格式。不要默认展示审计细节、光源分析或逐项理由；只有在保真风险会实质影响结果时，才加一条简短提示。用户追问后再解释原因。

```text
## 图片判断
- 场景：室外 / 有外部采光入口的室内 / 封闭室内
- 保真提示：仅在有人物、小物体、复杂材质或低清细节风险时说明一句。

## 六大时刻
- 可生成：...
- 可选：...
- 不建议：...

## 天气
- 可生成：...
- 可选：...
- 不建议：...

## 推荐组合
1. [时段 + 天气 + 成片目标]
2. ...

回复组合序号，或直接写「时段 / 天气 / 光源方位 / 成片目标 / 景深」。需要原因时可追问。
```

室外图需在内部评估六大时刻及晴、阴、雨、雾、雪，但只列出画面实际支持的选项。室内图只通过真实的外部采光入口或已有实用光源（practical light）提供选项；封闭室内不得把时段变化伪造成日光变化。

### 阶段 B：用户选择后的生成

仅在用户选择后执行：

1. **建立目标环境状态。** 确定时段、天气、太阳相对机位、自然采光入口或实用光源；先通过时段 × 天气冲突检查，再确定成片目标：摄影作品版、影视剧照版或不做成片处理。
2. **先安排观看路径。** 锁定视觉锚点及其次级信息；主光、塑形、实用光和暗部取舍都必须服务该锚点，不能因“电影感”让背景光、天气特效或无关区域抢走注意力。
3. **锁定输出画布。** 读取原图的像素尺寸 `W×H`、宽高比与横竖画幅。输出必须优先保持原始宽高比；生成工具支持原始尺寸时，同时使用完全相同的 `W×H`。若原始尺寸超出工具上限或工具不支持，则在相同宽高比下使用工具允许的尽可能大尺寸；不得为迁就尺寸而裁切、拉伸、补边或改变横竖画幅。
4. **仅实施必要的物理变化。** 建立一个主要且有动机的环境光；仅在合理时增加一个塑形策略，以及一个实用光/分离光。按强化效果的触发条件与冲突规则取舍，不叠加装饰性光效。保留原图的信息层级。
5. **最后做成片处理。** 仅在真正适配画面时调用 1–3 张用户认可的审美参考卡。胶片、LUT、颗粒、耀斑、散景或“电影感”标签都不能代替光照逻辑。
6. **执行拒收门。** 保真失败时，回退到更轻的变化或原图；不要用更多提示词掩盖失败。

按需读取参考文件：

- 室外时段、太阳方位、雨、雾、阴天、雪：读 tod-weather.md。
- 室内或任何通过窗、门、裂缝、天窗、洞口进入的外部光：读 indoor-light.md。
- 成片选择、景深、材质保护、提示词组织、验收：读 finish-and-qa.md。

## 输入约定

底图足以执行阶段 A。只有会实质改变阶段 B 结果的选项才向用户追问；其余内容保守推断并说明推断。

- 阶段 A 必需：底图。
- 阶段 B 必需：已选方案，或明确的时段/天气需求，或“保留现有环境状态”。
- 可选控制项：
  - 环境：室外 / 有外部采光入口的室内 / 封闭室内。
  - 太阳相对机位方位：镜头侧（顺光，camera-side/front light）、远侧/画面观看方向（逆光，far-side/view-direction backlight）、画面左侧、画面右侧；可补充低/中/高角度，入画/画外/被遮挡。
  - 太阳轨迹配对（sun-path pairing）：同一张底图需要生成成组的日出与日落时，必须使用同一画面坐标系并让两者处于相反画面侧；例如日出在画面左侧/左侧画外，则日落在画面右侧/右侧画外，反之亦然。用户明确指定方位时以用户指定为准。
  - 变体连续性：同一底图需生成多时段或多天气组，且低信息区域必须补全时，先确认一张“补全母版”；所有后续变体沿用同一场景补全、物体布局与几何，不得各自重设计。
  - 雨量、雾密度、积雪状态、降雪强度、风向。
  - 观看模式：真实低曝光（realistic low exposure）/ 影视可读性（cinematic readability）。
  - 成片目标：摄影作品版 / 影视剧照版 / 不做成片。
  - 景深：保留原图 / 环境深焦 / 前景边缘柔化 / 主体对焦。不得仅为遮盖瑕疵而擅自使用浅景深。

## 不可协商的锁定项

- **输出比例与尺寸锁定。** 输出必须保持原图宽高比。生成工具支持原图像素尺寸时，输出必须同时为原图的精确 `W×H`；受工具上限或能力限制时，在同一宽高比下采用其支持的尽可能大尺寸。不得裁切、拉伸、补边或改变横竖画幅以适配尺寸。
- 保持机位、透视、构图、物体数量与位置、主要几何关系、身份、原有纹理尺度和原生清晰度。
- 水面、玻璃、镜面与抛光地面中的既有倒影/镜像关系同属场景锁定项。天气可改变其亮度、清晰度、破碎度或湿润度，但不得改变对应物的位置、方向、数量或把倒影重绘为新物体。
- 每位人物都是不可变主体锚点：保持人数、位置、姿态、朝向、遮挡、服装大色块及与道具的接触关系。不得把小、躺卧、处于阴影中或被部分遮挡的人重释为床品、草料或物体。
- 叶片、灌木、草、毛发、碎石、沥青、水面等高频材质均为保护区。只允许宽阔、低频的明度、色温、大气、湿润度与覆盖变化。
- 不得用新增或强化的微结构表现天气/光线：禁止重复纹理、条纹、网格、浮雕纹、白色噪点、过度锐化、假边缘、合成颗粒及原图不存在的细节。
- 若某效果必须依靠新增纹理才可见，降低或取消该效果。不要靠延长负面提示词“修复”失败图。
- 底图已满足目标状态时，选择不生成或极轻的成片调整；不要为了显示变化而强行生成。

## 提示词组装顺序

提示词保持简洁，按以下顺序组织，避免堆叠形容词：

```text
用途：场景光影/天气编辑（lighting-weather）
输入图：编辑目标
输出画布：严格保持原图宽高比；若工具支持，使用原图精确像素尺寸 W×H；否则使用该比例下工具允许的最大尺寸，不裁切、不拉伸、不补边
场景锁定：机位、构图、几何、人物锚点、保护材质
观看路径：视觉锚点 + 次级信息 + 允许退后的区域
物理状态：室内/室外逻辑 + 时段 + 天气 + 光源方位 + 已通过的兼容关系
光照计划：一个主要有动机光源、明暗层级、允许的实用光/反射光
成片：摄影作品版或影视剧照版；仅调用选定参考卡的有效特征
约束：保护区仅允许低频变化
避免：仅列出本图相关的失败类型
```

直接图像编辑前先检查底图；每个不同目标状态单独生成一个版本；以非破坏方式保存。不得承诺像素级保真；一旦可见区域被错误重绘，判为不通过。

## 验收门（Acceptance Gate）

只有同时满足以下全部条件才可交付：

1. 目标状态通过物理关联证据识别，而不是靠滤镜。
2. 输出宽高比与原图一致；工具支持原图尺寸时，实际像素尺寸为原图精确 `W×H`，否则为该比例下工具允许的最大尺寸，且无裁切、拉伸、补边或画幅改变。
3. 每个可见光源都有可信的来源、方向、遮挡关系和受光表面。
4. 关键叙事信息在所选曝光模式下仍可读。
5. 机位、构图、场景身份及既有倒影/镜像关系保持锁定；成组变体使用同一补全母版。
6. 每位可见人物保持经审计的人数、姿态、位置、遮挡和与道具的接触关系。
7. 视觉锚点仍是首要观看对象；光效、实用光和天气不抢走其优先级。
8. 保护材质保留原图细节尺度，不出现假高频纹理。
9. 成片处理改善层级或氛围，不产生 HDR 式平均亮度、无逻辑的全局色滤或无必要特效。

出现重复纹理、无法解释的白噪点、道路/水面花纹、被锐化或变粗的植被、信息密度改变、无动机的新光源，或把雪/雨/雾当作均匀屏幕叠加时，立即拒收。
