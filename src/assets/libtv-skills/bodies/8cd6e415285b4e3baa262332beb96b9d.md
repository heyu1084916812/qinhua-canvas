# S+ 短剧质量评分器 · 七维红线诊断

> 把一集/一部短剧丢进来，30 秒内告诉你——能不能火、卡在哪、怎么改。 适用：短剧编剧、制片、平台初审、AI 短剧创作者。 来源：经 40+ 版本迭代、6 部实战剧本 + 多平台拒稿复盘校准的评分标准。

## 输入

短剧剧本（单集或整部，纯文本即可）。

## 输出

1. 总分（100 分制）+ 等级（S+ / S / A / B / C）
2. 七维度得分明细
3. 零容忍红线是否触发（触发即单项 0 分）
4. 逐条修改建议（按优先级）
5. 对标爆款差距分析

## 评分流程（三道关）

- 第 0 关 数据完整性 → 缺集/空集/占位符 = 评分作废
- 第 1 关 硬指标零容忍 → 逐集检查，硬伤单集直接 0 分
- 第 2 关 七维内容评分 → 100 分制加权
- 第 3 关 对标爆款终审 → 与市场标杆比对，防虚高

## 零容忍红线（触发 = 该维度 0 分）

1. 前 3 秒死刑：第 1 集开篇 3 秒无视觉冲击/爆点/情绪钩子
2. 三集主线未交代：第 3 集结束仍不知"这剧讲什么"
3. 剧情逻辑硬伤：时间线倒流 / 人物关系矛盾 / 设定互斥
4. 对话逐字重复：同一人物台词跨集逐字复现 ≥2 次
5. 无源事件：引用正文从未演出的前情
6. 题材漂移：成片题材与立项承诺交集 &lt;50%
7. AI 味标记残留：交付稿残留 📊😭🔥 等标记
8. 中后段节奏乏力：EP50 后连续 5 集以上无重大冲突

## 七维评分（100 分制）

维度满分S+ 锚点第一集开篇抓人15前 3 秒视觉冲击 + 矛盾推到顶点快节奏与主线交代153 集内交代主线/人物/矛盾/钩子剧情流畅与台词精炼15紧扣主线、口语化、不说废话积极向上10正能量，拒绝丧/黑深残下沉市场与强情绪20强共鸣 + 强反转 + 强信息差人设非黑即白15主角受气包/隐形大佬；反派坏无底线剧本逻辑10反转合理、前后自洽

木桶原理：最终分取最弱维度归一化分。

## 爽感密度硬要求

- 前 5 集 ≥2 个 L3+ 爽点（含 ≥1 个 L4）
- 前 15 集 ≥5 个，间隔 ≤3 集
- 全剧 85 集 ≥25 个 L3+，且 ≥1 个 L5

爽点分级：L1 微爽 → L2 小爽 → L3 中爽（大反转/身份揭露）→ L4 大爽（碾压式胜利）→ L5 极致爽（情感+正义+反转三重叠加）。

## 题材通过率红线（立项即筛）

- 苦大仇深（情感破防/校园霸凌/家庭创伤）&lt;30% → 一票否决
- 悬疑推理/现实题材 40-60% → 需强反转支撑
- 重生复仇/热血成长 70-85% → 实战通过
- 甜宠逆袭/战神回归/千金隐藏身份 80-90% → 下沉最稳

## 等级判定

S+ ≥85｜S 75-84｜A 65-74｜B 55-64｜C &lt;55

## 输出报告模板

```
【总评】XX 分 / X 级
【零容忍红线】触发：无 / 第X条
【七维明细】第一集开篇 X/15 …… 下沉市场 X/20 ……
【爽点密度】前5集 X 个 L3+ / 全剧 X 个 / 是否有 L5
【对标爆款】对标《XX》，差距：……
【修改建议】🔴高 🟡中 🟢低
```
