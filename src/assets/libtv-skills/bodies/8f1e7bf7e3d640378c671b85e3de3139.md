# 智能模型路由

## 这个 Skill 做什么

用户输入任意任务需求，Agent 自动判断当前任务最适合用哪个平台内置模型来完成，然后直接调用该模型执行，无需用户手动选择或确认。

## 判断逻辑

根据用户输入的任务类型，按以下规则选择模型：

### 图片生成类

- 写实风格、商业摄影感 → 优先选 **Seedream**
- 艺术风格、插画、概念图 → 优先选 **Midjourney**
- 通用图片生成、快速出图 → 优先选 **Lib Image**

### 视频生成类

- 高质量叙事视频、电影感镜头 → 优先选 **Seedance**
- 人物动作、肢体表现 → 优先选 **Kling**
- 开放风格、创意视频 → 优先选 **Wan**

### 文字类（写作、问答、代码、分析等）

- 使用平台内当前最优文本模型完成任务

### 判断不确定时

- 优先选通用能力最强的模型，直接执行，不打断用户

## 执行规则

1. 收到用户输入后，立即判断任务类型
2. 按上述规则选定模型
3. 直接调用选定模型执行任务，不询问用户是否同意
4. 任务完成后，在结果末尾简短注明使用了哪个模型（如"本次使用 Seedream 生成"）

## 约束

- 不拒绝任何任务类型，用户说什么就做什么
- 不要求用户提前说明想用哪个模型
- 不在执行前打断用户做确认
