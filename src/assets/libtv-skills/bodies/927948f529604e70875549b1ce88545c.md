# 爆款爽感饮料广告 20s

## 做什么

把“演员参考图 + 产品参考图”转成一支 **最终直出 20 秒视频** 的爽感饮料广告流程。注意：**生成广告符时，不要携带人物参考图和产品/道具参考图作为图片参考输入。** 广告符阶段只用文字信息和标准广告符样式参考来生成，避免模型把广告符误做成演员镜头板或产品分镜板。

严格分两段：

1. 用 **Seedream 5.0 Pro** 只生成两类静态策划资产：
   - **1 张 20s 标准化爽感广告符**（必须是像参考图1那样的**信息图 / 广告策略板**，不是分镜板，不是 keyframe 拼贴；**生成时不要携带演员参考图和产品/道具参考图**）
   - **1 张广告色卡**（像清透广告色卡参考图那样，色值与命名清晰）
2. 用户确认资产后，再整理成 **结构化 Seedance 2.5 广告提示词**，并调用 **Seedance 2.5** 直接输出 **20 秒商业广告视频**。

## 最重要的板式要求

### 广告符必须像“参考图1”

广告符应该是：

- **标准化中文信息图式广告符**
- 类似“爆款饮料广告四步五感万能公式”那类 **提案板 / 结构板 / 创意板**
- 重点是：**统一结构、时间阶段、五感逻辑、爽感卖点、品牌传播逻辑**
- 可以有：字幕、广告词、标题、副标题、说明文案、公式语、口号

广告符**不应该**是：

- 图2那样的 **五张镜头卡 / 故事板 / 关键帧卡片拼贴**
- 不是一个个具体镜头画面截图的组合
- 不是把 20 秒完全锁死成固定画面

如果生成结果更像图2而不是图1，视为失败，必须重做。

## 需要什么输入

最低必须有：

- **演员参考图** 1-4 张：男或女均可；至少一张正脸或 3/4 角度清晰图，用于锁定人物身份、发型和气质。
- **产品参考图** 1-5 张：至少一张包装正面清晰图，用于锁定包装、Logo、口味、主色、材质。
- **品牌名 / 产品名 / 口味**。
- **广告语 / slogan**（如没有，可先协助拟 2-3 个方向供用户选）。

可选：核心卖点、场景偏好、投放平台、目标人群、包装类型、画幅。默认：**16:9、Seedream 5.0 Pro、Seedance 2.5、20s、强BGM、强音效、自然连续广告表演**。

若演员图或产品图信息不足，先指出问题并要求补图；不要跳过验证直接生成。

## 怎么做

严格执行以下状态机：

`collect_inputs -> validate_refs -> lock_identity -> build_direction -> generate_ad_board -> generate_palette -> self_qc -> awaiting_asset_approval -> revise_assets | build_seedance_prompt -> final_video_generation -> video_qc -> done`

### 1. 锁定演员与产品

- 先锁定 **演员身份**：脸型、五官比例、发型、年龄感、体型和核心穿搭保持稳定。
- 再锁定 **产品身份**：包装轮廓、材质、Logo 区域、口味标记、主配色、关键图案和品牌名保持稳定。
- 多张图冲突时，要求用户指定主参考图。
- 不擅自改写包装文案，不虚构功效或法规敏感卖点。

### 2. 建立统一方向

把演员、产品、口味和场景偏好收束成一个统一的爽感广告方向。默认视觉语法：

- 清透、明亮、通透白场 / 浅色高键环境
- 高饱和但干净
- 真实透明冰块、细密气泡、冷凝水珠、清晰液体折射
- 水花要炸，但边缘干净
- 可用水果切片提示口味
- 产品始终是品牌视觉核心
- 演员负责提升代入感，不遮挡产品核心包装信息

### 3. 只生成两张静态资产

严格使用 **Seedream 5.0 Pro**，且只生成以下两张图：

A. 20s 标准化爽感广告符（16:9）

生成一张类似参考图1的 **中文信息图式爽感广告符**。

**输入规则：广告符生成阶段不要携带任何演员参考图、产品参考图或其他道具参考图作为图片条件。** 只允许使用：

- 用户填写的品牌名、产品名、口味、广告语、卖点等文字信息
- 标准化广告符样式参考

这样做的目的，是避免广告符被模型误解成‘演员镜头拼贴’或‘产品故事板’。

要求：

- 必须是 **标准化结构板**，不是故事板
- 推荐使用 **4栏或5栏的统一模块结构**
- 适配 **20 秒广告逻辑**，例如：
  - 0s-3s 感官炸弹
  - 3s-6s 价值特写
  - 6s-11s 爽感回馈
  - 11s-15s 心智定格
  - 15s-20s 品牌收口
- 必须尽量采用类似参考图1的标准信息架构：
  - 顶部大标题
  - 每个阶段顶部清晰时间标签（如 0s-3s / 3s-6s / 6s-11s / 11s-15s / 15s-20s）
  - 每栏主标题 + 副标题 + **3-5条 bullet 卖点/节奏说明**
  - 产品视觉元素（冰块、水花、杯体/罐体/瓶体、水果）
  - 可加入演员参与提示，但不要变成演员镜头卡片
  - **底部必须尽量包含一条“公式/总结条”**，如“动态冲击 + ASMR声音 = 爆款饮料广告”
  - **底部必须尽量包含“五感总结区/五感信息条”**，即视觉、听觉、触觉、味觉、嗅觉五个小模块
- **文字必须尽量清晰**，可以包含字幕、广告词、口号、说明文案，不做过多限制

B. 广告色卡（1:1 或 4:5）

生成一张类似清透广告色卡参考图的 **广告色卡**：

- 8-14 个色块较合适
- 每个色块需尽量包含：**HEX 值 + 英文色名 + 中文说明**
- 色彩来源于产品包装、口味水果、环境光、演员肤色/服装辅助色、品牌重点色
- 版式必须干净、可读、提案感强

### 4. 图片自检

在给用户看之前，按以下标准自检：

爽感广告符检查

- 是否明确接近 **参考图1的广告策略板 / 信息图风格**。
- 是否避免了 **图2式 storyboard / 镜头卡片拼贴**。
- 是否明确是 **20 秒** 而不是 15 秒。
- 文字是否足够清晰，主标题和阶段标题必须可读。
- 是否具备专业广告提案感，而不是廉价海报。
- 是否体现产品、五感、爽感逻辑和品牌传播结构。
- **是否包含每个阶段对应的节奏卖点文字/bullet 文案。**
- **是否包含底部公式条/总结条。**
- **是否包含底部五感总结区（视觉、听觉、触觉、味觉、嗅觉）。**
- 可以有广告词和字幕，不必刻意禁止。

广告色卡检查

- 色块数量是否合适。
- HEX、色名、中文说明是否尽量清晰。
- 颜色是否真的服务于广告，而不是随意采样。
- 是否体现“清透、高级、爽感”。

如果广告符更像图2，就必须重做；不要直接交给用户。

### 5. 强制用户确认资产

静态资产完成后必须停下来，只向用户确认以下 **4 项最终资产基础**：

1. **演员参考图**（供视频阶段使用）
2. **产品参考图**（供视频阶段使用）
3. **20s 标准化爽感广告符**（由文字信息生成，不携带人物/道具参考图）
4. **广告色卡**

明确询问：

**“请确认本次视频资产是否最终成立：演员参考图 / 产品参考图 / 20s 标准化爽感广告符 / 广告色卡。确认后我将输出结构化 Seedance 2.5 广告提示词，并直接生成 20 秒视频。”**

只有用户明确表达“确认 / 合格 / 继续 / 生成视频 / proceed / approved”等继续意图，才可以进入视频阶段。

### 6. 修改资产

如果用户要求修改：

- 优先提炼明确 delta，例如：
  - 广告符更像参考图1那样标准化
  - 产品更放大
  - 广告符更炸爽 / 更清透
  - 色卡更偏蓝紫 / 更偏果味橙黄
  - 文字需要更清晰
  - 口号更强
- 只重做受影响资产；不要擅自新增 keyframe。
- 修改后再次自检，并再次请求用户确认。

### 7. 构建结构化 Seedance 2.5 广告提示词

用户确认资产后，再构建 **结构化 Seedance 2.5 广告提示词**。提示词至少应包含这些模块：

1. **目标与成片规格**

   - 20s
   - 16:9
   - 高质量商业饮料广告

2. **演员锁定**

   - 明确演员外貌、发型、气质与服装参考优先级

3. **产品锁定**

   - 明确包装、Logo、主色、口味、材质与图案稳定

4. **视觉风格**

   - 清透、冰爽、高级、真实液体、真实冰块、冷凝水珠、细密气泡、商业棚拍光感

5. **20 秒镜头节奏**

   - 0-3s 感官炸弹
   - 3-6s 价值特写
   - 6-11s 爽感回馈
   - 11-15s 心智定格
   - 15-20s 品牌收口

6. **表演与连续性**

   - 演员动作自然
   - 镜头推进有逻辑
   - 饮用动作、拿取动作、反馈动作自然连续
   - 不木讷、不摆拍、不像AI模特

7. **音乐与音效**

   - 必须明确：**强 BGM + 广告音效设计**
   - 背景音乐默认：清爽、年轻、现代、具有节奏推进感的广告音乐，可更有感染力，不要过弱
   - 音效默认：开罐 / 气泡 / 冰块碰撞 / 水花 / 倒饮料 / 吞咽或清爽呼气等 ASMR 爽感音效
   - 音频节奏要配合画面起伏

8. **文案与字幕**

   - **允许有字幕、广告词、品牌口号、收口文案**
   - 不必过度限制
   - 以增强广告传播和品牌记忆为目标

### 8. 调用 Seedance 2.5 直接生成 20s 视频

只在资产确认后，使用 **Seedance 2.5**。

参考优先级：

`产品参考图 > 演员参考图 > 标准化爽感广告符 > 广告色卡`

补充说明：**上述优先级只适用于视频生成阶段。广告符生成阶段不使用演员参考图和产品/道具参考图。**

成片要求：

- **直接输出 20s 完整视频**
- **必须有明显 BGM**
- **必须有广告音效**
- **广告表演自然、连续、可信**
- **允许有字幕 / 广告词 / 品牌口号**

### 9. 视频自检

交付前检查：

- 演员身份是否稳定
- 产品包装是否稳定、Logo 是否可认
- 镜头节奏是否覆盖完整 20 秒结构
- 音乐与音效是否存在且足够明显
- 视频是否自然连续，不木讷、不割裂
- 是否具备广告词 / 文案的品牌传播感（若适合）
- 最后 2-3 秒是否足够稳定，便于品牌记忆落版

## 产出什么

本 Skill 的最终交付分为两阶段：

### 阶段一：确认资产

- 演员参考图（用户输入）
- 产品参考图（用户输入）
- **20s 标准化爽感广告符** 1 张
- **广告色卡** 1 张

### 阶段二：确认后直出

- **结构化 Seedance 2.5 广告提示词** 1 份
- **20s 16:9 最终视频** 1 支
  - 有强 BGM
  - 有广告音效
  - 可有字幕 / 广告词 / 口号

## 什么时候问你

必须停下来问用户的情况：

- 缺少关键演员图或产品图。
- 多张参考图冲突，无法判断主参考。
- 广告符不够像参考图1，反而更像图2。
- 广告符阶段误带入了演员参考图或产品/道具参考图，导致画面变成镜头拼贴。
- 广告符缺少阶段节奏文字、底部公式条或五感总结区。
- 广告符或色卡文字不清晰，需要决定是否重做。
- 静态资产已完成，需要用户确认四项最终资产。
- 用户想改方向，但没有说清修改点。
- Seedream 5.0 Pro 或 Seedance 2.5 当前不可用；不要偷偷换模型。
