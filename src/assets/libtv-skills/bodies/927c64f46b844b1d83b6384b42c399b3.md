# Skill名称

一键生成大剧开关板（Drama Opening & Closing Package Generator）

---

# Skill目标

根据用户提供的大剧海报、品牌Logo和画面尺寸，自动生成完整的大剧开关板视觉资产。

输出：

1. 背景底图
2. 开板图
3. 关板图
4. 开板视频
5. 关板视频

核心目标：

基于原海报进行视觉延展和品牌包装。

不是重新设计画面。

必须最大程度保持原海报：

- 光影方向
- 色彩关系
- 材质质感
- 空间结构
- 视觉风格
- 氛围元素

---

# 模型规范

## 图片生成模型

必须使用：

Lib Image

生成：

- 背景底图
- 开板图
- 关板图

---

## 视频生成模型

必须使用：

Seedance 2.0 VIP

生成：

- 开板视频
- 关板视频

---

# Prompt语言规范

所有生成提示词：

必须使用中文。

要求：

- 描述准确
- 指令明确
- 避免二次创作
- 避免重新设计

---

# 用户输入

## 1. 画面尺寸

用户提供：

例如：

1920\*1080

尺寸为最高优先级。

所有输出：

必须严格等于用户提供尺寸。

禁止：

- 修改比例
- 自动裁切
- 自动适配
- 生成其他尺寸

---

## 2. 大剧Logo

要求：

- 使用用户提供Logo
- 保持原始结构
- 保持原始比例
- 保持品牌识别
- 不重新设计Logo

---

## 3. 大剧海报

用于分析：

- 原始画面结构
- 光影方向
- 色彩关系
- 材质质感
- 空间关系
- 视觉氛围

---

# 背景生成规则

## 背景唯一原则

整个项目只生成一张背景底图。

后续：

- 开板图
- 关板图
- 开板视频
- 关板视频

全部必须使用同一张背景。

禁止：

- 重新生成背景
- 修改背景
- 替换背景
- 改变空间结构

---

# 背景生成提示词

基于原海报进行视觉延展：去掉画面中所有人物、人脸、身体轮廓、所有文案水印信息，保持原画面的光影方向、色彩关系、材质质感和空间结构完全不变，补全人物位置区域，使画面呈现完整的无人纯背景场景，整体风格与原海报一致，阴影不要过重，不要有AI感觉。

---

# 人物和文字清理规则

生成前必须删除：

- 所有人物
- 人脸
- 身体轮廓
- 人物剪影
- 原海报Logo
- 标题文字
- 所有文案
- 水印
- 平台信息

最终背景：

必须为无人纯背景。

---

# 输出1：背景底图 Background

模型：

Lib Image

输入：

原海报。

生成：

1张背景底图。

要求：

- 严格使用用户尺寸
- 去除人物
- 去除Logo
- 去除文案
- 保留原画面光影
- 保留原画面材质
- 保留原画面空间

输出：

Background.png

该背景作为后续所有资产唯一背景。

---

# 输出2：开板图 Opening Board

模型：

Lib Image

输入：

唯一背景底图。

生成：

1张开板图。

## 画面结构

### Logo规范

Logo位于：

画面视觉中心。

要求：

- 水平居中
- 垂直居中
- 保持原始比例

Logo尺寸：

约占画面宽度40%。

要求：

- Logo为最大视觉主体
- 清晰突出
- 不缩小
- 不偏移

---

### 按钮规范

Logo下方放置按钮。

按钮位置：

- 与Logo保持同一中心轴
- 水平居中
- 固定间距

按钮文字：

「精彩时刻」

按钮设计：

根据背景视觉生成。

要求：

具有：

- 与海报一致的材质
- 与海报一致的光影
- 与海报一致的质感

禁止：

- 普通UI按钮
- 电商按钮
- 模板按钮

---

# # 输出3：关板图 Closing Board\
模型： Lib Image\
输入： 开板图作为唯一基础垫图。 \
生成方式： 在开板图基础上进行修改。\
 修改规则： 仅修改按钮文字内容。\
 开板： 「精彩时刻」 替换为： 关板： 「精彩继续」 \
除此之外： \
必须保持完全不变： - 背景不变 - 光影不变 - 色彩不变 - 材质不变 - 构图不变 - Logo不变 - Logo大小不变 - Logo位置不变 - 按钮造型不变 - 按钮大小不变 - 按钮位置不变 - 按钮质感不变 禁止： - 重新生成背景 - 重新设计按钮 - 重新调整Logo - 改变画面风格

---

# 输出4：开板视频 Opening Animation

模型：

Seedance 2.0 VIP

规格：

时长：

4秒

尺寸：

严格使用用户输入尺寸。

输入：

- 同一背景底图
- 同一Logo
- 同一按钮

---

# 开板视频动画规则

## 第一帧规则

视频开始第0秒：

以下元素必须同时存在：

- 背景
- Logo
- 「精彩时刻」按钮

禁止：

- 背景先出现
- Logo后出现
- 按钮后出现

---

## Logo动画

Logo：

从第一帧开始存在。

动画：

- 轻微缩放进入
- 光线扫过Logo
- 边缘柔和发光
- 微弱呼吸感

要求：

保持Logo结构不变。

---

## 按钮动画

按钮：

与Logo同步出现。

动画：

- 材质高光变化
- 边缘光出现
- 轻微浮现

保持：

- 固定位置
- 固定大小
- 中心对齐

---

## 背景动画

背景：

保持原画面一致。

只允许：

- 光影流动
- 氛围变化
- 微粒运动

禁止：

- 改变场景
- 添加新元素
- 改变构图

---
