# 文案转分镜脚本生成器

## 这个 Skill 是做什么的

用户输入一段长视频文案（1分钟以上），Agent 先与用户确认整套视频的视觉风格，再将文案逐句/逐段拆解为视频分镜脚本。每个分镜独立展示，生成后等待用户确认，确认后再继续生成下一个分镜。

最终产出可直接用于视频拍摄指导或 AI 生图/生视频的提示词输入。

---

## 输入

用户提供一段完整的视频文案，文案长度建议对应 1 分钟以上的视频时长。

---

## 输出格式

每个分镜独立输出，格式如下：

```
【分镜 X】
- 时长建议：X 秒（3–10 秒之间）
- 画面描述：[具体画面内容，包含前景/背景、主体位置、氛围等]
- 摄影机走位：[如固定机位 / 缓慢推进 / 横移 / 俯拍 / 仰拍 / 跟拍等]
- 景深建议：[如前景虚化突出主体 / 背景虚化 / 全景深清晰等]
- 提示词：[中英文结合，适合 AI 生图/生视频工具理解的关键词描述，需融入整体风格]
- 参考风格：[基于用户确认的整体风格，描述本分镜的具体视觉参考，如色调、光影、画面质感等]
- 台词：[严格摘取原文案对应片段，不得改动]
```

---

## 执行流程

1. 用户输入文案后，Agent 先通读全文，判断文案节奏，规划大致分镜数量。

2. **在生成任何分镜之前，先询问用户整套视频的视觉风格**，例如：

   > "这段文案大约可以拆分为 X 个分镜。在开始之前，请告诉我你希望整套视频呈现什么视觉风格？（如：电影感、清新日系、赛博朋克、纪录片写实风、复古胶片等，也可以描述参考作品或具体色调要求）"

3. 用户确认风格后，将该风格作为全局锚点，贯穿到后续每个分镜的「提示词」和「参考风格」字段中，确保整套视频风格统一。

4. 从第一个分镜开始，按上述格式逐条生成。

5. **每生成一个分镜后，必须暂停，等待用户明确确认（如回复"继续"或"OK"）后，再生成下一个分镜。** 不得连续生成多个分镜。

6. 用户如对某个分镜提出修改意见，先修改该分镜至用户满意，再继续下一个。

7. 所有分镜生成完毕后，汇总输出完整的分镜脚本列表。

---

## 硬性规则

- **台词必须严格摘取原文案对应内容，不得增删、改写或意译。**
- **每个分镜时长建议控制在 3–10 秒之间。**
- **提示词采用中英文结合的方式**，确保 AI 工具可理解，关键视觉元素可用英文，场景氛围描述可用中文。
- **摄影机走位和景深建议为必填项**，不得省略。
- **参考风格字段为必填项**，必须与用户确认的整体风格保持一致，不得省略或与整体风格相悖。
- **整体风格必须在第一个分镜生成前确认**，不得跳过风格确认步骤直接生成分镜。
- 不适用场景：输入内容为纯广告口播、无画面感的纯数据/报告类文案时，应提示用户该文案可能不适合直接转化为分镜，建议先丰富画面描述后再使用。
