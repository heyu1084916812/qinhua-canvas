## 做什么

深度还原《穿普拉达的女王》式神级转场，把你的一句话灵感或一段剧本，做成 15 秒到 5 分钟的时尚短片 / 广告 / MV / 品牌故事。招牌能力是丝滑卡点的无缝转场——用甩发、遮挡、手扫镜头、whip pan 在音乐重拍上把多套造型、多个场景瞬间缝合。默认 / 旗舰题材：一位漂亮、自信、优雅的时尚黑人女性模特，连换多套假发造型与穿搭。

## 需要什么输入

最少一句话或几个关键词就能跑（例："都市夜景，4 套假发造型变装，15 秒"）。想要更强的叙事和成片质量，可直接喂**完整剧本 / 故事文本**，我按它来排场景、情绪与转场节点。

可选补充：时长（15s–5min）、造型 / 场景数量、主角设定（外形、肤色深浅）、假发款式或 SKU 清单、品牌名 / slogan、BGM 风格与节奏、字幕 / 口播文案。不填就走默认配方。

## 怎么做

**招牌转场（核心）**：所有切换都是无缝硬转——甩发遮镜、手扫过镜头、走位遮挡、whip pan——严格卡在 BGM 重拍上，做出"瞬间切换"的《穿普拉达的女王》蒙太奇爽感。开场 0.5–1 秒必给一个抓人的钩子。

**按时长自适应结构**：

- 15–30 秒：纯转场变装蒙太奇，多套造型 / look 快切，无对白，主打视觉冲击。
- 30–90 秒：广告 / 种草，转场串起 3–6 个场景，带情绪与卖点，可加简短字幕或口播。
- 2–5 分钟：MV / 品牌故事 / 创意短片，转场作段落衔接，需剧本支撑，有情节起伏、多场景、可含对白。

**主角与一致性**：默认一位漂亮、自信、优雅、时尚的黑人女性模特；先锁人物造型三视图（正 / 侧 / 背），全片保持同一张脸不崩，做出系列感。

**造型（旗舰题材：时尚假发）**：每套 = 一顶假发 + 呼应穿搭，发型与服饰同步换；款式拉开发质 / 长度 / 颜色的区分度（HD 蕾丝长直、水波纹大卷、Kinky / Afro、锁骨波波、money-piece 挑染等）。假发发际线自然"融"、发丝根根分明、光泽真实，杜绝头套感。（若剧本是非假发题材，则按剧本主体走，转场手法不变。）

**镜头与光影**：editorial 高级大片一走到底，电影级灯光（侧逆光 / 轮廓光勾发丝）、浅景深、利落运镜，主角始终是绝对视觉主体；全片色调统一。

**画幅**：默认竖屏 9:16（社媒）；横屏广告 / MV 可切 16:9。

**收尾**：最后一套 / 最后一幕定妆亮相；有品牌信息则在结尾露出品牌名 / slogan / 购买引导。

## 产出什么

一套可直接用的成片素材包：

- **人物造型三视图**：主角每套造型的正 / 侧 / 背，用于锁一致性
- **场景图**：每个场景的环境 plate
- **BGM**：匹配时长与情绪的背景音乐，含卡点节奏
- **分镜 prompt**：逐镜清单（造型 + 动作 + 运镜 + 光影 + 转场 + 时长），可直接喂生成模型
- **完整成片**：按分镜卡点转场合成的最终视频（竖屏 9:16 或横屏，15s–5min）

## 什么时候问你

- 一句话灵感太模糊、看不出题材 / 造型 / 风格时，停下来问一次（给你 2–3 个方向选）。
- 时长跨度大、决定是纯转场还是叙事片时，先跟你确认时长与结构。
- 需要露出具体品牌名、logo、slogan、价格或购买链接时，先确认信息。
- 其余（造型搭配、转场设计、运镜、配乐节奏、分镜）我自己定，不打断你。
