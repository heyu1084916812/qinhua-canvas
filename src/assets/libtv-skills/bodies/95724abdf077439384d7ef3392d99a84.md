# 云上万阙｜天庭导演

## 目标

把人物、城市、风景或一句场景主题，转化为明亮暖金、巨构微人、浓雾光海的中式九重天宫关键画面，并在关键帧通过验收后生成 5 秒短视频。

这套 Skill 不照搬某一张参考图。它提取并重组空间关系、建筑尺度、云海层次、光线逻辑和镜头语言；建筑纹样、人物身份、城市材质与叙事氛围根据用户输入重新设计。

## 一、四套核心方法

### 1. 巨构尺度对比

- 建筑、神树或巨柱占据画面主体，并被画面顶部和左侧或右侧裁切，产生“镜头装不下”的压迫感。
- 人物只作为尺度标尺，通常放在画面下方平台、栏杆或台阶附近；保持完整身体和自然间距，不做半身裁切。
- 至少建立三层空间：前景巨构遮挡层、中景平台与人物层、远景云海与天宫层。
- 如果建筑完整而舒服地缩在画框中，巨物感就会消失，需要重新生成。

### 2. 分层雾光系统

雾不是装饰，而是连接建筑、光线与空间纵深的介质。默认检查四层：

1. 地面雾：珍珠白低雾横向流过镜面平台，包裹柱脚和树根。
2. 建筑内雾：薄雾穿过斗拱、檐下和柱间，让体积光可见。
3. 中远景云海：翻涌云层吞没下层建筑与平台边缘。
4. 天空云层：浅蓝天空中仍有清晰、有体积的云，不使用空白渐变天。

主光通常来自画外低角度的左后方或右后方。暖白阳光擦过建筑，香槟金轮廓光只落在真实凸起、雕刻边缘、龙鳞、斗拱和叶脉上；浅蓝天空与珍珠白云海提供冷色环境补光。镜面地面同时反射天空、云雾、人物、建筑和暖金光带。

### 3. 城市天宫化

城市改造成天宫时，先锁定辨识度，再改变材质与附属结构。

必须保留：

- 地标的原始轮廓、位置和数量。
- 城市的横向轴线，例如黄浦江、塞纳河或纽约港。
- 城市密度节奏，例如巴黎低矮屋顶线与纽约垂直高楼群的差异。
- 地标特征，例如东方明珠球体、世贸中心的收尖轮廓、埃菲尔铁塔的桁架、自由女神的七芒冠与火炬姿态。

可以改变：

- 钢与玻璃改为黑金骨架、珍珠晶体与香槟金结构肋。
- 河流改为镜面天河，但宽度、方向和相对位置不变。
- 城市上方加入云桥、飞檐、云海、低雾与金色轮廓光。

如果不熟悉这座城市的人也无法认出地标，说明转换失败；不要用通用宝塔替换所有建筑。

### 4. 可验收的运动设计

提示词不能只写“缓慢推进”或“电影感运镜”，还要写清观众最后能看到什么。

万丈云廊｜向前推进

- 18mm 超广角、低机位，镜头沿长廊中轴向前推进。
- 最近的巨柱在前段明显向画面两侧移动，并在约 2 至 3 秒退出画面。
- 中景柱列依次放大，远处日轮门持续变大，形成近快远慢的视差。
- 三名微小人物背对镜头向前行走，至少完成两次自然步态；脚必须接触地面。
- 近处地雾横向流动，中景雾较慢，远处云海最慢。
- 避免电子变焦、镜头摇晃、人物倒滑、远云冻结和建筑变形。

檐下云台｜右移并轻推

- 镜头沿栏杆向右横移，同时轻微向前。
- 前景屋檐和巨柱移动最快，中景宫殿较慢，远处云海最慢。
- 人物沿栏杆向右行走，方向与镜头关系明确。
- 雾从建筑内部流向云海边缘。
- 屋檐、斗拱和柱体保持绝对刚性。

琼树云台｜环绕神树

- 镜头围绕象牙金色神树做小幅顺时针环绕并轻推。
- 左侧巨柱、神树主干和远处宫阙形成清晰视差。
- 细叶持续小幅起伏，粗壮主干和根系保持不动。
- 坐姿人物只做转头、衣袖轻摆等微动作，不站起、不融合。

垂天神榕｜沿台阶上升

- 镜头沿白玉阶向前并向上推进。
- 下方台阶退出画面，巨大树根向侧面掠过，上方树冠逐渐放大。
- 单人背对镜头向上攀登，5 秒内真实跨过 2 至 3 级台阶。
- 垂根以不同幅度轻摆，不能同步摆动，也不能变成电缆或头发。

## 二、输入理解

用户至少提供以下一种输入：

- 一张人物、城市或风景参考图；或
- 一句场景主题。

可选信息：人物数量与身份、服装造型、场景预设、画幅、镜头运动、只要关键帧还是关键帧加视频。

缺省规则：

- 人物参考：保留脸部身份，替换为原创天宫服装和头饰；除非用户要求人物特写，否则人物缩为场景中的尺度标尺。
- 城市参考：锁定地标轮廓、位置和数量，只改材质、云雾、附属结构与光线。
- 风景参考：保留地形轮廓，把道路转成云桥、谷地转成云海。
- 无参考图：使用本 Skill 的视觉规律原创构图。

生成前先决定：前景巨构是什么、人物放在哪里、雾从哪里进入、主光来自哪一侧。

## 三、关键帧生成

### 通用中文提示词模板

【镜头】18mm 或 20mm 超广角，低机位，三分之四视角。

【前景】一根巨大的【柱体／树干／屋檐】从画面顶部和【左侧／右侧】切入并超出画框，材质为【材质】，表面有原创【纹样】，形成镜头装不下的巨构尺度。

【中景】镜面【平台／长廊／白玉阶】延伸进云海；【人物数量】名微小人物在画面下方【动作】，完整身体可见，人物之间保持自然间距，只作为尺度参照。

【远景】多层云海、远处宫阙、云桥和【天瀑／浮岛】依次退入大气透视，远景轮廓逐层变淡。

【云雾】珍珠白地面低雾包裹柱脚；薄雾穿过斗拱和柱间；中远景翻涌云海吞没下层结构；浅蓝天空中仍有清晰体积云。

【光线】画外【左后方／右后方】低角度暖白太阳穿过云雾；香槟金轮廓光只沿真实雕刻凸起、斗拱边缘和叶脉产生；浅蓝天空与珍珠白云海提供冷色环境补光。

【材质与色彩】象牙白、香槟金、暖金、浅铜、少量朱红、珍珠白云雾、清透浅蓝天空；镜面地面反射建筑、人物、云雾、天空和暖金光带。

【避免】阴影中出现青绿或蓝绿色污染；橙黑滤镜；整幅画面压暗；深靛蓝柱体；随机发光颗粒；结构呼吸、融化或变形。

### 城市天宫化追加模板

保留【城市／地标】的原始轮廓、相对位置和数量：画面中的【地标 A】仍位于【位置】，保留【关键轮廓特征】；【地标 B】仍位于【位置】，保留【关键轮廓特征】。只把现代钢材与玻璃转换为黑金骨架、珍珠晶体和香槟金结构肋；把【河流／港湾】转换为同方向、同宽度的镜面天河。加入浓雾光海、云桥和暖金轮廓光，但不能把城市改成无法辨认的通用中式幻想城。

### 默认图片模型

- 默认：Seedream 5.0 Pro。
- 规格：16:9，2K，1 张。
- 仅当地标辨识度不足时，才考虑用 Lib Image 做补救测试；不要默认替换 Seedream 5.0 Pro。

### 关键帧验收

生成视频前逐项检查：

- 巨构是否占据主体并被至少两条画面边缘裁切。
- 人物是否足够小、身体完整、位置自然。
- 前景、中景、远景是否清楚分层。
- 地面雾、建筑内雾、中远景云海、天空云层是否同时存在。
- 镜面地面是否真实反射人物、建筑、天空和光线。
- 金色是否只出现在真实凸起和反光位置。
- 整体是否明亮暖金，阴影是否没有青绿色污染。
- 柱体、树干、屋檐和台阶是否保持刚性。

任何一项失败，只修改最明显的一个变量后重新生成，不要同时改动构图、材质、光线和人物。

## 四、视频生成

只有关键帧通过验收后才进入视频阶段。

- 模型：Seedance 2.5 全能参考。
- 输入：已经通过验收的关键帧。
- 默认规格：5 秒，720P，16:9。

### 中文运动提示词模板

镜头使用【向前推进／右向横移并轻推／顺时针环绕／沿台阶上升】。5 秒内，最近的【巨柱／树根／屋檐／台阶】产生清晰可见的位移并在【具体时间】退出或掠过画面；中景【柱列／树干／平台】移动较慢；远处【日轮门／宫阙／云海】最慢但持续变化。人物【面向关系】向【方向】自然行走，至少完成【步态次数】次完整步态，脚掌接触地面，不倒滑、不漂浮。近处低雾移动最快，中景雾较慢，远处云层最慢。柱体、树干、屋檐、斗拱与台阶保持绝对刚性；只允许薄雾、叶片、细枝、衣袖和发丝做小幅连续运动。避免电子变焦、远云冻结、镜头无位移、人物月球步和结构变形。

### 视频验收

同时查看首帧、中间帧和尾帧：

- 近、中、远景是否以不同速度移动，空间视差是否可读。
- 人物方向是否正确，脚是否接触地面，是否出现倒滑或漂浮。
- 建筑、树干和台阶是否始终稳定。
- 三层雾与远云是否在运动，而且速度有差异。
- 亮度和色温是否稳定，是否出现青绿色偏移。
- 镜头是否保留关键帧构图，而不是重新改写场景。

失败时只定位一个主要问题：

- 空间视差弱：把镜头位移改成可见结果，例如最近巨柱在第 2 至 3 秒退出画面、远处日轮门持续放大。
- 人物倒滑：明确写出行走方向、背面或正面关系、完整步态和脚掌接地。
- 远景冻结：明确远云持续缓慢漂移，速度约为近处低雾的三分之一。
- 结构变形：明确柱体、树干、斗拱或台阶绝对刚性，雕刻细节锁定。

## 五、输出

默认输出：

1. 一张关键帧图片节点。
2. 一个对应的 5 秒视频节点。
3. 本次实际使用的中文关键帧提示词与中文运动提示词。
4. 验收结论：哪些项目通过，哪些项目需要只改一个变量后重跑。

如果用户选择多镜头模式，再按“建立环境 → 展示尺度 → 人物进入 → 史诗收束”的顺序生成 4 个镜头；每个镜头先验收关键帧，再生成视频。
