# 红蓝双色针管笔速写

把任意主体（日常小物、人物穿搭、场景，或用户上传的照片）画成"白色素描本纸面上的红蓝双色针管笔手绘速写"。

## 何时使用

- 用户说"用红蓝速写风画 XX""把这个照片转成红蓝手绘速写""复刻这个速写风格"。
- 需要手账感、清新简洁、大量留白的插画时。

## 两种用法

用法触发参考图A. 风格直出用户只给主体描述，没有照片只挂三张风格母图B. 照片转插画用户上传了照片同时挂三张风格母图 + 用户照片

两种用法共用同一套风格锚点，区别只在参考图数量和"保持原特征"那一段。

## 风格锚点（固定不变，逐条写进 prompt）

1. **载体**：白色素描本纸面，纸张质感微微可见。
2. **工具**：红蓝双色针管笔（fineliner）手绘。
3. **线条**：随性、略带抖动的蓝色单线勾勒轮廓，不追求工整。
4. **红色用法**：只做局部点缀与阴影排线（腮红、饰品、衣褶、暗部），不做大面积红。
5. **上色**：仅用红蓝两色局部平涂，**大量留白，不涂满**。
6. **文字标注**：手写英文标题，字体随性可爱；红色手写箭头指向画面重点。
7. **气质**：简洁、清新、有手账速写感。

## 用法 A：风格直出

1. 建一个图片节点，挂上三张风格母图。
2. prompt 模板：

```
在白色素描本纸面上的手绘速写，红蓝双色针管笔风格。画面主体是【主体描述】，用随性略带抖动的蓝色单线勾勒轮廓，红色线条做局部点缀和阴影。仅用红蓝两色局部平涂，大量留白，不涂满。旁边有手写英文标题 "【英文标题】" 和红色手写箭头标注，字体随性可爱。整体风格简洁、清新、有手账速写感，纸张质感微微可见。参考图风格：{{风格母图}}
```

3. 槽位：
   - `【主体描述】`：要画的东西，越具体越好（例：一杯珍珠奶茶，带透明塑料杯、杯盖、粗吸管，杯中可见黑色珍珠）。
   - `【英文标题】`：手写英文标题（例：Bubble Tea）。
   - 若主体是人物穿搭，在主体描述后补一句：人物周围有手写英文标注和红色手写箭头指向各件单品，如 "cardigan"、"pleated skirt"、"canvas shoes"，字体随性可爱。

## 用法 B：照片转插画（主力用法，已验证）

1. 建一个图片节点，**同时挂三张风格母图 + 用户照片**。
2. prompt 模板：

```
将参考图中的人物/主体 {{用户照片}} 转换为红蓝双色针管笔手绘速写风格。

必须逐条保留原照片的关键特征：
1. 【特征 1，例：黑色双丸子头（两侧盘发），带齐刘海和鬓角】
2. 【特征 2，例：大眼睛圆睁，瞳孔看向斜上方，眉毛上挑，表情夸张兴奋】
3. 【特征 3，例：嘴巴张到极大，上排是一排尖锐的锯齿状三角牙，口腔深色】
4. 【特征 4，例：脸两侧和身体周围有多条弯曲的触手状肢体向外伸展飞舞】
5. 【配饰，例：戴银色圆环耳环】
6. 【服装，例：穿青绿色（teal）挂脖拉链背心，胸前有粉红色花卉刺绣图案，黑色拉链】
7. 【其他，例：手臂上有黑色绑带/臂环】
8. 【构图，例：人物为半身构图，双臂向两侧张开】

风格要求（参考 {{风格母图}}）：
- 在白色素描本纸面上作画，纸张质感微微可见
- 用随性略带抖动的蓝色针管笔单线勾勒人物轮廓、五官、头发和衣物
- 红色线条做局部点缀：口腔内部、花卉刺绣、耳环、衣物阴影排线、褶皱
- 仅用红蓝两色局部平涂，大量留白，不涂满
- 线条简洁有力，有手账速写感
- 人物居中，构图饱满
```

3. 关键：**"必须逐条保留原照片的关键特征"要编号逐条写实**——这是照片转插画最容易丢信息的地方。已验证三个成功案例（饺子脸女孩、锯齿女孩、图片节点 4）都靠这一步保住了人物神韵；只写"保持原人物特征"人物会被风格吞掉。

## 固定参数

- 模型：**Lib Image 2.5 Pro**
- 画面比例：**1:1**
- 生成数量：1 张
- 参考图权重：风格母图为主，照片为次（照片只提供主体特征，不提供画风）

## 常见坑

- 红色铺太多 → 破坏"大量留白"的手账感，明确写"仅局部点缀"。
- 线条太工整 → 失去手绘随性感，强调"随性、略带抖动"。
- 照片转插画时人物跑形 → 把原特征编号逐条写进 prompt，别只写"保持原人物特征"。
- 表情/夸张特征（锯齿牙、触手、夸张表情）最容易在转换中被"美化"掉，必须单独列条强调。
