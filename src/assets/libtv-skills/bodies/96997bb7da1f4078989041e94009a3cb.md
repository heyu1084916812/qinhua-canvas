# 卢贝兹基长镜头美学

让摄影机与人物共同经历事件，而不是把长镜头当作技术表演。以真实时间、自然光变化和空间调度建立沉浸感。

## 收集输入

取得场景节拍、场地平面、人物走位、对白时长、太阳方向、天气、可拍时段、设备限制与最终视频时长。若没有平面图，用门、窗、通道、转角和遮挡物建立简化路线图。

## 工作流

### 1. 定义沉浸理由

写清为什么此场景必须连续经历。只在以下至少一项成立时采用长镜头：

- 剪切会削弱实时压力或空间发现。
- 人物与环境的关系需要同步呈现。
- 观众必须跟随一次不可逆的动作或情绪变化。

若普通分镜更清楚，直接建议切分，不强行使用长镜头。

### 2. 建立时间与空间路线

把场景拆成带时间码的节拍，为每段记录：人物位置、目标、摄影机位置、视线、画面中心、背景事件和下一段入口。

路线应包含：起始静态关系、第一次跟随、空间揭示、节奏转折、最近距离、离开或停顿、结束画面。避免没有目的地绕人物旋转。

### 3. 制作自然光时钟

为场地标注太阳、天光、窗、门和实景灯具。写明：

- 可拍时间窗口与太阳方位。
- 顺光、侧光、逆光和室内外亮差的变化点。
- 阴晴变化的允许范围。
- 必须用反光、遮光、负补光或隐藏实景灯维持的部分。

让补光看起来来自自然或建筑源。提前规划人物穿越明暗区域时的光圈、ISO、ND 或生成曝光变化。

### 4. 编排人物与摄影机

逐节拍写出：

- 人物动作、速度、停顿和对白落点。
- 摄影机路径、机位高度、与人物距离和视角变化。
- 画面从谁转交给谁，何时允许人物离框。
- 对焦对象、焦点交接和遮挡时机。
- 操机、跟焦、灯光、群演与美术的执行提示。

优先用广角近距保留人物与环境，同时警惕面部畸变、边缘拉伸和无意义的超广角。

### 5. 设置安全切口

即使目标是连续镜头，也要设计不破坏观感的备用切口：经过黑暗、贴近墙体、被人物遮满、快速摇移、门框擦过或视线转移。

为每个高风险点准备 A/B 路线，并标明可从哪个节拍重新起拍。不要把整条镜头的成功押在最后一个动作上。

### 6. 形成排练表

至少安排：走位排练、摄影机排练、技术合排、光线窗口实测和完整录制。每次只修一类问题：先空间，再节奏，再焦点与曝光，最后处理表演细节。

记录每轮的计时、偏差位置和恢复方法。AI 视频则把整条长镜头拆成可验证的关键帧与连续动作约束。

### 7. 写生成提示词与质检

提示词明确：首帧、人物路径、摄影机路径、速度、转交点、自然光变化、曝光适应、背景事件和尾帧。禁止突然切镜、瞬移、人物复制、空间重排、光向跳变、无触发推拉和漂浮感。

质检真实时间、路径可行性、人物身份、门窗位置、光向、步速、焦点、运动惯性与尾帧闭合。

## 输出格式

1. **长镜头理由**：连续经历带来的叙事价值。
2. **路线图**：带时间码的节拍、人物与摄影机位置。
3. **自然光时钟**：时段、方向、亮差和控制手段。
4. **排练与风险表**：焦点、曝光、遮挡、备用切口。
5. **生成提示词**：完整动作链、首尾帧和禁止项。
6. **验收标准**：成功条件与可接受偏差。
