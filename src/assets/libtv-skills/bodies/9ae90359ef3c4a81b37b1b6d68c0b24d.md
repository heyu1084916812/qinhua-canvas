# 微表情表演生成

## 定位

拿到"她很难过"这类描述时，模型倾向于输出一堆静态形容词，生成结果往往是**一张会动的表情图**：情绪没有起点和终点，眼神不聚焦，呼吸缺席，脸上的松紧毫无变化方向。

本 skill 的作用是把一个情绪翻译成**七层能被摄影机看见的动作**，让十秒内的表演有时间轴、有生理依据、有一处不完美。

## 输入

用户至少要给出：**人物 + 情绪**。其余缺失项按 Ask User 处理，或直接用默认值补齐。

默认值：单人 / 单镜头 / 10 秒 / 特写起幅。

## 内部流程

### 第一步：把情绪写成一条曲线

不接受静态情绪。先确定**起点 → 终点**，以及中间的转折时刻。

- ✗ 悲伤
- ✓ 从抽泣式余震 → 空落但克制的平静

情绪不变化的镜头不值得拍。若用户只给了一个静态词，自行替他补出这个情绪的前一秒或后一秒。

### 第二步：按七层顺序拆解

七个标签固定、顺序固定，一个都不能省：

1. **【Emotional State】** 一句话给出情绪的起点与终点。只写状态，不写剧情、不写原因。
2. **【Eye Performance】** 优先级最高。必须包含四项：眼部状态（湿度、红肿、血丝）、视线焦点的变化方向（涣散→聚焦，或聚焦→失焦）、眨眼的节奏与次数、视线最终落点。
3. **【Breathing】** 写节奏曲线（紊乱 → 拉长 → 变深），并**至少埋一次不受控的破绽**：一次短促吸气、一次憋住、一次哭后打嗝式的余韵。这是整条提示词里真实感的主要来源。
4. **【Facial Muscles】** 分区写下颌、眉、唇，每一区都写"从…到…"的松紧变化方向，不写形容词。
5. **【Physiological Response】** 给 1–3 个身体动作锚点：擦泪、吸鼻、吞咽、肩膀回正、手指收紧。动作要小，且具体到用哪个部位完成。
6. **【Emotion Transition】** 明确时长（如"十秒内"）+ 一个收尾动作（呼出一口气、垂下视线）。
7. **【Cinematic】** 景别的变化方向（特写缓慢拉远至近景）+ 光线倾向 + 节奏。镜头服务情绪，不设计炫技运动。

### 第三步：逐层把形容词换成变化动词

成稿前过一遍每一层，凡是静态描述全部改写。

- ✗ 下颌紧绷、眉头紧锁
- ✓ 紧绷的下颌一点点松开，眉头缓缓舒展

## 输出

一段可直接投入视频生成的中文结构化提示词：七个方括号标签逐行排列，标签内为纯描述文本。

不输出解释、不输出分镜表、不加标题和结语。用户要求时，可另附一份标签保留英文的平行版本。

总长控制在 400 字以内——超过这个长度，模型会开始丢弃排在后面的层。

## 技巧

输出前逐条自检：

- 七个标签是否齐全、顺序是否正确
- 眼部层是否写了焦点变化与眨眼节奏（最常漏的一项）
- 呼吸层是否有一处"不受控"的细节
- 是否还有静态形容词没被换成变化动词
- 是否出现了台词、情节、第二个人物、第二个场景（都不允许）
- 时长是否在 15 秒内、总字数是否在 400 字以内

## Ask User

只在以下信息缺失且确实影响结果时提问，一次问完，不逐条追问：

- 情绪的**终点**不明（只说了"生气"，不知道是走向爆发还是压回去）
- 人物的性别与年龄感未知
- 是否需要英文平行版本

其余项（时长、景别、光线）直接用默认值，并在输出后用一行说明用了哪些默认值。

## 示例

**输入**：一个女人情绪风暴后慢慢平静下来，10 秒特写。

**输出**：

【Emotional State】情绪风暴刚刚过去，女子正在从崩溃中缓慢地把自己拼回来，疲惫、空、但逐渐平静。 【Eye Performance】眼睛红肿湿润，睫毛黏连着残余泪水；视线从涣散慢慢重新聚焦，最后一次缓慢眨眼后，目光重新稳定对准前方。 【Breathing】呼吸从紊乱的抽泣式余震，逐渐拉长、变深、恢复节奏——中间夹杂一两次不受控的短促吸气，像哭后的打嗝式余韵。 【Facial Muscles】紧绷的下颌一点点松开，眉头缓缓舒展，嘴唇的颤抖幅度逐渐减小直至停止。 【Physiological Response】抬手用指背轻轻擦过脸颊上残留的泪痕，吸了一下鼻子，喉咙完成一次吞咽，垮塌的肩膀缓慢回正。 【Emotion Transition】十秒内从"余震"走向"平静"，结尾处轻轻呼出一口气，神情空落但恢复了克制。 【Cinematic】特写缓慢拉远至近景，光线从暗部渐渐透进一点暖调，节奏舒缓。
