\## 做什么\
根据一个知识点或主题，生成知识类口播短视频的完整脚本与画面分镜方案。\
\
## 需要什么输入\
【必填】知识主题 / 核心知识点\
【可选】风格（干货硬核/轻松科普/故事化讲解）\
【可选】时长（默认60-90秒）\
【可选】目标受众（小白/进阶/专业）\
\
## 怎么做\
1. 拆解知识点，设计钩子开场 → 核心讲解 → 总结升华的结构\
2. 撰写口语化口播稿，控制信息密度与节奏\
3. 规划画面分镜：人物出镜 + 配图/动画/素材穿插\
4. 设计字幕重点与金句提炼\
5. 配套 BGM 节奏与剪辑卡点建议\
\
## 产出什么\
- 完整口播逐字稿\
- 分镜脚本（口播内容 + 对应画面）\
- 开场钩子设计 + 结尾引导\
- 字幕重点标注 + 金句提炼\
- BGM 与剪辑节奏建议\
\
## 什么时候转向你\
需要调整讲解深度、更换表达风格，或追加特定案例/数据时停下来询问。
