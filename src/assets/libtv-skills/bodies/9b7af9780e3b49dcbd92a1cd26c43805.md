# 公众号文章转视频

## Skill 定位

- 只负责把一篇公众号文章改编并制作成一条单集短视频及一张独立视频封面图。
- 保留原文核心事实、观点和语气，重组为适合视听传播的内容，不逐段照搬原文。
- 提供可跳过的配置流程，让用户选择视频风格、封面风格、时长、画幅、配音、字幕、音乐、原图使用强度和交付阶段。
- 默认完成内容提炼、口播、资产锚点、分镜、封面设计、视频制作和独立封面图生成。视频文件与封面图片是两个独立交付物；用户明确只要文字草案、脚本或分镜时，停在其指定阶段。
- 不把长文拆成多集；原文过长时只选择一个最有传播力且信息闭环的角度。

## 输入

优先接收以下任一种核心输入：

- 用户上传的 Markdown 文章文件；
- 用户复制粘贴的文章正文；
- 用户上传的其他文章文件、截图、配图或品牌素材。

不接收或解析公众号文章链接。用户只提供链接时，请其上传 Markdown/文章文件，或复制粘贴正文。

可选输入包括目标平台、时长、画幅、受众、视频风格、封面风格、配音、字幕、音乐、人物或手部参考图、品牌元素、必须保留或必须避开的内容。

若用户未指定，采用以下默认值：

- 平台：短视频平台；
- 画幅：9:16；
- 时长：约 90 秒；
- 语言：普通话；
- 视频风格：根据内容自动选择，默认偏图文混剪知识解说；
- 原图使用：图文平衡，所有与正文相关的可访问图片仍须使用；
- 封面风格：根据内容自动选择；没有人物参考图时不生成虚构博主；
- 封面交付：独立静态图片，不用视频首帧、任意截图或封面方案文字代替；
- 配音：中性自然旁白；
- 字幕：简体中文，关键词高亮；
- 音乐：根据主题自动选择；
- 交付阶段：完整视频和视频封面；
- 整体气质：清晰、可信、节奏紧凑，避免浮夸。

## 配置选择

- 获取文章内容后，若用户尚未给出配置意图，读取 可选创作配置，一次只问一个编号选择题。
- 用户选择“快速默认”时，直接使用默认值，不再逐项提问。
- 用户选择“只选视频与封面”时，只依次询问视频风格和封面风格，其余使用默认值。
- 用户选择“完整自定义”时，按参考文件中的顺序逐项询问；每轮只问一项，等待回答后再继续。
- 用户已明确提供的配置直接记录并跳过，不重复确认；用户说“你决定”“直接生成”或“用默认”时停止提问。
- 选择视频风格后读取 视频风格；选择或生成封面时读取 封面风格。
- 封面人物类风格需要用户上传人物参考图；不露脸但要出现手部、半脸边缘或侧脸时，需要上传对应局部参考图。不要凭空生成一个默认博主。

## 输入使用

- 先区分文章正文与公众号导航、广告、推荐阅读、留言等无关内容。
- 上传 Markdown 时，读取正文并提取标准 Markdown 图片、引用式图片、HTML `<img>`、本地或相对路径图片，以及 `http://`、`https://` CDN 图片；读取 Markdown 图片处理 后建立素材清单。
- 将 Markdown 中与正文相关的图片视为用户提供的可用素材。不得因为图片来自 CDN、使用远程地址或带查询参数而忽略；在对应镜头中优先使用。
- 结合图片的替代文字、标题、图注、前后段落和出现顺序判断其含义，不把图片错配到无关口播。
- 将标题、论点、数据、案例、步骤和结论视为内容依据；不得编造原文没有的事实、数据、人物经历或引语。
- 对模糊、矛盾或缺少上下文的信息使用审慎表述；必要时在创作前询问用户。
- 默认用户上传或粘贴的文章及其内嵌图片可用于本次改编；若用户明确说明有使用限制，则遵守限制并生成原创替代画面。
- 将用户明确指定的视频风格、封面风格、时长、画幅、配音、字幕、音乐、品牌要求和本轮交付阶段视为硬约束，其余偏好视为参考。

## 工作流

### 1. 确认可执行性

- 获取用户上传或粘贴的文章正文；只有链接时，请用户改为上传文件或粘贴正文，不尝试解析链接。
- 若输入为 Markdown，提取正文中的全部图片引用，区分可直接使用的内容图片与头像、二维码、广告、分隔图等非内容图片，并记录本地来源或完整 CDN 地址。
- 判断文章属于观点、教程、案例、故事或产品解读，并读取 改编策略 中的对应结构。
- 完成用户选择的配置流程；用户已选择“快速默认”或已提供完整配置时，不再追加问题。
- 建立交付清单并分别跟踪状态：`视频成片：待生成`、`独立封面图：待生成`。只有用户明确选择“不单独生成封面”时，才把封面标记为“已跳过”。
- 只有在缺少文章内容、关键事实无法判断、用户要求互相冲突或关键图片无法访问时才提问；其余情况使用默认值继续。

### 2. 确定单集选题

- 用一句话写出目标受众看完后应记住的核心结论。
- 选择一个主角度和 3—5 个信息节点，形成完整闭环。
- 同步提炼一个封面传播点：只表达本集最强的结果、冲突或收益，不把 3—5 个信息节点全部塞进封面。
- 舍弃不影响主结论的铺垫、重复论证、枝节案例和推广信息。
- 若文章包含多个并列主题，选择最有价值的一个，不拆成系列。

### 3. 改写口播

- 使用“钩子—展开—回报—收束”的口语结构。
- 开头 3 秒直接给出冲突、结果、反常识或明确收益，避免自我介绍和空泛寒暄。
- 每句话只表达一个意思，优先短句、主动语态和具体动词。
- 根据目标时长控制口播字数，任何情况下不得超过 1000 个汉字。
- 原文中的关键数字、专有名词和因果关系必须准确；无法确认时不扩写。

### 4. 建立资产锚点

- 根据用户选择的视频风格读取 视频风格，在生成画面前确定统一的色彩、字体气质、构图、光线、材质和风格专属锚点。
- 将 Markdown 中的内容图片优先分配给与其上下文对应的镜头；CDN 图片也必须进入分配流程，不得默认改用生成图替代。
- 对原图使用裁切、轻推拉、平移、景深、遮罩、标注或局部放大等视频化处理，但不得改变图片所表达的事实。
- 对反复出现的人物、场景、物件、图标和品牌元素建立稳定描述，并在后续镜头中保持一致。
- 原文图片不足时，再为缺口生成原创画面；抽象观点使用隐喻、图形、关键词动画或场景化演绎。
- 避免依赖生成画面中的复杂文字；正文文字通过字幕和后期排版呈现。

### 5. 设计分镜

- 把口播拆成节奏清楚的镜头，每个镜头只承载一个信息重点。
- 为每个镜头确定时长、口播、屏幕文字、画面内容、景别与运动、转场、声音、资产锚点，以及需要使用的原文图片或 CDN 地址。
- 将所选视频风格的固定镜头语言写入分镜；手指电脑屏幕讲解风必须标明屏幕内容、手指指向位置、手部进出画时间和局部放大区域。
- 屏幕主文案尽量不超过 15 个汉字；重要数据要有足够停留时间。
- 分镜表结束后单独附上“封面制作卡”；封面不属于视频时间线，不占用镜头时长。
- 读取 分镜与质检规范 后再生成和剪辑。

### 6. 设计视频封面

- 读取 封面风格，在生成媒体前完成独立的“封面制作卡”，至少写明封面标题、风格编号、画幅、主体素材、构图、文字层级、颜色和需要避免的问题。
- 文章标题不自动等于封面标题。用户未给标题时提炼 3 个 4—10 字候选；在“快速默认”“直接生成”或“你决定”模式下自动选最强候选并继续，其他模式一次只让用户选择一个。
- 人物类封面没有参考图时先请求上传，或改用“原图大字无人物风”；不得凭空生成默认人物。
- 用户选择“先看封面制作卡”时，交付封面制作卡并等待确认；其余交付模式继续生成，不在此停留。
- 只有用户明确选择“不单独生成封面”时跳过本环节和第 8 步。

### 7. 生成并剪辑成片

- 用户明确要求先审阅文字草案、脚本、素材清单或分镜时，先交付该阶段内容并等待确认，不提前生成媒体。
- 先载入分镜指定的本地、附件或 CDN 图片；保留 CDN 地址的完整路径和查询参数。访问失败时才请用户重新上传对应图片。
- 严格执行所选视频风格；手指电脑屏幕讲解风要把原文图片或界面作为清晰的真实屏幕内容，不使用生成模型重绘其中的文字、界面或数据。
- 按资产锚点先生成关键画面，再补充过渡镜头，避免逐镜头风格漂移。
- 让配音、字幕与画面语义对齐；背景音乐不得遮盖人声。
- 控制转场数量，优先使用切镜、轻推拉、遮罩和信息图动效。
- 用户要求成片或未限制交付阶段时，完成脚本和分镜后继续生成、配音、加字幕并剪辑成视频；不要在用户要求成片时只返回方案。
- 视频生成完成后把交付清单中的“视频成片”标记为已完成，但此时任务仍未完成，继续执行独立封面图生成。

### 8. 生成独立视频封面图

- 根据已确认或自动确定的封面制作卡，新建独立的图片生成任务，使用所选风格、参考图、原文图片、标题、字体和配色生成封面。
- 封面比例跟随视频画幅；只有用户明确要求“小红书图文封面”时使用 3:4，不把 3:4 强加给所有视频封面。
- 封面必须输出为独立静态图片文件或可预览图片结果。不得把封面塞入视频时间线，不得用视频首帧、任意截图、提示词或构图方案文字冒充封面成品。
- 生成后核对标题文字、主体、比例和安全区；不合格时先修正。封面图可预览后，才把交付清单中的“独立封面图”标记为已完成。
- 封面生成失败时明确说明失败，不得将只有视频的结果描述为完整交付。

### 9. 自检与交付

- 按 分镜与质检规范 检查事实、节奏、字幕、画面一致性、版权风险和成片完整性。
- 发现事实失真、人物或场景漂移、字幕错误、音画不同步时，先修正再交付。
- 检查交付清单。除非用户明确跳过封面，只有“视频成片”和“独立封面图”均为已完成，任务才算完成。
- 分别交付最终视频和独立视频封面，并用简短文字说明标题、时长、画幅、视频风格、封面风格和改编主线。

## 输出

- 默认主要输出两个独立结果：一条完整、可预览的单集短视频，以及一张完整、可预览的静态视频封面图。
- 默认规格：9:16、约 90 秒、普通话配音、简体中文字幕。
- 用户明确要求本轮只交付文字草案、脚本、素材清单、分镜或封面制作卡时，按指定阶段输出，不将其误称为最终视频或最终封面。
- 若平台暂时无法完成视频或封面，明确说明受阻环节，并交付已经完成的内容与可继续生成的完整口播、资产锚点、逐镜分镜和封面制作卡；不得把缺少任一默认交付物的结果描述为完整成品。

## 自检

- 是否只围绕一个核心结论，形成完整单集？
- 是否忠于原文且没有新增未经证实的事实？
- 口播是否不超过 1000 个汉字并符合目标时长？
- 前 3 秒是否给出明确吸引力？
- 人物、场景、色彩和风格是否连贯？
- 是否严格执行用户选择的视频风格和封面风格？
- 手指电脑屏幕讲解风中，手指是否指向正确区域且没有遮挡关键信息，屏幕原图是否清晰、无重绘乱码？
- Markdown 中与正文相关的本地图片和 CDN 图片是否已进入素材清单，并用于合适镜头？
- 封面标题是否 4—10 个字、清晰可读、处于安全区，并使用正确画幅？
- 是否实际输出了独立静态封面图片，而不是视频首帧、截图、提示词或构图方案？
- 字幕、配音、画面和音乐是否同步且清晰？
- 是否遵守用户指定的交付阶段？用户要求成片时是否实际生成了视频，而不是只输出脚本或分镜？
- 除非用户明确取消封面，交付清单中的视频与封面是否都已完成？

## Ask User

仅在以下情况询问用户：

- 用户只提供链接，没有上传文章文件或粘贴正文；
- 上传的文件不含可读取的文章正文；
- 文章的核心事实或目标受众无法合理判断；
- 用户要求在时长、内容完整性、画幅或风格上互相冲突；
- 关键本地图片缺失，或关键 CDN 图片因失效、防盗链、鉴权等原因无法访问。
- 用户选择人物类封面或真人口播，但未提供人物、手部或局部参考图。
- 用户选择完整自定义，但尚有必要配置未完成。

每次只问最影响继续创作的问题；能用默认值解决时直接继续。
