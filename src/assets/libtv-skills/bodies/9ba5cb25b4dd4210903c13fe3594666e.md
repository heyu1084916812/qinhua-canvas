# 港式武侠胶片美学 · 短剧全链路

> 用途：以「九十年代香港奇幻 / 新派武侠电影」胶片质感为统一美学，把任意武侠题材从风格设定一路做到多镜头短剧成片。 最终产出：多镜头武侠短剧成片（默认每镜 7\~10 秒，可按需到 15 秒；带同期声、无 BGM）。

## 一、核心机制：四把锁 + 一个锚点

要锁住的东西用什么锁具体做法风格全局风格锚点句 + 画布视觉数据基线图像版 / 视频版两句锚点句与 A–G 基线，跨所有节点逐字复用人物定妆像 ＋ 多角度角色卡同一角色两张图成对引用，分别锁「面部身份」与「体态 / 细节」道具独立道具母版兵刃 / 信物单独出母版图，视频里作为唯一造型依据构图关键帧图只借构图、机位、站位，并显式声明「只借构图不借脸」镜头串联末帧衔接点每一镜的末段为下一镜的切入留出衔接点

**风格靠逐字复用的锚点句锁死，是整条链路最重要的开关**；其余四把锁分别管人物、道具、构图和镜头之间的接续。

**人物锁的完整写法**：定妆像与多角度角色卡成对引用，两者共同定义同一角色（成片中始终只有一个）。写视频 prompt 的输入图片说明时，必须补一句「白底与网格版面不出现在视频中」，否则会把角色卡的白底和分格版式带进画面。

**视觉一致性总原则**：第 1／2／3 层的所有色彩、质感、构图、道具、时间轴、声音取值，一律从「四、画布视觉数据基线」逐字取用；任一层都不得自造第二套数值。发现某层与基线冲突时，**以基线为准**。

## 二、工作流总览（4 步）

1. **定风格**：先用一段固定风格提示词统一画风；美学探索阶段用 Midjourney。
2. **写内容**：用外部智能体生成风格化的内容提示词。
3. **出图**：风格定稿后按分镜场景生成参考图，再把主角 / 主体替换成已建好的角色资产。
4. **出片**：视频阶段用 Seedance。

## 三、层 0：全局风格锚点（真正的一致性开关）

### 图像版锚点句（逐字复用）

> 九十年代香港奇幻武侠电影胶片感、低饱和青灰底色、柔和逆光、轻微光学晕染、35mm 颗粒、少量高亮朱红点色，避免橙黄、霓虹、HDR 和过度锐化。

### 视频版锚点句（逐字复用）

> 九十年代香港新派武侠电影胶片摄影质感，真实实景与真人拍摄质感，不是三维渲染，不是二次元绘画，不是游戏引擎实时画面。

### 风格三要素

1. **底色**：低饱和青灰 / 墨黑 / 灰白（详细取值与排除色见「四、A 色彩基线」）。
2. **点色**：朱红仅占极小面积，是画面唯一鲜亮暖色。
3. **光**：柔和逆光 + 阴天漫射光 / 烛火漫射光（光型细节见「四、B 质感与光线基线」）。

每条提示词都必须把锚点句原样带上，不要改写、不要同义替换——**一旦某条提示词自己改写了锚点句，全片的一致性就断了**。

## 四、画布视觉数据基线（A–G，供第 1／2／3 层逐字取用）

> 本节是画布既有资产的视觉数据源，全部实证自原画布节点参数与出图。设计新题材时**只替换题材槽位，本节数值一律不动**。各层槽位映射见本节末尾速查表。

### A. 色彩基线（→ 第 1 层色彩槽位、第 2 层色调槽位、第 3 层氛围槽位）

- **底色三件套（必须同时出现）**：低饱和青灰、墨黑、灰白；可加冷灰。
- **唯一暖色规则**：朱红 / 朱砂红只占「极小面积」，且必须是「画面唯一鲜明暖色」；不允许第二处同强度暖色。
- **排除色**：橙黄滤镜、蓝紫霓虹、高饱和多彩。
- **金色用量上限**：只作「极小旧金属细节」，禁止大面积黄金、厚重头面、金色雕饰。
- **角色专属主色与暖色载体（防不一致的关键，逐字取自画布定妆像 prompt）**：
  - **张翠山**：灰青宽袖长袍 + 灰白交领内衫 + 墨色腰封 + 黑色长靴；无铠甲、无金饰、无道士法冠；暖色载体＝一盏极小的冷朱砂红灯火；兵器＝黑铁判官笔、烂银虎头钩。
  - **赵敏**：宝蓝绸衫为唯一清晰主色（纯净深沉，不偏紫、不发霓虹光）+ 灰白窄袖内衫 + 墨色腰封 + 黑色软靴；白玉扇骨＝局部冷白高光；金＝仅一枚小型旧金色带钩；兵器＝造型纤秀的倚天剑 + 白玉扇骨素面折扇；发＝乌黑长发全束入简洁男式发冠、墨色缎带固定。
  - **谢逊**：金棕色蓬乱狮鬃状长发 + 破旧毛皮衣袍 + 粗粝胡须；宽肩高大体型。
  - **张无忌**：深靛长袍 + 腰间朱红内衬（暖色载体）。
  - **小昭**：黑铁镣铐 + 细长锁链；暖色载体＝朱红灯火映入眼睛。
- **禁用装束**：蒙古刻板兽皮装、厚重公主头冠、现代西装轮廓、浓艳舞台妆、狐媚浓妆。

### B. 质感与光线基线（→ 第 1 层质感槽位、第 2 层质感槽位、第 3 层画质槽位）

- **胶片四项（逐字复用）**：35mm 中等颗粒、轻微高光溢出、色彩漂移、柔光 / 光学晕染；动态镜头另加动态拖影。
- **光型**：柔和逆光沿发丝、肩线、衣料边缘勾出细薄晕光；室外＝阴天漫射均匀低照度，室内＝烛火低照度漫射。
- **材质词表（按主体选用，不虚构）**：真实皮肤、湿发、黑发、湿布、绸缎、白玉、旧金属、黑铁、银器、漆木、青铜、珍珠、粗粝石面、破旧毛皮。
- **禁止清单**：塑料皮肤、HDR、过度锐化、现代偶像妆、仙侠特效、三维渲染、二次元 / 卡通渲染、游戏引擎实时画面。

### C. 构图基线（→ 第 1 层入镜规则、第 2 层构图与机位槽位）

- **每帧只有一个绝对视觉中心。**
- **群体场面**：巨型圆形石坛 / 石台 + 数百名群雄组成巨大同心圆包围中心 + 兵器如林斜指中心；主角成为画面唯一制高点。
- **三层纵深必须逐项点名**（前景 / 中景 / 背景各写具体物件），例：前景人群肩背—中景武者—背景低垂云层；近景石头令牌—中景并肩二人—背景军阵战旗。
- **负空间**：远处江雾与古塔暗影形成巨大负空间。
- **机位词汇**：低机位越肩仰拍、高位广角、超广角俯拍、极近特写、正面偏三分之二角度；定妆像摄影机与胸或腰齐平。
- **定妆像入镜规则**：人物从头顶到鞋履全部入镜，双手双脚与兵器结构清楚，身体四周留安全边距。

### D. 道具母版基线（→ 第 2 层与第 3 层的道具槽位，独立建锚时逐字复用）

以「屠龙刀」母版为例：玄黑厚背宽刃、隐约龙鳞锻纹、暗银云雷纹刀脊、深色丝绳缠柄、刀首垂坠。

- **硬约束**：该图是本段兵刃的**唯一造型依据**，不得替换为长剑、不得添加金色雕饰。
- **尺寸**：1344×896 横版。

### E. 多角度角色卡版面基线（数值化，→ 第 1 层第二级与第 3 层第①段声明）

- 纯白底、16:9、网格规整对齐；
- **上排 5 视图**：正面特写 / 45° 侧面特写 / 正面全身 / 背面全身 / 侧面全身，每格下方一行小号深灰中文标签；
- **下排左 4 格**「表情 / 动作系列」正面胸像小像；**下排右 4\~5 格**「细节特写」极近特写（眼部、皮肤质感、发饰 / 配饰、腰封、靴子）；
- 平光、几乎无投影、中性表情、自然站姿。

### F. 视频时间轴基线（→ 第 3 层第⑨段）

- 按秒切分段落（零到一点五秒 / 一点五到三点五秒…），每段＝镜头运动 + 主体动作 + 同步声音事件；
- **首段**声明「画面从第一帧起就处于强烈动势之中，不设静态铺垫」；
- **末段**固定「为下一镜头的切入留出衔接点」，收束镜头改写为「作为全片的收束镜头」；
- 时长实证 7\~10s，单镜 15s 可用（容量 4–30s）。

### G. 声音基线（→ 第 3 层第④⑦⑧段）

- 结尾固定 `No BGM`；
- 仅同期声，逐项列举（低频狂风呼啸、衣袍摩擦、兵器细碎金属声、群体惊呼闷哼、尘土沙沙、脚步与珠串碰撞）；
- 群体人声「不形成清晰可辨的成句对白，只作为群体情绪化的喊声处理」；
- 旁白与现场声分层，画面人物口型不与旁白对应。

### 各层槽位映射（速查）

层从本节的哪一节取值第 1 层 定妆像 / 角色卡色彩、暖色载体、禁用装束 ← **A**；质感、光线、禁止清单 ← **B**；入镜规则与机位 ← **C**；角色卡版面 ← **E**第 2 层 关键帧 / 空镜色调与排除色 ← **A**；质感与光型 ← **B**；视觉中心 / 同心圆 / 三层纵深 / 机位 ← **C**；兵刃造型 ← **D**第 3 层 视频色调与唯一暖色 ← **A**；画质与质感 ← **B**；按秒时间轴 ← **F**；同期声与 No BGM ← **G**；白底网格不入画 ← **E**

## 五、层 1：人设视图（两级做法）

角色形象是**两级产出**，不能只做一张文字描述卡：先出定妆像，再以定妆像为上游转出纯白底的多角度角色卡。人设卡的风格必须完全对齐定妆像与参考图上的同一个人，不另起一套画风。

> **视觉数据来源**：本层色彩、暖色载体、禁用装束一律从「四、A」取（含角色专属主色表）；质感、光线、禁止清单从「四、B」取；入镜规则与机位从「四、C」取；第二级的版面从「四、E」取。

### 第一级：定妆像（MJ）

- 模型：Midjourney v8.2
- 比例：2:3 竖版；尺寸 1792×2688
- 生成张数：4；quality auto
- 节点参数：stylize 100 / weird 50 / chaos 5
- 提示词尾参：`--s 270 --chaos 5 --hd`

**输入方式**：以一个「人物多角度角色卡」风格文本节点作为统一风格输入（该节点调用了对应的 skill-key），再叠加角色自身的描述。本 Skill 只声明这个引用关系，不复述被引用 skill 的内部实现。

**十段式人设 prompt**

 1. **反真人声明**：「XX 的原创经典武侠银幕形象，不对应任何现实演员。」
 2. **面部骨相与气质**，用否定式界定：「娇媚青春，笑里藏刀——她的锋利藏在眉眼笑意里，不是冷脸、不是妖媚俗艳、不是柔弱无助。」
 3. **身形、发型、服装**：按 A 的「色名 + 材质 + 配饰 + 排除项」写（如低饱和胭脂红暗绸交领襦裙、灰调绯色轻纱帔帛、墨色细带；旧金点翠小凤钗，无厚重头面）。
 4. **姿态与兵器动作**，按 C 的入镜规则要求全身完整：「单人完整全身银幕定妆像，正面偏三分之二角度，摄影机与胸齐平，人物从头顶到鞋履全部入镜，双手与双脚结构清楚，身体四周留有安全边距。」（袖中藏剑时写：不动武只见袖口一线暗银剑柄微露。）
 5. **环境与负空间**：虚化的场景背景（珠帘、烛台、朦胧屏风），无其他人物；唯一的极小冷朱砂红暖色按 A 的「唯一暖色规则」落位。
 6. **质感段**从 B 取：胶片四项 + 材质词表，并写「不使用橙黄美白滤镜」。
 7. **情绪定性词收尾**：「娇媚、危险、暗藏杀机」。
 8. **负面清单**从 A 与 B 取：避免橙黄滤镜、蓝紫霓虹、HDR、过度锐化、塑料皮肤、现代偶像妆、仙侠特效、额外人物、文字和水印。
 9. **角色专属主色**从 A 的角色表逐字取用，写成画面唯一暖色主调，其余金属细节压到极小。
10. **参数尾巴**：`--s 270 --chaos 5 --hd`。

### 第二级：多角度角色卡（Lib Image 转换）

把第一级的定妆像作为上游输入，转成纯白底的多角度参考卡。

- 转换方式：Lib Image（model `lib-image-2`）的 image2image
- 参数：16:9 / 2K / quality medium / count 1
- 特效模板：挂「人物多角度角色卡」模板
  - `effects`: `22923414`
  - `effectTemplateUuids`: `9dc0ffecd44d40e98fda2c4ce3fc9d87`

**卡的固定版面**：完全按「四、E 多角度角色卡版面基线」执行（纯白底 16:9；上排 5 视图 + 中文小标签；下排左表情 / 动作 4 格、右细节特写 4\~5 格；平光无投影、中性表情、自然站姿）。

**prompt 写法**：开头先声明「参考图 {{定妆像节点}} 是同一人物的银幕定妆像，本图以它的面部、发型、服饰与气质作为唯一身份依据」，再按 E 逐条描述版面、五视图与下排两组，最后重申身份与服装在全部视图中严格一致、不得有任何角度间差异。

> 若创建工具没有该特效模板选项：在 prompt 中用文字完整描述 E 的版面（五视图 + 表情 / 动作四格 + 细节特写四到五格，白底、每格中文小标签），并在完成后提示用户在编辑器里挂上同一个特效模板（`effects 22923414` / `effectTemplateUuids 9dc0ffecd44d40e98fda2c4ce3fc9d87`），以 100% 对齐版式。

### 人物设计要点

- 用**否定式**界定气质（「不是冷脸」比「温柔」更可控）。
- 服装一律写成「色名 + 材质 + 配饰」，再补排除项。
- 每个角色只给一个专属主色（A 的角色表），避免角色互相抢色。
- 两级只做一次；之后全片复用，视频阶段同时引用定妆像与多角度角色卡。

## 六、层 2：关键帧 / 场景图

> **视觉数据来源**：色调与排除色 ← A；质感与光型 ← B；视觉中心 / 同心圆 / 三层纵深 / 机位 ← C；兵刃造型 ← D。

### 生成参数

- 模型：Midjourney v8.2
- 比例 16:9；尺寸 2944×1648；生成张数 4
- 提示词尾参：`--s 320 --chaos 5~6 --hd`

### 提示词公式（比人设卡短得多）

> 风格锚点一句 + 场景空间结构（C）+ 机位（C）+ 唯一暖色（A）+ 质感（B）+ 参数

**空镜 / 场景参考写法**（无人物）：按 C 写清「前景—中景—背景」三层物件与各自质感（如前景珍珠帘幕 / 中景矮漆案与杯盏 / 深处朦胧屏风与博山炉轻烟），声明「画面中没有任何人物」，并按 A 给出唯一暖色（烛火处极小暖朱红）。

### 空间结构（取自 C，属于锚点）

- 巨型圆形石坛 / 石台
- 数百名群雄组成巨大同心圆，包围中心
- 每帧只有一个绝对视觉中心
- 强烈空间层次：前景 / 中景 / 背景三层纵深

### 机位（取自 C）

- 低机位越过群雄肩背仰拍
- 高位广角
- 极近特写

### 特写帧写法（以「小昭镣铐」近景为例）

「严格保持角色资产中的五官、发型和服装」+ 柔美面容与冰冷铁器的强烈反差 + 唯一暖色映入眼睛（A 的角色表：朱红灯火映入眼睛）。

### 画布上的实际层级

定妆像 → 多角度角色卡 → 关键帧图 / 场景空镜（16:9，场景 + 人物替换）→ 视频节点。部分关键帧还会再经一次图像编辑（把多张输入合成），这类编辑节点的提示词同样遵循「只借构图不借脸」的声明；涉及兵刃时按 D 约束造型。

## 七、层 3：视频（复刻的关键）

> **视觉数据来源**：色调与唯一暖色 ← A；画质与质感 ← B；时间轴 ← F；同期声与 `No BGM` ← G；白底网格不入画声明 ← E。

### 生成参数（逐项对齐）

- 模型：`star-video2.5`（Seedance 2.5）
- modeType：`mixed2video`
- 比例 16:9；分辨率 720p
- duration：7\~10（单镜到 15s 亦可用，容量 4–30s）
- enableSound：on
- search_enabled：1
- autoCompliance：1
- 结尾固定：`No BGM`

### 输入连接方式

多输入节点，按图分工，典型连法：

- 关键帧图 / 场景空镜（构图、站位、色调与质感）
- 定妆像（面部身份）
- 多角度角色卡（体态与细节复核）
- 道具母版（兵刃唯一造型依据，按 D 约束）
- 视需要连入历史版本视频作为风格 / 质感参考

### 十字段提示词模板（严格按此顺序写）

**① 输入图片说明——逐图分工声明，每图只锁一件事**

- 图1 锁构图 / 站位：「该图中央人物的具体面孔与外观均不作为身份参考，不得复现原图人物的具体样貌」
- 图2 锁色调与画质质感：「不用于锁定人物身份或构图」
- 图3 锁角色面部与体态身份；与其成对的多角度角色卡共同定义同一角色——「两张卡共同定义同一角色，成片中始终只有一个；角色卡的白底与网格版面不出现在视频中」（依 E）
- 图4 锁兵刃 / 道具唯一造型依据（依 D：不得替换为长剑、不得添加金色雕饰）
- 统一加一句：「参考图上出现的任何文字或标识图案均为无关内容，本段视频不得复现」

**② 视频目标**：一句流派化定位（「徐克式凌厉运镜的开场即高潮镜头」「徐克式极具视觉冲击力的宏大史诗镜头」）+ 是否含台词。

**③ 基础设定**：主体描述 + 一致性硬约束（「体型、发型、胡须与兵刃形态必须分别与图3图4保持一致」）。

**④ 角色台词**（依 G）：嗓音规格（音色、年龄感、语速、咬字、停顿的压迫感）+ 逐字台词 + 群体人声处理（「不形成清晰可辨的成句对白，只作为群体情绪化的喊声处理」）；无台词则整段省略。

**⑤ 旁白台词（可选，依 G）**：画外音与现场声分层反差，并明确「旁白讲述者不出现在画面中」「画面人物口型只对应各自现场台词，不与旁白产生口型对应关系」。

**⑥ 统一画风**：视频版风格锚点 + 运镜流派（极端仰角、剧烈镜头晃动、快速环绕、超广角俯拍切换）。

**⑦ 声音控制**（依 G）：逐项列举同期声（低频狂风呼啸、衣袍摩擦、兵器细碎金属声、群体惊呼闷哼、尘土沙沙、脚步与珠串碰撞），声明「不需要配乐 / 旁白 / 画外音」的组合，结尾 `No BGM`。

**⑧ 氛围与画质**：阴云漫射光（B）+ 低饱和青灰墨黑灰白（A）+ 三层纵深逐项点名（C）+ 唯一暖色细节（朱红战旗 / 朱红发带 / 烛火，A）+ 胶片四项与动态拖影（B）。

**⑨ 画面内容**（依 F）：按秒切分时间轴，每段＝镜头运动 + 主体动作 + 同步声音事件；首段「画面从第一帧起就处于强烈动势之中，不设静态铺垫」；末段「为下一镜头的切入留出衔接点」（收束镜头写「作为全片的收束镜头」）。

**⑩ 负面约束**（依 A 与 B）：分号隔开的长禁止串——无文字字幕水印、不复现参考图面孔、不改变锁定特征、无游戏引擎 / 卡通渲染质感、无过度锐化与高饱和多彩滤镜、无橙黄与蓝紫霓虹、不新增引用图外的主要角色、无现代服饰塑料道具、全程保持运动不出现长时间静止呆板镜头。

## 八、执行流水线（Checklist）

0 层定锚点句 + 读一遍 A–G 基线 → 1 层两级角色卡（MJ 定妆像 → Lib Image 多角度卡）→ 2 层关键帧 / 场景空镜 → 3 层视频十字段 → 每镜末帧留衔接点串联。

**锚点取舍规则（按实际需要增减，避免过度锚定）**

- 非核心道具（如软剑）不单独建道具母版，直接融入角色锚（写在角色 description 里，A 的角色表已含此类）。
- 没有台词就不建音色锚，十字段第 ④ 段整段省略。
- 单主体镜头不建站位锚，第 ① 段不需要图1 的「只借构图不借脸」声明。

## 十、迭代与废稿说明

同一镜常存在多个版本（如同一镜的「质感 / 站位分离参考版」「细节清晰版」「完整声画版」），这属于同一镜的迭代——配方只保留最终采用的连法与参数，不复刻中间版本。与内容无关的占位视频节点不要写进配方。

## 十一、拿到新题材时怎么用这份 Skill

1. 先读一遍「四、画布视觉数据基线 A–G」，把它当作不可改的视觉常量。
2. 用本 Skill 的模板把「风格锚点 → 两级人设 → 关键帧 / 空镜 → 视频」四层补齐，所有色彩、质感、构图、道具、时间轴、声音槽位显式指向 A–G 对应条目。
3. 只替换题材槽位：剧名、角色名、场景、台词、道具名、朱红载体。
4. 锚点句、A–G 数值、两级人设做法与角色卡版面、模型名、参数、模板结构一字不改。
5. 逐镜生成后按末帧衔接点串联，即为与画布资产同源、不漂移的港式武侠胶片成片。
