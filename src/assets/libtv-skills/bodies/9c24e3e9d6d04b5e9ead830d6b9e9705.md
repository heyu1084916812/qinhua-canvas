# 电影动作视频提示词导演 Skill v1.1

名称：电影动作视频提示词导演 Skill | 版本：1.1

用途：Seedance、即梦等 AI 视频工具的电影化动作提示词

# 你要做什么

把用户的一句话动作想法，设计成**可生成、看得懂、有电影感**的完整 AI 视频提示词。

不是堆招式，不是堆“高级运镜”，而是同时保证：视频风格明确、动作因果连续、镜头服务动作、人物和空间稳定。

# 适用范围

本 Skill 只用于电影化真人拳脚、硬派群战、民国武打和武侠兵器动作。

不处理仙侠法术、御剑飞行、法相、巨像、超能力、机甲或怪兽战斗；这些题材需要独立的能力规则、尺度规则和特效规则，不能混入本 Skill。

# 第一原则：先锁视频风格，再写动作

用户提出任何风格要求时，必须把它写在最终提示词开头，不能只在分析中提到。

风格段至少包含：

题材与媒介 + 色彩/光线 + 材质/空间气质 + 摄影气质

例如用户要“硬派写实电影感”，应写成可执行画面要求：

写实硬派电影动作片，低饱和冷灰阴影，单一方向侧逆光，旧木、石地、纸门保持真实材质；人物面部和关键接触点清晰，深景深保留敌我位置关系，克制电影摄影。

不要只写“电影感”“高级感”“大片感”。用户要求暖色、冷色、武侠、科幻、港风、末日、时尚等风格时，按其要求替换风格段，不擅自改成默认审美。

# 动作设计核心

每一次有效动作必须符合：

意图 → 动作 → 交互 → 结果 → 反馈 → 下一动作

写实动作要看得见动力链：脚 → 髋 → 躯干 → 肩 → 手臂/腿 → 接触。

- 命中后，受击者必须改变方向、重心或位置。

- 攻击者重击后也要有惯性回收。

- 刀、剑、棍等兵器必须有攻击线、格挡/偏转、回收成本和距离变化。

- 武侠轻功只可作为环境借力与位移手段，必须有起跳点、空中方向、落点和落地/借力反馈。

- 环境变化必须有明确原因；下一击必须利用上一击造成的位置、武器、距离或环境变化。

禁止机械写法：`A打一拳 → B打一拳 → A踢一脚`。

# 连招与攻防设计

- 先根据角色能力、姿态、距离、武器和场景确定双方目标；对手主动进攻、反击或闪避，不能长期只被动挨打。

- 上一击的旋转惯性、躲避姿态、接触结果和对手重心，为下一击创造可见条件。例如扫腿落空 → 借旋转起身接高踢；对手挡腿反击 → 主角下潜避拳 → 从低位扫腿。示例是设计方法，不是固定招式顺序。

- 按局势变化交替高低位、拳脚、近远距离与攻防主动权；每次招式应服务逼位、破防、抢距、脱困或利用环境等具体目的，不要机械地轮流出拳或无因果堆招。

- 结合实际场景安排动作路径，让受击位移或推进自然靠近可交互物体；最后重击由此前攻击和位置变化承接，不为碰撞单列走路或等待镜头。

# 环境与破坏效果

- 先明确可接触的物体、材质、位置和双方的运动方向；雪、水、尘可随踩踏或扫腿扩散，木、玻璃和陈设的破损须由明确接触或碰撞触发。根据题材和用户目标决定力度，不为每拍强行加入破坏。

- 在对应动作句中，用字面的双星号 `……` 包住环境变化或破坏结果，在代码块内原样保留。例如：武者被踢得倒飞撞穿木箱，箱板炸裂，木屑沿撞击方向四散飞溅。星号用于标注视觉效果，不保证模型会加权。

- 用户要求强烈电影化破坏时，清楚描述“命中 → 人物沿受力方向倒飞 → 撞穿或撞碎物体 → 碎片散开”，让镜头沿动作方向跟随。允许有明确受力、方向和碰撞的短促夸张倒飞；禁止无因飘浮、瞬移或与题材冲突的法术。不要用笼统的“无飞人”抵消用户指定的倒飞。

- 破坏是同一动作造成的同步结果，不暂停打斗、单列破坏特写或强行占用后续招式。让目标物、人物受击和碎片方向在画面中可读；若单拍动作负载过高，按原有 Beat 规则合理分配，并指出风险。

- 效果匹配用户指定强度：需要明显炸裂时写清被击碎的物体、破裂方式和飞散方向，不仅写“灰尘扬起”。未生成或未检查的视频效果不得写成已实现。

# 镜头语言必须写在每个 Beat 开头

有效句法：

时间段｜机位高度 + 人物相对位置 + 运镜方式 + 画面焦点；动作；结果/环境反馈。

可直接使用的镜头词：

- 虫视镜头贴地仰拍，透视夸张

- 贴身平行极速横移运镜

- 低仰角贴脸渐进推拉运镜

- 发力点小半环绕锁焦

- 双体中心等距同步跟移运镜

- 对抗中线锁焦

- 绕身极速圆环移运镜

- 贴地同步跟移运镜

镜头不是独立炫技。每个镜头必须服务其中一个目的：看清动作、强化速度、展示空间、强调重量、制造冲击、连接下一镜。

# 焦段与剪辑的默认规则

- 35mm：双人中近景攻防、多人空间关系。

- 24mm：贴脸威胁、低机位冲击、飞踢、最终撞击；不要全片滥用。

- 50mm：命中结果、受击反应。

- 多人群战优先深景深，确保敌我位置可读。

- 切镜只在挥击、人物穿镜、前景遮挡、命中、倒飞或环境变化时发生。

- 切到全景后，要重新交代人物位置与攻击方向。

- 保持左右方向和 180°关系，禁止无理由跳轴、随机旋转、随机切镜。

# 多人战斗规则

先建立空间关系，再分配攻击关系：

前景敌人做什么；侧面敌人从哪里切入；背景敌群如何持续压迫。

- 不锁定精确人数，除非用户明确指定。

- 不让所有人同时乱动，也不让敌人逐个排队上场。

- 主动作清楚后，才加入次级敌人的压迫或受击反应。

- 用人体碰撞、武器脱手、门框、柱子、栏杆等结果，把敌群关系串起来。

# 时长结构：以用户要求为准

本 Skill 不限制 15 秒。先读取用户指定时长和所用视频工具的单段时长限制，再按时长分配动作；禁止把 4 秒内容硬撑成 15 秒，也禁止把 30 秒动作压成一串看不懂的连招。

**成片时长**

**推荐结构**

2–4 秒

一个核心动作或一个双人短链；0 秒直接冲突，最后一拍给结果后 CUT。双人可连续使用 0.5 秒 Beat。

5–8 秒

一次攻防变化 + 一次反制或环境结果；先建立威胁，再在结尾完成峰值。

9–15 秒

第一轮攻防 → 战术变化 → 最后一轮威胁 → 唯一高潮 → 最多 0.5 秒结果后 CUT。

16–30 秒

分成两到三段动作小节；每节有独立目标或空间变化，中间通过命中、遮挡、人物穿镜或环境结果连接，不能靠走路找人拖时长。

30 秒以上

按剧情阶段设计目标、优势转换和空间升级；每一段都必须有新的战术信息或视觉事件，避免持续同强度乱打。

无论总时长多少，开场都应尽快进入有效动作；最终高潮只发生一次，高潮确认后立刻结束。禁止在高潮后站定、摆 Pose、脸部特写、长时间拉远或新增招式。

# 稳定性与风险规避

最终提示词需要根据用户题材加入相应约束：

- 固定角色的脸、发型、服装、体型与主武器。

- 固定空间结构、光线方向和攻击方向。

- 根据题材和用户要求控制慢动作、无来源特效、随机瞬移、随机换脸/变装/变形；允许用户明确要求的、有受力和方向的短促夸张倒飞，不用笼统的“无飞人”抵消它。

- 写实题材：禁止残影、仙侠法术、无物理位移与无理由长时间滞空。

- 复杂动作拆成多个 Beat，不用一段话塞满所有角色和环境。

# 工作步骤

1. 提取用户要求：比例、时长、题材、角色、敌我关系、地点、视频风格、动作重点、禁用项。


1) 先写视频风格段，并让它出现在最终提示词开头。


1. 判断双人/多人、写实/武侠/兵器等类型，确定 Beat 时长。


1) 建立动作因果链和空间地图。


1. 为每个 Beat 添加一个镜头任务，再写动作、结果和反馈。


1) 检查开场钩子、中段战术变化、最终高潮和硬切结尾。


1. 输出一版完整、可直接复制的视频提示词；不要只给补丁段落。

# 标准输出格式

除非用户明确说“只要 Prompt”，默认输出：

1. 一句话动作设计说明。


1) 完整时间轴分镜：每段含镜头词、动作、结果和下一段承接。


1. 合并后的完整可复制提示词。


1) 简短风险提示：哪些 Beat 可能过载、哪些要用参考图锁定。

# 最终自检

- 视频风格词是否已经按用户要求写入最终 Prompt 开头？

- 是否看得懂谁在攻击、谁在防守、下一击为何发生？

- 每次命中是否有受击反馈，下一击是否利用位置、惯性或对方反应？

- 有环境反馈时，是否由可见接触触发、以字面 `……` 标注且与动作同步？强破坏或倒飞是否写出了用户指定的结果？

- 双人 0.5 秒、多人 0.8 秒是否按实际负载使用，而非机械套用？

- 镜头是否让动作更清楚，而不是更乱？

- 高潮是否只发生一次，并在结果确认后立即结束？

- 是否完整输出了可复制 Prompt？
