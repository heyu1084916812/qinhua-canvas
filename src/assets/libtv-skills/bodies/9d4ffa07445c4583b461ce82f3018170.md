## 技能用途
本 Skill 用于快速创作以 IP 角色或吉祥物为核心的营销短片。通过「出发 → 跨世界穿越 → 回到原点收尾」的经典叙事结构，在保持角色一致性的前提下，实现多场景变换的快闪视觉效果。

## 适用输入
- **IP 角色信息**：基础形象描述、标志性识别元素、常持道具。
- **核心场景**：品牌门店或主推产品所在的主场景。
- **创意主题**：短片要传达的情绪或营销口号。
- **穿越设定**：2-4 个不同的平行世界风格（如赛博、古风、童话等）。

## 操作步骤
1. **锁定基线**：首先生成一张 IP 角色的「基线形象卡」，作为全片视觉的身份锚点。
2. **资产衍生**：基于基线卡，保持面部与体型不变，仅替换服装与手持物，生成各世界的「变体角色卡」。
3. **环境构建**：同步生成对应的场景空镜、转场特效道具及各世界专属的纪念品资产。
4. **分镜创作**：
    - **分镜 1（出发）**：主角在主场景通过道具开启次元门。
    - **分镜 2（穿越）**：角色以快闪节奏切换不同世界形象。
    - **分镜 3（回归）**：主角带回纪念品回到主场景，展示品牌主题。
5. **合成渲染**：将分镜视频按节奏剪辑，输出 20 秒左右的成片。

## 输出要求
- **角色一致性**：无论场景如何切换，角色面部特征与核心标志需高度统一。
- **画风统一**：默认采用 3D 卡通渲染，糖果色高饱和质感。
- **叙事完整**：具备明确的起承转合，包含转场特效与品牌口号定格。

## 注意事项
- 场景与道具生成时必须设置「无人物/无角色」负面提示词，避免干扰后期合成。
- 穿越世界的数量直接影响节奏，建议维持在 3 个左右以保证每个世界有 2.5s 以上的展示时长。
