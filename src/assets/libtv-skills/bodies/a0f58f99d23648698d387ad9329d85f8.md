# 中式天宫美学 Skill

## 目标

把用户的主题转成可控的中式天宫电影画面，而不是笼统的“仙气”描述。成图提示词必须先建立巨构景的空间尺度，再以小人物作为尺度参照；视频提示词必须从同一静帧的空间关系出发，明确镜头路径、可动元素、静止元素和速度。

适用于写实电影感的中式仙侠 / 天宫 / 云海 / 悬浮宫殿场景；不用于水墨、Q 版、二次元或强动作打斗，除非用户明确要求混合。

## 工作方式

1. 先从用户输入提取：主题或故事瞬间、主体建筑 / 地景、人物数量与动作、期待构图、时间与色调、是否含静水或瀑布、画幅与视频时长。
2. 读取 提示词模块库。选择**一个**机位方案、**一个**主光源、**一个**主空间关系和**一处**远景奇观。先确定“巨物 → 中景承托物 → 小人物”的尺度链；若用户未指定，默认采用横向天宫建立镜头、单名小人物、清晨或日落低角度侧光、2.35:1 宽画幅。
3. 不因信息不完整而连续追问；可以先用默认值输出，并在提示词前用一句话说明所采用的默认值。只有人物身份、场景类型或画面比例会实质改变结果且无法合理推定时，才问一个关键问题。
4. 用户只要图或只要视频时，按其要求输出；未特别说明时，默认同时输出“绘图提示词”和“对应图生视频提示词”。

## 成图提示词规则

- 采用“风格锚点 + 巨构图 + 空间层次 + 光线色彩 + 小人物 + 约束”的连续长段落写法。真实电影摄影、35mm 胶片、长焦压缩、低饱和等是可选风格锚点；不得为了套模板而覆盖用户指定的媒介、景深或色彩。
- 按视觉优先级写：镜头与构图 → 巨型框景 / 建筑 / 天象 → 前中远景与云海 → 材质 → 有机曲线 → 光线与色彩 → 人物 → 分层与画幅。人物段必须位于场景主体之后，除非用户明确要求人物主视角。
- 建立镜头优先写大尺度关系，例如“巨门 / 巨松 / 巨月 / 天宫 → 平台、石阶或栏杆 → 小人物”。每个画面保留一个主奇观和一处主要引导线，避免让多个同等强的主体彼此争抢。
- 每个具体元素都必须有位置、朝向、大小或与其他元素的关系。例如“右侧三分之一的宫阙”“人物只占画面高度的十二分之一”“桥在断口处戛然而止，桥下无支撑物”。
- **人物尺度是此风格的硬约束。** 天宫建立镜头、巨门、巨月、巨松、云海、峡谷和远景宫殿默认使用 `1/20–1/30` 的小人物；石阶、长廊、平台等带有人物引导的全景使用 `1/15–1/20`；只有用户明确要求人物叙事、可读服装或情绪镜头时，才可使用 `1/12–1/15`。除非用户明确要求人物主视角、半身或特写，不得放大至 `1/6`、`1/5` 等主体人像比例。
- 小人物是“尺度参照”，而非画面主体。使用“仅作为尺度参照、完整小比例轮廓、服色可辨、不抢占视觉中心”，不要默认写“人物必须清晰出现”“人物完整可见”“清晰五官”“人物优先”。小人物仍须写清人数、精确位置、朝向、服色对比、落脚位置和接触阴影；以服色和位置防漏生，不用放大人物补救。
- 同一静帧只保留一组人物逻辑。不得同时写“右侧几位小人物”与“平台尽头独自站立的人物”，除非明确写出总人数、各自位置及其中哪一组是尺度参照。
- 物理约束要写实：人物落地并有接触阴影；瀑布、水面、云海、倒影分别交代是否运动或是否完整；悬浮建筑只有在用户选择悬浮方案时才写“下方虚空、无支撑”。
- 材质不能只写“白玉”。写明色温、表面和受光，例如“暖象牙白、抛光但非哑光，宽而柔的高光带使圆柱呈圆润体积”。
- 光线只能有一个主来源；明确光从左 / 右、低 / 高、直射或天空反射而来，且写清受光面、背光面、投影方向和接触阴影。不要用“光影绝美”“氛围感”替代。
- 结尾加入必要的反向限制，优先处理：不要放大人物、不要多余人物、不要广角畸变、不要漂浮碎片、不要无来源补光、不要过曝死白、不要灰雾、不要文字水印、不要风格化卡通。只保留与本画面有关的限制。

## 图生视频提示词规则

- 将静帧视为首帧：不重写整段场景，先锁定建筑、人物比例与主构图。用户未指定慢镜头时，按约 5 秒的短视频默认采用**强动态版**：从“快速中轴推进、快速横向跟移、快速后拉展开、快速仰升、快速俯冲”中选择**一个**与画面几何关系相符的运镜；运镜必须匀速、稳定、有明确方向，不抖动、不旋转、不突然变速。
- 使用四段结构：`起始机位与快速稳定的镜头路径` → `人物或活体主体的一次完整动作` → `云海 / 瀑布 / 飞鸟等环境的可见动态与物理反馈` → `保持不变`。每段都交代屏幕方向、速度、幅度和边界；若用户明确要求静谧、慢镜头或展示静态建筑，再降级为慢速方案。
- 根据构图选择快速运镜：强对称、中轴纵深或建筑边线使用快速稳定前推、仰升或俯冲；古松、柱廊、岩壁框景使用快速稳定横移制造明显视差；平台、静水、悬崖或巨物尺度使用快速稳定后拉展开。一次提示词只保留一条主镜头路径，禁止为套模板而统一使用前推。
- 有静水倒影时，除非用户明确要波纹，写“水面保持镜面平静，倒影稳定完整”；其余动态元素应充分运动：云海快速翻涌或横向流动，瀑布高速连续下落，飞鸟快速扇翼并完成明确飞行路线，活体神兽完成大幅度且可辨认的动作。远景宫殿、石雕、建筑比例、光位、色调、人物身份应保持不变。
- **短视频必须有清晰可见的运动结果。** 含云海时，写前层云团快速横向推移、中层云快速翻卷、远层云相对稳定；含瀑布时，写高速水幕、飞散水雾与瀑底云汽；含飞鸟时，写连续快速扇翼、明确起点与终点，避免悬停；含活体巨龙、鲲或神兽时，写一次大幅抬首 / 转首 / 展翼 / 尾鳍摆动 / 游移，并交代它推动云雾或气流的反馈。允许云海、瀑布、飞鸟和巨兽同时具有强动态，但必须锁定各自的空间边界，不能遮没人物或冲向镜头。石雕、建筑和远山始终静止。
- 小比例人物可保持站立，也可沿画面引导线快步向纵深、侧前方或平台边缘移动。写清起点、屏幕方向、步幅、落脚、衣摆受风和投影移动；人物始终保持小比例，不能突然走近镜头或成为主体。
- 默认不在视频提示词中写具体秒数、时码或镜头时长；只写镜头、主体、环境的动作顺序。仅当用户明确指定时长、平台格式或需要按秒拆镜时，才写时长。无转场、无突然加速、无镜头抖动。

## 交付格式

除非用户要求解释，直接按以下格式给出。两段内容必须各自独立可复制。

```text
【绘图提示词】
...

【对应图生视频提示词】
...
```

输出前做一次一致性检查：机位没有互相冲突；人物数量、服色和位置前后一致；光源方向与投影方向一致；如果写了倒影，水面位置和被倒映物合理；没有把“静止”“缓慢运动”“无支撑 / 有地面”等相互矛盾的要求同时写入。
