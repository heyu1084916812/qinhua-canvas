# 情绪短片视觉构图创作

## 核心方法论

### 三层锚点体系

情绪短片需要在多镜头间保持视觉连贯性,同时允许构图灵活变化。核心是建立三层锚点系统:

**Layer 1: 风格锚点 (Style Anchor)**

- 定义: 用户认可的参考图像,固定整体美学调性
- 作用范围: 全片统一的色调、质感、光影处理方式
- 复用逻辑: 所有分镜生成时都引用风格锚点节点 (通过 reference_nodes 机制)
- 不变元素: 画风、色彩饱和度、光线质感、画面氛围

**Layer 2: 人物锚点 (Character Anchor)**

- 定义: 主角人物形象定版图,锁定面貌/身材/穿搭
- 作用范围: 同一角色在所有分镜中的视觉一致性
- 建立时机: 正式分镜制作前,先生成候选人物形象图供确认
- 不变元素: 面部特征、肤色、发型、体型、基础服装风格
- 可变元素: 不同季节场景下的穿搭细节(需符合人物整体气质)

**Layer 3: 构图锚点 (Composition Anchor)**

- 定义: 特定镜头的构图方式与视角设计
- 作用范围: 单个分镜的画面结构与空间关系
- 自由度最高: 可大幅调整角度、景别、框架元素
- 验证机制: 先生成静态图确认构图效果,通过后再转视频

### 先图后视频确认工作流

这是避免视频生成成本浪费的关键策略:

**Stage 1: 构图探索 (Image-based Exploration)**

- 目标: 快速验证构图方案的视觉效果
- 输出: 静态图像 (3-5秒生成,成本低)
- 决策点: 用户判断构图是否符合预期
  - 满意 → 进入Stage 2
  - 不满意 → 明确问题(角度/框架/主体比例)并重新生成图像
  - 方向错误 → 推翻当前方向,换新构图思路

**Stage 2: 视频生成 (Video Production)**

- 触发条件: 图像构图确认通过
- 执行方式: 基于确认图像作为首帧/参考生成视频
- 参数继承: 保持图像的构图、光影、人物姿态,只增加动态元素

**关键规则:**

- 绝不跳过图像确认环节直接生成视频(除非用户明确指定已有图像转视频)
- 每轮新构图方向都从图像开始,积累3-5个候选方案再批量确认
- 构图调整只在图像阶段迭代,视频阶段不做构图返工

### 特殊构图维度矩阵

常规构图(中景平视)容易产生视觉疲劳,特殊构图通过**维度组合**创造差异化:

**维度1: 视角高度轴**

- 仰拍(低角度向上): 强化框架感、透视感、压迫感
  - 适用: 建筑结构、屋檐、树枝框架、灯串天花板
  - 情绪: 渺小、仰望、憧憬
- 俯拍(高角度向下): 强化几何秩序感、全局视野
  - 适用: 楼梯间隙、操场分离、街道图案、书架网格
  - 情绪: 疏离、上帝视角、命运感
- 平视但超低/超高(极端化): 贴地/贴天花板拍摄
  - 适用: 车轮剪影、水面倒影、积水反射

**维度2: 框架遮挡轴**

- 前景遮挡: 透过障碍物窥视主体
  - 元素: 树叶间隙、书架空隙、玻璃反射、门框遮挡
  - 效果: 增加画面层次、暗示偷窥/观察视角
- 框中框: 建筑结构形成天然画框
  - 元素: 窗格、门洞、楼梯扶手、屋檐边缘
  - 效果: 聚焦视线、形式感强

**维度3: 主体比例轴**

- 极端特写: 局部充满画面
  - 对象: 眼睛、手指接触、呼吸细节
  - 时机: 情绪高潮时刻、细微互动
- 负空间: 人物占比极小,环境主导
  - 场景: 空旷操场、大片天空、空荡走廊
  - 情绪: 孤独、等待、渺小

**维度4: 光影关系轴**

- 剪影/逆光: 人物轮廓化,去除细节
  - 时机: 日落、夜晚路灯、强烈背光
  - 效果: 诗意化、去个体化、普遍情感
- 倒影/反射: 现实与镜像双重呈现
  - 媒介: 积水、玻璃橱窗、湖面
  - 效果: 虚实对照、内心外化

**维度5: 畸变变形轴**

- 鱼眼/超广角: 球形透视畸变
  - 场景: 狭窄空间(教室、走廊)放大空间感
  - 效果: 非常规视角、梦境感

**组合策略:**

- 单个分镜只突出1-2个维度(如"仰拍+框架感""俯拍+负空间")
- 避免维度堆叠过度(如同时用鱼眼+剪影+极端特写会混乱)
- 系列分镜覆盖多维度,避免重复使用同一组合

## 工作流程

### 1. 准备阶段

**输入清单:**

- \[ \] 用户提供或选定风格参考图(3-5张,确保风格统一)
- \[ \] 短片主题与情绪基调(如"青春懵懂期恋爱""分离与重逢")
- \[ \] 时长与结构框架(如"1分钟,四季流转""30秒,单一场景情绪爆发")
- \[ \] 人物设定(数量、性别、年龄段、关系)
- \[ \] 是否需要环境音效/BGM(情绪短片建议纯环境音)

**锚点建立流程:**

1. **风格锚点确认**

   - 将用户认可的参考图保存为风格锚点节点
   - 记录到锚点清单文件(`anchors/style_anchors.md`)
   - 所有后续生成调用这些节点作为reference_nodes

2. **人物锚点生成**

   - 基于风格锚点 + 用户人物描述,生成主角候选形象图(每角色2-3张候选)
   - 用户确认选定后,保存为人物锚点节点
   - 记录到锚点清单(包含面貌特征、服装基调描述)

3. **分镜框架规划**

   - 根据时长拆解分镜数量(通常5-10秒/镜,1分钟约10-15个分镜)
   - 按主题结构分组(如按时间/季节/情绪起伏划分批次)
   - 创建分镜表文件(`story_boards/task_[id].md`),包含:
     - 分镜编号、时长、场景、构图类型、情绪关键词
     - 预留node_key字段供后续关联生成节点

### 2. 分批生成阶段

**首批常规分镜**

目标: 建立叙事骨架,用相对常规的构图确保故事连贯

- 构图类型: 以中景、远景、侧面跟拍为主
- 生成策略: 直接生成视频(无需先出图确认,因构图常规风险低)
- 数量: 覆盖约40-50%总时长(为特殊构图留空间)
- Prompt结构:

  ```
  [场景环境描述] + [人物动作] + [情绪氛围] + [镜头运动]
  Reference: 风格锚点节点 + 人物锚点节点
  Duration: 5-10s
  Audio: 环境音效(具体声音类型)
  ```

**特殊构图补充轮次**

目标: 增加视觉冲击力和艺术性,打破常规镜头的单调感

1. **规划构图方向**

   - 根据已有分镜的构图分布,选择未覆盖的特殊维度
   - 示例: 已有5个常规中景 → 补充2个仰拍框架 + 1个极端特写 + 1个剪影

2. **生成候选图像**(关键步骤)

   - 每轮生成3-5张不同构图方向的静态图
   - Prompt明确标注构图维度:

     ```
     [特殊构图描述:如"ultra-low angle, looking up through tree branches"]
     + [场景] + [人物(引用锚点)] + [情绪]
     Reference: 风格锚点 + 人物锚点
     Output: Single frame image
     ```

3. **用户逐张确认**

   - 提问格式: "这张\[构图类型\]效果如何? 通过→转视频 / 不满意→说明问题 / 不需要→跳过"
   - 不满意时追问具体维度:
     - 角度问题? → 调整视角高度
     - 框架问题? → 调整前景遮挡元素
     - 主体比例问题? → 调整景别或裁切
   - 记录通过的图像节点,进入视频生成队列

4. **批量转视频**

   - 将确认通过的图像作为视频生成的首帧/参考
   - Prompt继承图像的构图参数,增加动态描述:

     ```
     Based on [image_node], generate video:
     [原构图描述] + [微动作:如"slight head turn""leaves gently swaying"]
     Camera: locked(if 构图强调框架感) / slow drift(if 需要轻微运镜)
     Duration: 5-10s
     ```

5. **验证与记录**

   - 生成后检查artifact.url字段是否返回(确保真实生成成功)
   - 更新分镜表,记录node_key和实际时长
   - 如遇"status=1但无artifact"情况,先询问用户是否在画布可见,再决定是否重试

**迭代原则:**

- 分批推进(每批3-5个分镜),避免一次性生成全部导致后期大量返工
- 用户每确认一批,询问是否继续下一批或调整方向
- 保持常规构图与特殊构图的平衡(约6:4或7:3比例)

### 3. 替换与补充阶段

**场景替换**

触发条件: 用户发现某些分镜场景重复或不够多样化

- 确认替换范围: 用户指定具体分镜编号
- 替换策略:
  - 保持构图类型和情绪节拍不变
  - 只改场景环境(如"校园操场"→"商场门口""巷口"→"地铁站台")
- 重新生成并更新分镜表的scene字段和node_key

**构图替换**

触发条件: 用户对某个分镜的构图效果不满意

- 流程: 先生成新构图的图像候选 → 确认 → 替换原视频节点
- 标记原节点为deprecated(不删除,保留在画布但注明已被替换)

**补充镜头**

触发条件: 用户在混剪时发现需要更多转场素材或特定情绪镜头

- 类型:
  - 空镜头(pure environment shots): 无人物,纯环境氛围
  - 过渡镜头(transition shots): 连接两场景的视觉桥梁
  - 情绪特写(emotion close-ups): 强化关键时刻的细节
- 流程: 同特殊构图补充轮次(先图后视频确认)

## 关键约束与标准

### 不可变规则

1. **风格一致性**

   - 所有分镜必须引用同一组风格锚点节点
   - 色调、光影质感、画面氛围必须统一
   - 测试方法: 将所有分镜截图并排,视觉上应像同一部作品

2. **人物一致性**

   - 同一角色在所有分镜中面貌、体型不变
   - 测试方法: 关键面部特征(眼睛形状、鼻梁轮廓、脸型)可识别对应
   - 容忍度: 允许光影、角度导致的外观差异,但五官结构必须稳定

3. **先图后视频验证**

   - 所有特殊构图方向必须先出图确认
   - 例外情况: 用户明确指定"直接生成视频"或"基于已有图像转视频"

### 保真度规则

1. **构图保真**

   - 图像确认时的构图框架,视频生成必须严格保持
   - 不可接受: 图像是仰拍,视频变成平视
   - 允许: 轻微机位漂移(slow drift)以增加动态感,但主体构图不变

2. **环境音效设计**

   - 每个分镜根据场景配置对应环境音(风声/脚步/蝉鸣/雪落/翻书声等)
   - 无对白短片: 绝不添加对话或旁白
   - 无BGM短片: 只保留自然环境音,不添加配乐(除非用户明确要求)

3. **时长控制**

   - 单个分镜: 5-10秒(情绪镜头可短至3秒,叙事镜头可长至12秒)
   - 总时长: 允许超出目标10-15%(为完整叙事留余地)
   - 不可接受: 为凑时长强行拉长单镜头或添加无意义镜头

### 一致性审查清单

**批次生成后必检项:**

- \[ \] 所有节点status=1且有真实artifact.url
- \[ \] 分镜表已更新node_key和actual_duration字段
- \[ \] 画布上节点顺序与分镜编号一致
- \[ \] 人物面貌在同批次内稳定(抽查3-5帧对比)
- \[ \] 风格色调统一(无突然变暗/变亮/变色的异常)

**特殊构图批次额外检查:**

- \[ \] 构图类型与分镜表描述一致(如标注"仰拍"实际是仰拍)
- \[ \] 特殊维度确实体现(如"框中框"有明显前景遮挡)
- \[ \] 未过度堆叠维度(避免"鱼眼+剪影+极端特写"同时出现)

## 高级技巧

### 季节/时间感的构图强化

不同季节适合不同构图维度:

**春季:**

- 仰拍树枝框架(樱花/新叶)
- 正面逆光(柔和阳光)
- 负空间(空旷感,新生气息)

**夏季:**

- 强烈剪影(正午/傍晚强光)
- 水面倒影(湖边/积水)
- 极端特写(汗珠/蝉鸣细节)

**秋季:**

- 俯拍落叶几何(地面图案)
- 框中框(枯枝门框)
- 负空间(萧瑟感)

**冬季:**

- 仰拍屋檐雪挂(寒冷框架感)
- 纯色块面(大片白雪背景)
- 呼吸特写(哈气雾化)

### 情绪转折的构图切换策略

- **情绪上升**: 常规中景 → 仰拍(开阔感) → 特写(亲密感)
- **情绪下降**: 远景(全局) → 负空间(疏离) → 剪影(去个体化)
- **情绪爆发**: 快速切换多种极端构图(鱼眼→极端特写→俯拍→逆光)
- **平静收尾**: 回归常规中景或对称构图(稳定感)

### 混剪节奏建议

- **开场**: 1-2个环境空镜(建立氛围)
- **主体部分**: 常规叙事镜头为主(60-70%),特殊构图点缀(30-40%)
- **高潮**: 集中使用特殊构图(3-5个连续极端镜头)
- **收尾**: 回归1个标志性常规镜头或对称镜头(呼应开场)

镜头切换频率:

- 平静段落: 每镜5-10秒
- 紧张/激动段落: 每镜3-5秒
- 高潮: 每镜2-3秒(快切)
