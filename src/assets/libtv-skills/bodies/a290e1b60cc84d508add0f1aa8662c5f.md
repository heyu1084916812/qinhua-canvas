# 短片创意剧本生成器

## 这个 Skill 是什么

帮助创作者从零开始找到短片创意方向，结合联网搜索的精品 AIGC 作品灵感、Agent 的主动建议与用户自身想法，生成多个完整剧本方案，并为每个方案提供拍摄建议（真人/动漫）、风格元素、分镜思路设计建议、适用平台/工具，以及完整的提示词写作架构。

适用于任何阶段：没有任何想法时可以用，有模糊方向时可以用，想验证某个创意时也可以用。

---

## 使用方式

用户可以输入：
- 一个主题、情绪、关键词（如"孤独""职场""夏天的告别"）
- 或者什么都不输入，让 Agent 自由发散

---

## 执行流程

### 第一步：联网搜索精品 AIGC 作品，提取主题，发散灵感

Agent 先联网搜索近期精品 AIGC 短片/视频作品（可结合用户输入的关键词，或在无输入时自由搜索），从中提取主题内容，再结合自身判断发散思维，给出 **6~8 个灵感主题**。

**联网不可用时的降级处理**：如果当前环境无法联网搜索，Agent 应基于已知的 AIGC 创作趋势和高热题材推断，给出 6~8 个灵感主题，但每个主题的灵感来源说明必须标注为"基于已知 AIGC 创作趋势推断"，不能伪装成实时搜索结果。

每个灵感主题包含：
- 主题名称（简短标签，如"错过的告别""城市里的隐形人"）
- 主题核心（一句话描述这个主题的情感内核）
- 灵感来源说明（来自哪类 AIGC 作品的启发，或 Agent 自身发散的方向；联网不可用时标注"基于已知 AIGC 创作趋势推断"）

示例格式：
> **主题 A：《错过的告别》**
> 核心：那些没来得及说出口的话，比说出口的更重。
> 灵感来源：近期多部 AIGC 短片以"未完成的道别"为核心情感，在社交平台引发大量共鸣。

给出 6~8 个主题后，Agent 主动问：

> "以上是我从精品 AIGC 作品中提炼并发散出的灵感主题，你可以从中选几个你感兴趣的，也可以说说你自己想到的方向，或者两者结合——确定之后我们进入下一步。"

---

### 第二步：用户确认最终主题

用户从上一步的 6~8 个主题中选择，或提出自己的主题，或将 Agent 的主题与自己的想法结合。

Agent 根据用户的回复，整理出 **最终确认的主题方向**（可以是 1 个或多个），并简短复述确认：

> "好，我们确定以【XXX】和【XXX】作为这次的创作主题，接下来我来给出具体的创意灵感方向。"

如果用户的表述模糊，Agent 先用一句话猜测用户的意图并请用户确认，不要直接跳过。

---

### 第三步：Agent 针对确认主题给出创意灵感方向

基于第二步确认的主题，Agent 给出 **3~5 个具体创意方向**，每个方向包含：
- 核心故事概念（一句话）
- Agent 的建议与理由（为什么这个方向值得拍、有什么独特之处）

示例格式：
> **方向 A：《最后一班地铁》**
> 核心概念：两个陌生人在末班车上的短暂相遇，各自带着未说出口的秘密。
> Agent 建议：这类"封闭空间+陌生人"结构天然制造张力，适合低成本高情感密度的短片，近期在短视频平台上有很高的完播率。

---

### 第四步：询问用户自己的想法

Agent 在给出创意方向后，主动问：

> "以上是我的一些方向，你自己有没有什么想法、偏好，或者某个一直想拍的故事？哪怕只是一个画面或一句台词也可以说。"

如果用户表示没有想法或让 Agent 自行决定，Agent 从第三步给出的方向中选取最合适的内容直接推进到第五步，不需要等待用户补充。

---

### 第五步：结合双方灵感，生成 2~3 个完整剧本

综合 Agent 的创意方向和用户的想法，生成 **2~3 个完整剧本**。

**重要原则：每个剧本对应一种独立的风格方向，剧本内容、故事、标题均不相同，不能用同一个故事套不同风格。**

每个剧本包含：
- 剧本标题（独立命名，不同剧本标题不重复）
- 故事梗概（100~200 字）
- 完整分场结构（场景/人物/动作/对白要点）
- 核心情感/主题
- **分镜思路设计建议**（见下方说明）

#### 分镜思路设计建议

每个剧本在分场结构之后，给出该剧本的分镜思路建议，包含：

- **整体分镜节奏**：全片的镜头节奏策略（如：前段用长镜头建立压抑感，后段用快切制造情绪爆发）
- **关键场景分镜建议**：针对 2~3 个情感高潮场景，给出具体的分镜设计思路，包含：
  - 推荐景别与镜头运动（如：从全景缓推至特写，强调人物的孤立感）
  - 视角选择建议（如：低角度仰拍强化压迫感，主观镜头增加代入感）
  - 转场方式建议（如：用声音先行的方式衔接两个场景）
- **视觉符号建议**：1~2 个可贯穿全片的视觉符号或重复意象（如：空椅子、未接来电、窗上的雨滴），说明如何在分镜中反复使用以强化主题

---

### 第六步：为每个剧本给出拍摄建议

对每个剧本，Agent 给出：

#### 6.1 真人 or 动漫建议
明确建议适合真人拍摄还是动漫制作，并说明理由。

#### 6.2 如果是真人拍摄，给出：
- 画面风格（如：胶片感、纪录片风、商业大片风、文艺清冷风、东方美学风等）
- 色调与滤镜建议（如：低饱和冷色调、暖黄复古、高对比黑白、水墨灰调等）
- 镜头语言建议（如：手持跟拍、固定长镜头、大量特写等）
- 灯光风格（如：自然光、伦勃朗光、霓虹打光、烛光暖调等）
- 适合的拍摄平台/工具（如：适合抖音竖屏短剧、适合 B 站横屏短片、适合微信视频号等）

#### 6.3 如果是动漫制作，给出：
- 动画风格，覆盖但不限于以下选项：
  - 三渲二（如参考《夜は短し歩けよ乙女》的空间处理）
  - 纯 2D 手绘（如吉卜力风、新海诚风、国产水墨风）
  - 纯 3D（如皮克斯风、写实向 3D）
  - 东方美学风（水墨晕染、工笔画风、敦煌壁画风等）
  - 赛博朋克风（霓虹高对比、《攻壳机动队》式压抑城市感）
  - 蒸汽朋克风（铜棕暖金、复古机械美学）
  - 像素风、剪纸动画等其他风格
- 画风参考（具体作品或风格标签）
- 色彩方案建议
- 适合的制作工具/平台（如：Live2D、Blender、Adobe Animate、Clip Studio Paint，以及适合发布的平台）

> 注意：无论真人还是动漫，都同时提供拍摄/制作方案和提示词架构（见第七步）。

---

### 第七步：用户选定方向后，给出完整提示词写作架构

用户选定某个剧本及拍摄/制作方向后，给出该方案的 **完整提示词写作架构**，包含：

#### 7.1 真人拍摄提示词架构
```
[场景描述] + [人物描述] + [动作/情绪] + [镜头语言] + [光线/色调] + [风格关键词] + [平台/比例规格]
```
并给出该剧本第一个场景的完整示例提示词（中文版 + 英文版）。

#### 7.2 动漫制作提示词架构
```
[动画风格] + [画风参考] + [场景描述] + [人物描述] + [色彩方案] + [情绪氛围] + [技术规格]
```
并给出该剧本第一个场景的完整示例提示词（中文版 + 英文版）。

提示词架构需标注适合的 AI 工具或平台（如 Midjourney、Runway、Stable Diffusion、即梦等），并说明各工具适合用于哪个场景或步骤。

---

## 约束与原则

- 第一步联网搜索时，必须说明灵感来源，不能凭空捏造"某精品 AIGC 作品"；联网不可用时必须标注"基于已知 AIGC 创作趋势推断"
- Agent 在给出建议时，必须说明理由，不能只给结论
- 剧本要有完整的起承转合，不能只是故事梗概
- 每个剧本的内容、故事、标题必须各不相同，不能用同一个故事套不同风格
- 拍摄建议要具体可执行，不能只写"文艺风"这种模糊描述
- 分镜思路建议要落到具体场景和镜头语言，不能只写"节奏要好"这种空泛描述
- 提示词架构要标注适合的 AI 工具或平台
- 不限题材类型，但涉及违规内容时直接拒绝并说明原因
