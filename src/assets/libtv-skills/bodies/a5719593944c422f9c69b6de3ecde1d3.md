# 天宫美学 Skill

## 一、基础设定

1. **默认模型**：Lib Image

2. **默认画幅**：16:9 横版

3. **默认出图数量**：1 张稳定经典版；只有用户明确要求时才生成多版

4. **提示词展示规则**：生成图片前，必须先向用户展示完整六段式提示词

5. **视频 / 音乐规则**：只输出“完整版 + 精简版”提示词，不自动生成

---

# 二、核心审美原则

默认气质：\
**超写实、电影级、东方神话、庄严、克制、神圣、空灵、苍茫、低饱和、真实材质、强空气透视、大面积留白、高级电影美学。**

避免：\
**艳丽廉价仙侠游戏风、过度金碧辉煌、霓虹色、密集粒子、现代建筑感、古风写真感、元素堆砌、人物抢主体。**

创作顺序：

1. 先定镜头

2. 再定空间

3. 再定主体

4. 再定奇观

5. 人物作为尺度参照

6. 神兽作为点睛

空间层级：

- **近景**：巨松、宫柱、屋檐、岩石、虚化枝叶

- **中景**：人物、平台、长廊、白玉栏杆、桥、镜湖

- **远景**：天宫、月宫、天门、主殿、宫殿群

- **超远景 / 奇观终点**：巨月、圆门、鲲、龙、瀑布、倒影、天河尽头

---

# 三、固定六段式提示词结构

## 1）整体描述

作用：一句话说明“是什么场景 + 核心奇观 + 整体气质”。

模板：

> 超写实电影级东方神话场景，【主题名称】，画面围绕【核心奇观】展开，整体呈现【神圣 / 空灵 / 庄严 / 苍茫 / 超现实 / 安静】的东方天界气质。

要求：

- 不堆砌细节

- 先锁定主题

- 明确唯一视觉核心

- 确定情绪与世界观

---

## 2）构图形式

作用：先规定镜头语言，再安排画面元素。

模板：

> 16:9 横版画面，超广角远景，采用【构图类型】。近景由【前景元素】形成遮挡或框景，中景为【平台 / 长桥 / 长廊 / 镜湖 / 人物区域】，远景主体为【天宫 / 月宫 / 天门 / 主殿】，视线最终落在【奇观 / 神兽 / 巨月 / 圆门】。

常用构图：

- 中轴对称

- 极端偏心

- 前景压框

- 框中框

- 强对角透视

- 长廊引导线

- S 形引导线

- 反透视

- 中央空洞

- 上下镜像

- 高机位鸟瞰

构图规则：

- 不默认中轴对称

- 构图必须服务主题

- 前景可占画面约 25%–50%

- 可让建筑被画面边缘裁切，增强巨大尺度感

- “局部显露”优先于“全部展示”

- 必须形成明确视线路径：\
  **前景框景 → 中景人物 → 远景建筑 → 深处奇观**

---

## 3）主体场景描述

作用：按照空间层级描述画面，而不是单纯堆元素。

固定顺序：

**前景 → 中景 → 远景 → 奇观 / 神兽**

模板：

> 无边无际的厚重云海铺满整个世界，【前景元素】贴近镜头形成空间层次；【中景空间】作为视觉过渡；远处主体建筑由白玉基座、朱红木构、层叠飞檐与淡金屋脊组成，半隐在云海与轻雾之间。画面中只出现一种神兽——【仙鹤 / 鲲 / 龙】，【数量、位置、状态】。

常用建筑语言：

- 白玉基座

- 汉白玉栏杆

- 朱红木构

- 层叠飞檐

- 淡金屋脊

- 高耸门楼

- 巨型宫柱

- 月洞门

- 回廊

- 白玉平台

- 云纹 / 龙纹 / 卷草纹浮雕

材质要求：

- 白玉具有真实石材与微弱透光感

- 木构符合中国古建结构逻辑

- 石材有重量感、风化感和纹理变化

- 云海遵循真实积云与大气规律

- 建筑尽量具有真实中国古建逻辑，不做游戏式悬浮城堡

---

## 4）氛围描述

作用：统一时间、光线、色彩和空气透视。

默认光影：\
**低角度暖金色侧逆光 / 侧后光**

模板：

> 时间设定为【清晨 / 傍晚 / 月升时刻 / 拂晓】，暖金色低角度阳光从【左侧 / 侧后方】照射，形成柔和侧逆光效果，【白玉栏杆 / 屋檐 / 古松 / 人物衣袍 / 神兽边缘】泛起金色轮廓光，远处主体被轻雾包裹，空气透视明显。天空以天青灰、浅蓝灰为主，云海呈象牙白、暖灰白，整体低饱和、通透、神圣、安静。

推荐配色：

- 天青灰

- 浅蓝灰

- 月白

- 象牙白

- 暖灰白

- 朱砂暗红

- 深松绿

- 少量暖金

经典明暗关系：\
**暗前景 → 暖中景 → 亮远景**

避免：

- 平坦正面光

- 多个冲突光源

- 高饱和 RGB 色

- 紫红、洋红、霓虹青等现代炫彩

- 不符合逻辑的强“神光”

---

## 5）人物描述（比例 / 位置 / 状态）

作用：人物不是主体，而是尺度参照与叙事锚点。

模板：

> 画面【中下方 / 中景平台 / 长桥转折处 / 长廊内 / 栏杆边缘】有【1 / 2 / 3】名极小人物，约占整体画面的【1%–3%】，人物身穿【浅青 / 月白 / 米白 / 淡粉】古代长袍，背对镜头，【缓慢行走 / 静静驻足 / 远望】，不强调面部，只作为尺度参照与叙事锚点。

人物规则：

- 默认 1%–3%

- 特殊中景可放宽到 3%–5%

- 以背影为主

- 不强调五官

- 不做近景人物写真

- 动作克制

- 1 人：孤绝、凝望

- 2 人：同行、朝圣

- 3 人：叙事、仪式感

---

## 6）画面美感控制

作用：规定最终审美方向，并限制模型跑偏。

模板：

> 整体追求东方神话现实主义与电影级概念艺术质感，强调【核心视觉母题】、空间秩序、材质统一、低饱和高级配色与大面积纯净留白。避免人物占比过大，避免神兽过多，避免艳丽仙侠游戏风，避免现代建筑感，避免杂乱装饰、霓虹色、粒子特效和古风写真感。画面要庄严、克制、真实、空灵，具有超写实材质、真实体积光与高级电影美学。

必须检查：

- 是否有唯一视觉核心

- 是否有清晰前中远景

- 是否存在足够留白

- 是否具有真实中国古建逻辑

- 是否低饱和

- 是否避免游戏感

- 是否避免过度金碧辉煌

- 是否具有电影摄影式空间层次

---

# 四、神兽规则

## 总规则

**一个画面只出现一种神兽。**

神兽必须：

- 数量克制

- 位于远景 / 天空 / 云层

- 不抢主体

- 最好成为视觉路径终点

- 可被云雾部分遮挡，保持神秘感

## 仙鹤

适合：\
镜湖、月宫、巨松、长桥、白玉平台。

数量：\
**2–5 只**

状态：

- 掠过月宫

- 飞过镜湖

- 停驻栏杆

- 停驻枝头

关键词：\
**轻盈、清冷、诗意、祥瑞、空灵**

## 鲲

适合：\
万丈云海、断崖天宫、圆门奇观、巨型神域。

数量：\
**仅 1 只**

状态：

- 云海深处若隐若现

- 只露背脊、尾部或远景轮廓

- 横穿巨大圆门

- 缓慢从云层显现

关键词：\
**苍茫、远古、神迹、巨大尺度、宁静**

## 龙

适合：\
天门、神桥、天河、主殿、神域入口。

数量：\
**仅 1 条**

状态：

- 盘旋天门上方

- 若隐若现于云层

- 顺天河走势远去

- 作为远景守护象征

关键词：\
**威仪、守护、秩序、庄严、神域**

# 六、图片生成工作流

用户输入主题后：

### 第一步：判断场景

识别：

- 核心主题

- 核心奇观

- 最适合的构图

- 前中远景

- 是否需要神兽

- 人物数量

- 时间与光影

### 第二步：输出完整六段式提示词

必须严格按照：

1. 整体描述

2. 构图形式

3. 主体场景描述

4. 氛围描述

5. 人物描述

6. 画面美感控制

### 第三步：展示给用户

在图片生成之前，完整展示六段式提示词。

### 第四步：生成

默认：

- 模型：Lib Image

- 比例：16:9

- 数量：1 张

- 风格：稳定经典版

只有用户明确说“出 4 版”“多出几版”等，才生成多版。

- 光影戏剧性

- 建筑显隐程度

- 神兽清晰度

- 人物位置

推荐：

- **A 稳定经典版**

- **B 空灵留白版**

- **C 空间强化版**

- **D 戏剧光影版**

- 远景

# 九、图生视频提示词工作流

核心原则：

**建筑稳，环境动，人物微动，神兽慢动，镜头克制。**

用户要求视频提示词时，只输出：

- 完整版

- 精简版

不自动生成视频。

## 完整版模板

> 保持原图【构图类型】稳定不变，建筑、【前景元素】、【中景元素】结构完全稳定，无变形和抖动。云海缓慢翻涌，薄雾沿【空间路径】轻柔穿行；【神兽】在【位置】极缓慢【动作状态】，动作舒展克制；【人数】名人物【动作】，衣袍和长发轻微飘动。镜头采用【运镜方式】，速度极慢。保持建筑、栏杆、柱列、【核心结构】和人物结构稳定，避免建筑变形、人物瞬移、神兽体型突变、云层剧烈翻滚、快速运镜、画面抖动和突然变焦。

## 精简版模板

> 【运镜方式】，云海缓慢翻涌，薄雾穿行，【神兽】极缓慢【状态】，人物【动作】，衣袍轻微飘动，建筑全程稳定，无抖动、无变形。

推荐运镜：

- 极慢前推

- 小幅弧形环绕

- 轻微抬升

- 轻微侧移

- 贴柱列平移

避免：

- 快速环绕

- 猛推

- 快速变焦

- 大幅旋转

- 强烈手持感

# 十、国风 AI 音乐提示词工作流

用户要求音乐提示词时，只输出：

- 完整版

- 精简版

不自动生成音乐。

## 完整版模板

> 高级东方美学国风电影配乐，缓慢、轻柔、空灵、神圣、克制，带有【主题情绪】。以古琴、洞箫为核心旋律，埙作为远景色彩点缀，柔和弦乐作为极淡背景铺底，编钟与远处古钟在关键节点轻敲，【可选：极轻低频鼓偶尔沉响】。旋律极简、舒展，大量留白，不追求传统民乐炫技，整体像【画面描述】的东方神话电影长镜头。声音空间宽广、通透、悠远，冷暖交织，带一点古老神秘感与极轻史诗气息。纯音乐，无人声，无强鼓，无电子舞曲节奏，无激烈高潮。

## 精简版模板

> 国风电影配乐，古琴 + 洞箫 + 埙 + 编钟，缓慢、空灵、【情绪关键词】，大量留白，极轻史诗感，纯音乐，无人声。

推荐乐器：\
古琴、洞箫、箫、埙、轻柔弦乐、编钟、古钟、极轻低频鼓。

避免：\
强鼓点、热血仙侠、高频密集旋律、流行歌曲结构、EDM、过度煽情、炫技演奏。

# 十二、高级技巧

## 大留白构图

适合：\
空灵、禅意、孤绝、远观型天宫场景。

调整：

- 天空 / 云海留白占 60%–70%

- 中景建筑密度降低约 50%

- 远景建筑几乎消失在晨雾中

- 色彩更偏蓝灰，减少金色

- 强化“极简构图、巨大空旷感、东方山水留白”

## 戏剧光影

适合：\
史诗海报、神迹显现、强逆光场景。

调整：

- 前景增加剪影

- 远景主体形成强逆光光晕

- 体积光穿过云层

- 增强明暗对比

- 仍保持低饱和与真实光源逻辑
