# 人物设定图共创

## 这个 skill 做什么

用户手上只有一个模糊的角色想法（甚至只有"帮我设计一个角色"这一句）时，先问清这次是「修改已有角色」还是「新建角色」，再按对应分支逐项询问角色要素，最终合成一份完整的角色设定文字，用户确认后再出一张 16:9 横版设定图。

**每个要素在回答文字之外，都可以补充参考图片**；结合文字要求与参考图生成该要素的设定内容。

**产出的核心承诺**：用户说的每一句意图，都必须在最终设定里找到对应的具体落点。达不到这一点，出图就一定不是用户预期的那个人。

## 什么时候用 / 什么时候不用

**用：**

- 从零造一个新角色、用户自己说不清具体设定时。
- 用户已有角色设定文字或参考图，只想出设定图时（跳过要素询问，直接整理设定后出图）。
- 用户想调整自己已有的角色（改造型、改服装、改气质等）时。
- 用户习惯"甩图说话"：用参考图代替文字描述某个要素时。

**不用：**

- 用户已经给出完整、可直接出图的提示词，只差生成——走通用出图即可。
- 真人、明星、已有版权角色（动漫 / 游戏 / 影视中的既有角色）的形象（参考图是这类形象时同样不适用）。

## 为什么"问得全"是成败关键

出图结果不达预期，根因几乎总是同一个：**前期没问到的部分，出图模型会用一个"平均值的默认角色"替你补上**——于是出来的不是你想的那个人。

所以本 skill 的第一原则是：**把用户的意图完整地抓到提问环节里**。凡是有可能影响成图的信息，宁可在提问阶段多问一句，也不要在出图阶段靠脑补。

推论出三条硬要求：

1. **意图优先**：先抓住用户"想要什么感觉、用来做什么、绝对不要什么"，再问具体要素。带着意图问，问题才问得准。
2. **要素问透**：每个要素都要问到"能直接画出来"的程度，含糊就地追问，不问到具体不下线。
3. **产出回扣**：合成设定文字时，逐条检查每条意图是否都落到了具体要素上。落不到就回去补问。

## 工作流

### 第 1 步 · 先问清：修改已有角色，还是新建角色

提问环节的第一个问题固定是：这次是「修改已有角色」，还是「新建角色」？不要替用户猜，也不要把它和后面的要素询问混成一问。

- **修改已有角色** → 进入第 2 步的「修改分支」。
- **新建角色** → 进入第 2 步的「新建分支」。
- **例外（直出模式）**：用户已提供完整设定文字或参考图，且明确只是要出一张设定图、不需要改动任何设定时，直接跳到第 3 步，把已有设定整理成结构化文字供用户确认。此时仍要做第 3 步的「意图回扣自检」，缺口照常补问。

### 第 2 步 · 逐项询问角色要素

**核心节奏：一次只问一个问题，且必须拿到该问题的明确、可用的答案之后，才提出下一个问题。** 不在一轮里同时抛出多个要素，也不把全部字段一次丢给用户填表。

- **什么算"准确答案"**：该要素能得到足以写进设定文字、并能直接转成出图提示词的具体描述（具体到颜色、长度、轮廓、材质、纹样、质感、脸型轮廓等可画面化的程度）。只得到笼统、空泛或含糊的回答（如"好看就行""随便""都行""普通的"）不算拿到准确答案。
- **答案不明确时**：就当前这一项继续追问澄清，直到拿到明确答案；不跳到下一项，也不带着含糊答案往下走。追问仍一次只问一个问题。
- **善用"追问子弹"**：每个要素下方列有 2–4 个可画面化的子维度。用户回答含糊或太短时，从这个要素的"追问子弹"里挑**一个**最相关的往下问，帮用户把话说具体。一次只挑一个，不要把子弹一次全打出去。
- **用户明确说"你定 / 你来决定"时**：针对当前这一项给出若干具体候选让用户挑选（不是一句"我帮你定了"就跳过），用户选定即为该项的准确答案；用户让 Agent 全权定夺时，给出的具体结果要在第 3 步设定文字里一并交用户确认。
- **用户一次答了多项时**：并就即可，但仍不主动合并提问；未被答到的项照常逐项问。
- **参考图与文字冲突、或只给图不给文字时**：先复述从图中读到的内容请用户确认或纠正；冲突先请用户取舍。确认到位才算拿到该项的准确答案，再问下一项。

**每次提问都要明确告知用户：这一项可以用文字回答，也可以直接给参考图，或者图文一起给。**

- 参考图可以是某个要素的单独参照（发型图、脸型图、服装图、气质氛围图、肤色肤质图、妆容图等），也可以是一张整体人物图；只取图中与所问要素相关的部分作为依据。
- 记清每张参考图对应哪个要素，不要把服装图当成发型依据，也不要把服装图当成脸型依据。
- 用户只给图、不给文字时，先用一句话复述自己从图中读到的要素内容（如"发型按图理解为黑色及腰长直发、发尾内扣"），请用户确认或纠正，再写进设定文字。
- 文字与参考图互相冲突时（例如文字说短发、图是长发），先向用户点明冲突并请其取舍，不自行选一个，也不默默忽略其中一方。

> 各要素的详细追问维度（"追问子弹"）见 `references/question-bank.md`。提问时按需读取，不必一次性全读。

#### 新建分支

按下列顺序从零问必问要素，**一项一问、问完一项再问下一项**。每项都适用上面的"文字或参考图"规则与核心节奏。

##### 第零组 · 意图前置（最先问，新建分支必问）

> 这一组是**新增的核心环节**。作用是先把用户的"预期"抓到台面上，后面所有要素都带着这个预期去问。不要跳过，也不要因为用户催进度就省略。

**0-1. 用途与定位**

这个角色是用来做什么的？决定出图的侧重。

- 追问子弹：戏份（主角 / 重要配角 / 路人 / NPC）？载体（小说插画 / 游戏立绘 / 动画人设 / 同人创作 / 单纯收藏）？最需要在图里突出的是哪个方面（脸 / 服装 / 气质 / 某个特征）？

**0-2. 整体感觉与风格倾向**

抛开具体设定，你希望这个角色给人什么感觉？有没有想参考的风格或作品氛围？

- 追问子弹：一句话氛围（如"清冷疏离""热烈张扬""阴郁危险""温柔可靠"）？时代或审美倾向（古风 / 赛博 / 蒸汽朋克 / 现代都市 / 废土）？有没有参照的作品或画风？

**0-3. 禁忌与"不要什么"**

有没有明确不想要的？用户经常靠"我不要 XX"来表达预期，这一问专门承接它。

- 追问子弹：不要的配色 / 元素 / 气质？不想要的既视感（"别像某角色"）？必须避开的雷区？

##### 前置项 · 角色整体造型参考图（新建分支必问）

先问用户是否有"角色整体造型参考图"——一张呈现角色整体造型的参考图，如全身人设图、造型氛围图。

- 答"**无**"：不再追问、也不问风格，沿用默认三块锚点（默认风格 / 默认质感 / 默认光影），直接进入第一组·世界观的题材背景。
- 答"**有**"并给出图后，按以下三条规则处理：
  1. **读取范围**：该图**仅供参考**，从中读取的内容限定为以下几类，不吸收背景、水印、其他角色等无关内容——五官、发型、脸型、身材（含胸、腰、臀、臂、手、腿、足的具体特征）、妆容、造型（发型、面部与整体造型细节）、服装（款式、版型、配色、纹样、材质）。
  2. **风格判定与追问**：出图默认锚点仍为**高精度 3D 半写实国漫风格**。判断该图风格——该图本身是高精度 3D 半写实国漫风格时，不追问风格，直接沿用默认锚点；该图**不是**该风格（如 2D 插画、赛璐璐、写实、像素、水墨、手绘等）时，**必须就风格单独问一次**"采用什么风格"，给出候选让用户挑（至少含：保持默认高精度 3D 半写实国漫风格、按这张参考图的画风出、其他可行风格），拿到明确答复才定风格。这一问同样遵守"一次只问一个问题"，用户未明确选定前不自行决定风格。
  3. **参考答案机制**：读取到的内容不单独成问答，而是拆到后续对应的提问环节里当参考答案使用——问到该要素时（如问到发型），先把从参考图中读到的该要素内容作为参考答案说出来（如"参考图里的发型是黑色齐肩外翘短发"），请用户确认、纠正或另给答案；用户认可即为该要素的准确答案，用户改的以用户为准。对应关系见下表。

| 参考图读取内容 | 归入的提问环节 |
| --- | --- |
| 五官 | 五官问 |
| 发型 | 发型问 |
| 脸型 | 脸型问 |
| 身材各部位（胸腰臀臂手腿足） | 身材比例问，以及手臂与手部问、腿部问等对应部位 |
| 妆容 | 妆容问 |
| 造型（发型、面部与整体造型细节） | 分别归入对应要素问 |
| 服装 | 服装风格问 |

参考图里没有对应内容的要素，照常正常提问，不硬塞参考答案。该机制**不改变**分组与提问顺序，也**不减少**任何一项提问。

##### 第一组 · 世界观与种族

**1. 题材背景**（世界观 / 时代 / 地域）

- 追问子弹：时代（古代 / 近未来 / 架空 / 现实）？地域或文化圈（东方 / 西幻 / 赛博都市）？是否与意图前置里的氛围一致？

**2. 种族（必问，且是后续提问的前提）**

先问清这个角色是什么种族。**即使答案是人类也必须明确确认一次**，不要默认为人类跳过。

- 追问子弹：人类 / 精灵 / 兽人 / 龙族 / 魔族 / 神明 / 妖怪 / 机械体 / 义体人 / 半血统 / 架空自定义种族？若为混血，是哪些血统的混合、哪一支占主导？该种族在其世界观里处于什么地位（稀少 / 常见 / 被排斥）？

**种族一旦确定，后续所有涉及外形的问题都要据此调整**，规则如下：

1. **影响面部特征**：定完种族后，问到「五官」时须按种族常识追加对应子项——精灵问耳型（尖耳 / 耳长 / 耳尖角度），兽人问兽耳位置与兽纹，龙族/魔族问瞳孔形状（竖瞳 / 异色瞳）与有无角，机械/义体问眼部是否为人造部件。人类则按原五官子项问。
2. **影响皮肤与质感**：非人种族须追加其专属体表追问——精灵（有无发光的纹路）、兽人（毛发覆盖部位与质感）、龙族（鳞片部位、颜色、光泽）、机械（金属 / 陶瓷 / 合成材质、接缝与发光部件）、幽灵或元素体（半透明程度、发光色、有无实体轮廓）。
3. **影响身材比例与体型体态**：非人种族须结合种族常识调整——兽人（体型更壮硕 / 更矫健）、精灵（更修长轻盈）、矮人（更矮壮）、龙族（更高大或可在人形下保留部分体量感）。
4. **影响年龄问法**：长寿命种族（精灵 / 龙族 / 神明 / 妖怪）须同时问"外貌年龄"与"实际年龄"，并确认两者差异（如"外貌 20 岁、实际 300 岁"）；人类按原问法。
5. **影响标志性特征与细节图**：种族的专属器官或标记（角、尾、翼、鳞、纹、发光核心等）**默认纳入标志性特征候选**，并会被出图时放进设计细节图，须在提问环节问清其形态与位置。
6. **不影响**意图前置、题材背景、性格气质、服装风格与鞋子等问题的问法。

> 若用户选的是架空自定义种族或混血，先请用户描述该种族的外形特征，再据其描述套用上面第 1–5 条。

**3. 生机感（生命体征；默认开启，题材涉及非活体时必问）**

默认按「**活人感**」出图（皮肤有血色、眼睛有神采、气色通透）。当角色题材本身不是活体（亡灵 / 僵尸 / 鬼魂 / 尸体 / 活死人 / 傀儡 / 人造体 / 元素体等），或第零组意图中出现"死人感""尸体""阴间""衰败""无生气"等表述时，**须就本项主动问一次并取得明确答复**，不得自行决定，也不要因为用户催进度就跳过。

- 追问子弹：这个角色**要不要保留活人感**？如果要削弱，是**全部削弱**还是**只削弱其中某项**？（下面各项可独立选择）
  - 眼睛：有神采（一大一小双高光）←→ 无光、浑浊、死水眼、瞳孔涣散
  - 皮肤：有血色、耳指尖透红 ←→ 苍白灰败、青灰、无血色
  - 面部：气色通透 ←→ 整体压暗、眼窝与颧骨凹陷
  - 唇色与瞳色：保留高饱和点缀 ←→ 灰紫、乌青、浑浊失焦
  - 皮肤质感：干净有弹性 ←→ 干裂、淤青、尸斑、缝线、腐坏（程度由用户定）
- 用户答"**不用**"（外表保持正常）：使用默认开启状态，后续不再追问。
- 用户答"**要削弱**"：按用户指定的子项关闭，未指定的项一律维持默认；并同步调整负面提示词中冲突的条目（见第 4 步"生机感开关"段）。关闭状态须写入设定文字。
- 用户答"**反过来**"（设定是死者 / 长生不死 / 已死之人，但外表仍是活人模样）：使用默认开启状态，并在设定文字中记录"设定与外观的差异"，避免出图时自作主张。

> 未触发上述条件时**不要为问而问**，直接用默认开启状态进入第二组。

##### 第二组 · 基本信息

1. **身份（角色定位）** — 追问子弹：职业 / 社会角色？所属阵营或组织？
2. **性别、年龄** — 追问子弹：年龄段（少年 / 青年 / 中年）？外貌年龄与真实年龄是否一致？（**长寿命种族**按第一组第 4 条问法处理）
3. **身高** — 追问子弹：具体数值，或高矮感知（娇小 / 标准 / 高挑）？
4. **身材比例** — 追问子弹：头身比？三围倾向（纤细 / 标准 / 丰满 / 健壮）？（**非人种族**结合种族常识调整）
5. **体型与体态**（与"比例"区分：比例是数字配比，体型体态是观感与骨架） — 追问子弹：胖瘦观感？骨架大小、肩宽窄？肌肉感（柔软 / 紧实 / 有力）？体态（挺拔 / 微驼 / 松弛 / 蓄势待发）？（**非人种族**结合种族常识调整）
6. **性格气质** — 追问子弹：核心性格三词？待人接物的方式？有无反差（外表 X、内里 Y）？
7. **气质的外化表现**（与"性格气质"区分：这一项问的是它**怎么体现在画面上**） — 追问子弹：常用表情倾向（冷淡 / 爱笑 / 阴郁 / 挑衅）？眼神特点（锐利 / 温和 / 空洞 / 慵懒）？姿态习惯（含胸 / 抱臂 / 手插兜 / 站姿笔挺）？

##### 第三组 · 从头到脚

1. **脸型** — 追问子弹：圆脸 / 方脸 / 长脸 / 瓜子脸 / 鹅蛋脸？下颌线（柔和 / 锋利）？
2. **发型** — 追问子弹：长短？直卷？层次与轮廓？刘海样式（齐刘海 / 中分 / 无刘海）？发尾处理（内扣 / 外翘 / 碎发）？（**兽人 / 有毛发覆盖的种族**须确认发际与毛发过渡）
3. **发色** — 追问子弹：主色？有无挑染 / 渐变 / 双色？发质观感（乌黑顺滑 / 亚麻蓬松 / 干枯）？
4. **五官**（**拆细为下列子项，逐项问到位**；**非人种族按第一组第 1 条追加专属子项**）
   - 眼型与瞳色 — 追问子弹：眼型轮廓（大眼 / 丹凤 / 上挑 / 下垂）？瞳孔颜色与形状（普通圆形 / 竖瞳 / 特殊纹样）？眼神底调？
   - 眉毛 — 追问子弹：眉形（平眉 / 剑眉 / 柳叶眉）？浓淡与粗细？
   - 鼻 — 追问子弹：鼻梁高低？鼻头形状（挺秀 / 小巧 / 立体）？
   - 唇 — 追问子弹：唇形（薄唇 / 饱满 / 桃心）？嘴角（上扬 / 平直 / 下压）？自然唇色？
   - 耳 — 追问子弹：耳型有无特别（普通 / 精灵耳）？有无耳饰穿孔？（**精灵族**重点确认耳长与耳尖角度）
5. **皮肤与质感**（**非人种族按第一组第 2 条追加其专属体表追问**） — 追问子弹：肤色（冷白 / 蜜色 / 小麦）？肤质（细腻 / 哑光 / 通透发光）？皮肤特征（疤痕 / 纹身 / 胎记 / 纹路）？非人种族另问：鳞片 / 毛发 / 金属 / 半透明 / 发光纹路等。
6. **妆容**（可给候选让用户挑，也可由用户用文字或参考图描述。答案要具体到可画面化，如"正红哑光唇色、眼尾上挑黑色眼线、淡粉腮红"，不写"妆好看"）
   - 浓淡（素颜 / 淡妆 / 浓妆 / 舞台妆）？眉形？眼妆（眼影、眼线、睫毛、美瞳）？唇妆（唇色、质地）？腮红与修容？面部妆饰（眉心坠、面靥、亮片、彩绘、贴花、伤效妆）？
7. **手臂与手部** — 追问子弹：手臂线条 / 粗细？手部特征？手上的装饰（戒指 / 手链 / 护腕 / 手套 / 纹身）？
8. **腿部** — 追问子弹：腿型？腿长观感？腿部装饰（袜 / 腿环 / 绑带 / 护膝 / 疤痕）？
9. **服装风格**（作为整体穿着，排在四肢之后、鞋子之前） — 追问子弹：风格方向（古风 / 制服 / 机能 / 礼服 / 便装）？**关键单品**（有没有特别想要的一件，如披风、腰封、某个配饰）？露肤程度？主色调倾向？
10. **鞋子**（收尾身体部位） — 追问子弹：鞋款（靴 / 运动鞋 / 凉鞋 / 木屐 / 无鞋）？配色？
11. **标志性特征**（最后压轴） — 追问子弹：有没有一眼能认出这个角色的独有元素（独有纹样、专属道具、特殊妆饰、身体标记、习惯性小物）？要几个？（**种族专属器官或标记**如角、尾、翼、鳞、发光核心等，按第一组第 5 条默认纳入候选，须问清形态与位置）

##### 服装与鞋子的生成规则（两条分支共用）

- **服装**：具体款式与配色**只问"风格 + 关键单品 + 主色调倾向"**（见第 17 项），细节由 Agent 根据「题材背景 + 服装风格 + 用户关键单品要求 + 参考图」自行生成，写进设定文字里一并确认。**用户明确点名的关键单品必须采用**，不得替换或省略。
- **鞋子**：鞋款与配色按用户回答确定；用户未明确时，由 Agent 结合题材背景、服装风格与造型参考图给出候选让用户挑。

#### 修改分支

先拿到该角色现有的设定文字、参考图或已出的设定图；用户还没提供时先请他提供，不要凭空想象原角色长什么样。

拿到后：

- **先确认改动意图**：问清用户这次想改哪些地方、改完之后希望是什么感觉（对应第零组的意图逻辑，精简为一问）。
- **只对用户想改动的要素逐项询问**，同样一项一问并遵守核心节奏（含糊则就地追问、用户让你定则给候选让用户挑）。
- 其余要素**沿用原设定**——不重问一遍，也不顺手改掉用户没提到的部分。
- **修改分支不问「角色整体造型参考图」这一前置项**，也不问第零组的完整三问（改为上面那一问）。
- 用户指名要改动的其他要素（妆容、手臂与手部、腿部、鞋子等）按此处理，只改用户指名的部分，不额外强制追问。
- 改动的要素同样可以只给图或图文并用。
- 若这个已有角色属于真人、明星或已有版权角色，按红线说明不适用。

### 第 3 步 · 合成设定文字

把要素合成一份结构化设定。产出前先做一次**意图回扣自检**：

1. 把第零组（修改分支为改动意图）收集到的每一条意图逐条列出。
2. 检查每一条是否都在下面的设定里找到了**具体要素落点**。
3. 任何一条落不到的，**回去补问对应要素**，不要用一句泛泛的形容糊过去。

**每条设定都要能回溯到用户说过的话或给出的参考图**，不要为了"显得完整"补用户没提的元素（用户没提世界观，就别擅自替他定年代）。文字要具体到能直接当出图提示词用——写"黑色及腰长直发、发尾内扣"，不写"发型好看"。凡依据来自参考图的，要把图里的对应特征翻译成具体描述（颜色、长度、轮廓、材质、纹样、皮肤质感、脸型轮廓、身材各部位、妆容细节等），不能只写"参考图那样"。修改分支下，未改动要素的表述与原设定保持一致，只体现用户要求的改动。

设定文字骨架见 `references/setting-template.md`（字段顺序与提问顺序对齐，含意图回扣栏）。

把设定文字发用户确认，**明确认可后才出图**；用户提出修改，就回到对应要素重问（可以补新参考图），不要在文字层面硬改掩盖分歧。

### 第 4 步 · 出图：一张 16:9 横版角色设定图

> **硬性检查点**：第 3 步的设定文字未经用户明确认可，**不得进入本步**。用户说"再改改"就回第 3 步。

**默认风格锚点（分为三块：默认风格 / 默认质感 / 默认光影）**：

三块各自独立、缺一不可，共同构成本 skill 的默认出图锚点，每次出图都须把三块一并写入提示词。三块之外，另配一份**固定负面提示词**（排除项，见本节下文"负面提示词"段），以及一个**生机感开关**（默认开启，仅当角色题材为非活体且用户同意时才关闭对应子项；见本节下文"生机感开关"段）。二者每次出图都须与三块一并写入。

> **① 默认风格（画面体裁与美术取向）**：
> **高精度 3D 半写实国漫风格**；偏国漫 3D 角色质感；高级 CG 质感；顶级 3D 人物渲染；五官立体；高级感；**画面以「信息图式角色设定稿」为优**（多版块分区、线框与文字标注、排版干净克制、主体周围留呼吸空间）；**不限定角色性别**（男性 / 女性 / 无性别 / 非人异形均可）；**造型有设计感**（剪影辨识度高——仅凭轮廓即可辨认角色；服装、配饰、配色围绕同一视觉母题，不杂糅）；**配色克制**（主色 ≤2 + 点缀色 1）；精品人物设计图。

> **② 默认质感（材质与细节还原）**：
> 真实皮肤肌理；发丝独立、真实、细腻，没有塑料感、发丝不结块，且有丝绸般的各向异性带状高光；五官轮廓立体真实；**毛绒、织物、蕾丝、皮革等材质的纤维与纹理级还原**；**配饰与小物件材质分明**（金属、珍珠、缎面、毛绒、塑料等反射与质感各异）；**材质对比明确**（软 / 硬、哑光 / 光泽并存，不一片糊）；**皮肤有次表面散射**（耳廓、指尖透光泛红）；**细节分层**（面部与标志性特征最高精度，次要区域适度简化，避免全图同精度导致糊）；**边缘干净**（无脏边、无溢出、无多余肢体与手指）；**精致 BJD 人偶质感**（球体关节人偶般的精致五官与肤质、细腻通透的陶瓷感肌肤、圆润的关节与手部造型、精致考究的材质与做工）；超高清 8K。

> **③ 默认光影（布光与调色）**：
> **柔光棚拍光**（大面积柔光、无硬阴影）；**中性灰白底**；**三点式布光**＝主光 + 补光 + **单侧柔和发丝/肩线轮廓光**（只在一侧后方打一道柔光，照亮发丝与同侧肩线，把角色从背景中"托"出来；**不做双侧对称描边**，避免抠图贴纸感；浅色底上主要作用于深色头发）；**面部塑形光用蝴蝶光**（正面偏上方的柔和主光，额头与双颊受光、鼻下形成小片柔和阴影——脸显小而立体，且**五官保持清晰可读**；不用伦勃朗光或侧面硬光遮掉半张脸）；**眼球高光一大一小两点**（瞳孔靠上、偏光源侧一个主光点，对侧一个较小次光点——眼神水润有神；**禁止无高光**）；**主体与背景分离**（微明度差 / 暗角）；**高光保留细节、不烧成死白**；**光源色温随角色气质与主色调决定**（冷白 / 中性白 / 暖白按角色定，不写死）；**全图中低饱和 + 局部点缀**（整体压中低饱和保持干净，仅瞳色、唇色、标志性单品保留高饱和作视觉锚点）；干净通透的画面。

- 上述三块即为**本 skill 的默认风格锚点**，每次出图都须按此写入提示词。
- **光源色温不写死**：由 Agent 依据角色的气质与主色调**自行推断**（不必单独追问用户），如粉系柔软角色用暖白/暖粉、清冷科幻角色用冷白、中性现代角色用中性白；并在设定文字中写明本角色所用色温，随三块一并写入提示词。用户明确指定色温时以用户为准。
- 用户在任意环节用文字或指定图片明确要求换风格时，以用户指定为准（可只覆盖其中一块，其余两块保持不变）；用户给出的角色整体造型参考图非默认风格时，按第 2 步的风格追问结果执行（用户明确选定才采用，未选定不自行决定）。未被用户覆盖的锚点不变。

**生机感开关（默认开启；角色题材确为非活体时，须先问用户并取得同意才可关闭或降级）**：

三块正向锚点中的若干条目以"**活人感**"为前提（皮肤有血色、眼睛有神采、气色通透等）。当角色题材本身就不是活体时，这些条目会与设定直接冲突，故设本开关统一管理。

> **默认状态（开启 · 活人感）**：眼球有神采（一大一小双高光、禁止无高光）；皮肤有血色与次表面散射（耳廓、指尖透光泛红）；面部气色通透；瞳色与唇色保留高饱和作视觉锚点；皮肤为真实肌理、有弹性、干净。

> **关闭 / 降级后（非活体）逐项可替换为**：
> - **眼球高光** → 无高光 / 浑浊蒙雾 / 死水眼 / 瞳孔涣散失焦；
> - **皮肤血色** → 无血色、苍白灰败或青灰，无透光泛红；
> - **面部光影** → 仍保留立体（蝴蝶光或顶光均可），但整体压暗、加重眼窝与颧骨凹陷阴影；
> - **局部点缀色** → 瞳色与唇色改为灰紫 / 乌青 / 浑浊失焦，不保留高饱和；
> - **皮肤质感** → 可加干裂、淤青、尸斑、缝线、腐坏等（具体程度由用户定）。

- **触发条件**：满足任一条即**须主动就本开关问一次并取得用户明确答复**，不得自行决定——① 第 2 步·第一组「种族」为**亡灵 / 僵尸 / 鬼魂 / 尸体 / 活死人 / 傀儡 / 人造体 / 元素体**等非活体；② 第零组「整体感觉」中出现**"死人感""尸体""阴间""衰败""无生气"**等表述；③ 用户在其他环节主动表露类似意图。
- 未触发时**不追问**，直接使用默认开启状态。
- **逐项可独立开关**：用户可只关掉其中一项（如"保留有神的眼睛，但皮肤要苍白"），未指定的项一律维持默认。
- **与负面提示词联动（关闭时必须同步调整）**：
  - **必须移除**：关闭 `眼球高光` 后，须从负面提示词中移除**眼睛无高光**、**眼神涣散**（二者与本关闭状态直接冲突）。
  - **视用户要求可移除**：**蜡像感 / 假面感**（若用户要的正是蜡质、僵硬的尸体观感）。
  - **始终保留**：**面部扁平无起伏**、**塑料皮肤**、**过度磨皮**、**抠图贴纸感描边**——非活体同样要立体、同样不能塑料糊化。
  - `内容回避` 组中的**血迹 / 暴力元素**在僵尸、尸体、暗黑等题材确需时，按上文规则放行对应条目。
- 关闭状态与"哪些子项被关闭"须在设定文字中写明（见 `references/setting-template.md`），并随三块锚点一并写入出图提示词。

**负面提示词（固定排除项，每次出图都须与三块正向锚点一并写入提示词，不得省略）**：

> **默认负面提示词**（按类分组；**每一条都对应上面三块正向要求的反面**）：

- **表情须以"语言较难描述的复杂情绪"为主**，而非基础情绪。示例：委屈、不甘、隐忍、嘲讽、惊愕、释然、决绝、脆弱、欲言又止、强作镇定、心灰意冷、似笑非笑等。避免"开心 / 生气 / 难过"这类基础情绪占满版面。
- 表情真实自然、不夸张不做作；同一角色**妆面与发型在 8 张之间保持一致**，不因表情变化丢妆或改妆。
- **文字标注**：每张下方标该情绪的中文名称。

**版块④ · 设计细节图（若干）**

- 位于**右侧贯穿全高的长栏**（约占全图面积 **26.0%**，约 416×900），纵向堆叠若干细节格，展示该角色的**标志性特征或专属物件，并标明其在身上的位置**。
- **张数由该角色的标志性特征数量决定**（一格一特征，格数 = 特征数），不预设固定张数，也不写死取材清单；格多则纵向排布加长、格少则留白，不硬凑。
- 每格比例自定，可为横条或方形局部特写。
- **文字标注**：每格下方标**名称 + 位置**（如"右腰银铃挂饰""左肩火焰纹样"）；名称写清是什么，位置写清在身体何处。
- **不要把与角色无关的通用部位**（单纯为了填满而截的袖口、裙摆等）当细节图——只有当它本身属于标志性特征时才出。
- 特征很少（如一两个）就只出对应少数几格，版面留白即可，不硬凑无意义细节格。

**尺寸标注**：身高与头身比等文字（如"165cm / 约 7.5 头身"）随版块①头部特写或三视图就近标注。

**出图提示词构成**：

> 设定文字关键项 + 用户文字要求 + 第零组意图（用途侧重、整体感觉、禁忌避让）+ 参考图对应的外观描述 + **默认风格锚点三块**（按上文 ① 风格 / ② 质感 / ③ 光影的原文逐条写入；用户明确指定时可只覆盖其中一块）+ **生机感**（默认开启＝活人感；非活体且用户同意关闭时，写明被关闭的子项，并同步移除负面提示词中的「眼睛无高光」「眼神涣散」）+ **负面提示词**（六类固定排除项，见上文）+ **背景规格**（中性灰白系棚拍底、无多余背景图案）+ 四版块版式描述（右侧细节栏贯穿全高、左侧分上下两带与各自比例、各版块位置尺寸与标注要求；表情图 8 张以复杂情绪为主；细节图按标志性特征出图并标位置）。

保留脸型 / 发型 / 发色 / 五官 / 皮肤与质感 / 妆容 / 服装 / 配色 / 手臂与手部 / 腿部 / 鞋子 / 标志性特征等外观描述。用户若一句话指定别的版式，以用户指定为准。

## 红线

1. **一次只问一个问题**：不在答案含糊或未经用户确认的情况下跳到下一项，也不用 Agent 自己的设想替用户填掉含糊回答；含糊就地追问，用户让 Agent 定则给候选让用户挑。
2. **意图必须落到要素上**：第零组收集的每条意图，都必须在设定文字里找到具体落点；落不到就回去补问，不许用泛泛形容糊过去。
3. **未获明确认可不得出图**：第 3 步设定文字必须经用户明确认可，才进入第 4 步。
4. **角色整体造型参考图只作参考**：未经用户在对应环节确认，不得直接当作该要素答案；不吸收图中无关内容（背景、水印、其他角色等）。
5. **外观一致性**：同一角色的脸型、发型、发色、五官、皮肤与质感、妆容、服装、配色、手臂与手部、腿部、鞋子、标志性特征，在头部特写、三视图、表情图、设计细节图与各版块之间必须保持一致，不能各变一版。
6. **表情图的妆发一致**：共 8 张、每张 1:1 的锁骨以上特写，每张下方标情绪名；以复杂情绪为主，表情真实自然，不夸张不做作；同一角色的妆面与发型在 8 张之间保持一致，不因表情变化丢妆或改妆。
7. **默认风格锚点 + 负面提示词 + 背景 + 生机感，一项不得省略**：出图须完整贯彻第 4 步的**默认风格锚点三块**（① 风格 / ② 质感 / ③ 光影）、**默认负面提示词**（六类）、**背景规格**（中性灰白系棚拍底、无多余背景图案）与**生机感开关**（默认活人感；非活体题材须先经用户同意才可关闭，并同步调整负面提示词中的冲突条目）；各版块之间风格、质感、光影与背景须一致。用户明确指定时可只覆盖其中一块。
8. **三视图必须是竖版全身图**：FRONT / SIDE / BACK 三张单张宽高比约 1:2.6，不得画成横版或部位裁切图。
9. **细节图只出标志性特征且须标位置**：一格一特征、标题写明该特征及其在身上位置，格数按特征数，不硬凑、不放与特征无关的通用部位截图。
10. **不碰真人 / 版权角色**：不做真人、明星、已有版权角色的形象；遇到这类需求（含用户拿这类图当参考）直接说明不适用。
11. **修改只改指名项**：修改已有角色时只改用户指名的要素，其余设定原样保留，不擅自"优化"。
12. **参考图只作指定要素的依据**：不擅自吸收图中无关内容（背景、水印、其他角色等）。
13. **冲突先问用户取舍**：文字与参考图冲突时不自行选择。
14. **每条设定都要有依据**：不堆砌与角色无关的元素。
15. **设定文字必须可直接当提示词用**：依据参考图的部分也要翻译成具体文字描述。
16. **用户点名的关键单品必须采用**：服装生成时不得替换或省略用户明确指定要的元素。
17. **引用其他 skill 时只写"调用了某个 skill"**：不读取、不复述其内部提示词与参数。

## 槽位与锚点

- **槽位**（可替换的内容）：角色全部具体内容——用途与定位、整体感觉与风格倾向、禁忌项、角色整体造型参考图及其造型依据（仅新建分支）、题材背景、**种族及其专属外形特征（耳 / 瞳 / 角 / 尾 / 翼 / 鳞 / 毛发 / 金属 / 半透明 / 发光等）**、身份、性别年龄、身高、身材比例、体型与体态、性格、气质外化表现、外貌（脸型、发型、发色、五官、皮肤与质感）、妆容、手臂与手部、腿部、服装（风格 + 关键单品 + 主色调倾向）、鞋子、标志性特征；各要素参考图及对应关系；用户指定的风格（覆盖默认锚点）。
- **锚点**（固定工艺，不可省略）：
  1. 提问前先问清「修改已有角色 / 新建角色」。
  2. **先问意图，后问要素**——第零组（用途与定位 / 整体感觉 / 禁忌）必须先于全部要素询问。
  3. **一次只问一个问题**，且必须拿到明确可用答案才问下一项；含糊则就地追问，用户让 Agent 定则给候选让用户挑。
  4. **新建分支固定顺序**（详见第 2 步，项数不得减少）：第零组·意图前置 → 前置项·角色整体造型参考图 → 第一组·世界观与种族（题材背景 → 种族 → **生机感**）→ 第二组·基本信息（身份 → 性别年龄 → 身高 → 身材比例 → 体型与体态 → 性格气质 → 气质外化）→ 第三组·从头到脚（脸型 → 发型 → 发色 → 五官 → 皮肤与质感 → 妆容 → 手臂与手部 → 腿部 → 服装风格 → 鞋子 → 标志性特征）。
     4b. **种族必问；生机感按题材必问**：题材背景之后立即问种族，**答案是人类也须确认一次**；种族一经确定须据此调整后续问法，架空自定义种族或混血先请用户描述外形再套用。种族为非活体（亡灵 / 僵尸 / 尸体等）或用户表露"死人感"时，须就「生机感」问一次并取得明确答复后才可关闭（详见第 4 步）。
  5. **角色整体造型参考图仅新建分支提问，修改分支不问**。
  6. **该图非默认风格（高精度 3D 半写实国漫风格）时必须询问用户采用什么风格**，未选定不自行决定。
  7. **该图仅供参考**，读取范围限定为五官 / 发型 / 脸型 / 身材（胸腰臀臂手腿足）/ 妆容 / 造型 / 服装；读取内容拆到后续对应提问环节作参考答案、经用户确认后采用；**不改变要素顺序与项数**。
