# 复古胶片英雄质感

把画面做成**复古胶片电影质感**：胶片颗粒 + 高对比暗调 + 暗部青绿墨绿与亮部暖黄橙的冷暖对撞 + 暖橙轮廓光勾边 + 主体半剪影但保留清晰细节与体积感 + 粉紫黄昏天空 + 轻微运动模糊。

原素材来自一组超级英雄题材参考图（蜘蛛侠、恶灵骑士、死侍、钢铁侠、美国队长、蝙蝠侠、绿巨人），但这套质感**不绑定超级英雄题材**，换任意主体都能套。

## 这个 Skill 做什么

两种用法，共用同一套风格关键词：

1. **单独出图**：用户描述一句画面 → 生成一张符合该质感的图。
2. **叠加使用**：把「风格关键词段」附到别的图片提示词末尾，让已有任务统一成这套质感。

**复刻方式：纯文字关键词，不传参考图。** 不要要求用户上传或引用参考图来复刻这套质感。

## 该用 / 不该用

该用：

- 用户提到"复古胶片感""电影感""胶片颗粒""暗调""青绿暗部/暖橙亮部""暖橙轮廓光""粉紫黄昏天空"等描述。
- 用户要把一组图统一成同一种电影胶片质感。

不该用：

- 用户要的是干净顺滑的商业修图风、纯白背景电商图、日系清新、明亮通透的赛博霓虹风——这些与"胶片颗粒 + 暗调冷绿"直接冲突。
- 用户明确要求不用颗粒、不要色调偏移。

## 强度口径：只走"黄金中间档"（最重要的一条）

这套质感有一个明确的最佳档位，偏向任何一侧都会失败。**默认按黄金中间档执行。**

**黄金中间档（目标状态，五项同时到位）：**

1. **暗部更沉、对比更强**——暗调压得住，画面不灰平；
2. **暖橙轮廓光明显且好看**——沿主体边缘勾出清晰、漂亮的暖橙光边；
3. **粉紫天空色调准确**——黄昏粉紫要出得来且不过艳；
4. **胶片颗粒粗细适中**——细腻、看得见，但不到糊、不到噪点堆积；
5. **主体亮度与细节清晰度更好**——主体保留可读的细节、受光面与体积感。

**两个必须避开的失败方向（偏哪边都算不合格）：**

- **偏亮、偏干净**：暗部被抬亮、颗粒缺失、色调被洗掉 → 质感丢失，普通明亮电影感。
- **过黑、过糊**：大面上全黑成死剪影、重拖影糊片、环境脏到看不出主体 → 强度过头，画面不可读。

判据很简单：**暗调要沉、对比要强，但主体必须还能看清细节与体积感——不是死黑剪影。**

## 锚点（固定工艺，无论什么主体都必须保留）

1. **暗调高对比**：暗部偏青绿/墨绿并压得下去，亮部暖黄橙提得起来，中间调少，避免灰平。**但不把暗部压成纯黑死块。**
2. **暖橙轮廓光**：主体边缘有一道明显、干净的暖橙轮廓光，是画面最亮的信息；它负责把主体从暗背景里"勾"出来，而不是把主体整体照亮。
3. **半剪影 + 保留细节**：主体呈半剪影状态，受光侧和关键体积转折（肩线、面部结构、披风褶皱等）要读得出来。**清晰不等于打亮，暗不等于没有细节。**
4. **粉紫黄昏天空**：天空呈准确的粉紫过渡，作为画面冷暖对撞的冷端来源，不偏灰、不偏橙、不过饱和。
5. **胶片颗粒适中**：全画面可见的细腻有机颗粒，暗部略明显；是质感的一部分，不是噪点堆叠。
6. **轻微运动模糊**：只在边缘或局部（如肢体末端、披风、飞溅物）出现轻微拖影，用来暗示速度，**不做全画面拖糊**。
7. **电影感构图**：宽画幅感、主体偏置、大面积负空间留给天空或地面。

## 硬规则（必须守住，不满足就重做）

- **必须保留胶片颗粒**：不允许干净无颗粒的顺滑画面；颗粒要细腻可见，但不得堆成噪点。
- **必须保持冷暖对比**：暗部青绿/墨绿 与 亮部暖黄橙 同时存在，**不允许整体单一色调**（整张青绿、整张暖橙、整张灰蓝都算不合格）。
- **必须保留粉紫天空**：粉紫不作为唯一色调，但必须存在且色调准确。
- **必须有暖橙轮廓光**：画面缺了这道边缘光，主体就会糊进背景，直接判不合格。
- **主体必须可读**：允许暗、允许半剪影，但关键结构与体积转折要能看清。**主体全黑成一块、或糊到不可辨认，都是不合格。**
- **运动模糊必须轻微且局部**：只出现在边缘/局部，不覆盖主体，不做全画面拖糊。
- **不得偏亮偏干净**：暗部不得为"看清主体"而抬亮，环境不得处理成光滑无细节。
- **画面内不得出现文字或水印**：无字幕、无水印、无 logo、无边框、无 UI 元素。
- **只用文字关键词复刻**：不依赖参考图、不把参考图当输入传给生成节点。
- **主体不限**：题材换成非超级英雄时，这套质感同样成立。

## 执行流程

1. **解析输入**：从用户那句话里抽出 {主体}{场景}{动作}{氛围}{镜别}，缺项按上表默认值补，主体缺失则直接问用户。
2. **组装提示词**，按固定顺序拼： `{主体} + {动作/场景/镜别/氛围} + 光影段 + 质感段 + 镜头段 + 画幅提示`
   - 光影段：高对比暗调打光，暗部青绿墨绿且压得住，暖橙轮廓光明显勾边，主体半剪影但保留受光面与体积转折，天空粉紫过渡准确。
   - 质感段：复古胶片、细腻可见的胶片颗粒（暗部略明显）、低饱和电影级调色，环境保留适当粗糙纹理。
   - 镜头段：电影感宽画幅构图、主体偏置、大面积负空间，边缘/局部轻微运动模糊。
3. **生成**：调用图像生成节点产图。**模型、生成数量、画幅等参数沿用执行时用户在该节点上的选择，本 Skill 不写死具体模型与参数值**——不同画布/不同模型的可用选项不一样，写死会让 Skill 在别的画布上跑不起来。（经验：Midjourney 8.2 上这套关键词出图稳定；换成别的模型时同样沿用节点选择即可。）
4. **对照硬规则自检**（见下）。
5. **不达标就改提示词重试**，按方向回修而不是继续加码：

失败表现往哪里调整质感丢失：偏亮、偏干净、颗粒没了加"高对比暗调、暗部青绿墨绿、细腻胶片颗粒、低饱和电影级调色"画面灰平、对比不够加"高对比、暗部压沉、暖橙轮廓光明显"，同时保留主体受光面主体死黑成一块、细节看不到减"剪影/extreme low-key"，改为"半剪影，保留受光面与体积转折"，适度提主体亮度主体糊到不可辨认、全画面拖影减运动模糊，改为"仅边缘/局部轻微运动模糊"颗粒过重发噪改为"细腻可见的胶片颗粒，暗部略明显"，去掉 coarse/heavy grain天空偏灰/偏橙/过艳明确写"粉紫黄昏天空、色调准确、不过饱和"色调偏单一显式写满冷暖两端："暗部青绿墨绿、亮部暖黄橙，冷暖对撞"出现文字水印提示词中明确 negative：无文字、无水印、无 logo、无边框

6. **叠加用法**：用户是在做别的图片任务时，不要另起一次生成，只输出「风格关键词段」，让用户粘到自己提示词末尾；输出时说明哪一段是可直接粘贴的。

## 自检清单

- \[ \] 整体是暗调高对比，暗部沉得下去，不是灰平中调
- \[ \] 暗部是青绿/墨绿，亮部是暖黄橙，两者同框对撞
- \[ \] 主体边缘有清晰的暖橙轮廓光，光边好看、干净
- \[ \] 主体是半剪影，但受光面与体积转折仍能看清（**没有全黑成一块**）
- \[ \] 主体没有因为压暗而丢失细节，也没有因为提亮而显得平淡偏亮
- \[ \] 粉紫黄昏天空存在且色调准确，不偏灰、不偏橙、不过艳
- \[ \] 胶片颗粒细腻可见，暗部略明显；**既不是没有颗粒，也不是噪点堆叠**
- \[ \] 运动模糊只出现在边缘或局部；**全画面没有拖糊、主体轮廓清晰可读**
- \[ \] 画面整体质量落在"黄金中间档"：既不像偏亮偏干净的普通电影感，也不像全黑重拖影的糊片
- \[ \] 画面中没有任何文字、水印、logo、边框
- \[ \] 主体换成非超级英雄题材时，这套质感依然成立
