# 仙侠玄幻打斗提示词规范

把题材设定组装成一份可直接投喂视频模型的超长提示词（不少于 3900 字）。本规范是**叠加在视频生成任务上的写法规范**，不单独产出成片。

## 何时使用

- 用户要做仙侠 / 玄幻 / 国漫风格的打斗视频，尤其是一镜到底、法天象地对决、万剑诀斩兽、巨剑贯穿反派这类大场面。
- 用户已有角色参考图或角色设定，需要把它们锁进提示词。
- 用户明确要求「提示词不少于 3900 字」。

## 硬性前提

1. **字数下限 3900 字**。不足时通过细化动作起承转合、逐回合攻防、运镜轨迹、光影层次、粒子材质、背景动态、空间结构等正当维度补足，禁止无意义重复或注水。
2. **模型容量先算清**。单镜头时长需求超过所选模型的单次上限时，先与用户确认方案（换用支持更长时长的模型，或改多镜），不要静默改型或压缩内容。
3. **参考图数量先与用户确认**。有几张图、哪几张进提示词（例如「正常形态 / 法相形态」各两张，还是只用其中两张），必须先问清再写；不要自己挑。

## 一、提示词组装结构

按下面的顺序拼装，每一段都写足：

 1. **风格锁定**：中国三维玄幻国漫动画质感（donghua 番剧 / 院线动画电影风格），赛璐璐与厚涂结合、干净卡通描边、通透色彩分层、风格化光影；明确排除真人影视、写实电影、真人皮肤质感、实拍。
 2. **镜头与时间约束**：单镜头、一镜到底、连续时间、连续空间；无剪辑、无转场、无跳切、无蒙太奇、无分屏、无黑场、无闪白、无重放、无定格、无慢动作、无速度斜坡。
 3. **帧率约束**：原生逐帧，动作密集处一拍一；禁止光流插帧、RIFE、DAIN、任何 AI 补帧、时间插值、帧间自动平滑。
 4. **背景清晰度**：背景必须极其复杂，且全程清晰；镜头快速运动时背景不能模糊、拉丝、融化、拖影、简化成色块、浅景深虚化。逐项列出必须可读的细节（石纹、玉纹、铜锈、铁锈、木纹、金痕、裂纹、水波、刻度、铭文、锈迹、瓦当、斗拱、雕花、纸纹、刺绣、文字、笔画、花瓣、轮廓、轨迹、颗粒）。
 5. **粒子系统**：打铁花级别密度，列清触发时机（碰撞、命中、掌击、爆发、重踏、炸裂、喷涌）与粒子种类；要求真实重力、抛物线、阻力、冷却变色（白炽→金红→暗红），分前景 / 中景 / 远景三层；粒子不合并成雾、不遮脸、不糊背景、不变模糊光斑。
 6. **角色锁定**：逐个角色写明外观基线（脸型、五官、发型、发色、发饰、服装层数、领口、袖口、腰带、护腕、靴子、武器形状与纹样、灵力颜色、体型比例、气质），并声明任何一帧都不得换脸、变装、变色、变体型、多手多脚、武器消失。参考图用 `{{node_key}}` 引用，不写 URL。
 7. **固定场景与连续空间**：声明全程不换场景，并分层写清空间结构（中央主体、四周、左侧、右侧、后方、前方、上方、地面），每层都带可读细节；再写背景动态元素清单。
 8. **运镜总规则**：镜头是连续有生命的飞梭，一直跟随主体不切换；列出允许的运镜动作；声明绝不甩出主体、不失焦、不切另一机位；禁止突然变焦、无意义旋转、穿模、穿过人物身体、被粒子完全遮挡。
 9. **动作总规则**：攻防转换频率（每秒 5–6 次）、每 0.2–0.3 秒一个明确动作；列出动作词表；要求每个动作有起势、发力、命中、反弹、卸力、再起，不摆拍、不停顿、不慢动作。
10. **逐回合动作与运镜**：见第二节。
11. **负面约束**：见第四节。
12. **质检清单**：见第四节。

## 二、逐回合动作与运镜写法

- 按时间轴切段（如 0.0–0.5s、0.5–1.0s……），**每段单独成句**，写清：谁攻击、用什么部位、攻击哪里、对方如何格挡或闪避、是否命中、武器是否碰撞、脚和另一只手如何参与、镜头如何运动、背景哪些细节可见、粒子如何飞溅。
- 段与段之间保持动作连贯，前段的结束姿态就是后段的起手。
- 长镜头可先密集切段（每 0.5 秒一段）铺满前段，再用 3–5 秒的大段承载高潮与收尾。
- 高潮段要写足过程，不要一句带过：例如换装变身要写出「旧装解离成光粒 → 新甲由粒子反向汇聚编织 → 粒子收拢入体 → 身形暴涨」的完整过渡，而不是「瞬间变身」。
- 收尾段写清终局的先后或同时关系。

### 用户明确要求过的写法要点（照做）

- **御剑朝向**：主角御剑踏剑时，剑尖（剑刃前端）始终指向飞行前进方向、在前，剑柄在后；转向、折返、俯冲、拉升时剑尖先指向新方向。反派不踏剑、不御剑，以魔功凌空、脚踏魔云飞行。
- **尺度比例统一**：变身后的法相体量、身高、肩宽、头颅、手臂长度，以及能量球与法相的相对尺寸，必须在所有镜头保持一致，不得忽大忽小；固定基准要写出来（例如球体直径约等于法相一颗头颅、约胸腔宽度三分之一），并声明透视变化不改变真实尺度。
- **法相与星球的比例**：法相要比星球更高，镜头对两尊法相都取能容纳头部、肩胸与手臂的**上半身完整构图**，不被画面边缘切掉头颅或肩膀；星球在身后下方显得较小。
- **能量球要有冲击距离**：不是原地推出，要有蓄力起手 → 离手 → 拖焰破空飞行 → 命中的完整位移过程，镜头先跟球飞行再后拉。
- **终结巨剑来自法阵**：巨剑不是主角手拿，而是自法阵符文中升起、成形、射出，前端拖出极长的凝实剑气，先绞碎能量球再持续贯穿反派。
- **反派结局**：反派在贯穿剑气中直接消融、化为飞灰直至消失，不表现物理崩坏、不分层碎裂。
- **终局同时发生**：反派被贯穿消灭与星球被炸掉一半必须在同一瞬间同时发生，不分先后。
- **开场即追逐**：第一幕两人就在高速追逐，不做静止对峙或蓄势停顿。
- **镜头贴近穿体**：随巨剑高速俯冲、从剑尖贴近穿过时，要写清该瞬间的画面状态。

## 三之二、可选：四阶段节奏模板（30 秒）

当用户给的是一条 30 秒、以「近身缠斗 → 蓄力大招 → 大招倾泻 → 余韵收锋」推进的打斗时，可直接套用下面的四阶段结构与镜头语言。它是**可选模板**，与第一节的组装结构叠加使用：第一节的 12 段照写，时间轴部分按本模板组织。

模板变量用 `{主体}`、`{巨兽}`、`{招式}`、`{招式特效}`、`{气劲名称}`、`{武器}`、`{地面}`、`{天空}`、`{环境元素}`、`{debris}`、`{碰撞音效}`、`{崩裂音效}`、`{终极技}` 等占位，替换成具体内容。

### 第一阶段 00:00–00:07 · 极致近身搏杀

- **镜2（00:02–00:05）过肩视角 OTS ｜ 极速甩镜 Whip Pan**：主体借反震之力腾空，与巨兽展开高速近身对轰；身形翻飞，每一次攻击都带拖曳特效；镜头随攻势疯狂左右甩动，巨兽的冷蓝爪影与金色气劲在天地间交织成毁灭的光网；最后一击对拼，环形气浪呈同心圆炸开，将 debris 震成齑粉。音效：密集对轰爆鸣，最后一声如天雷滚动的巨响。

- **镜10（00:23–00:26）全景 ｜ 推镜**：场景已被夷平，金色丁达尔光束斜射，空气中飘散发光粒子与巨兽的灰烬。（镜头运动平缓，**不是慢动作**，画面速率正常。）

### 音频约束

**NO BGM**：不生成背景音乐、不写交响乐与鼓点等配乐指令。只保留画面内音效（碰撞、崩裂、破空、音爆、嗡鸣、低喝等）。模板原文中出现的「BGM 史诗交响乐」一律以本条为准，去掉。

3. 镜9 不得写白光吞没整个屏幕、白屏闪烁；改为强光爆发但不白屏、不闪白、不切黑，巨兽与背景在光中仍可辨。
4. 镜12 不得写画面切黑；改为不切黑、镜头连续跟随或自然停在主体离去的画面。
5. 全脚本遵守主规范的无慢动作、无定格、无闪白、无白屏、无切黑、无转场硬切、连续运镜（一镜到底或连续运镜）、镜头连贯、NO BGM。

## 四、负面约束与质检清单

### 负面约束（每条提示词都要写全）

- 剪辑类：禁止剪辑、转场、跳切、蒙太奇、分屏、黑场、白场、闪白、重放、定格、慢动作、速度斜坡。
- 插帧类：禁止光流插帧、RIFE、DAIN、AI 补帧、时间插值。
- 背景类：禁止背景模糊、浅景深、虚化、融化、拉丝、拖影、简化。
- 角色类：禁止换脸、服装 / 武器 / 发色 / 体型异常变化、换装瞬切而无粒子过渡、反派踏剑御剑、能量球原地瞬撞而无飞行冲击距离、终结巨剑由主角手拿、剑气过短或一击即收、表现反派物理崩坏分层碎裂、武器消失、手指畸形、关节反向、融化、闪烁、果冻效应、鬼影。
- 粒子类：禁止粒子糊成雾、遮挡脸部与背景、变成色块。
- 镜头类：禁止镜头切换、失焦、甩出主体、穿模、穿过人物身体。
- 质感类：禁止真人影视质感、写实皮肤、电影景深、低帧率卡顿、画面撕裂、水印、文字、logo。
- 空间类：从起点到终点必须由一次连续运镜完成，禁止中途硬切场景。
- 音频类：禁止 BGM、配乐、交响乐、鼓点等音乐性音轨。

### 质检清单（交付前逐条过）

 1. 是否单镜头、无切换？
 2. 是否原生帧、无插帧？
 3. 背景是否全程极其复杂且清晰？
 4. 角色外观是否与参考图 / 设定一致，武器是否正确？
 5. 是否不额外预设参考图没有的身份关系与特征？
 6. 是否允许飞行、踏空、御风而不局限于地面？
 7. 是否每秒 5–6 次攻防转换？
 8. 每个回合是否写清武器碰撞、踢、掌击、格挡与闪避？
 9. 粒子是否达到打铁花级别且不糊？
10. 镜头快速运动时背景是否不模糊？
