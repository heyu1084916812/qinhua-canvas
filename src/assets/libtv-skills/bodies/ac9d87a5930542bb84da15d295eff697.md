# 片段拆分 v1.0

将剧本按指定分镜时长上限，在自然断点处智能拆分为多个片段，输出带秒数标记的分段结果。

---

## 工作流程

### Step 0：确认时长上限（必须执行）

如果用户未在消息中明确指定每段时长上限，**必须先询问**：

> 每段分镜的时长上限是多少秒？（例如 15s、20s、30s）

用户指定后进入下一步。如果用户已在触发消息中给出了上限数值（如"按 20 秒拆分"），直接跳过此步。

---

### Step 1：分析剧本结构，标记自然断点

扫描剧本全文，用以下 4 个维度标记所有「自然断点」：

**断点优先级（从高到低）：**

优先级断点类型识别规则示例P1对话轮次边界角色 A 台词结束 → 角色 B 台词开始`角色A："……"` → `角色B："……"`P2动作节点转折动作描写中有明显的阶段切换拔剑 → 冲刺 → 格挡P3情绪转折情绪氛围明显变化紧张对峙 → 温情回忆P4场景转换地点/时间发生变化宫殿内 → 城外荒野

**P1 是最理想的拆分点**，应优先使用。P4 仅在以上都不存在时作为兜底。

---

### Step 2：估算各潜在段时长

对剧本内容，逐段估算播放时长。估算规则如下：

2.1 台词时长

```
台词时长 = 台词文字字符数 ÷ 4
```

- 文字字符：中英文 + 数字，**不含**标点符号
- 4 字符 ≈ 1 秒（中文正常语速 + 表演停顿）

参考值：

台词长度预估时长8 字2 秒12 字3 秒16 字4 秒20 字5 秒40 字10 秒

2.2 动作时长

动作类型特征时长典型关键词简单动作单次小幅动作1.5s转头、点头、握拳、睁眼、皱眉、抬手、放下中等动作幅度较大的动作3.5s拔剑、冲刺、格挡、跃起、踢出、闪身、推开复杂动作多环节组合动作5.0s横扫、炸开、旋转下坠、化作火光直扑、贯穿情绪特写面部表情变化2.5s眼眶泛红、嘴角勾起、目光阴沉、咬牙、颤抖

2.3 纯叙述/描写

非动作、非台词的叙述性文字（如环境描写、心理独白），按 **2 字/秒** 估算。

2.4 总时长

```
预估总时长 = 台词时长 + 动作时长 + 叙述时长
```

---

### Step 3：拆分与输出

拆分策略

从剧本开头开始，逐句累加时长，当累计时长**接近或超过**上限时，在最近的自然断点处拆分：

1. **首选 P1 断点**（对话轮次边界）——最自然，不打断台词
2. **其次 P2/P3 断点**（动作节点 / 情绪转折）
3. **最后兜底**：在句号处硬拆

拆分判断原则

- **不强贴上限**：如果自然断点对应的累计时长明显短于上限（如上限 30s，但自然断点在 18s），就在 18s 处拆，不要硬凑到 30s
- **宁短勿超**：宁可拆短，不要让任何片段超过上限
- **下限提醒**：如果某片段估算 &lt; 5 秒，向用户说明并建议是否与相邻段合并
- **秒数取整**：四舍五入到整数秒

输出格式

```
【分段1-秒数15s】
剧本原文内容...

【分段2-秒数13s】
剧本原文内容...

【分段3-秒数18s】
剧本原文内容...
```

- 分段编号从 1 开始
- 秒数为该段预估总时长（整数）
- 分段之间保留空行分隔
- 原文内容逐字保留，不做任何修改

## 示例

输入剧本：

```
杨戬握紧三尖两刃刀，目光凌厉："你到底是什么人？"
黑袍人缓缓转身，嘴角勾起一抹冷笑："一个你惹不起的人。"
话音刚落，黑袍人化作一团黑雾，直扑杨戬面门！
```

用户指定上限：15s

分析过程：

- 第1句：握拳(1.5s) + 目光凌厉(0s, 归于台词) + 台词"你到底是什么人"(7字÷4=1.8s) = 3.3s
- 第2句：转身(1.5s) + 冷笑(2.5s) + 台词"一个你惹不起的人"(8字÷4=2s) = 6.0s
- 第3句：化作黑雾直扑(5.0s) = 5.0s
- 累计到第2句结束 = 9.3s（未超15s），第3句后 = 14.3s（接近上限且句末是自然收束）

拆分结果：

```
【分段1-秒数9s】
杨戬握紧三尖两刃刀，目光凌厉："你到底是什么人？"
黑袍人缓缓转身，嘴角勾起一抹冷笑："一个你惹不起的人。"

【分段2-秒数5s】
话音刚落，黑袍人化作一团黑雾，直扑杨戬面门！
```

---

## 注意事项

1. **原文不变**：拆分只加标记，不修改剧本原文一个字
2. **完整输出**：所有分段合并后 = 完整原文，无遗漏无重复
3. **时长是估算**：告知用户时长为估算值，实际制作时可能有差异
4. **如剧本极短**（总时长 &lt; 上限），直接输出 1 个分段即可
