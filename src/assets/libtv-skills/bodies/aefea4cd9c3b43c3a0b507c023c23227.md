## 2. 上游资产工序（顺序不可颠倒）

**设定图 → 色卡 → 视频提示词**，是角色不变形、颜色不漂移的上游根因。

### 2.1 设定图

- 每个角色/生物/载具/关键道具各一张四视图 DESIGN SHEET
  - 正面/侧面/全身正/全身背
  - 机械与载具用 SIDE/FRONT/TOP/3-4 VIEW
  - 可变形物件用多形态同图
- 白/灰底纯净背景，标题印图：`{对象名} - {类型} DESIGN SHEET`
- **背面视图最容易省、最不能省**——只给正面，转身镜头必穿帮
- 配套产出**部件清单**（拆到"款式+图案+颜色+袖长/腰线"粒度），同一份清单原样搬进视频提示词的角色锚定文字
- 机械件与武器必须单列

### 2.2 色卡

- 每场景组一张 13 色复合色卡 = 7 色承前 + 6 色新增

- 每色绑定具体物件（"青灰=站台铁皮顶棚"有效，"青灰=阴影"为虚绑定，禁止）

- 定 2–3 个贯穿色写进每张色卡永不替换

- 色卡必须是白底平色块图（16:9），标题印图：

  ```
  {项目} EP{N} SEG{M} - {内容} COLOR REFERENCE
  ```

- 视频提示词里三件套一起上：

  1. 挂色卡图锚定
  2. "所有色彩严格按色卡13色执行+不可偏离色板"
  3. 最重要的 3–5 色用 HEX 直写进画面描述

### 2.3 反偷懒铁律总则

凡挂了媒介与成片不同的参考图（设定图/色卡/故事板/白模），必须配对应反偷懒铁律，堵住白底、拼版构图、标注文字、平涂质感泄漏进成片。

## 3. 五层提示词架构

```
第1层 [STYLE LOCK]   胶片层（逐字复制，全片不变）+ 类型调性层（每段重写）
第2层 @素材锚定区     角色/场景/色卡/音色/故事板，逐条带"严格按此图渲染+不可改造"
第3层 结构声明        总时长 + 镜头数 + 过渡类型 + 遮罩说明
第4层 逐镜头执行块     机位/画面/背景/末段 + 时间戳或节拍 + 台词（含情绪曲线）
第5层 声音设计+命名铁律 逐镜头声音 + 一条一条起名字锁死 + 综合否定清单
```

### 3.1 双层 STYLE LOCK

**胶片层**（逐字固定）：

```
[STYLE LOCK]
Shot on 35mm Kodak Vision3 500T film stock + analog film grain visible
+ practical light only + Christopher Doyle cinematography
+ Wong Kar-wai painterly desaturation + photochemical film texture
+ slight halation on highlights + organic film noise
+ heavy atmospheric haze + tactile real-world materials
+ film print look not digital cinema look
+ photorealistic film still aesthetic
+ real physical scene captured through a camera lens + not a 3D render.
```

**调性层公式**：

```
{动作/情绪参考片} + {节奏/张力词} + {结尾beat参考} + {画幅} + {光线时段}
```

调性层是防单调的唯一手段：胶片层不动，追逐像麦克斯、喜剧像猫和老鼠、静默像库布里克。

### 3.2 镜头块固定字段

- **机位**：景别+焦段+运镜+handheld呼吸感
- **画面**：主体@锚定+位置+HEX+动作
- **背景**：纵深+虚化
- **末段**：本镜结束状态，为下一镜留接口——连贯性关键

### 3.3 时间轴选择

- **秒数模式**：打斗、道具飞行、精确动作
- **节拍模式**：行走、舞蹈、音乐驱动段

## 4. 时长三档策略（2.5 更新）

### A. ≤30s 直出

一次生成。一镜到底或多镜头硬切（≤5 镜）。30s 一镜到底推荐五拍递进：0-4 / 4-9 / 9-15 / 15-22 / 22-29。

### B. 延长至约 60s

用视频延长功能。官方模板：

> 参考@视频1的内容，延长视频 X s向后延长。要求延长自然、动作衔接流畅， 禁止生硬切镜、禁止物体凭空出现。{后续动作与情绪推进}。

延长中换场景，用原生遮罩转场模板：

> 需要在切镜处使用"遮罩转场"：{前景物}完全遮挡镜头使画面变暗，随后镜头穿过 {前景物}拉开，直接显现出下一个场景：{新场景描述}。由{旧景别}自然切换为{新景别}。

**每次延长必须重申一次**："全片保持35mm胶片质感、胶片颗粒与@图片N色卡13色不变。"

### C. 180s 超长视频

选【超长视频】模式。L1–L3 前置一次，分镜按"幕"写（每幕约 30–60s、3–5 拍），幕间用白雾/隧道黑等遮罩物过渡，遮罩必须做到 near total whiteness / darkness，禁止半灰。

## 5. 段间衔接（跨段焊接）

- **设计层**：结尾 1–2 秒遮罩物（黑遮罩=逆光剪影填满 / 白遮罩=云雾强光冲镜 / 贴镜遮罩=道具拍镜头 / 穿越遮罩=镜头穿过结构）+ 下段起手从同色遮罩渐显。 同一遮罩物、同一 HEX、同一画幅位置。
- **素材层**：段 N 截取末帧（遮罩帧或关键姿态帧）作为段 N+1 起手锚定图。
- **声音层必须同步遮罩**：遮罩物接近时其声源放大占据声场，其余环境声被压制。
- 段内换场景优先改用 §4-B 的原生遮罩转场，手工遮罩帧保留给跨段与超长幕间。

## 6. 2.5 新能力接入

### 6.1 智能编辑 / 高级编辑 / 视频编辑

公式 = \[具体修改对象\] + \[动作与变化描述\] + \[生效时序\]

必填动词：编辑/增加/删除/修改/替换/改成。

示例：

```
在视频的4-9秒，把男生的牛仔裤替换为深黑色的西装裤。严格保持原视频的景别、运镜与胶片质感不变。
```

高级编辑/视频编辑支持红框圈选："将红框内的xx修改为…"

### 6.2 BGM 分离 / 移除

任何自带音乐的参考视频，先移除 BGM 再投喂或延长，防止音乐串入成片声床。

### 6.3 白模接入

**粗颗粒**（白模动画→替换角色+渲染场景）：

```
参考@视频1的动态运镜、物理光影变化，将视频中的白色人型模型精确替换为@图片1里的{角色}。
人物形象严格参考设定图（部件清单），保持角色一致性，不穿模不变脸。
{完整四肢动作序列}。场景渲染为{场景描述}，机位与原视频完全一致。
最终为35mm胶片质感 + 色卡13色执行。
```

有四肢/翅膀的模型必须写出完整动作序列，最佳实践是不上传带四肢翅膀的白模。

**细颗粒**（已建模 3D 场景→材质光影上色）：

```
【渲染指令】将@视频1的白模动画渲染成最终成片（去除轨迹线、坐标线与相机cone等干扰信息）。
【分段渲染描述】0-{N}s：{背景环境/色调/人物材质/光影}
{s}（转场触发点）：{转场后新场景渲染描述}
【场景处理】街道背景参考@图片2的场景锚定渲染
【整体收束】人物渲染保持不变；全片35mm胶片质感
```

Blender/Maya 设定相机路线后导出视频投喂，是专业运镜的推荐路径。

### 6.4 迁移创意

参考@视频1的创意形式、镜头节奏、转场方式 + 替换为你的主体与场景，STYLE LOCK 与色卡照常锁定。

### 6.5 绿幕

直接生成"纯净色键绿背景"表演素材用于后期合成（背景无渐变无阴影，颗粒只作用于人物）；或用编辑功能把已有视频背景整段改为绿幕。

### 6.6 多人参考

多角色同框时各挂设定图锚定，写"双人身份铁律：绝对禁止面部特征互换+绝对禁止换装"。

### 6.7 音色参考升级

说话角色挂 @音频N 音色锚定 + 音色描述 + 语速（每秒N字）+ 每句台词单独标情绪曲线。一句台词值 5 行表演指导，这是"角色"与"TTS"的分界线。

## 8. 声音设计

逐镜头写：持续声床标"层"字；中英双写拟声词（rope whoosh / metallic clinking / sand crunching）；声音随叙事变化。

BGM 三策略：

- **白噪音占位**：片场戏、日常戏
- **纯音效无 BGM**（默认）：追逐、动作、喜剧 beat
- **单一乐器史诗段**：史诗段、航拍转场

知道哪些留给后期的音效，在提示词里明确禁掉。

每段必写收尾句：

```
仅生成动作音效与对白音效与环境音效 + 不要bgm + 无字幕。
```

## 9. 资产分组（画布管理）

三层分组：

- **L1 全局资产**：主角设定图、贯穿音色
- **L2 场景组**：场景锚定+色卡，色卡作用域 = 场景组边界
- **L3 段落组**：故事板/音频/视频节点/截帧

组内横轴=制作流程轴：

```
设定图 → 色卡 → 锚定 → 故事板 → 音色 → 视频 → 截帧
```

段落组之间必须有截帧或遮罩帧连线，没连线说明与前后是断的。

四套命名标题一律印在图上：

```
设定图：{对象名} - {类型} DESIGN SHEET
色卡：  {项目} EP{N} SEG{M} - {内容} COLOR REFERENCE
故事板：{项目} EP{N} SEG{M} STORYBOARD {镜头数}PANEL
音色：  {角色名} VOICE ANCHOR - {音色关键词}
```

## 11. 2.5 实战避坑（来自官方手册评论区实测）

1. 参考图堆 10 张以上易连续生成失败——核心锚定贵精不贵多。
2. 真人脸一致性：侧脸易不像、说话时牙齿/眨眼易糊——真人戏以正脸中近景为主，大侧脸特写说话镜头拆成"侧脸无台词 + 正脸说词"两拍。
3. 长视频积分成本高——先 10s 低清验证一致性，再跑 30s，最后跑延长与 180s。
4. 视频结尾偶发红绿网格噪点——留 1–2 秒余量，结尾用遮罩或渐暗收场便于裁掉。
