# 高饱和手绘民俗拼贴

本文件必须独立工作。不要依赖其他 Markdown、脚本或外部说明文件。参考素材只用于抽象提炼颜色、笔触、构图和运动规律，不得复刻具体画面。

## 核心命题

把现实对象画成“被阳光晒热的手工海报”：颜色直接、笔触可见、比例略带童真，植物像色块海浪，主体像剪下来重新贴回画面。成片必须同时具有：

- 草木绿与日光黄主导的高饱和色域；
- 不均匀厚涂、干刷、刮擦和纸纤维；
- 轮廓清楚但不追求摄影级精确；
- 前中后景像剪纸层片般分离；
- 轻快、质朴、略荒诞的民俗叙事；
- 海报式大形与视频式局部运动并存。

如果画面只是普通卡通、平滑矢量、照片滤镜或写实风景，则判定失败。

## 原创性边界

- 不复刻具体插画、封面、动物姿势、文字排版或商标。
- 不要求模仿在世艺术家；只使用通用的厚涂、水粉、拼贴和民间图案语言。
- 人物、动物、场景和装饰必须重新设计。
- 默认不生成可读文字。需要标题时，使用用户提供的准确文字，并单独预留字区。

## 画面结构

### 三层拼贴

1. 前景：叶片、花头、纸边或粗笔触，占画面 10%–25%，可轻微越界。
2. 中景：唯一主角或主物，占画面 35%–60%，轮廓最清楚。
3. 后景：田野、树丛、墙面或天空，简化为2–4块大色面。

每镜只保留一个主动作。主体与背景必须用明度差、互补色或纸边阴影分离，禁止把所有细节涂成同等密度。

### 构图

- 竖屏优先 9:16，海报主体可略偏中心。
- 使用三角形、弧形或对角线组织动物与植物。
- 允许轻微错误透视和夸张比例，但主体结构仍可辨。
- 每镜保留至少15%的呼吸区，避免满屏碎花。
- 装饰性重复元素以3、5、7个为宜，避免机械网格。

## 色彩系统

默认色板：

- 草叶绿 `#4F8E2F`
- 酸橙黄 `#C6D92C`
- 日光黄 `#F2C94C`
- 乳白 `#F2E8C9`
- 番茄红 `#D85A32`
- 湖水蓝 `#4F9AA8`
- 土壤褐 `#65432F`

使用比例：

- 绿色系 40%–55%；
- 黄与乳白 20%–30%；
- 红橙点色 8%–15%；
- 蓝或褐作为平衡色 10%–20%。

禁止霓虹渐变、金属铬、全黑赛博背景和统一复古滤镜。颜色应像颜料本身发亮，不像数字光效。

## 笔触与材质

- 主体：半厚涂水粉，边缘可见刷毛分叉。
- 植物：大块平涂叠加干刷叶脉，不逐片写实描摹。
- 纸张：暖白粗纸、轻微颗粒、局部擦痕和不齐边缘。
- 阴影：用更深的同类色或一层半透明脏色，不使用真实软阴影。
- 高光：奶油白短笔触，方向统一。
- 拼贴层：允许1–3毫米视觉错位、轻微翘边与柔短投影。

## 主体设计

优先使用：

- 家禽、山羊、鱼、猫、昆虫等日常动物；
- 劳作人物、节庆队伍、乡村器物；
- 果树、菜圃、野花、池塘和晒谷场；
- 单纯动作：奔跑、回头、啄食、抬头、递果、举旗。

人物五官简练、表情直接。动物可以略拟人，但不要穿完整商业卡通服装。每镜只出现1–3个主要角色。

## 光线

- 默认晴日散射光，方向为左上至右下。
- 不做写实体积光；用色块明暗与暖黄边缘暗示阳光。
- 阴影偏蓝绿或土褐，禁止纯黑。
- 高光区域仍保留纸纹和笔触。

## 视频运动

### 运动原则

运动像“纸片、颜料和印刷层被轻轻唤醒”，而不是流畅3D动画。

- 角色：每秒2–6像素的轻弹、点头或两帧式迈步。
- 植物：0.8–1.5秒一个缓慢摆动周期，幅度2°–6°。
- 拼贴层：前后层产生1%–3%视差。
- 笔触：可沿既有纹理逐段显影，禁止像液体霓虹流动。
- 镜头：每镜只选极慢推近、横移或定镜之一，幅度3%–8%。

### 节奏

- 0–4秒：建立主体和色域；
- 4–8秒：一个动作触发环境回应；
- 8–12秒：拼贴层扩张或节庆性高潮；
- 12–16秒：重新收束成完整海报构图。

### 转场

优先使用叶片擦镜、纸张翻页、颜料块覆盖、主体跳切和图形匹配。禁止数字故障、粒子爆炸、炫光闪白和复杂三维旋转。

## 声音

- 使用木鱼、手鼓、口哨、拍手、鸟鸣、脚步和纸张摩擦。
- 节拍可略带不齐，保持手作感。
- 音效与动作一一对应，不堆叠宏大管弦。
- 结尾保留0.3–0.5秒环境声余韵。

## 制作工作流

1. 写一句寓言式事件，不超过25字。
2. 锁定主体、唯一动作、主色和识别物。
3. 设计三层拼贴及色块面积。
4. 先生成一张无文字身份锚点。
5. 后续图保持主体造型、笔触粗细和色板不变，只轮换动作或机位。
6. 每4秒只安排一个可读事件。
7. 图生视频时限制镜头幅度，优先局部摆动与层片视差。
8. 使用质量表验收；硬失败时重做，不继续叠加修饰词。

```

```

## 硬失败

- 主体无法一眼辨认；
- 看不见真实笔触和纸张层次；
- 色域灰暗或变成霓虹数码色；
- 拼贴层没有前中后关系；
- 一镜出现两个以上主动作；
- 视频中主体造型、色板或笔触突然改变；
- 出现随机文字、品牌、水印或可识别作品复刻。

## 100分质量检查

- 主体与寓言事件 20分；
- 高饱和色板控制 18分；
- 水粉笔触与纸纹 18分；
- 三层拼贴和构图 16分；
- 动作与镜头克制 12分；
- 转场和声音手作感 8分；
- 原创性与无瑕疵 8分。

90分以上可作为最终关键帧；80–89分做一次定向修复；低于80分重写主体、色块或层次。
