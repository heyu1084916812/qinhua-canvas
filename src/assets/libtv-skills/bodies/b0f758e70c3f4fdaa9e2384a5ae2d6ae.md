# 香水详情页视觉设计工作流

## Skill 简介

本 Skill 将香水品牌参考图转化为完整的详情页视觉卡片体系，覆盖8大核心卖点模块。支持两种工作模式：

- **模式A · 单图参考**：基于1张品牌参考图，提炼视觉风格，生成8张详情页卡片
- **模式B · 多图融合**：融合2-4张参考图的视觉语言精华，生成8张融合风格详情页卡片

---

## 第一步：接收输入，判断模式

**询问用户：**

1. 上传参考图（1张 → 模式A；2-4张 → 模式B）
2. 提供香水产品基本信息：品牌名、产品名、核心香调（前/中/后调原料）、品牌定位关键词

根据参考图数量自动进入对应分支。

---

## 第二步A · 单图参考 — 风格分析

**输入：** 1张品牌参考图

**分析维度：**

- 整体风格定位（如：中式极简禅意、日式侘寂自然主义等）
- 核心色调（提取5色色板：主色、辅色、点缀色、背景色、文字色）
- 构图特征（留白比例、产品摆放方式、背景处理）
- 字体风格（衬线/无衬线、中英文搭配方式）
- 自然素材语言（使用了哪些自然元素：植物、石材、光线等）
- 情绪氛围关键词（3-5个）

**输出：** 风格分析报告 + 风格情绪板（Style Moodboard）

情绪板包含：

1. 核心色板（5色）
2. 自然质感素材拼贴
3. 香水产品意象
4. 留白东方构图示意
5. 字体风格示意
6. 生活方式场景参考

---

## 第二步B · 多图融合 — 视觉语言融合分析

**输入：** 2-4张参考图

**逐图分析**：对每张参考图分别提取：

- 产品形态与包装设计特点
- 色调与背景处理方式
- 排版与字体风格
- 自然元素与场景氛围
- 独特视觉亮点（该图最值得借鉴的1-2个要素）

**融合策略制定：**

- 确定主色调体系（从多图中取交集或互补色）
- 确定构图主策略（哪张图的构图逻辑作为主框架）
- 确定各卖点模块分别借鉴哪张图的哪个视觉要素
- 输出融合视觉语言说明文档

---

## 第三步：规划8大卖点模块

基于风格分析结果，为以下8个模块分别制定视觉方案：

屏序卖点模块核心内容视觉重点①品牌故事首屏品牌名+产品名+核心Slogan产品居中大图，背景自然意境，大面积留白②香调成分前/中/后调原料特写+香调金字塔天然原料实物排列，分层结构图示③天然原料溯源产地信息+零添加承诺+可持续认证原产地场景大图，经纬度/地图细节装饰④瓶身工艺玻璃工艺+瓶盖材质+标签印刷产品极致特写，侧光打亮，标注线说明⑤使用体验喷雾方式+持香时长+使用步骤喷雾动作特写，雾气弥散，时间轴图示⑥生活方式场景使用场景+品牌生活主张人物+自然环境，晨间仪式感氛围⑦环保理念可回收包装+植物油墨+认证信息包装平铺展示，认证图标，自然点缀⑧系列收尾引导产品系列全家福+规格选择+购买引导多瓶陈列，品牌Slogan收尾，引导下单

---

## 第四步：逐张生成详情页视觉卡片

按照第三步规划，依次生成8张视觉卡片。

### 通用生成规范

**画面尺寸：** 750×1000px（标准详情页比例）

**色调锚点（根据风格分析结果填入）：**

- 主背景色：米白 / 深绿 / 炭黑（按模块切换）
- 植物元素色：墨绿 #2D4A2D
- 金属/点缀色：哑光金 #C9A96E
- 文字色：深棕 #3D2B1F / 米白 #F5F0E8

**字体规范：**

- 中文：端庄纤细衬线体，字重Light/Regular
- 英文：细英文衬线体（如Garamond/Didot风格）
- 中英双排，英文字号约为中文的70%

**构图原则：**

- 大面积留白（留白比例≥40%）
- 产品/主体居中或黄金分割位
- 文案克制，每屏不超过3行主要文字
- 自然元素点缀，不喧宾夺主

---

### 各屏详细生成提示词

① 品牌故事首屏

**模式A提示词框架：**

```
参考[参考图]的品牌视觉风格，设计香水详情页第1屏【品牌故事首屏】。
画面：香水瓶居中，背景[风格分析中的背景处理方式]，大面积[主背景色]留白。
顶部品牌中英文名，中央主标题"[产品名] · [英文名]"，下方副标题"[品牌核心主张一句话]"。
[风格关键词]构图，[色调描述]色调，高端小众香氛品牌调性。
```

**模式B融合要点：**

- 产品形态参考：\[图X\]的瓶身形态与排版简洁度
- 背景意境参考：\[图X\]的自然场景与色调深度
- 字体风格参考：\[图X\]的英文字体优雅度
- 整体高级感参考：\[图X\]的产品+背景搭配方式

---

② 香调成分卖点

**画面构成：**

- 三种核心天然原料实物特写（前调/中调/后调）
- 精致排列在米白石面或木面上
- 香水瓶置于一侧
- 香调金字塔结构图示（可选）

**文案模板：**

```
前调 · [前调原料名] / 中调 · [中调原料名] / 后调 · [后调原料名]
```

**色调：** 米白底色 + 墨绿植物 + 深棕木质

---

③ 天然原料溯源卖点

**画面构成：**

- 原产地场景大图铺底（原始森林/高山/产地实景）
- 叠加经纬度坐标或地图标注细节
- 前景摆放原料实物特写

**文案模板：**

```
取材[产地描述] · 零添加合成香精 · 可持续采集认证
```

**色调：** 深绿 + 金色晨光 + 米白

---

④ 瓶身工艺卖点

**画面构成：**

- 香水瓶多角度极致特写
- 侧光打亮，展示材质质感
- 标注线指向各工艺细节

**文案模板：**

```
[玻璃工艺] · [瓶盖材质] · [标签材质] · [包装特点]
```

**色调：** 浅灰石纹背景 + 产品本色 + 极简奢感

---

⑤ 使用体验卖点

**画面构成：**

- 手持香水瓶喷雾的优美动作特写
- 雾气在空气中弥散效果
- 使用步骤图示（可选）
- 持香时长时间轴

**文案模板：**

```
细腻雾化喷头 · 均匀附着肌肤 · 持香[X]-[X]小时
```

**持香时长分段展示：**

- 0-2h：前调清新
- 2-6h：中调木质
- 6-12h：后调余韵

**色调：** 米白 + 雾气质感 + 柔光

---

⑥ 生活方式场景卖点

**画面构成：**

- 东方面孔女性人物
- 白色/浅色简约服装
- 自然环境背景（竹林/松林/花园）
- 柔和晨光侧打

**文案模板：**

```
晨间仪式感 · 让每一天从自然开始
```

**色调：** 米白 + 自然绿 + 金色晨光

---

⑦ 环保理念卖点

**画面构成：**

- 产品外包装盒平铺展开
- 展示包装材质细节
- 绿叶松枝点缀
- 环保认证图标区域

**文案模板：**

```
100%可回收包装 · 植物油墨印刷 · 无动物测试 · 素食友好认证
```

**色调：** 米白 + 深棕 + 苔藓绿

---

⑧ 系列收尾购买引导

**画面构成：**

- 3-4瓶不同容量/香调香水整齐陈列
- 深色石面或木面承托
- 松枝苔藓自然元素点缀
- 规格选择信息
- 品牌Slogan大字收尾

**文案模板：**

```
[容量规格选项] · 持香时长[X]-[X]小时
[品牌核心Slogan]
```

**色调：** 深绿 + 米白 + 炭黑

---

## 第五步：交付与复盘

**交付清单：**

- \[ \] 风格分析报告（含情绪板）
- \[ \] 8大卖点模块规划文档
- \[ \] 8张详情页视觉卡片

**质量自检标准：**

1. 整体视觉风格是否统一（色调、字体、构图语言一致）
2. 每张卡片是否清晰传达对应卖点
3. 文案是否克制、诗意、符合高端小众香氛调性
4. 产品主体是否在每张卡片中清晰可见
5. 8张卡片连贯阅读是否形成完整的品牌叙事

## 风格锚点（以本次画布为参考基准）

本次画布验证的视觉风格锚点，可作为同类香氛品牌的参考基准：

- **整体风格：** 中式极简禅意 + 日式侘寂自然主义
- **色调体系：** 墨绿 #2D4A2D · 深棕 #3D2B1F · 米白 #F5F0E8 · 炭黑 #1A1A1A · 哑光金 #C9A96E
- **自然素材：** 松树皮纹理、苔藓、松针、枯枝、晨雾
- **构图语言：** 大面积留白、产品居中或黄金分割、自然元素点缀
- **字体组合：** 纤细英文衬线体 + 端庄中文字体，Light字重
- **情绪关键词：** 纯净、克制、诗意、高级、自然、禅意
