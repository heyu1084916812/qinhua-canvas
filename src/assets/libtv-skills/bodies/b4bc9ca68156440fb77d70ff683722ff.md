## 用途

本 Skill 用于指导商业品牌、吉祥物、潮玩及文创 IP 的标准化视觉全案设计，确保从人设策略到落地应用的一致性与专业度。

## 适用输入

- **品牌背景**：调性（如：国潮、科技、简约）、受众群体、世界观设定。
- **核心特征**：姓名、性格、爱好、标志性动作或专属纹样。

## 操作步骤

1. **策略设定**：梳理 IP 定位，完成基础人设档案（性格、故事背景）。
2. **形象创作**：绘制标准三视图（正/侧/背），确定头身比例规范及标准色卡（CMYK/RGB）。
3. **动态延展**：设计基础表情集（6个起）及常用动作包（走、跑、打招呼等）。
4. **衍生应用**：创作周边样机（贴纸、帆布袋等）及线上运营物料（头像、封面）。
5. **手册编制**：整合为 IP 使用规范手册（Mini VI），明确禁止修改的行为。

## 输出要求

- **文件规格**：300DPI 透明底 PNG、AI/PSD 矢量源文件、PDF 规范手册。
- **内容清单**：三视图、比例图、色卡、动作延展、样机效果图。
- **表情包规格**：GIF 透明底，240×240px 微信标准尺寸。

## 注意事项

- **生产性**：造型需考虑易立体化，适合后期 3D 建模及周边衍生品生产。
- **识别度**：核心符号应简洁清晰，确保小尺寸或单色应用下仍具备高辨识度。
- **规范性**：严格遵守色卡及轮廓粗细规范，防止后期应用变形走样。
