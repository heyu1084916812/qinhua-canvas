## 输入

- **首张定稿图（绝对锚点图）**：上传的场景、人物位置关系定稿图（例：前景为躺在沙发上的女主，后景为坐在餐桌前且身后有窗户的男主）。
- **剧本台词与剧情动作**：角色台词、情感变化、微表情及肢体动作（例：男主停下手中动作，转头看向女主）。
- **镜头意图**：用户希望调整的景别与视角变化（例：切到男主看向女主的中景/特写）。
- **画幅比例**（必问项）：16:9（电影宽屏）、2.35:1（宽银幕）、4:3等。
- **调色风格**（必问项）：青橙商业大片、暗调悬疑Noir、暖调复古胶片、赛博霓虹等。
- **单步确认反馈**：用户对预览构图方案的“确认”或“修改意见”。

## 输入使用

- **怎么用（严格遵守与重中之重）**：
  - **背景空间防穿帮机制（核心重中之重）**：
    1. **角色背景绑定分析**：分析定稿图时，必须建立“角色-背景专属绑定矩阵”。例如：
       - **男主专属背景**：餐桌、身后的窗户、窗外的光线与景物。
       - **女主专属背景**：沙发、附近的茶案或地毯。
    2. **景别切换时的透视继承**：当镜头从定稿图的全景/大景别**推进至某个角色的中景、近景或特写时**，Prompt 必须**精确复刻该角色在定稿图中的专属背景**。
       - *错误示例*：男主切中景时凭空出现一面白墙或书架（穿帮）。
       - *正确示例*：男主切中景时，提示词必须强调“**男主坐在餐桌前，正身后依然是定稿图中的那扇窗户，窗户在浅景深下自然虚化，光线从窗外透入**”。
  - **首图基准改动句式**：所有后续提示词必须采用\*\*“在定稿图的基础上，保持场景空间与角色服装光影一致，将镜头位置推进/改动至……”\*\*的标准前置约束句式。
  - **生成前强制确认**：每一张分镜图在输出最终 Prompt 前，**必须**先输出详细的【构图预判方案】与【定稿图背景对应分析】，并向用户提问确认。
  - **构图多元化**：杜绝单一过肩镜头（OTS）。灵活交替使用正打近景、侧面中景、低角度仰拍、特写等，丰富镜头语言。

## 内部流程和 Knowhow

### 1. 定稿图视觉资产深度解析 (Anchor Analysis Step)

当用户上传或确定首张定稿图后，Skill 必须在内部执行并输出以下空间拆解：

- **空间坐标轴**：确定男主、女主的绝对位置（如：女主在前/左，男主在后/右）。
- **角色-背景映射**：
  - `角色A（如男主）` ↔ `专属背景（如身后的窗户、餐桌）`
  - `角色B（如女主）` ↔ `专属背景（如躺着的沙发、客厅区域）`
- **环境主光源**：识别光线来源（如：从男主身后的窗户透入的自然光/逆光）。

### 2. 景别推拉与透视计算 (Perspective Scaling)

当镜头从全景（Master Shot）切换至特定角色的中景/近景/特写时：

- **近大远小与景深虚化**：镜头靠近男主时，男主身后的窗户在画面中的比例放大，但透视结构不变，同时背景（窗户）根据焦段产生大光圈浅景深（Bokeh）虚化。
- **视线方向（Look Direction）**：若男主看向女主（女主在前景/左侧），男主的头部与眼神必须朝向画面左前方，符合 180 度轴线规则。

### 3. Prompt 构建公式（防止背景穿帮）

> `[在定稿图的基础上修改镜头景别与位置]` + `[画幅与焦段]` + `[主体角色动作与微表情]` + `[精准继承定稿图中该角色身后的专属背景元素]` + `[环境光影与边缘光漫反射]` + `[统一电影调色与画质]`

*示例（男主中景）*：

> 在第一张定稿图的基础上修改镜头位置与景别。电影剧照，2.35:1画幅，中景镜头（85mm焦段，f/2.0浅景深）。摄像机向后景的男主推进。主体是坐在餐桌前的男主，他停下手中的动作，头部微转，眼神深邃地看向画面左前方的女主方向。**男主的正身后完全继承定稿图中的那扇窗户**，窗外的自然光从男主后方照入，在男主的头发和肩膀边缘形成一道清晰的逆光轮廓（边缘光）。背景中的窗户与餐桌呈自然的大光圈虚化，与定稿图的环境透视完全一致。光影过渡自然，没有任何贴图感，青橙电影调色，胶片质感。

>
> - **【定稿图背景精准对齐】**：
>   - 当前镜头聚焦对象：**\[如：男主\]**
>   - 锁定定稿图专属背景：**\[如：男主身后的窗户与餐桌\]**（镜头推进至中景后，男主身后**严格保持窗户元素**，并按透视放大虚化，绝不更改背景）。
> - **【镜头类型与景别】**：\[如：正打中景 / 85mm焦段 / 浅景深\] *(非过肩视角)*

## 自检

- \[ \] **背景防穿帮重中之重自检**：当切到男主/女主单人景别时，提示词中是否**精准写明了定稿图里该角色身后的具体背景**（如男主身后的窗户）？背景是否与定稿图一致？
- \[ \] **透视与景深自检**：景别缩小（如全景变中景/特写）时，背景是否加上了大光圈虚化和透视放大的描述？
- \[ \] **单张生成与确认自检**：是否仅输出了当前这**一张**镜头？是否在输出 Prompt 前输出了预览方案并**提问等待用户确认**？
- \[ \] **构图多样性自检**：本次视角是否避免了单一的挂肩视角？景别是否合理使用了中景/近景/特写？
- \[ \] **光影融合自检**：Prompt 是否包含了“逆光边缘”、“环境光漫反射”、“光影自然过渡”等防 P 图感词汇？

## Ask User

- **初始阶段**：
  - 若未指定，询问**画幅比例**（16:9 / 2.35:1 等）与**电影调色风格**（青橙 / 暗调悬疑 / 胶片等）。
  - 引导用户上传“第一张定稿图”，或由 Skill 协助创作第一张交代人物与背景关系的定稿图。
- **每张分镜图生成前（强制交互）**：
  - 展示【构图与背景对齐方案】后，明确提问：“**请确认：您对该镜头的景别与背景锁定方案是否满意？确认后我将为您生成提示词。**”
- **单张 Prompt 输出后**：
  - 提示：“请使用以上提示词去 Image 2 生成图片。生成满意后，请告诉我后续剧情或说‘下一步’，我们将开始推演下一个镜头。”
