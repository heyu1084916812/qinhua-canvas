### 技能用途

本 Skill 专门用于环太湖地区（苏、锡、常、湖）的雕塑、公共艺术、景观装置及文旅打卡点的全流程设计支撑。核心解决水岸性、生态红线合规、地域文化转译及强文旅属性的落地问题。

### 适用输入

- 项目具体位置（坐标/岸线桩号）及甲方性质。
- 预算区间、工期要求及核心主题倾向。
- 场地现状照片或环境简报。

### 操作步骤

1. **场地与合规核查**：填写「项目六字段卡」，启动生态红线核查（水源保护区、湿地红线、防洪补偿等），确认水位线与岸线性质。
2. **文化采集与转译**：从环太湖专属语汇库（太湖石、溇港、蚕桑、吴门画派等）提取素材，通过「文化转译四步法」形成设计主张。
3. **方案推演**：进行形态抽象与空间建模，重点校验车视（环湖路）、船视（湖面）及人视（岸上）的三重视觉效果。
4. **技术深化**：执行耐候专项设计（抗台风、防梅雨、抗腐蚀），按下方「公共雕塑材质选型」选择适配材质，核算成本。
5. **视觉与交付**：生成包含水位对比、日夜景对比的写实效果图，并输出标准施工图纸及维护手册。

### 公共雕塑材质选型

公共雕塑材质须同时满足耐候、地域转译与安全三项要求，选型时按下列要点逐项核对。

**常用材质及适用场景**

- **316 不锈钢**：耐氯离子腐蚀，适用于近水、高湿及大跨度悬挑造型；表面宜做拉丝或喷砂钝化，避免镜面高反光造成眩光与光污染。
- **耐候钢（考顿钢）**：锈层稳定、色彩呼应太湖渔耕与工业记忆，适用于内陆段与主题叙事雕塑；近水部位需做防腐隔离并设排水，防止锈液污染铺装。
- **紫砂陶 / 陶板**：呼应宜兴陶都文脉，适用于体量较小、可分段烧制的作品；需做低温冻融与吸水率控制，避免梅雨季开裂。
- **竹钢 / 重组竹**：体现江南竹文化，低碳且亲和，适用于景观装置与休憩构件；须做防霉、防腐及防白蚁处理，并预留通风间隙。
- **铸铜 / 锻铜**：适合精细人物与叙事主题，质感厚重；表面宜做钝化封护，控制铜绿析出。
- **石材（花岗岩、青石）**：耐久、维护低，适用于基座与厚重体量；近水段应选吸水率低品种，避免冻融与泛碱。
- **玻璃 / 亚克力 / 树脂透光材质**：用于夜间光效与文旅打卡点；须做抗紫外黄变、抗风压与防破碎（夹层或钢化）处理。

**选型约束**

- **耐候优先**：环太湖高湿、多台风、梅雨集中，材质须通过抗腐蚀、抗风压、抗冻融评估；空腔结构必须预留排水孔及通风口。
- **地域转译**：材质应能承载太湖石、溇港、蚕桑、吴门画派等语汇，避免与地域文脉无关的通用材料。
- **安全与可维护**：临水、临人区域禁用易碎、易脱落及尖锐材质；优先选择便于清洁、可局部更换的方案。
- **生态合规**：触碰生态红线的部位优先采用轻质可拆卸材质，避免永久性硬质基础。
- **成本匹配**：在预算区间内权衡材质耐久性与全生命周期维护成本，并在材质明细表中标注替代方案。

### 输出要求

- **合规性报告**：明确标注生态红线冲突项及化解路径。
- **设计方案**：含核心意象转译逻辑、多维度效果图、平立剖图纸。
- **技术附件**：材质明细表（含选型依据与替代方案）、构造大样、防雷与排水专项说明、造价预估。

### 注意事项

- **生态优先**：若触碰一级水源保护区等红线，必须调整为轻质可拆卸装置或重新选址。
- **尺度锚定**：所有效果图必须包含标准人物参照，严禁悬浮或比例失调。
- **耐候处理**：环太湖地区高湿、多台风，空腔结构必须预留排水孔及通风口。
- **材质留痕**：材质选型须在材质明细表中逐项说明依据，禁止无理由堆砌高价材料。
