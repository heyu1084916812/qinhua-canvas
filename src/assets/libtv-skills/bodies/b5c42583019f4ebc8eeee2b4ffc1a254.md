# 戈登威利斯暗部摄影

把黑暗当作选择性信息，而不是缺少光。用建筑、人物位置和曝光关系决定观众能看见什么、暂时不能看见什么。

## 收集输入

取得场景权力关系、秘密或信息揭示、场地结构、门窗与顶面、人物走位、关键表情或道具、前后镜头、显示终端与交付平台。

## 工作流

### 1. 建立“显示/隐藏”矩阵

逐节拍列出：必须看清、可只见轮廓、可延迟揭示、必须保持未知的对象。每个暗部都要服务其中一项。

写清谁控制空间、谁被空间压住、权力何时转移。不要因为“高级”而无差别压暗所有面孔。

### 2. 利用建筑组织权力

先观察现有空间，不急于重造。用门框、天花、走廊、桌面、窗、墙体和负空间安排人物：

- 中心或边缘、前景或深处、被框住或占据开口。
- 头顶空间、视线高度和人物之间的尺度差。
- 谁靠近光源，谁留在建筑阴影中。
- 哪个动作改变构图里的权力比例。

让构图在没有对白时也能说明关系。

### 3. 设计暗部与光源

选择少量可信光源，例如顶光、窗光、台灯、走廊光或门缝光。为每个光源写明方向、遮切、衰减、照射范围和不应照到的区域。

使用负补光、旗板与遮光控制反射；让亮部成为暗部的参照。需要隐藏眼睛时明确叙事原因，需要读眼神时保留最小可读层次。

### 4. 建立曝光梯度

不要只给单一曝光值。按层级规定：关键表情、次要人物、深色服装、木材或墙体、窗外、高光实景灯和最深黑位。

同时写明：

- 哪些暗部必须保留纹理，哪些可以接近纯黑。
- 哪些高光可以溢出，哪些必须保色。
- 监看环境、平台压缩与手机屏幕对黑位的影响。
- 后期禁止自动提亮或把所有暗部归一化。

### 5. 选择克制的摄影机

优先稳定、观察式机位和清晰的建筑透视。每次移动都应对应权力变化、信息进入或人物打破秩序。

限制焦段家族与机位高度。避免用持续漂移、浅景深和眩光把结构性的暗部变成泛化“氛围”。

### 6. 转译为生成提示词

明确写出：建筑构图、人物权力位置、唯一或主要光源、阴影覆盖区域、面孔与眼睛的可读程度、亮暗层级、稳定机位、黑位纹理和禁止自动补光。

禁止只写“黑色电影”“教父感”或姓名。禁止复制具体影片构图、角色、服装和剧照。

### 7. 做黑位质检

检查不同显示器与缩略图：主体是否仍可识别；暗部是否块状断层；噪点、压缩和色偏是否吞掉信息；AI 是否添加无来源轮廓光、蓝橙对打或全局雾化。

修正顺序：恢复叙事亮部；恢复建筑层次；限制杂散光；最后微调黑位。不要直接整体提亮。

## 输出格式

1. **权力与信息图**：显示、隐藏、延迟揭示对象。
2. **建筑构图表**：人物位置、框架与机位。
3. **暗部光源图**：来源、遮切、照射和禁照区域。
4. **曝光梯度**：各层亮度、纹理与高光策略。
5. **生成提示词**：黑位、构图、可读性与禁止项。
6. **平台质检**：大屏、手机和压缩后的风险。
