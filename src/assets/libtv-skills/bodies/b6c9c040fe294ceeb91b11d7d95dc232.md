# Cinematic One-Take Video

## Core Methodology

### 1. Multi-Reference Synthesis Framework

一镜到底视频生成依赖于**分层引用逻辑**,将多个参考素材解耦为独立控制维度:

- **分镜拼接图(Storyboard)**: 定义镜头语言规划

  - 景别序列(特写→中景→全景)
  - 空间关系(人物-场景-细节元素)
  - 叙事节奏(情绪推进曲线)
  - 视觉符号系统(UI弹窗/粒子特效等)

- **人物三视图(Character Sheet)**: 锁定视觉一致性

  - 面部特征(五官/发型/肤色)
  - 服装样式(条纹上衣/丸子头等)
  - 体态比例(身高/姿态)

**引用顺序规则**: 先引用分镜图建立空间框架,再引用角色图锁定主体特征。这确保模型优先理解场景结构,再进行角色绑定。

### 2. Camera Motion Choreography (运镜编排)

核心思想: **用镜头运动代替剪辑切换**。将分镜之间的过渡转化为连续的相机轨迹设计。

**三层运镜复杂度递进**:

**Level 1 — 单轴运动**(基础一镜到底):

- Dolly Out(向后直线拉镜): 从特写拉到全景
- 禁用虚化/淡入淡出/任何转场特效
- 适用场景: 揭示空间关系/逐步建立环境压迫感

**Level 2 — 复合运动**(增强节奏感):

- Dolly + Pan(后拉+横摇): 拉镜时带出侧面细节
- Arc Orbit(弧形环绕): 从正面转到背面,带出360度环境
- Tilt Up(仰拍拉升): 从人物拉到天花板,营造压迫感

**Level 3 — 动态节奏设计**(电影感): 将5-10秒视频切分为3-4个运镜段落,每段2-3秒,通过加速度变化创造节奏:

- 段落1: Whip Pan甩镜开场(快速建立冲击感)
- 段落2: 减速至平滑Arc环绕(带出细节)
- 段落3: 再次加速Dolly Out至全景(收尾张力)

**关键约束**: 段落之间必须**丝滑连续**,不能有停顿或硬切。运动曲线类似音乐的渐强渐弱(crescendo/diminuendo)。

### 3. Transition Continuity Rules (转场连续性规则)

**绝对禁止项**:

- ❌ 硬切镜头(直接跳到下一个场景)
- ❌ 虚化转场(模糊过渡)
- ❌ 淡入淡出(dissolve)
- ❌ 任何遮挡式转场(wipe/iris等)

**连续性检查清单**:

1. **空间连续性**: 前景深度→背景深度必须在同一物理空间内可达
2. **运动速度连续性**: 镜头移动速度不能突变(用缓入缓出曲线)
3. **光线连续性**: 主光源方向和色温保持不变
4. **主体追踪**: 人物在画面中心的相对位置平滑移动,不突然跳跃

## Workflow

### 1. Preparation Stage

**素材准备清单**:

- \[ \] 分镜拼接图(至少2-3个关键帧,标明景别变化)
- \[ \] 人物三视图(正面/侧面/背面,统一服装风格)
- \[ \] 场景氛围参考(光线风格/环境细节/色调)

**分镜分析维度**:

1. **景别映射**: 将分镜拆解为

   - 极近景(ECU: Extreme Close-Up) → 面部特写
   - 中景(MS: Medium Shot) → 半身+桌面环境
   - 全景(FS: Full Shot) → 整个房间+四周元素

2. **元素清单提取**:

   - 固定元素(不变): 人物外观/主灯光/基础场景布局
   - 渐变元素(随镜头推进出现): 错误弹窗/粒子特效/远景细节
   - 情绪元素: 从专注凝重→被错误信息包围的压迫感

3. **运镜路径规划**: 在草稿纸上绘制俯视图,标出相机起点→轨迹→终点,标明速度变化点。

### 2. Initial Generation Stage

**提示词结构公式**:

```
[环境设定] + [人物状态] + [运镜序列] + [技术约束] + [禁止项]
```

**具体执行**:

1. **环境设定**(15-20字): "深夜高楼办公室,灯光昏暗,冷蓝调光线,窗外城市夜景"

2. **人物状态**(20-30字): "年轻东亚女性(丸子头,条纹无袖上衣),坐在电脑前,神情凝重,屏幕光打在脸上"

3. **运镜序列**(核心,50-80字): "镜头从面部极近特写开始,缓慢向后直线拉镜(dolly out),逐步露出上半身、桌面、显示器,继续后拉至房间全景,四面墙壁的错误弹窗逐渐浮现包围,全程单次不间断连续运动"

4. **技术约束**(必加): "画面始终清晰锐利,无剪辑,无转场,一镜到底(one continuous shot)"

5. **禁止项**(明确列出): "禁止虚化模糊,禁止淡入淡出,禁止硬切镜头,禁止任何转场特效"

**引用方式**:

- 在提示词之前先引用分镜图,然后引用人物三视图
- 使用"参考构图"和"参考人物外形"等显式标记区分引用用途

### 3. Iteration Stage

**诊断问题类型与解决方案**:

问题A: 出现硬切镜头(分镜间割裂)

**症状**: 视频在2-3秒处画面突然跳到下一个场景 **原因**: 模型将分镜理解为独立镜头序列而非连续空间 **修正策略**:

- 增强空间连续性描述: "镜头从A位置**沿直线轨道**移动到B位置"
- 添加物理约束: "摄影机固定在滑轨上,单次移动完成全部景别变化"
- 使用"丝滑连续/无停顿/一气呵成"等强调词

问题B: 转场处出现虚化

**症状**: 画面在景别切换时短暂失焦或模糊 **原因**: 模型默认用虚化处理大景别跨度 **修正策略**:

- 在禁止项中明确: "禁止虚化模糊(no blur/defocus)"
- 补充技术要求: "画面始终保持锐利清晰(sharp focus throughout)"
- 降低单次运镜跨度(从ECU→FS改为ECU→MS→FS两段)

问题C: 运镜太平淡,缺乏节奏感

**症状**: 视频像匀速后退,没有情绪起伏 **原因**: 只使用了单一运动模式 **修正策略**:

- 引入复合运动: "后拉+轻微横移" "弧形环绕旋转"
- 设计速度变化: "开场快速甩镜,中段减速环绕,结尾加速拉升"
- 添加节奏描述词: "分三段节奏" "渐强式推进" "波浪式运动"

**关键注意**: 每次只改一个维度。不要同时修改运镜方式+禁止项+时长,这会让问题诊断变得困难。

**迭代终止条件**:

- ✅ 分镜之间无可见切换点
- ✅ 全程画面清晰无虚化
- ✅ 运镜有明显节奏感(非匀速)
- ✅ 人物外观与三视图高度一致
- ✅ 场景元素(弹窗/特效)按预期时机出现

## Key Constraints & Standards

### Immutable Rules (绝对不可违反)

1. **一镜到底定义**: 从按下录制到停止录制之间,相机不能停止运动或出现任何形式的剪辑切换。对应术语"one continuous shot" "oner"。

2. **禁止转场类型**(必须在提示词中明确禁止):

   - Cut(硬切)
   - Dissolve(叠化/淡入淡出)
   - Blur/Defocus transition(虚化转场)
   - Wipe(划像)
   - 任何基于遮挡或特效的过渡

3. **引用完整性**: 必须同时引用分镜图和人物三视图,缺一会导致空间结构混乱或人物不一致。

### Consistency Rules (一致性标准)

1. **空间一致性**: 分镜中定义的物理空间关系必须在3D空间中可达。例如,如果分镜1显示人物正面,分镜2显示背面,那么运镜轨迹必须是环绕而非跳切。

2. **光线一致性**: 全程主光源(如显示器蓝光)方向和色温不变。环境光可以因景深变化而衰减,但不能突变色温。

3. **人物一致性**: 面部特征/发型/服装必须完全匹配三视图。如果迭代中人物外观发生变化,需要重新生成。

### Quality Thresholds (质量阈值)

1. **时长范围**: 5-10秒最佳。低于5秒运镜过于仓促,高于10秒容易出现一致性崩溃。

2. **运镜段落数**: 3-4段最佳。2段太单调,5段以上容易出现硬切。

3. **景别跨度**: 单次生成最多跨越3个景别(如ECU→MS→FS)。跨度更大需要拆分为多次生成后拼接。

4. **清晰度标准**: 全程必须保持"画面锐利(sharp focus)",即使在快速运动时也不能有运动模糊(motion blur)超过合理范围。测试方法:暂停视频任意帧,主体必须清晰可辨。

### Technical Parameters (技术参数)

1. **分辨率策略**: 如遇到生成失败,首选降低分辨率而非简化提示词。分辨率对一致性影响小于内容复杂度。

2. **模型选择**: Fast版本适合迭代测试,确定方案后切换到标准版获得更高画质和更平滑运镜。

3. **参考图比例**: 分镜图和人物图的影响权重约为6:4。如需强化人物一致性,可在提示词中增加"严格遵循人物三视图外观"等强调语句。

## Example

**Scenario**: 深夜加班场景 — 从程序员面部特写拉到被错误弹窗包围的全景

**Input**:

- 分镜拼接图: 3帧(特写/中景/全景)
- 人物三视图: 东亚女性,丸子头,条纹上衣
- 时长: 5秒

**Prompt**:

```
深夜,高楼办公室内,灯光昏暗,冷蓝调。镜头从女主角(扎丸子头、穿条纹无袖上衣的年轻东亚女性)的面部极近特写开始,她双眼专注凝视屏幕,神情凝重,蓝色屏幕光打在脸上。

镜头缓慢向后直线拉镜(dolly out),逐渐露出她的上半身与桌面,桌上散落着草稿纸、文件,显示器屏幕上燃烧着橙色火焰粒子特效,红色数字"-100"醒目浮现。

镜头继续后拉至房间全景,整个房间的四面墙壁上密密麻麻浮现出蓝色与红色错误弹窗("运镜异常""生成失败""-100"),弹窗不断增多向四周扩散,将她小小的身影完全包围在错误信息的海洋中。窗外是深夜城市万家灯火。

整个过程为单次不间断的向后推拉运镜,无剪辑,无转场,全程画面清晰锐利,禁止虚化模糊,禁止淡入淡出,禁止硬切镜头,一镜到底。
```

**Expected Output**:

- 5秒视频,从0.5秒面部特写平滑过渡到4.5秒全景
- 人物外观与三视图100%匹配
- 错误弹窗在3秒后开始出现,4秒时达到包围效果
- 全程无可见切换点或虚化

## Advanced Techniques

### 首尾帧精确控制法

如果多次迭代仍无法消除转场处的不连续,可以使用**关键帧锚定策略**:

1. 将分镜的第1帧和第2帧之间的过渡,拆分为独立的"过渡段"生成
2. 明确指定起始帧状态和结束帧状态:
   - "起始: 面部特写,眼睛在画面中心"
   - "结束: 中景,人物在画面下半部,桌面占画面上半部"
3. 生成这个2-3秒的过渡段后,再生成下一段

这种方法牺牲了"真正的一镜到底",但在技术限制下可以获得视觉上无缝的效果。

### 运镜语法库

建立标准运镜术语词典,提高提示词的精确度:

- **Dolly**: 摄影机前后移动(in=推进,out=后拉)
- **Pan**: 水平旋转(left/right)
- **Tilt**: 垂直旋转(up/down)
- **Orbit/Arc**: 围绕主体旋转
- **Crane**: 升降运动
- **Whip Pan**: 快速甩镜(用于建立冲击感)
- **Tracking Shot**: 跟随移动主体

在提示词中混合使用这些术语,可以创造更复杂的运镜轨迹,例如"Dolly out + slight pan left + gradual tilt up"可以描述一个向后拉的同时轻微左摇并仰视的复合运动。

### 情绪-运镜映射表

不同情绪需要不同的运镜节奏:

目标情绪推荐运镜速度关键特征压迫/焦虑Dolly out中速-慢速逐渐揭示包围主体的元素震撼/冲击Whip pan → 急停快速甩镜后突然静止营造对比探索/发现Orbit + Dolly in慢速环绕观察细节再聚焦紧张/悬疑Slow push in极慢匀速缓慢推进,逐步放大细节失控/混乱不规则Pan + Tilt快速多变频繁改变方向但不硬切

根据叙事需求选择对应的运镜模式,可以大幅提升情绪表现力。
