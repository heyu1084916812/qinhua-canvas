# Cinematic Action Freeze-Frame Design

电影级武打动态定格画面生成技术。通过消除环境特效干扰,聚焦于人体运动本身的张力表达,结合极端透视与多机位构图策略,创造具有院线级质感的动作瞬间。

## Core Methodology

### Pure Tension Logic（纯粹张力逻辑）

**Zero Environment FX Rule（零环境特效原则**）严禁一切环境特效层:扬尘、碎石、烟雾、火花、粒子、爆炸残留、能量波纹。动作的爆发感必须且只能通过角色自身的肢体表达实现。这是与普通动作片视觉效果的核心区隔——去除冗余信息,将观众注意力100%锁定在人体运动的力量美学上。

**Human Geometry Tension（人体几何张力**）动作必须体现"拉伸与压缩"物理逻辑:

- **极致伸展瞬间**:肢体呈现超常延伸(长手/长腿效应),关节角度接近生物极限,服装面料在应力点产生清晰褶皱纹理
- **肌肉雕塑状态**:发力部位的肌群必须处于紧绷收缩状态,表皮与肌肉结构形成明显起伏地形
- **动态形变夸张**:允许超出常人的运动形变表现,通过夸张化的肢体比例强化视觉冲击力

**Strike Rhythm（打击节奏感**）定格画面必须捕捉动作的"顶点时刻":

- 蓄力→爆发→收势的"承转合"中,选取爆发的峰值瞬间
- 最极致的肢体伸展点或最紧张的肌肉收缩点
- 杜绝"动作摆拍感"(静态姿势摆拍)与"软弱感"(力量传导不完整)

### Cinematic Language（电影语言构图）

**Extreme Perspective Mandate（强制极端透视**）必须使用超广角/鱼眼镜头达成极端近大远小比例:

- 主打击部位(拳/脚)占据画面1/3以上前景空间
- 强制产生畸变透视,将人体拉伸成非自然几何体
- 创造"即将击中观众"的临场压迫感

**Dynamic Dutch Angle（狂暴倾斜构图**）画面倾斜角度不少于30°(标准荷兰角为15-45°):

- 通过打破水平线平衡感表达战局的凶险与激烈
- 倾斜方向应顺应动作力量方向(如右侧踢腿配合右上倾斜)
- 45°以上为"极端荷兰角",用于表现失控/致命一击

**Multi-Angle Matrix（多机位矩阵**）标准四机位覆盖逻辑:

1. **正面极低仰拍(Worm's Eye)**:贴地蠕虫视角向上看,强调凌驾感与破坏力,主打击部位正面冲向镜头
2. **侧面贴地追镜(90° Lateral)**:完整呈现动作剪影与人体几何轮廓,技术可读性最高
3. **斜后方追拍(Over-shoulder Pursuit)**:跟随旋转方向从背后追入,观众被"卷入"动作之中,临场感与速度感最强
4. **斜高俯压迫构图(Bird-eye Diagonal)**:45°俯角压缩身体为平面几何,完整呈现旋转轨迹,设计感最强

**Hard Light Sculpting（硬光雕刻**）必须使用硬光或锐利侧逆光:

- 在角色身体与轮廓上切割出深刻阴影带
- 强调肌肉结构与动态线条的起伏
- 拒绝柔光/环境光/漫反射——这些会削弱力量感
- 优选单一强光源制造高对比度剪影效果

## Workflow

### 1. Preparation Stage

**角色素材清单**

- 三视图参考(正面/侧面/背面)或多角度全身照
- 服装细节特征(图案/颜色/面料质感)
- 角色体型特征(身高比例/肌肉量/体态)

**动作类型决策**确定动作分类与顶点定格瞬间:

- 踢腿类:回旋踢顶点/侧踢伸展峰值/跳跃下劈落点前
- 拳击类:冲拳最远伸展点/勾拳收力瞬间/摆拳侧击峰值
- 摔技类:过肩摔腾空瞬间/锁技关节极限角度
- 跳跃类:二段跳最高点/翻滚空中悬停瞬间

**机位角度预选**根据动作类型预判最佳机位:

- 腿部动作优先:侧面追镜(完整展示腿部线条)、正面仰拍(压迫感)
- 拳部动作优先:斜后方追拍(拳头前景巨大)、侧面剪影(轨迹清晰)
- 旋转动作优先:斜高俯视(完整呈现旋转轨迹)、侧面追镜(速度感)

### 2. Initial Design Stage

**提示词框架结构**\[角色身份与服装\] + \[核心动作描述\] + \[人体张力细节\] + \[机位与透视\] + \[光影雕刻\] + \[画面风格\] + \[严格禁止项\]

示例构成:

```
"一位9岁小女孩,穿蝴蝶图案黑色哈伦裤与白色T恤,
执行高空回旋踢的顶点定格——右腿水平伸展至极限,裤子面料在大腿与小腿连接处产生清晰应力褶皱,支撑腿深度屈膝,上身反向扭转保持平衡,双臂展开形成人体风车轮廓,
超广角鱼眼镜头,极端近大远小透视,踢出的右脚占据画面右侧1/3前景,
30度荷兰角倾斜构图,低角度贴地仰拍,
硬光侧逆光从右上方45度角切入,在身体轮廓切割出锐利光边,背景纯白高调,
冷峻写实的院线级胶片质感,
严禁:地面扬尘、颗粒飞溅、碎屑、背景环境物、动作模糊、肢体穿模、表情呆滞、僵硬站姿"
```

**角色一致性策略**基于参考图的角色特征锚定:

- 面部特征:年龄/肤色/发型发色/五官比例
- 体型特征:身高/体型/肌肉量/四肢比例
- 服装识别:核心图案/颜色组合/面料质感
- 在提示词开头强调"严格还原参考图中的角色外观"

**透视与畸变校准**超广角透视的控制维度:

- 主打击部位(拳/脚)在画面中的占比:1/3(标准)到1/2(极端)
- 畸变程度描述:"极端近大远小"(标准)、"鱼眼畸变将腿部拉伸成压迫性柱体"(强化)
- 镜头焦距暗示:"16mm超广角"(中度)、"8mm鱼眼"(极端)

### 3. Iteration Stage

**Multi-Angle Batch Production（多角度批量生产**）标准操作:单一动作生成4个机位版本进行对比选优:

1. 正面极低仰拍 → 压迫感测试
2. 侧面贴地追镜 → 技术可读性测试
3. 斜后方追拍 → 临场感测试
4. 斜高俯压迫构图 → 设计感测试

每个机位提示词仅调整\[机位与透视\]部分,其余元素保持一致确保对比有效性。

**Tension Audit Checklist（张力审查清单**）逐项检查生成结果:

- \[ \] 环境特效零污染:无扬尘/烟雾/粒子/碎屑
- \[ \] 肢体延伸达标:主打击部位占前景1/3以上
- \[ \] 肌肉状态正确:发力部位呈紧绷收缩而非松弛
- \[ \] 服装应力纹理:关节弯曲处/拉伸处有清晰褶皱
- \[ \] 透视畸变到位:近大远小比例明显,非平行透视
- \[ \] 光影雕刻清晰:轮廓光或侧逆光产生明确阴影带
- \[ \] 动作顶点准确:捕捉爆发峰值而非过渡瞬间

**Consistency Cross-Check（一致性交叉检查**）多机位输出的角色识别度检查:

- 面部特征跨机位对比:肤色/五官/发型是否一致
- 服装图案还原:核心识别图案(如蝴蝶图案)在各角度是否保留
- 体型比例稳定性:身高/四肢比例在不同透视下是否合理

不一致时优先保留角色识别度最高的版本,或在提示词中强化"严格保持角色外观一致性,参考图为xxx"

**Angle Selection Logic（角度选优逻辑**）根据用途选择最终输出:

- 宣传海报/封面:选斜高俯视(设计感最强)
- 动作教学/技术展示:选侧面追镜(技术可读性最高)
- 沉浸式体验/游戏视角:选正面仰拍或斜后方追拍(临场感最强)
- 全面展示:保留全部4个角度作为对比组

## Key Constraints & Standards

### Immutable Rules（不可违背的硬性规则）

**环境特效绝对禁止**以下元素在任何情况下不得出现:

- 地面扬尘/沙尘
- 空气中的颗粒物/碎屑/碎石
- 烟雾/蒸汽/雾气
- 火花/电弧/能量波
- 爆炸残留物/冲击波可视化
- 背景环境破坏效果(碎裂墙体/掉落物体)

违反此规则的输出直接判定为不合格,必须重新生成。

**透视强制标准**

- 必须使用超广角(16mm以下等效焦距)或鱼眼镜头
- 主打击部位(拳/脚)必须占据画面前景1/3以上空间
- 必须产生明显的近大远小透视畸变
- 禁止使用标准镜头(35-70mm)或长焦镜头(85mm以上)

**荷兰角最低阈值**画面倾斜角度不得低于30°。低于此阈值的构图缺乏狂暴感,无法达成预期张力表达。特殊情况(如静态蓄力瞬间)可降至15°,但仍需保持倾斜。

### Fidelity Rules（高保真度规则）

**人体几何合理性**

- 允许夸张化肢体比例,但关节连接逻辑必须正确
- 肌肉收缩方向必须符合发力逻辑(如踢腿时大腿前侧肌群紧绷)
- 服装应力纹理必须出现在合理位置(关节弯曲处/拉伸部位)
- 杜绝肢体穿模(手臂穿过身体/腿部相互穿插)

**光影物理准确性**

- 硬光投射的阴影边缘必须锐利清晰
- 侧逆光必须在轮廓产生明确光边(Rim Light)
- 单一光源时阴影方向必须统一
- 拒绝多光源造成的混乱阴影(除非特殊创意需求)

**动作顶点识别准确性**定格瞬间必须捕捉:

- 踢腿:腿部伸展至最远点,膝关节接近锁死前的瞬间
- 冲拳:拳头前伸至最远点,肘关节即将完全伸直的瞬间
- 跳跃:腾空最高点,身体即将下落前的悬停瞬间
- 旋转:旋转速度最快点,身体扭转至最大角度的瞬间

### Consistency Rules（一致性规则）

**角色跨机位识别度**多角度生成时,以下特征必须100%保持:

- 核心服装图案(如蝴蝶图案、条纹、logo)
- 肤色色值(允许±5%光影变化)
- 发型与发色
- 体型比例(身高/四肢长度比)

**风格统一性**同一批次输出必须保持:

- 相同的光影风格(硬光/柔光/侧逆光)
- 相同的色调处理(冷色调/暖色调/黑白)
- 相同的画面纯净度(纯白背景/纯黑背景/简化场景)

**透视一致性逻辑**不同机位的透视畸变程度应保持相近:

- 若正面仰拍使用8mm鱼眼,侧面追镜也应使用8mm而非16mm
- 各机位的主打击部位占比应保持在相近范围(如均为画面1/3)

## Example

### 回旋踢四机位定格案例

**角色设定**9岁小女孩,蝴蝶图案黑色哈伦裤,白色T恤,黑色短发。

**动作选择**高空回旋踢的顶点定格——右腿水平伸展至极限,支撑腿深度屈膝,双臂展开平衡。

**机位1:正面极低仰拍**

```
一位9岁小女孩,穿蝴蝶图案黑色哈伦裤与白色T恤,黑色短发,
执行高空回旋踢的顶点定格——右腿水平伸展至极限正面冲向镜头,脚掌占据画面下半部分,裤子面料在大腿拉伸处产生清晰褶皱,支撑腿深度屈膝,双臂展开,
8mm鱼眼镜头,极端近大远小透视,脚掌占据画面右下1/2前景空间,
30度荷兰角向右倾斜,极低角度贴地仰拍(Worm's Eye View),
硬光从右上方60度角斜射,在身体左侧轮廓切割出锐利光边,背景纯白高调,
冷峻写实的院线级35mm胶片质感,高对比度,
严禁:地面扬尘、颗粒飞溅、碎屑、任何背景环境物、动作模糊、肢体穿模
```

**机位2:侧面贴地追镜**

```
一位9岁小女孩,穿蝴蝶图案黑色哈伦裤与白色T恤,黑色短发,
执行高空回旋踢的顶点定格——从正侧面视角完整呈现人体剪影,右腿水平伸展,支撑腿深蹲,上身反向扭转,双臂展开形成人体风车轮廓,
16mm超广角镜头,侧面90度贴地追镜,
35度荷兰角向右上倾斜,低角度平行地面拍摄,
硬光侧逆光从身体右侧90度角切入,将全身轮廓刻成锐利光线,背景纯白,
冷峻写实的院线级35mm胶片质感,
严禁:地面扬尘、颗粒飞溅、碎屑、任何背景环境物、动作模糊
```

**机位3:斜后方追拍**

```
一位9岁小女孩,穿蝴蝶图案黑色哈伦裤与白色T恤,黑色短发,
执行高空回旋踢的顶点定格——摄影机从斜后方45度角跟随旋转方向追入,右腿与脚跟在前景巨大呈现,身体扭转与面部表情同时可见,
12mm超广角镜头,斜后方Over-shoulder追拍角度,
30度荷兰角向右倾斜,低角度贴地向上拍摄,
硬光从左上方斜射,照亮面部与踢腿侧轮廓,背景纯白,
冷峻写实的院线级35mm胶片质感,
严禁:地面扬尘、颗粒飞溅、碎屑、任何背景环境物、动作模糊
```

**机位4:斜高俯压迫构图**

```
一位9岁小女孩,穿蝴蝶图案黑色哈伦裤与白色T恤,黑色短发,
执行高空回旋踢的顶点定格——45度俯角将旋转身体压缩成平面几何,头部、双臂、踢出的右腿形成三点星形构图,完整呈现旋转轨迹,
16mm超广角镜头,45度斜高俯视(Bird-eye Diagonal),
30度荷兰角倾斜,从右上方向左下方俯拍,
硬光顶光从正上方垂直投射,在身体周围产生清晰阴影投影,背景纯白,
冷峻写实的院线级35mm胶片质感,几何构图设计感,
严禁:地面扬尘、颗粒飞溅、碎屑、任何背景环境物、动作模糊
```

**输出对比与选优**

- 机位1(正面仰拍):压迫感最强,脚掌冲镜视觉冲击力最大,适合表现"被击中"的受击方视角
- 机位2(侧面追镜):技术可读性最高,完整展示踢法的人体几何美学,适合动作教学或技术展示
- 机位3(斜后方追拍):临场感与速度感最强,观众被"卷入"动作之中,适合沉浸式体验场景
- 机位4(斜高俯视):几何设计感最强,构图最具艺术性,适合海报、封面等宣传物料

根据用途选择最终输出,或保留全部4个角度作为完整对比组。
