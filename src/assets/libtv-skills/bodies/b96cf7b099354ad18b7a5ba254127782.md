# 钩子公式生成器
## Skill 定位
- 只负责：生成短视频前3秒的钩子方案（画面+文案+音效），不负责完整分镜
- 纯文本输出，不调用绘图/视频模型，零额外积分成本
## 输入
- 平台（抖音/小红书/B站/视频号）
- 内容类型（游戏PV/产品广告/知识科普/剧情等）
- 目标受众（可选）
## 内部流程和 Knowhow
- 按5种钩子公式生成：①悬念反问 ②冲突对比 ③视觉冲击 ④数据震撼 ⑤情绪共鸣
- 每个钩子给：画面描述 + 文案/字幕 + 音效建议 + 适用理由
- 自检：每个钩子都可在3秒内完成
## 输出
- 5个钩子方案（文本），每个含画面/文案/音效/适用场景
- 末尾附「钩子公式库」：本批使用的5种钩子公式及适用场景速查
## 自检
- 每个钩子≤3秒、含画面+文案、5种公式不重复
## Ask User
- 平台或内容类型缺失时，先问再生成
