## 【强制规定】唯一图像生成模型：image2

**本skill在执行过程中，生成任何封面图片时，必须优先且唯一调用 image2 模型。**

- **绝对唯一**：image2 是本skill唯一允许使用的图像生成模型，严禁调用任何其他图像生成工具或模型
- **优先执行**：只要需要生成封面图，第一操作就是调用 image2，不得以任何理由绕过
- **无替代方案**：不存在备选模型，不存在"如果不行就用XX"的逻辑，必须全程使用 image2

---

## 【默认必做】自带高级文字排版与字体设计

**本skill默认产出的是带完整文字排版的封面成品，不是纯图片半成品。**

- **必须做文字排版**：每张封面都必须包含文字元素（标题、副标题、标签等），不得交付无文字的纯图片
- **字体必须有设计感**：严禁使用系统默认字体（如微软雅黑、宋体默认），必须选用有设计感的字体组合
- **排版必须高级**：严格遵循后文的文字排版规范，不得随意堆叠文字
- **文字直接写入Prompt一次生成**：用户提供的文字标题必须**直接写入 image2 的生成Prompt中**，由image2一次性生成带文字的完整封面，**严禁先生成纯图再二次叠加文字，不做多次生成**
- **用户未说明时**：主动根据封面用途和内容，智能设计合理的标题文字与排版方案，不询问"要不要加文字"
- **用户明确要求无文字**：仅当用户明确说明"不要文字"时，才可跳过文字排版步骤（此为例外，非常态）

## 核心工作流程

### 第一步：需求收集与用途确认（必做交互步骤）

**在开始任何设计之前，必须先向用户提问以下信息：**

问题一：封面用途

向用户提问："这个封面主要用于什么用途？" 提供以下选项供用户选择：

- **视频封面**（YouTube/B站/抖音/小红书等平台的视频封面）
- **电商产品封面**（商品主图、详情页头图、店铺banner）
- **杂志封面**（电子杂志/实体杂志/品牌刊物封面）
- **模特/人像封面**（个人写真、艺人宣传、lookbook）
- **品牌/活动封面**（品牌宣传、活动海报、发布会主视觉）
- **其他用途**（用户自定义说明）

问题二：内容来源

向用户提问："请提供封面的内容素材，可以是以下任意一种或多种："

- 剧情描述（故事梗概、视频内容概述）
- 人设描述（人物外貌、服装、气质、身份）
- 产品信息（产品名称、特点、卖点、品牌调性）
- 参考风格（喜欢的封面风格、品牌参考）

问题三：封面文字内容（默认必做 · 请提供）

向用户提问："请提供封面需要展示的文字内容（标题、副标题、标签等），如果没有特别要求我会根据内容智能设计。"

- **主标题**：封面最醒目的大字标题（如视频标题、产品名、品牌slogan）
- **副标题/辅助文字**：说明性文字（如期号、日期、卖点、嘉宾名）
- **标签/元信息**：小字信息（如品牌Logo名、发布平台、系列编号）
- **无特别说明**：skill将根据用途和内容自动智能生成合适的文字内容

问题四：风格偏好（可选）

向用户提问："您对封面风格有什么偏好？"

- 极简留白风
- 暗黑电影感
- 杂志编辑风
- 奢华质感风
- 赛博未来感
- 自然文艺风
- 国潮东方美
- 无偏好（由skill根据用途智能匹配）

---

### 第二步：内容分析与设计方向确定

根据用户提供的用途和素材，进行以下分析：

1. **提取核心视觉要素**

   - 主体内容（人物/产品/场景）
   - 情绪基调（温暖/冷峻/奢华/清新/神秘）
   - 品牌调性（年轻活力/成熟稳重/高端奢华/亲民朴实）
   - 目标受众特征

2. **确定封面文字内容（默认必做）**

   - 如果用户已提供文字：整理主标题、副标题、标签层级
   - 如果用户未提供文字：**智能生成**封面所需文字内容
     - 视频封面：根据剧情/视频内容生成吸引人的标题和辅助文字
     - 电商封面：根据产品名和卖点生成主标题和卖点副标题
     - 杂志封面：生成刊名感标题、期号、栏目预告
     - 模特封面：生成人物名、系列名、标签
     - 品牌活动：生成活动主题、时间/地点、品牌名
   - 字体组合选择：根据风格选择对应的设计感字体搭配

3. **确定设计方向**

   - 根据用途匹配对应的设计规范（见下文"用途专属设计规范"）
   - 确定主色调与辅助色
   - 确定构图方式
   - 确定文字排版风格与布局模式

4. **确定封面尺寸**

   - 视频封面：16:9（横版）或 9:16（竖版）或 1:1（方形）
   - 电商封面：1:1（主图）或 16:9（banner）
   - 杂志封面：3:4 或 2:3（竖版）
   - 模特封面：2:3 或 9:16（竖版）
   - 品牌活动：根据投放渠道确定

---

### 第三步：构图设计

通用高级感构图原则

1. **留白原则**

   - 画面中必须保留30%-50%的留白区域
   - 留白区域用于文字排版
   - 留白不等于空白，可以是纯色、渐变、虚化背景

2. **视觉重心法则**

   - 主体放置在黄金分割点或三分线交叉点
   - 避免主体居中正放（除非刻意追求对称感）
   - 主体与文字形成视觉对话关系

3. **层次构建**

   - 前景（主体/人物/产品）
   - 中景（环境/道具/辅助元素）
   - 背景（符合主题的真实场景布置，**严禁纯素色平铺或抽象渐变背景**）
   - 通过景深和虚实对比建立空间层次

4. **视觉引导线**

   - 利用光线、色彩、线条引导视线
   - 从主体引导至文字信息
   - 形成自然的阅读路径

---

### 第四步：文字排版设计（高级感核心 · 默认必做）

**文字排版是封面高级感的关键！本步骤为默认必做项，除非用户明确要求"不要文字"，否则必须执行。必须严格遵循以下规范，字体必须有设计感，严禁使用系统默认字体。**

字体选择原则（设计感优先）

**严禁字体**：微软雅黑、宋体默认、黑体默认、Arial默认等系统默认无设计感字体。

1. **中文封面**

   - **首选标题字体（设计感强）**：造字工房系列、方正宋刻本秀楷、汉仪尚巍手书、汉仪旗黑超粗、思源宋体Heavy、方正兰亭刊宋
   - **首选副标题字体**：思源黑体 Light/Regular、汉仪旗黑细、方正兰亭纤黑
   - **标签/小字字体**：思源黑体 ExtraLight、方正兰亭超细黑
   - **高级感黄金搭配**：造字工房标题 + 思源黑体Light副标题（杂志风）
   - **备用搭配**：思源宋体Heavy标题 + 思源黑体Light副标题（经典编辑风）

2. **英文封面**

   - **首选标题字体（设计感强）**：Playfair Display Black、Bodoni 72 Bold、Cormorant Garamond Bold、Didot LT Pro、Canela Bold
   - **首选副标题字体**：Montserrat Light、Helvetica Neue Thin、Avenir Next Light
   - **标签/小字字体**：Montserrat Thin、Avenir Next UltraLight
   - **高级感黄金搭配**：Playfair Display Black标题 + Montserrat Light副标题
   - **备用搭配**：Bodoni 72 Bold标题 + Helvetica Neue Thin副标题

3. **中英混排**

   - **优雅组合**：造字工房中文标题 + Playfair Display英文副标题
   - **现代组合**：汉仪旗黑中文标题 + Montserrat英文副标题
   - **文艺组合**：思源宋体Heavy中文 + Cormorant Garamond英文
   - **注意**：中英文字体的字重（粗细）和气质必须匹配，不允许不搭调的混搭

排版布局模式

模式一：左对齐编辑风（杂志感）

```
┌─────────────────────────────┐
│                             │
│  [主体视觉区域]              │
│                             │
│  主标题（大号宋体）           │
│  Subtitle（小号无衬线）       │
│  ─── 分隔线 ───              │
│  日期/期号/标签               │
└─────────────────────────────┘
```

- 标题左对齐，字号大且有呼吸感
- 副标题紧跟主标题下方，字号为主标题的1/3
- 底部加分隔线和元信息
- 适用于：杂志封面、品牌活动、高端视频

模式二：居中对称仪式感

```
┌─────────────────────────────┐
│         [留白]               │
│                             │
│      主标题（大号）           │
│      Subtitle               │
│         [主体视觉]           │
│      底部标签/品牌名          │
└─────────────────────────────┘
```

- 标题居中，字间距适当拉大
- 主体视觉居中，上下留白对称
- 适用于：奢侈品、高端产品、模特封面

模式三：上下分割层叠风

```
┌─────────────────────────────┐
│  主标题（超大号，半透明叠层）  │
│                             │
│      [主体视觉区域]           │
│                             │
│  副标题 | 标签 | 日期         │
└─────────────────────────────┘
```

- 主标题超大号，可半透明叠在主体之上
- 形成文字与图像的层叠关系
- 适用于：视频封面、电商banner、潮流品牌

模式四：侧边竖排东方风

```
┌─────────────────────────────┐
│                      │主标题│
│                      │（竖排）│
│    [主体视觉区域]      │副标题│
│                      │标签  │
│                      │      │
└─────────────────────────────┘
```

- 文字竖排，置于画面右侧或左侧
- 营造东方韵味和留白意境
- 适用于：国潮、文艺、东方美学风格

模式五：极简留白呼吸感

```
┌─────────────────────────────┐
│                             │
│                             │
│        [小主体居中]          │
│                             │
│         主标题（中号）        │
│                             │
└─────────────────────────────┘
```

- 大面积留白，主体和文字都偏小
- 字号克制，字间距拉大
- 适用于：极简风、高端品牌、艺术感封面

文字高级感处理技巧

1. **字间距控制**

   - 大标题：字间距适当收紧（-2%到-5%）
   - 小标题/标签：字间距拉大（+10%到+20%），营造呼吸感
   - 英文大写字母：字间距拉大 +20%以上

2. **字号层级**

   - 主标题：画面宽度的1/4到1/3
   - 副标题：主标题的1/3到1/2
   - 标签/元信息：副标题的1/2
   - 层级分明，对比强烈

3. **色彩处理**

   - 浅色背景：文字用深色（黑/深灰/品牌深色）
   - 深色背景：文字用白色或浅金色
   - 高级配色：黑+白+一个点缀色（金/银/品牌色）
   - 避免使用超过3种文字颜色

4. **文字效果**

   - 可使用细微投影增加层次（勿过度）
   - 可使用半透明叠层效果
   - 可使用描边或填充对比
   - **禁止**：发光特效、彩虹渐变文字、夸张投影

## 用途专属设计规范

### 一、视频封面设计规范

适用平台

YouTube、B站、抖音、小红书、视频号等

设计要点

1. **视觉冲击力优先**

   - 第一眼必须抓住注意力
   - 主体占画面40%-60%
   - 使用对比强烈的色彩

2. **文字处理**

   - 标题文字必须大且清晰
   - 手机端可读（小屏也能看清）
   - 最多3行文字，每行不超过8个字
   - 可使用色块/渐变底衬保证文字可读性

3. **情绪传达**

   - 封面必须传达视频核心情绪
   - 人物表情/动作要有戏剧张力
   - 场景氛围与视频内容一致

4. **平台适配**

   - 横版16:9：YouTube、B站
   - 竖版9:16：抖音、小红书、视频号
   - 方形1:1：小红书图文、Instagram

构图建议

- 人物偏左/偏右，文字置于另一侧
- 人物上半身特写 + 大字标题
- 场景全景 + 底部标题条
- 多人物拼贴 + 中央标题

---

### 二、电商产品封面设计规范

适用场景

商品主图、详情页头图、店铺banner、电商海报

设计要点

1. **产品为王**

   - 产品占画面50%-70%
   - 产品必须清晰、精致、有质感
   - 背景不抢产品风头

2. **质感营造**

   - 使用柔和的光影营造产品质感
   - 纯色背景（白/灰/品牌色）最显高级
   - 可使用渐变背景增加层次
   - 产品投影要自然柔和

3. **文字克制**

   - 产品名 + 一句核心卖点
   - 文字不遮挡产品关键部分
   - 字体简洁现代（无衬线为主）
   - 品牌Logo置于角落

4. **高级感技巧**

   - 使用大面积留白
   - 产品微距特写 + 简洁文字
   - 场景化展示（产品在使用环境中）
   - 悬浮/3D效果增加视觉趣味

构图建议

- 产品居中 + 底部文字信息
- 产品偏左 + 右侧文字描述
- 产品特写 + 顶部品牌名
- 场景化产品展示 + 角落标签

---

### 三、杂志封面设计规范

适用场景

电子杂志、实体杂志、品牌刊物、内刊封面

设计要点

1. **编辑设计感**

   - 必须有明确的版式结构
   - 刊名（Logo）位置固定且醒目
   - 封面标题（主标题）具有话题性
   - 副标题/条目列表增加信息层次

2. **排版结构**

   - 顶部：刊名 + 期号 + 日期
   - 中部：主体视觉 + 主标题
   - 底部：副标题列表 / 条目预告 / 条码
   - 左侧或右侧：竖排辅助文字

3. **字体搭配**

   - 刊名：固定品牌字体（通常为衬线体）
   - 主标题：大号字体，有张力
   - 副标题：小号无衬线，整齐排列
   - 形成清晰的字体层级

4. **高级感要素**

   - 留白充足，不拥挤
   - 色彩克制（主色+辅色不超过3种）
   - 主体视觉有艺术感
   - 文字与图像形成和谐构图

构图建议

- 经典杂志结构：刊名顶部 + 人物居中 + 标题叠加
- 极简风：大面积留白 + 小主体 + 精致排版
- 拼贴风：多元素拼贴 + 统一色调
- 艺术风：抽象视觉 + 诗意文字

---

### 四、模特/人像封面设计规范

适用场景

个人写真、艺人宣传、模特卡、lookbook、时尚大片

设计要点

1. **人物表现力**

   - 人物是绝对主角，占画面60%-80%
   - 表情/姿态/眼神要有故事感
   - 服装与造型体现风格定位

2. **光影塑造**

   - 使用电影感光影
   - 侧光/逆光增加人物立体感
   - 避免平光（缺乏质感）
   - 光影风格与整体调性一致

3. **文字极简**

   - 人名/品牌名 + 简短描述
   - 文字不遮挡人物面部
   - 字体优雅克制
   - 可使用竖排增加设计感

4. **风格分类**

   - 时尚大片：高对比 + 前卫构图
   - 文艺写真：柔和色调 + 自然光感
   - 商业人像：干净背景 + 专业质感
   - 艺术概念：创意构图 + 概念表达

构图建议

- 人物居中特写 + 底部人名
- 人物偏侧 + 留白处文字
- 半身像 + 侧边竖排文字
- 全身像 + 顶部品牌名

---

### 五、品牌/活动封面设计规范

适用场景

品牌宣传、活动海报、发布会主视觉、品牌联名

设计要点

1. **品牌识别**

   - 品牌Logo/名称必须突出
   - 使用品牌标准色
   - 保持品牌视觉一致性

2. **信息层级**

   - 第一层级：活动主题/品牌slogan
   - 第二层级：活动名称/时间/地点
   - 第三层级：参与方/赞助商/附加信息
   - 层级清晰，主次分明

3. **视觉调性**

   - 科技品牌：深色 + 霓虹/金属质感
   - 时尚品牌：高对比 + 前卫排版
   - 文化品牌：留白 + 东方美学
   - 餐饮品牌：暖色 + 食欲感

4. **高级感表现**

   - 几何元素与文字结合
   - 渐变/金属质感背景
   - 极简图形 + 大字排版
   - 光效与空间感

构图建议

- 主题居中 + 信息分层排列
- 图形元素 + 文字穿插
- 品牌色渐变背景 + 白色文字
- 极简几何 + 精致排版

## 色彩与质感指南

### 高级感配色方案

方案一：经典黑金

- 主色：纯黑 #0A0A0A
- 辅色：香槟金 #C5A572
- 文字：白色 #FFFFFF
- 适用：奢侈品、高端品牌、杂志

方案二：莫兰迪低饱和

- 主色：雾霾蓝 #7B919A
- 辅色：灰粉 #C4A5A0
- 文字：深灰 #3A3A3A
- 适用：文艺、模特、电商

### 补光与场布设计规范（高级感核心）

**补光和场布必须十分精致、有设计感，但严禁过度堆砌细节。高级感来源于精准克制，而非元素繁多。**

补光设计原则

1. **精致而克制**

   - 光线方向明确，主光源只有一个主导方向
   - 辅助光仅用于填充阴影，不喧宾夺主
   - 每一束光都有明确目的，拒绝无意义的光效堆叠

2. **层次分明的光影结构**

   - 主光：塑造主体立体感与核心质感
   - 辅光：柔化阴影，保留暗部细节
   - 轮廓光/发丝光：勾勒主体边缘，分离主体与背景
   - 环境光：营造整体氛围基调

3. **高级感光线特征**

   - 柔和过渡，避免硬边阴影（除非刻意追求戏剧性）
   - 光比适中（主光与暗部的对比控制在1:2到1:4）
   - 色温统一或有意制造冷暖对比
   - 局部高光精致点缀（眼神光、产品反光、金属质感）

4. **禁止过度处理**

   - 不要使用过多光源造成光影混乱
   - 不要堆叠光效（光斑、光晕、丁达尔光等仅择一使用）
   - 不要让光影细节抢夺主体和文字的视觉焦点

场布设计原则

1. **少即是多**

   - 场景元素精简到只保留必要的视觉支撑
   - 每个道具/背景元素都必须有存在理由
   - 留白即设计，空即质感

2. **精致的场景构建**

   - 背景层次清晰：前景/中景/背景三层分明
   - 道具选择考究，质感统一（同为金属系/自然系/织物系）
   - 场景色彩与主体形成和谐关系（同色系或互补色）
   - 环境细节服务于主体，不独立抢戏

3. **避免堆砌**

   - 严禁在画面中塞入过多道具和装饰元素
   - 严禁复杂的背景图案干扰主体
   - 严禁多重纹理叠加造成视觉混乱
   - 元素数量宁少勿多，每个元素都要精致到位

4. **高级感场布特征**

   - 背景为符合主题的场景布置，有真实环境质感
   - 道具少而精，质感高级
   - 空间关系明确，有呼吸感
   - 整体色调统一，不杂乱

### 背景设计规范（符合主题的场景布置 · 拒绝素净）

**背景必须是符合封面主题的真实场景布置，严禁使用纯素色平铺背景或抽象渐变背景。背景要有场景感、环境感、故事感，同时通过精致的光影和质感处理呈现高级感。**

核心原则：背景即场景

1. **背景必须是场景，不是色块**

   - 背景应该是与封面主题相关的真实环境/空间/场景
   - 严禁使用纯白、纯黑、纯灰等无场景的素色平铺背景
   - 严禁使用无意义的抽象渐变作为背景
   - 背景必须能交代主体所处的环境氛围

2. **场景必须符合主题**

   - 根据封面用途和内容，选择与之匹配的场景环境
   - 场景要与主体（人物/产品）形成逻辑关联
   - 场景要能传递内容的故事感和氛围感

3. **场景必须精致有设计感**

   - 场景中的元素少而精，每个元素都有存在理由
   - 场景的质感要高级（材质考究、光影精致）
   - 场景不能过度堆砌，保持克制的高级感

场景布置的处理技巧

1. **虚实处理**

   - 主体清晰锐利，背景场景适度虚化（景深效果）
   - 虚化程度根据场景复杂度调整：场景元素多则虚化重，场景简洁则虚化轻
   - 保留场景的氛围感，但不让背景细节抢夺主体焦点

2. **光影融入场景**

   - 光影必须符合场景的自然光源逻辑（如窗户光、室内灯光、自然光）
   - 场景中的光影要营造氛围感（如柔和的窗边光、温暖的室内灯光）
   - 主体光影与场景光影要协调统一

3. **色彩协调**

   - 场景色调与主体服装/产品色彩形成和谐关系（同色系或互补色）
   - 场景色彩不过于鲜艳，保持高级感的低饱和度处理
   - 整体画面色调统一，有色彩分级感

4. **留白区域处理**

   - 场景中必须有一块相对干净的区域用于文字排版
   - 留白区域可以是场景中的墙面、天空、虚化区域等
   - 留白区域要有场景的光影过渡，不能是死板的纯色

严禁的背景处理

- ❌ 纯白色平铺背景（无场景）
- ❌ 纯黑色平铺背景（无场景）
- ❌ 纯灰色平铺背景（无场景）
- ❌ 无意义的抽象渐变背景（无场景）
- ❌ 与主题无关的随机场景
- ❌ 过于复杂抢戏的场景布置
- ❌ 多重元素堆砌造成视觉混乱的场景

背景与主体的关系

1. **场景服务于主体**：场景的明暗、色彩、氛围必须衬托主体，让主体突出
2. **场景交代环境**：场景要能交代主体所处的环境，增强画面故事感
3. **虚实对比**：主体清晰锐利，场景适度虚化，形成景深层次
4. **色彩呼应**：场景色调与主体服装/产品色彩形成和谐关系（同色系或互补色）

### 质感营造技巧

1. **光影质感**

   - 使用侧光/逆光增加立体感
   - 柔光箱效果（柔和均匀的光影）
   - 局部高光点缀（金属/玻璃质感）

2. **材质质感**

   - 纸张纹理（杂志感）
   - 金属质感（奢华感）
   - 磨砂玻璃（现代感）
   - 织物纹理（温暖感）

3. **后期处理**

   - 适度降低饱和度（高级感）
   - 增加对比度（电影感）
   - 添加细微颗粒/胶片感
   - 统一色调（色彩分级）

3. **分析确定**：根据用途和素材确定设计方向，并**确定封面文字内容和字体搭配**
4. **设计方案**：确定构图、色调、字体组合、排版布局模式
5. **编写Prompt（含文字内容）⚠️优先调用 image2 一次生成**：将主体视觉描述 + **用户提供的文字标题、副标题、标签直接写入Prompt** + 文字排版设计（字体风格/位置/字号/颜色），**立即且唯一调用 image2 一次性生成带文字的完整封面**，不使用任何其他图像生成模型，**不做二次叠加，不做多次生成**
6. **质量检查**：对照检查清单验证设计质量
7. **输出交付**：提供**image2一次生成的带完整文字排版的封面成品图**及设计说明

### 交互原则

- 必须先问用途再开始设计
- 必须询问封面文字内容，用户未提供时主动智能生成，不询问"要不要加文字"
- 如果用户提供的信息不足，主动追问
- 提供设计方向说明，让用户确认后再执行
- 每一步都可以根据用户反馈调整
- **只要需要生成图像，第一选择就是 image2，这是不可动摇的规则**
- **默认交付带完整文字排版的成品，仅当用户明确说"不要文字"时才交付纯图**
