# 2D 手绘美术幻想风格短片生成器

## 用途

本 Skill 专精于将概念艺术与东方幻想美学融合，生成具有数字手绘质感的视频内容。它能够将抽象的故事梗概转化为包含戏剧性光影、水彩肌理和叙事张力的动态短片，适用于高品质视觉化创作。

## 适用输入

- **核心需求**：故事梗概、剧本文本或核心情绪描述。
- **参考素材**：角色设定图（@image）、场景氛围图、画幅要求（横屏/竖屏）。
- **辅助信息**：BGM 节奏参考、旁白脚本、目标时长（15s - 3min）。

## 操作步骤

1. **需求解析**：系统根据输入明确故事内核、角色数量及视觉定位，生成《需求确认单》。
2. **素材结构化**：分析参考图的色彩倾向与笔触风格，提取角色特征并建立一致性索引。
3. **分镜设计**：创作详细的故事板（Storyboard），规划景别（近景/特写为主）、运镜（缓慢推拉）与光影方案。
4. **画面与视频生成**：通过图生视频工作流（Image-to-Video），先确立关键帧风格，再生成连贯的视频片段。
5. **剪辑与后期**：按照情绪曲线组接镜头，统一色彩方案（暖橙×冷紫互补色），并合成背景音乐与音效。

## 输出要求

- **视觉风格**：明显的数字画笔肌理，虚实结合的边缘处理，强烈的戏剧性侧逆光（Rim Light）。
- **技术规格**：1080p 或 4K 分辨率，24fps 电影级帧率，16:9 或 9:16 画幅。
- **内容构成**：完整成片视频、Markdown 格式的分镜脚本表、原始素材包。

## 注意事项

- **一致性**：需在 Prompt 中重复使用角色种子短语（Seed Phrase）以确保角色不走形。
- **动态控制**：本风格强调“静谧的力量感”，应避免过于剧烈的画面晃动或快速闪烁。
- **色彩约束**：严格遵循暖橙红背景与冷紫灰人物的色调体系，以增强视觉高级感。
