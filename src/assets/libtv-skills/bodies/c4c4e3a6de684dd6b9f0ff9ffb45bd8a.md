# 双人打斗视频生成

## 用途

把一段双人对战的设定，生成一套可用的双人对战视频。

**适用**：两名角色的对战，需要体现双方兵器、技能特点与打斗过程。

**不适用**：单人动作、群战（三人及以上混战）。遇到这类需求不要套用本 skill。

## 输入

一次性向用户收齐以下信息，缺哪项就明确追问，不要自行编造：

项说明战斗场景对战发生的地点、环境、氛围对战双方两名角色的身份与外形特征双方兵器各自使用的武器双方技能特点真气颜色与形态、特殊格斗技巧、特殊武器用途开始站位图双方开局的相对位置与朝向

## 硬要求（必须满足，不满足就重做）

1. **动作不粘连**：两人动作必须各自独立、边界清晰，不能出现肢体互相穿插、粘连成一团的情况。
2. **动作不变形**：角色的身形、兵器形态在整个打斗过程中保持稳定，不能扭曲、拉长、崩坏。
3. **极具爆发力**：打击要有力量感与速度感，动作干脆，不能软绵绵、拖沓。
4. **场景破坏感**：打斗对周围环境造成可见的破坏与冲击（碎裂、扬尘、冲击波等），强化爆发力。

## 生成流程

1. 确认输入信息完整，尤其是双方技能特点与开始站位图。
2. 依据站位图确定开局构图，保证两名角色位置、朝向与用户提供的一致。
3. 按双方的兵器与技能特点设计打斗动作，确保两人的动作线各自独立、互不粘连。
4. 生成视频时，把「动作不粘连、不变形」作为首要校验项，把「爆发力、场景破坏感」作为表现强化项。
5. 产出整套双人对战视频后，逐条对照上面的硬要求自检，不合格则调整重生成。

## 测试用例

**输入**：

- 战斗场景：夜晚的古城墙废墟，地面碎石遍布
- 对战双方：黑衣剑客（瘦高，长发束起）、赤甲力士（魁梧，光头）
- 双方兵器：黑衣剑客用双短剑；赤甲力士用一柄重锤
- 双方技能特点：黑衣剑客真气为青蓝色、呈细长丝线状，擅长贴身快攻与瞬步；赤甲力士真气为暗红色、呈块状护体，擅长重击与震地
- 开始站位图：黑衣剑客在画面左侧、面朝右；赤甲力士在画面右侧、面朝左，两者相距约五步

**期望产出**：一套双人对战视频，两人动作各自独立不粘连、身形兵器不变形，打击具爆发力，打斗过程中城墙与地面出现碎裂、扬尘等破坏效果。
