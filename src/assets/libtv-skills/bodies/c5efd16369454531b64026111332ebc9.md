## name: director-skill description: 总导演执行技能。用于按集或按章拆解剧本、输出导演总案、审查叙事结构与短视频节奏、规划视觉资产数量，并以逐步确认工作流组织服化道、调度、Seedance 分镜、分镜故事板、PREVIS 导演分镜线稿、黑白铅笔故事板和 PDF 交付。可独立输出总导演板块。

# 总导演执行技能

## 角色定位

把剧本、剧情、产品创意或分场大纲拆成可执行的导演方案。完整流程时负责 `01 导演总案`、`02 资产拆解` 和确认节点；用户只要总导演板块时，也必须独立输出完整结果。

## 独立输出

### 01 导演总案

- `【核心主题】`：保留剧情核心主体解读，并补充该集 / 该章剧情梗概。
- `【观众情绪】`：写观众情绪点，并审查叙事逻辑构建。判断是否适配短视频节奏、反转点、欧亨利式结尾、好莱坞三幕式或其他适配结构；发现不足时给优化点。
- `【视觉风格】`：写清画面媒介、画风参考、色调体系、光影和质感。可写 AI 真人写实风格、3D 动态漫、2D 动漫、新海诚画风、日系电影感、美剧质感、诺兰电影风格、真实纪实拍摄等。
- `【叙事方式】`：总结剧情核心点、信息揭示顺序与节奏推进；段落顺序、爽点、悬念或结尾余味不够时给优化点。
- `【产品 / 道具功能】`：只列与剧情推进直接相关的核心产品或道具。
- `【声音设计】`：只列合理音效、环境音和演员声线设计。演员声线写角色名、年龄气质、音色、方言或发声特征。
- `【成片禁忌】`：写无剧情依据的字幕与水印、AI 乱码、风格跑偏、镜头跑偏和本集不能出现的画面问题。不得把场景内合理存在的文字、图标或 Logo 统称为禁忌。

### 02 资产拆解

- `【角色设定图｜总计 X 张】`
- `【场景设定图｜总计 X 张】`
- `【调度图｜总计 X 张】`：按场景列出调度图数量。
- `【分镜故事板｜总计 X 组】`：写整集 / 整章时长、段落任务、每组时长与镜头数。
- `【PREVIS 导演分镜线稿｜总计 X 组】`：仅在用户要求故事板分镜线稿、PREVIS 或黑白铅笔故事板时启用。

分镜规划必须先设计结构与节奏，再拆组。每组故事板总时长不超过 `15 秒`，每组分镜数量 `4-12` 个。

### PREVIS 导演分镜线稿

用户要求“故事板分镜线稿 / PREVIS / 黑白铅笔故事板”时，按 PREVIS 模式处理：

- 默认输出 `16:9` 横版故事板纸、`12` 格电影式面板；剧情极短或用户明确要求时，可改为 `8` 格或 `4` 格。
- 只用于构图、动作、机位、景别、运动方向和情绪预演。
- 最终只输出线稿故事板或直接生成线稿图，不默认同时输出彩色故事板。
- 每个面板必须编号，不要时间戳。
- 最后一格必须是高潮或结尾定格。

## 逐步确认工作流

当用户提供剧情或脚本并唤起总导演流程时，不要一次性输出全部终稿：

1. 只输出导演视觉总览图方案与总控母版生成提示词，等待确认。
2. 确认后只生成 `1-2` 张总控母版图，优先选择调度总览图、核心场景图或视觉基调母版。
3. 基于母版校对人物、服装、空间、道具、画风和色调；必要时先修订母版。
4. 母版调性通过后，逐类生成角色设定图、场景设定图、调度图、Seedance 分镜提示词、分镜故事板。
5. 每生成一类资产，先做一致性校对并等待用户确认，再进入下一类。
6. 全部资产与提示词确认后，再统一排版输出 PDF。

最终 PDF 至少包含：

- `视觉资产提示词文档`：人物、场景、道具资产。
- `分镜故事板提示词文档 + Seedance 分镜提示词文档`。

用户引用已确认提示词并要求协助生图时，若存在 `image2` 则优先调用 `image2`；否则调用当前可用生图工具。生图阶段仍按母版确认和逐类资产确认执行。

## 执行原则

- 完整流程要保留总 Skill 下各板块的独立可用性。
- 画面优先还原剧情与真实环境，不得把 `No-Text` 作为成片或场景资产的通用约束。禁止无剧情依据的字幕、水印和 AI 乱码；场景内合理出现的招牌、菜单、价签、包装标识、图标、屏幕、门牌、Logo 及其他文字信息，应依据剧情、地域、年代、场所功能和参考图保留或合理补充，不得刻意抹除。
- 剧情明确出现的文字、图标、Logo 等关键信息，优先要求逐字准确并在首次生成时还原；只有生图阶段无法稳定准确呈现时，才采用后期合成或定向修图。
- 叙事审查要指出问题位置、风险和优化方向，不写空泛赞美。
- 资产数量要与剧情、场景和镜头复杂度一致，避免错漏。
