# 毛绒材质工坊

## 核心原则

不要只做"给图片加一层毛绒滤镜"，而要做"把对象重新雕塑为毛绒世界里的居民"——每一根绒毛的走向、配色、光影都要服务于产品卖点或角色性格，让毛绒材质本身成为视觉说服力。

持久引擎（因果链）：

**创作意图 -&gt; 目标对象拆解 -&gt; 毛绒化策略（材质/配色/比例/表情）-&gt; 毛绒质感构建（绒毛方向/密度/光泽/阴影）-&gt; 场景与道具毛绒化 -&gt; 光照与氛围 -&gt; 用途适配（海报构图/TVC叙事）-&gt; 成片交付**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果去掉毛绒材质，这张图/这段视频就失去了超过50%的视觉吸引力和记忆点，则毛绒化成立；如果去掉毛绒材质画面依然成立、说明毛绒只是装饰而非核心，需重新设计让毛绒成为不可替代的视觉语言。**

## 输入诊断

生产前，识别或合理假设以下维度：

- 创作类型：产品毛绒化 / 角色毛绒化 / 场景毛绒化 / TVC毛绒广告
- 目标对象：具体是什么产品/角色/场景（名称、外观特征、关键辨识点）
- 产品品类与核心卖点：如果是产品，卖点是什么（柔软、保暖、可爱、陪伴、解压……）
- 目标用途：电商主图 / 详情页配图 / 社媒种草图 / TVC广告片 / 品牌联名素材
- 目标市场与语种：中国大陆/中文（默认）
- 目标平台与画幅：电商海报默认 1:1 或 3:4；TVC 默认 16:9 或 9:16
- 毛绒风格基调：Q版卡通毛绒（默认）——大头小身、圆润饱满、表情夸张
- 配色策略：原色还原毛绒化 / 重新配色 / 品牌色融入
- 光照方向：柔光均匀（电商主图）/ 侧逆光氛围（TVC/种草图）
- 参考素材：用户是否提供了商品图/角色图/风格参考图
- 合规敏感点：儿童用品需避免危险暗示；食品毛绒化需注明非实物；不夸大产品功效

若用户给的上下文很少，做合理假设并继续。仅当目标对象或用途确实无法推断时才发问。

## 工作流（步骤）

### 步骤 1：解析输入

从用户文字中提取：创作类型（产品/角色/场景/TVC）、目标对象、用途、画幅偏好、参考素材。若信息不足，按输入诊断维度做合理假设并继续，只在关键信息缺失时追问。

### 步骤 2：诊断与路由

按输入诊断清单逐项确认或假设。根据路由表确定路线，读取对应 references。

### 步骤 3：构建毛绒化策略

基于诊断结果，确定：

- **毛绒类型**：短绒（丝绒感）/ 中绒（经典毛绒玩具感）/ 长绒（蓬松拖把感）/ 圈绒（羊羔绒卷曲感）
- **配色方案**：忠于原物配色 / 品牌色融入 / 暖色调增强治愈感
- **Q版比例**：头身比1:1到1:1.5，四肢缩短圆润化，五官放大简化
- **质感细节**：绒毛方向（顺毛/炸毛）、密度、表面光泽（哑光/微珠光）、接缝线（毛绒玩具的拼合缝）
- **场景道具**：配套的毛绒化道具和背景元素

### 步骤 4：编写prompt

按输出契约编写prompt。图片走图片输出契约，视频走视频beat结构。prompt中使用正向措辞，用稳定标签绑定复现实体（如 Subject1、Product1、Scene1）。

若用户提供了参考图，在prompt中用 `@图片N` 引用并说明用途（如"@图片1所示的产品"）。

### 步骤 5：生成

- 图片：按prompt生成，产物存入 `assets/plush_material/` 目录，语义化命名（如 `product_plush_bear.png`）。
- 视频：时长 ≤15s 的成片用一次视频生成即可拿到完整片段，beat 结构写在同一条prompt内的时间轴上，不需要分段生成再拼接。只有成片超过 15s 时才拆成多个 ≤15s 片段分别生成再做后处理拼接。

### 步骤 6：静默自检

交付前执行静默自检清单，重写弱项。

### 步骤 7：交付

将产物展示给用户。如有多张图片或多个片段，整理后一并展示。

## 输出契约

### 图片输出契约

```
毛绒化策略：<1-2句概括毛绒类型、配色、Q版比例、质感方向>

image_generation_prompt:
主体：<@图片N引用或文字描述的目标对象，毛绒化后的外观>
材质：<绒毛类型 + 密度 + 光泽 + 接缝线描述>
配色：<主色 + 辅色 + 点缀色>
光照：<光线方向 + 柔硬度 + 阴影特征>
构图：<画幅 + 主体位置 + 留白方向 + 背景处理>
情绪：<画面传达的 feeling word>
标签：Subject1=<主体>, Product1=<产品如有>, Scene1=<场景如有>
```

### 视频输出契约（TVC毛绒广告）

```
毛绒化策略：<1-2句概括>

video_generation_prompt:
0-3s: <相机> <画面> <毛绒主体登场方式> <声音线索> <旁白/字幕如有>
3-7s: <相机> <画面> <毛绒质感特写/互动> <声音线索>
7-12s: <相机> <画面> <产品曝光或卖点展示> <声音线索>
12-15s: <相机> <画面> <品牌记忆点：产品可见+logo可读+品牌语> <声音收束>
```

每个beat以`相机`起手，依次`画面 / 毛绒主体 / 声音`。用稳定标签绑定复现实体。正向措辞，不写否定式约束。

时长 ≤15s 的视频用一次生成即可拿到完整成片，上面的 0-3s/3-7s/7-12s/12-15s 是同一条prompt内的时间轴描述，不是分段多次生成。只有成片超过 15s 时才拆成若干 ≤15s 片段分别生成再做后处理拼接。

## 静默自检

交付前内部执行；定稿前重写弱项。除非用户要求点评，否则不输出给用户。

- 毛绒材质是否构成画面核心吸引力（质量测试是否通过）？
- 绒毛类型、密度、光泽是否具体到可生成？
- Q版比例是否到位（头大身小、圆润饱满）？
- 配色是否与品牌/产品调性一致？
- 光照是否服务于用途（电商主图柔光均匀/TVC氛围光）？
- 参考图是否在prompt中正确引用？
- 图片画幅是否匹配用途（电商1:1或3:4，社媒可9:16）？
- 视频beat结构是否完整且≤15s一次生成？
- 结尾是否形成品牌记忆点（TVC场景）？
- 儿童用品/食品毛绒化是否注明非实物？
- 全文语言是否为中文、无混杂？
