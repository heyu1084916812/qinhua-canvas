# 粘土定格动画生成 (Claymation Production)

## 用途

本 Skill 旨在通过模块化工作流，将文字脚本转化为具有高度视觉一致性的粘土定格动画视频。它利用“多重锚点锁定”技术，确保长篇故事中角色形象不跑偏、材质质感统一。

## 适用输入

- **故事脚本**：包含情节起伏、角色动作、场景切换及对白。
- **形象参考**：已有角色形象图或特定的粘土材质风格描述。

## 操作步骤

1. **脚本模块化拆解**：将剧本划分为 8-12 个独立镜头（Shot），每个镜头对应一个叙事微单元。
2. **建立一致性锚点**：
   - **角色锚点**：生成并锁定角色的比例、色彩和面部特征参考图。
   - **风格锚点**：定义粘土的哑光质感、手作瑕疵感和暖色调光效。
   - **环境锚点**：固定关键场景（如河流、森林）的地理特征。
3. **分镜图绘制**：为每个镜头生成一张静态分镜底图，明确构图与角色位置。
4. **视频生成执行**：采用“分镜图+角色参考+风格参考”的多图控制模式生成视频片段。
5. **一致性审计**：对比相邻镜头的角色保真度、光影方向和动作节奏，对跳戏镜头进行重绘。

## 输出要求

- **视觉风格**：明显的粘土手工质感，表面无过度反光，呈现 Q 版可爱或特定艺术风格。
- **叙事逻辑**：视频需准确还原脚本中的情绪转折（如从迷茫到坚定）。
- **镜头语言**：包含全景（交代环境）、中景（展示动作）与特写（捕捉表情）的有机组合。

## 注意事项

- **动作控制**：避免过于流畅的数字模拟感，保留定格动画特有的物理顿挫感。
- **时长分配**：建议单个镜头时长控制在 4-10 秒，总成片由多个片段拼接而成。
- **属性对齐**：若角色有配饰（如帽子、包包），必须在所有相关镜头的提示词中显式声明。
