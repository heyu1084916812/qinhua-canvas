### 1. 人物关系：**情绪供需的极致反差**

- **人类（主人）：** 设定为\*\*“易燃易爆的吐槽役”\*\*。永远处于极度烦躁或正经办事的状态，对一切暧昧、抒情或无关紧要的话天然排斥，输出全靠“吼”和“骂”（你个变态/坏猫/臭猫）。
- **动物（猫）：** 设定为\*\*“铜墙铁壁的进攻方”\*\*。对人类的愤怒完全免疫，且具有极强的“曲解”能力。它们把人类的愤怒当作互动信号，甚至把辱骂当成另一种形式的“回应”。

### 2. 核心喜剧套路：**逻辑错位（语义偷换）**

这是所有段子的灵魂，分两种玩法：

- **套路一：同词异义（听话听音）**

  - *例：* 老板说“**腿白长**了”（废物的意思），女子直接偷换为“**腿白**（颜色）*长*”。
  - *例：* 主人说“**洗**东西”，猫偷换为“洗（接受）喜欢我”。
  - **技巧：** 抓住对方话语中的**形容词/动词**，剥离其当下语境，强行赋予其字面或暧昧含义。

- **套路二：强凑谐音（谐音梗扣分但好笑）**

  - *例：* 头发油 — **爱拉夫油**（I love you）。
  - *例：* 打火机点 **心**。
  - *例：* 尺子 — **爱老虎油**（I love you very much）。
  - **技巧：** 制造一个看似正经的提问（问头发、问打火机），诱导对方给出基础回答，再抛出精心准备的谐音陷阱。

- **套路三：情绪反向收割**

  - 人类骂“快滚、消失、坏猫”，在动物视角里，这等于“你成功地让我情绪波动了”。
  - 猫说“你不理我我就发疯”，是把人类的冷漠**具象化**为物理伤害（刮风），逼着人类必须开口回应——**只要回嘴，就算输**。

### 3. 语言节奏：**三明治结构**

每一组对话都是固定的“三板斧”，非常利于短视频或段子创作：

1. **引诱（抛饵）：** 动物/下属先提出一个**生活化/无厘头**的问题（关于天气、血型、走路）。
2. **打击（正解）：** 人类给出一个**暴躁/正经**的回复（没有、怎么了、A型）。
3. **反转（升番）：** 动物/下属利用对方的回复，**强行升华**成土味情话。人类气急败坏骂一句“臭/坏/变态”收尾。

## 动作配合

娇嗔地、气鼓鼓地、甩尾巴、跺脚、扭头、嘟嘴、瞪眼、轻推、假装生气

## 使用要点

1. **语气要到位**：嘴上说"臭""坏"，但语气是撒娇不是真生气
2. **动作要配合**：甩尾、跺脚、嘟嘴等小动作增加可爱感
3. **节奏要快**：对方说完立刻回怼，不要冷场
4. **反差要明显**：越是凶巴巴的语气，越显得可爱
5. **关系要亲密**：只适合关系亲近的角色之间使用

# 影视化叙事的多模态参考任务

**第一段：总体设定 + 主体定义**
- 用一句话定调整体场景与氛围（如"傍晚悬崖竹林，烟雨江湖电影感""现代办公室文戏，自然柔和光照"）。
- 一次性绑定全部主体与核心资产：`<主体N>@图片N` 或 `将 @图片N 中的[2-3 个稳定静态特征] 定义为 <主体N>`。
- 多素材同主体：`将 @图片1 中的[…]、@图片2 中的[…] 定义为 <主体N>`。
- 人脸参考策略（如适用）：`<主体1> 的面部特征参考 @图片1（大头照），妆造参考 @图片2（全身照）`。
- 首尾帧约束（如适用）：`@图片N 作为首帧约束 / 尾帧约束`。
- 运镜参考来源（如有 @视频N 作运镜锚定）一并在此声明，例：`运镜参考 @视频1 的中景推拉与轻微摇移`。

**第二段：镜头分镜（仅使用多模态参考形态）**
- 顺序使用 `镜头1 / 镜头2 / 镜头3 …`，**禁止写绝对秒数**（如 `0–3s`）。Seedance 2.0 对精确时间支持不稳定。
- 每个镜头按 **运镜方式 → 主体动作与表情 → 位置 / 空间变化 → 音频信息** 四要素组织。
- **运镜限制**：单镜头只指定 1 种运镜方式（推 / 拉 / 摇 / 移 / 固定 / 跟拍择一），禁止叠加。
- **动作描述要求**：
  - 肢体细化 + 程度量化（手 / 腿 / 头 / 肩背 + 幅度 / 速度 / 力度）。
  - **优先低缓连续小动作**，规避狂奔 / 大跳 / 剧烈翻滚等高爆发动态。
  - 补充动作过渡衔接（前后惯性承接，如"借着转身惯性顺势抬手"）。
  - 情绪具象外化：用具体身体细节代替"悲伤 / 愤怒"等抽象词，例如悲伤 → "肩膀微微颤抖、眼眶泛红、手指攥紧衣角"。
- 描述动作和站位时使用强视觉指代 `<主体N>` 或 `<主体N>@图片N`：
  - 正确：`<主体1>（李武）站起身走向 <主体2>（苏有）`，`@图片2 中的女生位于画面左侧`。
  - 错误：`@图片2位于…`（数字粘连歧义），`@图片1跑向…`（裸接动词）。

**第三段：风格 + 约束包**（按场景自动挂载以下标准包）
- 整体美术调性 / 视觉风格（如"烟雨江湖电影感，冷调低饱和，电影胶片质感"）。
