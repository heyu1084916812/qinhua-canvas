# 剧情短剧分镜提示词写作规范

本 Skill 用于为剧情短剧（以盛唐背景为典型语境）撰写视频生成提示词。每次调用时，按照以下 11 个字段依次填写，输出一份可直接粘贴进视频生成节点的完整提示词。

---

## 使用前准备

在开始写提示词之前，先确认以下信息已就绪：

- **分镜场次名称**（如"入局""出门踩点""拔刀"）
- **本场涉及的所有角色节点 key**（人物定妆图，含面部/服装/气质锁定）
- **场景/空间节点 key**（室内/室外环境参考图）
- **道具节点 key**（如屠刀、花车等关键道具）
- **音频节点 key**（配音演员声线，如有）
- **上一场尾帧节点 key**（用于连续性锚点，如有）
- **本场台词文本**（一字不差，含说话人标注；若本场确实无对白，请明确注明"本场无对白"）
- **剧情衔接说明**（上一场结尾状态 → 本场开场状态）
- **本场核心戏剧目标**（心理/权力/信息博弈层面，不是表面动作）

> **⚠️ 开始前必须检查以下两项，任一不满足则暂停：**\*\***① 节点 key 检查：** 如果用户未提供任何节点 key（角色/场景/道具均无），**立即暂停**，列出本场需要的节点类型清单（如：主角定妆图节点、场景环境节点、关键道具节点），请用户补充后再继续。不得用文字描述替代节点引用，不得填写占位符。 \*\***② 台词检查：** 如果用户未提供台词，且未注明"本场无对白"，**立即暂停并询问**："本场是否有对白？如有，请提供台词原文（含说话人）；如确实无对白，请注明，届时各分镜台词栏填写'无对白'。"不得自行编造台词内容。

## 提示词模板

### 1. 标题

```
【场次名称】
```

用分镜/场次简称，直接点明本段戏份。例：`【入局】`、`【出门踩点】`、`【拔刀】`。

---

### 2. SCENE CONTEXT

```
SCENE CONTEXT
时代背景：[朝代/年号语境，如"盛唐开元天宝年间，长安城内"]
时间：[白日/黄昏/夜间，精确到时段]
地点：[具体场所，如"刘三算命铺内→铺门口街道"]
剧情衔接：[上一场结尾状态]→[本场开场状态]，[承接关系说明]
本场核心戏剧目标：[不是表面动作，而是背后的心理/权力/信息博弈]
```

**写法要求：**

- 时代背景不要泛泛写"古代"，要锁定具体朝代语境（影响服饰、建筑、语言风格）
- 剧情衔接必须写清楚"从哪里来、到哪里去"，让模型理解场景切换的因果
- 核心戏剧目标要写人物的内在动机和博弈关系，不要写"主角走出门"这类表面动作

**示例：**

```
SCENE CONTEXT
时代背景：盛唐开元天宝年间，长安城东市坊间，繁华但暗流涌动
时间：午后白日，阳光斜射
地点：刘三算命铺内 → 铺门口 → 王家肉铺对面街道
剧情衔接：刘三刚接到线报，得知王大头近日在街上耀武扬威→本场刘三以"出门踩点"为名，实为首次近距离观察王家肉铺布局与人员配置
本场核心戏剧目标：刘三完成对王家肉铺的空间认知建立，同时保持身份掩护不被察觉，为后续入局埋下信息优势
```

### 3. ACTIVE REFERENCES

```
ACTIVE REFERENCES
@{{角色A节点key}} — 锁定：[脸型/发式/体型/服装/气质，列出不可修改项]
@{{角色B节点key}} — 锁定：[同上]
@{{场景节点key}} — 锁定：[空间布局/光线/建筑细节]
@{{道具节点key}} — 锁定：[道具精确形制]
@{{音频节点key}} — 锁定：[声线特征]
@{{尾帧节点key}} — 锁定：[上一镜结尾构图，用于本场开场连续性]
```

**写法要求：**

- 每个引用节点必须注明锁定的具体内容，不能只写 `@{{key}}`
- 人物锁定项至少包含：脸型特征、发式、服装颜色/款式、体型、气质关键词
- 场景锁定项至少包含：空间布局（门窗位置）、主要光源方向
- 道具锁定项要写到"精确形制"，避免模型自由发挥
- **节点 key 必须是画布上真实存在的节点。若用户未提供节点 key，按「使用前准备」的检查规则暂停，不得用文字描述或占位符替代。**

**示例：**

```
ACTIVE REFERENCES
@{{i-DH6U2vm93I}} — 锁定：刘三，中年男，面容清瘦，头戴方巾，青灰色布衫，身形偏瘦，眼神沉稳带算计感，不可改变发式与服装颜色
@{{i-PyPe3pi4RD}} — 锁定：王大头，壮年男，体型魁梧，络腮胡，深色圆领袍，气质霸道，不可改变体型与胡须形态
@{{i-KVfyRUGZmD}} — 锁定：王家肉铺，门面朝南，木质招牌，铺前有案板，左侧挂猪肉，光线从右侧街道射入
@{{i-7w50u7Wfsw}} — 锁定：屠刀，宽背厚刃，刀柄缠黑布，刀身无花纹，长约50cm，不可替换为其他刀型
@{{a-egAZneqYNi}} — 锁定：刘三配音声线，中年男声，略带沙哑，语速平稳，不急不缓
@{{i-H947hs4DsS}} — 锁定：上一场尾帧，刘三站在铺门口，背对镜头，视线朝向街道右侧，本场开场需从此构图接续
```

### 4. CONTINUITY RULE

```
CONTINUITY RULE
道具因果链：[道具出现/消失的逻辑]
人物出入场顺序：[谁先出现、谁后出现、谁始终在场]
屏幕方向稳定性：[人物相对位置，防止越轴]
身份关系稳定性：[层级/关系，如"王大头（东家）> 掌柜 > 帮工 > 小二"]
空间连续性：[镜头切换时空间逻辑]
```

**写法要求：**

- 道具因果链：每件关键道具都要写清楚"它在哪里、什么时候出现、什么时候可以消失"
- 人物出入场：按时间顺序写，避免模型在某个镜头里凭空多出或少了人物
- 屏幕方向：锁定主要人物的左右位置，防止越轴
- 身份关系：明确层级，防止模型把掌柜演成东家

**示例：**

```
CONTINUITY RULE
道具因果链：屠刀在王大头腰间，全程可见刀柄，未经明确拔刀动作不得出现刀身；刘三手中无道具，不得凭空出现折扇或其他物件
人物出入场顺序：刘三全程在场（视角人物）；王大头在第二镜出现，第四镜离开；掌柜和帮工在王大头在场时保持低头忙碌状态
屏幕方向稳定性：刘三在画面左侧或左前方，王家肉铺在画面右侧，不得越轴
身份关系稳定性：王大头（东家）气场压制所有人，掌柜见到王大头需有明显低头/侧身礼让动作
空间连续性：从算命铺内切到街道，铺门始终在画面左后方，街道纵深向右延伸
```

### 5. FORMAT

```
FORMAT
总时长：[秒数，通常18–24秒]
剪辑模式：Timed multishot（多镜头定时剪辑）
语言：中文对白，半文言但通俗，不用现代网络用语
NO项：
- 无旁白
- 无字幕
- 无英语
- 无配乐煽情（不得在对白段落加背景音乐）
- 无背景群众杂声（除非明确写入AUDIO字段）
- 无特效（无光效爆闪、无慢动作滤镜）
```

**写法要求：**

- 总时长要与 CAMERA/EDITING 里各分镜时间码加总一致
- NO 项要具体，写清楚"不要做什么"

---

### 6. CAMERA/EDITING

```
CAMERA/EDITING
[整段镜头调度逻辑概述：情绪或权力转折的起承转合，2–3句话]

时间码分镜：
0.0s–Xs｜镜头1｜[场景/位置]
  FOV：[焦距/视角]
  景别：[特写/近景/中景/全景/大全景]
  动作：[可拍到的身体/手/物件/视线，具体到部位]
  台词：[见下方台词填写规则]
  表演要点：[心理状态描述，不用抽象形容词]
  剪辑标记：[HARD CUT / MATCH CUT / 无]
```

**台词填写规则（三种情况，必须区分）：**

情况处理方式用户提供了台词原文一字不差填入，含说话人标注，如 `刘三：「今日天气不错。」`用户明确注明"本场无对白"所有分镜台词栏填写 `无对白`用户未提供台词，且未注明无对白**立即暂停，询问用户**："本场是否有对白？如有请提供台词原文；如确实无对白请注明。" 不得自行编造任何台词。

**写法要求：**

- 先写整段调度逻辑概述，让模型理解这段戏的情绪走向
- 每个分镜必须包含：FOV、景别、动作、台词、表演要点
- 表演要点用可观察的行为描述，不用"紧张""激动"等抽象词
- 时间码要连续，各镜头加总等于 FORMAT 里的总时长
- HARD CUT 用于场景/情绪突变；MATCH CUT 用于动作/视线的连续性剪辑

**示例（节选）：**

```
CAMERA/EDITING
整段调度逻辑：从刘三主观视角的"观察"切入，逐步推近王家肉铺，在王大头出现的瞬间完成权力关系的视觉建立；全段保持刘三的冷静旁观基调，不用快切制造紧张感，用景别推进代替情绪煽动。

0.0s–3.5s｜镜头1｜算命铺门口，刘三背对镜头
  FOV：35mm广角，平视
  景别：中景
  动作：刘三站在铺门口，右手搭在门框上，视线朝向街道右侧，身体未动
  台词：无对白
  表演要点：刘三的视线是"扫视"而非"盯视"，像在看街景，不让旁人察觉他在观察特定目标
  剪辑标记：无

3.5s–7.0s｜镜头2｜街道，刘三主观视角→王家肉铺正面
  FOV：85mm中长焦，平视，轻微手持晃动模拟主观视角
  景别：全景→中景（缓慢推进）
  动作：镜头从街道人流中穿过，落在王家肉铺招牌上，停留，再缓慢下移到铺前案板
  台词：无对白
  表演要点：镜头运动要"克制"，推进速度慢，像一个有经验的人在不动声色地记录空间
  剪辑标记：MATCH CUT（接刘三视线方向）
```

### 7. PERFORMANCE LOCK

```
PERFORMANCE LOCK
[角色A]：
  不要演成：[过火/类型化的错误方向]
  而要演成：[正确的表演基调]
  关键动作边界：[具体动作的上限]

[角色B]：
  不要演成：...
  而要演成：...
  关键动作边界：...
```

**写法要求：**

- 每个有台词或重要动作的角色都要写
- "不要演成"要具体指出类型化陷阱
- "而要演成"要给出可操作的替代方向
- "关键动作边界"要写清楚动作的上限，防止过火

**示例：**

```
PERFORMANCE LOCK
刘三：
  不要演成：侦探片里的神探，眼神锐利、动作夸张、明显在"调查"
  而要演成：一个出门散步的算命先生，漫不经心，偶尔停步，像在想事情
  关键动作边界：视线停留在王家肉铺不超过2秒，随即自然移开；不得有摸下巴、皱眉等"思考"的程式化动作

王大头：
  不要演成：脸谱化的反派，一出场就凶神恶煞
  而要演成：一个习惯了被人怕的地头蛇，威压是自然流露的，不需要刻意表演
  关键动作边界：说话时音量正常但语气笃定；不得有拍桌子、指人鼻子等夸张动作
```

### 8. AUDIO

```
AUDIO
环境声：[真实存在的环境声]
道具声：[关键道具的声音]
呼吸/气息：[关键情绪节点的呼吸处理]
台词音量处理：[关键台词的音量/混响]
明确排除：
  - [不要出现的声音]
  - [不要出现的声音]
```

**写法要求：**

- 只列真实存在于场景中的声音，不要写"配乐烘托气氛"
- 道具声要具体到"什么道具、什么动作、产生什么声音"
- 明确排除项要具体

---

### 9. LIGHTING

```
LIGHTING
色温：[如"4800K，偏暖白"]
主色调：[如"暗部青绿墨蓝，亮部暖肤色，整体低饱和"]
光源方向：[主光来源与方向]
特殊光效：[如"轻微bloom/halation，高光边缘有轻微晕散，非HDR过曝"]
稳定性要求：基础光效不因剧情紧张程度改变，不得在对峙场景突然压暗或加红光
```

**写法要求：**

- 色温和色调在整个系列里保持一致（固定为4800K + 青绿墨蓝暗部 + 暖肤色）
- 明确写出"不因剧情紧张而改变基础光效"
- bloom/halation 是这套风格的标志性光效，每场都要写

---

### 10. ENDING FRAME

```
ENDING FRAME
构图：[具体描述结尾停留的画面]
人物位置：[各人物在画面中的位置]
道具状态：[关键道具的最终状态]
情绪基调：[这个结尾画面传递的情绪]
下一场衔接提示：[这个尾帧如何作为下一场的连续性起点]
```

**写法要求：**

- 结尾帧要具体到"谁在哪里、做什么、看哪里"
- 道具状态要写清楚，确保下一场引用时有据可查
- 下一场衔接提示是给下一条提示词的写作者看的，不是给模型的指令

---

### 11. NO/LOCKS（汇总禁止项）

```
NO/LOCKS
视觉禁止：
  - 不要英语字幕或英语文字出现在画面中
  - 不要现代元素（手表、眼镜、现代建筑）
  - 不要凭空生成未在 ACTIVE REFERENCES 中引用的道具
  - 不要夸张表情（哭泣、大笑、瞪眼）
  - 不要特效（光效爆闪、粒子、慢动作滤镜）
  - 不要改变角色服装颜色或发式

表演禁止：
  - 不要类型化的"坏人表演"（狞笑、阴险眼神）
  - 不要类型化的"好人表演"（无辜眼神、委屈表情）
  - 不要过度肢体语言（指手画脚、夸张手势）

音频禁止：
  - 不要背景音乐
  - 不要旁白
  - 不要现代音效（电子音、合成器）

叙事禁止：
  - 不要在单条提示词里跨越超过3个场景
  - 不要让未出场角色的声音出现在画面外
```

```

```

## 使用说明

1. **每次只写一个场次**，不要把多个场次合并进一条提示词
2. **台词必须一字不差**；若本场无对白，请在输入时明确注明"本场无对白"；若未注明，将暂停询问，不自行编造
3. **ACTIVE REFERENCES 里的节点 key 必须是真实存在的节点**；若未提供任何节点 key，将暂停并列出所需节点类型清单，不用文字描述替代
4. **CONTINUITY RULE 要在每场之间保持一致**，特别是屏幕方向和道具状态
5. **LIGHTING 色调在整个系列里固定**，不要因为场景不同而改变基础色调
6. **ENDING FRAME 是下一场的起点**，写完一场后立即记录尾帧状态，供下一场引用
