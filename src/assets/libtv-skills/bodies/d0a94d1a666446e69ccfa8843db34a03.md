# 短剧全流程系统

## 硬约束

1. **一次一个命令，文件间必停等**。创作期（/创作方案 等）每个文件落盘后停、等用户确认再推进。`/分集 {N}` 按混合确认模式推进——Phase 0→1 连续、剧本落盘后停；Phase 1.5→2 S1A 连续、首段分镜落盘后停；S1B\~S1H 每段必停。
2. **产物必须落盘文件**。所有生成内容写入文件，不只在对话中输出。
3. **每次落盘后跑校验**。被阻断则修复后重跑——校验脚本是规则的唯一可执行权威。
4. **零铺垫·冲突先行**（v2.0）：全集全段禁止场景空镜/角色定位/因果前置三类铺垫。从冲突中间切入，15s 只做一件事。
5. **信息融入冲突**：所有背景信息在冲突进程中自然释放，无独立交代段。
6. **视觉丰富**：每段 15s 必须满足运镜 ≥ 2 种 / 景别 ≥ 3 档 / 角度 ≥ 2 种 / 构图 ≥ 2 种。具体策略取值以 `pipeline.md` §0.3 分镜决策锁定表为准——不可从训练数据采样构图/运镜/角度替代锁定表取值。

## 执行规范速查

- **沙盒门控**：创作期每个文件执行 5 步循环（读→写→checkpoint→摘要→等用户），详见 `references/gates/沙盒门控规范.md`。
- **零弹窗**：禁止 `rm -rf` / `Remove-Item -Recurse -Force` 等黑名单命令；文件操作统一用 `scripts/_file_ops.py`。禁止创建 `tmp_` / `.tmp` 前缀临时文件；决策点用 `--decision-points-stdin` 管道传参。
- **资产边界**：角色/物品/场景档案保持数据纯净——角色档案不含场景和独立调度物，物品档案不含角色和场景，场景档案不含角色和独立调度物。一图一资产。
- **不调用外部 Skill**：生成剧本、资产、分镜只用本 Skill 的脚本和 references。
