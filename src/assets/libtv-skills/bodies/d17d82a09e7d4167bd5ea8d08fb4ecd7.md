# 短剧剧本·导演级全流程编排

## 这个 Skill 做什么

输入短剧剧本文本，按专业导演工作流依次产出：

1. **切点清单**：语义完整的表演单元拆分，连续时码，复检
2. **逐镜头分析**：10 维度全量分析（含光影描述），台词逐字保留
3. **分场剧本**：标准格式，与逐镜头分析完全对应
4. **全量资产清单**：视觉风格锁定句 + 人物/场景/道具表，含可直接用于生图的 prompt
5. **画布结构占位**：锚点图片节点、分镜视频节点（含情绪指令+完整台词/动作+光影描述，**不含字幕**）、配音 TTS 节点、音效 SFX 节点、智能剪辑节点、合成节点，全量连接；所有节点在画布上按类分区、按顺序排版，prompt、引用关系、node_key 全部建好并连接
6. **文件记录**：锚点清单文件、分镜表文件（含画布排版信息）、任务进度游标

**全程为结构占位模式**，不主动触发真实生成，不消耗积分，用户确认后再执行真实生成。

---

## 输入格式说明

剧本文本应包含以下结构（缺失字段会在对应步骤标注"待补充"，不编造）：

```
[集号标题]
[场号] [时间] [内/外] [地点]
人物-[角色名]
服装-[角色名]（[服装描述]）
道具-[道具名]（[描述]）、...
▲ [动作描述]
[角色名]（[情绪/语气]）：[台词]
```

## 执行流程

### 第零步：批次初始化

读取已有资产文件（如存在）：

```
anchors/[作品名].md        ← 人物/场景/道具锚点清单，含 node_key、状态、父锚点关系
story_boards/task_[ID].md  ← 分镜表，含 node_key、情绪指令
audio/task_[ID].md         ← 配音TTS节点清单 + 音效SFX节点清单，含 node_key
```

**处理逻辑：**

情况处理方式文件存在列出可复用/可派生资产清单，供用户确认哪些沿用、哪些派生、哪些新建，再继续文件不存在，用户未提及复用意图直接进入第一步文件不存在，但用户明确提及"复用上一集/上一批次资产"等意图**不得静默跳过**，主动告知："未找到对应资产文件，无法自动复用。请提供上一批次的 node_key 清单，或确认重新规划资产。"等用户回复后再继续

---

### 第一步：切点清单

**拆分原则**：按语义完整的表演单元拆分，不按标点机械切割。一个"表演单元"指：同一机位/景别下，人物完成一个连贯的动作或情绪表达，中间无明显跳变。

**时码规则**：

- 从 `00:00.0` 开始，连续覆盖至片尾，无缺口无重叠
- 时码精度到 0.1 秒
- 每个镜头时码格式：`MM:SS.s–MM:SS.s`

> ⚠️ **时码精度说明**
>
> 输入类型时码来源精度说明视频素材逐帧扫描精确帧时码，可直接用于剪辑剧本/小说文本导演视角估算为规划估算值，非精确帧时码，实际制作时需根据拍摄结果调整

**输出格式：**

```
【切点清单】共 N 个镜头，全片 MM:SS.ss
MM:SS.s–MM:SS.s
MM:SS.s–MM:SS.s
...（逐行列出全部镜头时码）

复检：
- 时间码 00:00.0 连续覆盖至 [片尾时码]，无缺口无重叠
- 单镜头最长 Xs（镜头N），[是否超8秒]
- 全片平均镜头时长约 Xs，[是否超8秒，超则重新扫描]
```

**强制复检**（适用于视频输入，文本输入下仅供参考）：

- 单镜头时长超过 8 秒必须二次复核
- 全片平均镜头时长超 8 秒视为异常，重新扫描

---

### 第二步：逐镜头分析

严格按切点清单逐镜头拆解，数量与时间码完全对应，不得合并跳过。

**每镜头输出格式：**

```
【MM:SS.s–MM:SS.s】
画面：[构图、景别、色调、背景]
人物：[在场角色、位置关系]
动作：[肢体动作，细节描述]
台词：[逐字保留原文，无台词写"无"]
画面文字：[字幕/标题/道具文字，无则写"无"]
声音：[环境音、音效描述]
镜头：[景别+角度+运动方式]
光影：[光源方向、光质（硬光/柔光/散射光等）、阴影形态、光影情绪氛围描述]
转场：[转场类型]
情绪：[当前镜头情绪标注]
备注：[特殊说明，无则写"无"]
```

> ⚠️ **光影字段说明**：每个镜头必须填写光影描述，包含光源方向（如顶光、侧光、逆光、底光等）、光质（硬光/柔光/散射光/自然光等）、阴影形态（如长阴影、轮廓光、投影方向）以及整体光影情绪氛围（如压抑、温暖、神秘、冷峻等）。不得留空或写"无"。

**台词处理规则**：

- 台词逐字保留原文，不改写、不缩写、不意译
- 系统提示音/UI文字单独列入"画面文字"字段
- OS（内心独白）标注为"台词（OS）"
- VO（画外音）标注为"台词（VO）"

### 第三步：分场剧本

按场号重新组织为标准分场格式，信息与逐镜头分析完全对应，不丢失任何台词或动作。

**格式规范：**

```
场景 [场号]  [地点]·[时间]·[内/外景]
出场人物：[人物编号] [角色名]、...

▲ [动作描述]

[角色名]（[情绪/语气]）：[台词原文]

▲ [动作描述]

[角色名]（VO）：[旁白原文]

涉及人物：[编号列表]
涉及场景：[编号列表]
涉及道具：[编号列表]
```

---

### 第四步：全量资产清单

4.1 视觉风格锁定句

从剧本中提炼一句话，全流程所有 prompt 首句复用：

> 格式：`[时代/世界观]，[画面基调]，[色彩风格]，[镜头质感]，电影级构图`

4.2 人物表（编号 A-01、A-02…）

字段说明角色名—年龄气质—外貌特征五官、肤色发型发色—全套服装含配饰，多套服装分别列出体型—核心情绪基调全片主导情绪，用于分镜情绪指令参照生图 prompt可直接用于图片生成的完整 prompt（首句为视觉风格锁定句）

**人物三视图 prompt 结构：**

```
【视觉风格锁定句】。角色：[角色名]，[年龄气质]，[外貌特征]，[发型发色]，[服装配饰]，[体型]。横版白底角色设定图，左侧1/3区域为大幅正面半身肖像，右侧2/3区域为全身正面、侧面、背面三视图并排站立；四个视图中服装、发型、配饰完全一致，均匀柔光，无多余背景元素。
```

4.3 场景表（编号 S-01、S-02…）

字段说明场景名—空间类型室内/室外/虚构空间布局朝向—环境细节—光源时间—色调—关键陈设—生图 prompt可直接用于图片生成的完整 prompt

**场景参考板 prompt 结构：**

```
【视觉风格锁定句】。场景：[场景名]，[空间类型]，[布局朝向]，[环境细节]，[光源时间]，[色调]，[关键陈设]。横版多格场景参考板，主体为6-9格同一场景的不同视角，右侧附空间轴测图与视角编号，底部附材质参考、主色/点缀色色卡、氛围关键词；所有格子为同一空间、同一光线条件、同一色调。
```

4.4 道具表（编号 P-01、P-02…）

字段说明道具名—外观形状—颜色材质—尺寸—特征细节—生图 prompt可直接用于图片生成的完整 prompt

**道具三视图 prompt 结构：**

```
【视觉风格锁定句】。道具：[道具名]，[外观形状]，[颜色材质]，[尺寸]，[特征细节]。白底道具设定图，正面/侧面/背面多角度展示，附1张关键细节特写；材质、颜色、尺寸清晰呈现。
```

### 第五步：锚点新建原则

**优先级顺序（从高到低）：**

1. **直接复用**：已有锚点与当前需求完全一致（同角色同造型、同场景同光线）→ 直接引用已有 node_key，不新建
2. **派生**：已有锚点与当前需求有实质关联但存在差异（同角色换装、同道具材质细化、同场景不同时段）→ 新建派生节点，prompt 中标注"基于 \[父锚点编号\] 派生"，记录 `parent_node_key`
3. **独立新建**：确无可复用/派生对象 → 独立新建，分配新编号

**派生锚点 prompt 结构补充：**

```
【视觉风格锁定句】。基于 [父锚点编号] {{父锚点node_key}} 派生，保持[角色名/场景名]的[一致要素]不变，本版本变化：[具体差异描述]。[完整 prompt 内容]
```

---

### 第六步：画布结构占位搭建

> **核心原则**：本步骤完成后，画布上所有节点的 prompt、引用关系、顺序、node_key 必须全部建好并连接完毕；节点按类分区、按各自顺序排版。**不主动触发任何真实生成。**

6.0 画布分区排版规则

画布按以下分区从左到右、从上到下排列，同类节点按编号/出场顺序依次排列：

分区内容排列方式**人物锚点区**（左上）所有人物图片节点（A-01、A-02…）按角色编号从左到右横向排列**场景锚点区**（中上）所有场景图片节点（S-01、S-02…）按场景编号从左到右横向排列**道具锚点区**（右上）所有道具图片节点（P-01、P-02…）按道具编号从左到右横向排列**分镜视频区**（中部）所有分镜视频节点（VID-01、VID-02…）按分镜顺序从左到右横向排列**智能剪辑区**（中部，视频区下方）所有智能剪辑节点（CLIP-01、CLIP-02…）按剪辑顺序从左到右横向排列，连接对应分镜视频节点**音频区**（下部）配音 TTS 节点（TTS-01…）+ 音效 SFX 节点（SFX-01…）TTS 节点在上行，SFX 节点在下行，均按时间顺序从左到右排列**合成节点区**（最右/最下）合成节点（COMP-01）单独放置，连接全部视频与音频节点

**排版执行要求：**

- 每个分区内节点间距均匀，不堆叠
- 跨区连线（引用关系）在画布上明确建立，不遗漏
- 派生锚点节点紧靠父锚点节点右侧排列，并用连线标注派生关系

6.1 锚点节点（图片占位）

按第五步锚点新建原则，为每个人物、场景、道具创建图片节点：

- 写入完整 prompt（首句为视觉风格锁定句）
- 设置对应 tag（character / scene / prop）
- 记录 node_key
- **在画布人物/场景/道具锚点区按编号顺序排列，建好所有引用连线**

6.2 分镜视频节点（视频占位）

为每段分镜（≤15秒/段，支持自定义10秒/20秒）创建视频节点：

- 通过 `reference_nodes` 连接对应锚点图片节点（在画布上建好连线）
- **不添加任何字幕**（视频画面中不包含字幕、文字叠加或标题文字）
- 记录 node_key
- **在画布分镜视频区按分镜顺序从左到右排列，连线至对应锚点节点**

**视频 prompt 结构（完整，不得因镜头描述删改台词/动作内容；不含字幕指令）：**

```
【视觉风格锁定句】。
场景 {{场景node_key}}：[场景描述]。
人物A {{人物node_key}}：[人物描述]。
[人物B {{人物node_key}}：[人物描述]。]
[道具 {{道具node_key}}：[道具描述]。]

视频内容片段（完整，逐镜头）：
[时码] [景别·运动] [人物动作描述]
[角色名]：[台词原文，逐字保留]
[角色名]（OS）：[内心独白原文]
...

情绪指令：
主导情绪：[情绪词]
微表情变化：[时间点]-[情绪变化描述，例如"0:03 眉头微蹙→0:05 嘴角压抑上扬，隐忍中带讽刺"]

光影描述：
光源方向：[顶光/侧光/逆光/底光/环境光等]
光质：[硬光/柔光/散射光/自然光等]
阴影形态：[长阴影/轮廓光/投影方向等]
光影氛围：[压抑/温暖/神秘/冷峻/浪漫等情绪氛围描述]

镜头描述：[镜头链条式概述，光线调性、运镜方式、剪辑节奏]

无字幕：画面中不添加任何字幕、文字叠加或标题文字。
```

6.3 智能剪辑节点（剪辑占位）

为需要智能剪辑的片段创建智能剪辑节点（CLIP-01、CLIP-02…）：

- 写入剪辑指令 prompt（含剪辑范围、节奏要求、转场方式）
- 通过 `reference_nodes` 连接对应分镜视频节点（在画布上建好连线）
- 记录 node_key
- **在画布智能剪辑区按剪辑顺序从左到右排列，连线至对应分镜视频节点**
- **不主动触发真实剪辑生成**

6.4 音频系统（独立模块）

**配音 TTS 节点**（逐句独立，每句台词一个节点）：

- 节点类型：音频占位
- 格式：`[角色名]（[情绪/语气]）：[台词全文，逐字保留]`
- 记录 node_key，**在画布音频区 TTS 行按时间顺序排列，连线至对应分镜视频节点**
- 等待用户确认后再提交生成

**音效 SFX 节点**（按场景/动作节点划分，不擅自新增 BGM）：

- 节点类型：音频占位
- 内容：音效描述 + 时间范围
- 格式：`[时间范围] [音效描述] [情绪氛围关键词]`
- 记录 node_key，**在画布音频区 SFX 行按时间顺序排列，连线至对应分镜视频节点**
- 等待用户确认后再提交生成

> ⚠️ **音频规则**：只建配音 TTS 和音效 SFX 节点，不擅自新增 BGM 节点。如需 BGM，等用户明确指定后再建。

**音频确认步骤**：

1. 展示全部配音 TTS 节点清单，等待用户确认
2. 展示全部音效 SFX 节点清单，等待用户确认
3. 用户逐项或批量确认后，才提交对应节点生成

6.5 合成节点

用视频合成工具建一个合成节点：

- 按分镜顺序拼接全部分镜视频节点
- 按估算时间点挂载全部音频节点（配音 TTS + 音效 SFX）
- 记录 node_key
- **在画布合成节点区单独放置，连线至全部分镜视频节点和音频节点**
