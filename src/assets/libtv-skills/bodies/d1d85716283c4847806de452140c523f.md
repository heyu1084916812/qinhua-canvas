\## 做什么\
读取用户上传的短剧完整剧本、人物人设文案，自动拆解角色、场景、道具三大模块，生成统一美术标准的3A次世代写实CG全套设定素材，包含角色标准三视图+面部特写、场景光影材质规范、道具高精度建模描述。

# ##核心方法论：采用三路并行输出逻辑

本工作流采用**三路同步生成**架构，仅依靠一份短剧完整剧本，生成三类功能互补的美术资产：\
A 分支：角色三视图\
3D建模，AI人设，写实精致国漫CG次世代风格，角色+年龄+性别+具有美感的服装+符合服装的鞋，无背景杂物，超干净纯浅灰色背景，脚下带有干净柔和投影，轻胶片颗粒，细节拉满，8K 超清画质 +发丝自然蓬松，纹理必须极致清晰；微表情：双眼平静直视镜头，嘴唇自然闭合，面部肌肉放松，呈现活泼克制的写真状态，完美模特身材，大长腿，双手自然下垂，全身面向镜头，纯净的灰色背景\
画面左侧是人物全身三视图+右侧面部正面特写，背景无接缝。裙摆之间不要有遮挡

\
B分支：场景设定图\
3D国漫场景设定图，电影级CG质感，超写实渲染，3D动漫CGOC染质感，Unreal Engine 5 风格，PBR物理材质，全局光照（GI），体积光 + 主体场景（核心对象 + 属性） + 空间布局（视角 + 内部结构 + 环境环绕） + 视觉要素（色彩光影 + 氛围 + 细节） + 画质要求，无人物，+从正面平视视角展现细节完美的真实场景，广角全景镜头，纵深延伸式场地，尽显宏大\
\
C分支：道具设定图\
3D建模，AI人设，写实精致国漫CG次世代风格，3D动漫CGOC染质感 + 主体道具（核心对象 + 属性） + 空间布局（视角 + 内部结构 + 环境环绕） + 视觉要素（色彩光影 + 氛围 + 细节） + 画质要求，无人物+题材，真实道具，写实风格，正面完整展示图，纯白背景，32k超清，3d风格，概念艺术，概念艺术。无人\

## 需要什么输入\\

必填：短剧完整剧本文本 / 分角色人物人设文案\
可选补充：画风限定（国漫CG/主机写实/BJD人偶）、画质梯度、镜头规格、渲染引擎（UE5）、角色身高身形、服装配饰、场景环境要求、道具细节需求\
\\

## 怎么做\\

1. 自动解析剧本，拆分出场全部人物、出现的场景、关键剧情道具；\\
2. 统一采用3A主机写实次世代/真人CG标准建模规范，PBR物理材质、实时光追、8K超清；\\
3. 人物统一输出：全身正面/侧面/背面三视图+面部平视特写，纯浅灰无影背景，五官对称不歪头，严格匹配人设五官、发型、服装、身形；\\
4. 场景输出：全局光照参数、体积光、色彩白平衡规范、环境材质分层方案；\\
5. 道具输出：高精度纹理、金属/布料/皮革细分材质、尺寸比例设定；\\
6. 统一控制光影：柔和自然光，面部无杂乱硬阴影，可自定义冷调/暖调氛围感，轻胶片颗粒，无多余背景杂物；\\
7. 严格遵循用户给定身形、妆容、穿搭、身高、站姿、肢体摆放要求。\
   \\

## 产出什么\\

1. 全部出场角色标准化CG设定文案（三视图+面部特写完整描述，可直接用于AI出图/建模软件）；\\
2. 短剧全剧情场景UE5渲染规范+场景建模参数；\\
3. 全部剧情道具高精度次世代材质设定说明；\\
4. 配套统一美术风格总规范（光影、画质、镜头、分辨率标准）。\
   \\

## 什么时候问你\\

1. 剧本人物外貌、服装、场景描述模糊缺失关键信息时，一次性汇总提问补全；\\
2. 用户有特殊画风/渲染/镜头特殊定制需求，与基础模板冲突时确认；\\
3. 角色身高、体型、服装配饰存在矛盾设定时，确认取舍；\
   其余信息完整时自动生成全部素材，不打断流程。
