## 内容阶段

### G1 — 素材确认

接受：PDF/Word 文档、URL、文字介绍、一句话需求。提取品牌/产品名、核心卖点、关键数据、目标人群、品牌 VI 色，输出素材卡。

```
[关卡G1: 素材确认]
  ├─ ✅ 确认 → G2
  ├─ ✏️ 修改补充 / 📝 手动编辑 / 🔄 换输入源
  └─ 🚩 若素材含党政元素 → 自动激活红色合规模式（见 branch-a + red-compliance.md）
```

### G2 — 剧本选择

按 `references/industry-angles.md` 行业角度库自动生成 5-6 个剧本提案（30-60s），结构：钩子→痛点→方案→背书→CTA。

```
[关卡G2: 剧本选择]
  ├─ ✅ 全选 / ☑️ 勾选部分
  ├─ ✏️ 修改某条 / 🔀 换角度 / ➕ 补充角度
  └─ ⏱ 调总时长 30s / 60s / 90s
```

### G3 — 剧本完善（可跳过）

对选定剧本做体检与逐条优化：

```
[关卡G3: 剧本完善]
  ├─ 🩺 剧本体检（智能体自动评分展示）:
  │    ├─ 钩子强度(前3秒抓不抓人)
  │    ├─ 痛点共鸣(目标人群戳不戳中)
  │    ├─ 信息密度(节奏内能否讲完)
  │    ├─ 情感曲线(有无起伏)
  │    └─ CTA明确度(行动指令清不清)
  │    └─ 弱项逐条给优化建议，用户勾选采纳
  ├─ ✏️ 逐幕打磨: 钩子/痛点/方案/背书/CTA 五段任意段单独重写
  ├─ 🗣 口语化测试: 按预估语速朗读，检验顺口度与时长匹配
  ├─ 🔀 A/B 变体: 生成 2 个调性变体（如理性版 vs 情感版）并排对比
  └─ ⏭ 跳过: 「剧本已满意」→ 直接进 G4
```

## 定调阶段

### G4 — 风格选择（六选一，剧本后置）

剧本确认后，基于剧本内容与行业做智能推荐：

```
[关卡G4: 风格选择]
  ├─ 🎯 智能推荐 → 按剧本调性推荐 1-2 个分支
  ├─ 📋 六风格全览:
  │    A MG扁平动画   — 纯色块/弹跳动画/活泼年轻
  │    B 2.5D等距插画 — 建筑剖面/等距旋转/大气空间
  │    C 商务信息图   — 数据动画/图表生长/理性专业
  │    D 剪纸拼贴风   — 纸质感/图层叠落/温暖手工
  │    E 手绘涂鸦风   — 逐笔生长/手写出现/即兴知识感
  │    F 温暖绘本风   — 柔光/翻书/三态角色/治愈情感
  ├─ 📌 直接选择
  └─ 🤷 拿不定 → G6 用「对比模式」看 3 张样板图再定
```

### G5 — 色卡确认

画布生成**色卡图片节点**（prompt 见 style-locks.md 附录），hex 值同步记录 manifest。后续所有关键帧出图时色卡图作为参考图绑定。

```
[关卡G5: 色卡确认]
  ├─ ✅ 通过 → G6
  ├─ 🎨 换主色 / 🔄 重新生成 / 🖼 从品牌VI提取
  ├─ 🎭 换风格情绪: 温暖亲切(暖)/专业严谨(冷)/活力青春(高饱和)/高端大气(低饱和+金)/科技感(蓝紫渐变)
  └─ 🎯 手动调色 → 逐个 hex 修改后重生成
```

### G6 — 风格确定（样板3张 + 调参迭代 + DNA 固化）

画布操作：图片节点 → G4 所选分支的首选模型（自动匹配，见 model-matrix.md）→ prompt = 对应 STYLE_LOCK（色卡 hex 已替换）+ **剧本中最代表性的一幕** → 生成风格样板。

```
[关卡G6: 风格确定]
  ├─ 🖼 多场景样板（一次生成 3 张并排展示）:
  │    ① 人物特写镜 ② 室内/中景镜 ③ 全景/空镜
  │    目的: 验证风格在特写/中景/全景下都不崩
  ├─ 🔁 调参迭代版本化:
  │    每轮调参生成新版本(v1/v2/v3...)，历史版本并排展示
  │    可回滚到任意历史版本定为最终版
  │    各分支调参项见对应 reference「精细调参备查」
  ├─ 🔍 对比模式 → 生成 3 个不同分支的样板图并排（G4 拿不定时）
  ├─ 🎨 色调不对 → 回退 G5 调色卡
  ├─ 🔀 换风格 → 回退 G4 重新选择分支
  └─ 📜 通过后执行风格DNA固化:
       最终调参结果 + STYLE_LOCK 终稿 + 色卡 hex + 样板图节点ID
       写入「风格DNA卡」入 manifest，后续所有生成节点强制引用，
       任何漂移对照 DNA 卡判定
```

### G7 — 节奏与输出格式

```
[关卡G7: 节奏与输出格式]
  ├─ 🎵 视频节奏: ⚡快(3-4s/镜) / ⏱标准(5s) / 🧘慢(6-8s)
  │    └─ 影响分镜时长编排，必须在分镜生成前确定
  └─ 🔀 输出格式: 🎬标准视频 / 🖼动态海报系列 / 📊动画PPT

  注: 图像/视频模型不再询问，由 model-matrix.md 按分支自动匹配，
      匹配结果在 G9 积分确认时随报价一并汇报。
```

## 锁定阶段

### G8 — 分镜确认

按 G7 节奏与自动匹配模型的时长规格拆镜头序列（⚡3-4s / ⏱5s / 🧘6-8s，不超模型上限）。每镜字段：镜号/画面描述/出场角色/场景/运镜/转场类型/音效事件/时长。

**转场策略**：基础转场 = 合成节点直接拼接；特殊转场（翻纸/橡皮擦/3D翻书等）= 生成独立「转场视频片段」（上镜尾帧→图生视频，见 libtv-operations.md 第 6 节）。

```
[关卡G8: 分镜确认]
  ├─ ✅ 通过 → G9
  ├─ ✏️ 改镜 / ➕➖ 增删合并拆分
  ├─ ⏱ 调节奏 → 回 G7 改节奏后重排分镜
  └─ 🎞 改转场 → 指定镜间转场方式
```

### G9 — 积分确认（含模型自动匹配汇报）

```
[关卡G9: 积分确认]
  智能体汇报:
  ├─ 🤖 模型自动匹配结果:
  │    图像模型: [model-matrix 首选]（备选: [...]）
  │    视频模型: [model-matrix 首选]（备选: [...]）
  │    特殊说明: [超长镜用画面推演/多参考换HappyHorse等]
  ├─ 💰 报价:
  │    关键帧 N张×0.25 + 视频 N段×10 + 转场 N段×10 ≈ XXX 积分
  │    可选增强: 高清放大/帧率提升（逐项报价）
  │    当前余额: XXX（充足/缺口 XX）
  └─ 决策:
       ├─ ✅ 锁定预算开工
       ├─ 💰 设预算上限（超出即暂停报用户）
       ├─ ✂️ 降规模 → 回 G8 减镜头 或 回 G7 换输出格式
       └─ ⏸ 暂停（先充值）
```

### G13 — 试炼镜头（防浪费终极保险）

```
[关卡G13: 试炼镜头]
  从分镜中选 1 个代表性镜头（含主角+主场景+典型运镜，
  各分支推荐选镜见对应 reference），走完「关键帧 → 视频片段」完整流程:
  ├─ 成本: ≈0.25(图) + 10(视频) ≈ 10.25 积分
  ├─ 验证: 风格/角色保真/运动流畅度/单镜时长/转场设想
  ├─ ✅ 端到端达标 → 解锁批量生产（G14）
  └─ ❌ 不达标 → 定位问题环节回退（模型?参考图?prompt?）
       修完重新试炼，直到通过
```

## 量产阶段

### G14 — 逐镜关键帧（分批 + 衔接检查）

图片节点逐镜生成：prompt = STYLE_LOCK 原文 + 场景描述 + 角色外观(照抄 manifest) + 动作构图 + 景别；参考图按配方绑定。批大小 = min(会员并发上限, 5)。瑕疵优先用画布「局部重绘/擦除」修复。

```
[关卡G14: 关键帧确认 | 第N/N批]
  ├─ ✅ 本批通过 → 下一批 / 全部通过进 G15
  ├─ 🔗 相邻镜头衔接检查:
  │    上镜尾帧 vs 本镜首帧的构图/色彩/角色位置连续性对比
  ├─ 🎨 一致性抽查(对照风格DNA卡) → 漂移镜号一键对照档案重生成
  ├─ 🔄 全部重生成 / 🎯 指定镜号重生成 / 📐 指定镜号调参
  └─ ⏸ 暂停 → 回 G10/G11
```

### G15 — 逐镜视频片段（分批）

视频节点从关键帧连线生成，prompt 只写运动（镜头运动+主体动作+动效元素），禁止重复描述外观风格；时长按节奏与模型上限。各分支运动词库见对应 reference。

### G16 — 合成确认

框选全部片段 → 视频合成 → 按分镜排序 → 实时预览；音频节点 Mureka 生成 BGM（各分支情绪词见对应 reference）；可选高清放大/帧率提升；导出 MP4 下载至 final/。

```
[关卡G16: 合成确认]
  ├─ ✅ 通过 → G17
  ├─ 🎬 片头片尾 / 🎞 转场增删换 / 🔊 音频调整
  ├─ 📝 字幕 / 🎙 配音 / 📦 多版本导出
  └─ 🔙 回分支重做（保留当前成片）
```

### G17 — 物料包确认

详见 `references/private-domain-package.md`：交付物下载 + 对话侧文案（朋友圈×3/社群话术/私信脚本/落地页/推文大纲）+ 画布通用海报（5 类型 × 3 尺寸）+ 多语言版。

## 画布执行通则（G10-G16 所有分支共用）

详见 `references/libtv-operations.md`，核心规则：

1. 关键帧 prompt = STYLE_LOCK 原文 + 场景 + 角色外观(照抄manifest) + 动作构图 + 景别；参考图按分支配方绑定
2. 视频 prompt 只写运动，禁止重复描述外观风格
3. 批大小 = min(会员并发上限, 5)；每批抽查一致性，漂移即弃
4. 每批生成前核对积分余额（积分守卫）
5. 失败重试：同 prompt ≤2 次 → 换备选模型 1 次 → 报用户

## 成本提示（LibTV 积分）

- 图像节点 ≈ 0.25 积分/张；视频节点 ≈ 10 积分/段（以平台实时扣费为准）
- 60s 成片（14 镜 + 3 转场段）≈ 175 积分；动态海报 5 张 ≈ 51 积分；动画 PPT 8 页 ≈ 82 积分
- 前期验证成本：色卡+样板 ≈ 1 积分，角色双验 ≈ 0.5/角色，试炼镜头 ≈ 10.25 积分
- **G13 试炼镜头通过前量产锁死**，用约 20-40 积分的小额验证替代数百积分的批量返工
