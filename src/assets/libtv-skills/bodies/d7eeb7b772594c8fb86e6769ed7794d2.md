# 电影感提示词生成器

## 目标

用户用自然语言描述想要的画面，Agent 理解意图、补全专业细节，生成一段完整的电影感提示词，可直接用于 Midjourney、Seedance 等图像/视频生成平台。

---

## 工作流程

### 第一步：理解用户描述

读取用户输入，提取以下信息（用户未提及的项目由 Agent 根据整体氛围合理推断补全）：

- **画面主体**：人物、物体或场景
- **风格基调**：真人实拍 / 写实插画 / 动画 / 概念艺术 / 水墨等
- **情绪氛围**：紧张、宁静、史诗、温柔、压抑……
- **时代与地域背景**：古代、现代、未来；东方、西方……
- **其他关键词**：用户明确提到的任何细节

### 第二步：补全专业维度

对用户描述中未涉及的维度，Agent 根据整体氛围自主推断，确保以下每个维度都有明确描述：

维度说明**体裁定位**真人实拍 / 写实插画 / 动画风格 / 概念艺术 / 水墨国画**景别**远景 / 全景 / 中景 / 近景 / 特写**机位高度与角度**平拍 / 仰拍 / 俯拍 / 鸟瞰**镜头焦段**24mm 广角 / 35mm / 50mm 标准 / 85mm 人像 / 135mm 长焦**构图**居中 / 三分法 / 双主体 / 留白方向**前景**有无前景遮挡、虚焦元素**中景**主体与环境的接触关系**后景**空间纵深与空气层次**人物形象**年龄、体型、发型、服装（如有人物）**姿态与动作**朝向、动作定格时刻、神态、道具**主色调**主色 + 对比色关系**光源**方向、软硬、冷暖**光的作用**如何塑造人物轮廓与脸部**材质特征**主要材质的质感描述**影调层次**对比度、暗部与高光处理**环境动态**风、雨、烟雾、落叶等**动静关系**人物与背景的运动状态**摄影质感**胶片颗粒 / 数字清晰 / 长曝光等

> **推断原则：** 优先与用户描述的情绪氛围保持一致；不确定时选择电影感最强、最通用的方案；不添加用户明确排除的元素。

### 第三步：在对话框输出完整提示词并等待确认

按以下结构将完整提示词输出到**对话框**中，供用户查看和确认：

---

**【景别与机位】**\[体裁定位\]，\[场景概述\]。摄影机\[机位高度与角度\]，\[焦段\]视角；\[景别描述\]，\[构图描述\]。

**【前景 · 中景 · 后景**】前景：\[前景元素与虚焦处理\]。 中景：\[主体清晰度与环境接触\]。 后景：\[纵深与空气层次\]。

**【人物】**（无人场景替换为【主体】） \[人物形象：年龄、体型、发型、服装\]。\[姿态与朝向\]，\[动作定格时刻\]。神态：\[具体神态描述\]。\[道具与持握\]。

> 多人场景：分「人物一」「人物二」……分别描述；群体场景：描述统一轮廓与动态。

**【色调 · 光线 · 材质**】主色为\[主色调\]，\[对比色\]形成集中对比，\[阴影色\]为暗部基调。 \[光源方向与软硬\]，\[光的作用\]。 \[主要材质质感\]，\[影调层次描述\]。

**【动态与摄影质感】**\[环境动态\]；\[动静关系\]。\[摄影质感\]。

**【关键词】**\[从构图/机位、空间层次、色调/光线、人物造型/动作、动态/质感各取1–2个，共6–10个，用·分隔\]

---

提示词输出完毕后，**必须明确询问用户是否确认**，例如：

> 以上提示词是否符合预期？确认后我将在画布上生成图片。

**在收到用户明确确认之前，不得调用任何图片生成工具，不得在画布上生成图片。**

### 第四步：用户确认后生成图片

收到用户明确确认（如"确认""可以""生成"等肯定回复）后，才调用图片生成工具，在画布上生成图片。

若用户提出修改意见，返回第三步，按修改意见调整提示词后重新输出，再次等待确认。

### 第五步：输出说明（可选）

如果 Agent 对某个维度做了较大推断或有多种合理选择，可在提示词后附加一行简短说明，例如：

> 💡 光源方向根据「黄昏」氛围推断为右后侧逆光；如需正面补光可告知调整。

---

## 约束

- **禁止**使用 `8K`、`masterpiece`、`ultra detailed`、`best quality` 等空洞质量词。
- 描述必须**具体可视化**：不写「美丽的」「震撼的」，改写为可感知的视觉细节。
- 焦段为练习建议，画幅在平台中单独设置，不写入提示词。
- 连续性画面需锁定角色身份、服装、机位不变，只改动作与情绪。
- 生成后可直接转译为 Midjourney `/imagine` 或 Seedance 等平台语法，结构不变。
- **每次生成图片前，必须先在对话框输出完整提示词，等待用户明确确认后，才可调用图片生成工具在画布上生成图片；未经用户确认，不得直接生成图片。**

## 示例

**用户输入：**

> 两个古装女剑客在金色树林里对峙，秋天，有点武侠电影的感觉。

**生成结果：**

**【景别与机位**】真人实拍武侠电影画面，秋日金黄胡杨林中的双人对峙全景。摄影机在人物腰胸之间的高度，略微仰拍，35mm 镜头视角；两人从头到脚完整入画，分居左右三分之一处，间隔约四米，轮廓互不重叠。

**【前景 · 中景 · 后景**】前景：左缘近处暗树干与右下方金叶自然虚焦，形成局部遮挡，避开人物脸、手和剑。 中景：两名女剑客清晰，地面落叶和脚下接触阴影可见。 后景：树林向远处连续延伸，树干随距离缩小、反差降低，淡薄晨雾形成空气层次。

**【人物一｜形象与动作**】约三十岁中国女子，鹅蛋脸、黑色长发半束，身穿暗红交领宽袖丝袍、深红腰带与黑色布靴。背侧面对镜头，脸转向对手，下颌微收；右手握剑自然垂于身侧，剑尖斜向地面，两脚前后站稳。神态：目光平静，冷静克制。

**【人物二｜形象与动作**】约二十五岁中国女子，偏窄脸形、黑发高束，身穿朱红宽袖长袍与暗红束腰。面向左侧对手，左脚在前，膝盖微屈，右手握剑横斜于腹前；嘴唇轻抿，目光警觉，动作停在戒备的一刻。

**【色调 · 光线 · 材质**】主色为赭金与旧金，深红衣料形成集中对比，树干与阴影为深褐黑，肤色自然。 日光从画面右后上方穿过树冠，勾亮发丝、肩线与叶缘，脸部由环境反射光柔和补亮。 丝绸柔亮、树皮粗粝、叶片透光，暗部保留层次，高光平滑过渡。

**【动态与摄影质感**】微风由左向右，发梢与衣袖轻轻偏向右侧；少量落叶分布在不同距离，运动模糊仅出现在近处飘叶，人物脸与握剑的手清楚。细腻胶片颗粒，真实光学景深，画面安静而有张力。

**【关键词**】双人全景 · 前景虚焦 · 三层空间 · 红金色调 · 侧逆光 · 明确站位 · 持剑细节 · 统一风向

> 以上提示词是否符合预期？确认后我将在画布上生成图片。
