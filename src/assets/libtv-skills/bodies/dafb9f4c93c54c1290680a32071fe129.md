===== 一、整张画布固定分区【带位置标注说明】\
整张人设图分为6个固定区域，位置永久锁定，只能修改人物服装，不能改动区块排布；浅灰色纯色影棚背景，最顶端居中为自定义标题栏。\
\
区域0（顶部通栏）：【标题区】\
功能：填写角色姓名，例：顾家养女、何欢欢。\
\
区域1（左上：画面左侧40%大小）：【面部特写区】\
内容：人物大半身脸部特写，完整锁定五官、脸型、发型、肤色；这是角色的样貌基准，所有其他角度全部以此脸为准，杜绝换脸。\
用途：用来固定人物长相，后续所有穿搭、角度都沿用这张脸。\
\
区域2（右上：画面右侧60%上半格）：【穿搭A组（日常装）】\
内部包含左右两小格：\
2-1：穿搭A 正面全身站姿\
2-2：穿搭A 背面全身站姿\
自定义标签：常服/通勤装/休闲装，可随意修改服装款式、颜色、面料。\
\
区域3（左下方格子）：【穿搭B组（正装/礼服）】\
内部包含左右两小格：\
3-1：穿搭B 正面全身站姿\
3-2：穿搭B 背面全身站姿\
自定义标签：晚礼服、旗袍、西装等，支持任意版型更换，正反面结构严格对应。\
\
区域4（右下方格子）：【穿搭C组（居家便装）】\
内部包含左右两小格：\
4-1：穿搭C 正面全身站姿\
4-2：穿搭C 背面全身站姿\
自定义标签：睡衣、家居服、私服，可自由修改样式。\
\
区域5（左下角最底栏）：【Q版形象区】\
并排3个同款Q版小人，完全复刻真人的五官、发色、第一套穿搭；用来做IP卡通形象，画风独立柔和，不和真人画风冲突。\
\
区域6（右下角最底栏网格框）：【专属配饰绑定区】\
网格画布，专门摆放该角色固定饰品：耳钉、项链、手链、包包、随身道具；可以设定“配饰永久固定，换衣服首饰不变”，也可以跟着穿搭更换配饰。\
\
===== 二、人物与换装规则（新手易懂版）\
1、样貌锁定规则：区域1的脸部为唯一标准，整张图里所有真人角度，脸型、骨相、发型、肤色完全一模一样，AI不得私自改动长相。\
2、自由换装规则：穿搭A/B/C这三组，用户可以随便写任何服饰（裙子、风衣、西装、汉服、休闲装都行），AI只替换衣服，人物身形、脸蛋完全不动；每套衣服必须同时画出正面、背面，保证版型统一，不会正反面矛盾。\
3、配饰两种模式可选：\
模式1（固定配饰）：配饰区的物件全程绑定角色，不管怎么换衣服，首饰、随身道具不变；\
模式2（随穿搭更换）：每套穿搭搭配不同的饰品，在配饰区同步展示。\
4、Q版规则：自动参照真人样貌生成卡通形象，不用单独描述Q版样貌。\
\
===== 三、画质渲染标准\
超写实真人影视CG质感，影棚柔光，8K超清，UE5+PBR物理布料材质，衣服褶皱自然贴合身体。\
真人区域不卡通、不二次元；Q版区域保持可爱画风，分区互不干扰。\
\
===== 四、硬性防错约束（防止新手翻车）\
1、所有全身人像直立落地，站姿标准，禁止肢体穿模、手脚畸形、身体扭曲、悬浮飘起。\
2、每一套服装的正面和背面版型严格对应，不会出现背面款式错乱、空白的问题。\
3、6个区块的位置不能打乱、不能合并、不能删除任何一块，框架永远固定。\
4、不会凭空多出多余人物、杂物，只生成用户指定的角色、三套穿搭、对应配饰。\
\
===== 五、新手调用引导说明（使用方法，照着填写即可）\
用户只需要按照固定格式填写4部分内容，其余全部由Skill自动处理：\
①顶部标题：角色名称\
②穿搭A（右上区域）：填写第一套衣服的详细描述\
③穿搭B（左下区域）：填写第二套衣服的详细描述\
④穿搭C（右下区域）：填写第三套衣服的详细描述\
⑤配饰设定：选择【配饰固定不变】或者【穿搭搭配不同配饰】\
\
===== 六、负面禁止项（规避所有常见错误）\
禁止打乱分区位置、任意删减视图；禁止不同角度人物长相不一样；禁止服装正反面造型矛盾；禁止区块互相重叠挤压；禁止穿模、畸形肢体；禁止私自固定服装不让用户更换。
