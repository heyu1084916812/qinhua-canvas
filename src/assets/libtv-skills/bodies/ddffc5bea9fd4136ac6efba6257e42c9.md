# 巨构图生视频·缓慢下压推近 Skill

## 核心定位

以**科幻工业巨构图片为首帧**，生成 5 秒短视频。运镜方式固定为**缓慢下压推近（Slow Push Down）**，让静态巨构图片产生沉稳、史诗的临场感。

---

## 运镜方式（固定锚点）

### 🎬 运镜A：缓慢下压推近（Slow Push Down）

- 镜头从高位缓慢向下压，同时向巨构核心区域推近
- 节奏：匀速，沉稳，史诗感
- 适合：大气层俯瞰视角、高空巨构全景图、渺小人影仰望巨构、砼核斜面/拱门/双柱

---

## 视觉风格锚点（固定不变）

要素描述色调冷蓝钢铁色（主调）+ 橙色核心光源（点缀）光影橙蓝对撞，戏剧性侧光或底光大气体积雾弥漫，大气透视，远景消散人影前景渺小人影作为尺度参照（不可缺失）城市密集城市建筑群铺满画面背景质感胶片颗粒，电影质感，非游戏渲染感

---

## Prompt 模板

```
以{{首帧图片}}为首帧，镜头从高位缓慢向下压并向巨构核心区域推近，匀速沉稳，史诗感，冷蓝钢铁色调，橙色核心光源，橙蓝光对撞，体积雾，前景渺小人影，密集城市建筑群，胶片颗粒，电影质感，5秒
```

---

## 执行步骤

1. **接收首帧图片**：用户提供一张科幻工业巨构风格图片
2. **套用 Prompt 模板**：将首帧图片填入模板，确认视觉风格锚点全部保留
3. **生成视频**：时长 5 秒，以首帧图片为参考素材
4. **质检**：
   - \[ \] 镜头缓慢下压推近效果明显
   - \[ \] 橙蓝色调对撞
   - \[ \] 体积雾存在
   - \[ \] 胶片颗粒质感
