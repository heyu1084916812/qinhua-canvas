# Nike风格产品落地页UI演示视频生成

## 核心方法论

### 三层视觉叠加框架(Visual Layer Compositing)

这是电商UI演示视频的核心设计逻辑,将视频内容分解为三个独立叠加的视觉层:

**Layer 1 (全屏UI骨架层)** — 网页界面必须铺满整个画面,无黑边无留白

- 全屏Hero区域:产品占据全屏宽度展示
- 完整电商UI元素:标题大字、价格、CTA按钮、产品描述文案
- UI元素定位:文字排版、按钮位置、布局网格系统

**Layer 2 (品牌动态元素层)** — 品牌特有的视觉语言运动

- 背景动态纹理:碳纤维/网眼/速度线/光影变换
- 品牌字体排版:粗犷倾斜超大无衬线字体,具体文案内容(如"JUST DO IT")
- 色彩系统:品牌主色调与产品配色的对比关系

**Layer 3 (场景融合层)** — 产品使用场景与UI的自然交织

- 运动员/模特与产品的互动画面
- 产品细节特写与页面产品图的呼应关系
- 场景画面与UI元素的空间融合(不是简单叠加,而是视觉交织)

### 时间轴段落结构(Temporal Segment Architecture)

标准15秒视频采用**3段式递进**结构:

**0-5秒 (Hero入场段)** — 建立视觉冲击

- 产品正面特写推镜 + 全屏UI界面淡入
- 品牌大字从背景流动进入画面
- 目标:3秒内抓住注意力,建立品牌识别

**5-10秒 (动态场景段)** — 展示产品使用场景

- 运动员/模特使用产品的动态画面
- UI滚动效果启动,页面向下展开内容
- 交互动效模拟:悬停放大(150%)、颜色反转
- 视差滚动:背景与前景以不同速度移动

**10-15秒 (产品详情页定格段)** — 完整UI收尾

- 定格在全屏产品详情页
- 包含完整电商元素:产品图、标题、价格、加入购物车按钮、描述
- 产品图必须与参考图保持一致
- 作为整个演示的收尾画面,用户可截图看清所有UI细节

### 产品一致性校准法则(Product Fidelity Calibration)

电商UI视频的致命问题是**产品图不一致** — 场景中的产品与参考图细节差异。必须采用:

**参考图权重强化**

- 在提示词开头明确"核心展示主体是该产品图片"
- 多次强调"跑鞋细节与产品图片相呼应"
- 在最后一幕要求"产品图与参考图呼应"

**细节锚点描述**

- 提取参考图的关键特征:配色(橙/蓝/黄)、鞋型轮廓、材质纹理
- 在场景描述中嵌入这些细节:"运动员穿着橙蓝配色跑鞋"

**分段校验逻辑**

- 第一段:产品正面特写,必须与参考图100%一致
- 第二段:场景中产品可以有角度变化,但配色/轮廓不能变
- 第三段:最终定格页面的产品图,回归参考图原貌

## 工作流程

### 1. 准备阶段

**产品参考图分析**

- 提取产品关键特征:配色方案、材质纹理、形态轮廓
- 记录细节描述词:"橙色鞋面+浅蓝侧条+黄色鞋底+网眼透气材质"
- 确定产品最佳展示角度:正面/侧面/45度斜视

**品牌风格研究**

- Nike风格关键词:粗犷倾斜字体、暗色背景、大胆留白、全宽Hero图
- Adidas风格:三条纹、科技感、几何切割
- Apple风格:极简白底、精密产品渲染、柔和阴影
- 提取3-5个该品牌的标志性视觉元素

**交互动效清单**

- 列出需要模拟的UI交互:滚动、悬停放大、颜色反转、视差效果
- 为每个交互编写具体描述:"鼠标悬停时跑鞋放大150%、背景从黑色反转为白色"

**时长与规格决策**

- 15秒 = 3段式(5秒入场+5秒场景+5秒定格)
- 30秒 = 5段式(Hero+场景1+交互演示+场景2+定格)
- 比例:16:9电脑端 / 9:16手机端 / 1:1社交媒体

### 2. 提示词构建阶段

**基础框架:视频属性声明(放在最前)**

- 模型选择声明:"用minimax h3生成" / "用runway生成"
- 时长与规格:"15秒,16:9" / "30秒,9:16竖屏"
- 核心约束前置:"必须遵循以下提示词,不允许改动"

**第一层:UI骨架描述**

- 明确界面类型:"一个网站页面,网站页面UI设计,网站动效"
- 全屏铺满要求:"UI界面填满16:9画面每个角落,无黑边无留白"
- 核心滚动效果:"视频展示了流畅的网页向下滚动效果"

**第二层:品牌风格注入**

- 风格定位句:"一个极具爆发力与动感的耐克(Nike)官网风格产品落地页UI/UX演示视频"
- 产品锚点:"核心展示主体是该产品图片\[编号\]"
- 字体排版:"粗犷有力、倾斜的超大号无衬线字体进行张扬的排版,文案为'JUST DO IT'、'SPEED UNLIMITED'"
- 背景纹理:"极具速度感的动态光影、暗色碳纤维或运动透气网眼纹理在交织变换"

**第三层:场景融合描述**

- 动态场景:"运动员穿着\[产品配色描述\]跑鞋在田径赛道冲刺的动态画面与UI动效自然交织"
- 产品呼应:"跑鞋细节与产品图片相呼应"
- 视觉融合:"赛道上的速度线与背景光影纹理融合,强化了运动气息"

**第四层:交互动效明确**

- 滚动节奏:"视频展示了节奏紧凑、充满力量感的网页向下滚动效果,每2-3秒切换一个视觉焦点"
- 具体交互:"鼠标悬停时跑鞋瞬间放大150%,背景从暗色反转为白色,出现加入购物车按钮高亮动画"
- 视差效果:"页面滚动时背景以0.5倍速移动,前景产品以1倍速移动,产生视差深度"

**第五层:最后一幕定格要求**

- 结尾画面:"最后5秒定格在完整全屏产品详情页"
- UI元素清单:"包含产品大图、产品标题大字、价格标签、加入购物车按钮、产品描述文案、尺码选择器"
- 产品一致性:"产品图与参考图呼应,保持配色与细节一致性"

**优先级排序原则**

- 第1优先:全屏铺满 + 产品一致性(这是最常见的生成问题)
- 第2优先:品牌风格特征(字体、配色、纹理)
- 第3优先:交互动效细节(悬停、滚动)
- 第4优先:场景融合自然度

### 3. 生成后问题诊断与迭代

**标准问题检查清单**

UI层问题:

- \[ \] UI界面是否铺满全屏?(最高频问题)
- \[ \] 是否有黑边/画中画效果?
- \[ \] 文字排版是否为乱码/无意义字符?
- \[ \] 最后一幕是否定格在完整产品详情页?

产品一致性问题:

- \[ \] 场景中的产品与参考图配色是否一致?
- \[ \] 产品细节(鞋型轮廓/材质纹理)是否匹配?
- \[ \] 最后定格页面的产品图是否回归参考图?

动效质量问题:

- \[ \] 是否有真实的滚动效果?还是只是场景硬切?
- \[ \] 交互动效(悬停放大/颜色反转)是否体现?
- \[ \] 视差滚动效果是否存在?
- \[ \] 节奏是否紧凑(2-3秒切换焦点)?

品牌风格问题:

- \[ \] 字体是否符合品牌特征(Nike的粗犷倾斜/Apple的优雅细线)?
- \[ \] 背景纹理是否到位(碳纤维/速度线/光影)?
- \[ \] 整体色调是否匹配品牌调性?

**针对性优化策略**

问题:UI没铺满屏幕 → 在提示词第一句强调"UI界面填满16:9画面每个角落,无黑边" → 补充"全宽Hero区域,产品占据全屏宽度展示"

问题:产品图不一致 → 增加产品细节锚点描述:"橙色鞋面+浅蓝侧条+黄色鞋底" → 多次重复"与产品图片相呼应""保持配色一致性"

问题:滚动效果弱/只有场景切换 → 明确"视差滚动效果:背景0.5倍速,前景1倍速" → 要求"内容从下方滑入画面,而非黑场硬切"

问题:交互动效缺失 → 编写具体交互描述:"悬停瞬间放大150%" → 指定触发时机:"在第7-9秒展示悬停交互"

问题:最后一幕不是产品页 → 单独一段强调"最后5秒定格在完整全屏产品详情页" → 列举必需UI元素:"产品图、标题、价格、按钮、描述"

问题:字体排版为乱码 → 指定具体文案:"'JUST DO IT'、'SPEED UNLIMITED'" → 描述字体特征:"粗犷倾斜超大无衬线字体"

## 关键约束与标准

### 全屏UI铺满规则(最高优先级)

- UI界面必须填满画面每个角落,16:9视频不允许出现上下黑边,9:16视频不允许出现左右黑边
- 禁止画中画效果:不能是"一个浏览器窗口漂浮在空间中",必须是沉浸式全屏UI
- Hero区域必须全宽:产品展示区域横向占满整个画面宽度

### 产品一致性规则

- 配色锚点不可变:参考图的主色调(如橙/蓝/黄)在所有场景中保持一致
- 轮廓特征不可变:鞋型/包包形状/电子产品外观的基本轮廓在各角度下保持识别度
- 最后定格页必须回归:最终产品详情页的产品图必须与参考图保持最高相似度

### 三段式时间轴规则(15秒标准)

- 0-5秒:Hero入场段,建立视觉冲击与品牌识别
- 5-10秒:动态场景段,展示产品使用场景与UI滚动
- 10-15秒:产品详情页定格段,呈现完整电商UI元素
- 每段内部2-3秒切换一个视觉焦点,保持节奏紧凑

### 交互动效具体化规则

- 悬停放大:必须指定放大倍数(如150%)和触发时机(第7-9秒)
- 颜色反转:必须指定反转前后的具体颜色(暗色→白色)
- 视差滚动:必须指定不同层的速度比(背景0.5倍速,前景1倍速)
- 不能仅描述"有交互效果",必须写清"在XX秒时,鼠标悬停在产品上,产品放大150%,背景从黑色反转为白色"

### 品牌风格标志物规则

- Nike:粗犷倾斜字体+暗色碳纤维+速度线+"JUST DO IT"
- Apple:极简白底+精密渲染+柔和阴影+细线衬线字体
- Adidas:三条纹+科技感网格+几何切割+运动场景
- 每个品牌至少提取3个标志性视觉元素嵌入提示词

### 最后一幕UI元素清单(强制要求)

必须包含以下电商UI元素,缺一不可:

- 产品大图(与参考图一致)
- 产品标题大字
- 价格标签
- 加入购物车/立即购买按钮
- 产品描述文案(至少3行)
- 可选:尺码选择器/颜色选项/评分星级

### 文字内容可读性规则

- 禁止乱码:不能出现无意义字符流
- 指定具体文案:"JUST DO IT""SPEED UNLIMITED""BUY NOW"
- 字体特征描述:"粗犷倾斜超大号无衬线字体"而非"好看的字体"

### 视差滚动技术标准

- 必须有多层速度差:背景层(0.5x) &lt; UI元素层(1x) &lt; 前景产品层(1.2x)
- 内容入场方式:从画面下方滑入,而非黑场淡入或硬切
- 滚动连贯性:页面各部分之间平滑过渡,无跳跃感

### 节奏控制标准

- 15秒视频至少包含5-7个视觉焦点切换
- 每个焦点停留2-3秒
- 切换方式:推镜/横移/缩放/淡入淡出,避免单一黑场切换
- 避免节奏过慢:不能出现5秒以上的静态画面

## 推荐工具与模型

使用 Minimax H3(海螺H3) 进行视频生成,特别适合UI演示类动态视频,支持复杂的多层视觉叠加与动态效果。

## 高级技巧

### 产品锚点强化技巧

当产品一致性问题反复出现时,采用"三明治强调法":

- 提示词开头:"核心展示主体是该产品图片\[编号\]"
- 提示词中段:"跑鞋细节与产品图片相呼应"
- 提示词结尾:"最后定格页面产品图与参考图保持一致" 前中后三次强调同一约束,提升模型对该约束的权重。

### 分段描述优先级技巧

当提示词过长时,采用"核心约束前置+细节描述后置":

1. 最前:模型声明+时长规格+"必须遵循以下提示词"
2. 第二段:全屏铺满+产品一致性(最高频问题)
3. 第三段:品牌风格+场景融合
4. 第四段:交互动效细节
5. 最后:最后一幕定格要求

### 品牌风格迁移技巧

Nike风格提示词 → Apple风格提示词:

- "粗犷倾斜字体" → "优雅细线衬线字体"
- "暗色碳纤维背景" → "纯白极简背景"
- "速度线与光影" → "柔和阴影与精密渲染"
- "运动员冲刺场景" → "产品360°旋转特写" 保持三层叠加框架不变,替换品牌标志性视觉元素即可。
