# Directing Film

## 核心原则

把导演设计视为“观众体验的因果工程”，不是漂亮镜头清单。先决定观众此刻知道什么、期待什么、感受什么，再决定表演、调度、构图、摄影、声音和剪辑。

每个镜头都必须履行 **shot contract（镜头契约）**：改变信息、情绪、关系、空间理解或节奏中的至少一项。没有功能的镜头删掉或合并。

## 先选择工作模式

用户需要模式默认交付一句画面、单镜头或简单提示词精简视觉处理一条视觉意图 + 构图/光线/动作提示一场戏如何拍场景导演场景诊断 + 节拍图 + 调度 + 分镜/镜头表短片、短剧、广告、MV 或完整段落完整导演包导演阐述 + 节奏架构 + 视觉规则 + 场次/镜头方案Seedance、可灵、Runway 等生成视频AI 连续镜头包不变量锁定 + 时间线提示词 + 首尾状态 + 连续性检查S/S+ 短剧或完整 AI 影视制片S+ 导演制片系统剧本诊断 + 三道确认 + 分镜提示词 + 生产控制 + 100 分质量门只要求诊断或建议评审模式问题、影响、优先级、可执行改法；不要擅自重写

不要把简单请求膨胀成完整制片文件。信息缺失时，先做可逆假设并标注；只有缺失信息会改变叙事方向、交付格式或成本时才提问。

## S+ 导演制片工作流

完整项目按以下门控顺序推进：

`识别任务与硬约束 → 脚本诊断 → 优化并做剧情确认 → 节奏架构 → 视觉圣经并做视觉确认 → 场景真实感 → 调度与连续性 → 分镜与镜头语言 → 光影/色调/声音 → 生成提示词 → AI 制片计划 → S+ 质量门并做分镜确认 → 正式生产`

不得用后游成果掩盖上游问题：剧情未确认，不批量做视觉；视觉未确认，不批量生分镜；分镜未确认，不进入正式批量生成。单镜或简单请求采用最小充分模式，可把三次确认合并成一次对关键假设的明确复述。

### 1. 建立导演简报

提取并明确：

- 载体、时长、画幅、受众、平台、制作方式与资源限制
- 一句话事件、主题命题、主要 POV、类型承诺与目标余味
- 参考作品中真正要借鉴的变量：距离、节奏、光比、色彩、运动或表演强度；不要复制镜头表面
- 必须保留与必须避免的元素

以一句“导演北极星”收束：`让观众通过___的体验，在___时意识到___。`

### 2. 脚本诊断、优化与剧情确认

先按 `script-doctor.md` 标注 P0–P3 问题，修复因果链、场景功能、人物选择、视觉证据、伏笔与回收。用户给出固定结局时，把它列为不可变约束，只优化使其成立的路径。

对每场戏回答：

1. 谁在此刻想得到什么？
2. 谁或什么阻挡他？代价是什么？
3. 谁知道什么？观众比角色多知道还是少知道？
4. 场景从何种关系/情绪状态开始，以何种状态结束？
5. dramatic question（戏剧问题）是什么？
6. turn（转折）发生在哪一行为、信息或权力变化上？
7. 如果删掉这场戏，因果链损失什么？

把文本拆为可表演、可看见的 beat（节拍）：目标或策略发生变化才换 beat，不要按台词行机械切分。

在扩展完整视觉方案前提交：`保留项 / 修改项 / 修改理由 / 不变结局（如有） / 剧情确认请求`。收到剧情确认后再进入节奏和视觉设计。

### 3. 设计信息与情绪曲线

为段落安排：建立 → 期待 → 阻碍/升级 → 转折 → 余波/回报。结构是诊断工具，不是固定公式。

给每个 beat 标注：`观众问题 / 新信息 / 情绪压力 / 角色策略 / 结束变化 / 时长预算`。节奏来自信息释放、动作完成、表演停顿和声音预期，不等同于剪得快。

### 4. 写视觉论点并做视觉确认

在逐镜头前确定 3–5 条一致的视觉规则，例如：

- 前半保持旁观距离，角色撒谎后才进入主观近景
- 权力属于能占据前景并控制出入口的人
- 摄影机只在人物做出不可逆决定时移动
- 暖色只属于虚假的安全感，真相出现后让中性光侵入

同时定义一次有意义的规则破坏。规则破坏必须对应叙事变化。

把画幅、角色妆造、场景、色板、动机光、镜头规则和禁用风格汇总为视觉圣经；用户需要色卡时，按 `color-card-prompt-protocol.md` 输出精确 HEX、功能标签和纯平面设计提示词。完成视觉确认后再批量设计镜头资产。

### 5. 建立场景真实感，再调度人物和空间

先按 `scene-truth.md` 建立：`刺激 → 判断 → 目标 → 策略 → 可表演动作`。人物每次移动、停顿、回避视线和操作道具，都必须有当前刺激、意图和阻力；把抽象情绪翻译成演员能执行的动词和行为。

画出或文字描述平面关系：出入口、关键道具、遮挡、光源、人物起止点、视线轴、行动轴、屏幕方向。复杂多人或障碍物分隔的场景，先生成一张高位斜俯视 blocking diagram（调度图），锁定前/近/远/最远层、人物朝向、视线、路径、障碍和出口；它是连续性几何资产，不是美术成片。先让角色因目标和策略而移动，再为最佳观众位置选择机位。

把 blocking（调度）写成动词：逼近、回避、占领、遮挡、让路、夺回、停住。不要只写“走到窗边”。

### 6. 建立覆盖与剪辑逻辑

为每个 beat 选择最低充分覆盖：主镜头、关系双人、单人、近景、插入、反应或环境。先说明“为什么切”，再决定“切到什么”。

在画分镜前先做镜头关系链：`本镜建立的问题 → 本镜释放的信息 → 观众视线落点 → 结尾产生的期待 → 下一镜回答/延迟/反转什么`。分镜首先是可重排的叙事原型，不是精美插画。

每个镜头填写镜头契约：

`编号｜时长｜beat｜叙事功能｜主体与可见动作｜景别/机位/镜头假设｜构图与层次｜运动及动机｜声音｜入镜状态｜出镜状态｜转场/切点｜连续性风险`

**Do not invent camera movement.** 如果静止机位更能制造观察、压迫、尴尬或表演空间，就保持静止。运动必须由揭示、跟随、关系重排、主观变化或节奏需要触发。

### 7. 让光影、色调和声音共同导演

先锁定整场戏的动机光、对比与曝光意图、肤色/材质/空气规则和跨场色板进程，再允许单镜变化。规划对白、动作声、环境底、声音视角、画外声、音乐进入/退出和有意义的静默。允许声音先于画面或延迟离开，用 J-cut/L-cut 连接因果与情绪；不要把音乐当作修补不成立戏剧的胶水。

### 8. 生成可执行提示词

在任何逐镜头提示词前锁定：角色身份、服装、关键道具、场景几何、时间天气、光向、色彩规则、镜头语法和禁项。

大型复杂场景静帧不要把所有名词等权堆入长段落。先建立 scene graph，按 `成像合同 → 环境边界 → 主锚点 → 空间骨架 → 方向地标 → 功能簇 → 生命与事件 → 光线/空气 → 材质/色彩 → 摄影成像 → 禁项` 组织，并划分 P1 硬约束、P2 可识别支持信息、P3 纹理信号；用尺度—可见性预算判断微观细节是否能在当前机位成立。完整规则见 `prompt-engine.md`。

视频提示词按 `prompt-engine.md` 的标杆合同写清：`共享锁定 → 镜头目的 → 开场状态 → 单一主动作脊柱 → 主体路径 → 摄影机路径 → 前中后景构图演变 → P1/P2/P3 动态层级 → 物理视听响应 → 结束状态 → 下一镜接力点 → 本镜禁项 → 降级方案`。这里的“单一主动作”是单一因果动作脊柱，不是只能有一次肢体运动；不中断长镜头可包含按顺序发生、共同服务同一目标的微节拍。若平台/模型明确支持单节点多镜头，可用 3–5 个显式 `HARD CUT` 段落，每段都写自己的镜头契约，并共享调度图、角色/场景/色卡/声音锚点；不支持或连续性不稳时拆成独立视频节点。分别输出角色/场景/道具资产、调度图、分镜静帧、首尾帧、文生或图生视频提示；复杂动作拆镜，不在一条生成里要求多次变装、跨时空、多人精细互动和连续镜头变焦。

### 9. 建立 AI 制片计划

从成片反推资产 dependency graph，按 high-risk-first 先验证会推翻方案的镜头；为每类任务做 model routing，维护 version ledger。每个生成 attempt 必须指向父版本并声明分支类型、失败假设、唯一主变量、冻结项和回归项；换 seed 的抽样分支只能证明随机性，不能冒充已验证的修复。若使用无限画布，不要只把镜头排成线性清单：把已批准的角色、场景、道具、色卡和生物设定做成可复用 anchor hub，用带职责的连线分叉给多个镜头；把生成尝试、截帧回流、延长/变体和裁剪、去字幕、放大等精修节点保留为可追溯分支。每个高风险镜头预设 split、composite 和 fallback，只有通过表演、连续性、入出点与 handoff 检查的素材才标记 ready-for-edit。完整画布协议见 `ai-production-control.md`。

### 10. S+ 质量门与分镜确认

按 `s-plus-quality-gates.md` 做 100 分评分、五项一票否决和三遍审片：story pass、silent pass、AI production pass。S+ 必须达到 90–100，故事与钩子至少 12/15，核心 10 分项至少 8/10，且无 veto。

提交节奏、调度、分镜、视听、提示词、生产风险和评分证据，完成分镜确认后才进入正式批量生产。

### 11. 做三轮反证

1. **静音检查**：关掉对白，关系与关键信息是否仍可理解？
2. **闭眼检查**：只听声音，空间、节奏和转折是否仍有形？
3. **剪辑检查**：每个切点是否有视线、动作、声音、构图、信息或情绪依据？连续性是否足以让故意破坏规则显得有意？

## 硬性质量门槛

- 不要用“电影感、高级感、氛围感”代替可执行选择。
- 不要从景别列表开始；先给出戏剧目的、beat 与视觉论点。
- 不要把规则三分法、浅景深、低机位默认成“好看”。说明它如何改变注意力或关系。
- 不要把焦段当作独立情绪按钮。区分机位造成的透视与焦距造成的视场；缺少传感器、距离或空间信息时标注为镜头族与假设。
- 不要为了覆盖而覆盖。每个备选机位都应服务表演、信息或剪辑保险。
- 不要机械遵守 180°；先建立空间，需要越轴时说明动机，并用移动机位、中性镜头或新轴线重新定向。
- 不要让每个 beat 都同强度。保留呼吸、悬置、误导和余波。
- 不要引用具体电影镜头却凭记忆断言。需要精确复刻或比较时，查证片段、剧本或可靠来源。
- 不要把生成模型做不到的复杂连续动作伪装成可执行提示词；指出风险并拆分。

## 最小交付顺序

除非用户指定格式，按此顺序输出：

1. 导演判断：一句北极星 + 当前最大戏剧问题
2. Beat/节奏图
3. 视觉与声音规则
4. 调度与空间/连续性策略
5. 分镜或镜头表
6. 风险、替代方案与自检结论

让每一层都能追溯到上一层：镜头服务 beat，beat 服务场景转变，场景转变服务整体主题与观众体验。

## 常见失败

失败修正镜头很多但戏不推进给每镜补“观众状态改变”；补不出就删除节奏只剩“快剪”改用信息、压力、停顿、动作完成和声音预期设计波形构图漂亮却演员无事可做从人物目标、策略和空间争夺重做调度全片视觉强度恒定建立规则、递进与一次叙事驱动的破例对话戏只会正反打先找关系变化、前景权力、视线回避与关键反应AI 镜头各自好看但接不上锁定不变量，记录每镜首尾状态和接力点
