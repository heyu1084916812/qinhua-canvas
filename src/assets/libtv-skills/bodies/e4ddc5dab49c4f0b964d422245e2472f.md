# 去AI感：场景人物添加提示词指南

## 核心理念

AI默认输出存在四大通病，需通过精准提示词主动规避：

| 通病 | 表现 | 破解方向 |
|---|---|---|
| 服装模版化 | 白毛衣/黑西装/碎花裙等"出厂设置" | **服装具象化** |
| 姿态僵硬感 | 双手抱胸/叉腰/立正等机械摆拍 | **动态叙事化** |
| 质感廉价化 | 塑料皮肤/过度磨皮/不自然光影 | **场景行为化** |
| 情绪空洞化 | 假笑/空洞凝视/标准化神态 | **负面词避雷** |

---

## 使用方法

**输入**：一张已有的场景参考图（产品图/空间图/户外场景图）+ 想添加的人物设定（人数、关系、氛围）

**输出**：在保留原场景不变的前提下，生成带有自然人物互动的新图

> ⚠️ **使用前提**：必须先上传需要添加人物的场景参考图。如果用户尚未提供场景图，请先提示：「请先上传你想添加模特的场景图，可以是产品图、空间图或任意户外/室内场景图。」

---

## 第一步：判断场景规模

拿到参考图后，先判断场景规模，再选择对应的提示词模板：

| 场景类型 | 判断标准 | 皮肤描述策略 |
|---|---|---|
| **大场景 / 远景** | 人物预期占画面高度 1/4 以下；场景有明显纵深（泳池边、湖边、庭院全景、海滩等） | 简化皮肤描述，优先保证人物与场景比例一致 |
| **近景 / 中景** | 人物预期占画面高度 1/3 以上；场景以人物为主体，背景为辅 | 保留详细皮肤质感描述（毛孔、汗光、晒痕等） |

## 提示词结构模板

> 📌 **输入质量说明**：如果用户提供的人物描述是泛化写法（如"穿比基尼""站在旁边微笑"），直接按下方四个方向主动扩写为具象化提示词，无需等待用户补充细节。

### 模板 A：大场景 / 远景

```
基于{{参考图}}这张[场景描述]，保持原场景所有元素不变（[列举关键场景元素]、相机角度和取景距离不变）。

加入[人物设定]，让他们自然互动，不要摆拍：

- [人物A]：穿[具体材质+细节+磨损状态的服装描述]，正在做[具体行为动作]，[细节神态描述]；
- [人物B]：穿[具体材质+细节的服装描述]，正在做[具体行为动作]，[细节神态描述]；

[人物关系互动描述：视线交流、身体朝向呼应等]。

人物比例与场景保持一致，遵循场景景深和透视关系；
皮肤保留自然质感，避免磨皮塑料感；
光影延续原图[具体光影特征]，不要柔光棚拍效果；
不要假笑、不要空洞凝视、不要双手抱胸或叉腰的机械姿势、不要[人数]人间距均匀对称构图、不要人物过大填充画面、不要失去场景纵深感。
整体保持原图的[场景风格]摄影质感。
```

## 四个方向的具体写法

### 1. 服装具象化

❌ 避免：`穿白色T恤` / `穿连衣裙`

✅ 改为：`穿一件洗得微微泛白、领口松垂的亚麻衬衫敞口罩在橄榄色三角比基尼外，衬衫下摆打了个随意的结`

**要素**：材质 + 颜色细节 + 磨损/使用痕迹 + 穿着方式 + 搭配逻辑

### 2. 动态叙事化

❌ 避免：`站在旁边` / `坐着` / `微笑`

✅ 改为：`侧坐在躺椅边缘，光脚踩着木甲板，正低头把玩手里的鲜切菠萝片，嘴角带着看东西时不自觉扬起的笑`

**要素**：具体动作 + 动作对象 + 身体细节 + 自然产生的表情（而非刻意摆出的）

### 3. 场景行为化

❌ 避免：孤立描述人物姿势

✅ 改为：让人物与场景道具发生真实互动（倒水、整理物品、分食物、拿取道具）

**要素**：人物与场景元素的具体互动行为 + 视线/身体朝向的群体呼应

### 4. 负面词避雷（必加）

```
不要假笑、不要空洞凝视、不要双手抱胸或叉腰的机械站姿、
不要正对镜头的对称摆拍构图、不要磨皮塑料感皮肤、
不要柔光棚拍效果、不要[人数]人间距均匀对称构图、
不要人物过大填充画面、不要失去场景纵深感
```

## 实操案例参考

### 案例1：沙滩场景 + 三模特互动

- **场景**：黄色遮阳伞、条纹躺椅、木质甲板、椰子树
- **人物**：三位模特，各自有具体行为（把玩菠萝片 / 倒柠檬水 / 整理篮子），形成自然对话群体
- **关键**：三人视线交流 + 身体朝向呼应，而非各自单独摆姿势

### 案例2：庭院露台 + 情侣互动

- **场景**：黄白扇贝边遮阳伞、黑色铁艺圆桌椅、柠檬水与烘焙点心
- **人物**：情侣，男生拿柠檬水看向女生 / 女生掰点心分给男生低头笑
- **关键**：两人身体前倾呼应，营造日常对话瞬间而非摆拍
