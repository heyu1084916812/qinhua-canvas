# 人物多视图生成器

## Skill 简介

本 Skill 分两个阶段，帮助用户从人物小传出发，生成指定风格的角色母版图，再基于母版图生成进阶版多视角角色设定研究板。支持写实影视、动漫、游戏 CG、概念插画等所有风格，适用于电影前期概念、动画角色开发、游戏角色开发、漫画创作、服装复刻和 AI 视频二次生成参考。

---

## 第一阶段：人物母版图（定妆照）

### 触发条件

用户提供人物小传文本，要求生成角色母版图 / 定妆照。

### 用户输入

- 人物小传文本（包含年龄、性别气质、职业身份、时代背景、阵营来源、当前状态、性格核心等信息）
- 画面风格（如：写实影视人像 / 日系动漫 / 游戏 CG / 概念插画 / 水墨国风 / 赛博朋克等，用户自定义）

### 执行步骤

1. 从人物小传中提取以下要素，转化为可见的视觉特征：

   - 脸型、眉眼、鼻梁、嘴唇、下颌线
   - 发型、发色、肤色、体型
   - 服装主色、服装结构、标志性配饰、身份信物
   - 至少 1 个不完美或故事痕迹（如疤痕、雀斑、眼下疲惫、发丝凌乱、衣领磨损、袖口旧痕、手部老茧、配饰氧化、轻微泥点或血迹）

2. 使用以下提示词生成图像：

```
根据以下人物小传，生成一张角色中景母版图。画面必须是单人、正面面向镜头、眼睛直视镜头、头部到胸部或头部到腰部的中景构图。人物肩膀基本平行于镜头，头部正直，不要侧脸，不要 3/4 侧身，不要背影，不要全身图。
背景必须是纯色背景，白色、暖白或浅灰；光线柔和均匀，面部五官、发型、服装主结构和材质细节清楚。整体像角色定妆照 / 角色母版参考图，不是海报、写真或概念插画封面。
请从人物小传中提取年龄、性别气质、职业身份、时代背景、阵营来源、当前状态和性格核心，并转化为可见的脸部特征、发型、服装、配饰、身份符号和细节痕迹。
必须锁定 8-12 个视觉锚点：脸型、眉眼、鼻梁、嘴唇、下颌线、发型、肤色、体型、服装主色、服装结构、标志性配饰、身份信物。至少加入 1 个不完美或故事痕迹，例如疤痕、雀斑、眼下疲惫、发丝凌乱、衣领磨损、袖口旧痕、手部老茧、配饰氧化、轻微泥点或血迹。
画面风格：[画面风格]，五官比例、皮肤质感、头发层次、布料和配饰材质均符合该风格规范，服装细节丰富但轮廓干净，适合作为后续多角度角色设定和 AI 视频生成的统一人物参考。
负面要求：不要侧脸，不要 3/4 角度，不要低头，不要仰头，不要全身，不要动作姿势，不要复杂场景，不要风景背景，不要强逆光，不要霓虹光，不要文字、水印、边框、Logo。
人物小传：[粘贴人物介绍]
```

### 产出

一张指定风格的角色中景母版图（定妆照），可直接用于第二阶段输入。

---

## 第二阶段：多视图角色设定研究板

### 触发条件

用户上传母版参考图，并提供角色定位信息，要求生成多视角设定研究板。

### 用户输入

字段说明角色参考图用户上传（建议使用第一阶段产出的母版图）画面风格如：写实影视 / 日系动漫 / 游戏 CG / 概念插画等，用户自定义角色定位主角 / 配角 / 反派等世界观所处的故事世界背景职业身份角色的职业或社会身份族属/阵营/来源种族、阵营或出身背景当前状态角色当前的情绪或处境必须保留的特征不可更改的核心视觉特征必须避免的方向明确禁止出现的视觉元素输出用途电影前期 / 动画开发 / 游戏开发 / AI 视频参考等画幅推荐 2:1 或 16:9视角数量用户指定需要的视角（如正面+侧面，或正面+左侧+右侧+背面等）

### 执行步骤

1. 读取用户上传的角色参考图，识别并锁定以下核心辨识度要素：

   - 脸型、五官比例、发型、发色、肤色、体型
   - 服装主色、标志性配饰、气质与身份特征

2. 结合用户填写的角色定位信息，使用以下提示词生成图像：

```
请基于用户上传的角色参考图，生成一张 Character Turnaround / Character Design Sheet 角色设定研究板。
目标不是海报、游戏卡牌、漫画封面或 UI 页面，而是一张白底工业级角色设计图，用于电影前期概念、美术设定、动画角色开发、游戏角色开发、服装复刻和 AI 视频二次生成参考。
请严格保留参考图中角色的核心辨识度：脸型、五官比例、发型、发色、肤色、体型、服装主色、标志性配饰、气质与身份特征。所有视图、表情、特写和道具细节必须是同一个角色，不要换脸，不要换发型，不要换服装体系，不要生成另一个相似角色。
画面风格：[画面风格]，整体风格规范与参考图保持一致。

画布要求：横向超宽画布，画幅为 [画幅]，纯白或极浅灰背景，无外框、无纸张质感、无卡牌包装、无 UI 面板、无装饰边框，整体像专业角色设定表，排版清晰、模块丰富、留白干净。

整体结构包含以下模块（根据用户指定视角数量和输出用途选择适用模块）：
A. 全身视图（用户指定视角，如正面、左侧面、右侧面、背面）
B. 头部多角度
C. 表情研究
D. 面部特写
E. 服饰细节研究
F. 配饰与道具研究
G. 标志与纹饰研究
H. 手脚姿态研究

角色信息：
- 画面风格：[画面风格]
- 角色定位：[角色定位]
- 世界观：[世界观]
- 职业身份：[职业身份]
- 族属/阵营/来源：[族属/阵营/来源]
- 当前状态：[当前状态]
- 必须保留的特征：[必须保留的特征]
- 必须避免的方向：[必须避免的方向]
- 输出用途：[输出用途]
- 视角数量：[视角数量]
```

3. 生成图像需要向用户确认。

### 产出

一张横向超宽画布的工业级多视角角色设定研究板，包含用户指定视角的全身视图及相关细节模块，风格与参考图保持一致。

---

## 使用约束

- 两个阶段可独立使用，也可串联使用（第一阶段产出直接作为第二阶段输入）。
- 第二阶段必须严格保持角色辨识度，不得更换脸型、发型或服装体系。
- 视角数量完全由用户指定，Agent 不得自行增减。
- 生成过程中需要向用户逐步确认，不能直接出图。
- 画面风格由用户自定义，支持但不限于：写实影视人像、日系动漫、游戏 CG、概念插画、水墨国风、赛博朋克等。
