# 角色设定图skill

## Skill 定位

- 只负责：把用户提供的任意角色描述或参考图，转换成一张横向四视图角色设定图的完整图片提示词。
- 固定呈现结构：正面近景、正面全身、侧面全身、背面全身。
- 不为角色自行设定身份、物种、外观、服装、道具或世界观；角色内容完全来自用户输入。

## 输入

- 必需：角色文字设定、角色参考图，或两者之一。
- 可选：指定呈现风格（写实摄影、游戏CG、动画设定、概念艺术等）、背景、画幅和想强调的结构。
- 未指定时，默认使用横向 16:9、中性影棚背景、清晰专业的角色资产展示方式。

## 输入使用

- 将用户明确提供的角色身份、轮廓、比例、色彩、材质、服装、配件、道具和可见特征视为严格约束。
- 有角色参考图时，以参考图中的角色身份与设计为最高优先级；文字只补充或修改用户明确指出的内容。
- 同时提供角色参考图与风格参考图时：角色参考图负责角色一致性，风格参考图只负责渲染语言、光线和质感。
- 不擅自添加会改变角色身份的关键设计。信息不足但已能识别角色时，保持描述概括，不用无关细节填充。

## 内部流程和 Knowhow

### 1. 锁定角色资产

- 先提取并锁定角色的身份锚点：主体轮廓、核心识别部位、主色、材质、服装层次、配件与道具。
- 将所有锚点同步到四个视图；每个视图必须是同一个角色、同一时刻、同一套设计。

### 2. 固定版式结构

- 采用横向 16:9 的四栏角色设定板，统一中性背景、统一光线、统一相机高度与统一展示比例。
- 左栏约占画面宽度的 35%：正面近景，突出头部、面部、面具或最核心识别部位，以及上半身关键结构。
- 第二栏：完整正面全身/全尺寸视图，从主体最高点至最低点完整入镜，展示正面比例与整体结构。
- 第三栏：完整标准侧面全身/全尺寸视图，展示纵深、厚度、轮廓、突出结构和配件层次。
- 第四栏：完整标准背面全身/全尺寸视图，展示背部、后侧结构及仅能从后方确认的信息。
- 对非人形、机械或生物角色，将“全身”理解为主体的完整尺度，将“面部”理解为最具识别度的正面核心部位；版式逻辑保持不变。

### 3. 提示词生成

- 先写角色内容，再写版式、镜头、光线、背景与一致性约束；同一项角色细节只完整描述一次。
- 使用明确的空间关系：从左至右为正面近景、正面全身、侧面全身、背面全身。
- 用必要的负面约束消除常见错误：不出现文字、水印、额外人物、剧情场景、拼贴感、视图间角色不一致、多余肢体和主体裁切。

## 输出

- 先用一行说明已锁定的版式与默认设置。
- 再输出一段可直接用于图片生成的完整中文提示词。
- 提示词必须包含：用户提供的角色内容、四视图顺序、横向画幅、统一背景与光线、角色一致性要求，以及本次必要的负面约束。
- 除非用户要求，不输出角色卡文字、标尺、标签、说明框或多余的配件小窗。

## 自检

- 是否严格为横向四栏：正面近景、正面全身、侧面全身、背面全身？
- 四个视图是否明确为同一角色，且身份锚点、比例、颜色、材质、服装、配件与道具保持一致？
- 正面、侧面、背面是否各自提供不同且必要的结构信息？
- 全尺寸视图是否完整入镜，背景、光线、机位和缩放是否统一？
- 是否删除了文字、水印、无关剧情、额外人物、拼贴感与会破坏设定图结构的元素？
- 是否只使用了用户提供或明确允许补全的角色信息？

## Ask User

- 只有在未提供任何角色描述或角色参考图时，询问用户“要制作哪个角色的设定图？”。
- 当多张角色参考图互相冲突，且用户未说明哪张为准时，询问优先参考图。
- 当用户明确要求的版式与固定四视图结构冲突时，询问是坚持固定结构还是切换版式。
- 除以上情况外，不追问；直接按默认版式完成。
