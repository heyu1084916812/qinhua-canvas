# Multi-Character Music Video Production Skill

## Core Methodology

### 1. Character-to-Instrument Casting Logic

Assign band roles based on visual characteristics extracted from reference images:

- **Lead vocalist**: Characters with expressive faces, dramatic lighting, ritualistic poses — frontman energy
- **Drummer**: Characters with explosive visual effects (liquid melts, particle bursts) — kinetic energy output
- **Guitarist**: Characters with sharp edges, mechanical elements, cold metallic sheen — piercing high-frequency aesthetic
- **Bassist/Synthesizer**: Characters with audio visualization elements, waveform patterns, low-frequency color palettes (deep blue, dark green)
- **Stage backdrop/Logo**: Graphic-heavy images with typography or geometric compositions — becomes environmental design element

**Casting Principle**: Match visual energy signature to instrumental role. Soft-edged = ambient instruments, hard-edged = percussive/lead instruments.

### 2. Unified Aesthetic Constitution Framework

Establish immutable visual rules governing the entire video:

**Style Fusion Architecture**: Define 4-6 aesthetic layers that must coexist in every frame:

- Primary genre aesthetic (death metal brutality, electronic glitch, etc.)
- Sacred/profane contrast layer (religious iconography vs. desecration)
- Technological layer (cyberpunk neon, holographic UI, mechanical instruments)
- Organic horror layer (tentacles, bio-melt, Lovecraftian geometry)
- Particle/fluid dynamics layer (acid drips, energy particles, molten metal)
- Typography/graphic layer (integrated 3D text, not overlays)

**Transition Doctrine**: Hard cuts only, no soft fades. Symbol/text appearance synchronized to musical beat points (default: 0s, 2s, 4s, 7s, 10s, 13s). Scene shifts must be percussive, not gradual.

**Color Authority**: Define 8-10 core colors with specific hex codes and semantic roles. Example:

- Dark blood red (#8B0000) = violence/passion
- Incense gold (#C9A96E) = sacred/ritual
- Acid fluorescent green (#39FF14) = toxic/alien
- Holographic cyan (#00FFFF) = technology/future

All colors must maintain high contrast with crushed blacks and toxic/divine edge glow.

### 3. Layered Typography Integration System

**Not Overlay — Spatial Embedding**:

Typography exists in 3D scene space with real occlusion relationships:

- **Carved/Etched**: Text physically carved into church walls, floor cracks, character skin
- **Projected/Holographic**: Text as light projection on surfaces, holographic billboards in scene
- **Organic Writing**: Text formed by tentacles, liquid metal, energy particles
- **Architectural**: Text as massive 3D structures characters move through

**Layer Hierarchy Rules**:

- Characters can pass in front of/behind text
- Text must never cover eyes or primary facial expressions
- Text placement follows rule of thirds, not center-lock
- Text animation synchronized to musical beat points (slam, shake, dissolve, reassemble)

**Font Fusion Strategy**: Combine 3-4 typographic styles matching the aesthetic layers:

- Death metal spiked logos
- Gothic blackletter Latin fragments
- Acid-melted dripping letterforms
- Cold holographic circuit fonts

## Workflow

### 1. Preparation Stage

**Input Analysis Checklist**:

- Count reference images → each becomes a band member or environmental element
- Extract dominant colors from each image using histogram analysis
- Identify visual energy signatures: explosive/calm, organic/mechanical, warm/cold
- Note existing visual effects in references (glitches, particles, lighting)
- Determine if any image lacks human subject → repurpose as stage backdrop/logo

**Aesthetic Constitution Design**:

- Select 4-6 aesthetic layers to fuse (based on user's genre preference or default to extreme contrast fusion)
- Define color palette (8-10 colors with hex codes and semantic roles)
- Establish transition doctrine (hard cuts vs. motion blur swipes vs. glitch tears)
- Create beat point timeline (default 6 points across 15s: 0, 2, 4, 7, 10, 13)

### 2. Initial Design Stage

**Scene Architecture**:

- **Single-scene mode**: All characters in unified space (cathedral, cyber alley, cosmic void)
- **Dual-scene mode**: Parallel spaces hard-cutting between each other, merging at climax
- **Multi-scene mode**: Each character in separate space, converging through portal/window transitions

**Cinematography Diversity Matrix**:

Plan 8-10 distinct camera movements across 15 seconds:

 1. **Establishing shot** (0-2s): Low-angle push-in or crane-down reveal
 2. **Impact zoom** (2-3s): Handheld crash zoom on drummer with frame shake
 3. **Lateral swipe** (3-4s): Fast pan right with motion blur, guitarist reveal
 4. **Vertical travel** (4-5s): Rising shot through smoke, vocalist boots → face
 5. **Dutch angle** (5-6s): 30° tilted push on bassist, oppressive framing
 6. **Orbital track** (6-7s): 90° arc around vocalist, front → profile
 7. **Rapid intercutting** (7-8s): Hard cuts every 12 frames alternating scenes
 8. **Reveal pullback** (8-10s): Extreme close-up (eyeball) pulling to full band wide
 9. **Member carousel** (10-12s): Handheld whip cuts through 5 members, crash zoom each
10. **Final freeze push** (12-15s): Slow push into frozen climax tableau, cut to black

**Prompt Framework Structure**:

\[Duration & format\] + \[aesthetic constitution\] + \[color palette\] + \[texture/grain rules\] + \[transition doctrine\] + \[typography system\] + \[symbol/particle inventory\] + \[5-member casting with roles\] + \[10-shot cinematography sequence with timestamps\] + \[dual-scene alternation logic\] + \[climax convergence\] + \[negative constraints\]

Each section must use domain-specific terminology and concrete parameters (hex codes, degree angles, frame counts).

### 3. Iteration Stage

**Coherence Audit Dimensions**:

1. **Visual continuity**: Do all shots belong to the same aesthetic universe? Check color consistency, texture grain, lighting logic.
2. **Character identity persistence**: Are facial features, body proportions, costume details consistent across all shots?
3. **Typography integration depth**: Is text overlaid or spatially embedded? Does it have proper occlusion with characters?
4. **Cinematography diversity**: Count distinct camera movements — minimum 8 types across 15s.
5. **Beat synchronization**: Do major visual events (symbol flash, text slam, character action) align with declared beat points?

**Substitution Strategy for Problematic Elements**:

If user requests removal of specific motifs (e.g., "remove blood"):

- Identify visual function: blood = liquid splatter + red color + violence signifier
- Replace with functional equivalents maintaining visual energy:
  - Liquid splatter → molten metal, acid slime, energy particles
  - Red color → gold (sacred), cyan (tech), green (toxic)
  - Violence signifier → shattered glass, torn fabric, exploding geometry

**Storyboard Extraction Protocol**:

When generating reference frames:

- Extract at beat point timestamps (0s, 2s, 4s, 7s, 10s, 13s)
- Each frame must show: character + scene + typography + particle effects in integrated composition
- Frame composition follows cinematography plan (low-angle, Dutch angle, etc.)
- Use parallel generation for all frames to ensure style consistency

## Key Constraints & Standards

### Immutable Rules

- **Frame one identity**: Video must start with exact match to user's first reference image (character pose, lighting, composition)
- **No soft transitions**: Strictly prohibited — no fades, dissolves, cross-dissolves, or gradual opacity changes
- **Eyes always visible**: Typography and foreground elements must never cover character eyes
- **Brand sanitization**: Remove all real-world brand logos, commercial products, identifiable copyrighted text

### Fidelity Rules

- **Aesthetic layer completeness**: Every frame must contain all declared aesthetic layers (e.g., if constitution defines 6 layers, all 6 must be visually present)
- **Color palette adherence**: Only use declared hex colors; deviations limited to ±10% luminance for lighting variation
- **Texture grain consistency**: Film grain, scan lines, halftone patterns must maintain consistent intensity across all shots (no clean digital shots mixed with gritty ones)
- **Cinematography execution**: Each planned camera movement must be distinctly recognizable; avoid static or subtle movements

### Consistency Rules

- **Character appearance lock**: Face structure, skin tone, hair style, costume details must remain pixel-identical across all shots within 5% tolerance
- **Typography style coherence**: If using 4 font styles, each must serve consistent semantic role throughout (death metal = violence words, Gothic = sacred words, etc.)
- **Scene logic**: If dual-scene mode, both scenes must follow same aesthetic constitution but differ in environment (cathedral vs. cyber city, not visual style)
- **Beat point precision**: Major visual events must occur within ±2 frames of declared beat timestamps

### Optimization Thresholds

- **Minimum cinematography diversity**: 8 distinct camera movements across 15 seconds
- **Maximum single-shot duration**: 3 seconds (exceptions: establishing shot, final freeze)
- **Typography coverage limit**: Text can occupy up to 30% of frame area but must maintain readable negative space
- **Particle density threshold**: Effects should enhance, not obscure — character silhouette must remain identifiable through all particle/fluid effects
