## 运行环境说明

本skill主要在**搭建了画布功能的AI综合体网站**上使用（如即梦、可灵等支持画布节点链接的AI创作平台）。

### 画布环境特点

- 画布上可以放置多个图像节点
- 每个图像节点可以链接/引用其他节点作为参考
- 新生成的图像可以继承被链接图像的视觉特征（环境、人物外貌、光影风格等）
- 通过节点链接形成视觉连贯链条

### 画布链接引用机制（v0.1 核心新增）

**每次生成分镜图时，必须同时链接以下两张图片作为参考：**

1. **当前场景的锚点环境图**（带人物位置关系的全景图）

   - 确保环境布局、人物位置关系一致
   - 防止场景空间穿帮
   - **永久参考点**：第一张带人物的环境全景图生成后，必须链接到后续所有分镜中作为人物位置的永久参考点

2. **上一张已制作的分镜图**

   - 确保视觉风格、人物外貌、光影氛围连贯
   - 防止人物外观突变和色调跳变

链接规则

分镜类型链接锚点环境图链接上一张分镜图说明场景锚点图本身（首张）否（自身即锚点）链接上一个场景最后一张分镜保持跨场景的视觉风格连贯场景内的后续分镜✅ 必须（永久参考）✅ 必须双重保险确保连贯回忆/闪回段落首张新建锚点图链接回忆前的最后一张分镜标明时空转换回忆/闪回内的后续分镜✅ 必须（新锚点图）✅ 必须双重保险确保连贯结尾全景✅ 必须✅ 必须收尾与全片风格统一

分镜生成顺序规则（v0.1 重要新增）

**一次只生成一张分镜！禁止一次性生成多张分镜！**

- 每次只输出一张分镜图的提示词，等这张分镜生成完毕后，再生成下一张
- 不要在一次回复中同时给出多张分镜的提示词
- 生成完一张分镜后，等待确认结果，再开始下一张分镜的生成

**分镜必须严格按顺序生成，禁止跳着生成！**

1. ✅ **正确**：生成分镜1 → 等待生成完毕 → 生成分镜2 → 等待生成完毕 → 生成分镜3 ...
2. ❌ **错误1**：分镜1 → 分镜3 → 分镜8（跳着生成）
3. ❌ **错误2**：一次性输出分镜1、2、3的提示词（批量生成）

**原因**：

- 上一张分镜是下一张分镜的重要参考，必须等上一张生成完毕后才能生成下一张
- 如果一次性生成多张，后续分镜无法正确链接上一张分镜作为参考
- 如果跳着生成，会导致视觉风格和人物外貌不连贯
- 每生成一张分镜后，该分镜成为下一张分镜的"上一张分镜"

链接操作流程示例

```
[带人物的环境全景图（锚点图）]
       │
       ├──引用──→ [分镜1] ──引用──→ [分镜2] ──引用──→ [分镜3] ──引用──→ [分镜4]
       │                    ↑                  ↑                  ↑                  ↑
       └────────────────────┘──────────────────┘──────────────────┘──────────────────┘
              （锚点图永久链接 + 每张分镜同时链接锚点图 + 上一张分镜）
```

**具体操作**：

1. 在画布上放置**带人物的环境全景图**节点（锚点图）
2. 按顺序生成分镜1，链接锚点图
3. 生成下一张分镜（分镜2），同时拖拽链接**锚点图**和**上一张分镜（分镜1）**
4. 继续按顺序生成（分镜3），同时拖拽链接**锚点图**和**上一张分镜（分镜2）**
5. 以此类推，严格按顺序生成
6. 输入分镜的构图描述和提示词
7. 确保两张参考图都被正确链接后再生图
8. 检查生成结果与参考图的一致性

## 核心工作流程

### 第一步：剧本分析与场景理解

1. 仔细分析用户上传的剧本内容
2. 提取关键要素：
   - 时代背景与环境场景
   - 人物角色及其外貌特征、身份、服装
   - 人物之间的关系（对话、互动动作）
   - 剧情时间线与转折点
   - 情绪变化与叙事节奏

### 第二步：制作开场环境全景图

1. 首先制作一张**开场空镜/环境全景图**，用于交代故事发生的环境背景
2. 然后通过镜头切换（切镜），从环境全景过渡到具体场景的门牌或入口
3. 为后续分镜建立空间锚点

### 第三步：制作带有人物位置关系的全景图（锚点分镜）

**这是整个分镜流程中最核心的固定步骤！**

1. 在每个新场景开始时，必须先制作一张**带有人物位置关系的全景图**
2. 这张全景图的作用：
   - 确定当前场景的环境布局
   - 明确所有人物在场景中的位置关系
   - 为后续细分分镜提供空间参考基准
   - **作为画布链接引用的锚点节点**
3. 这张锚点分镜必须清晰展示：
   - 环境空间的整体结构
   - 每个人物的具体位置
   - 人物之间的距离和方位关系

### 第四步：分镜细化创作（带画布链接引用）

基于锚点全景图，根据剧情推进制作详细分镜。

**一次只生成一张分镜！禁止一次性生成多张分镜！**

**分镜生成必须严格按顺序进行，禁止跳着生成！**

**每制作一张分镜图，必须执行以下链接操作：**

1. 在画布上找到当前场景的\*\*带人物的环境全景图（锚点图）\*\*节点 → 拖拽链接到新生成分镜的参考输入（永久参考点）
2. 在画布上找到**上一张已制作的分镜图**节点 → 拖拽链接到新生成分镜的参考输入
3. 确认两张参考图都已正确链接
4. 输入分镜构图描述和提示词
5. 生成分镜图（**只生成这一张**）
6. 检查生成结果：
   - 环境是否与锚点图一致？
   - 人物外貌是否与上一张分镜一致？
   - 光影风格是否连贯？
7. 如不一致，调整提示词后重新生成
8. 生成成功后，该分镜自动成为下一张分镜的"上一张分镜"
9. **再开始下一张分镜的生成**

**生成顺序示例：**

- 先生成分镜1（链接锚点图）→ **等待生成完毕**
- 再生成分镜2（链接锚点图 + 分镜1）→ **等待生成完毕**
- 再生成分镜3（链接锚点图 + 分镜2）→ **等待生成完毕**
- 再生成分镜4（链接锚点图 + 分镜3）→ **等待生成完毕**
- 以此类推...

## 分镜构图规则体系

### 构图模式分类

模式一：全景交代构图（参考图一风格）

- **用途**：开场全景、场景转换、人物位置关系交代
- **特点**：展示完整环境与所有人物位置
- **适用场景**：
  - 每个新场景的开场
  - 需要明确人物在环境中的位置时
  - 群体戏、多人对话的开场

模式二：并排对话构图（参考图二风格）

- **用途**：两人或两人以上并排坐/站的对话戏
- **特点**：人物呈横向平行排列，镜头从侧前方拍摄
- **构图要点**：
  - 三个人物并排肩并肩
  - 镜头位于人物侧前方
  - 构图不居中，保留电影感
  - 背景环境信息适度呈现
- **适用场景**：
  - 面馆三人吃面场景
  - 网吧三人坐一排场景
  - 任何并排站位/坐姿的对话场景

模式三：挂肩视角构图（参考图三风格）

- **用途**：人物面对面的对话戏
- **特点**：
  - 前景是一个人物的背影/肩膀（虚化处理）
  - 后景是对话的另一方
  - 形成面对面的对话模式
- **适用场景**：
  - 回忆场景中男主与学长的对话
  - 任意两人面对面的对话戏
- **重要提示**：不要全程使用挂肩视角，需与其他构图交替使用

模式四：侧前方上半身特写构图（参考图四风格）

- **用途**：单人对话、情绪表达
- **特点**：
  - 镜头位于人物侧前方（非正面居中）
  - 拍摄人物上半身特写
  - 重点呈现人物表情与情绪
- **使用规则**：
  - 拍摄单人特写后，下一个分镜应切到**该人物所看到的画面**
  - 例如：A和B面对面 → 先拍A的侧前方特写（带情绪）→ 下一个分镜拍A看到的B
- **适用场景**：
  - 男主说话的特写
  - 老板回应的特写
  - 惊讶表情特写

模式五：低机位前景构图（参考图五风格）

- **用途**：人物倒地、特殊视角、戏剧性场景
- **特点**：
  - 低机位拍摄
  - 前景虚化（如倒地的人物和掉落的物品）
  - 后景清晰（站着的人物或观察者）
- **适用场景**：
  - 男主倒地后，前景是倒地的男主和地上的枪
  - 后景是看着这一切的男二男三
  - 制造戏剧性的叙事效果

### 提示词使用注意事项

1. **简洁至上**：不需要添加"high quality", "detailed"等修饰词，AI模型已具备基础画质能力
2. **位置精准**：明确说明人物在画面中的位置（左侧/右侧三分之一处）
3. **基于锚点**：所有提示词必须引用锚点环境图作为参考
4. **人物参照**：如涉及特定人物，需同时引用人设图
5. **保持一致**：前后分镜的人物位置、朝向必须逻辑连贯
6. **顺序生成**：严格按分镜1→2→3的顺序生成，禁止跳着生成
7. **双图链接**：每张分镜必须同时链接锚点环境图 + 上一张分镜

## 核心创作原则

### 原则一：分镜必须展示「事件的开始」

**这是最核心的规则！**

1. 分镜图必须展示**事件的起始状态**，绝不能展示事件进行到一半的状态
2. 错误示例：直接拍摄B被A击杀的过程
3. 正确示例：
   - 先拍摄B紧张地走在机房里（事件开始）
   - 然后通过AI视频模型完成击杀过程
   - 分镜只需要「开头」，不需要「过程」
4. 具体应用：
   - 男主掏钱结账的场景 → 分镜拍摄男主正在吃面的画面，而不是直接拍掏出支票的画面
   - 男主倒地的场景 → 分镜拍摄男主开始倒地的起始状态

### 原则二：人物位置关系不能穿帮

1. 每个分镜中的人物位置必须与锚点全景图保持一致
2. 当分镜拍摄A、B、C三人时，需注意：
   - 如果上一个分镜中人物看着画面的右边
   - 下一个分镜（该人物看到的画面）中，相关人物应位于画面的右侧三分之一处，看向画面的左边
3. 确保所有分镜中的人物位置逻辑连贯

### 原则三：画布链接引用防穿帮（v0.1 新增）

**每次生成分镜图时必须链接两张参考图：**

1. **锚点环境图**（当前场景的带人物位置全景图）

   - 作用：锁定环境布局和人物空间关系
   - 防止：场景穿帮、人物位置混乱

2. **上一张分镜图**

   - 作用：保持视觉风格和人物外貌连贯
   - 防止：人物长相突变、服装变化、光影跳变

3. **特殊情况处理**：

   - 场景第一张分镜（锚点图本身）：不需要链接锚点图（自身即锚点），但需链接上一个场景最后一张分镜保持整体风格
   - 回忆/闪回开始：建立新锚点图，链接回忆前最后一张分镜
   - 平行剪辑：两组画面交替时，各自维护自己的锚点图和上一张分镜链

4. **链接后的检查**：

   - 生成图片后对比锚点图：环境结构是否一致？
   - 生成图片后对比上一张分镜：人物外貌是否一致？
   - 如发现不一致：调整提示词，强调"与参考图保持一致"后重新生成

### 原则四：构图避免规整，追求电影感

1. 不要使用居中对称构图
2. 采用三分法、黄金分割等构图原则
3. 预留画面呼吸空间
4. 光影处理要符合场景氛围
5. 适当使用框架构图（从门外拍包间内部等）

### 原则五：正反打对话模式

适用于人物面对面或非并排站位的对话场景：

1. 先拍摄A的上半身特写（给出情绪表情）
2. 切到A看到的画面（B或A关注的对象）
3. 再拍摄B的上半身特写
4. 切到B看到的画面（A）
5. 形成交替的对话节奏

### 原则六：固定镜头时间跳跃手法

用于制造叙事时间感和节奏感：

1. 使用固定镜头拍摄某一动作的开始
2. 角色挣脱或离开画面
3. 下一个分镜跳过中间过程
4. 直接展示时间跳跃后的结果状态
5. 示例：
   - 男二挣脱男三跑出画面（固定镜头）
   - 下一张分镜直接是高空俯拍三人倒地不起

### 原则七：分镜起始必须是带位置关系的全景

每个新场景或新段落的分镜制作流程：

1. **先制作带位置关系的全景图**（锚点分镜）
2. 分析剧情中哪些人在对话或有关联
3. 根据分析结果进行细分分镜创作
4. 所有分镜的人物位置必须参照锚点图
5. **所有后续分镜生成时必须链接锚点图 + 上一张分镜图**

## 质量检查清单

在完成分镜创作后，需检查以下内容：

### 分镜内容检查

- \[ \] 每个新场景是否都有锚点全景图？
- \[ \] 分镜是否都展示事件的「开始」而非「过程」？
- \[ \] 人物位置关系是否与锚点图一致？
- \[ \] 构图是否避免了居中对称？
- \[ \] 对话戏是否使用了正反打或挂肩视角？
- \[ \] 人物表情和情绪是否连贯？
- \[ \] 光影风格是否统一？
- \[ \] 是否有使用固定镜头时间跳跃手法增强叙事？

### 画布链接检查（v0.1 新增）

- \[ \] 每张分镜图是否都正确链接了当前场景的锚点环境图（永久参考点）？
- \[ \] 每张分镜图是否都正确链接了上一张分镜图？
- \[ \] 是否一次只生成了一张分镜，没有一次性生成多张？
- \[ \] 分镜是否严格按顺序生成，没有跳着生成？
- \[ \] 场景切换时锚点图是否已更新为新场景的锚点？
- \[ \] 回忆/闪回段落是否有独立的锚点图？
- \[ \] 回忆结束回到主场景时是否切回原场景锚点图？
- \[ \] 生成图片后是否检查了与参考图的环境一致性？
- \[ \] 生成图片后是否检查了与上一张分镜的人物外貌一致性？
- \[ \] 修改镜头位置时是否使用了正确的提示词格式？

## 使用说明

当用户提供：

1. 人设描述（人物外貌、服装、身份等）
2. 剧本文本
3. 具体需求说明

按以下步骤执行：

 1. 分析剧本，提取关键要素
 2. 逐个场景制作**带人物的环境全景图（锚点图）**
 3. 将锚点图放置在画布上作为永久参考节点
 4. **一次只生成一张分镜！禁止一次性生成多张分镜！**
 5. **严格按分镜1→2→3→4的顺序制作分镜**，禁止跳着生成
 6. **每张分镜生成时必须同时链接：锚点图（永久参考） + 上一张分镜**
 7. 每个分镜附带构图说明和画布链接说明
 8. 生成完一张分镜后，等待确认结果，再开始下一张分镜
 9. 如需修改镜头位置，使用「修改镜头位置提示词模板」
10. 输出完整分镜脚本
11. 可选择使用即梦seedance2.0模型将分镜转为视频
