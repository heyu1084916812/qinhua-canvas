# 电商产品展示视频 Skill

## Skill 定位

- 只负责：将**单个产品**（任何电商品类）的产品图 + 卖点信息，转换为一支**15-30秒高转化产品展示短视频**，适用于信息流广告、商品详情页主图视频、短视频挂车
- 不负责：口播达人带货（真人出镜讲解）、剧情种草类视频（需要演员/故事线）、多产品合集对比视频、长直播切片

## 输入

用户必须提供：

1. **产品参考图**：至少1张（产品主图/白底图/场景图，越清晰越好；多图可分别提供正面/侧面/细节/包装）
2. **产品名称**：品牌+品名（如"小米手环9 Pro"）
3. **品类**：美妆护肤 / 3C数码 / 食品饮料 / 家居日用 / 服饰鞋包 / 母婴玩具 / 其他

建议用户提供（没有则由AI根据品类合理推断）： 4. **核心卖点（1-3条）**：每条不超过15字，按优先级排序（如"24小时续航""IP68防水""1.74英寸AMOLED大屏"） 5. **价格锚点**（可选）：日常价 / 活动价 / 折扣力度 6. **目标人群**（可选）：如"25-35岁上班族女性""学生党""银发族" 7. **视频风格偏好**（可选）：高级质感 / 活泼种草 / 简约科技 / 温暖治愈 / 快节奏卡点；默认根据品类自动匹配 8. **CTA文案**（可选）：如"点击下方小黄车""限时特惠立即抢购"；默认用通用引导

## 输入使用

- **产品参考图**：作为视频生成的核心视觉锚点（全能参考/角色参考模式），所有镜头中产品外观必须严格还原参考图，不得擅自改变颜色、造型、Logo位置、包装设计
- **核心卖点**：决定镜头叙事顺序和演示重点——第1卖点对应最核心的展示镜头（最长时长），其余卖点各分配1个演示/特写镜头
- **品类**：决定视觉风格、BGM调性、镜头语言和字幕样式（见"品类适配参考"）
- **价格锚点**：出现在片尾CTA定格画面；如有活动价/原价对比，用"原价\~划线+活动价高亮"视觉处理
- **目标人群**：影响画面色调、模特手型/肤色（如有手持镜头）、字幕字体选择、BGM风格
- **风格偏好**：覆盖默认品类风格，但不得偏离电商产品展示的专业感（不能做成搞笑/鬼畜/纯艺术片）
- **未提供的字段**：AI根据品类常识合理补充，但产品名称、外观、核心卖点绝对不能编造——缺信息必须在Ask User阶段询问

## 内部流程和 Knowhow

### Step 1：信息校验与卖点提炼

1. 检查产品图清晰度和角度，判断是否需要用户补图（如只有正面无侧面则在Ask User中提示）
2. 将用户提供的卖点（如有）精炼为"画面可展示"的语言——抽象卖点（如"好用""舒服"）必须转化为可视觉化的具体表现（如"水滴自动滚落→防水""一秒折叠→便携"）
3. 如果用户未提供卖点，根据产品图+品类+产品名称，先**向用户确认**3个推断卖点再继续（走Ask User）

### Step 2：黄金结构分镜设计（15-30秒）

严格遵循电商产品展示视频的"5秒钩子定律"——前5秒必须留住用户，否则直接划走。

**标准5段式结构**（总时长按卖点数量在15-30秒内弹性调整）：

段落时长占比功能必备元素**①钩子开场**0-3秒抓住注意力产品最高颜值角度+冲击性视觉（光效/水溅/慢动作/微距）+钩子字幕（痛点提问或效果冲击，如"黑头终于有救了！"）**②产品亮相**3-7秒建立产品认知产品360°旋转展示 / 开箱拆封 / 从包装盒中取出；品牌Logo清晰可见；配品类标签字幕**③核心卖点演示**7秒-结束前5秒说服购买每个核心卖点1个镜头，按优先级排列；卖点间用快切/转场衔接；演示要"看得见效果"（防水→水滴/浸泡；续航→时间数字变化；轻薄→对比参照物）**④信任背书/使用场景**卖点中穿插或合并降低决策门槛真人手持使用（只出现手，不出全脸，规避数字人风险）/ 多场景快切（居家/办公/户外）/ 细节特写（材质纹理/接口/按键）**⑤CTA收尾**最后3-5秒促转化产品定格拉大+核心卖点浓缩字幕+价格信息+CTA按钮动效（如"立即抢购"脉冲放大）；背景音乐在此处加入"叮"的提示音效

### Step 3：镜头语言规范（详见《镜头库参考.md》）

- **运镜**：产品展示以微距特写+环绕旋转+推镜为主，避免无意义的大场景空镜；运镜稳，不要手持抖动（除非用户要求"真实开箱感"）
- **光线**：产品主光45°侧光打亮产品质感，轮廓光分离产品与背景，暗调高级品类用侧逆光勾勒轮廓，食品类用暖光+侧逆光凸显质感
- **背景**：纯色/渐变/简洁场景（不得喧宾夺主）；高端品类用深色/黑底，平价快消用浅色/马卡龙色
- **转场**：硬切为主，卖点之间可用闪白/光效/匹配剪辑转场，不使用花哨的翻页/旋转/分屏转场
- **字幕**：居中或底部1/3处，字号大（手机端可读），加粗无衬线字体，关键数字/价格用品牌主色高亮；不超过2行

### Step 4：视频生成提示词书写（详见《提示词规范参考.md》）

- 使用英文书写视频生成提示词（中文可能导致渲染异常）
- 结构：【镜头景别+运镜】+【产品精确外观描述（锚定参考图）】+【动作/演示过程】+【光线/背景/色调】+【画面质感参数】
- 每镜独立提示词，按时间轴编号（Shot 01/02/03...）
- 负面词统一追加：`no text watermark, no logo other than product brand, no distorted product shape, no extra limbs, no human face close-up, no cartoon style unless specified, low quality, blurry`

### Step 5：BGM与节奏建议（写入分镜备注，由视频后期/AI配乐匹配）

- 快消品/食品：BPM 120-140，轻快明亮，卡点剪辑
- 美妆护肤：BPM 90-110，高级感电子/轻奢钢琴
- 3C数码：BPM 100-120，科技感电子/未来感
- 家居日用：BPM 80-100，温暖轻快/治愈系
- 服饰鞋包：BPM 110-130，时尚节拍/Lo-fi Hip Hop
- 片尾CTA：BGM音量微降+加入提示音效（whoosh/叮/叮咚）

### Step 6：品类差异化适配（详见《品类适配参考.md》）

不同品类有固定的"高转化镜头范式"，必须遵守：

- **美妆护肤**：质地特写（膏体拉丝/液体流动/泡沫绵密）→上肤前后对比（只展示局部皮肤，不出全脸）→质地吸收过程微距
- **3C数码**：开箱拆封→产品正面45°展示→接口/按键特写→屏幕点亮→功能演示→轻薄/防水等卖点可视化
- **食品饮料**：开盖/撕开瞬间（蒸汽/汁水慢动作）→食材特写（纹理/色泽）→倒入/夹取/咬开（爆浆/拉丝/酥脆碎裂）→满足表情（仅嘴部以下）
- **家居日用**：产品静止展示→使用前痛点场景（凌乱/脏污/不便）→使用过程演示→使用后整洁效果→多场景展示
- **服饰鞋包**：产品平铺/挂拍展示→面料细节特写→上身效果（模特展示全身/半身，不拍全脸）→搭配展示→行走/动态展示
- **母婴玩具**：柔和暖光→材质安全特写（圆润边角/无毛刺）→儿童使用（需家长手部陪同出镜，避免儿童单独操作危险物品）→亲子互动温馨场景

## 输出

产出一支完整的电商产品展示短视频分镜方案，包含：

1. **视频基础信息**：产品名、品类、目标时长（秒）、风格关键词、BPM建议
2. **分镜表**（markdown表格，每镜一行）：
   - 镜号 | 时长 | 景别 | 运镜 | 画面内容（中文描述）| 字幕文案 | 提示词（英文）| 音效/BGM备注
3. **视频生成提示词**：每镜独立英文提示词，直接可用于LibTV视频生成节点
4. **片尾CTA设计**：定格画面布局描述+字幕文案+动效说明
5. **剪辑节奏说明**：转场方式、卡点建议、整体节奏曲线

## 自检

输出前必须检查：

- \[ \] 产品外观在每镜提示词中是否与参考图一致（颜色/造型/Logo/比例不跑偏）
- \[ \] 前3秒是否有强钩子（视觉冲击+钩子字幕），不能平淡开场
- \[ \] 核心卖点是否全部覆盖，且第一卖点给到了最核心/最长的演示镜头
- \[ \] 卖点演示是否"画面可感知"——避免"XX效果好"这类无法视觉化的描述
- \[ \] 字幕是否简洁（≤2行）、字号够大、不遮挡产品主体
- \[ \] 是否出现了人脸特写（禁止，除非品类必须且用户同意）
- \[ \] 总时长是否在15-30秒范围内（短信息流优先15秒，详情页主图视频可到30秒）
- \[ \] 负面词是否每镜都有追加
- \[ \] 提示词是否为英文书写
- \[ \] CTA是否清晰明确（告诉用户下一步做什么）
- \[ \] 是否编造了用户未提供的产品参数/功效/认证（如"FDA认证""医生推荐"等无依据信息绝对禁止）
- \[ \] 价格信息是否准确（仅使用用户提供的价格，不得编造折扣力度）

## Ask User

遇到以下情况必须暂停并向用户确认，不得自行编造：

1. 用户未提供产品图 → 提示上传至少1张产品主图
2. 用户提供了产品但未给卖点，且AI无法从产品图+名称推断出具体卖点 → 给出3-5个候选卖点让用户勾选/补充
3. 产品图模糊/角度严重缺失（如只有包装盒无产品本体） → 提示补图
4. 产品属于特殊品类（药品/医疗器械/保健品/食品）需要合规声明 → 向用户确认是否有相关资质，并在视频中加入必要的免责提示（如"本品不能代替药物""个体效果因人而异"）
5. 用户要求出现真人全脸/全身体验 → 确认是否接受AI数字人/手部出镜替代，规避肖像权风险
6. 卖点涉及无法视觉化的抽象功能（如"AI智能""云端同步"） → 与用户确认是否同意使用图形化UI动效/图标叠加表现
