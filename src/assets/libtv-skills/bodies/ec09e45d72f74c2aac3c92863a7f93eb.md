## name: script-to-seedance description: 将原始短剧或剧集剧本优化为带镜头规划的正式剧本，并进一步转换为可直接用于 Seedance 视频生成的 A24 实拍感结构化分镜。用于处理原始剧本、复核或继续加工已优化剧本、生成逐镜 Seedance 提示文档，以及执行完整的“剧本优化→最终分镜”两阶段流程；支持 Markdown 剧本和用户直接粘贴的文本。

# 剧本转 Seedance 分镜

严格执行两阶段流水线，保留原始台词、镜头顺序、镜头等级和时间分配。将详细创作规则留在参考文件中，按任务需要读取。

## 判断任务入口

1. 用户提供原始剧本并要求完整成品：依次执行阶段一和阶段二。
2. 用户只要求优化剧本：仅执行阶段一。
3. 用户提供已经包含“镜头节奏速览表”和“正式镜头表”的优化剧本：跳过阶段一，直接执行阶段二。
4. 用户只要求复核：读取对应参考文件进行检查，不擅自重写。

若输入不完整但仍可合理推导，明确列出最少量假设后继续。只有缺少剧本正文或关键台词等会改变成品的内容时才请求补充。

## 阶段一：优化剧本

完整读取 references/stage1-script-optimization.md，将用户剧本作为其中的输入剧本执行。

必须做到：

- 原样保留既定台词，不增删、不改写。
- 输出规定的十二个章节；“八、镜头节奏速览表”和“九、正式镜头表”必须存在。
- 让场景名称、镜头编号、时间区间、时长和 A/B/C 级别前后一致。
- 严守各等级镜头时长上限，并完成参考文件规定的自检门。
- 不输出阶段一内部推导过程，只输出最终优化剧本。

阶段一输出是阶段二唯一的剧情与镜头依据。不得在阶段二擅自修订阶段一的剧情结构。

## 阶段二：生成 Seedance 分镜

完整读取 references/stage2-seedance-storyboard.md，将阶段一成稿或用户提供的优化剧本作为输入执行。

必须做到：

- 按标题定位“镜头节奏速览表”和“正式镜头表”，并用标准编号八、九进行校验。
- 不遗漏、合并、拆分或重新排序输入镜头。
- 保持每个镜头的编号、时间区间、时长和叙事等级不变。
- 只输出一次本集全局资产表；单镜头使用资产 ID 引用，并只记录状态差异。
- 区分叙事等级 A/B/C 与运镜等级 M-A0/M-A1/M-B/M-C。
- 从 16mm 或 35mm 胶片模拟中作出明确选择，并为每镜选择一种焦距。
- 保留人物身份、角色定位、权力感、身体状态、情绪变化、音色和语速等完整表演信息。
- 对照输入逐字检查台词；不得让表演提示取代或改写原台词。
- 输出参考文件规定的逐镜 Seedance 文档，不输出分析过程。

## 交付与校验

在交付前逐项核对：

- 十二个章节完整，八、九章可被标题识别。
- 01 与 02 的镜头数量和顺序完全一致。
- 各镜头起止时间连续，总时长一致。
- 所有场景名称来自阶段一的场景清单。
- 所有资产引用都能在全局资产表中找到。
- 运镜编码只使用 M-A0、M-A1、M-B、M-C。
- 胶片介质与镜头焦距没有混写。
- 所有既定台词与输入逐字一致。
- Markdown 表格包含表头、分隔行、数据行和完整竖线。

发现错误时先修正并重新完整校验，交付时不要附带失败版本。

用户要求保存文件但未指定名称时，使用：

- `01-优化后剧本-[集名].md`
- `02-Seedance最终分镜-[集名].md`

若只执行一个阶段，只生成对应文件。
