## 需要什么输入

**最少提供（三选一即可开工）：**

- 一句话故事想法
- 粗略故事框架或大纲（几句话讲清起承转合）
- 基础分镜草稿（哪怕只有几行镜号+画面简述）

**可选提供（给了就采用，没给就按专业默认补全，不反复追问）：**

- 类型题材、目标总时长、画幅比例（16:9 / 9:16 / 2.35:1）
- 风格参考（参考影片、导演风格、影调色调）
- 角色设定、现成对白、指定配音风格
- 投放平台（院线 / 抖音 / 快手 / 视频号 / 广告渠道）
- 已有素材（人物定妆照、场景照片、道具图——有则作为锚点基准图）

## 怎么做

按以下九个阶段顺序执行。阶段一\~六产出专业分镜脚本；阶段七\~九把分镜变成视频。

### 阶段一：剧本拆解（叙事骨架）

1. 把输入拆成**节拍表（Beat Sheet）**：开场钩子 → 建置（人物/环境/矛盾）→ 激励事件 → 递进冲突 → 中点转折 → 危机最低点 → 高潮爆发 → 收束/余韵。
2. 短内容（≤60s）至少保证：**前 3 秒钩子 + 一个反转/情绪爆点 + 一个余韵收尾**。
3. 标注每场戏的**情绪曲线**（压抑→积蓄→爆发→回落），分镜节奏必须服务这条曲线。
4. 确定叙事视角（单一主角 POV / 上帝视角 / 双视角交叉），全片不无故跳视角。
5. **按总时长反推镜头组数量**：总时长 ÷ 15s ≈ 组数，每个节拍点分配到具体的组。

### 阶段二：建立四大锚点（一致性核心，最高优先级）

锚点是一切一致性的地基。**先建锚点，再写分镜，再生素材，顺序不可颠倒。**

2.1 人物锚点（Character Anchor）——锁人物一致性

每个有台词或特写超过 2 秒的角色，建一张锚点卡：

字段写法要求锚点 ID格式 `CHAR-A`、`CHAR-B`，全片引用姓名/身份一句话年龄感例：「30 岁出头，眼角有细纹」脸型五官具象可视觉化，例：「瘦长脸，高颧骨，单眼皮，右眉尾有一颗小痣」发型发色例：「黑色短寸，鬓角微白」体型姿态例：「瘦高，习惯性微驼背」标志性服装精确到颜色材质，例：「藏蓝色工装外套，左袖磨白，内搭灰T恤」随身道具例：「屏幕碎裂的旧手机，胸前挂工牌」习惯性动作例：「紧张时用拇指反复摩挲手机边缘」

**铁律：**

- 锚点卡 30\~60 字，全部是可视觉化的具象描述，禁止「帅气」「沧桑」类抽象词。
- 分镜中每个镜头涉及该角色时，画面描述**逐字复制锚点原文**，禁止改写、省略、同义替换。
- 剧情导致外观变化（受伤/换装/时间跨度）→ 生成 `CHAR-A-v2` 新锚点卡，标注变化原因与生效镜号。
- 任何镜头不得出现锚点之外的新外观描述。

2.2 场景锚点（Scene Anchor）——锁场景一致性

字段写法要求锚点 ID格式 `SCENE-1`、`SCENE-2`地点例：「老城区居民楼顶层天台」时间具体到时辰天色，例：「傍晚 7 点，天光将尽，蓝调时刻」光源与色调例：「对面楼暖黄灯光为主光源，环境偏冷蓝，高反差」关键陈设3\~5 件地标性陈设，例：「生锈铁皮水箱、晾衣绳上滴水的白衬衫、墙角一箱空啤酒瓶」氛围关键词例：「潮湿、闷热、城市的喘息声」

**铁律：**

- 同一场景每次入镜，画面描述开头**逐字复用场景锚点原文**。
- 场景内时间/光线推进 → 生成 `SCENE-1-v2`，标注变化。
- 陈设位置全片保持空间逻辑一致（水箱在画面左侧就永远在左侧，配合轴线）。

2.3 道具锚点（Prop Anchor）——锁关键道具一致性

凡是在 2 个以上镜头出现、或承担叙事功能的关键道具，建锚点卡：

字段写法要求锚点 ID格式 `PROP-1`、`PROP-2`名称例：「泡皱的生日贺卡」外观细节具象可视觉化，例：「米白色卡纸，边缘被雨水泡皱卷起，蓝色钢笔字迹晕开」叙事功能例：「全片情感爆点载体」状态变化例：「GROUP-01 完好 → GROUP-03 被雨水打湿 → GROUP-05 被抚平」

**铁律：** 道具每次入镜逐字复用锚点原文；状态变化必须与其出现的镜头组时间码对应，不得出现「上一组湿了、下一组又干了」的穿帮。

2.4 配音锚点（Voice Anchor）——锁声音一致性

每个有声角色（含旁白）建一张配音锚点卡：

字段示例角色CHAR-A 陈默音色音高「低沉沙哑的男中音」年龄感「40 岁上下，声带带轻微烟酒感」语速节奏「偏慢，句与句之间有半拍停顿」口音/语言「轻微北方口音，偶尔吞字」气息特征「句尾气息下沉，疲惫感」情绪基调「克制、压抑，爆发前声音反而更轻」

**铁律：** 分镜表中该角色每句台词后括号标注 `(配音：CHAR-A锚点 + 当下情绪)`，当下情绪只允许在锚点基调上做加减（如「更哑」「几乎耳语」），不得偏离锚点基底。

### 阶段三：划分镜头组（Group）——全片结构单元

1. **每组总时长 ≤15 秒**，由若干 1\~3 秒镜头组成（通常 4\~10 镜/组）。
2. 组的两层意义：
   - **制作单元**：一组对应一次 AI 视频生成或一个生成批次；
   - **节奏单元**：一组完成一个微型呼吸（起→承→小落点），组与组之间是全片节奏换气口。
3. 每组开头必须写**组头信息卡**：

```
GROUP-01 | 时间码 00:00-00:12 | 总时长 12s | 镜头数 6
戏剧功能：开场钩子 + 建置人物处境
情绪节拍：压抑、悬念
主场景：SCENE-1（天台）
出场锚点：CHAR-A、PROP-1
环境音基调：雨后滴水声 + 远处车流低鸣（贯穿全组不间断）
组内衔接策略：景别远→近递进，镜5情绪爆点，镜6静音收尾
组间衔接：J-cut——GROUP-02 的雨声在 00:11.5 先入
所需素材：SCENE-1 场景图、CHAR-A 定妆图、PROP-1 道具图
```

4. **组内衔接规则：**
   - 镜头间默认硬切，遵循动作匹配/视线匹配/30° 规则；
   - 组内景别按「远→近」递进（积蓄情绪）或「近→远」释放（情绪落地），一组只走一个方向；
   - 同组同场景时，环境音跨镜头连续不间断。
5. **组间衔接规则（每组末尾必须标注）：**
   - 优先 **J-cut**（下一组声音先入）或 **L-cut**（本组声音延续）实现无缝换气；
   - 场景大跳转用**声音桥**或**空镜缓冲组**（整组 1\~2 个空镜）过渡；
   - 时空跳跃用匹配剪辑（图形/动作/声音相似）；
   - 禁止两组之间毫无衔接设计的「裸跳」。

### 阶段四：分镜设计（镜头语言库）

**时长精度规则：**

- 每镜 **1\~3 秒，精确到整秒或半秒**（如 1.5s）；
- 唯一例外：情绪特写/爆点镜可到 4 秒，必须在剪辑备注写明动机；
- 每镜标注**绝对时间码**；全片从 00:00 起连续无缝，无空隙无重叠（叠化除外，需标注重叠时长）。

**景别（由远到近）：** 大远景（环境/孤独）→ 远景/全景（人物与环境关系）→ 中景（叙事主力）→ 近景（表情情绪）→ 特写/大特写（情绪爆点、关键道具、细节伏笔）。

**角度：** 平视（共情）｜俯拍（弱势/压迫）｜仰拍（强势/威胁）｜荷兰角（失衡不安，全片≤3 次）｜鸟瞰（命运感）｜POV（代入）｜过肩（对话关系）。

**运镜（1\~3 秒镜头以单一运镜为主，禁止一镜堆多种）：** 推（逼近真相）｜拉（抽离孤独）｜摇（展示空间）｜移/跟（陪伴行进）｜升降（格局变化）｜环绕（关系张力）｜手持（纪实紧张）｜固定（克制凝视）｜变焦（间离年代感，慎用）。

**构图：** 三分法（常规叙事）｜居中对称（仪式感）｜框架式（门窗框人，暗示困住）｜负空间留白（孤独悬念）｜纵深调度（前中后景三层信息）。

### 阶段五：镜头衔接与转场（剪辑逻辑）

**剪辑铁律：**

1. **180° 轴线**：关系戏不越轴；要越轴必须给骑轴镜头或运动越轴过渡。
2. **30° 规则**：同主体相邻两镜机位角度变化 ≥30°，否则换景别（故意跳切需标注「风格化跳切」）。
3. **动作匹配剪辑**：上一镜动作中段切出、下一镜接续完成——1\~3 秒短镜头衔接的主力手法，跨镜动作必须写清「切出帧动作」和「切入帧动作」。
4. **视线匹配**：A 看向画右 → 下一镜 B 在画左回望。
5. **正反打**：对话戏按「过肩A→过肩B→近景A→近景B」呼吸式推进，情绪升级时景别逐级收紧。

**转场库（每镜入点和出点都要标注）：** 硬切（默认，占 80%+）｜叠化（时间流逝/回忆，标注重叠时长）｜淡入淡出（开场结尾/段落大分隔）｜匹配剪辑（时空跳跃）｜甩镜/遮罩（快节奏段落）｜J-cut｜L-cut｜声音桥/空镜。

### 阶段六：节奏与声音设计

**镜头时长配比：** 动作/追逐 1\~1.5s｜常规叙事/对白 2\~3s｜情绪戏/特写 3s（爆点镜可到 4s 须备注）｜空镜 1.5\~2.5s｜竖屏短剧整体偏下限（1\~2s 为主）。

**节奏曲线规则：**

- 开场第一组前 3 秒必须出钩子（悬念画面/冲突动作/反常细节）；
- 连续 3 个以上同景别同时长的镜头是节奏事故，必须打破；
- 高潮段：组内镜头越来越短（3s→2s→1s）、音效越来越密；爆点前 1\~2 秒**抽掉所有声音**（静音是最强的重音）；
- 爆点后给一个 3 秒长镜或空镜组让观众喘息（余韵）；
- 全片最后一组：呼应第一组（环形结构）或留白（开放结局）。

**四层声音（每镜标注，没有就标「无」）：**

1. **对白/配音**：台词 + 配音锚点 + 当下情绪；
2. **环境音**：以组为单位设基调，组内连续不间断，组间 J-cut/L-cut 渐变交接；
3. **拟音/音效**：标注精确出现时间码（如「00:07.5 水滴落在蛋糕盒上」）；
4. **音乐**：情绪走向、乐器质感、进入/退出时间码（精确到组与秒）。

**声音原则：** 音效有层次（近/中/远）；重要音效前用「安静」做对比；对白戏音乐压在铺底层级，不抢人声。

### 阶段七：素材图片建立（从分镜到视觉资产）

**全部分镜脚本定稿后**，按下述流程把文字锚点变成视觉资产：

1. **建立素材清单**：从四大锚点表导出《素材需求总表》，逐项列出：
   - 人物定妆图：每个 CHAR 锚点至少 1 张**基准定妆图**（正面半身或全身，光线中性，清晰展示锚点卡全部外观特征）；外观有 v2 变化的每个版本各 1 张；
   - 场景图：每个 SCENE 锚点 1 张**空镜基准图**（无人物，完整体现时间/光源/陈设/氛围）；
   - 道具图：每个 PROP 锚点 1 张**道具特写图**（每个状态版本各 1 张）。
2. **素材图生成规范**：
   - 生成提示词 = 锚点卡原文 + 画幅 + 影调风格 + 「照片级真实质感，真人影视画面」；
   - 同一角色的所有素材图必须基于同一张基准定妆图做图生图衍生，禁止每次纯文生图重新抽卡；
   - 全片素材图统一影调（在项目信息表中锁定一个影调描述词串，所有素材提示词末尾追加同一词串）。
3. **验收标准**：素材图与锚点卡逐项比对，任一字段不符即重新生成；人物素材图之间做「同一人」目检。
4. **素材命名规范**：`CHAR-A_基准.png`、`CHAR-A-v2_基准.png`、`SCENE-1_空镜.png`、`PROP-1_状态1.png`——文件名即锚点 ID，后续镜头组按 ID 引用，禁止口头描述指代。

### 阶段八：素材与镜头组匹配 → 逐组生成视频

1. **匹配连接**：为每个镜头组建立《组-素材对照表》：

```
GROUP-01 所需素材：SCENE-1_空镜.png（场景基准）、CHAR-A_基准.png（人物基准）、PROP-1_状态1.png
GROUP-02 所需素材：SCENE-1_空镜.png、CHAR-A_基准.png、CHAR-B_基准.png
……
```

规则：组头信息卡的「出场锚点」与素材文件一一对应；任何一个镜头组不得引用尚未生成的素材。

2. **逐镜头生成提示词组装**，每个镜头的最终生成提示词按固定公式拼装：

```
【场景锚点原文】+【人物锚点原文】+【道具锚点原文（如出场）】+ 主体动作与表演细节 + 景别/角度/运镜 + 光影变化 + 氛围词 + 画幅与影调统一词串 + 「照片级真实质感，真人影视画面」
```

3. **生成方式选择：**
   - 有对应素材图的镜头 → **图生视频**：以素材图作为首帧/参考图，提示词只写「动作 + 运镜 + 时长」，一致性交给图片锁；
   - 无素材图的过渡空镜 → 文生视频，提示词用完整公式；
   - 每镜生成时长按分镜表时长执行（1\~3 秒），单组内镜头逐个生成、按时间码命名归档（`G01-S03.mp4` = GROUP-01 镜 3）。
4. **连续性保障：**
   - 同组内相邻镜头保持上一镜的出点状态（如运镜方向、人物位置）写入下一镜提示词；
   - 跨镜动作匹配的镜头，把「切出帧动作」写明给两个镜头共用；
   - 组间 J-cut/L-cut 的声音设计在整合阶段实现，画面生成阶段只需保证出点/入点画面状态匹配。
5. **质检回炉**：每镜生成后对照分镜表检查——人物是否漂移、场景陈设是否一致、动作是否完成、时长是否合规；不合格即调提示词重生成，不凑合。

### 阶段九：整合成片

1. **画面组装**：按全片时间码顺序排列所有镜头片段；组间按既定衔接方式处理（J-cut/L-cut 在剪辑时间线上实现声音提前/延后；叠化按标注重叠时长执行）。
2. **声音合成（四层，自下而上）：**
   - 音乐层：按进入/退出时间码铺设，对白段压低；
   - 环境音层：按组铺设基调，组间渐变交接；
   - 拟音层：按精确时间码对点；
   - 配音层：按配音锚点逐句生成/录制，情绪标注来自分镜表。
3. **成片自检**（对照文末质量红线全量过一遍）→ 导出。

## 产出什么

按执行阶段交付，层层递进，缺一不可：

1. **项目信息表**：片名 / 类型 / 目标总时长 / 镜头组总数 / 画幅 / 影调风格（含统一影调词串）/ 一句话故事核 / 情绪曲线（文字版）
2. **四大锚点表**：人物锚点表、场景锚点表、道具锚点表、配音锚点表（字段见阶段二）
3. **分镜表（核心交付物）**：按镜头组组织，每组先给「组头信息卡」（格式见阶段三），再给该组分镜表。列结构固定：

镜号时间码(起-止)时长景别角度运镜画面描述（含人物/场景/道具锚点原文）台词/配音（含配音锚点）音效/音乐（含时间码）入点转场出点衔接剪辑备注

**画面描述模板（每镜必须遵循）：**`【SCENE-X锚点原文】+【CHAR-X锚点原文】+【PROP-X锚点原文(如出场)】+ 主体动作与表演细节 + 景别/角度/运镜 + 光影变化 + 氛围词`写好的画面描述必须是**可直接复制投喂 AI 视频生成工具的自包含提示词**——脱离分镜表单独看也信息完整。

4. **音效音乐总清单**：按时间码列出环境音基调（按组）、拟音音效（精确到秒）、音乐段落进入/退出点。
5. **素材需求总表 + 素材图片文件**：人物定妆图、场景空镜基准图、道具特写图，按锚点 ID 命名（见阶段七）。
6. **组-素材对照表 + 逐镜生成提示词清单**（见阶段八）。
7. **镜头视频片段 + 整合成片**（如当前环境具备视频生成与剪辑条件；不具备时交付到第 6 项，并给出明确的生成执行手册）。

## 什么时候问用户

- 题材、时长、平台全都没给，且直接影响结构决策 → 只问一次，问完自己定其余全部。
- 角色超过 3 个且关系不明 → 问一次。
- 素材图与锚点出现方向性分歧（如用户提供的定妆照与文字锚点冲突）→ 问一次以哪个为准。
- 用户要求与专业规范冲突（如明确要越轴、无锚点换造型）→ 一句话说明专业代价，然后按用户意愿执行，不纠缠。
- 其余一切情况：按专业默认直接产出，不追问、不索要确认。

## 质量红线（交付前自检）

 1. **时间码连续**：全片从 00:00 起无缝衔接，无空隙无重叠（标注了重叠时长的叠化除外）。
 2. **镜头时长合规**：每镜 1\~3 秒；超 3 秒必须有剪辑备注写明动机，且不超过 4 秒。
 3. **镜头组合规**：每组 ≤15 秒，组头信息卡齐全（时间码区间/戏剧功能/情绪节拍/出场锚点/环境音基调/组内衔接策略/组间衔接方式/所需素材）。
 4. **锚点一致性**：全片任何镜头的人物/场景/道具/配音描述与锚点卡逐字一致。
 5. **五要素齐全**：每镜必有 景别+角度+运镜+画面描述+声音标注。
 6. **衔接明确**：每镜入点转场与出点衔接都有标注；每组末尾标注到下一组的衔接方式，禁止「裸跳」。
 7. **轴线检查**：关系戏标注轴线方向，无无动机越轴；相邻镜头符合 30° 规则或已换景别。
 8. **声音连续**：同组同场景环境音跨镜头连续；高潮爆点前有静音设计。
 9. **画面描述自包含**：任意一镜单独复制出来可直接用于 AI 视频生成。
10. **素材闭环**：每个镜头组引用的素材均已生成且命名与锚点 ID 一致；素材图与锚点卡逐项比对通过。
11. **节奏服务情绪**：组内镜头时长曲线与情绪曲线同向，高潮段镜短声密，余韵段镜长声稀。
