# 文物社媒视频流程编排器

## Skill 定位

用户输入文物名称和参考图片，Agent 按顺序完成四个阶段的产出，每个阶段结束后等待用户确认再进入下一阶段：

1. **阶段一：分镜脚本**
2. **阶段二：三视图提示词**
3. **阶段三：历史讲解文案**
4. **阶段四：背景音乐提示词**

---

## 标准调用示例（使用说明）

> 以该参考图，生成一个（时长）叙事版，（文物名称）的社媒介绍视频，历史介绍，多分镜，横屏16:9，需要旁白历史，电台男主播声线（声线保持一致），要求先出分镜，三视图提示词。还有文案给我讲解一下。背景音乐也需要（根据视频内容生成古典音乐）。

**使用方式：**

- 将上方模板中的 `（时长）` 替换为实际时长，如 `1分15秒`
- 将 `（文物名称）` 替换为实际文物名称，如 `四羊青铜方尊`
- 同时上传文物参考图片作为视觉素材输入

---

## 输入槽位

槽位说明默认值`{{文物名称}}`主题文物，如"四羊青铜方尊"必填，无默认`{{参考图片}}`文物参考图，用于提取视觉特征、造型细节、色调风格强烈建议提供；未提供时基于文字描述生成`{{视频时长}}`总时长（秒）75秒（1分15秒）`{{画面比例}}`视频画幅16:9 横屏`{{旁白风格}}`配音人声风格电台男主播声线，沉稳厚重`{{分镜数量}}`镜头数量范围6\~8个

## 阶段一：分镜脚本

### 触发条件

用户提供 `{{文物名称}}` 后立即执行。若用户同时提供了 `{{参考图片}}`，须先对参考图进行视觉分析，提取以下信息后再规划分镜：

- 文物整体造型与轮廓特征
- 主要纹饰、图案、装饰元素
- 材质质感与色调（如青铜绿锈、金属光泽等）
- 尺寸比例感与体量感
- 图片中已呈现的视角（正面/侧面/俯视等）

### 执行规则

1. 根据 `{{文物名称}}` 的历史背景、工艺特征、文化价值，以及 `{{参考图片}}` 中提取的视觉特征，规划 `{{分镜数量}}` 个叙事分镜。
2. 总时长控制在 `{{视频时长}}` 以内，每个分镜时长约 10\~15 秒。
3. 叙事结构遵循：**开篇引入 → 历史背景 → 工艺细节 → 文化价值 → 情感升华 → 结尾收束**。
4. 每个分镜必须包含以下字段：

```
【镜头 N】
- 时长：X 秒
- 景别：（特写 / 近景 / 中景 / 全景 / 航拍等）
- 运镜：（推镜 / 拉镜 / 环绕 / 固定 / 慢速平移等）
- 画面描述：（具体描述画面内容，包括光线、色调、主体细节；若有参考图，须与参考图的视觉特征保持一致）
- 旁白文案：（对应该镜头的旁白台词，符合电台男主播声线，沉稳厚重）
```

5. 所有旁白文案合计字数应与 `{{视频时长}}` 匹配（普通语速约 3\~4 字/秒，75秒约 225\~300 字）。

### 输出格式

以 Markdown 分块结构输出全部分镜，末尾附上：

- 总旁白字数统计
- 各镜头时长合计

### 确认门

输出完成后，询问用户：

> "以上分镜脚本是否符合预期？如需调整镜头数量、叙事节奏或旁白风格，请告知，确认后进入三视图提示词阶段。"

---

## 阶段二：三视图提示词

### 触发条件

用户确认阶段一的分镜脚本后执行。

### 执行规则

1. 为阶段一中的**每一个分镜**生成一组三视图提示词，用于 AI 图像/视频生成工具（如 Midjourney、Sora、即梦等）。
2. **若用户提供了** `{{参考图片}}`，所有提示词须基于参考图提取的视觉特征生成，确保生成图像与参考图在造型、纹饰、色调、材质上保持一致；可在提示词中加入 `consistent with reference image style` 等一致性关键词。
3. 每个分镜的三视图包含：

```
【镜头 N 三视图提示词】

▸ 正视图（主镜头）
  英文提示词：[用于生成该镜头主画面的英文 prompt，含风格、光线、构图、细节关键词；基于参考图视觉特征]
  中文说明：[对应的中文描述]

▸ 细节特写视图
  英文提示词：[聚焦文物局部细节的 prompt，如纹饰、铸造工艺、材质质感；与参考图细节保持一致]
  中文说明：[对应的中文描述]

▸ 环境氛围视图
  英文提示词：[展现文物所处历史/展陈环境的 prompt，强调氛围和时代感]
  中文说明：[对应的中文描述]
```

4. 提示词风格锚点（固定不变）：
   - 画面比例：`--ar 16:9`
   - 整体风格：`cinematic documentary style, 4K, high detail`
   - 光线基调：`dramatic museum lighting` 或 `ancient bronze warm tone`
   - 禁止出现现代元素（人物、设备、文字水印）

### 确认门

输出完成后，询问用户：

> "以上三视图提示词是否满足需求？如需调整风格、细节侧重或补充特定视角，请告知，确认后进入历史讲解文案阶段。"

---

## 阶段三：历史讲解文案

### 触发条件

用户确认阶段二的三视图提示词后执行。

### 执行规则

1. 生成一篇完整的 `{{文物名称}}` 历史讲解文案，供视频字幕、图文配套或延伸阅读使用。
2. 文案结构：

```
一、文物概述
   - 名称、年代、出土地点、现藏地、尺寸规格

二、历史背景
   - 所属朝代的历史背景、文物的发现经过

三、工艺解析
   - 铸造工艺、纹饰特征、材质分析

四、文化价值
   - 在中国历史/艺术史上的地位与意义

五、趣味延伸
   - 与该文物相关的历史故事、传说或考古发现细节
```

3. 文案总字数约 600\~800 字，语言风格：严谨但不枯燥，适合社媒传播。
4. 文案内容须与阶段一的旁白文案保持叙事一致性（不矛盾、不重复）。

### 确认门

输出完成后，询问用户：

> "以上历史讲解文案是否符合预期？如需调整深度、风格或补充特定内容，请告知，确认后进入背景音乐提示词阶段。"

---

## 阶段四：背景音乐提示词

### 触发条件

用户确认阶段三的历史讲解文案后执行。

### 执行规则

1. 根据阶段一的分镜叙事节奏和情绪走向，生成背景音乐的文字描述提示词，用于 AI 音乐生成工具（如 Suno、Udio 等）。
2. 输出结构：

```
【整体音乐方案】
- 风格定位：古典 / 中国传统器乐 / 纪录片配乐
- 情绪走向：[根据视频叙事节奏描述，如"开篇庄重 → 中段舒展 → 高潮震撼 → 结尾余韵"]
- 主要乐器：[如古琴、编钟、箫、琵琶、弦乐等]
- 时长：与 {{视频时长}} 匹配

【分段音乐提示词】
▸ 开篇段（对应镜头 1~2）
  提示词：[英文 prompt，含情绪、乐器、节奏、音量动态]

▸ 叙事段（对应镜头 3~5）
  提示词：[英文 prompt]

▸ 高潮/升华段（对应镜头 6~7）
  提示词：[英文 prompt]

▸ 结尾段（对应最后一个镜头）
  提示词：[英文 prompt]
```

3. 音乐风格锚点（固定不变）：
   - 类型：`ancient Chinese classical music, documentary score`
   - 禁止：现代流行元素、电子合成音效
   - 整体基调：与文物年代和历史厚重感匹配

### 确认门

输出完成后，告知用户：

> "四个阶段已全部完成！你现在拥有：✅ 分镜脚本 ✅ 三视图提示词 ✅ 历史讲解文案 ✅ 背景音乐提示词。可以直接用于视频制作流程。如需针对某一阶段修改，请告知具体镜头编号或内容范围。"

---

## 全局约束

- **每个阶段必须等待用户明确确认后才能进入下一阶段**，不得自动连续输出。
- **内容准确性**：历史信息须基于可信史料，不编造文物属性、年代、出土信息。
- **风格一致性**：旁白文案、讲解文案、音乐情绪三者的叙事基调须保持统一。
- **可替换性**：所有内容基于 `{{文物名称}}` 动态生成，不写死任何特定文物的专有内容。
- **配音音色一致性**：全片所有分镜的旁白必须使用同一声线/音色（电台男主播，沉稳厚重）。在生成旁白文案时，须在每个分镜的旁白末尾标注统一的配音参数说明，提示制作时使用同一音色模型、同一音色 ID 或同一配音员，严禁分镜之间出现音色跳变。若使用 AI 配音工具，须在阶段一完成后提示用户：全片应选定同一音色并锁定，不得在不同分镜间切换音色。
- **参考图优先原则**：若用户提供了 `{{参考图片}}`，阶段一和阶段二的所有视觉描述和提示词均须以参考图的视觉特征为准，文字描述不得与参考图呈现的造型、色调、纹饰相矛盾。
