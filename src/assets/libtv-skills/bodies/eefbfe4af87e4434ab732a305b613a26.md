# 直播间贴片生成

## 这个 Skill 做什么

用户提供产品图 + 风格/氛围 + 文案 + 价格，产出一整套电商直播间贴片素材、最终效果图与贴片动效视频。这是一条**端到端的完整链路**：先分析，再依次生成底图素材、效果图，确认后拆分交付物，最后用纯贴片生成动效视频。

**交付物**：5 张静态图 + 1 条动效视频（默认竖屏 9:16，1080×1920）。

#交付物规格1纯贴片透明底 PNG，不含模特/背景/产品2直播背景纯净场景3模特白底图模特单独，白底4产品白底图产品单独，白底5贴片合集黑底 PNG6贴片动效视频由纯贴片图生视频（最后一步）

**静态图阶段只要 PNG，不要「智能剪辑」节点**（用图片节点直接生成）；动效视频是最后一步。

---

## 触发条件

用户提供产品图 + 风格/氛围 + 文案 + 价格，要求做直播间贴片 / 整套直播间画面。

若文案或价格不全，先按类目和活动性质代拟一套默认文案，交用户确认或修改后再动工。

---

## 生成前分析（两个维度，必须都做）

### 1. 分析行业类目

判断商品所属类目，据此匹配色系、装饰与整体调性。色系与类目对应关系见下方「内置知识库 · 色系与类目」。

### 2. 分析活动性质

区分两种情况，据此匹配色系、装饰、氛围与促销强度：

- **日常活动**：克制、高级、长效表达。用「官方正品 / 会员礼遇 / 日常焕肤」这类措辞，避免「狂欢 / 疯抢」的强促销红。
- **节日大促 / 节日活动**（七夕 / 双11 / 双12 / 618 等）：可用强促销表达，节日专属配色、限时紧迫感、满减/直降/赠品等促销强度更高的组件，并叠加该节日的专属氛围装饰。

分析结论要明确告知用户，并作为后续所有图的风格基准。

---

## 端到端流程（按顺序执行）

### 1. 生成白底产品图

以用户上传的原图为基准，外观一致、包装文字清晰、不变形、不乱码。

### 2. 生成白底模特图

模特形象需符合用户指定的风格与氛围。

### 3. 生成完整效果图

**必须同时链接（reference_nodes）产品、模特、背景三份素材**，缺一不可。

- 背景满幅；模特、产品原样合成，自然融合、光影统一、无白底方块无白边。
- 贴片文字与图标用矢量图层精确排版。

这是**确认门**：效果图交用户确认通过后，才进入拆分步骤；不通过就改到用户满意。若用户对方向不满意（如觉得「不好看」），先问清是哪些维度不满意（配色风格 / 模特 / 背景场景 / 贴片样式 / 排版布局），再给 2\~3 个明确的风格方向供选择，一次改到位，不要盲目重生成。

### 4. 从定稿效果图拆分 5 项

1. **纯贴片**：透明底 PNG，不含模特/背景/产品
2. **直播背景**：纯净场景
3. **模特白底图**
4. **产品白底图**
5. **贴片合集**：黑底 PNG

### 5. 生成贴片动效视频（最后一步）

用**纯贴片**生成动效视频（图生视频，贴片动效）。可用 MiniMax H3，时长 5–15 秒。

动效建议：呼吸光环、流光扫字、逐条滑入、图标依次点亮、粒子漂浮。

---

## 硬性质量要求

所有图（尤其最终效果图）必须满足：

- 所有组件、产品、文案、图标**零 bug、不模糊、不错位、不乱码**。
- **元素与定稿像素级一致**：只做抠图 / 换底，不重绘、不换脸、产品不变形、包装文字清晰。
- **产品全程一致**：无论用户上传还是系统虚拟生成，产品（含包装文字）都要保持一致性、没有 bug、不变形。
- **组件在效果图中与定稿一致**：造型、配色、字体、排版、图标不走样、不被重新设计。

---

## 工艺铁律

这是本流程最核心的约束，直接决定质量能否达标：

- **AI 只生成无文字的场景 / 模特 / 产品**，不负责画文字和图标。
- **所有标题、价格、卖点、权益文字与图标，一律用矢量图层精确排版叠加**，保证锐利清晰、图标与文字一一对应、可核对。
- **定稿组件原样合成**进最终图，而不是让 AI 重画。
- **静态图阶段只要 PNG，不要「智能剪辑」节点**：不调用会产生智能剪辑的编辑合成工具，改用图片节点直接生成。
- **动效视频为最后一步**。

> 让 AI 直接「画」中文小字和图标，必然出现笔画粘连、发虚、图标错位、乱码，反复重生成无法根治。这是本流程全部工艺选择的根本原因。

## 内置知识库

### 组件类型库

- **价格券卡**：满减券 / 直降 / 划线价 / 限时特惠 / 第二件半价 / N折 / 红包 / 购物金
- **标签挂件**：TOP1 爆款 HOT NO.1 徽章 / 丝带标签 / 七夕限定吊牌
- **竖版导航卡**：福利堆叠卡 / 尺码表 / 下单指引
- **横条**：权益条

### 版式规律（9:16）

顶部满幅色块标题 → 中部人物偏右手持产品 → 左侧促销竖卡 → 下方产品货盘 + 倒影 → 底部满幅权益条。

**顶部和底部要铺满屏幕，不留空不留白。**

### 色系与类目

色系适用类目 / 场景红金大促 / 家电 / 食品蓝青数码 / 母婴粉医美 / 七夕绿生鲜 / 踏青暖木中式 / 文玩黑金 / 香槟金美妆个护

### 七夕专属氛围

爱心光晕、鹊桥星光、玫瑰花瓣、爱心金饰、礼盒丝带。

### 动效建议

呼吸光环、流光扫字、逐条滑入、图标依次点亮、粒子漂浮。

---

## 执行顺序小结

1. 收到产品图 + 风格氛围 + 文案 + 价格
2. 分析类目 + 活动性质 → 告知用户
3. 生成白底产品图、白底模特图
4. 链接产品 + 模特 + 背景生成完整效果图 → **交用户确认**
5. 确认通过后，从定稿效果图拆分 5 项（纯贴片透明底 / 直播背景 / 模特白底 / 产品白底 / 贴片合集黑底）
6. 最后用纯贴片生成动效视频
