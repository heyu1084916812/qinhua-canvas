## 三种画幅

分别规定整张故事板、单个画格、最终视频的比例，默认均为 16:9。竖屏成片可用竖屏单格和横向整板；网格由内容决定，不由参考图方向决定。16:9 是精确比例，1.78 仅为近似。

设整板 W×H、C 列 R 行、单格宽高比 q、左右边距 mx、上下边距 my、总标题区 Hh、列间距 gx、行间距 gy、每行格标题高度 ht：

`panelWidth = min((W-2mx-(C-1)gx)/C, q*(H-2my-Hh-R*ht-(R-1)*gy)/R)`

`panelHeight = panelWidth/q`

剩余空间给页眉和边距，不拉伸画格。无需默认展示公式；有硬性像素要求时据此计算。默认九格 3×3，更多内容可选十二格 4×3 或十五格 5×3。每张至少九格，格数等于网格容量。空白不等于空面板。标题保持简短可读。

# 附录 B：题材导演要点

仅应用相关部分，不将案例情绪、人物或动作强加给所有需求。

## 近身打斗与力量对抗

`距离/架势 → 发力与目标 → 防守方式 → 接触 → 偏转或破防 → 受力结果 → 下一状态`

- 区分压肩、抓腕、架臂和推肘，不在图文中互换。写明哪名角色哪只手控制对方什么部位。
- 手还在压腕时不能同时出拳，除非有释放与换手；关键控制保持连续。
- 高潮前建立必要条件，如进入防守内侧、重心失衡、护盾裂开，不无因跳到终结命中。
- 连拳次数由视频时间表达，单格仅一个拳击瞬间和另一手的合法状态，不画压手加两拳。
- 全景建立距离，中景说明回应，特写给接触证据，俯视解释换位；不为丰富镜头重复命中。
- 特效附着来源；存在胸口、地面来源时不写 limb-attached only。双方能量语法可辨，不每次所有颜色齐爆。
- 灵体轮廓、冲击环并非必备；需要时固定来源、数量、退场时点，高亮不遮接触。
- 严格连招超出容量时增加时长或分段，不压成无法辨认的连续光效。

## 表演、舞蹈与情绪

`触发/意图 → 呼吸与目光 → 支撑和重心 → 收缩/伸展/停顿 → 动作后状态`

- 每个舞姿明确支撑脚、手或髋部，以及重心如何从上一姿态到达。膝跪旋转、髋滑、单腿平衡不直接瞬移衔接。
- 打开—回缩—重新尝试可形成阻力，但按主题选择，不把所有独舞写成思念。
- 身体峰值与情绪峰值可分离，如跳跃后握物停顿；为后者留时间，不均分全部格。
- 布带只在需求适用时加入。固定连接点、具体尾端与合理长度；区分手驱动、腰牵引、惯性、重力和摩擦。
- 同一尾端不能既自然垂落又被手举过头顶；手持长绸与系腰长带是不同结构。
- 脸手特写无需同时露腰结，通过前后镜头维持归属；不强求每格完整人物与腰带。
- 握物靠近脸部应有动机和后果。对白不是默认配件，需要时留足时间；不声称未经核验的外语格律或 IPA 正确。
- 提前建立出口与离场方向。空场、遗留物或松弛布料可以承接余韵。

## 物件、产品与操作展示

`初始状态 → 人/机构操作 → 可见变化 → 结果证据 → 收束展示`

- 固定产品比例、结构、开合与部件数量，不把真实产品的未见结构当成已知事实。
- 操作手、接触点与反馈在合适景别中可见；按钮与反馈可拆镜，不无触发变状态。
- 品牌与材质在最终层，白模负责结构和操作。需要准确产品文字时区分它和板上排版文字，不用全局无文字否定需求。
- 灯光帮助读懂材质或功能，不以特效暗示未经支持的性能功效。

## 环境、灾难与奇观

`稳定空间 → 变化源 → 传播路径 → 人/物响应 → 可见结果`

- 无角色时删人物引用和数量约束，锁定空间、尺度与变化目标。
- 先建立受影响目标，再破坏或变形，不爆炸后才出现被毁建筑。
- 风云烟水尘各有来源与尺度，不所有层同步漂移；镜头运动与场景运动分别写。
- 一镜一个主变化，其他层为反馈；光源移动、遮挡变化在后续保持因果。
- 结尾改变明确空间状态，如通道打开、水位落定、尘雾露出新结构，不停在无结果光爆。

## 两个已分析案例的边界

- 近身打斗案例有效地先建立封手/入内条件，再给终结接触和倒地；实际视频有额外切镜及更大幅绕转，不能视为逐格精确执行的证明。
- 独舞案例以同一布带连接全身、脚、手、脸等景别，并分开动作峰值与情绪停顿；部分镜头连接点不清楚，不能宣称物件连续性完全正确。
- 独舞文字要求 2D，但可见故事板与视频有明显体积渲染；报告版本或执行不一致，不归因于未经验证的模型机制。
- 案例只提供设计经验和检查点，不复制其角色、配色、诗句、情节或固定格数。

# 附录 C：电影分镜、构图与运镜标准

每次创作都读取。把高水平导演目标写成可执行的空间与时间选择，不能依赖赞美性形容词。

## 1. 先完整表达，再选择镜头

先写一句核心叙事，再把用户的显性要求逐项映射到镜头。每格必须有一句“这一格让观众新知道什么”。建立条件、改变局势、显示证据、观察反应、确认后果都可构成一镜；无信息增量的重复姿势应重写。

至少九格只是下限。需要十二格才能完整表达时用十二格；不要因固定纸张容量删掉关键结果，也不要增加需求外的角色、战斗或奇观凑格。

节奏服从题材：太极、悬疑、细微表演需要准备和停顿，不能把九格自动均分成九个急促片段。只给了主题时可调总时长，给了明确时长时保留关键节拍、压缩辅助事件，不跳过物理必要过渡。

## 2. 景别节奏：相邻不能相同

统一使用：

代码景别判断依据EWS远景环境主导，人物很小，交代尺度与位置WS全景完整人物和脚部支撑可读，带必要环境MLS中全景约膝部以上，强调身体动作关系MS中景约腰部以上，强调手势与人物互动MCU中近景约胸部以上，强调表情与局部动作CU近景脸或一个关键身体/物件部位占据主要画面ECU大特写眼、指尖、接触面、纹理等更小的局部

无人物镜头按目标物相对尺度类比判断。不要靠同义词和代码改名制造假变化。

先为九格或更多镜头排景别序列，再写动作。例如 `EWS → MCU → WS → ECU → MS → CU → MLS → ECU → WS` 仅展示相邻不同，不是所有作品的固定模板。允许隔镜返回同景别。

俯视、仰视、侧面、越肩都是机位；固定、跟拍、推近都是运镜，不能替代景别变化。主体裁切与占画比例必须支持标注。同一个全身人物只是从左移到右、从平视改俯视，仍属于相同景别。

镜头内发生景别变化时，按故事板关键瞬间标主景别，同时检查上一镜末画面和下一镜开画面的实际尺度。不要以运镜过程规避相邻变化要求；也不为换景别破坏动作可读性。连续 ECU→CU 只有确实显著扩大取景范围且有叙事理由才保留。

## 3. 每格构图必须具体

按当前画幅确定以下信息，挑最重要的写进 BEAT：

- \*\*视觉重点：\*\*观众第一眼应看哪只手、哪个表情、哪个接触点或环境变化。
- \*\*主体位置和尺度：\*\*中央/左或右三分之一/边缘，完整身体或明确裁切，运动前方和视线方向预留多少可用空间。
- \*\*空间层次：\*\*以已有场景锚点组织前景、中景、背景；特写可简化背景。前景有遮挡时不盖住必需证据，不无因添加门框、柱子或道具。
- \*\*线与形：\*\*地缝、墙边、手臂弧、身体对角线如何引向焦点；避免头饰碰边、手掌与脸叠成一团、背景线穿颈等轮廓粘连。
- \*\*留白与压力：\*\*空白服务动作目的，如前进空间、视线对象、人物退出后的余韵；不机械给所有镜头相同留白比例。
- \*\*透视与相机：\*\*镜头高度、水平/仰俯角、与主体的相对方向、广角空间感或压缩关系相互一致。不要同时要求贴近超广角与无透视变形。

在关键前后形成视觉联系：同一构图里位置或姿态改变，或者相同运动方向由全身转为局部。允许有理由的中心对称、偏置、框景、对角线与简洁平面构图，不给每格强塞不同花样。

## 4. 运镜指导要能执行

每镜选择一个主动作，写清：

`相机起始位置/取景 → 被什么动作或视线触发 → 运动方向与路径 → 相对速度 → 关键帧位置 → 停止条件/结束构图 → 揭示的信息`

- 推近：从什么范围靠近哪个证据，何时停止，是否保留手和头。不能每镜都写 slow cinematic push-in。
- 跟拍：跟随哪名角色/哪一接触点，保持什么距离或画面位置，背景怎样产生视差。
- 横移：为了揭示遮挡后的对象、比较空间或维持动作方向；不能移到轴线另一侧却没有交代。
- 升降：由脚步到身体、由个体到环境等明确的信息变化，速度符合时间预算。
- 环绕：仅在需要解释关系时使用有限角度，规划轴线与身体方向；不要给克制题材默认全圈旋转。
- 固定：让动作、重量、对称或停顿主导画面，是有意选择；仍写明固定高度、方位和取景。

相机位移与变焦是不同手段，不能混称。景深、拉焦可作辅助，但要指定焦点对象和触发，不与主运镜争夺信息。无必要时不写焦距数值；写了则保证景别和空间能够成立。

故事板只呈现上述路径中最有用的单个瞬间，视频在对应时刻到达该画面。两份提示词不能分别描述不同的镜头终点。

## 5. 连续性必须跨镜检查

对每条连接 Pn→Pn+1 检查：

1. \*\*身体：\*\*支撑脚、重心、手的任务、关节姿态和动作完成阶段能衔接；下一镜不重启上一步。
2. \*\*方向：\*\*人物屏幕移动、视线和对手关系一致。换轴需要明确的可见过渡或中性轴向建立镜头，不用一次硬切让方向翻转。
3. \*\*空间：\*\*地面锚点、目标、出口与角色距离一致；特写结束后回到可辨认的位置。
4. \*\*物件：\*\*归属、持握手、连接点、绷紧/松弛、完整/破损状态延续。
5. \*\*光效声音：\*\*光源侧、特效来源和消散阶段延续；声音按触发发生，音桥不能无因重复接触。
6. \*\*剪辑：\*\*切在动势、目光、接触、声音或反应的明确时刻。匹配动作方向和画面落点，让观众不必重新寻找重点。

若使用省略剪辑，声明省略的过程并保证下一状态可理解。核心需求涉及的落地、接触、开合、命中或反应不能被省略。
