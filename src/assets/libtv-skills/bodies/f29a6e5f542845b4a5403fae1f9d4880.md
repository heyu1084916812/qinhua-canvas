# 爆款AI视频剧本拆解

## 这个 Skill 是做什么的

用户提供一个爆款 AI 生成视频（真人风格、动漫画风等均适用），Agent 对视频内容进行逐帧拆解，每一次镜头切换单独输出一个标准剧本场景块并配精准时间节点，剧本开头统一描写一次画风与风格，结尾附上可复用的创作建议。

## 什么时候该用

- 看到一条爆款 AI 生成视频，想逐帧搞清楚它的拍摄逻辑和叙事结构
- 想复刻或改编某条视频的分镜设计和拍摄手法
- 需要一份带精准时间节点、标准剧本格式的完整文档用于后续创作
- 适用视频类型：AI 真人风格、AI 动漫画风等 AI 生成视频

## 什么时候不该用

- 视频不是 AI 生成类型（如真实拍摄的真人视频、非 AI 制作的动画）
- 只想要简单的视频摘要，不需要完整剧本格式

## 输入

用户直接提供视频文件或视频链接。开始拆解前，先确认用户已提供视频内容。

若用户未提供视频，暂停执行并提示：「请先提供需要拆解的视频文件或链接，我来为你进行完整的剧本拆解。」

## 输出格式

### 第一部分：画风与风格描写（仅在剧本开头出现一次）

在所有场景块之前，输出一段对该视频整体画风与风格的精准描写，包括：

- 画面风格（写实/动漫/赛博朋克/古风等）
- 色调与色彩倾向
- 光影特点
- 镜头语言整体风格
- AI 生成特征描述（如有）

格式示例：

```
【画风与风格】
画面风格：……
色调：……
光影：……
镜头风格：……
AI生成特征：……
```

---

### 第二部分：逐镜头场景块

每一次镜头切换单独输出一个场景块，不合并。每个场景块前一行标注精准时间节点。场景之间空一行。不限制字数，以内容完整为准。

**格式示例：**

```
时间节点：00:00–00:03

001（开场）日 外 地点大类 - 地点小类
人物 - 姓名1、姓名2
服装 - 姓名1（服装描述）、姓名2（服装描述）
道具 - 道具1、道具2

▲ 动作描写，描述画面中发生的事情、人物动作、镜头运动、光影氛围等。不重复描述整体画风。
姓名1：台词内容
姓名2 OS：内心独白内容（仅在视频中明确有内心独白时使用）
```

**格式规则：**

- 时间节点写在场景头前一行，格式：`时间节点：00:00–00:03`，精准到秒
- 每一次镜头切换单独成一个场景块，不与相邻镜头合并
- 场景头格式：`[编号]（所属段落）[昼夜] [内/外] [地点大类] - [地点小类]`
  - 昼夜：日 / 夜 / 晨 / 黄昏等
  - 内/外：内（室内）/ 外（室外）
  - 所属段落：开场 / 发展 / 高潮 / 结尾，括注在编号后
- 人物行：`人物 - 姓名列表`（本场景出现的人物）
- 服装行：`服装 - 姓名（描述）`（逐一列出每个人物的服装）
- 道具行：`道具 - 列表`（本场景涉及的关键道具、环境元素）
- 空一行后开始动作与台词
- 动作描写用 `▲` 开头，包含：画面内容、镜头描述（景别/机位/运动）、光影变化、转场方式等；**不在场景块内重复描述整体画风与风格**
- 台词格式：`人物名：台词内容`
- OS独白格式：`人物名 OS：内心独白内容`（仅在视频中明确有内心独白/旁白时使用，不强制添加）

---

### 第三部分：可复用的创作建议

基于以上拆解，总结该视频在以下方面的可复用规律：

- 叙事结构公式
- 情绪钩子设计
- 镜头语言习惯
- 口播节奏特点
- 可直接套用的创作技巧

## 执行步骤

1. 确认用户已提供视频文件或链接；若未提供，暂停并提示用户先提供视频
2. 访问并完整观看视频内容，判断是否为 AI 生成视频；若不是，告知用户此 Skill 适用于 AI 生成视频，询问是否继续
3. 观察视频整体画风与风格，在剧本开头输出一次「画风与风格」描写，后续场景块不再重复
4. 按时间顺序逐帧分析，识别每一次镜头切换点（包括景别变化、机位变化、剪辑切换等），每次切换单独成一个场景块
5. 为每个场景块标注精准时间节点（格式：00:00–00:03，精准到秒）和所属段落（开场 / 发展 / 高潮 / 结尾）
6. 按标准剧本格式逐一输出每个场景块：
   - 时间节点写在场景头前一行
   - 场景头包含编号、所属段落、昼夜、内/外、地点
   - 人物行、服装行、道具行逐一列出
   - 动作描写（▲）整合画面、镜头、光影、转场等视觉信息，不重复整体画风描述
   - 台词写清楚角色名；OS独白仅在视频中明确有内心独白时才写，不强制添加
7. 所有台词以完整句子呈现，不做省略
8. 完成所有场景块后，输出「可复用的创作建议」模块
9. 最终产出为一份结构完整、精准时间节点、标准剧本格式、可直接用于二次创作的剧本文档
