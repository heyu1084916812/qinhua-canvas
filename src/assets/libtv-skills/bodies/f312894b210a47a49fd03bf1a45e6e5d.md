# 品牌营销短剧成片流水线

把一份营销剧本，经「角色/产品资产 → 逐镜分镜图 → 逐镜分镜视频 → 合成」跑成一条可直接投放的营销短剧成片。

## 输入

- `{{品牌与产品}}`：品牌名、主推产品、核心卖点（如续航、用车成本、保养）。
- `{{营销主题}}`：本次要传达的主线，如「家用出行升级」。
- `{{成片时长}}`：默认约 1 分钟（原画布为 50 秒 / 5 段）。
- `{{人物设定}}`：主角与关系人，含年龄、身份、性格（原画布：女儿小夏 26 岁精致上班族、妈妈 55 岁节俭型时尚长辈）。
- `{{品牌资产图}}`（可选）：人物参考图、产品图；有则作为角色三视图与分镜图的上游输入。

## 最终产出

- `{{成片}}`：一条营销短剧视频（原画布对应「视频合成 6 成片」，链路末端 result.mp4）。

## 阶段 0：剧本（文本节点）

产出 `{{剧本}}` 文本节点，内容必须包含 6 项：标题、时长、风格、人物小传、逐场景（地点＋时间码＋台词/旁白）、道具清单与背景音乐走向。

- 原画布取值：风格「轻喜剧＋情感向＋产品卖点植入（自然不生硬）」；5 段共 50 秒（小区楼下 → 车内 → 车内 → 停车场 → 停车场）；道具：主推车型、手机、购物袋、车钥匙；配乐「开头轻快俏皮、中间温馨舒缓、结尾大气有质感」。
- 替换为你的 `{{风格}}`、`{{场景}}`、`{{台词与旁白}}`、`{{道具}}`、`{{配乐走向}}`。
- 要点：产品卖点写在人物对话里（如用车成本、续航），旁白只做结尾一句品牌主张，避免说教。

## 阶段 1：人物与产品资产

1. 准备/生成角色定妆图：`{{主角定妆图}}`、`{{配角定妆图}}`。
2. 准备产品参考图：`{{产品图}}`；有贯穿道具时再加 `{{道具图}}`。
3. 用「角色三视图生成」节点把角色立起来，原画布是 3 个此类节点：
   - `{{角色三视图A}}` ← `{{配角定妆图}}` + `{{剧本}}`
   - `{{角色三视图B}}` ← `{{主角定妆图}}` + `{{产品图}}` + `{{剧本}}`
   - `{{角色三视图C}}` ← `{{主角定妆图}}` + `{{剧本}}`
- 提示词、模型与生成参数：按需填写（原画布快照未提供）。

## 阶段 2：分镜脚本表

- `{{脚本表}}`（script_table 节点）← `{{剧本}}`，把剧本拆成逐镜脚本（原画布为 11 行）。
- `{{分镜图分组}}`：以该脚本表为来源的分镜图分组容器，用于收纳后续分镜图节点。

## 阶段 3：逐镜生成分镜图 → 分镜视频

对每一个镜头 `{{分镜k}}` 重复：

1. **分镜图**：多输入节点，把要用到的人物/产品资产连进同一个分镜图节点，让画面人物与道具和资产保持一致。原画布上的实际搭配方式：
   - 主配角同框：`{{主角定妆图}}` + `{{配角定妆图}}`；
   - 带产品/道具的镜头：再加 `{{产品图}}` 或 `{{道具图}}`；
   - 需要沿用上一镜人物状态或画面：把上一镜的 `{{分镜k-1}}` 也连进来（原画布中「分镜 #2 ← 分镜 #3」「分镜 #1 ← 分镜 #2」即此类回连）；
   - 需要角色形象一致性时，把对应的 `{{角色三视图}}` 也连进来（原画布中分镜 #10 同时连了三视图）。
2. **分镜视频**：以该 `{{分镜k}}` 为上游生成对应分镜视频 `{{分镜k视频}}`。
3. **跨镜延续**：下一镜的图或视频可以直接把上一镜的视频连进来（原画布中「视频节点 2 ← 视频节点 5」「视频节点 4 ← 视频节点 5」），用于动作/口型衔接。
- 各分镜图、分镜视频的提示词与模型参数：按需填写（原画布快照未提供）。

## 阶段 4：合成

把要进入成片的分镜视频全部连进 `{{合成节点}}`（video_clip「视频合成」）。原画布该节点有 11 路上游，其中一部分是辅助/衔接视频而非最终镜头，按你的实际情况取舍数量即可。

## 阶段 5：成片

`{{成片}}` ← `{{合成节点}}`，输出最终 MP4，交付前抽看节奏与卖点是否落在台词里。

## 锚点（固定工艺，不要改）

1. 三段式结构不可跳：剧本 → 角色/产品资产（含角色三视图）→ 分镜图 → 分镜视频 → 合成 → 成片。
2. 每个分镜图节点都必须连入对应的人物/产品资产，保证人物一致性；不要用纯文生图跳过资产阶段。
3. 先从剧本节点生成脚本表，再按脚本表展开分镜，不要跳过脚本表直接生成分镜图。
4. 跨镜一致性靠「上一镜的分镜图或视频回连进下一镜」实现，这是这套做法的关键工艺。
5. 合成必须用专门的视频合成节点（video_clip），成片是它的下游视频节点，不要用单个分镜视频充当交付物。

## 槽位（每次替换）

`{{品牌与产品}}`、`{{营销主题}}`、`{{风格}}`、`{{场景}}`、`{{台词与旁白}}`、`{{道具}}`、`{{配乐走向}}`、`{{主角定妆图}}`、`{{配角定妆图}}`、`{{产品图}}`、`{{道具图}}`、`{{分镜k}}`、`{{分镜k视频}}`，以及各生成节点的模型名、生成数量、时长、分辨率等参数。

## 执行检查

- [ ] 剧本节点含时长、风格、人物、逐场景台词、道具、音乐走向
- [ ] 角色三视图以定妆图＋剧本为输入
- [ ] 每个分镜图都连入了对应人物/产品资产
- [ ] 每张分镜图都生成了对应的分镜视频
- [ ] 所有要进成片的分镜视频都已连进合成节点
- [ ] 成片由合成节点的下游视频节点产出 MP4

## 本配方不采用的尝试

原画布上还存在同一镜的多版本平行视频、以及未接合成的备用视频链（如「视频节点 10」并行两条、分镜 #5 / #4 / #9 / #11 的备用视频）。这些属于试错稿，不写进配方：生成时遇到多个版本，只保留进入合成的那一版。

## 未确认项

- 各图片/视频节点的提示词、模型名与生成参数未随画布提供，配方中对应位置留为槽位。
- 平行版本的视频节点是否也要进入成片未确认，本配方默认只采用进入合成的那一版。
