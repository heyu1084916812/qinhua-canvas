# AI 短剧全流程制作 Skill

> libTV无限画布流 · 灵活入口 · 15秒叙事单元 · 画布节点联动 · 电影美学风格匹配 · 提示词全中文

---

## 一、启动与欢迎语

激活本 Skill 时，**首先输出欢迎语**，然后等待用户输入：

> **今天想要我帮你做什么？给我一个想法或者给我一篇小说，我帮你把视觉资产做出来。**

随后根据用户输入自动判断启动环节（见"灵活入口"）。

**会话恢复检查**（欢迎语前执行）：读取 `./style-lock.json`，若 `locked=true`，提示用户"检测到已锁定美学风格：《{电影名}》，是否继续？"；否则正常启动。

## 三、全流程步骤

```
项目主节点 → ①创意输入 → ②人物小传 → ③故事大纲 → ④正文小说 → ⑤分镜剧本 → ⑥视觉资产群 → ⑦故事板/视频提示词
```

### 环节①：创意输入

**目标**：提炼故事种子，匹配锁定电影美学风格。

1. 确认核心要素：题材、基调、受众、角色数、画面风格（3D漫剧/2D漫剧/真人拍摄，默认3D漫剧）。
2. 输出"故事种子卡"：题材、一句话概念、核心冲突、风格基调。
3. **美学风格匹配**（仅真人拍摄时）：从题材关键词查 `./knowledge-base/10-电影美学风格映射表.md` 精确/模糊匹配，选定参考电影，用户确认后写入 `./style-lock.json` 持久化。详见 `./knowledge-base/11-风格锁定与注入机制.md`。
4. 询问是否进入人物小传。

> **\[外挂文档\]** 电影美学映射表（17题材×5部电影=85条记录+色卡+质感词包）已移至 `./knowledge-base/10-电影美学风格映射表.md`，仅在真人拍摄风格时按需加载。

### 环节②：人物小传生成

**目标**：生成角色性格、背景、动机与人物关系。

遵循 `./references/01-人物小传规则.md`。每名角色含：姓名、性别、年龄、职业、外貌描述（五官/体型/发型/妆容/服装）、角色定位、性格关键词、人设档案、成长弧光。输出 Markdown 表格。

### 环节③：故事大纲构建

**目标**：生成含起承转合、冲突与结局的完整大纲。

遵循 `./references/02-故事创作规则.md`。大纲含起（开场）、承（发展）、转（反转）、合（结局），每段标注核心爆点与视觉钩子。输出后须用户确认方可写正文。

### 环节④：正文小说创作

**目标**：撰写镜头感正文，保持角色一致性。

遵循 `./references/02-故事创作规则.md` 输出格式规范。核心规则：对话格式 `**角色名**：(动作/情绪) 台词`；关键动作特效用【】标记；每场景结尾有「🎬 视觉钩子」；禁止纯文学抽象描述；场景≤5人、动作2-3步分解、对话驱动。

### 环节⑤：分镜剧本生成

**目标**：将正文转为分镜剧本，确保0吞台词、时长合规、动线清晰。

遵循 `./references/03-分镜剧本规则.md`。需确认画面比例（默认16:9）、单集时长（默认2分钟）、画面风格（默认3D漫剧）。

**四大铁律**：①不吞台词（实际时长≥字数÷语速系数+0.2s缓冲）②叙事单元4-15秒③超15秒强制拆分④排版固定。

**台词计算**：语速系数 正常5字/秒·快速7字/秒·慢速4字/秒；实际时长=字数÷系数+0.2s（向上取整0.5秒倍数，&lt;1秒设1.5秒）；长台词21字+每10-12字切一次；交叉对话强制分镜。

**镜头硬限**：每镜≥1秒；叙事单元4-15秒。

**专业规则**：动线与空间站位（宏观起点→路径→终点，微观画面方位）；色温标注（日间5600K/黄昏4000K/室内3200K/月光6500K）；对话三机位（A双人同框→B说话人→C反应，180度不越轴）；戏型频率（日常1.5-3.5s/打斗0.3-1.2s/混合1-2.5s）。

**三阶自检**：一阶台词时长→二阶镜头≥1秒→三阶叙事单元4-15秒，循环至全部通过。

> **\[外挂文档\]** 分镜规则的完整模板、计算示例、输出格式详见 `./references/03-分镜剧本规则.md`。

**知识库调用**：根据题材和戏型按需读取 `./知识库/` 中的文档辅助分镜设计。如武侠题材读取国风武侠规则和打斗全流程，文戏读取微表情系列。完整调用索引见 `./knowledge-base/12-知识库调用索引.md`。

### 环节⑥：视觉资产提取

**目标**：提取人物/道具/场景，生成全中文资产提示词。

资产类型模板文档核心内容人物资产`./references/04-人物资产模板.md`人物版主视觉、三视图、五官特写道具资产`./references/05-道具资产模板.md`道具主视觉、多角度展示、材质工艺场景资产`./references/06-场景资产模板.md`场景主体、风格对标、布光、色彩美学

**美学风格自动注入**（仅 `./style-lock.json` 中 `locked=true` 且真人拍摄时）：读取锁定风格质感词包和色卡，在提示词末尾无侵入追加"美学风格锚定+美学质感注入+色卡参考"格式块。场景资产注入完整词包，人物/道具资产注入中等力度。详见 `./knowledge-base/11-风格锁定与注入机制.md`。

> **\[外挂文档\]** 电影美学映射表和注入机制已移至 `./knowledge-base/`，仅按需加载。

**知识库调用**：生成资产提示词时参考 `./知识库/` 中的文档。人物资产必读 `./知识库/写实人像去 AI 感提示词大全.md`（去AI感约束）和 `./知识库/电影质感 AI 提示词大全.md`（中英对照）；场景/道具资产参考电影质感提示词大全。完整调用索引见 `./knowledge-base/12-知识库调用索引.md`。

### 环节⑦：故事板与视频提示词

**目标**：按15秒叙事单元生成故事板和逐镜视频提示词。

产出模板文档单位故事板`./references/07-故事板模板.md`每叙事单元一张（2×4八宫格/手绘分镜）视频提示词`./references/08-视频提示词模板.md`每叙事单元一组（总时长15秒）

**美学风格自动注入**（条件同⑥）：故事板追加完整质感词包+色卡；视频提示词追加完整词包+色卡，并将参考电影名写入"导演与电影风格"字段。

> **\[外挂文档\]** 运镜、特效、微表情等专题参考素材存放在 `./知识库/` 目录中，按题材按需读取。

**知识库调用**：生成视频提示词时，根据题材读取 `./知识库/` 中的运镜、特效、微表情文档辅助设计。如武侠题材读取国风武侠规则和打斗全流程，仙侠题材读取仙侠特效和施法手势。完整调用索引见 `./knowledge-base/12-知识库调用索引.md`。

## 四、15秒叙事单元约束（全局铁律）

因 AI 视频生成上限为 15-30 秒，分镜及之后环节必须以 **15秒叙事单元** 为基本单位：

1. **分镜规划**：正文按15秒切分，每单元含起势-推进-落点，2-6个分镜，时间衔接无断层。
2. **故事板**：每单元生成一张，不可跨单元混合。
3. **视频提示词**：每单元生成一组，单组总时长=15秒。
4. **单元间衔接**：标注过渡方式（匹配剪辑/视线引导/声音桥梁/光效转场/黑场淡出）。
5. **时长推算**：1分钟≈4单元，2分钟≈8单元。

详细规则见 `./references/09-15秒叙事单元规则.md`。

## 五、美学风格匹配与注入机制

### 核心流程

```
用户提供题材(真人拍摄) → 查映射表匹配电影 → 用户确认 → 写入style-lock.json → 环节⑥⑦自动注入质感词包
```

### 三项核心能力

能力实现①精确映射+模糊匹配题材关键词→别名表→映射表匹配；支持近义词/组合题材/场景反推/兜底默认②风格锁定持久化写入 `./style-lock.json`，含题材/电影/质感词包/色卡；会话中断可恢复③无侵入注入环节⑥⑦提示词末尾追加美学格式块，不修改原有内容

### 注入条件

仅当 `./style-lock.json` 中 `locked=true` **且** 画面风格=真人拍摄时执行。3D漫剧/2D漫剧不执行锁定注入。

> **\[外挂文档\]** 完整映射表（85条记录）、注入机制详细规则、交互示例均移至 `./knowledge-base/` 目录，仅在需要时加载。

## 六、画布节点联动

节点类型用途项目主节点流程根节点文本节点种子卡、小传、大纲、正文、分镜表、提示词图片节点人物/道具/场景资产图、故事板

```
项目主节点 → ① → ② → ③ → ④ → ⑤ → ⑥资产群 → ⑦故事板/视频提示词
```

## 八、中文提示词强制约束（红线）

**所有提示词禁止英文，必须用中文。**

1. 资产/故事板/视频提示词的所有描述、风格关键词、画质参数均用中文。
2. 英文术语替换为中文（如 cinematic lighting→电影级灯光、Unreal Engine 5→虚幻引擎5、PBR→物理材质渲染）。
3. 数值参数（8K、16:9、f/2.8）和品牌名可保留，但品牌名优先中文化（ARRI→阿莱、Kodak→柯达）。
4. 中英对照参照 `./知识库/电影质感 AI 提示词大全.md` 的中英对照表。
