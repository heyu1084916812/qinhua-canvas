# 宋韵国风视频 · 公开版

作者：**Sim**

以真实古装电影摄影为视觉目标，让环境有空间、人物有身份、光影有来源、材料有触感。既能创作完整视频，也能准备后续制作需要的场景与角色图片。

## 先确定这次交付什么

沿用用户已有主题、人物、画幅、时长和模型。根据用途选择工作流，不把视频提示词截取一段当作所有图片的提示词。

请求主要任务读取资料主题、场景提案、故事给具体世界、人物关系和事件；按用户所需深度交付本文与视觉语言场景底图、环境资产、空镜让场所结构、视点和行动空间成为主体图片资产与模型适配角色、定妆、人物资产、角色多角度先固定身份、脸、发式和服装，再派生所需角度图片资产与模型适配带人物的剧情图、视频首帧一个可见时刻，交代人物位置、动作对象和下一步空间图片资产与模型适配分镜、Seedance 等视频提示词可见的事件、动作交接、人物反应与时间衔接视频创作复盘已有图像或成片看实际结果，优先修影响目标的少量偏差检查与修正

“场景图”若未说明带人，先按环境为主体设计；纯场景底图不添加主角。用户明确要人物活动时保留它，不能一律清空人群。若用户只要一张图片，就给一张的提示词，不自动扩成定妆包或分镜。

关键用途或参考关系不清楚时，只问影响结果的一两项；其余条件可简短说明假设后继续。模型只是平台标签时，不擅自判定底层版本。先提供可用的正文，再处理依赖平台能力的设置。

## 贯穿图像与视频的视觉原则

1. **具体光源。** 写清天光、窗光、铺檐或其他场景光源如何照亮人物和环境。柔和中保留方向与明暗，不把全部阴影抹平。
2. **柔润而可辨。** 近处有皮肤、衣料和器物细节，远处随距离自然变柔。适度空气透视与亮部过渡，不靠浓雾、泛白或大片金光。
3. **空间随用途安排。** 场景资产优先读清建筑、水路、道路和物件位置；角色资产优先读清脸与衣装；剧情帧优先读懂人物当下的关系。
4. **材料各有反应。** 丝织物、粗布、木材、陶器、湿土和水面有不同反光、重量与纹理，衣服不统一变成透光薄纱。
5. **服装服务身份。** 具体说明领口、袖型、衣层、系带、裙或裤的结构，避免只写“古风美女、白衣、飘逸”。不默认年轻女性、宫廷华服、固定画幅或固定景别。
6. **生活与表演有因果。** 剧情里人物有动作对象与可读反应；定妆资产允许自然正面站立和看镜头，不为了“抓拍”牺牲可复用性。
7. **画幅本身承载影像。** 默认无生成字幕、标题、水印和额外电影黑边；文字需要时另按用户要求设计。

具体构图、光影与材质见视觉语言。静态资产与剧情镜头可以使用不同景深和灯光安排，不能强制每张都侧逆光、大光圈、大前景虚焦。

## 生图交付必须完整

先给一句用途与主要画面决定，再给用户能独立复制的最终提示词。Image、Banana、Midjourney 三路共用同一套内容约束，但按各自写法组织；用户点名哪几种，就交付哪几种。

- Image：自然语言写清主体、构图、空间、光影与材料，按需要短分段。
- Banana：自然语言说明参考素材各自负责什么、哪些特征保留、当前只生成或修改什么；没有附件时输出完整文生图正文。
- Midjourney：常规生图优先紧凑英文画面描述，重要主体和景别前置；编辑模式另用明确修改指令。正文与可选设置分开，不能只给参数或泛化审美词。

可按需参考场景图片示例、角色资产示例、剧情关键帧示例。这些是试跑起点，不表示每种模型的最终出图都已验证。

## 视频创作保留完整调度

视频仍按风格与环境 → 人物和道具初态 → 分镜/时间段 → 动作、接触、反应与末态 → 声音 → 连续性要求组织。不给静态图写完整时间轴，也不把视频压缩成一张定妆照。

镜头数、总时长、情绪和关系服从故事，不强制温情、赠物、微笑或大景开场。需要完整视频示例时，选择花市《赠春》或田园《春野一盏》。

## 交付边界

只要创作文本时，不自动运行生成、编辑或发布。工具、参数和参考图只使用实际存在且当前入口支持的项；不虚构图片编号、图片地址、固定身份能力或已通过的生成结果。

图片完成前检查“是否满足资产用途”；视频完成前检查“事件、空间与时间是否成立”。视觉风格不等于历史考据，要求严格复原时再核查具体时期、地区和物件。没有原始提示词与设置时，不从一组失败图反推确定的模型原因。
