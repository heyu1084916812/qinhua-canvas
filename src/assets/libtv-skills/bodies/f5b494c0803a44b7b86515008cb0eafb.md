# 汽车 TVC 广告生产器

以用户提供的脚本初稿和锚点素材为起点，完成从脚本优化、分镜图生成到视频合成的完整汽车TVC生产链路。

> 本 Skill 仅适用于 **LibTV 平台**，所有提示词写法、模型选择、参考图引用规则均以 LibTV 平台规范为准。

## 适用场景

用户已有汽车 TVC 脚本初稿，需完整走完从脚本到成片的生产链路。分镜图和视频段按编号顺序逐张/逐段推进：每张分镜图经用户确认后立即生成对应视频段，不等所有图生成完再统一生成视频。整体节奏、转场、色调在导演构思阶段统一设计并贯穿全程。**用户在第二步选择跳过的分镜，整个 3-1→4-2 单元均跳过，不生成图也不生成视频；如需补生成，按第三步开头的「补生成说明」执行。**

## 不适用场景

- 完全没有脚本初稿
- 只需要广告文案或单张图片

## 锚点素材说明

类型内容要求作用车辆锚点官方多角度产品图锁定车身轮廓、配色、细节人物锚点多角度参考图（含服装、眼镜等特征）锁定人物外貌；自带特征不得在提示词中强行删除环境锚点场景参考图锁定场景氛围；大范围位移须按运镜路线提供多张**车外/室内场景多角度锚点**同一场景从多个方位拍摄的参考图（正面/侧面/背面/斜45°等），或由 Agent 依据脚本生成的多角度环境图；适用于室外和室内场景锁定场景在不同视角下的空间结构和光线，支撑多角度运镜和环绕类镜头，避免视角切换时场景变形或漂移道具锚点摆件、头枕、安全带等特写锁定道具形态和颜色

### 场景多角度锚点：使用说明

**何时需要**：脚本中出现以下任一情形时，须主动提示用户补充或生成（室外和室内场景均适用）：

- 同一场景出现多个不同机位/角度的镜头
- 局部环绕（≤90°）或大范围位移类运镜
- 车辆在同一场景中从不同方向驶入/驶出

**手动添加（用户已有素材）**：

1. 准备覆盖主要视角的多张参考图（建议至少3张：正面/侧面/背面或斜45°）
2. 在 LibTV 平台按顺序上传，依次分配 Mixed 编号（如 Mixed5=正面、Mixed6=侧面、Mixed7=背面）
3. 导演构思阶段声明每个编号对应视角，全程固定不变
4. 提示词中按镜头实际视角引用对应编号，注明"约束场景空间结构和光线氛围不变形"

**无素材时：依据脚本生成多角度环境图**：

1. 从脚本提取场景关键词（地点、时段、天气、氛围、地面材质、背景建筑/植被/室内陈设等）
2. 生成正面/主视角基准图，用户确认场景氛围和光线基调
3. 以基准图为参考（@基准图），依次生成侧面、背面、斜45°等角度，提示词须保持光线方向、地面材质、背景元素一致
4. 用户逐张确认，不符合预期的重新生成
5. 确认通过后按视角顺序分配 Mixed 编号，导演构思阶段声明并固定
6. 后续分镜按实际视角引用对应编号，约束场景空间结构不漂移

> 生成的多角度环境图仅作为锚点参考，不代替真实拍摄素材；用户后续提供真实参考图时以真实图替换。

### 大范围位移/路跑类镜头处理规则

单张环境锚点无法支撑连续纵深运动，按优先级选用：

1. 多张环境锚点或「场景多角度锚点」覆盖运镜路线（起点/中段/终点）
2. 拆分短镜头分段生成，再按顺序拼接
3. 切换「全能参考」模式，把多张参考图和锚点一并输入

### 参考图标记使用规范（LibTV 平台）

- **Mixed 编号固定含义，全程不变**：Mixed1=车辆 / Mixed2=人物 / Mixed3=道具A / Mixed4=道具B / Mixed5=环境场景（正面/主视角）。需要超过5类锚点时（如场景多角度、第二人物等），按顺序扩展为 Mixed6、Mixed7……须在第一步声明每个扩展编号对应的素材类型和视角，全程固定。
- **图生视频模式**：以分镜图为构图/基调参考，大模型有较高自由度，不严格锚定每个像素；但车辆、人物、场景等关键资产须严格依据锚点约束，不得变形或失真。不要额外切换为全能参考模式。
- **人物参考图自带特征**（眼镜/发型/服饰）不要写到负面词删掉；不需要该特征时必须更换参考素材。
- **场景基准图机制**：每个场景组内第一个最终确认通过的分镜定稿图（在 3-3 确认通过时即标记），作为该场景组内后续分镜的色调/构图/质感基准；后续同场景组分镜均须 @该场景基准图。**场景基准图一经在 3-3 标记，不因后续 4-1/4-2 视频段未通过而取消标记；视频段重新生成时仍须 @ 已标记的场景基准图。** 不同场景组各自维护独立的场景基准图，不强制跨场景组统一到同一张图；但各场景基准图的整体风格调性必须服从全片风格基准。**场景基准图被重新生成时**：若用户要求重新生成该场景的基准图，须在新图确认通过后更新场景基准图，并提示用户：该场景内已生成的后续分镜图和视频段可能需要重新生成以保持一致，由用户决定是否回滚。

## 生产链路

### 前置步骤：风格确定

**触发时机**：用户提交输入后、第一步开始前，统一检查。仅当用户既未提供风格参考图、也未给出风格描述时触发。

Agent 根据品牌调性、车型定位和核心卖点，推荐2\~3种风格方向，每种包含：风格名称、情绪词描述、调色方案概述（色温倾向/对比度/饱和度）。用户选定后，该风格方向将作为全片风格基准的初始输入，在第一步导演构思确认门正式锁定。

---

### 第一步：优化脚本 + 导演构思

**前置检查**（进入本步骤前，在前置步骤完成后统一执行）：

1. 风格基准缺失 → 已由前置步骤处理；若前置步骤被跳过且风格仍缺失，重新触发前置步骤
2. 车辆锚点缺失 → 提示变形风险，等待用户选择上传或接受风险后继续
3. 脚本含同一场景多角度镜头、环绕或大范围位移运镜（室外或室内均适用）→ 提示用户补充场景多角度锚点，或触发「无素材时生成多角度环境图」流程

**1a. 优化脚本**

- 保留用户脚本的核心剧情和创意方向
- 按广告时长拆分为具体分镜列表，补充情绪节奏建议
- **按场景归组**：将所有分镜按所属场景归组，并在分镜列表中标注场景组名称（如"海边""山地""城市夜景""室内展厅""楼顶""定制场馆"等）。**场景归组判断规则**：
  - 以物理地点 + 光线环境的组合作为判断依据：同一物理地点且光线环境相近的分镜归为同一场景组
  - **同一地点在脚本中非连续出现时，仍归为同一场景组，共用同一张场景基准图**（例如：脚本中 S01\~S03 在海边、S04\~S06 在山地、S07\~S08 再次回到海边，则 S01\~S03 和 S07\~S08 同属"海边"场景组，共用同一张海边场景基准图）
  - 同一地点但光线环境差异显著时（如同一展厅的白天自然光 vs 夜间人工光），可拆分为两个场景组，并在场景组名称中注明（如"展厅-日景""展厅-夜景"）
  - 全片只有一个场景时，该场景第一个确认通过的分镜定稿图即为全片唯一场景基准图，后续所有分镜均 @此图
- **黑名单扫描**：脚本优化完成后、进入1b之前，对照黑名单逐条检查，发现风险项须标注并给出替代方案

**1b. 为每个分镜补充完整导演构思字段**（Agent 主动设计，不需要用户逐条指定）

字段说明编号分镜序号（S01、S02……）场景组所属场景名称（如"海边""山地""城市夜景""室内展厅""楼顶""定制场馆"等），同一场景组内的分镜共用同一张场景基准图镜号全片唯一镜头编号（Shot-01、Shot-02……），跨分镜连续递增；同一分镜内多镜头时依次递增（Shot-03a、Shot-03b）时间节点起止时间（见分镜时长规范）画面描述主体内容、前后景、动作、视线方向旁白/字幕对应文案景别 ★从以下类型中选择并说明叙事理由：**大远景**（宏观环境/地理位置）/ **远景**（整体场景和车辆全貌）/ **全景**（车辆完整入画，含周边环境）/ **中景**（车辆上半部或人物腰部以上）/ **近景**（车辆局部或人物胸部以上）/ **特写**（车标、轮毂、内饰细节或人物面部）/ **大特写**（极度放大的单一细节）；同一分镜内多镜头时须逐镜标注景别变化机位与角度 ★摄影机位置（地面/低角度/平视/高角度/俯拍/航拍）+ 水平角度（正面/侧面/斜45°/背面）+ 仰俯角度；须与景别配合构图方式 ★构图方式（三分法/中心构图/对角线/框架构图/引导线等）；视频比例影响构图；根据叙事需要主动设计运镜路线 ★运动方式+时机+节奏；优先低风险手法（见运镜风险分级）；高风险手法须同步标注风险等级并触发规避方案光线设计 ★主/辅/轮廓光位置、光比、色温；根据场景氛围推导（见光线/调色参考）调色方案 ★色调倾向、对比度、饱和度、质感；**须严格服从第一步锁定的全片风格基准**；同一场景组内各分镜调色须保持一致；风格文字描述须转译为具体调色参数后写入转场方式 ★与下一分镜的转场类型；最后一个分镜填"无"音效设计 ★引擎/环境声/道具声；全局无背景音乐（除非第六步叠加BGM）锚点引用本分镜引用的 Mixed 编号及约束说明（含场景多角度锚点编号和视角）

> ★ = Agent 主动设计

**景别设计原则**：

- 景别须服务叙事目的：开场/收尾建议远景或全景交代环境，高潮/卖点镜头建议近景或特写强化细节
- 同一分镜内多镜头时，景别变化须有叙事逻辑（如远景→近景→特写的递进）
- 景别与机位角度须配合：大远景/远景通常配合高角度或航拍；特写/大特写通常配合低角度或平视
- 景别须在提示词中转化为具体距离感描述（如"全景：车辆完整入画，车身占画面宽度约70%"）

**风格基准处理**：

- 用户提供参考图：从参考图提取主色调、对比度、质感，写入调色方案字段
- 用户提供文字描述（如"自然森系风格"）：转译为具体调色参数——提取色温倾向（暖/冷/中性）、推导对比度和饱和度区间、确定主色调和辅助色、描述质感风格（胶片感/自然光感等），写入每个分镜的调色方案字段
- 均未提供：已在前置步骤确定，直接使用

**运镜风险分级**：

- **低风险优先**：单一方向平移、推进、摇镜、横移、跟拍、固定机位
- **中风险谨慎使用**：局部环绕（≤90°）、缓慢升降、简单跟拍——须精确描述运动轨迹
- **高风险须触发规避方案**：复杂3D完整环绕、大范围位移、多段连续复杂运镜——仅在用户明确要求或叙事强需要时使用，必须同步执行「大范围位移处理规则」或拆分方案

**全片一致性约束**：

> 分为两个层级：全片风格基准（硬性约束，导演构思阶段锁定）和场景内一致性（执行层约束，按场景组分组管理）。

- **全片风格基准（硬性约束）**：在第一步导演构思阶段，必须明确并锁定全片风格基准，包括：整体调色倾向、色温区间、饱和度、对比度、质感风格（如胶片感/数字感）。此基准一经确认不得在后续步骤中随意更改，所有场景组的调色方案均须服从此基准，不允许出现整体风格调性偏离。
- **场景内一致性（执行层）**：同一场景组内的分镜互相保持色调/构图/质感一致。以该场景组内第一个最终确认通过的分镜定稿图作为该场景组的基准图，场景组内后续分镜生成时须 @该场景基准图。不同场景组各自维护独立的场景基准图，不强制跨场景组统一到同一张图；但各场景基准图的整体风格调性必须服从全片风格基准。
- **节奏**：情绪节奏（开场/高潮/收尾）在脚本阶段确定，各分镜时长和运镜须匹配
- **转场**：导演构思阶段逐分镜确定，合成阶段不得自行更改

**分镜时长规范**：

- 标准时长（15s/30s/60s）：单条5s最多3镜；单条8s最多4镜；单镜≥1.5s；高潮镜头建议≥2s
- 自定义时长：按实际总时长等比推算，单镜≥1.5s，高潮镜头建议≥2s，总镜数不超过总时长（秒）÷1.5

**运镜写法示例**（优先复用，不限于此）：

运镜手法具体写法示例平移镜头与车身等高等速横向移动，前景物体飞速掠过拉出横向运动拖影环绕低空平滑环绕车尾，镜头带高速惯性自然抖动推进镜头急速向前推进，贴近车身侧面掠行而过，点状灯光在车身上纵向拉丝流动冲刺POV车头第一人称视角，物体向镜头飞速逼近，出口强光瞬间灌入画面、短时纯白过曝入场车身从画面右侧极速驶入，切开空气

> 光影描述必须写具体物理现象（如"隧道灯光在车身拉出超长横向光影拖影"），禁止抽象描述（如"光在车身上流淌"）。

**光线/调色参考**（根据叙事情绪主动推导，不限于此）：

3-2. 生成分镜图

**提示词结构（静态图）**：

- 【主体描述】车辆/人物/道具的位置、朝向、姿态、材质细节；景别对应的距离感（如"全景：车身占画面宽度约70%"；"特写：车标占画面中心约40%"）
- 【空间层次】近景→中景→背景的分层描述，确保场景有纵深感
- 【光线设计】光源方向、色温数值（如3200K/6500K）、光比（强侧光/柔漫射光）
- 【调色基调】色温倾向、对比度、饱和度、质感风格；须服从全片风格基准；风格文字描述须将转译后的调色参数写入
- 【锚点约束】Mixed编号 + 约束说明；场景多角度锚点须注明对应视角和"约束场景空间结构和光线氛围不变形"
- 【负面约束】明确列出不允许出现的元素、状态、错误

**执行要求**：

- 严格依据第一步导演构思字段执行；调色须服从全片风格基准，且与同场景组已生成分镜保持一致
- 所有锚点均须作为强约束引用，不得忽略
- **场景基准图引用**：若当前分镜所属场景组已有确认通过的定稿图，须 @该场景基准图；若当前分镜是该场景组内第一张（场景基准图尚未产生），则正常生成，确认通过后在 3-3 标记为该场景基准图
- 画质标准：商业广告级别，车辆质感细腻，无明显噪点或模糊
- 默认模型：通用图像 Pro

**生成后自检**（发现问题则重新生成）：

- 车辆数量、停放位置、朝向是否与脚本一致；是否存在明显物理错误（车轮悬空、比例失真等）
- 道具位置、人物配饰是否与参考图一致
- 背景是否有空间层次（近景/中景/背景分层）
- 调色是否服从全片风格基准；同场景组内调色是否与场景基准图一致；景别是否与导演构思一致（距离感、画面占比）

**翻车修复**：

**重新生成规则**：同一张图累计超过2次仍不合格，停止重试，提示用户选择：①更换锚点素材；②调整导演构思；③降低分镜复杂度。

4-1. 生成对应视频段

以分镜图为构图/基调参考，大模型有较高自由度，不严格锚定每个像素细节。**车辆、人物、场景等关键资产须严格依据锚点约束，确保准确还原，不得变形或失真。**

> **场景变形风险提示**：多角度运镜等场景若环境锚点不足，须主动告知用户补充多视角参考图（或触发「无素材时生成多角度环境图」流程），或按「大范围位移处理规则」选择替代方案。

**视频提示词结构**：

- 【全局统一设定】全片风格基准（调色倾向/色温/饱和度/对比度）+ 全局物理规则（运动模糊强度/抖动幅度）+ 全局音效
- 【逐镜描述】机位+景别+运镜方向+速度（缓慢/匀速/急速）+轨迹（弧线/直线/跟随）+物理体感（惯性抖动/平滑滑动）；主体运动方式；光影动态（具体物理现象：光源扫过方向、光影移动速度）；速度感（前景物体飞掠速度、运动拖影长度）
- 【锚点约束说明】各Mixed编号的约束作用；场景多角度锚点须注明对应视角和"约束场景空间结构不漂移"
- 【全局负面约束】明确列出不允许出现的变形/错误/状态

**执行要求**：

- 运镜/光线/调色/转场/音效严格按第一步字段执行；光影描述必须写具体物理现象，禁止抽象描述
- 调色须服从全片风格基准，且与同场景组已生成分镜保持一致；若当前分镜所属场景组已有场景基准图，须 @该场景基准图；若当前分镜是该场景组第一张（场景基准图尚未产生），则无需 @，正常生成
- **合成模式选择**：
  - 优先「图生视频」：适用于大多数场景，以分镜图为构图/基调参考
  - 切换「首尾帧」：需要精确控制视频起止画面时使用
  - 切换「全能参考」：需要多张参考图同时约束、图生视频无法覆盖时使用（如大范围位移、多锚点强约束场景）
  - 记录本次使用的合成模式
- 默认模型：Seedance 2.0；广告时长较长（如60s）、运镜复杂或用户有明确更高质感要求时升级为 Seedance 2.5

**生成后自检**（发现问题则重新生成）：

- 车辆数量、车型、朝向是否与脚本一致；人物外貌、服装、道具是否与分镜图一致
- 速度感是否达标（前景是否有运动拖影）；运镜是否平滑（有无硬切/跳变）
- 调色是否服从全片风格基准；同场景组内调色是否与场景基准图一致；景别是否与导演构思一致

**翻车修复**：

故障修复方案速度感弱，无动态模糊速度感靠前景物体飞快掠过实现，不是光写车跑得快多镜头分镜丢失/融合拆分视频，一条5s最多3镜车辆方向翻转图生视频优先锁定构图；文字写明前进方向；后期水平翻转兜底大范围位移建筑变形按「大范围位移处理规则」执行调色偏离全片风格基准补充全片风格基准调色参数约束并重新生成同场景组调色与场景基准图不一致补充场景基准图调色描述，并 @该场景基准图重新生成多角度场景切换时场景漂移检查是否引用了对应视角的场景多角度锚点；若无，先补充对应角度锚点图

**视频段重新生成与跳过规则**：反复不达标（建议超过2次）时，Agent 主动询问用户是否跳过先继续下一个分镜（由用户决定，不得自动跳过）；跳过的视频段标注"待处理"，所有其他分镜完成后再回来处理。

### 第五步：测试与迭代（可选）

> 触发条件：所有分镜完成后，用户希望对整体效果做系统性复盘和调优时进入。效果已达标可直接跳过进入第六步。

**本步骤的迭代修改须遵循「后期修改分镜的回滚规则」，按修改类型决定回滚范围。**

1. 针对需要调优的分镜，重新出静态图 → 验证车辆/人物/场景/道具是否达到预期（按回滚规则执行，不重做所有分镜）
2. 重新出图合格后，以新图为构图/基调参考、结合对应锚点资产重新生成该分镜的视频段 → 调试运镜、速度、光影动态
3. 效果不满意时：
   - 构图/造型问题 → 回到第三步重新出静态图
   - 速度/运镜问题 → 用户截取上一版视频效果最好的一帧上传，Agent 以此帧为参考、结合锚点资产执行图生视频二次迭代
   - 大范围位移穿帮 → 按「大范围位移处理规则」拆分或切换模式重做
4. 每次复盘3项指标：色调一致性（全片风格基准 + 场景组内一致性）/ 造型还原度 / 运动速度

**确认门**：迭代完成后询问效果是否达标，确认后进入第六步。

### 第六步：背景音乐（可选）

- **不需要**：输出各视频段素材及完整素材清单（格式见「最终产出」章节），用户自行在 LibTV 平台剪辑功能中拼接为完整成片。

- **需要**：在 LibTV 平台视频生成阶段同步生成背景音乐，直接输出含背景音乐的完整成片：

  - 时长与广告总时长对齐
  - 音乐风格从参考图视觉情绪、调色方案或用户风格文字描述推断
  - 提示词中明确描述各段情绪节奏（如：0\~5s 低沉蓄力、5\~20s 激昂高潮、20\~30s 收尾余韵）

  **确认门**：呈现含背景音乐的成片，询问是否符合预期。如需调整，重新生成并再次输出。
