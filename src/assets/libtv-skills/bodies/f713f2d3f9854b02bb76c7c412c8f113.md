# 采访类短视频 Seedance 2.5 多层嵌套生成 Skill

版本：V1.4 默认视频模型：即梦 Seedance 2.5 默认图片模型：GPT Image 2 默认画幅：9:16 默认时长：10秒内优先，采用最短充分时长 默认交付：根据任务自动判断是否需要人物资产、场景资产、产品三视图和完整采访视频提示词。

---

# 一、Skill 名称

采访类短视频 Seedance 2.5 多层嵌套生成 Skill

---

# 二、一句话介绍

根据采访脚本、人物、场景、产品与参考素材，按需生成人物四宫格、纯场景、产品三视图，并输出10秒内优先、逐句深度微表演的 Seedance 2.5 真人采访视频提示词。

---

# 三、适用场景

适用于街采、小区、居家、车内、工位、宝妈、夫妻、用户证言及产品体验等真人采访视频。支持脚本直出和采访视频还原，并可按需生成人物四宫格、纯场景、产品三视图及 Seedance 2.5 完整视频提示词。

---

# 四、如何使用

提供采访口播，建议补充人物、场景、季节、服饰和时长。指定人物时可要求人物四宫格；需要固定场景时可要求纯场景；产品入镜时上传产品图并说明谁拿、是否展示。提供参考视频时说明1:1还原或仅参考构图、情绪、镜头。

---

# 五、输出内容

按任务自动输出人物四宫格、纯场景、产品三视图和完整 Seedance 2.5 采访提示词。未触发的资产自动跳过。已建立的人物、场景、产品统一用@简称调用；视频提示词包含生成设置、时间轴、逐句微表情、声音及负面限制。

---

# 六、做什么

本 Skill 专门处理真人采访类短视频，包括：

- 街头采访
- 小区散步采访
- 居家采访
- 沙发采访
- 车内采访
- 工位采访
- 办公室采访
- 商场采访
- 景区采访
- 用户证言
- 宝妈采访
- 夫妻采访
- 单人口播采访
- 双人采访
- 多人轮流采访
- 产品体验采访
- 带产品展示的采访
- 有参考视频的采访还原
- 无参考视频的脚本直出

核心目标：

 1. 人物必须具有真实活人感，拒绝数字人、假人、蜡像感。
 2. 每一句台词必须单独设计微表情、眼神、呼吸、嘴型、下颌、头肩、手部及身体重心。
 3. 人物双眼必须有明确聚焦对象，禁止空洞失焦。
 4. 中文台词与嘴型严格同步，不吞字、不漏字、不擅自改词。
 5. 默认真人手机采访质感、中近景、一镜到底、轻微手持感。
 6. 默认无模型字幕、无画面文字、无贴纸、无水印、无BGM。
 7. 默认10秒内优先，不为了“完整感”机械拉成12秒或15秒。
 8. 需要指定人物时，可单独输出人物四宫格设定。
 9. 需要固定场景时，可单独输出纯场景设定。
10. 产品需要入镜且用户提供产品图时，先建立产品三视图资产。
11. 已建立的人物、场景、产品资产，在完整视频提示词中统一使用@简称调用。
12. 所有静态图片资产默认使用 GPT Image 2 出图；只有用户明确指定其他图片模型时才切换。

# 七、默认模型路由规则

## 7.1 视频模型

所有采访视频生成提示词默认适配：

**即梦 Seedance 2.5**

除非用户明确指定其他视频模型，否则不得自行切换。

## 7.2 图片模型

所有静态图片资产默认使用：

**GPT Image 2**

包括但不限于：

- 人物四宫格
- 人物正面/侧面/背面设定
- 纯场景图
- 场景 Clean Plate
- 产品三视图
- 产品保守三视角
- 关键静态画面
- 采访首帧
- 产品标准展示图

只要任务涉及“出图、生成图片、建立人物资产、建立场景资产、建立产品资产”，默认直接按 GPT Image 2 的生成逻辑输出对应图片提示词或执行出图。

### 强制规则

1. 用户未指定图片模型时，不询问，直接默认 GPT Image 2。
2. 用户明确指定其他图片模型时，以用户指定模型为准。
3. 视频模型与图片模型必须严格区分：
   - 视频：Seedance 2.5
   - 图片：GPT Image 2
4. 不得因为视频使用 Seedance 2.5，就把人物四宫格、场景或产品三视图交给视频模型生成。
5. 图片资产生成完成并确认后，再作为视频生成中的视觉参考资产使用。
6. 已确认的人物、场景、产品图片资产可以复用，不重复生成，除非用户要求修改。
7. 若用户明确要求“先出图再做视频”，必须先完成 GPT Image 2 图片资产，再进入视频提示词层。
8. 若用户只需要视频提示词且没有要求独立图片资产，则不额外出图。

# 九、多层嵌套任务路由

收到需求后，必须先内部执行：

任务识别 ↓ 参考视频判断 ↓ 指定人物判断 ↓ 独立场景判断 ↓ 产品入镜判断 ↓ 图片资产模型路由判断 ↓ 资产层条件触发 ↓ 采访导演层 ↓ 逐句微表演 ↓ 时长计算 ↓ Seedance 2.5完整提示词 ↓ 强制自检 ↓ 交付

---

# Layer 0｜任务识别层

## 0.1 是否为采访类视频

符合以下任一结构即可调用：

- 画外采访者提问，被采访者回答
- 手持麦克风街采
- 居家采访
- 小区采访
- 用户证言
- 单人采访式口播
- 双人采访
- 多人采访
- 产品体验式采访

如果不是采访类，不调用本 Skill。

## 0.2 是否有参考视频

如用户提供采访参考视频，内部读取：

- 分辨率
- 画幅
- 帧率
- 总时长
- 镜头数量
- 是否一镜到底
- 切镜时间
- 人物数量
- 人物站位
- 景别
- 构图
- 机位高度
- 拍摄距离
- 焦段感
- 手持晃动
- 运镜
- 对焦
- 景深
- 麦克风方向
- 台词起止
- 语速
- 停顿
- 重音
- 动作顺序
- 眼神路径
- 微表情
- 听者反应
- 环境声
- 结尾余韵

用户明确要求“逐帧、1:1、完全还原”时：

必须锁定：

- 总时长
- 镜头结构
- 人物位置
- 构图
- 运镜
- 切镜
- 动作顺序
- 说话轮次
- 情绪节奏
- 环境声

最终提示词禁止出现：

- 参考视频
- 原视频
- 复刻
- 模仿原片
- 照着素材
- 与上传视频一致

必须全部转化为独立、具体、可执行的描述。

## 0.3 是否需要人物资产

满足以下任一条件时触发人物资产层：

1. 用户明确要求指定人物。
2. 用户要求人物单独输出。
3. 人物需要跨镜头稳定。
4. 人物需要跨多条视频复用。
5. 人物为固定主角。
6. 用户要求人物先确认后再生成视频。

否则不单独输出人物资产，人物信息直接融合进完整视频提示词。

人物资产一旦触发，默认使用 **GPT Image 2**。

## 0.4 是否需要场景资产

满足以下任一条件时触发场景资产层：

1. 用户要求单独输出场景。
2. 用户要求先生成场景。
3. 场景需要跨镜头保持稳定。
4. 多条采访需要复用相同空间。
5. 用户要求场景先确认。

否则场景直接融合进视频提示词。

场景资产一旦触发，默认使用 **GPT Image 2**。

## 0.5 是否需要产品三视图

必须同时满足：

【用户提供产品图片】

【当前采访需要产品真实入镜】

才触发产品三视图资产层。

采访不需要产品时，禁止自动生成产品三视图。

产品三视图一旦触发，默认使用 **GPT Image 2**。

## 人物四宫格固定画质提示

白色无缝影棚背景，柔和自然光，细腻接触阴影，高分辨率人物设定稿，专业影视角色概念设计排版。

8K超高清真人摄影质感，真实人体结构，皮肤保留毛孔、自然光泽、轻微雀斑或生活瑕疵；鼻翼与脸颊细小毛孔清晰，轻微不均匀肤色，脸颊和鼻翼极淡泛红，细小面部绒毛清晰；发丝根根分明；嘴唇水润但不过度油亮；瞳孔有真实环境光斑。

冷色调为主，肤色保留自然暖调，光线洁净柔和，高对比但不过度戏剧化。

摄影参数：

- 85mm定焦
- f/2.8
- HDR
- 专业影棚柔光
- 高清锐利

拒绝：

- 塑料皮肤

- 身材漂移
- 正背面不一致
- 四宫格出现不同人物

## 三视图模式判断

### 模式A｜完整三视图

如果真实素材能够确认产品正、侧、背面：

输出：

1. 正面0°
2. 标准侧面90°
3. 背面180°

### 模式B｜保守三视角

如果只提供正面或看不到真实背面：

输出：

1. 正面0°
2. 左前45°
3. 右前45°

禁止擅自编造：

- 背标
- 配料表
- 营养成分表
- 条形码
- 生产信息
- 认证信息
- 隐藏侧面文字
- 不存在的包装结构

- 1:1

- 无手

# Layer 8｜逐句深度微表演系统

每一句台词必须独立设计。

不得整段只配置一个总情绪。

每句话必须包含七阶段：

## 1. 开口前0.2—0.3秒

- 嘴角
- 唇线
- 下颌
- 手部

## 2. 开口瞬间

写清：

- 第一字嘴型

- 瞳孔是否重新聚焦
- 下颌是否下沉
- 肩膀是否随呼气放松

## 3. 句子前半段

写清：

- 初始表情
- 眉眼变化
- 嘴角变化
- 视线路径
- 手指动作
- 身体动作
- 语速
- 音量

## 4. 核心重音

每个主要重音至少绑定一项：

- 眉峰抬起
- 眉头轻压
- 上眼睑打开
- 下眼睑收紧
- 鼻翼轻张
- 嘴角上扬
- 嘴角下压
- 下颌前送
- 点头
- 摇头
- 手指动作
- 手掌翻转
- 身体前倾
- 产品动作

## 5. 后半句变化

必须体现情绪递进，例如：

- 回忆 → 开心
- 疲惫 → 放松
- 认真 → 满意
- 期待 → 安心
- 疑惑 → 笃定
- 无奈 → 释然

禁止整句保持相同表情强度。

## 6. 句尾收住

写清：

- 嘴唇闭合
- 嘴角回落
- 抿唇
- 下颌回收
- 吞咽
- 呼气
- 眉眼放松
- 手势停止
- 视线位置

## 7. 句后0.2—0.4秒余韵

写清：

- 眨眼
- 呼气
- 表情回弹
- 看采访者
- 看同行人物
- 看产品
- 身体重心恢复
- 麦克风是否回撤

# Layer 13｜时长控制系统

默认：

【10秒内优先 + 最短充分时长】

不是默认固定10秒。

例如：

6秒能够完整表达 → 约6秒 8秒能够完整表达 → 约8秒 9.5秒能够完整表达 → 约9.5秒

禁止为了凑时长增加：

- 空镜
- 长停顿
- 重复动作
- 无意义余韵

## 用户明确指定时长

用户明确要求5秒、6秒、8秒、10秒：

严格按用户要求。

用户说：

- 10秒内
- 不要太长
- 控制短一点

则10秒限制优先。

## 长口播处理

10秒无法自然说完时，依次压缩：

1. 无信息停顿
2. 开口预备时间
3. 重复听者反应
4. 重音拖长
5. 结尾余韵

然后允许使用：

偏快但真实、清晰、可理解的采访语速。

禁止：

- 吞字
- 漏字
- 改词
- 删除台词
- 机械倍速
- 嘴型失真

仍无法完成时：

使用完整表达所需的最低超时时长。

若明显超过15秒：

优先按完整语义或完整说话轮次拆成多条，每条尽量10秒以内。

禁止在一句话中间截断。

# 十九、什么时候问你

默认最低干预，不机械追问。

以下情况才询问：

1. 无法判断是否为采访类任务。
2. 用户上传多个产品但无法确定使用哪一个。
3. 用户要求产品入镜但没有产品素材。
4. 用户指定人物，但多个形象要求互相冲突。
5. 用户要求场景资产，但场景条件互相冲突。
