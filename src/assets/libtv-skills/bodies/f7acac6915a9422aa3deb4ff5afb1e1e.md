# Cyberpunk Character Showcase Video Production

## 核心方法论

### 阶段式资产生成框架

完整工作流严格遵循四阶段资产演进,每个阶段产出独立可用的中间资产,避免在最终视频阶段才发现角色设计问题:

**阶段1:风格探索(3:4单角色)**

- 输入:用户提供的参考图(单一风格锚点)
- 工具:Midjourney V7
- 输出:3:4竖版单角色或多角色初稿,用于验证画风、配色、服装细节
- 核心约束:此阶段禁止生成16:9横版,必须保持竖版以聚焦角色本体设计

**阶段2:材质升维(3:4→3D写实)**

- 输入:阶段1的MJ角色图
- 工具:LibNano Pro(超现实3D转换)
- 转换提示词核心元素:
  - 物理材质重建:织物纹理(weave/drape)、金属磨损(scratches/oxidation)、皮肤质感(matte skin texture)
  - 解剖学修复:手指数量/关节、肢体比例、面部对称性
  - 光影系统:纯白背景、柔光+边缘光、无卡通渲染
  - 毛发仿真:逐根渲染、重力流向、次表面散射(SSS)
- 输出:保持3:4尺寸的3D写实角色,供用户确认材质质量
- 关键检查点:在此阶段必须确认角色外观无误,后续不再调整单体设计

**阶段3:横版组合构图(3:4→16:9)**

- 输入:用户确认的3D写实角色
- 工具:Lib Image模型
- 构图逻辑:
  - 多角色排列:左-中-右三点式站位或对称式背靠背
  - 背景文字:粗犷英文大字(组合名称),笔画清晰,无碎屑细节
  - 画面净化:去除多余元素,保持画面柔和以突出角色立体感
  - 武器展示:每个角色的主武器必须清晰可见,作为后续分镜设计依据
- 输出:16:9横版角色组合图,作为视频生成的最终参考
- 尺寸切换原因:横版构图才能容纳多角色并为视频提供正确宽高比

**阶段4:动态视频生成**

- 输入:16:9组合图 + 完整分镜脚本
- 工具:Seedance 2.0
- 输出:15秒集结视频

### 分镜脚本设计框架:3×3矩阵逻辑

每个角色必须占用3个镜头(特写/中景/全景),通过转场技术无缝衔接,最终汇入集结场景。核心维度:

**景别轴(强制三级分布)**

- 特写镜头(Extreme Close-Up):聚焦装备细节(头盔划痕/枪口/剑尖/弓弦),建立质感可信度
- 中景镜头(Medium Shot):展示武器使用技能(射击/挥剑/蓄力),配合镜头快速推拉强化冲击感
- 全景镜头(Wide Shot):呈现角色整体动作+环境关系,同时作为转场出口

**转场逻辑(五类衔接方式)**

- 遮蔽转场:前一角色技能释放时的光效(能量爆发/刀光/枪口闪光)充满画面,光芒消散后切入下一角色
- 动势衔接:跟随运动轨迹切换(子弹飞行路径/箭矢上升/冲击波扩散)
- 相似转场:前后镜头的视觉元素呼应(剑气圆圈扩散→弓弦圆形拉满)
- 无缝衔接:镜头运动连贯性(环绕→俯冲→推进)
- 技巧转场:武器特效作为过渡媒介(刀光弧线扫屏/能量光柱遮蔽)

**节奏控制(快慢镜交替)**

- 慢镜场景:特写镜头、角色入场、最终定格(强调细节/仪式感)
- 快镜场景:武器使用、转场动作、冲击特效(强化速度感/爆发力)
- 时间分配:单角色段4秒 × 3人 + 集结段3秒 = 15秒总时长

**运镜技术(强制多样化)**

- 推拉镜头:配合武器节奏做快速推拉(每次射击对应一次推镜)
- 环绕镜头:360°旋转展示角色全貌(集结场景标配)
- 升降镜头:低角度仰拍(英雄视角)→高空俯冲(建立全景)
- 跟踪镜头:镜头随子弹/箭矢/冲击波高速移动

## 工作流程

### 1. 准备阶段

**必需输入资产**

- \[ \] 用户提供的参考图(风格锚点,单一明确的视觉方向)
- \[ \] 角色提示词(中文完整描述,包含姿势/服装/武器/风格/背景色)
- \[ \] 组合名称(英文,用于最终字幕)

**工具准备检查清单**

- \[ \] Midjourney V7模型(初始角色生成)
- \[ \] LibNano Pro模型(2D→3D转换)
- \[ \] Lib Image模型(横版组合图)
- \[ \] Seedance 2.0模型(视频生成)

**关键决策点**

- 角色数量(2-3人为宜,超过3人会导致单角色展示时间不足)
- 武器类型分布(必须差异化:近战/远程/特殊能力,避免重复)
- 集结场景环境(废墟/工厂/城市广场,需匹配角色风格)

### 2. 执行阶段

**Step 1: MJ角色生成(3:4竖版)**

严格使用用户提供的原始中文提示词,禁止添加任何英文补充。关键操作:

```
输入: 参考图节点 + 用户原始提示词
模型: Midjourney V7
尺寸: 3:4(竖版)
输出: 单个图片节点
```

**常见错误**:

- ❌ 在用户提示词后追加英文翻译/优化(用户明确要求"什么都不用加")
- ❌ 直接生成16:9横版(此阶段必须竖版聚焦角色)
- ❌ 同时生成多张变体(应等用户确认后再迭代)

**Step 2: 3D写实转换(保持3:4)**

使用标准化的3D转换提示词,核心是材质物理化重建:

```
输入: Step 1的MJ图片节点
模型: LibNano Pro
提示词结构:
  "Convert to hyper-realistic 3D CGI collectible figurine render.
  Physically-based rendering, octane render quality.
  Preserve [角色设计/姿势/服装] exactly.
  Transform surfaces into real-world materials:
    - Fabric: visible weave and drape
    - Metal: wear, scratches, oxidation
    - Skin: matte synthetic texture
  Pure white studio background, soft diffused lighting with rim light.
  No cel shading, no toon rendering.
  Fix all hands/fingers: correct anatomy, natural count, proper joints.
  Remove 2D artifacts and compression glitches.
  Hyper-detailed hair simulation: individual strands, realistic clumping,
    natural flow, visible scalp, SSS translucency.
  Pore-level skin texture, fabric fiber micro-detail, specular highlights,
    depth in shadows. Ultra detailed, 8K."
尺寸: 3:4(保持竖版)
输出: 3D写实图片节点
```

**质量检查维度**:

- \[ \] 手指数量正确(5指),关节自然
- \[ \] 面部对称,无重复/扭曲特征
- \[ \] 织物褶皱符合重力
- \[ \] 金属表面有磨损/氧化细节
- \[ \] 毛发有逐根质感,非贴图式块状

**Step 3: 16:9组合图生成**

用户确认3D效果后,基于写实图生成横版组合:

```
输入: Step 2的3D写实图
模型: Lib Image
提示词核心:
  "根据参考图风格,生成[完全相同/完全不同]的角色样貌、服饰、武器、动作。
  人物背后添加[组合名称],英文字体,粗犷有力,大字。
  避免杂碎细节,画面柔和,人物干净立体。"
尺寸: 16:9(横版)
输出: 组合图片节点
```

**构图要点**:

- 多角色排列遵循视觉平衡(高矮胖瘦分布,武器朝向不交叉)
- 背景文字占画面上部1/4,不遮挡角色身体核心部位
- 纯色背景(白色/深灰/渐变),无复杂场景干扰

**Step 4: 分镜脚本生成**

基于16:9组合图中的角色数量和武器属性,按3×3矩阵逻辑编写分镜:

**角色分析清单**:

- \[ \] 每个角色的外观特征(发型/肤色/服装颜色/装备细节)
- \[ \] 主武器类型(枪械/刀剑/弓箭/能量装置)
- \[ \] 武器使用方式(射击/挥砍/蓄力/爆发)
- \[ \] 转场衔接点(武器特效/动作轨迹/光影元素)

**分镜模板(以3角色为例)**:

```
【角色A — 代号NAME_A】武器:XXX
  镜头1(特写): [装备细节推进] 慢镜头
  镜头2(中景): [武器使用技能] 快镜头+推拉配合
  镜头3(全景): [大范围动作+转场出口] 转场方式:XXX

【转场: XXX转场 → 角色B登场】
  过渡描述: [前一镜头元素如何演变为下一镜头入口]

【角色B — 代号NAME_B】武器:XXX
  镜头4(特写): [装备细节] 慢镜头
  镜头5(中景): [武器技能] 快镜头
  镜头6(全景): [动作+转场] 转场方式:XXX

【转场: XXX转场 → 角色C登场】

【角色C — 代号NAME_C】武器:XXX
  镜头7(特写): [装备细节] 慢镜头
  镜头8(中景): [武器技能] 快镜头
  镜头9(全景): [动作+转场至集结] 转场方式:XXX

【最终集结场景】
  镜头10(全景建立): 俯冲至集结场景,三人分别从不同方向入场
  镜头11(环绕展示): 360°环绕,人物微动(风吹/装备闪烁)
  镜头12(定格): 后拉至组合图构图,文字逐笔出现,微动定格
```

**分镜脚本必需元素**:

- 明确镜头编号(1-12连续)
- 景别标注(特写/中景/全景)
- 节奏标注(慢镜/快镜)
- 转场方式命名(遮蔽/动势/相似/无缝)
- 运镜描述(推拉/环绕/俯冲/跟踪)
- 时长分配(每段约4秒,集结3秒)

**Step 5: 视频节点生成**

```
输入: 16:9组合图节点 + 完整分镜脚本文本
模型: Seedance 2.0
参数:
  尺寸: 16:9
  分辨率: 720p
  音画: 同出
  时长: 15秒
提示词: [完整分镜脚本粘贴]
输出: 视频节点
```

### 3. 迭代优化阶段

**角色设计迭代(发生在阶段1-2)**

- 如用户对MJ初稿不满意,重新生成MJ图(调整提示词中的姿势/服装/配色)
- 如3D转换出现解剖错误(手指/面部),重新执行Step 2并加强修复提示词
- 禁止在视频生成后再回溯修改角色外观(返工成本过高)

**组合图迭代(发生在阶段3)**

- 文字样式调整:修改"粗犷有力"为具体字体描述("机械感/书法体/霓虹光效")
- 排列方式调整:"背靠背"改为"三角站位"或"阶梯式排列"
- 背景简化:如出现多余碎屑,强调"纯色背景,无杂物"

**视频分镜迭代(发生在阶段4)**

- 转场不流畅:检查前后镜头的衔接元素是否匹配(光效颜色/运动方向)
- 节奏拖沓:缩短慢镜时长,增加快镜占比
- 角色展示不均:检查每个角色是否严格占用3个镜头

**一致性审计清单**

- \[ \] 角色外观在所有镜头中保持一致(发型/肤色/服装)
- \[ \] 武器类型固定(不能中途切换)
- \[ \] 场景环境统一(废墟/工厂/广场风格贯穿全片)
- \[ \] 光照方向一致(顶光/侧光/逆光)

## 关键约束与标准

### 尺寸规则(不可违反)

- **阶段1-2必须3:4竖版**:聚焦角色本体设计,避免横版导致角色过小
- **阶段3-4必须16:9横版**:容纳多角色排列,匹配视频宽高比
- **禁止混用尺寸**:不能用16:9图转3D,也不能用3:4图直接生成视频

### 提示词使用规则

- **用户原始提示词神圣不可侵犯**:MJ生成阶段严禁添加任何英文翻译/优化/补充
- **3D转换提示词标准化**:使用固定模板,仅替换"\[角色设计\]"等占位符
- **分镜脚本提示词完整性**:必须包含所有12个镜头的详细描述,不能简化为"参考上文"

### 分镜设计铁律

- **3×3强制分布**:每角色3镜头(特写/中景/全景),不能2镜或4镜
- **转场方式多样化**:避免连续使用同一转场类型(如连续3次遮蔽转场)
- **无硬切镜头**:每个镜头切换必须有视觉衔接元素(光效/运动/相似构图)
- **集结场景独立性**:最后3秒的集结段不属于任何单一角色,是独立段落

### 解剖学与物理约束

- **手指修复优先级最高**:3D转换时必须明确要求"correct anatomy, natural finger count"
- **重力逻辑**:织物褶皱/毛发流向/武器挥动轨迹必须符合物理
- **动作夸张但不扭曲**:允许超越现实的动作幅度(跳跃高度/挥砍速度),但关节弯曲方向必须正确

### 视频技术参数

- 模型:Seedance 2.0(当前唯一支持复杂分镜的模型)
- 分辨率:720p(平衡质量与生成速度)
- 音画:同出(自动生成匹配音效,用户要求"无背景音乐"时生成环境音)
- 时长:固定15秒(超过15秒会导致节奏松散,低于15秒无法完整展示)

### 质量验收标准

- \[ \] 角色外观在MJ→3D→组合图→视频全流程保持一致
- \[ \] 每个角色获得平等的展示时长(±0.5秒误差)
- \[ \] 转场流畅无跳跃感(前后镜头视觉元素连贯)
- \[ \] 武器使用符合该武器类型的真实操作逻辑
- \[ \] 最终定格画面与16:9组合图构图完全一致
- \[ \] 背景文字清晰可读,笔画书写动效完整

## 推荐工具与模型

- **\[@tool:lib_nano_pro:LibNano Pro:ICON_URL\]** — 2D到3D超写实转换,物理材质重建能力强,手部修复效果优于其他模型

## 常见问题处理

**Q: 用户提供两张参考图,如何处理**?A: 必须明确每张图的用途。如用户说"参考图一和参考图二",需反问:"是分别生成两张图,还是融合两种风格?"避免自行猜测。

**Q: 3D转换后手指仍然错误怎么办**?A: 在提示词中加强手部修复描述:"Fix and reconstruct all hands with anatomically correct five fingers, proper joint articulation, no fused digits, no extra fingers. Each hand must have exactly one thumb and four fingers."

**Q: 视频生成时角色外观与组合图不一致**?A: 检查是否正确引用了16:9组合图节点作为参考。Seedance 2.0需要明确的图片节点输入才能保持角色一致性。

**Q: 用户要求"完全相同"vs"完全不同"的角色组合**?A:

- "完全相同":复制3D写实图中的所有角色外观(发型/服装/武器),仅改变排列方式和背景文字
- "完全不同":保持风格(赛博朋克/动漫)和质感(3D写实),但重新设计角色样貌/服装/武器类型

**Q: 15秒时长不够展示4个角色怎么办**?A: 不要增加角色数量。15秒是经过验证的最优时长:3角色×3镜头×1.33秒+集结3秒=15秒。4角色会导致单镜时长压缩至1秒以下,无法呈现细节。建议拆分为两个独立视频。
