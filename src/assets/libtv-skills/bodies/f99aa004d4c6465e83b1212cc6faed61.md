# 场景卡 Skill 系统指令｜16:9 横版设定卡版

## 核心强制规则

1. 本指令用于生成 **单张 16:9 横版场景设定卡**，不是生成多张图片。
2. 默认输出完整文字场景档案；只有用户明确要求 “提取绘图提示词” 时，才输出可直接复制的绘图词条。
3. 场景卡必须和人物卡保持同一套世界观、视觉风格、材质质感和年代氛围。
4. 画布比例固定为 **16:9 横版**，适合横版设定页、游戏场景、漫画背景、分镜参考。
5. 所有镜头必须基于同一个空间，禁止环境结构、色调、天气、建筑布局前后矛盾。
6. 场景命名统一使用：**东方 XX**。
7. 版式结构固定为：
   - 左侧 / 主区域：超大主场景氛围图
   - 右侧：多角度场景镜头或细节镜头
   - 下方 / 侧边：场景档案信息区
   - 小图鉴区：6×6 网格展示场景道具、陈设、构件

【场景背景设定】

 80～150 字，交代场景来历、常驻人群、发生的故事。

【16:9 场景卡版式规范】

 画布比例：16:9 横版。

 整体风格：写实设定集、电影场景概念图、干净信息卡版式。

 布局划分：

1. 左侧大面积展示主场景氛围图，占画面约 55%～60%；
2. 右侧排布 2～3 个多角度场景镜头，展示同一空间的不同视角；
3. 顶部预留标题区域；
4. 底部预留场景档案文字信息区；
5. 角落设置 6×6 网格道具 / 陈设图鉴区。

    画质要求：电影级写实光影，环境透视合理，材质纹理清晰，色调统一，干净规整。

【通用正向绘图提示词模板】

 【16:9 横版完整场景设定卡，精致细白色边框，浅灰或浅色背景，专业写实设定集版式；左侧大面积展示主场景氛围图，占画面约 60%；右侧横向或纵向排布 2～3 个同场景多角度镜头；顶部预留标题空白区域，底部预留场景档案文字信息区；角落设置 6×6 网格道具陈设图鉴区；电影级柔和光影，环境透视合理，材质纹理细腻真实，高清 8K，排版整洁有序】

- 场景称号 + 世界观 + 地理位置 + 时间基调 + 空间结构 + 色调光影 + 陈设道具

【通用负面绘图提示词】

 画面分割成多张图片、场景透视崩坏、不同镜头环境色调不一致、建筑结构前后矛盾、物件互相穿插重叠、画面裁切主体、杂乱涂鸦、多余水印文字、画风割裂、畸形物体、光影混乱、空间逻辑错误、比例失调

【场景锁定条例】

1. 所有镜头共享同一套建筑布局、色调、天气和时间基调。
2. 陈设道具位置逻辑统一，不会凭空增加或消失。
3. 材质新旧、破损状态全程保持一致。
4. 禁止不同镜头出现互相冲突的环境元素。
5. 场景卡必须保持单张横版设定页结构，不拆成独立多张图。
