# 活动开场 FPV 穿越视频制作

## 概述

本 Skill 用于为线下活动制作开场宣传视频及正门合成图。 核心手法：FPV 穿越机一镜到底，从城市高空俯冲穿越至室内舞台，完整展现活动视觉体系。 视觉风格锚点：高饱和蓝绿粉撞色，科技感强，动感十足。

## 工作流程

### 第一步：生成活动主视觉卡片

- 输入：{{活动主视觉横版}}
- 操作：基于主视觉横版，生成适配视频用的主视觉卡片版本（竖版/方版）
- 输出：活动主视觉卡片图

### 第二步：生成室内舞台效果图

- 输入：{{舞台风格参考}} + {{活动主视觉横版}}
- 操作：以舞台风格参考为结构锚点，以活动主视觉为配色/内容锚点，生成带活动主视觉的室内 LED 舞台效果图
- 锚点：
  - 舞台结构：圆形升降台 + 顶部环形灯架 + 多块 LED 拼接屏
  - 配色：高饱和蓝绿荧光绿粉色撞色
  - 屏幕内容：完整显示活动主视觉文字与视觉元素
- 输出：室内舞台效果图

### 第三步：生成正门合成图（独立产出）

- 输入：{{正门建筑原图}} + {{活动主视觉横版}}
- 操作：将活动主视觉贴图合成到正门拱门建筑上，保留建筑原有结构与日间实景光线
- 锚点：
  - 保留建筑原始形态，不改变拱门结构
  - 活动主视觉完整呈现在拱门显眼位置
  - 配色与主视觉一致：蓝绿粉高饱和彩虹效果
  - 保留日间自然光，可有人物走过增加真实感
- 输出：正门合成图 ✅ 独立产出

### 第四步：生成 FPV 开场视频（最终产出）

- 输入：{{城市航拍大景}} + {{正门建筑原图}} + 室内舞台效果图 + 活动主视觉卡片
- 操作：以上述四类素材为参考，生成 FPV 穿越机一镜到底开场视频
- 视频结构锚点：
  - 第一段（0\~5s）：高空俯瞰城市大景，FPV 高速俯冲穿越高层建筑群，直冲场馆正门拱门
  - 第二段（5\~9s）：穿过拱门进入隧道，进入室内会场，镜头从舞台近景快速拉开至舞台全景
- 运镜锚点：
  - 全程 FPV 第一人称视角，高速向前俯冲飞行
  - 强烈运动模糊，带呼啸风声/穿梭音效
  - 进入室内后空间混响感增强，轻微环绕拉升
- 视觉风格锚点：
  - 高饱和蓝绿粉撞色，与活动主视觉配色一致
  - 科技感强，动感十足
- 输出：活动开场视频，约 9 秒 ✅ 最终产出
