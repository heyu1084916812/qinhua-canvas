# AI视频脚本创作与分镜生成

## 核心方法论

### 分层推进式脚本创作

将视频创作拆解为三个独立推进层级:

- **需求层(第1阶段)**: 明确视频主题、目标观众、情感基调、时长范围、视觉风格 — 这是剧本的核心约束
- **剧本层(第2-3阶段)**: 完整故事线 → 分场脚本 → 多轮优化 — 固化内容结构
- **分镜层(第4-5阶段)**: 将确认剧本转化为可执行的视觉指令 — 镜头语言、画面描述、时长控制

每层必须经用户确认后锁定,再进入下一层。**禁止跳跃式推进**(例如未确认剧本就输出分镜)。

### 时长驱动的分镜合并逻辑

针对Seedance 2.0的15秒单镜头时长限制,采用**场景连贯性优先**的合并策略:

- **同场景连续镜头**: 若场景不变(例如同一人物对话、同一空间内动作),合并至最多15秒
- **镜头语言一致性**: 合并后的镜头必须保持统一的摄影运动逻辑(例如推镜头组+固定镜头组,不可混合推拉摇移)
- **情感节奏断点**: 当剧情发生情感转折、场景切换、时间跳跃时,必须拆分为独立镜头
- **关键镜头独立**: 特写、冲突高潮镜头即使&lt;15秒也独立保留,不强制合并

合并原则: `总时长 = ∑(镜头时长), 单镜头时长 ≤ 15s, 总镜头数 = 原始分镜数 / 合并率`

### 多轮优化的收敛机制

剧本优化阶段(第3阶段)必须遵循:**每轮迭代只允许修改一个维度**

- **维度1(故事线)**: 情节逻辑、因果关系、人物动机
- **维度2(对白)**: 台词自然度、信息密度、情感表达
- **维度3(视觉)**: 场景描述、动作设计、画面感
- **维度4(节奏)**: 段落时长配比、情绪曲线、叙事张力

每次修改后必须输出完整剧本,由用户确认是否继续优化。**禁止一次性多维度修改**,避免优化方向发散。

## 工作流程

### 1. 需求采集阶段(第1阶段)

**执行逻辑**: 通过5个必答问题建立视频约束边界

采集清单:

1. **视频主题**: 核心表达内容、关键信息点(例如「产品推广」「品牌故事」「教育科普」)
2. **目标观众**: 年龄段、兴趣圈层、观看场景(例如「18-30岁短视频用户」「企业培训受众」)
3. **情感基调**: 轻松/严肃、温暖/冷峻、幽默/正式(例如「轻松幽默的年轻化表达」)
4. **时长范围**: 最短-最长秒数区间(例如「30-60秒」「90-120秒」)
5. **视觉风格**: 实拍/动画、色调偏好、参考案例(例如「电影感实拍,暖色调」)

**关键决策点**:

- 若用户已提供初始脚本,必须询问「是否需要优化」,明确是否跳过第2阶段直接进入第3阶段
- 若用户仅提供主题,必须完成5项采集后进入第2阶段

**输出物**: 《需求确认表》,含上述5项内容,用户确认后锁定

### 2. 完整剧本创作阶段(第2阶段)

**执行逻辑**: 基于确认需求生成初版完整剧本

剧本结构:

- **开场段(10-15%)**: 建立场景/提出问题/抛出冲突
- **发展段(60-70%)**: 信息展开/情节推进/矛盾深化
- **高潮段(10-15%)**: 冲突解决/情感释放/核心信息点
- **结尾段(5-10%)**: 情感落地/行动号召/品牌露出

内容要素:

- **人物**: 姓名、身份、核心性格(若有人物)
- **场景**: 地点、时间、环境氛围
- **对白**: 完整台词(若有配音)
- **动作**: 关键肢体动作、表情、物品互动
- **时长标注**: 每段落预估秒数

**质量自检**:

- 时长总和是否在需求范围内(±10%容差)
- 情感曲线是否符合基调设定
- 是否有明确的视觉抓手(画面可实现性)

**输出物**: 《完整剧本v1》,用户确认是否进入优化(第3阶段)或直接分镜化(第4阶段)

### 3. 多轮优化阶段(第3阶段)

**执行逻辑**: 单维度迭代,每轮输出完整剧本

迭代流程:

1. 用户指出需要优化的维度(故事线/对白/视觉/节奏)
2. AI仅针对该维度修改,保持其他部分不变
3. 输出《完整剧本v2/v3/v4...》,用户评审
4. 重复1-3直至用户确认「剧本最终版」

**禁止行为**:

- 一次修改多个维度
- 未经用户明确要求擅自调整内容
- 输出局部修改(必须输出完整剧本)

**输出物**: 《完整剧本最终版》,用户明确确认后锁定,进入分镜阶段

### 4. 初始分镜生成阶段(第4阶段)

**执行逻辑**: 将剧本逐场景转化为分镜脚本,暂不考虑15秒限制

分镜字段:

- **镜号**: S01, S02, S03...
- **时长**: 单镜头秒数(精确到0.5秒)
- **景别**: 远景/全景/中景/近景/特写
- **机位运动**: 固定/推/拉/摇/移/跟/升降
- **画面描述**: 主体物+环境+光线+色彩,符合Seedance提示词结构(例如「暖色调客厅,阳光透过窗帘,女孩坐在沙发上低头看手机,中景固定镜头」)
- **音频**: 对白/旁白/音效/音乐(若有)

**分镜拆解原则**:

- 每个剧本段落≥1个镜头
- 对话场景:每句关键台词对应1个镜头(反打镜头)
- 动作场景:每个关键动作对应1个镜头(例如「开门」「拿起杯子」各1镜)
- 情绪特写:高潮段必须有特写镜头

**输出物**: 《初始分镜表》,含N个原始镜头(N通常=剧本段落数×2-3)

### 5. 分镜合并与输出阶段(第5阶段)

**执行逻辑**: 应用时长驱动的合并逻辑,生成可执行分镜

合并步骤:

1. **场景聚类**: 标记连续的同场景镜头组
2. **时长计算**: 计算每组总时长,若≤15秒则标记为可合并
3. **镜头语言检查**: 可合并组内检查机位运动是否一致,不一致则拆分
4. **情感断点识别**: 检查是否有情绪转折,有则在该处切断
5. **执行合并**: 合并后重新编号(M01, M02...),更新时长和画面描述

合并示例:

```
原始:
S01 (3s) 特写,女孩低头
S02 (4s) 中景,女孩站起
S03 (5s) 全景,女孩走向门口
→ 同场景,总计12s,机位从特写→中景→全景有推移逻辑
→ 合并为: M01 (12s) 特写推至全景,女孩从低头站起走向门口

原始:
S04 (8s) 室内,女孩关门
S05 (6s) 室外,街道人群
→ 场景切换,不可合并
→ 保留为: M02 (8s) 室内关门, M03 (6s) 室外街道
```

**输出格式**:

```
最终分镜表:
M01 | 12s | 特写推至全景 | [画面描述]
M02 | 8s | 固定中景 | [画面描述]
M03 | 15s | 跟镜头 | [画面描述]
...
总时长: XXs
镜头数: N个
```

**技术参数整合**: 在最终输出时附加:

- **视频时长**: 用户指定或默认总分镜时长
- **画幅比例**: 9:16(竖屏) / 16:9(横屏) / 1:1(方形)
- **分辨率**: 1080p / 2K / 4K

**输出物**: 《最终分镜表(Seedance可执行版)》,每个镜头≤15秒,含技术参数

## 核心约束与标准

### 时长控制规则

- **单镜头上限**: 15秒(Seedance 2.0技术限制)
- **合并优先级**: 场景连贯性 &gt; 镜头数量最小化
- **禁止强制合并**: 跨场景、跨情绪、跨时间线的镜头严禁合并
- **特殊镜头豁免**: 关键特写、冲突高潮镜头即使&lt;5秒也独立保留

### 分镜画面描述标准

- **主体明确**: 必须指定画面主要物体/人物(例如「女孩」「咖啡杯」)
- **环境具体**: 必须包含场景类型(「客厅」「街道」「办公室」)
- **光线描述**: 必须标注光线质感(「柔和日光」「冷色调霓虹灯」)
- **动作清晰**: 必须描述关键动作(「低头看手机」「快速奔跑」)
- **避免抽象词**: 禁止使用「美丽的」「震撼的」等主观形容词,改为具体视觉元素(「逆光剪影」「广角畸变」)

### 工作流推进约束

- **严格阶段锁定**: 每阶段必须输出完整交付物,经用户明确确认后才能进入下一阶段
- **禁止自动推进**: 不可在用户未确认的情况下自动输出下一阶段内容
- **版本追踪**: 每次迭代必须标注版本号(v1/v2/v3...)
- **完整性原则**: 优化阶段每次必须输出完整剧本,分镜阶段必须输出完整分镜表,禁止局部修改

### 优化收敛规则

- **单维度修改**: 每轮迭代只允许修改故事线/对白/视觉/节奏中的一个
- **用户主导**: 优化方向由用户明确指出,AI不可擅自判断
- **3轮警示**: 若优化超过3轮仍未收敛,主动询问用户是否需要重新梳理需求

## 推荐工具与模型

使用 **Seedance 2.0** 进行最终视频生成。该模型支持文本到视频生成,适合处理合并后的分镜序列,单镜头时长限制15秒,适配多种分辨率和画幅比例。

## 高级技巧

### 蒙太奇合并策略

当需要压缩镜头数量但保持叙事节奏时,使用蒙太奇逻辑合并:

- **平行蒙太奇**: 同时发生的不同场景合并为快速切换镜头组(例如「室内打电话 + 室外接电话」合并为一个12秒镜头,画面分屏或快速切换)
- **交叉蒙太奇**: 建立因果关系的不同时空镜头合并(例如「回忆闪回 + 现实特写」)

### 情感节奏映射

在分镜阶段,将剧本的情感曲线映射为镜头时长曲线:

- **平静段**: 镜头时长较长(8-12秒),固定镜头为主
- **紧张段**: 镜头时长缩短(3-6秒),运动镜头增多
- **高潮段**: 极短镜头(2-4秒)+ 特写景别

通过时长节奏强化情感表达,即使合并后也能保持原有节奏感。

### 技术参数预设库

根据视频类型预设常用参数组合:

- **短视频类**: 9:16, 1080p, 30-60秒, 8-12个镜头
- **品牌宣传片**: 16:9, 2K, 60-90秒, 10-15个镜头
- **产品展示**: 1:1, 1080p, 15-30秒, 5-8个镜头

在需求采集阶段快速匹配预设,减少参数决策时间。
