# 狄金斯光影方法

把剧本意图转成能拍、能复现、能检查的摄影方案。先回答观众为什么要看，再决定光从哪里来、机位为何移动。

## 收集输入

优先取得：

- 场景文本、人物目标、情绪转折和必须保留的动作。
- 场地平面、门窗方向、现有灯具、拍摄时段和天气。
- 画幅、交付平台、实拍或 AI 生成方式。
- 角色与道具参考、上一镜与下一镜、可用镜头或等效视角。

信息不足时，列出最少假设并继续给出方案；不要用器材清单掩盖叙事缺口。

## 工作流

### 1. 锁定叙事任务

用一句话写清：观众此刻应与谁站在一起、先看到什么、最后意识到什么。

标出每个节拍的变化：信息揭示、权力转移、情绪转折、身体动作。没有节拍变化，就不要为炫技增加新机位或新灯位。

### 2. 绘制真实光源地图

列出画面内可成立的太阳、天光、窗、门、台灯、顶灯、路灯、车灯或火光。为每个光源写明：

- 叙事理由与开启状态。
- 方向、高度、软硬、色温和衰减。
- 照到谁、避开谁、背景如何分层。
- 实拍需要的隐藏灯、反光、遮光或负补光。

优先使用一个主导方向，再以精确控制完成层次。若某束光无法解释来源，删除、改位或给它建立可信动机。

### 3. 建立克制的镜头语法

为一个场景限定小型焦段家族，保持人物比例与空间关系稳定。每个镜头写明：

- 景别、等效焦段、机位高度、距离和构图重心。
- 前景、中景、背景的叙事作用。
- 摄影机静止或移动；若移动，写出触发它的动作或信息。
- 开始画面、结束画面和与相邻镜头的衔接点。

只有角色、信息或空间关系发生变化时才移动摄影机。避免无理由推进、漂浮运镜和焦段堆砌。

### 4. 设计曝光与可读性

先排序必须保留的视觉信息：面孔、眼神、手部、道具、轮廓或背景出口。再规定：

- 主体相对曝光与可接受的暗部范围。
- 高光保护对象和允许溢出的区域。
- 负补光、剪影、反差和背景亮度关系。
- 从一个空间进入另一个空间时的曝光过渡。

允许黑，但不要让压黑替代选择；允许自然变化，但要知道观众仍能读到什么。

### 5. 转译为生成提示词

把方案写成可见、可执行的描述，依次包含：

1. 人物、动作与空间关系。
2. 构图、机位高度、等效焦段与景深。
3. 光源位置、方向、软硬、色温与衰减。
4. 摄影机运动、触发点、速度和停止点。
5. 曝光优先级、材质、空气与色彩约束。
6. 连续性要求和禁止项。

不要只写摄影师姓名或“电影感”。不要要求复制具体影片、镜头、剧照或人物肖像。

### 6. 做连续性与失败检查

逐镜检查：主光方向、时间、人物轴线、视线、焦段家族、机位高度、肤色、黑位、高光、雾量和运动方向。

发现问题时按以下顺序修正：删掉无理由元素；恢复主要光源；恢复空间关系；恢复曝光优先级；最后才调整风格参数。

## 输出格式

按以下结构交付：

1. **场景意图**：一句话观众位置与转折。
2. **光源地图**：来源、方向、色温、控制与叙事理由。
3. **镜头表**：节拍、景别、焦段、机位、运动、首尾帧。
4. **曝光与色彩**：主体层级、黑位、高光和连续性。
5. **生成提示词**：一版完整提示词与禁止项。
6. **质检清单**：最可能失败的三项与修复动作。
